# 重疾与医疗

> 健康险里最容易混淆的就是"重疾"和"医疗"。一句话：医疗报销看病花的钱，重疾赔一笔让你养病不慌。

## 一、百万医疗险

- **干什么**：住院（含特殊门诊）大额医疗费报销，额度常 200–400 万，年保费几百元。
- **关键点**：
  - **免赔额**：通常年免赔 1 万（社保报销后自付超 1 万才赔），小病用不上、大病才显威力。
  - **续保条件**：优先"保证续保"（如 20 年），避免停售/理赔后买不到。
  - **院外药/特药**：看是否含抗癌药清单、CAR-T 等。
  - **健康告知**：有既往症可能不保/除外，趁健康早买。
- **适合**：所有人基础兜底（搭配社保）。

## 二、重疾险

- **干什么**：确诊合同约定的重疾（如恶性肿瘤、急性心肌梗死等）一次性赔付保额，钱自由支配（治病、还贷、养家）。
- **2020 新规**：重疾定义统一为 28 种重度疾病 + 3 种轻度疾病，各家产品在此基础上扩展。
- **怎么挑**：
  - **保额优先**：30–50 万起步，预算有限先保额。
  - **定期 vs 终身**：预算紧选定期（保到 70 岁）便宜；预算足再终身。
  - **消费型 vs 返还型**：纯消费型杠杆高；返还/两全型"有事赔钱、没事返本"但保费贵很多、收益低，一般不优先。
  - **轻中症/多次赔付**：看是否含轻症中症赔付、是否分组，按需。
- **和医疗险关系**：医疗报医疗费，重疾补收入中断，**不冲突、建议都买**。

## 三、惠民保

- **干什么**：地方政府指导的普惠医疗险，保费极低（几十到百元）、带病可保、年龄不限。
- **定位**：健康异常买不了商业医疗险的"兜底"；健康人仍优先百万医疗（保障更全）。
- **注意**：免赔更高、报销比例略低、特药清单有限。

## 四、高端/中端医疗（可选）

- 想要私立医院、特需部、直付、全球医疗，选中高端医疗；保费高，按预算与需求。

## 五、常见选择

- 标准打法：社保 + 百万医疗（保证续保）+ 重疾（消费型定期，保额够）。
- 老人/带病：社保 + 惠民保 + 意外。
- 儿童：少儿医保 + 百万医疗 + 少儿重疾（定期）+ 意外。

## 六、重疾险深度解析

### 保额选择指南

| 家庭情况 | 建议保额 | 计算依据 |
|----------|----------|----------|
| 单身无负债 | 30 万 | 治疗费 + 康复期生活费 |
| 有房贷（100 万） | 50 万 | 房贷余额 + 治疗费 + 1-2 年家庭开支 |
| 有娃有房贷 | 50-100 万 | 房贷 + 子女教育 + 父母赡养 + 康复费 |
| 家庭经济支柱 | 50-100 万 | 3-5 年家庭刚性支出（替代收入中断） |

- **核心原则**：保额优先于保障期限。预算有限先保到 70 岁做高保额，而非追求终身低保额。
- **通货膨胀调整**：20 年后 50 万购买力约相当于今天 30 万，条件允许可适当超额配置。

### 赔付条件详解

| 条件类型 | 说明 | 注意事项 |
|----------|------|----------|
| 确诊即赔 | 确诊合同约定疾病即赔（如恶性肿瘤） | 部分产品要求"确诊后存活 14 天" |
| 实施约定手术 | 实施手术后赔付（如冠状动脉搭桥术） | 必须是开胸手术，微创不赔 |
| 达到约定状态 | 疾病达到合同约定状态（如脑中风后遗症） | 通常要求确诊后 180 天仍遗留功能障碍 |

### 轻症 / 中症 / 重症

| 等级 | 赔付比例 | 典型疾病 | 作用 |
|------|----------|----------|------|
| 轻症 | 保额的 **20%-30%** | 原位癌、轻度脑中风、不典型心梗 | 降低赔付门槛，早发现早赔 |
| 中症 | 保额的 **50%-60%** | 中度烧伤、中度帕金森 | 介于轻症与重症之间，填补赔付空白 |
| 重症 | 保额的 **100%** | 恶性肿瘤、急性心肌梗死、脑中风后遗症 | 核心保障 |

- **多次赔付 vs 单次赔付**：

| 维度 | 单次赔付 | 多次赔付 |
|------|----------|----------|
| 保费 | 便宜 20%-30% | 较贵 |
| 赔付次数 | 1 次 | 2-6 次（分组/不分组） |
| 适合人群 | 预算有限 | 预算充足、有家族病史 |
| 关键差异 | 赔付一次后合同终止 | 首次赔付后合同继续有效 |

- **分组与不分组**：多次赔付产品将疾病分组（如恶性肿瘤一组、心脑血管一组），同组内只赔一次；不分组产品限制更少但价格更高。
- **恶性肿瘤多次赔付**：癌症复发、转移、持续均可再次赔付，间隔期通常 3 年，实用价值高。

> 来源：中国保险行业协会《重大疾病保险的疾病定义使用规范（2020 年修订版）》

## 七、医疗险深度解析

### 百万医疗险核心要素

| 要素 | 说明 |
|------|------|
| 保额 | 通常 200-400 万（住院医疗费报销，非实际花费） |
| 免赔额 | **1 万元/年**（社保报销后自付超 1 万部分才赔） |
| 保证续保 | 优先选 **保证续保 20 年**的产品，避免停售或理赔后无法续保 |
| 报销范围 | 社保目录内 + 部分产品含社保外（自费药、进口药） |

### 免赔额深度解析

| 免赔额类型 | 说明 | 适合人群 |
|------------|------|----------|
| 1 万免赔（标准） | 年度累计自付超 1 万才赔 | 大多数人 |
| 0 免赔 | 无门槛，花多少报多少 | 预算充足、追求零自付 |
| 5000 免赔 | 折中方案 | 性价比取向 |

- **免赔额的意义**：过滤小额理赔，大幅降低保费，让百万医疗险"几百元保几百万"成为可能。
- **家庭共享免赔额**：部分产品支持全家共享 1 万免赔额，降低家庭总自付。

### 续保条件对比

| 续保类型 | 说明 | 风险 |
|----------|------|------|
| 保证续保（20 年） | 20 年内无论是否理赔、产品是否停售均可续保 | 最优选择 |
| 保证续保（6 年） | 6 年内保证续保，到期后需审核 | 次优 |
| 非保证续保 | 每年审核，停售即无法续保 | 风险高 |

- **20 年期产品到期后**：通常可免健康告知续保该公司其他医疗险（具体看条款）。
- **年龄影响**：50 岁后投保百万医疗险保费显著上升，且健康告知更严格。

### 增值服务

| 增值服务 | 说明 | 实用性 |
|----------|------|--------|
| 院外药/特药报销 | 覆盖抗癌药、靶向药、CAR-T 等院外购药 | 极高（很多抗癌药需院外购买） |
| 质子重离子治疗 | 覆盖尖端放疗技术 | 高（费用约 30 万，社保不报） |
| 就医绿通 | 快速挂号、住院安排 | 中高 |
| 费用垫付 | 保险公司先行垫付医疗费 | 高（解决大额医疗费周转问题） |
| 外购药直付 | 药房购药免现金结算 | 高 |

> 来源：银保监会《健康保险管理办法》、中国保险行业协会

## 八、重疾险与医疗险组合策略

| 组合方案 | 重疾险 | 医疗险 | 适用人群 |
|----------|--------|--------|----------|
| 经济型 | 定期 30 万（保到 70 岁） | 百万医疗（保证续保 20 年） | 预算有限的年轻人 |
| 标准型 | 定期 50 万（保到 70 岁） | 百万医疗 + 院外药 | 有房贷有娃的家庭 |
| 全面型 | 终身 50 万（含轻中症） | 百万医疗 + 中端医疗 | 预算充足家庭 |
| 儿童型 | 少儿定期 30 万 | 百万医疗 | 0-17 岁儿童 |

### 理赔场景分析

| 场景 | 医疗险作用 | 重疾险作用 |
|------|------------|------------|
| 小病住院（花费 5 万） | 社保报销后自付 3 万，医疗险赔 2 万（扣 1 万免赔） | 不赔（未达重疾标准） |
| 确诊癌症（治疗费 50 万） | 报销治疗费（社保 + 医疗险覆盖大部分） | 一次性赔 50 万（自由支配） |
| 心脏支架手术（花费 15 万） | 报销手术费 | 看是否达轻症标准，若达则赔 10-15 万 |

> 来源：中国保险行业协会、银保监会

## 九、常见问题 FAQ

| 问题 | 解答 |
|------|------|
| 重疾险和医疗险可以同时赔吗？ | 可以。医疗险报销医疗费，重疾险赔现金，两者不冲突。 |
| 有了社保还需要百万医疗吗？ | 需要。社保有封顶线、自费药限制，百万医疗覆盖社保外的大额支出。 |
| 惠民保和百万医疗有什么区别？ | 惠民保门槛低但免赔高、报销比例低；百万医疗保障更全但需健康告知。 |
| 重疾险是确诊即赔吗？ | 部分是（如恶性肿瘤），但很多重疾需要实施手术或达到约定状态才赔。 |
| 百万医疗险的 1 万免赔额怎么算？ | 社保报销后个人自付部分年度累计超过 1 万的部分，医疗险赔付。 |
| 买重疾险选消费型还是返还型？ | 预算有限选消费型（杠杆高），预算充足且有储蓄需求可考虑返还型，但性价比通常较低。 |

## 十、重疾险投保健康告知要点

### 常见健康告知问询

| 问询内容 | 影响 | 如实告知要点 |
|----------|------|--------------|
| 既往病史 | 重疾/慢性病可能拒保或除外 | 如实告知所有确诊过的疾病 |
| 体检异常 | 结节、囊肿、血压血糖异常等 | 需提供体检报告，可能加费或除外 |
| 家族病史 | 直系亲属有重大疾病 | 部分产品问询，如实告知 |
| 吸烟/饮酒 | 增加心脑血管疾病风险 | 吸烟者保费通常上浮 20%-50% |
| BMI | 过度肥胖增加疾病风险 | BMI >28 可能被加费 |

### 核保结论

| 结论 | 说明 |
|------|------|
| 标准体承保 | 健康状况良好，按标准费率承保 |
| 加费承保 | 存在一定风险，需额外加费（通常加 10%-50%） |
| 除外承保 | 某些疾病或部位不在保障范围内 |
| 延期承保 | 暂不承保，需观察一段时间后重新评估 |
| 拒保 | 风险过高，保险公司拒绝承保 |

- **多公司投保**：不同公司核保标准不同，A 公司拒保可能 B 公司标准承保，建议同时投保 2-3 家。
- **智能核保**：部分产品支持在线智能核保，即时给出结论，不影响其他公司投保。

> 来源：银保监会《健康保险管理办法》、中国保险行业协会

## 十一、惠民保深度解析

| 要素 | 说明 |
|------|------|
| 定位 | 地方政府指导的普惠型补充医疗保险 |
| 保费 | 通常 **50-200 元/年**（各地不同） |
| 保额 | 通常 100-300 万 |
| 免赔额 | 通常 **1-2 万元**（高于百万医疗） |
| 报销比例 | 70%-80%（低于百万医疗的 100%） |
| 健康告知 | 无或极宽松，既往症可保（但赔付比例可能降低） |

### 适合人群

| 人群 | 是否适合 | 说明 |
|------|----------|------|
| 健康且能买百万医疗 | 不优先 | 百万医疗保障更全 |
| 有既往症买不了百万医疗 | **适合** | 惠民保是唯一的医疗险兜底 |
| 高龄老人（70+） | **适合** | 商业医疗险保费极高或拒保 |
| 预算极低 | 适合 | 50-200 元/年提供基础保障 |

> 来源：各城市医保局、银保监会《关于规范和促进城市定制型商业医疗保险发展的通知》
