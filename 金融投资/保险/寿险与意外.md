# 寿险与意外

> 这两类便宜、杠杆高，却最常被忽略。定寿是"爱与责任"，意外是"小钱大保障"。

## 一、定期寿险（定寿）

- **干什么**：保障期内身故/全残，一次性赔给受益人。主要保**经济支柱**——万一出事，房贷、孩子、父母有人接住。
- **为什么是"底线"**：有房贷、有抚养/赡养责任的人最该买；不保自己，保家人。
- **怎么挑**：
  - **保额**：≈ 房贷余额 + 子女教育到成年 + 父母赡养 + 几年家庭开支（常见 100–300 万）。
  - **期限**：保到责任最重的阶段（如 60 岁、房贷还清、孩子经济独立）即可，不必保终身。
  - **健康告知/免责**：看免责条款（一般 3 条，少的更好）；吸烟者保费更高。
  - **消费型**：便宜（30 岁男 100 万保到 60 岁，年缴常几百到一千多）。
- **不适合**：无负担的单身、已退休者意义不大。

## 二、意外险

- **干什么**：意外导致的身故、伤残、医疗费用。注意"意外"定义——外来、突发、非本意、非疾病（中暑/猝死多数不算意外，除非产品含猝死责任）。
- **怎么挑**：
  - **综合意外保额** 50–100 万（杠杆极高，年保费常百元级）。
  - **意外医疗**关键：0 免赔、100% 报销、含社保外用药，比身故保额更常用。
  - **伤残按等级赔**：意外险按《人身保险伤残评定标准》比例赔付，断指也有得赔。
  - **特定责任**：自驾/公共交通额外赔、猝死责任（酌情）。
- **适合**：所有人，尤其通勤、运动、出差频繁者；老人小孩防摔伤骨折。

## 三、两者组合示例

- 30 岁有房贷有娃：定寿 200 万（到 60 岁）+ 综合意外 100 万（含意外医疗）。
- 老人：侧重意外（防骨折）+ 医疗兜底，寿险意义不大。
- 孩子：意外（含医疗）为主，寿险无需。

## 四、常见误区

1. "我有重疾险了不用买寿险"——重疾不赔身故（除非带身故责任且保额共享），定寿是独立兜底。
2. "意外险随便买"——看意外医疗是否含社保外、免赔额多少，差别很大。
3. "猝死算意外"——多数意外险不含，需专门含猝死责任或靠寿险/重疾（带身故）覆盖。

## 五、定期寿险深度解析

### 定期 vs 终身寿险

| 维度 | 定期寿险 | 终身寿险 |
|------|----------|----------|
| 保障期限 | 固定年限（如 10/20/30 年，或保至 60/65/70 岁） | 终身（必然赔付） |
| 保费 | **便宜**（30 岁男 100 万保到 60 岁，年缴约 800-1200 元） | **贵**（同等保额年缴约 8000-15000 元） |
| 赔付概率 | 保障期内身故才赔，到期未出险不赔 | 必然赔付（100% 赔付概率） |
| 核心功能 | 纯保障，杠杆极高 | 保障 + 财富传承/资产规划 |
| 适合人群 | 有房贷、有抚养/赡养责任的经济支柱 | 有财富传承需求、高净值人群 |

- **消费型定期寿险**：到期未出险不返还保费，但保费极低，杠杆最高。
- **返还型定期寿险**：到期未出险返还已交保费或保额，但保费贵 2-3 倍，一般不优先推荐。
- **储蓄型终身寿险**：保单有现金价值，可退保取钱，兼顾保障与储蓄功能，但流动性差。

> 来源：中国保险行业协会、银保监会《人身保险产品基础术语》

### 保额计算公式

**推荐保额 = 房贷余额 + 子女教育至成年费用 + 父母赡养费 + 3-5 年家庭刚性支出**

| 项目 | 估算方式 |
|------|----------|
| 房贷余额 | 查询银行贷款余额（假设 100 万） |
| 子女教育 | 每年 3-5 万 × 剩余教育年限（假设 20 年 = 60-100 万） |
| 父母赡养 | 每月 2000 元 × 预计赡养年数（假设 10 年 = 24 万） |
| 家庭开支 | 月支出 × 36 个月（约 15-25 万） |
| **合计建议保额** | **约 200-250 万**（可根据实际情况调整） |

### 受益人设置

| 受益人类型 | 说明 | 建议 |
|------------|------|------|
| 法定受益人 | 按继承法分配（配偶、子女、父母平均） | 默认选项 |
| 指定受益人 | 明确指定具体人员及比例 | **强烈建议**，避免理赔纠纷 |
| 多受益人 | 可指定多位受益人及各自比例 | 例：配偶 50%、子女 30%、父母 20% |

- **指定 vs 法定**：指定受益人可避免保险金被作为遗产处理（遗产需先偿还被保险人生前债务）。
- **变更**：投保人可随时变更受益人，无需征得原受益人同意。

### 免责条款

| 常见免责条款 | 说明 |
|--------------|------|
| 投保人故意杀害/伤害 | 不赔 |
| 被保险人故意犯罪或拒捕 | 不赔 |
| 被保险人 2 年内自杀 | 不赔（2 年后自杀可赔） |
| 酒驾/无证驾驶 | 部分产品免责 |
| 战争/核辐射 | 多数产品免责 |
| 特定高风险运动 | 如跳伞、蹦极、潜水超深度等 |

- **免责条款越少越好**：市面上最少的定寿产品仅 3 条免责（故意杀害、故意犯罪、2 年内自杀）。

> 来源：中国保险行业协会、银保监会

## 六、意外险深度解析

### 意外医疗详解

| 要素 | 说明 |
|------|------|
| 定义 | 因意外伤害导致的医疗费用报销 |
| 常见额度 | 1-10 万（意外医疗保额） |
| 免赔额 | 0 免赔最优，部分产品 100 元免赔 |
| 报销比例 | 100% 报销最优，部分产品 80%-90% |
| 报销范围 | 含社保外用药（自费药、进口药）最优 |

- **意外医疗是意外险最常用的保障**：身故/伤残是极端情况，而跌倒扭伤、猫抓狗咬、交通事故门诊等意外医疗才是高频理赔。
- **选择要点**：**0 免赔 + 100% 报销 + 含社保外** 三者缺一不可。

### 伤残等级与赔付

| 伤残等级 | 赔付比例 | 典型情形 |
|----------|----------|----------|
| 一级 | 保额的 100% | 植物人、双目失明 |
| 二级 | 保额的 90% | 偏瘫 |
| 三级 | 保额的 80% | 一肢缺失 |
| 四级 | 保额的 70% | 双耳失聪 |
| 五级 | 保额的 60% | 一肢功能丧失 |
| 六级 | 保额的 50% | 部分丧失劳动能力 |
| 七级 | 保额的 40% | 一指缺失 |
| 八级 | 保额的 30% | 部分功能障碍 |
| 九级 | 保额的 20% | 轻度功能障碍 |
| 十级 | 保额的 10% | 轻微功能障碍 |

- **伤残等级鉴定**：由保险公司认可的司法鉴定机构按照《人身保险伤残评定标准》评定。
- **骨折也能赔**：十级伤残包含"身体各部位骨折愈合后无功能障碍"，意外导致骨折即可按 10% 赔付。

### 猝死保障

| 要素 | 说明 |
|------|------|
| 定义 | 外表健康的人在急性症状发生后 6 小时内突然死亡 |
| 是否算意外 | **多数意外险不含猝死**，因猝死通常由心脑血管疾病引发（非"意外"定义） |
| 覆盖方式 | 部分意外险附加"猝死责任"，或通过定期寿险/重疾险（带身故责任）覆盖 |
| 保额 | 意外险猝死保额通常 20-50 万 |

- **高风险人群**：长期加班、高压工作、熬夜、肥胖、有心血管病史者，建议关注猝死保障。

### 交通意外额外赔付

| 场景 | 说明 |
|------|------|
| 自驾意外 | 驾驶私家车发生意外，额外赔付（通常与综合意外保额叠加） |
| 公共交通意外 | 乘坐飞机、火车、轮船、公交等，额外赔付 |
| 航空意外 | 飞机失事额外赔付，保额通常最高（100-500 万） |
| 电梯意外 | 部分产品覆盖电梯事故 |

- **叠加赔付**：公共交通意外保额通常与综合意外保额独立，可叠加赔付。

> 来源：中国保险行业协会《人身保险伤残评定标准》、银保监会

## 七、寿险与意外险组合方案

| 人群 | 寿险配置 | 意外险配置 | 年缴预算 |
|------|----------|------------|----------|
| 25-35 岁有房贷 | 定寿 200 万（保至 60 岁） | 综合意外 100 万（含 0 免赔意外医疗） | 约 1500-2500 元 |
| 35-45 岁有娃有房贷 | 定寿 300 万（保至 60 岁） | 综合意外 100 万 + 猝死责任 | 约 2500-4000 元 |
| 45-55 岁 | 定寿 100 万（保至 65 岁） | 综合意外 50 万 | 约 1500-2500 元 |
| 60 岁以上 | 一般无需定寿 | 意外 20 万（侧重骨折/医疗） | 约 200-500 元 |
| 全职太太/先生 | 定寿 50-100 万（覆盖育儿责任） | 综合意外 50 万 | 约 500-1000 元 |
| 单身无负债 | 可不买定寿 | 综合意外 50 万 | 约 100-200 元 |

## 八、定寿健康告知与投保要点

### 常见核保问询

| 问询内容 | 影响 | 应对建议 |
|----------|------|----------|
| 既往重疾史 | 可能拒保 | 如实告知，多家同时投保 |
| 慢性病（高血压/糖尿病） | 视程度加费或拒保 | 轻度可控者部分公司可标准体 |
| BMI | 过胖可能加费 | BMI >28 需注意 |
| 吸烟 | 保费上浮 **20%-50%** | 戒烟后再投保可降低保费 |
| 高风险运动/职业 | 部分产品拒保 | 选择职业分类宽松的产品 |

### 投保流程

1. **确定保额与保障期限**：根据负债和家庭责任计算。
2. **对比产品**：关注保费、免责条款、健康告知宽松度。
3. **如实告知**：健康告知问卷逐条核对，有问必答、不问不答。
4. **等待期**：通常 **90-180 天**，等待期内身故不赔（退还已交保费）。
5. **保单生效**：确认保单信息、受益人设置、缴费方式。

### 保单管理

| 事项 | 说明 |
|------|------|
| 保单检视 | 每年检查保障是否匹配当前负债和家庭状况 |
| 受益人更新 | 结婚/离婚/子女出生后及时更新 |
| 续期缴费 | 设置自动扣款，避免断缴导致保单失效 |
| 保单贷款 | 现金价值高的保单可申请保单贷款（不超过 80% 现金价值） |

> 来源：中国保险行业协会、各寿险公司

## 九、意外险常见理赔场景

| 场景 | 是否理赔 | 理赔内容 |
|------|----------|----------|
| 跌倒骨折 | **赔** | 意外医疗报销 + 伤残（如达等级） |
| 猫抓狗咬 | **赔** | 意外医疗报销（含狂犬疫苗） |
| 交通事故 | **赔** | 综合意外 + 交通意外额外赔付 |
| 运动扭伤 | **赔** | 意外医疗报销 |
| 中暑 | **不赔** | 非意外（身体内部原因） |
| 食物中毒 | **赔** | 外来+突发，属于意外 |
| 猝死 | **视产品** | 多数不含，需专门含猝死责任 |
| 酒驾事故 | **不赔** | 多数产品免责 |

### 理赔流程

1. **出险报案**：发生意外后尽快通知保险公司（通常要求 48 小时内）。
2. **就医**：二级及以上公立医院就诊，保留所有医疗票据。
3. **准备材料**：诊断证明、病历、医疗费发票、费用清单、身份证复印件。
4. **提交理赔**：通过 APP、官网或线下提交。
5. **审核赔付**：保险公司审核后打款（通常 5-15 个工作日）。

> 来源：中国保险行业协会、各保险公司理赔手册

## 十、定期vs终身寿险深度对比

### 保障期限对比

| 维度 | 定期寿险 | 终身寿险 |
|------|----------|----------|
| 保障期限 | 固定年限（10/20/30年或保至60/65/70岁） | 终身（必然赔付） |
| 赔付概率 | 保障期内身故才赔，到期未出险不赔 | 必然赔付（100%赔付概率） |
| 保费 | 便宜（30岁男100万保到60岁，年缴约800-1200元） | 贵（同等保额年缴约8000-15000元） |
| 核心功能 | 纯保障，杠杆极高 | 保障+财富传承/资产规划 |
| 适合人群 | 有房贷、有抚养/赡养责任的经济支柱 | 有财富传承需求、高净值人群 |

### 产品类型详解

| 类型 | 特点 | 适合人群 |
|------|------|----------|
| 消费型定期寿险 | 到期未出险不返还保费，但保费极低 | 预算有限、追求高杠杆 |
| 返还型定期寿险 | 到期未出险返还已交保费或保额，但保费贵2-3倍 | 追求返还、预算充足 |
| 储蓄型终身寿险 | 保单有现金价值，可退保取钱，兼顾保障与储蓄 | 有传承需求、追求确定性 |
| 增额终身寿险 | 保额逐年递增，现金价值增长快 | 资产增值、养老规划 |

### 选择建议

| 情况 | 建议 |
|------|------|
| 有房贷、有娃 | 定期寿险，保到房贷还清、孩子独立 |
| 无负债、无牵挂 | 可不买寿险，或买意外险 |
| 高净值、有传承 | 终身寿险，兼顾保障与传承 |
| 预算有限 | 定期寿险，保额做高 |

## 十一、保额计算深度解析

**推荐保额 = 负债 + 教育 + 养老 + 3-5年家庭刚性支出**

| 项目 | 估算方式 | 示例 |
|------|----------|------|
| 负债（房贷+车贷+其他） | 查询银行贷款余额 | 约130万 |
| 子女教育 | 每年费用 × 剩余教育年限 | 约75-175万 |
| 父母赡养 | 每月费用 × 预计赡养年数 × 12 | 约56万 |
| 家庭开支 | 月支出 × 36个月 | 约30-50万 |
| **合计建议保额** | | **约290-410万** |

- **建议**：有房贷有娃的家庭建议保额300万以上，根据实际情况调整。

## 十二、受益人设置技巧

| 维度 | 法定受益人 | 指定受益人 |
|------|------------|------------|
| 定义 | 按继承法分配（配偶、子女、父母平均） | 明确指定具体人员及比例 |
| 优点 | 无需指定，省事 | 避免理赔纠纷，定向传承 |
| 缺点 | 可能被作为遗产处理（需先偿还债务） | 需明确指定，变更需申请 |
| 建议 | 默认选项 | **强烈建议**，避免纠纷 |

- **指定技巧**：明确每位受益人的受益比例（如配偶50%、子女30%、父母20%）。
- **定期更新**：结婚/离婚/子女出生后及时更新受益人。
- **避免遗产处理**：指定受益人可避免保险金被作为遗产处理（遗产需先偿还被保险人生前债务）。
