# 保险

> 保险是"家庭财务的兜底"，不是理财（多数返还型/分红型性价比低）。本板块讲清：先保谁、保什么、怎么配、哪些坑别踩。

> ⚠️ 本板块为保险常识科普，**不构成投保建议**；具体产品以合同条款为准，重大决策建议咨询独立理财师/精算视角的专业意见。

## 核心原则

1. **保障优先于理财**：先买纯保障（医疗/重疾/意外/定寿），再考虑储蓄型。
2. **先保经济支柱**：赚钱的人先保，孩子和老人次之（孩子靠大人，老人杠杆低）。
3. **保额 > 期限 > 公司**：出事赔多少比保多久重要；公司大小影响服务但受监管兜底。
4. **如实健康告知**：隐瞒病史是未来拒赔的最大隐患。
