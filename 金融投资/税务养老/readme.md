# 税务与养老

> 两块"确定性很高、多数人却没用足"的钱：个税专项扣除（合法少交税）和个人养老金（税延+强制储蓄）。本板块把规则和怎么用讲清楚。

> 数据时点 2026 年；个税与养老金政策会调整，**以税务部门/人社部最新公告与"个人所得税 APP"为准**。

## 核心逻辑

1. **先减税、再储蓄**：专项扣除是"无风险省钱"，人人该用满。
2. **个人养老金是"税延+长期"**：高税率人群省当下税、退休按 3% 缴，划算；低税率人群意义弱化。
3. **养老靠组合**：国家基本养老（第一支柱）+ 企业/职业年金（第二）+ 个人养老金与商业养老（第三），别只赌其一。
