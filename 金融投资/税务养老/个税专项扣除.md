# 个税专项附加扣除（2026）

> 七项扣除都是"在算税之前先减去"，等于合法少交税。很多人没填或填不全，等于白送钱。

## 一、七项标准（2026）

| 扣除项 | 标准 | 备注 |
|--------|------|------|
| 3 岁以下婴幼儿照护 | **每孩 2000 元/月** | 多孩叠加 |
| 子女教育 | **每孩 2000 元/月** | 学前+学历教育；夫妻可分摊或由高收入方全额报更划算 |
| 赡养老人 | **3000 元/月**（独生）；非独生每人≤1500 | 父母任一方满 60 岁 |
| 继续教育 | 学历 400 元/月（在读期）；职业资格取证当年 3600 元 | 同一年多项可叠加规则以内 |
| 大病医疗 | 医保范围内自付 **超 1.5 万**部分，据实扣，**最高 8 万/年** | 汇算时填，需医保数据 |
| 住房贷款利息 | **1000 元/月** | 首套贷款；与租金二选一 |
| 住房租金 | **1500/1100/800 元/月**（按城市规模分档） | 无房且在工作城租房；与房贷利息二选一 |

- 基本减除费用 5000 元/月（6 万/年）+ 五险一金 + 以上专项 = 应纳税所得额。
- 税率表（综合所得年度）：3% / 10% / 20% / 25% / 30% / 35% / 45% 七级超额累进。

## 二、能省多少（直觉）

- 假设你适用 10% 档：每 1000 元/月扣除 = 年省 1200 元税；2000 元/月 = 年省 2400 元。
- 双娃+房贷+赡养的"标准家庭"，年扣除额度轻松 5–8 万，对应省税数千到上万。
- 高收入（20–45% 档）省得更多，填满最值得。

## 三、怎么申报

1. 每年 **12 月**在"个人所得税 APP"确认次年扣除（可一键带入上年）。
2. 平时在【专项附加扣除填报】新增/修改；选"通过扣缴义务人申报"（单位按月扣）或"综合所得年度自行申报"（汇算退）。
3. 留好凭证（合同、票据、证明），税务可能抽查。

## 四、常见坑

1. 房贷利息和租金**只能选一个**，别重复填（系统也会校验）。
2. 夫妻分摊看谁税率高——让高收入方全额报更省。
3. 大病医疗只有**汇算时**能填，平时忘了一年就没了。
4. 信息变了（换城租房、孩子入学）不及时更新，可能漏扣或多扣引发风险。

---

*以上为 2026 年公开标准，以"个人所得税 APP"与税务公告最新为准。*
