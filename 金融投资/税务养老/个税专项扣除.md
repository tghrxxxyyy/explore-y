# 个税专项附加扣除（2026）

> 七项扣除都是"在算税之前先减去"，等于合法少交税。很多人没填或填不全，等于白送钱。

## 一、七项标准（2026）

| 扣除项 | 标准 | 备注 |
|--------|------|------|
| 3 岁以下婴幼儿照护 | **每孩 2000 元/月** | 多孩叠加 |
| 子女教育 | **每孩 2000 元/月** | 学前+学历教育；夫妻可分摊或由高收入方全额报更划算 |
| 赡养老人 | **3000 元/月**（独生）；非独生每人≤1500 | 父母任一方满 60 岁 |
| 继续教育 | 学历 400 元/月（在读期）；职业资格取证当年 3600 元 | 同一年多项可叠加规则以内 |
| 大病医疗 | 医保范围内自付 **超 1.5 万**部分，据实扣，**最高 8 万/年** | 汇算时填，需医保数据 |
| 住房贷款利息 | **1000 元/月** | 首套贷款；与租金二选一 |
| 住房租金 | **1500/1100/800 元/月**（按城市规模分档） | 无房且在工作城租房；与房贷利息二选一 |

- 基本减除费用 5000 元/月（6 万/年）+ 五险一金 + 以上专项 = 应纳税所得额。
- 税率表（综合所得年度）：3% / 10% / 20% / 25% / 30% / 35% / 45% 七级超额累进。

## 二、能省多少（直觉）

- 假设你适用 10% 档：每 1000 元/月扣除 = 年省 1200 元税；2000 元/月 = 年省 2400 元。
- 双娃+房贷+赡养的"标准家庭"，年扣除额度轻松 5–8 万，对应省税数千到上万。
- 高收入（20–45% 档）省得更多，填满最值得。

## 三、怎么申报

1. 每年 **12 月**在"个人所得税 APP"确认次年扣除（可一键带入上年）。
2. 平时在【专项附加扣除填报】新增/修改；选"通过扣缴义务人申报"（单位按月扣）或"综合所得年度自行申报"（汇算退）。
3. 留好凭证（合同、票据、证明），税务可能抽查。

## 四、常见坑

1. 房贷利息和租金**只能选一个**，别重复填（系统也会校验）。
2. 夫妻分摊看谁税率高——让高收入方全额报更省。
3. 大病医疗只有**汇算时**能填，平时忘了一年就没了。
4. 信息变了（换城租房、孩子入学）不及时更新，可能漏扣或多扣引发风险。

## 五、子女教育扣除详解

| 要素 | 说明 |
|------|------|
| 扣除标准 | 每孩 **2000 元/月**（24000 元/年） |
| 适用阶段 | 学前教育（3 岁至小学入学前）+ 全日制学历教育（小学、初中、高中、大学、硕士、博士） |
| 扣除方式 | 父母可选择一方全额扣除，或双方各扣 50%；选定后一年内不变 |
| 扣除期限 | 从子女接受教育的当月至教育结束的当月 |
| 境外教育 | 境外学校须纳入中国教育部认可名单，否则不能扣除 |

- **多子女叠加**：两个孩子 = 4000 元/月，三个孩子 = 6000 元/月，直接抵扣应纳税所得额。
- **时间节点**：子女年满 3 岁当月起适用"子女教育"，此前适用"3 岁以下婴幼儿照护"，无缝衔接。
- **常见问题**：子女中途休学的，休学期间不扣除；恢复学籍后继续扣除。

> 来源：《个人所得税专项附加扣除暂行办法》（国发〔2018〕41 号）及国家税务总局公告

## 六、继续教育扣除详解

| 类型 | 标准 | 期限 |
|------|------|------|
| 学历继续教育 | **400 元/月** | 在读期间（最长不超过 48 个月） |
| 职业资格继续教育 | **3600 元/年** | 取得证书的当年 |

- **学历教育**：在中国境内接受的本科及以上学历（学位）继续教育；在读期间按月扣除。
- **职业资格**：取得国家职业资格目录内的证书（如注册会计师、法律职业资格、教师资格等），取证当年一次性扣 3600 元。
- **叠加规则**：同一学历在读期间，如果同时有职业资格取证，可叠加扣除；但同一职业资格不可重复扣。
- **夫妻分摊**：学历教育可由本人或父母扣除（纳税人为本人扣除更常见）；职业资格由本人扣除。
- **常见问题**：自考、成人高考、在职研究生均属学历继续教育；短期培训不属于。

> 来源：《个人所得税专项附加扣除暂行办法》第八条

## 七、大病医疗扣除详解

| 要素 | 说明 |
|------|------|
| 扣除条件 | 医保目录范围内自付部分**累计超过 15000 元** |
| 扣除上限 | 超出 15000 元的部分据实扣除，**年度最高 80000 元** |
| 申报方式 | **仅在年度汇算清缴时扣除**，平时预扣预缴不能扣 |
| 扣除人 | 本人、配偶、未成年子女的医疗支出均可由本人扣除 |

- **自付计算**：仅限医保目录范围内个人自付部分，自费药、自费项目不在扣除范围。
- **家庭统筹**：夫妻可选择由一方扣除全部，或各自扣除自己和未成年子女的部分，灵活安排。
- **年度汇算时间**：每年 3 月 1 日至 6 月 30 日，通过"个人所得税 APP"填报。
- **常见问题**：
  - 慢性病门诊费用纳入年度累计自付额计算。
  - 医保报销后个人自付超 15000 元的部分，需保留好医疗费用票据。
  - 大病医疗与商业医疗险报销不冲突——保险报销的部分不影响扣除额的计算（因为扣除的是医保目录内的自付部分）。

> 来源：国家税务总局《个人所得税专项附加扣除操作办法（试行）》

## 八、住房贷款利息扣除详解

| 要素 | 说明 |
|------|------|
| 扣除标准 | **1000 元/月**（12000 元/年） |
| 适用条件 | 本人或配偶使用商业银行或住房公积金个人住房贷款购买住房 |
| 首套房认定 | 享受首套住房贷款利率的住房贷款（认贷不认房） |
| 扣除期限 | 贷款合同约定开始还款的当月至贷款全部归还或贷款合同终止的当月，**最长 240 个月（20 年）** |
| 扣除方式 | 夫妻约定由一方扣除，选定后一年内不变 |

- **首套认定**：以贷款时银行执行的利率为准，不是以当前是否首套为准。即使后来买了二套房，只要贷款利率是首套利率，仍可扣除。
- **与租金互斥**：本人及配偶在主要工作城市无自有住房才能扣租金；有房贷利息则不能同时扣租金。
- **提前还贷**：贷款提前结清的，从结清当月起停止扣除。
- **常见问题**：夫妻双方各自有首套贷款，只能选择其中一套由一方扣除，不可双方各扣一套。

> 来源：《个人所得税专项附加扣除暂行办法》第十四条

## 九、住房租金扣除详解

| 城市类型 | 扣除标准 |
|----------|----------|
| 直辖市、省会城市、计划单列市及国务院确定的其他城市 | **1500 元/月** |
| 市辖区户籍人口超过 100 万的城市 | **1100 元/月** |
| 市辖区户籍人口不超过 100 万的城市 | **800 元/月** |

- **适用条件**：本人及配偶在主要工作城市没有自有住房；夫妻双方主要工作城市相同的，只能由一方扣除。
- **不需要租赁合同备案**：但建议保留租赁合同、支付凭证备查。
- **与房贷互斥**：有住房贷款利息扣除资格的不能同时享受租金扣除。
- **常见问题**：换城市工作的，按新城市标准执行；年度内多次换城市的，不重复扣除。

> 来源：《个人所得税专项附加扣除暂行办法》第十七条

## 十、赡养老人扣除详解

| 要素 | 说明 |
|------|------|
| 扣除标准 | 独生子女 **3000 元/月**（36000 元/年）；非独生子女每人不超过 **1500 元/月** |
| 被赡养人 | 父母任一方**年满 60 岁**（含祖父母、外祖父母，父母均已去世的情况下） |
| 扣除方式 | 独生子女全额扣除；非独生子女可平均分摊、约定分摊或由父母指定分摊，每人不超过 1500 元/月 |
| 扣除期限 | 被赡养人年满 60 岁当月至赡养义务终止的月末 |

- **非独生分摊**：三种方式——平均分摊（默认）、书面约定分摊、父母指定分摊。约定或指定的须签订书面协议，且一年内不得变更。
- **父母是否在世不影响**：只要有一位父母年满 60 岁即可享受扣除。
- **常见问题**：子女已去世的祖父母、外祖父母，由孙子女赡养的，孙子女也可享受赡养老人扣除。

> 来源：《个人所得税专项附加扣除暂行办法》第二十二条

## 十一、3 岁以下婴幼儿照护扣除详解

| 要素 | 说明 |
|------|------|
| 扣除标准 | 每孩 **2000 元/月**（24000 元/年） |
| 适用对象 | 3 岁以下（含 3 岁当月）的婴幼儿 |
| 扣除方式 | 父母可选择一方全额扣除，或双方各扣 50% |
| 扣除期限 | 婴幼儿出生当月至满 3 周岁当月 |

- **与子女教育衔接**：满 3 岁后自动从"婴幼儿照护"过渡到"子女教育"，扣除标准一致（均为每孩 2000 元/月）。
- **多孩叠加**：双胞胎、多胞胎按孩数叠加扣除。
- **常见问题**：婴幼儿出生当年即可开始扣除（从出生当月算起），不必等到次年汇算。

> 来源：《国务院关于设立 3 岁以下婴幼儿照护个人所得税专项附加扣除的通知》（国发〔2022〕8 号）

## 十三、申报流程详解

### 第一步：信息准备

- 收集家庭成员身份证号、子女学籍信息、贷款合同编号、租赁地址等。
- 确认扣除方式选择（夫妻分摊/一方全额）。

### 第二步：年度确认（每年 12 月）

- 打开"个人所得税 APP"→ 专项附加扣除填报 → 选择扣除年度 → 带入上年信息或新增。
- 系统自动校验：房贷与租金是否重复、扣除比例是否合规。

### 第三步：选择申报方式

| 方式 | 适用场景 | 优劣 |
|------|----------|------|
| 通过扣缴义务人申报 | 有固定工作单位 | 每月预扣预缴时即享受，现金流提前释放 |
| 综合所得年度自行申报 | 自由职业/无固定单位 | 全年汇算时一次性扣除，可退税 |

### 第四步：年度汇算（3 月 1 日 - 6 月 30 日）

- 合并全年综合所得，多退少补。
- 大病医疗必须在此期间填报。
- 可通过"个人所得税 APP"或办税服务厅办理。

## 十四、常见问题 FAQ

| 问题 | 解答 |
|------|------|
| 夫妻双方都有扣除项，怎么分摊最省税？ | 让**边际税率高的一方**多扣或全额扣，整体税负最低。 |
| 房贷还清了还能扣吗？ | 贷款合同终止当月起停止扣除。 |
| 换城市租房了怎么办？ | 按新城市标准执行，及时更新扣除信息。 |
| 父母刚满 60 岁，当年能扣吗？ | 从父母年满 60 岁当月起即可扣除，按剩余月份计算。 |
| 大病医疗自付 15000 元怎么算？ | 医保目录范围内个人自付部分的年度累计金额，不含自费项目。 |
| 留学生在境外读书能扣子女教育吗？ | 境外学校须在教育部认可名单内，否则不能扣除。 |
| 自由职业者能享受专项附加扣除吗？ | 可以，在年度汇算时自行申报扣除。 |

## 十五、专项附加扣除操作指南

### 个税 APP 填报流程（以住房租金为例）

1. **打开 APP** → 专项附加扣除填报 → 选择扣除年度。
2. **选择扣除类型** → 住房租金。
3. **填写信息**：工作城市、租赁地址、租赁起止时间、房东信息（选填）。
4. **选择申报方式**：通过扣缴义务人申报（单位按月扣）或综合所得年度自行申报（汇算退）。
5. **提交**：确认信息无误后提交。

### 信息变更处理

| 变更类型 | 操作方式 | 注意事项 |
|----------|---------|---------|
| 换城市租房 | 新增一条信息，选择新城市 | 不能修改原记录，需新增 |
| 子女入学 | 更新子女教育信息 | 学前→学历教育自动衔接 |
| 父母满 60 岁 | 新增赡养老人信息 | 从满 60 岁当月起扣除 |
| 取得职业资格证书 | 新增继续教育信息 | 取证当年一次性扣 3600 元 |
| 贷款还清 | 修改住房贷款利息信息 | 从还清当月起停止扣除 |

### 常见填报错误

- **房贷与租金重复填报**：系统会校验，不能同时享受。
- **扣除比例选择错误**：子女教育选 100% 或 50%，夫妻协商一致。
- **赡养老人扣除主体错误**：只有纳税人本人可扣除，不能由父母扣除。
- **继续教育扣除期限超限**：学历教育最长 48 个月。

> 来源：国家税务总局《个人所得税专项附加扣除操作办法（试行）》

## 十六、夫妻扣除分配最优方案

### 分配原则

- **核心原则**：让边际税率高的一方多扣或全额扣，整体税负最低。
- **计算方法**：比较夫妻双方的边际税率，税率高的一方享受扣除更省税。

### 分配方案示例

| 扣除项 | 丈夫（税率 20%） | 妻子（税率 10%） | 建议方案 |
|--------|-----------------|-----------------|---------|
| 子女教育（2000 元/月） | 全额扣除 | 不扣 | 丈夫扣除更省 |
| 赡养老人（3000 元/月） | 全额扣除 | 不扣 | 丈夫扣除更省 |
| 住房贷款利息（1000 元/月） | 不扣 | 全额扣除 | 丈夫扣除更省 |
| 住房租金（1500 元/月） | 不扣 | 全额扣除 | 丈夫扣除更省 |

### 注意事项

- **扣除比例选择**：子女教育可选择一方 100% 或双方各 50%，选 100% 由高税率方扣除最省。
- **赡养老人分摊**：非独生子女可平均分摊、约定分摊或父母指定分摊，每人不超过 1500 元/月。
- **年度确认**：每年 12 月确认次年扣除分配方案，选定后一年内不变。

> 来源：国家税务总局政策解读

## 十七、继续教育扣除详解

### 学历继续教育

| 要素 | 说明 |
|------|------|
| 扣除标准 | **400 元/月**（在读期间） |
| 适用教育 | 本科及以上学历（学位）继续教育 |
| 扣除期限 | 在读期间，**最长不超过 48 个月** |
| 扣除主体 | 纳税人本人（推荐）或父母 |
| 学历类型 | 自考、成人高考、在职研究生均属学历继续教育 |

### 职业资格继续教育

| 要素 | 说明 |
|------|------|
| 扣除标准 | **3600 元/年** |
| 适用资格 | 国家职业资格目录内的证书 |
| 扣除时间 | 取得证书的**当年** |
| 扣除主体 | 纳税人本人 |
| 证书类型 | 注册会计师、法律职业资格、教师资格、医师资格等 |

### 叠加规则

- 同一学历在读期间，同时有职业资格取证，可叠加扣除。
- 同一职业资格不可重复扣（一次取证扣一次）。
- 学历教育扣除 + 职业资格扣除可同时享受。

> 来源：《个人所得税专项附加扣除暂行办法》第八条

## 十八、大病医疗扣除实操

### 扣除条件与计算

| 要素 | 说明 |
|------|------|
| 扣除条件 | 医保目录范围内个人自付部分**年度累计超过 15000 元** |
| 扣除上限 | 超出 15000 元的部分据实扣除，**年度最高 80000 元** |
| 扣除主体 | 本人、配偶、未成年子女的医疗支出均可由本人扣除 |
| 申报时间 | **仅在年度汇算清缴时扣除**（3 月 1 日 - 6 月 30 日） |

### 扣除计算示例

| 项目 | 金额 |
|------|------|
| 年度医保目录内自付总额 | 60,000 元 |
| 超过 15,000 元部分 | 45,000 元 |
| 年度扣除上限 | 80,000 元 |
| **可扣除金额** | **45,000 元** |
| 适用税率 20% 时省税 | **9,000 元** |

### 实操注意事项

- **自付范围**：仅限医保目录范围内个人自付部分，自费药、自费项目不在扣除范围。
- **家庭统筹**：夫妻可选择由一方扣除全部，或各自扣除自己和未成年子女的部分。
- **慢病门诊**：慢性病门诊费用纳入年度累计自付额计算。
- **票据保留**：保留好医疗费用票据，税务可能抽查。
- **与商业保险不冲突**：保险报销的部分不影响扣除额的计算（因为扣除的是医保目录内的自付部分）。

### 申报流程

1. **收集数据**：通过医保 APP 或医保局查询年度自付总额。
2. **打开 APP**：个人所得税 APP → 年度汇算 → 新增大病医疗。
3. **填写信息**：患者姓名、身份证号、自付金额。
4. **提交申报**：系统自动计算扣除额，合并到综合所得。

## 十九、夫妻扣除分配最优方案

### 分配原则

## 十三、扣除项目详解

### 13.1 子女教育扣除

| 扣除项目 | 扣除标准 | 扣除方式 | 适用条件 |
|---------|---------|---------|---------|

| 被赡养人 | 扣除标准 | 扣除方式 | 适用条件 |
|---------|---------|---------|---------|
| 年满60岁父母 | 3000元/月 | 兄弟姐妹分摊 | 父母年满60周岁 |
| 年满60岁祖父母 | 3000元/月 | 独生子女/分摊 | 父母已去世 |

- **扣除标准**：每月3000元，每年36000元，独生子女可全额扣除，兄弟姐妹可分摊扣除额度。

- **适用条件**：被赡养人需年满60周岁，包括亲生父母、继父母、养父母，以及子女均已去世的年满60岁的祖父母、外祖父母。

| 扣除项目 | 扣除标准 | 扣除方式 | 适用条件 |
|---------|---------|---------|---------|
| 个人自付医疗费用 | 超过15000元部分 | 本人或配偶扣除 | 年度自付超15000元 |
| 未成年子女医疗费用 | 超过15000元部分 | 父母一方扣除 | 子女自付超15000元 |

| 扣除项目 | 扣除标准 | 扣除方式 | 适用条件 |
|---------|---------|---------|---------|
| 首套住房贷款利息 | 1000元/月 | 夫妻一方扣除 | 首套住房贷款 |
| 贷款期限 | 最长240个月 | 不超过240个月 | 贷款合同约定 |

- **扣除标准**：每月1000元，每年12000元，最长扣除240个月（20年），夫妻双方可约定由一方扣除。
- **适用条件**：必须是首套住房贷款利息支出，即购买住房时享受首套住房贷款利率的住房贷款，包括商业贷款与公积金贷款。
- **注意事项**：夫妻双方婚前分别购买住房发生的首套住房贷款，婚后可选择其中一套住房由购买方按扣除标准的100%扣除，或对各自购买住房分别按扣除标准的50%扣除。

## 十四、个税筹划技巧

### 14.1 扣除最大化策略

| 策略 | 操作方法 | 节税效果 | 适用人群 |
|------|---------|---------|---------|
| 全额扣除 | 确保所有符合条件的项目都申报扣除 | 高 | 所有纳税人 |
| 夫妻分配 | 让高税率方扣除 | 中高 | 双薪家庭 |
| 跨年扣除 | 合理安排大病医疗等跨年扣除 | 中 | 有大病医疗支出者 |
| 信息更新 | 及时更新专项附加扣除信息 | 中 | 信息变化者 |

- **全额扣除**：逐项检查所有符合条件的专项附加扣除项目，确保全部申报扣除，避免遗漏。
- **夫妻分配**：对于子女教育、赡养老人等可由夫妻双方分配的扣除项，让边际税率高的一方全额扣除，可最大化节税效果。
- **跨年扣除**：大病医疗扣除可在次年汇算清缴时扣除，若当年扣除不足，可结转以后年度扣除。

### 14.2 收入安排策略

| 策略 | 操作方法 | 节税效果 | 适用人群 |
|------|---------|---------|---------|
| 平滑收入 | 避免收入过度集中于某个月 | 中 | 收入波动大者 |
| 福利转换 | 将部分工资转为福利 | 中 | 高收入者 |
| 年终奖规划 | 合理选择年终奖发放方式 | 中高 | 有年终奖者 |
| 股权激励 | 合理安排行权时间 | 高 | 有股权激励者 |

- **平滑收入**：避免收入过度集中于某个月，导致适用更高税率，可与公司协商将部分奖金平滑至其他月份发放。
- **福利转换**：将部分工资转为公司福利（如交通补贴、通讯补贴、住房补贴），福利收入不计入工资薪金所得，可降低税负。
- **年终奖规划**：年终奖可选择单独计税或并入综合所得计税，根据个人收入情况选择最优方式，一般中高收入者选择单独计税更优。

### 14.3 投资相关筹划

| 策略 | 操作方法 | 节税效果 | 适用人群 |
|------|---------|---------|---------|
| 公积金优化 | 在政策允许范围内提高公积金缴存比例 | 中 | 有公积金者 |
| 企业年金 | 参加企业年金计划 | 中 | 有企业年金者 |
| 商业健康险 | 购买符合规定的商业健康保险 | 低 | 有健康险需求者 |
| 个人养老金 | 参加个人养老金制度 | 中高 | 有养老需求者 |

- **公积金优化**：在政策允许范围内提高公积金缴存比例，公积金缴存免征个人所得税，可降低应纳税所得额。
- **企业年金**：参加企业年金计划，企业年金缴费部分免征个人所得税，退休领取时按较低税率缴税，可实现税收递延。
- **个人养老金**：参加个人养老金制度，每年最高12000元额度享受税收递延优惠，退休领取时按3%缴税，适合边际税率10%以上人群。

> 来源：国家税务总局政策解读、个人所得税APP操作指南

### 个税扣除案例分析
#### 案例一：单身白领扣除计算
- **情况**：月薪15000元，无子女，租房，赡养老人。
- **扣除**：住房租金1500+赡养老人3000=4500元。
- **应纳税所得额**：15000-5000-4500=5500元。
- **应纳税额**：5500×3%=165元。
#### 案例二：已婚家庭扣除计算
- **情况**：夫妻双方月薪各15000元，一个子女，有房贷，赡养老人。
- **扣除**：子女教育2000+房贷利息1000+赡养老人3000=6000元。
- **应纳税所得额**：15000-5000-6000=4000元。
- **应纳税额**：4000×3%×2=240元。
