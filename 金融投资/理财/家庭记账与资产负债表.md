# 家庭记账与资产负债表

> 赚钱重要，知道钱去了哪更重要。记账 + 一张家庭资产负债表，让每一分钱都有位置，也让冲动消费无处遁形。

## 一、分类记账

- **三分类法**（够用且不累）：
  - **收入**：工资、奖金、理财收益、副业、其他。
  - **固定支出**：房租/房贷、水电、保险、月供——每月必花的硬性支出。
  - **弹性支出**：餐饮、购物、娱乐、旅游——可压缩的部分。
- **记账节奏**：不用记到一分不差；**每天 1 分钟随手记，每周 10 分钟对一次账**即可。
- **工具思路**：选支持多账本/家庭共享、能自动导入银行卡流水的记账 App；不方便用 App 的，微信/支付宝账单导出到表格同样有效。
- **关键不是"记"，是"复盘"**：不复盘，记账就是自欺。

## 二、月度复盘

- **每月 30 分钟**：分类汇总 → 与上月对比 → 找"超支项" → 定下月预算。
- **两个参考指标**：
  - **储蓄率**：每月储蓄 ÷ 收入，目标 **20–30%**（先存后花，工资到账先转储蓄）。
  - **固定支出占比**：固定支出 ÷ 收入 ≤ 50%，超过说明财务弹性低，抗风险能力弱。
- **常见优化点**：先看"固定支出能不能降"（大件），再看"弹性支出哪些是冲动消费"（小额积沙成塔）。

## 三、家庭资产负债表

- **资产**（按流动性排列）：
  - 现金、活期/货币基金（随时能动）
  - 定期存款、理财、国债、债券基金
  - 股票基金、股票（波动资产）
  - 房产（按市场价，不必每月重估）
  - 保单现金价值、公积金余额、养老金账户
- **负债**：
  - 房贷、车贷、消费贷、信用卡欠款（按月供折现或剩余本金）
- **净资产** = 总资产 − 总负债。
- **做表频率**：每半年更新一次；房产、大额资产变动时随手更新。

## 四、财务健康指标

| 指标 | 健康标准 | 说明 |
| --- | --- | --- |
| 紧急备用金 | 3–6 个月生活开支 | 放货基/活期，随时可取 |
| 负债收入比 | 月供合计 ≤ 月收入 50% | 超过 50% 属高负债 |
| 负债资产比 | 总负债 ≤ 总资产 50% | 防止"负资产" |
| 储蓄率 | 20–30% 以上 | 越低越危险 |
| 资产流动性 | 随时可用 ≥ 3 个月开支 | 防"有房没钱" |

- **三个红线**：靠借钱投资、以贷养贷、动用应急金做高风险投资。

## 五、每年一次"财务体检"

1. 重算资产负债表，看净资产是否增长。
2. 复盘储蓄率达成情况，调预算。
3. 检查保障：保险是否覆盖、额度是否够（详见 ../保险）。
4. 检查投资配置：收益与风险是否匹配、是否过于集中（详见 ../基金 ../炒股）。
5. 更新长期目标：买房、教育、养老的进度与缺口（详见 ../税务养老）。
