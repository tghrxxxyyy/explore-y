# 银行理财 R1–R5

> 资管新规后，银行理财全面"净值化"——**不再保本保收益**，每天看净值涨跌。买之前必须懂风险等级。

## 一、风险等级（R1–R5）

| 等级 | 含义 | 典型投向 | 适合 |
|------|------|---------|------|
| R1 谨慎 | 低风险，本金近乎安全 | 国债、存款、货币工具 | 保守、活钱 |
| R2 稳健 | 中低风险，小幅波动 | 高等级债、固收+ | 大多数人 |
| R3 平衡 | 中等，可能有明显波动 | 债+少量股/商品 | 能承受波动 |
| R4 进取 | 中高，波动大 | 股债混合、衍生品 | 有经验 |
| R5 激进 | 高，可能大亏 | 股票、复杂衍生品 | 专业/能亏 |

- **普通人主流是 R2/R3**；R4/R5 波动可能超心理预期，慎碰。
- 等级与历史收益无关——高等级≠高收益，只是高波动。

## 二、净值化意味着什么

- 产品每天公布净值，你看到的是"份额×净值"，**会涨会跌**，赎回时按当时净值。
- "业绩比较基准"≠ 保证收益，只是参考；实际可能达不到甚至亏损。
- 封闭期/最短持有期：期内不能赎回，买前看锁定期是否匹配你的钱的使用时间。

## 三、怎么挑

1. **先匹配风险等级**：保守选 R2 及以下；能接受波动再上 R3。
2. **看底层资产**：固收类（债为主）稳，含股/衍生品的波动大。
3. **看期限与流动性**：开放式（可申赎）/ 定开（周期开放）/ 封闭（到期取），别把短期要用的钱锁死。
4. **看费用**：管理费、托管费、赎回费，长期累积影响收益。
5. **分散**：不把全部稳健资金压一只产品。

## 四、和存款/货基的区别

- 存款：保本保息（50 万内保险），但收益低、流动性差。
- 货基：近似活钱，极稳，收益低。
- 银行理财 R2：收益略高，但**不保本**、有小幅波动，适合代替"不太动的闲钱"。

## 五、避坑

1. "理财经理说稳赚"——口头不保险，合同写风险等级；R2 也可能阶段性破净。
2. "预期收益率"——新规后叫"业绩比较基准"，不保证。
3. 把理财当存款——急用钱时恰逢净值低位，可能割在低点。
4. 盲目追高收益产品——高收益对应高风险等级，看等级别只看数字。

## 六、R1–R5风险等级详解

### R1谨慎型（低风险）

| 维度 | 详情 |
|---|---|
| 收益范围 | 年化1.5%–2.5% |
| 投资标的 | 国债、央行票据、银行存款、货币市场工具 |
| 适合人群 | 保守型投资者、退休人群、风险厌恶者 |
| 典型产品 | 现金管理类理财、短期限固收产品 |
| 波动特征 | 净值几乎无波动，最大回撤<0.5% |
| 流动性 | 多为开放式，支持T+0或T+1赎回 |

### R2稳健型（中低风险）

| 维度 | 详情 |
|---|---|
| 收益范围 | 年化2.5%–3.5% |
| 投资标的 | 高等级信用债、国债、同业存单、少量权益 |
| 适合人群 | 大多数普通投资者、中短期闲钱管理 |
| 典型产品 | 固收类理财、固收+产品（低权益仓位） |
| 波动特征 | 净值小幅波动，最大回撤1%–3% |
| 流动性 | 开放式或定开式，部分有最短持有期 |

### R3平衡型（中等风险）

| 维度 | 详情 |
|---|---|
| 收益范围 | 年化3%–5% |
| 投资标的 | 债券为主+少量股票/商品/可转债 |
| 适合人群 | 能承受一定波动、追求较高收益的投资者 |
| 典型产品 | 固收+产品（中高权益仓位）、混合类理财 |
| 波动特征 | 净值有明显波动，最大回撤3%–8% |
| 流动性 | 多为定开式，需关注封闭期 |

### R4进取型（中高风险）

| 维度 | 详情 |
|---|---|
| 收益范围 | 年化5%–10%（波动大，可能亏损） |
| 投资标的 | 股票+债券+衍生品+另类资产 |
| 适合人群 | 有投资经验、能承受较大波动的投资者 |
| 典型产品 | 混合类理财、权益类理财、结构性产品 |
| 波动特征 | 净值波动大，最大回撤10%–20% |
| 流动性 | 多为封闭式或定开式，流动性较差 |

### R5激进型（高风险）

| 维度 | 详情 |
|---|---|
| 收益范围 | 年化10%以上（可能大亏） |
| 投资标的 | 股票、复杂衍生品、另类投资 |
| 适合人群 | 专业投资者、能承受本金大幅亏损 |
| 典型产品 | 权益类理财、结构化产品、量化衍生品 |
| 波动特征 | 净值波动极大，最大回撤>20% |
| 流动性 | 封闭期长，流动性差 |

> 来源：银保监会《商业银行理财业务监督管理办法》、各银行理财产品说明书

## 七、银行理财 vs 存款 vs 基金对比

| 对比维度 | 银行存款 | 银行理财R1-R3 | 公募基金 |
|---|---|---|---|
| 本金保障 | 保本（50万内存款保险） | 不保本 | 不保本 |
| 收益确定性 | 固定利率 | 业绩比较基准（不保证） | 净值波动，无承诺 |
| 收益范围 | 1%–2.5% | 2%–5% | 浮动（可能亏损） |
| 流动性 | 活期随时/定期到期 | 开放式/定开式/封闭式 | 大多数T+1赎回 |
| 监管机构 | 央行/银保监会 | 银保监会 | 证监会 |
| 投资门槛 | 低 | 1元起（部分1万起） | 低（10元起） |
| 适合场景 | 应急金、保守配置 | 闲钱管理、稳健增值 | 长期投资、追求收益 |

### 三者配置建议

- **应急金（3–6个月开支）**：全部放活期存款或货币基金，确保随时可用。
- **短期闲钱（1年内）**：银行理财R1-R2 + 货基，兼顾安全与收益。
- **中期资金（1–3年）**：银行理财R2-R3 + 短债基金，追求较高收益。
- **长期资金（3年以上）**：基金（指数/主动） + 储蓄国债，追求长期增值。

> 来源：银保监会《资管新规》、证监会《公开募集证券投资基金运作管理办法》

## 八、净值化转型的深远影响

### 什么是净值化转型

- **2018年资管新规**：打破刚性兑付，银行理财从"预期收益型"转向"净值型"。
- **核心变化**：产品净值随底层资产价格波动，投资者自负盈亏。
- **时间节点**：2021年底过渡期结束，全面净值化。

### 净值化对投资者的影响

| 影响方面 | 转型前（预期收益型） | 转型后（净值型） |
|---|---|---|
| 收益 | 以为稳赚不赔 | 实际可能亏损 |
| 净值可见性 | 每月公布一次 | 每日公布净值 |
| 投资体验 | 无感持有 | 可能看到净值波动 |
| 选择难度 | 低（收益写在合同） | 高（需理解净值含义） |

### 如何适应净值化

1. **降低收益预期**：业绩比较基准≠承诺收益，实际可能达不到。
2. **接受短期波动**：债券价格波动会导致净值小幅起伏，但长期持有大概率正收益。
3. **分散配置**：不把所有钱压单一产品，分散不同风险等级的产品。
4. **拉长持有期**：封闭期/持有期越长，越能平滑波动，减少追涨杀跌。

> 来源：中国人民银行《关于规范金融机构资产管理业务的指导意见》

## 九、破净处理：理财亏损怎么办

### 什么是破净

- **定义**：理财产品净值跌破1.0，即持有期间出现亏损。
- **原因**：底层债券价格下跌（利率上行）、权益市场波动、信用风险事件。
- **常见场景**：债市调整期（如2022年11月债市大跌）、股市大幅下跌。

### 破净后怎么办

- **不要恐慌赎回**：短期波动≠永久亏损，割在低点可能锁定损失。
- **评估持有期**：如果资金1年内不用，可耐心等待净值修复。
- **检查底层资产**：如果是债券类理财，债市回暖后净值大概率修复；如果是权益类，需评估市场趋势。
- **考虑定投摊薄**：如果看好长期，可在净值低位加仓，摊低成本。

### 如何预防破净风险

- **选择低风险等级产品**：R1-R2产品破净概率低。
- **关注产品说明书**：了解底层资产配置，避免权益仓位过高的产品。
- **分散投资**：不把全部资金压单一产品。
- **设定止损线**：如果最大回撤超过你的承受能力，及时调整。

> 来源：银保监会《商业银行理财业务监督管理办法》、各银行理财产品说明书

## 十二、银行理财购买渠道

| 渠道 | 优点 | 缺点 |
|---|---|---|
| 手机银行APP | 24小时可操作，产品最全，费率常有优惠 | 需注册开通手机银行，界面可能复杂 |
| 网上银行 | 大屏操作方便，适合查看产品详情 | 需U盾或动态密码，安全性要求高 |
| 柜台 | 面对面咨询，适合老年用户 | 受营业时间限制，排队耗时 |
| 第三方平台（天天基金等） | 产品丰富，费率一折起 | 需额外开户，部分银行产品不支持 |

- **费率差异**：同一产品不同渠道费率可能不同，APP端常有申购费折扣。
- **首次购买**：首次购买银行理财需在银行网点或APP完成风险评估问卷。
- **跨行购买**：部分银行理财支持跨行代销，但可能影响赎回到账速度。

## 十三、银行理财常见误区

### 误区一：银行理财保本保收益

- **现实**：资管新规后全面净值化，银行理财**不再保本保收益**。
- **合同为准**：口头承诺无效，产品说明书中的风险等级才是真实依据。
- **R2也可能破净**：2022年债市调整期间，大量R2产品阶段性跌破净值。

### 误区二：只看收益率，不看风险等级

- **收益率≠承诺**：业绩比较基准只是参考，实际可能达不到甚至亏损。
- **高收益对应高风险**：R4/R5产品收益率高，但最大回撤可达10%–20%以上。
- **应先看风险等级**：保守型投资者应优先选择R1–R2产品。

### 误区三：忽视费用和锁定期

- **费用累积影响收益**：管理费、托管费、销售服务费每年从净值扣除，长期持有影响显著。
- **封闭期内无法赎回**：急用钱时可能面临流动性危机，甚至割在净值低位。
- **赎回费阶梯**：持有时间越短赎回费越高，短期频繁申赎会侵蚀收益。

### 按风险偏好配置

|---|---|---|---|---|
| 保守型 | 40% | 60% | 0% | 以R1–R2为主，追求安全 |

| 平衡型 | 10% | 50% | 40%（R3–R4） | 可承受一定波动 |
| 激进型 | 0% | 30% | 70%（R4–R5） | 追求高收益，能承受较大回撤 |

| 资金期限 | 推荐等级 | 产品形态 | 说明 |
|---|---|---|---|
| 随时可能用 | R1 | 现金管理类（T+0） | 如朝朝宝、添利宝 |
| 1–3个月 | R1–R2 | 开放式或短期定开 | 兼顾安全与收益 |
| 3–12个月 | R2 | 定开式或封闭式 | 封闭期越长收益通常越高 |
| 1–3年 | R2–R3 | 封闭式或持有期产品 | 拉长持有期平滑波动 |
| 3年以上 | R3–R4 | 长封闭期产品 | 追求更高收益，需能承受波动 |

| 应急金（3-6个月） | 活期存款+货基 | 100% | 确保随时可用 |
| 短期闲钱（1年内） | 银行理财R1-R2+货基 | 各50% | 兼顾安全与收益 |
| 中期资金（1-3年） | 银行理财R2-R3+短债基金 | 60%+40% | 追求较高收益 |
| 长期资金（3年以上） | 基金（指数/主动）+储蓄国债 | 70%+30% | 追求长期增值 |

> 来源：银保监会、证监会、财政部相关公告

## 十七、银行理财购买渠道详解

### 渠道对比

| 渠道 | 优点 | 缺点 | 适合人群 |
|------|------|------|---------|
| 手机银行APP | 24小时可操作，产品最全，费率常有优惠 | 需注册开通手机银行 | 年轻人 |
| 网上银行 | 大屏操作方便，适合查看产品详情 | 需U盾或动态密码 | 中年人 |
| 柜台 | 面对面咨询，适合老年用户 | 受营业时间限制 | 老年人 |
| 第三方平台 | 产品丰富，费率一折起 | 需额外开户 | 比价型用户 |

### 购买注意事项

- **费率差异**：同一产品不同渠道费率可能不同，APP端常有申购费折扣。
- **首次购买**：首次购买银行理财需在银行网点或APP完成风险评估问卷。
- **跨行购买**：部分银行理财支持跨行代销，但可能影响赎回到账速度。

> 来源：各银行官网、第三方理财平台

## 十八、银行理财配置建议

### 按风险偏好配置

| 风险偏好 | R1占比 | R2占比 | R3及以上占比 | 说明 |
|---------|--------|--------|-------------|------|
| 保守型 | 40% | 60% | 0% | 以R1-R2为主，追求安全 |
| 稳健型 | 20% | 60% | 20%（R3） | 核心R2，少量R3增厚收益 |
| 平衡型 | 10% | 50% | 40%（R3-R4） | 可承受一定波动 |
| 激进型 | 0% | 30% | 70%（R4-R5） | 追求高收益，能承受较大回撤 |

### 按资金期限配置

| 资金期限 | 推荐等级 | 产品形态 | 说明 |
|---------|---------|---------|------|
| 随时可能用 | R1 | 现金管理类（T+0） | 如朝朝宝、添利宝 |
| 1-3个月 | R1-R2 | 开放式或短期定开 | 兼顾安全与收益 |
| 3-12个月 | R2 | 定开式或封闭式 | 封闭期越长收益通常越高 |
| 1-3年 | R2-R3 | 封闭式或持有期产品 | 拉长持有期平滑波动 |
| 3年以上 | R3-R4 | 长封闭期产品 | 追求更高收益，需能承受波动 |

### 季节性配置建议

- **年初**：银行"开门红"期间，理财产品收益较高，可重点配置。
- **季末/年末**：银行揽储期，短期理财收益可能走高。
- **节假日前**：国债逆回购收益可能飙升，可短期配置。
- **季末最后一天**：银行理财收益可能阶段性走高。

### 理财产品筛选五步法

| 步骤 | 关注点 | 具体做法 |
|------|--------|---------|
| 第一步 | 风险等级 | 根据自身风险偏好选择R1-R5等级 |
| 第二步 | 底层资产 | 查看产品说明书中的投资标的 |
| 第三步 | 期限匹配 | 确保产品期限与资金使用计划匹配 |
| 第四步 | 费用结构 | 对比管理费、托管费、赎回费 |
| 第五步 | 历史业绩 | 关注最大回撤和同类排名 |

> 来源：银保监会《商业银行理财业务监督管理办法》、各银行理财产品说明书
