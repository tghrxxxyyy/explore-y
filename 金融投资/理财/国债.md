# 国债

> 国债 = 国家信用借钱，几乎是"无信用风险"的稳健投资。适合保守型、长期不用的钱。

## 一、储蓄国债（最贴近普通人）

- **类型**：凭证式（纸质/电子凭单）、电子式（记账，每年付息）。3 年、5 年为主。
- **特点**：100 元起，国家信用，利率通常高于同期定存；电子式每年派息，现金流友好。
- **购买**：发行期到银行柜台/网银抢（热门常"秒空"），主要面向个人。
- **提前兑取**：持有不满半年不计息，满半年按档计息并扣少量手续费——流动性一般，适合确定中长期不用的钱。
- **2026 年起**：电子式储蓄国债被纳入**个人养老金可投资范围**，可用养老金账户买（见 ../税务养老）。

## 二、记账式国债

- 在二级市场（银行端/交易所）买卖，价格随市场利率波动，可随时卖但可能有价差盈亏。
- 适合想兼顾收益与一定流动性的进阶用户；不懂价格波动者慎选。

## 三、为什么买国债

- **安全**：几乎无违约风险（对比企业债/理财）。
- **省心**：买入持有到期拿本息，不用盯盘。
- **配置角色**：资产组合里的"压舱石"，对冲权益市场波动。

## 四、什么时候划算

- 利率下行周期，提前锁定较高票息更值；利率上行时新发利率更高，旧债价格会跌（持有到期不受影响）。
- 和定存比：期限长、利率常略高，但流动性弱于货基、强于定存（凭证式可提前兑）。

## 五、避坑

1. "国债稳赚不赔"——持有到期确实稳；但记账式在二级市价买卖有波动，卖出可能亏。
2. 买到"假国债"：只通过银行/官方渠道，警惕高息"国债理财"骗局（实质是旁氏）。
3. 把短期要用的钱买长期储蓄国债——提前兑取损失利息。

## 六、国债类型详解

### 储蓄国债（电子式）

| 维度 | 详情 |
|---|---|
| 发行主体 | 财政部 |
| 购买渠道 | 银行柜台/网银/手机银行 |
| 起购金额 | 100元 |
| 期限 | 3年、5年 |
| 付息方式 | 每年付息一次 |
| 提前兑取 | 持有满半年可兑取，按档计息 |
| 适合人群 | 追求稳定收益、长期不用的个人投资者 |

### 储蓄国债（凭证式）

| 维度 | 详情 |
|---|---|
| 发行主体 | 财政部 |
| 购买渠道 | 银行柜台（需带身份证） |
| 起购金额 | 100元 |
| 期限 | 3年、5年 |
| 付息方式 | 到期一次还本付息 |
| 提前兑取 | 持有满半年可兑取，按档计息 |
| 适合人群 | 中老年投资者、习惯纸质凭证 |

### 记账式国债

| 维度 | 详情 |
|---|---|
| 发行主体 | 财政部 |
| 交易场所 | 银行间市场、交易所市场 |
| 购买渠道 | 银行APP/证券账户 |
| 起购金额 | 100元（银行间）/10张（交易所，每张100元） |
| 期限 | 1年–30年不等 |
| 付息方式 | 按年付息或到期一次付息 |
| 流动性 | 可在二级市场买卖，价格随利率波动 |
| 适合人群 | 进阶投资者、希望兼顾收益与流动性 |

### 电子式 vs 凭证式 vs 记账式对比

| 对比维度 | 电子式储蓄国债 | 凭证式储蓄国债 | 记账式国债 |
|---|---|---|---|
| 购买方式 | 线上 | 线下柜台 | 线上 |
| 付息方式 | 每年付息 | 到期还本付息 | 按年付息 |
| 流动性 | 可提前兑取 | 可提前兑取 | 可二级市场交易 |
| 价格波动 | 无 | 无 | 有（利率风险） |
| 适合场景 | 长期持有 | 中老年投资者 | 进阶投资者 |

> 来源：财政部国债发行公告、中央国债登记结算有限责任公司

## 七、购买渠道与流程

### 线上购买（推荐）

| 渠道 | 操作步骤 | 优点 |
|---|---|---|
| 手机银行 | 登录→投资理财→国债→选择产品→购买 | 方便快捷，可预约 |
| 网银 | 登录网银→投资理财→国债→购买 | 操作直观 |
| 券商APP | 交易→国债逆回购/国债→购买 | 适合记账式国债 |

### 线下购买

| 渠道 | 操作步骤 | 适合人群 |
|---|---|---|
| 银行柜台 | 带身份证、银行卡→填申请表→购买 | 中老年投资者 |
| 国债承销团银行 | 工农中建交等大行均可办理 | 所有投资者 |

### 购买时机

- **发行期**：储蓄国债通常每月10日发行，热门品种常"秒空"，建议提前准备好资金。
- **提前蹲守**：发行当天早上9点开售，建议提前登录银行APP准备。
- **额度分配**：不同银行额度不同，可多开几家银行账户提高中签概率。

### 购买注意事项

1. **确认账户状态**：确保银行卡已开通投资功能，账户余额充足。
2. **阅读说明书**：了解利率、期限、提前兑取规则。
3. **保留凭证**：电子式保存交易记录，凭证式保管好纸质凭证。
4. **到期处理**：到期自动还本付息到账户，无需操作。

> 来源：各银行国债销售公告、财政部《储蓄国债发行管理办法》

## 八、利率计算与收益分析

### 储蓄国债利率计算

- **电子式（每年付息）**：
  - 年利息 = 面值 × 票面利率
  - 利息每年自动到账，可再投资（复利效应）
  - 示例：10万元，3年期，票面利率2.5%，每年利息2500元

- **凭证式（到期还本付息）**：
  - 到期本息 = 面值 × (1 + 票面利率 × 期限)
  - 示例：10万元，3年期，票面利率2.5%，到期本息107500元

### 记账式国债收益计算

- **持有到期**：收益 = 面值 × 票面利率 × 持有年限
- **二级市场交易**：
  - 资本利得 = 卖出价 − 买入价
  - 持有期间利息 = 持有天数 × 票面利率 / 365
- **注意**：利率上行时，旧债价格下跌，卖出可能亏本

### 国债 vs 定存收益对比

| 产品 | 3年期利率（参考） | 5年期利率（参考） | 付息方式 |
|---|---|---|---|
| 储蓄国债 | 2.5%–2.8% | 2.6%–2.9% | 每年付息 |
| 银行定存 | 2.0%–2.5% | 2.2%–2.6% | 到期还本付息 |
| 大额存单 | 2.2%–2.8% | 2.4%–3.0% | 到期还本付息 |

- **结论**：国债利率通常高于同期定存，且每年付息有复利优势。

> 来源：财政部国债利率公告、各银行存款利率表

## 九、提前兑取规则详解

### 储蓄国债提前兑取

| 持有期限 | 计息规则 | 手续费 |
|---|---|---|
| < 6个月 | 不计息 | 无 |
| 6个月–1年 | 按票面利率的60%计息 | 0.1% |
| 1年–2年 | 按票面利率的70%计息 | 0.1% |
| 2年–3年 | 按票面利率的80%计息 | 0.1% |
| 3年–5年 | 按票面利率的90%计息 | 0.1% |

### 提前兑取操作

- **电子式**：在银行APP或柜台操作，当日或次日到账。
- **凭证式**：只能到原购买银行柜台办理，需携带身份证和凭证。
- **到账时间**：通常T+1或T+2到账。

### 提前兑取注意事项

1. **持有不满半年不计息**：这是最大的风险，短期资金不要买储蓄国债。
2. **手续费**：按兑取本金的0.1%收取，最低1元。
3. **利息损失**：提前兑取会损失部分利息，越早兑取损失越大。
4. **替代方案**：如果急需用钱，可考虑记账式国债二级市场卖出（可能有价差盈亏）。

> 来源：财政部《储蓄国债发行管理办法》、各银行国债兑取规则

## 十、国债逆回购

### 什么是国债逆回购

- **本质**：你把钱借给别人（以国债为抵押），到期收回本息。
- **安全性**：交易所担保交收，安全性极高，几乎无风险。
- **参与门槛**：沪市10万起，深市1000元起。

### 操作流程

1. **开通证券账户**：选择一家券商开户。
2. **银证转账**：将资金从银行卡转入证券账户。
3. **选择品种**：根据资金闲置时间选择1天、7天、14天等品种。
4. **下单卖出**：在交易软件中选择"国债逆回购"，输入金额和利率。
5. **到期自动回款**：到期日本金和利息自动回到账户，次日可用。

### 收益计算

- **年化收益率**：行情软件显示的是年化收益率，波动较大。
- **实际收益**：实际收益 = 本金 × 年化收益率 × 实际天数 / 365。
- **示例**：10万元，1天期逆回购，年化收益率2.5%，实际收益 ≈ 6.85元。

### 操作技巧

| 技巧 | 说明 |
|---|---|
| 周四买入1天期 | 计息3天（周末照常计息） |
| 节假日前买入 | 计息假期全程 |
| 月末/季末/年末 | 资金紧张时收益率冲高 |
| 下午2:30–3:00下单 | 收益率通常较高 |

### 国债逆回购 vs 货基

| 对比维度 | 国债逆回购 | 货币基金 |
|---|---|---|
| 收益 | 波动大（1%–5%） | 稳定（1.2%–1.8%） |
| 流动性 | 到期自动回款 | T+0/T+1赎回 |
| 操作 | 需手动操作 | 自动计息 |
| 门槛 | 沪市10万/深市1000元 | 无门槛 |
| 适合场景 | 节假日前/月末冲高 | 日常闲钱管理 |

> 来源：上海证券交易所《国债逆回购交易规则》、深圳证券交易所《国债逆回购交易规则》
