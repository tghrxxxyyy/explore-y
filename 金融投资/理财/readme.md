# 理财（现金与稳健管理）

> 投资不止股票基金。本板块讲"不追求高收益、但要安全稳健"的那部分钱：存款、货基、银行理财、国债——对应的是"随时要用的钱"和"一两年内不动的钱"。

> ⚠️ 本板块为理财常识科普，**不构成投资建议**；产品收益与风险以发行方披露为准，存款受存款保险保障（单家银行 50 万内）。

## 核心逻辑

1. **按"钱的使用时间"配工具**：随时用→活钱（货基/活期）；1–3 年不用→定存/理财/国债；3 年以上可承受波动→权益（股票基金，见 ../炒股 ../基金）。
2. **安全垫思维**：先有 3–6 个月开支的应急金（活钱），再做其他投资。
3. **收益=风险补偿**：承诺"高收益零风险"必是骗局（详见 ../防骗反诈）。
