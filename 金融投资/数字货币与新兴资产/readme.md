# 数字货币与新兴资产

> 本板块只讲**认知**，不讲**荐币**。数字货币（虚拟货币）在中国大陆被明令禁止交易炒作，相关业务被定性为非法金融活动；而黄金 ETF、REITs 等新兴资产则提供了普通人可合规参与的配置选项。本板块帮你认清"是什么、风险在哪、能不能碰、怎么合规碰"。

> 核心前提：**中国大陆禁止虚拟货币交易炒作**。境内没有合法的个人交易通道，境外平台服务境内居民同样属非法。请把本板块当作风险教育，而非投资指南。

## 核心提醒

- **监管红线**：境内禁止代币发行融资（ICO）与虚拟货币交易炒作，相关业务活动属于**非法金融活动**；挖矿已被清理整治。个人参与，法律不保护。
- **普通人默认高风险**：虚拟货币 24 小时交易、无涨跌停、无熔断，单日跌 30%–50% 不罕见；绝大多数小币种最终归零。
- **占比极小**：若坚持探索，金额不得超过总资产的极小比例（例如 5% 以内），且只用彻底闲置的钱，**不借钱、不加杠杆、不 all in**。
- **只讲认知不讲荐币**：任何"带单群、稳赚翻倍、老师带飞"都是骗局信号；凡是让你拉人头的更是一律远离。
- **合规替代**：想要资产配置的确定性，用黄金 ETF、宽基指数基金等成熟品种即可实现；想合规接触加密资产，可了解香港持牌机构与境外受监管交易所，但跨境资金与外汇限制需自行核实。

先读「数字货币入门」建立底层认知，再读「风险与监管」认清现实，最后读「新兴资产概览」判断自己真正需要哪种资产。顺序不可颠倒——**先懂风险，再谈参与**。
