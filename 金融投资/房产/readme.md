# 房产

> 房子既是住的地方，也是最重的资产决策。本板块聚焦"钱"的维度：房贷怎么选、自住还是投资、置换流程与避坑。（装修/租房看 ../../生活/居家）

> ⚠️ 房产政策（限购、首付、利率、税费）因城施策、变动频繁，本板块为通用框架，**交易前务必查当地最新规定**。

## 核心逻辑

1. **房子的大头是"杠杆+现金流"**：月供是否可持续，比"会不会涨"更先决。
2. **自住看舒适与通勤，投资看租售比与流动性**：两套标准别混。
3. **政策是最大变量**：利率、限购、税费随时调，决策要基于当下可执行政策。
