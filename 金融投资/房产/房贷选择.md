# 房贷选择

> 房贷是普通人能拿到的最便宜的大额杠杆。怎么贷、贷多少、选什么还款方式，直接决定十几年现金流。

## 一、三种贷款

- **公积金贷款**：利率最低（2026 首套 5 年以上约 2.6%，二套约 3.075%），但有额度上限（各地不同，常 50–120 万），且需缴存满一定期限。优先用足。
- **商业贷款**：利率随 LPR（2026-07 五年期以上 3.5%，首套实际约 3.05% 上下），灵活、额度高。
- **组合贷**：公积金额度不够时，组合商贷补齐——最大程度用低息公积金。流程比纯商贷繁琐。

## 二、LPR 浮动 vs 固定

- 现在新发放房贷基本是 **LPR 浮动**（在 LPR 基础上加减点，加减点终身不变，LPR 随重定价日变）。
- 选浮动是主流：长期看利率有下行空间，且加减点固定、未来可转。固定利率极少见于新发。
- **重定价日/周期**：合同定（如每年 1 月 1 日或贷款发放日对应日），LPR 变动后到重定价日才调整月供。

## 三、等额本息 vs 等额本金

| 方式 | 月供 | 总利息 | 适合 |
|------|------|--------|------|
| 等额本息 | 每月一样（前期利息占比高） | 较多 | 收入稳定、求省心 |
| 等额本金 | 每月递减（前期高） | 较少 | 前期还款能力强、想省息 |

- 多数人选等额本息（月供可预期）；等额本金总息少但前期压力大。
- 提前还款：等额本息前期还的大多是利息，早还省息明显；是否提前还应看手头资金的机会成本（理财收益 vs 房贷利率）。

## 四、贷多少、贷多久

- **月供 ≤ 家庭月收入 1/3–1/2**：留足生活与抗风险空间。别把月供压到收入 50% 以上。
- **期限**：能长则长（30 年），月供压力小、提前还款灵活；短期限省息但月供高。
- **首付**：首套多地 15% 起，二套 15%–30%；首付多则月供少，但别把流动资金压干。

## 五、提前还款与转贷

- 手有余钱且理财收益低于房贷利率，可考虑提前还（部分/全部），注意是否有违约金、是否缩期或减额。
- "转贷/经营贷置换房贷"有合规与续贷风险，普通人不建议盲目操作。
- 存量房贷可关注"存量利率调整"政策，符合条件会自动/申请下调。

## 六、等额本息 vs 等额本金深度解析

### 计算原理

| 方式 | 月供公式 | 特点 |
|------|----------|------|
| 等额本息 | 每月还款总额固定（本金递增 + 利息递减） | 前期还的主要是利息，后期还的主要是本金 |
| 等额本金 | 每月还固定本金 + 剩余本金利息 | 月供逐月递减，前期压力大但总息少 |

### 实际案例对比（贷款 100 万，利率 3.5%，期限 30 年）

| 项目 | 等额本息 | 等额本金 |
|------|----------|----------|
| 首月月供 | **4490 元** | **5694 元** |
| 末月月供 | 4490 元 | 2787 元 |
| 总利息 | **61.7 万** | **52.6 万** |
| 利息差额 | — | **省 9.1 万** |
| 前 5 年总还款 | 26.9 万 | 31.8 万 |

### 选择建议

| 情况 | 推荐方式 | 理由 |
|------|----------|------|
| 收入稳定、月供压力小 | 等额本金 | 总息少，提前还款更划算 |
| 收入增长期、前期压力大 | 等额本息 | 月供可预期，前期负担轻 |
| 计划提前还贷 | 等额本金优先 | 前期还本多，提前还时本金余额小 |
| 月供占收入超 40% | 等额本息 | 降低前期压力，避免断供风险 |

### 提前还贷判断

| 判断维度 | 建议 |
|----------|------|
| 理财收益率 > 房贷利率 | 不建议提前还（钱用来投资更划算） |
| 理财收益率 < 房贷利率 | 建议提前还（减少利息支出） |
| 等额本息已还过半 | 提前还意义不大（利息已还大部分） |
| 等额本金还款前期 | 提前还省息效果明显 |
| 手头无其他投资渠道 | 建议部分提前还（留足应急资金） |

- **提前还贷方式**：
  - **缩短年限，月供不变**：省息最多（推荐）。
  - **减少月供，年限不变**：降低月供压力，但总息节省较少。
  - **部分提前还款**：还一部分本金，剩余继续按原合同执行。

> 来源：中国人民银行、各商业银行贷款计算器

## 七、LPR 浮动利率详解

### LPR 定价机制

| 要素 | 说明 |
|------|------|
| LPR 报价 | 每月 20 日（遇节假日顺延）由 18 家报价行报价 |
| 报价基准 | LPR = MLF 利率 + 报价行加点 |
| 房贷利率 | 房贷利率 = LPR + **固定加减点**（加减点在贷款期限内不变） |
| 重定价日 | 通常为每年 1 月 1 日或贷款发放日对应日 |

### LPR 变动影响

| LPR 变动 | 对已有房贷影响 |
|----------|----------------|
| LPR 下行 | 下个重定价日后月供减少 |
| LPR 上行 | 下个重定价日后月供增加 |
| LPR 不变 | 月供不变 |

### 固定利率 vs LPR 浮动利率

| 维度 | 固定利率 | LPR 浮动利率 |
|------|----------|--------------|
| 利率锁定 | 全程不变 | 随 LPR 变动（加减点固定） |
| 适合场景 | 预期利率上行 | 预期利率下行（当前主流） |
| 转换灵活性 | 一旦选定不可转回 | 部分银行允许转回固定（政策变动中） |
| 当前状态 | 极少见于新发房贷 | 2020 年后新发房贷默认 LPR 浮动 |

- **2024-2026 趋势**：LPR 持续下行，选择 LPR 浮动的借款人月供不断减少，验证了浮动利率的优势。

> 来源：中国人民银行《贷款市场报价利率（LPR）报价机制》

## 八、公积金贷款 vs 商业贷款 vs 组合贷

### 公积金贷款

| 要素 | 说明 |
|------|------|
| 利率 | 首套 5 年以上约 **2.6%**，二套约 **3.075%**（2026 年参考） |
| 额度上限 | 各地不同（常 50-120 万元） |
| 申请条件 | 连续缴存 6-12 个月以上（各地要求不同） |
| 优势 | 利率最低，月供最少 |
| 劣势 | 额度有限、审批慢、开发商可能不接受 |

### 商业贷款

| 要素 | 说明 |
|------|------|
| 利率 | 5 年以上 LPR + 加减点（2026 首套实际约 3.0%-3.5%） |
| 额度 | 无上限（按收入流水和首付比例确定） |
| 审批 | 速度快，接受度高 |
| 优势 | 灵活、额度高、放款快 |
| 劣势 | 利率高于公积金 |

### 组合贷

| 要素 | 说明 |
|------|------|
| 定义 | 公积金贷款 + 商业贷款组合使用 |
| 目的 | 公积金额度不够时，用商贷补齐，最大化低息公积金 |
| 操作 | 先申请公积金，不足部分用商贷补 |
| 注意 | 流程比纯商贷繁琐，部分开发商可能不愿接受 |

### 三种贷款选择决策

| 情况 | 推荐方案 |
|------|----------|
| 公积金额度足够覆盖房款 | 纯公积金贷款 |
| 公积金额度不足 | 组合贷（公积金 + 商贷） |
| 急需放款/开发商不接受公积金 | 先纯商贷，后续申请"商转公"（如有政策） |
| 二套房 | 公积金二套 + 商贷二套组合 |

> 来源：各地住房公积金管理中心、商业银行

## 九、公积金贷款详细攻略

### 缴存要求

| 条件 | 说明 |
|------|------|
| 连续缴存 | 申请前连续缴存 6-12 个月（各地不同） |
| 账户余额 | 部分城市要求账户余额达到一定额度 |
| 贷款次数 | 公积金贷款最多使用 2 次（已结清可再用） |
| 缴存基数 | 影响可贷额度（缴存基数 × 倍数 = 可贷上限） |

### 额度计算

| 城市类型 | 常见额度上限 |
|----------|--------------|
| 一线城市（北上广深） | 80-120 万 |
| 二线城市 | 60-80 万 |
| 三四线城市 | 40-60 万 |

### 商转公流程

1. 确认当地是否支持商转公政策。
2. 提前还清商业贷款或提供担保。
3. 向公积金中心提交申请（房产证、贷款合同、还款记录等）。
4. 审批通过后，公积金中心放款还清商贷，剩余按公积金利率执行。
5. 注意：商转公可能有排队周期（3-6 个月甚至更长）。

> 来源：各地住房公积金管理中心

## 十、常见问题 FAQ

| 问题 | 解答 |
|------|------|
| 等额本息和等额本金哪个好？ | 没有绝对好坏，看收入水平和还款计划。前期压力小选等额本息，想省息选等额本金。 |
| 提前还贷有违约金吗？ | 部分银行对还款满一定期限（如 1-3 年）内提前还款收取违约金（1%-3%），需看合同。 |
| LPR 下降后月供什么时候变？ | 在下一个重定价日（通常每年 1 月 1 日）调整。 |
| 公积金断缴了还能贷款吗？ | 一般不能。断缴后需重新连续缴存满要求月数才能申请。 |
| 组合贷可以分开还吗？ | 公积金和商贷分别还款，但通常绑定同一张银行卡自动扣款。 |
| 二手房能用公积金贷款吗？ | 可以，但额度和房龄有关（房龄过老可能降低额度或拒贷）。 |

### 影响利率的因素

- **城市能级**：一线城市竞争激烈，加减点往往更优惠。
- **银行政策**：不同银行对同一城市加减点可能相差 5-10bp。
- **客户资质**：征信良好、收入稳定、首套房客户可获更优利率。
- **贷款金额**：大额贷款可能有议价空间。

## 十二、公积金贷款额度计算

### 计算方法

公积金贷款额度通常取以下四个值中的**最小值**：

| 计算方式 | 说明 |
|----------|------|
| 账户余额 × 倍数 | 各地倍数不同（如 10-20 倍） |
| 还款能力 | 月缴存额 ÷ 缴存比例 × 贷款年限对应系数 |
| 房价成数 | 房价 × 贷款比例（首套 70%-80%，二套 50%-60%） |
| 城市额度上限 | 各地规定的最高额度 |

### 各城市额度上限参考

| 城市 | 个人额度上限 | 夫妻额度上限 |
|------|-------------|-------------|
| 北京 | 120 万 | 120 万 |
| 上海 | 78 万（补充后可达 120 万） | 120 万 |
| 广州 | 60 万 | 100 万 |
| 深圳 | 90 万 | 110 万 |
| 杭州 | 60 万 | 100 万 |
| 成都 | 60 万 | 80 万 |

### 提高额度的技巧

- **夫妻共同贷款**：双方公积金共同使用，额度叠加。
- **补缴公积金**：部分城市允许补缴以提高贷款额度。
- **连续缴存**：缴存时间越长，可贷额度越高。
- **选择组合贷**：公积金额度不足时，商贷补齐。

> 来源：各地住房公积金管理中心

### 计算器使用步骤

## 十四、组合贷最优方案

### 组合贷策略

- **公积金贷款额度**：优先用足公积金额度上限。
- **商贷部分**：公积金不足部分用商贷补齐。
- **还款方式**：公积金等额本息 + 商贷等额本金（组合优化）。
- **还款年限**：公积金选 30 年（月供低），商贷选 20 年（省息）。

### 组合贷避坑

- **开发商拒绝**：部分开发商不愿接受组合贷（流程复杂），购房前确认。
- **审批周期**：组合贷审批通常比纯商贷长 1-2 个月，预留时间。
- **提前还款**：组合贷提前还款需分别与公积金中心和银行协商。

> 来源：各地住房公积金管理中心、商业银行
