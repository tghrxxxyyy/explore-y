# 置换流程（卖一买一 / 改善）

> 置换最难的不是买，而是"卖和买的时间差"——资金链、居住空档、房价波动都可能卡住。本文给时间线与风控。

## 一、先算清账

- 现有房能卖多少（挂牌价≠成交价，留议价空间）。
- 目标房总价、首付缺口 = 目标首付 − 现有房净回款（扣贷款、税费、中介费）。
- 过渡期是否需要租房、搬家成本。

## 二、两种路径

### 路径 A：先卖后买（稳妥）
- 卖房回款 → 还清按揭/解押 → 再买新房。资金链最安全，但可能错失心仪房或短暂租房。
- 适合：市场下行/不确定、现金流紧、不想背"双房贷"。

### 路径 B：先买后卖（抢房）
- 先订新房（交定金/首付，可能需过桥资金）→ 再卖旧房回款填坑。
- 风险：旧房卖慢/卖低，资金断档、双月供压力大；过桥贷有利息与期限。
- 适合：市场上行、已锁定心仪房、旧房好出手、有短期资金周转能力。

## 三、关键节点与坑

- **解押**：旧房有贷先还清解押才能过户；自筹或中介/担保"赎楼"有费用。
- **连环单**：你的买家的买家……任一环掉链子都影响你；合同写清"过户/付款节点+违约"。
- **户口迁出**：旧房户口（尤其学区）必须约明迁出时间与违约，否则影响买家也影响自己信用。
- **满五唯一**：影响个税/增值税，卖前确认持有年限与唯一住房，能省则省。
- **过渡居住**：先卖后买者提前找短租，避免拖家带口仓促。

## 四、风控清单

1. 两份合同（买+卖）的时间节点对齐，留缓冲期。
2. 定金/首付托管（资金监管），别直接打给个人。
3. 双房贷压力测试：假设旧房 3–6 个月没卖出，月供能否扛。
4. 所有口头承诺写进合同补充协议。

## 五、常见失误

- 先买后卖，旧房挂太高迟迟不出，资金链紧被迫降价割肉。
- 忽略解押/户口细节，交割扯皮拖数月。
- 没做资金监管，定金被卷。

## 六、置换流程详解

### 卖旧买新流程（先卖后买）

#### 第一步：评估与挂牌

1. **房产评估**：找2-3家中介评估，了解市场价和成交周期。
2. **定价策略**：比市场价低5%-10%加速成交，或持平价等待。
3. **挂牌准备**：房产证、身份证、婚姻证明、物业费缴纳证明。
4. **选择中介**：大品牌中介客户多、流程规范，但中介费较高。

#### 第二步：带看与签约

1. **配合看房**：保持房屋整洁，方便中介带客户看房。
2. **议价谈判**：留出5%-10%的议价空间，确定最终成交价。
3. **签订合同**：明确付款方式、过户时间、户口迁出、家具家电等。
4. **收取定金**：一般为成交价的5%-10%，存入资金监管账户。

#### 第三步：收款与解押

1. **买方付款**：全款或贷款审批通过后放款。
2. **还清贷款**：自筹或用买方首付还清按揭贷款。
3. **办理解押**：到银行办理抵押注销，拿回房产证。
4. **户口迁出**：按合同约定时间迁出户口。

#### 第四步：过户与交房

1. **办理过户**：到不动产登记中心办理产权转移。
2. **税费缴纳**：契税、增值税、个税等，按合同约定由谁承担。
3. **物业交割**：水电气暖物业费结算，钥匙移交。
4. **交房完成**：买方验收，卖方收到全部房款。

### 先买后卖流程（先买后卖）

#### 第一步：寻找目标房源

1. **明确需求**：面积、位置、学区、配套等。
2. **看房选房**：多看多比，锁定目标。
3. **签约购房**：与卖方签订购房合同，支付定金。
4. **资金安排**：自筹首付或过桥资金，准备过户。

#### 第二步：同步挂牌旧房

1. **同步挂牌**：在签约新房后立即挂牌旧房。
2. **加速成交**：定价略低于市场价，争取快速成交。
3. **优先全款客户**：全款客户成交快，减少贷款等待时间。

#### 第三步：新房过户与旧房回款

1. **新房过户**：按合同约定时间办理过户。
2. **旧房回款**：旧房买家付款后，资金用于填补新房款项。
3. **时间衔接**：两套房过户时间尽量接近，减少资金占用。

#### 第四步：完成置换

1. **新房交房**：验收新房，办理入住。
2. **旧房交房**：按合同约定时间交房给买家。
3. **资金结算**：所有款项结清，交易完成。

## 七、税费计算详解

### 卖房税费

| 税费项目 | 税率/金额 | 免征条件 |
|---------|----------|---------|
| 增值税 | 5.3%（含附加） | 满2年免征（普通住宅） |
| 个人所得税 | 差额20%或全额1% | 满五唯一免征 |
| 中介费 | 成交价1%-3% | 无 |
| 评估费 | 评估价0.1%-0.5% | 无 |
| 抵押注销费 | 约100-500元 | 无 |

### 买房税费

| 税费项目 | 税率/金额 | 备注 |
|---------|----------|------|
| 契税 | 首套≤90平1%，>90平1.5%；二套1%-2% | 各城市不同 |
| 中介费 | 成交价1%-3% | 无 |
| 贷款服务费 | 数百至数千元 | 视银行而定 |
| 产权登记费 | 80-550元 | 住宅类 |

### 税费节省策略

- **满五唯一**：卖房前确认持有年限和唯一住房，免个税。
- **满2年**：普通住宅满2年免增值税。
- **合理定价**：合理定价减少增值部分，降低税费。
- **合同约定**：明确约定税费由谁承担，避免纠纷。

## 八、贷款衔接安排

### 贷款类型选择

| 贷款类型 | 利率 | 额度 | 适合人群 |
|---------|------|------|---------|
| 公积金贷款 | 2.6%左右 | 40-120万 | 缴存公积金职工 |
| 商业贷款 | LPR+加点 | 无上限 | 所有购房者 |
| 组合贷款 | 混合利率 | 公积金+商贷 | 公积金额度不足 |

### 贷款申请要点

- **收入证明**：月供不超过月收入的50%。
- **征信记录**：近2年无严重逾期。
- **负债率**：总负债不超过资产的70%。
- **流水要求**：提供6个月以上银行流水。

### 公积金贷款衔接

- **连续缴存**：贷款申请时需连续缴存6-12个月。
- **账户余额**：余额影响贷款额度，尽量保持较高余额。
- **断缴影响**：已放款一般不影响，新申请需恢复缴存。

### 过桥资金使用

- **适用情况**：先买后卖，旧房未回款需资金周转。
- **成本**：过桥资金利息较高，通常按日计息。
- **风险**：旧房卖慢或卖低，可能导致资金链断裂。
- **建议**：尽量避免使用过桥资金，或控制使用时间。

## 九、时间规划建议

### 先卖后买时间线

| 阶段 | 时间 | 主要事项 |
|------|------|---------|
| 评估挂牌 | 1-2周 | 房产评估、定价、挂牌 |
| 带看成交 | 1-3个月 | 配合看房、议价、签约 |
| 收款解押 | 1-2个月 | 收款、还贷、解押 |
| 过户交房 | 1个月 | 办理过户、税费缴纳、交房 |
| 买房过户 | 1-2个月 | 看房、签约、过户 |
| **总计** | **4-8个月** | 完成整个置换周期 |

### 先买后卖时间线

| 阶段 | 时间 | 主要事项 |
|------|------|---------|
| 看房签约 | 1-2个月 | 寻找目标、签约购房 |
| 同步挂牌 | 签约后立即 | 旧房挂牌销售 |
| 新房过户 | 1-2个月 | 办理新房过户 |
| 旧房回款 | 2-4个月 | 旧房成交、回款 |
| 完成交割 | 1个月 | 两套房交割完成 |
| **总计** | **5-8个月** | 完成整个置换周期 |

### 时间衔接技巧

- **预留缓冲期**：各环节预留1-2周缓冲，避免时间紧张。
- **同步操作**：能同时进行的环节尽量同步，缩短总时间。
- **提前准备**：贷款申请、资料准备等提前完成，不耽误进度。
- **中介协调**：让中介协助协调各方时间，提高效率。

## 十、资金安排详解

### 资金缺口计算

- **旧房净回款**=成交价-贷款余额-税费-中介费。
- **新房总成本**=成交价+税费+中介费+装修费。
- **资金缺口**=新房总成本-旧房净回款-自筹资金。

### 资金来源渠道

| 渠道 | 优势 | 劣势 | 适合情况 |
|------|------|------|---------|
| 自有资金 | 无成本 | 占用流动资金 | 资金充足 |
| 家人借款 | 无息或低息 | 欠人情 | 短期周转 |
| 过桥资金 | 快速到账 | 利息高 | 紧急情况 |
| 信用贷款 | 门槛低 | 利率较高 | 小额缺口 |

### 资金安全措施

- **资金监管**：购房款存入监管账户，保障资金安全。
- **定金托管**：定金由中介或银行托管，不直接给个人。
- **分阶段付款**：按进度付款，避免一次性支付大额资金。
- **合同约定**：明确违约责任，保障自身权益。

## 十一、风险控制要点

### 市场风险

- **房价波动**：置换期间房价可能上涨或下跌。
- **应对策略**：合理定价、加快成交、避免追高。

### 资金风险

- **资金链断裂**：旧房卖慢或卖低，新房需付款。
- **应对策略**：预留缓冲资金、避免过度杠杆、准备备用方案。

### 时间风险

- **交房延迟**：过户、贷款等环节可能出现延迟。
- **应对策略**：预留缓冲时间、同步操作、提前准备资料。

### 法律风险

- **合同纠纷**：条款不清、违约等情况。
- **应对策略**：请律师审核合同、明确约定、保留证据。

### 信用风险

- **贷款被拒**：征信问题、收入不足等。
- **应对策略**：提前了解征信、准备充分资料、选择合适银行。

## 十一、置换流程详解

### 11.1 标准置换流程

| 步骤 | 内容 | 时间 | 关键点 |
|------|------|------|--------|
| 1. 评估需求 | 确定置换原因、目标区域、户型、预算 | 1-2周 | 明确核心需求，避免冲动决策 |
| 2. 房屋估价 | 委托2-3家中介评估旧房价值 | 1周 | 多家对比，了解市场真实价格 |
| 3. 制定计划 | 确定卖旧买新/买新卖旧/同时进行 | 1周 | 根据资金情况选择策略 |
| 4. 挂牌出售 | 签约中介、定价、看房 | 2-8周 | 定价合理，保持房屋整洁 |
| 5. 签约旧房 | 与买家签约、收定金 | 1-2周 | 明确付款方式、过户时间 |
| 6. 看房选房 | 新房看房、谈判、签约 | 2-8周 | 预留足够时间，不仓促决定 |
| 7. 贷款申请 | 提交贷款资料、审批 | 2-4周 | 提前准备资料，选择合适银行 |
| 8. 过户旧房 | 旧房过户给买家 | 1-2周 | 确保买家贷款已批复 |
| 9. 过户新房 | 新房过户到自己名下 | 1-2周 | 确保资金到位 |
| 10. 交房验收 | 新房交房、旧房交房 | 1-2周 | 仔细验收，有问题及时提出 |

### 11.2 三种置换策略对比

| 策略 | 优点 | 缺点 | 适用情况 |
|------|------|------|---------|
| **卖旧买新** | 资金充足，无贷款压力 | 需要租房过渡，时间不确定 | 旧房好卖、资金紧张 |
| **买新卖旧** | 直接入住新房 | 资金压力大，可能需要过桥贷 | 资金充足、新房紧迫 |
| **同时进行** | 无缝衔接，无需租房 | 操作复杂，风险较高 | 时间充裕、操作经验丰富 |

### 11.3 置换时间规划

| 策略 | 预计总时间 | 关键节点 |
|------|-----------|---------|
| 卖旧买新 | 3-6个月 | 旧房出售时间、新房选择时间 |
| 买新卖旧 | 2-4个月 | 新房签约、旧房出售 |
| 同时进行 | 2-4个月 | 两个交易同步进行 |

> 来源：链家、贝壳研究院置换流程指南

## 十二、资金安排详解

### 12.1 资金来源

| 来源 | 金额 | 使用优先级 | 注意事项 |
|------|------|-----------|---------|
| 旧房出售款 | 房屋总价 | 优先使用 | 到账时间不确定 |
| 存款 | 个人储蓄 | 次优先 | 预留6个月生活费 |
| 公积金 | 账户余额 | 可提取 | 置换可提取，需提前申请 |
| 商业贷款 | 银行批复额度 | 补充使用 | 利率较高，谨慎使用 |
| 亲友借款 | 协商金额 | 临时周转 | 明确还款时间，避免纠纷 |

### 12.2 资金时间安排

| 时间点 | 资金需求 | 来源 | 说明 |
|--------|---------|------|------|
| 签约旧房 | 定金（5-10万） | 旧房买家支付 | 收到定金后才有资金 |
| 签约新房 | 定金（5-20万） | 存款/亲友借款 | 需要提前准备 |
| 新房贷款审批 | 首付款（30%-70%） | 旧房出售款+存款 | 确保资金在贷款前到位 |
| 旧房过户 | 收尾款 | 买家贷款/现金 | 确保过户前资金到位 |
| 新房过户 | 尾款 | 贷款+自有资金 | 确保过户前资金到位 |

### 12.3 过桥资金使用

| 情况 | 解决方案 | 成本 | 风险 |
|------|---------|------|------|
| 旧房未卖，新房需付款 | 过桥贷款 | 月息1%-2% | 旧房未按时卖出 |
| 旧房已签约，尾款未到 | 信用贷款 | 年化6%-10% | 买家违约 |
| 新房需提前付首付 | 亲友借款 | 无息或低息 | 影响关系 |

> 来源：房产交易资金规划指南

## 十三、贷款衔接策略

### 13.1 贷款类型选择

| 贷款类型 | 利率（2025年） | 期限 | 适用情况 |
|---------|---------------|------|---------|
| 公积金贷款 | 3.1% | 最长30年 | 公积金缴存充足 |
| 商业贷款 | 3.5%-4.0% | 最长30年 | 公积金不足 |
| 组合贷款 | 3.1%+3.5%-4.0% | 最长30年 | 公积金+商业贷款组合 |

### 13.2 贷款衔接要点

- **提前申请**：贷款审批需2-4周，提前准备资料。
- **选择银行**：多家银行对比利率和审批速度。
- **资料准备**：收入证明、银行流水、征信报告、购房合同。
- **贷款额度**：确保贷款额度足够覆盖新房尾款。
- **还款计划**：确保月供不超过家庭月收入的50%。

### 13.3 旧房贷款处理

| 情况 | 处理方式 | 说明 |
|------|---------|------|
| 旧房有贷款 | 提前还款或转按揭 | 确保旧房无贷款才能过户 |
| 旧房贷款未还清 | 用买家首付还贷款 | 常见做法，但需谨慎 |
| 旧房贷款已还清 | 直接过户 | 最简单情况 |

> 来源：银行房贷政策、房产交易贷款指南

## 十四、税费计算器

### 14.1 卖旧房税费

| 税费类型 | 税率 | 计算方式 | 减免政策 |
|---------|------|---------|---------|
| 增值税 | 5.3% | （卖出价-买入价）×5.3% | 满2年免征 |
| 个人所得税 | 1%或差额20% | 卖出价×1%或（卖出价-买入价-合理费用）×20% | 满5年唯一免征 |
| 中介费 | 1%-2% | 卖出价×1%-2% | 无 |
| 评估费 | 0.1%-0.5% | 评估价×0.1%-0.5% | 无 |

### 14.2 买新房税费

| 税费类型 | 税率 | 计算方式 | 减免政策 |
|---------|------|---------|---------|
| 契税 | 1%-3% | 成交价×1%-3% | 首套房90㎡以下1%，90㎡以上1.5% |
| 中介费 | 1%-2% | 成交价×1%-2% | 无 |
| 贷款服务费 | 0.5%-1% | 贷款金额×0.5%-1% | 无 |
| 抵押登记费 | 80-550元 | 固定费用 | 无 |

### 14.3 置换总税费估算

| 项目 | 金额（以500万旧房、600万新房为例） | 说明 |
|------|--------------------------------|------|
| 卖旧房增值税 | 约26.5万（如不满2年） | 满2年免征 |
| 卖旧房个税 | 约5万（1%）或差额20% | 满5年唯一免征 |
| 卖旧房中介费 | 约5-10万 | 1%-2% |
| 买新房契税 | 约6-18万 | 1%-3% |
| 买新房中介费 | 约6-12万 | 1%-2% |
| **合计** | **约48-71.5万** | 视具体情况 |

> 来源：国家税务总局、房产交易税费标准

## 十五、风险防范

### 15.1 交易风险

| 风险类型 | 具体表现 | 防范措施 |
|---------|---------|---------|
| 买家违约 | 买家贷款未批、反悔不买 | 约定违约金、及时催办 |
| 卖家违约 | 卖家一房多卖、反悔不卖 | 签订正式合同、资金监管 |
| 中介风险 | 中介挪用资金、虚假承诺 | 选择正规中介、资金监管 |
| 政策风险 | 限购政策变化、贷款政策收紧 | 提前了解政策、预留缓冲期 |

### 15.2 资金风险

| 风险类型 | 具体表现 | 防范措施 |
|---------|---------|---------|
| 资金监管 | 买家首付被挪用 | 使用银行资金监管账户 |
| 过桥风险 | 过桥贷款到期、旧房未卖出 | 控制过桥时间、准备备用方案 |
| 贷款风险 | 贷款未批、额度不足 | 提前了解征信、准备充分资料 |

### 15.3 法律风险

| 风险类型 | 具体表现 | 防范措施 |
|---------|---------|---------|
| 合同风险 | 合同条款不明确、遗漏关键条款 | 请律师审核合同 |
| 产权风险 | 产权不清晰、有抵押/查封 | 提前查询产权状态 |
| 交房风险 | 房屋质量问题、户口未迁出 | 交房前仔细验收、约定户口迁出时间 |

> 来源：房产交易法律风险防范指南

## 十六、置换注意事项

### 16.1 旧房出售注意事项

- **定价合理**：参考周边同户型成交价，不要过高或过低。
- **房屋整洁**：保持房屋干净整洁，利于看房。
- **配合看房**：保持联系方式畅通，方便中介安排看房。
- **签约谨慎**：仔细阅读合同条款，特别是付款方式、过户时间、违约责任。

### 16.2 新房购买注意事项

- **看房充分**：多看几套，对比户型、楼层、朝向、周边配套。
- **开发商资质**：选择正规开发商，查看五证是否齐全。
- **合同条款**：仔细阅读购房合同，特别是交房时间、违约责任。
- **贷款准备**：提前了解贷款政策，准备充分资料。

### 16.3 交接注意事项

- **旧房交接**：确认房屋内设施设备、户口是否迁出。
- **新房验收**：仔细检查房屋质量，有问题及时提出。
- **物业交接**：办理物业交割，结清物业费、水电费。
- **户口迁移**：确保原房主户口已迁出。

> 来源：房产交易实战经验总结

## 八、置换时机判断

### 九、卖房时机

| 时机 | 特征 | 建议 |
|------|------|------|
| **市场升温期** | 成交量放大、价格上涨 | 适合卖出，可获得更好价格 |
| **政策宽松期** | 限购放松、利率下降 | 适合卖出，买家增多 |
| **季节旺季** | 3-4月、9-10月传统旺季 | 适合挂牌，带看量大 |
| **市场高点** | 价格涨幅放缓、成交量下降 | 考虑卖出，避免高位套牢 |

### 十、买房时机

| 时机 | 特征 | 建议 |
|------|------|------|
| **市场低迷期** | 成交量萎缩、价格下跌 | 适合买入，议价空间大 |
| **政策收紧期** | 限购严格、利率上升 | 适合买入，竞争减少 |
| **季节淡季** | 1-2月、7-8月淡季 | 适合看房，决策更从容 |
| **市场低点** | 价格企稳、政策见底 | 适合买入，长期持有 |

### 十一、置换决策框架

- **刚需置换**：自住需求优先，不必过度择时，"卖一买一"时间差控制在3-6个月内。
- **改善置换**：考虑家庭结构变化（如二孩、老人同住），提前规划置换时间。
- **投资置换**：需判断市场趋势，高位卖、低位买，赚取差价。

> 来源：贝壳研究院房产市场报告、各城市房管局交易数据

## 十二、卖一买一流程详解

### 十三、卖房流程

| 步骤 | 时间 | 注意事项 |
|------|------|---------|
| **1. 挂牌** | — | 选择正规中介、合理定价 |
| **2. 带看** | 1-3个月 | 保持房屋整洁、配合看房 |
| **3. 签约** | 1-2周 | 明确付款方式、交房时间 |
| **4. 网签** | 1-3天 | 双方到场，确认合同条款 |
| **5. 资金监管** | 1-2周 | 买方资金进入监管账户 |
| **6. 过户** | 1-2周 | 双方到场，办理产权转移 |
| **7. 交房** | 1-2周 | 结清物业费、水电费 |

### 十四、买房流程

| 步骤 | 时间 | 注意事项 |
|------|------|---------|
| **1. 看房** | 1-3个月 | 明确需求、预算、区位 |
| **2. 签约** | 1-2周 | 确认产权、贷款资格 |
| **3. 贷款申请** | 1-2周 | 准备收入证明、银行流水 |
| **4. 银行审批** | 2-4周 | 等待审批、配合补充材料 |
| **5. 过户** | 1-2周 | 双方到场，办理产权转移 |
| **6. 抵押登记** | 1-2周 | 银行办理抵押登记 |
| **7. 放款** | 1-2周 | 银行放款给卖方 |
| **8. 交房** | 1-2周 | 验房、结清费用 |

### 十五、时间差控制

- **同步交易**：卖房与买房同时进行，签约时约定好时间衔接。
- **过桥资金**：如时间差较大，可考虑过桥资金（短期借款），但需控制成本。
- **合同约定**：在卖房合同中约定"过户后X个月内交房"，为买房争取时间。

> 来源：房产交易实战经验总结、各城市房管局交易流程指南

## 十六、置换税费计算

### 十七、卖房税费

| 税费类型 | 税率 | 说明 |
|---------|------|------|
| **增值税** | 5.3%（满2年免征） | 房产证不满2年需缴纳 |
| **个人所得税** | 1%或差额20%（满5唯一免征） | 房产证满5年且唯一住房免征 |
| **中介费** | 1-2% | 由卖方承担（部分城市由买方承担） |

### 十八、买房税费

| 税费类型 | 税率 | 说明 |
|---------|------|------|
| **契税** | 1-3% | 首套房90㎡以下1%，90㎡以上1.5%；二套房3% |
| **印花税** | 0.05% | 个人购买住宅免征 |
| **中介费** | 1-2% | 由买方承担（部分城市由卖方承担） |
| **贷款服务费** | 约0.5-1% | 通过中介贷款需支付 |

### 十九、税费优化策略

- **满5唯一**：房产证满5年且唯一住房，免征增值税和个人所得税，可节省约6-7%税费。
- **合理定价**：通过合理定价降低差额，减少个人所得税。
- **选择时机**：在税费优惠政策期间交易（如契税减免政策）。
- **夫妻更名**：如满足条件，可通过夫妻更名方式过户，避免部分税费（需专业指导）。

> 来源：财政部《关于调整房地产交易环节契税营业税优惠政策的通知》、各城市房管局税费规定

## 二十、资金周转方案

### 二十一、常见资金周转方式

| 方式 | 优点 | 缺点 |
|------|------|------|
| **自有资金** | 无成本 | 资金压力大 |
| **过桥贷款** | 快速获得资金 | 利率高（月息约1-2%） |
| **信用贷款** | 手续简单 | 额度有限、利率较高 |
| **公积金提取** | 利率低 | 提取条件严格 |
| **亲友借款** | 无成本或低息 | 可能影响关系 |

### 二十二、过桥资金使用建议

- **成本计算**：过桥资金月息约1-2%，时间越长成本越高，需精确计算时间差。
- **额度控制**：过桥资金额度尽量覆盖卖房尾款与买房首付的差额。
- **还款计划**：明确还款来源（卖房尾款）和还款时间，避免资金链断裂。
- **风险提示**：如卖房交易延迟，过桥资金成本会大幅增加，需预留缓冲时间。

### 二十三、公积金提取策略

- **租房提取**：每月可提取一定额度用于租房，可积累购房资金。
- **购房提取**：购房后可提取公积金账户余额，用于支付首付或还贷。
- **还贷提取**：每月可提取公积金用于偿还房贷，减轻月供压力。
- **销户提取**：退休、出国定居等情况下可销户提取全部余额。

> 来源：各地住房公积金管理中心、各银行过桥贷款业务规则

## 二十四、置换风险控制详解

### 时间差风险管理

| 风险 | 应对措施 |
|------|---------|
| 旧房卖不掉 | 定价略低于市场价，加快成交 |
| 新房被别人买走 | 签合同时约定违约金条款 |
| 资金链断裂 | 预留3-6个月月供储备金 |
| 过桥成本超预期 | 精确计算时间差，预留缓冲期 |

### 合同关键条款

| 条款 | 要点 |
|------|------|
| 付款节点 | 明确每笔款项的支付时间 |
| 过户时间 | 约定具体过户日期 |
| 违约责任 | 明确违约金比例（通常5-10%） |
| 户口迁出 | 约定迁出时间和违约责任 |
| 物业交割 | 明确水电气暖物业费结算时间 |

### 置换核心原则

- **先卖后买更稳妥**：资金链最安全，避免双月供压力。
- **做好资金监管**：定金、首付存入监管账户，避免资金风险。
- **时间差要留缓冲**：两套房过户时间尽量接近，但要预留应急时间。
- **所有承诺写进合同**：口头承诺无效，必须写入补充协议。

> 来源：贝壳研究院房产市场报告、各城市房管局交易数据

### 置换常见问题

| 问题 | 解答 |
|------|------|
| 卖房后多久必须买房 | 没有时间限制，但建议尽快避免房价波动 |
| 过桥资金利率多少 | 月息约1-2%，年化约12-24% |
| 公积金可以提取几次 | 购房提取一般限2次，租房提取每月可提 |
| 置换需要多少时间 | 顺利情况下约2-3个月，复杂情况可能4-6个月 |

### 置换税费节省技巧

| 技巧 | 节省金额 |
|------|---------|
| 满5唯一免个税和增值税 | 约6-7% |
| 首套房契税1-1.5% | 比二套省1.5-2% |
| 合理定价降低差额 | 减少个税基数 |
| 夫妻更名过户 | 避免部分税费 |

### 置换核心原则总结

- **做好预算**：卖房净回款减去首付缺口，确保资金充足。
- **控制时间差**：两套房过户时间尽量接近，减少资金占用。
- **预留应急资金**：准备3-6个月月供储备金，应对突发情况。
- **选择正规中介**：大品牌中介流程规范，避免交易风险。
