# 置换流程（卖一买一 / 改善）

> 置换最难的不是买，而是"卖和买的时间差"——资金链、居住空档、房价波动都可能卡住。本文给时间线与风控。

## 一、先算清账

- 现有房能卖多少（挂牌价≠成交价，留议价空间）。
- 目标房总价、首付缺口 = 目标首付 − 现有房净回款（扣贷款、税费、中介费）。
- 过渡期是否需要租房、搬家成本。

## 二、两种路径

### 路径 A：先卖后买（稳妥）
- 卖房回款 → 还清按揭/解押 → 再买新房。资金链最安全，但可能错失心仪房或短暂租房。
- 适合：市场下行/不确定、现金流紧、不想背"双房贷"。

### 路径 B：先买后卖（抢房）
- 先订新房（交定金/首付，可能需过桥资金）→ 再卖旧房回款填坑。
- 风险：旧房卖慢/卖低，资金断档、双月供压力大；过桥贷有利息与期限。
- 适合：市场上行、已锁定心仪房、旧房好出手、有短期资金周转能力。

## 三、关键节点与坑

- **解押**：旧房有贷先还清解押才能过户；自筹或中介/担保"赎楼"有费用。
- **连环单**：你的买家的买家……任一环掉链子都影响你；合同写清"过户/付款节点+违约"。
- **户口迁出**：旧房户口（尤其学区）必须约明迁出时间与违约，否则影响买家也影响自己信用。
- **满五唯一**：影响个税/增值税，卖前确认持有年限与唯一住房，能省则省。
- **过渡居住**：先卖后买者提前找短租，避免拖家带口仓促。

## 四、风控清单

1. 两份合同（买+卖）的时间节点对齐，留缓冲期。
2. 定金/首付托管（资金监管），别直接打给个人。
3. 双房贷压力测试：假设旧房 3–6 个月没卖出，月供能否扛。
4. 所有口头承诺写进合同补充协议。

## 五、常见失误

- 先买后卖，旧房挂太高迟迟不出，资金链紧被迫降价割肉。
- 忽略解押/户口细节，交割扯皮拖数月。
- 没做资金监管，定金被卷。

## 六、置换流程详解

### 卖旧买新流程（先卖后买）

#### 第一步：评估与挂牌

1. **房产评估**：找2-3家中介评估，了解市场价和成交周期。
2. **定价策略**：比市场价低5%-10%加速成交，或持平价等待。
3. **挂牌准备**：房产证、身份证、婚姻证明、物业费缴纳证明。
4. **选择中介**：大品牌中介客户多、流程规范，但中介费较高。

#### 第二步：带看与签约

1. **配合看房**：保持房屋整洁，方便中介带客户看房。
2. **议价谈判**：留出5%-10%的议价空间，确定最终成交价。
3. **签订合同**：明确付款方式、过户时间、户口迁出、家具家电等。
4. **收取定金**：一般为成交价的5%-10%，存入资金监管账户。

#### 第三步：收款与解押

1. **买方付款**：全款或贷款审批通过后放款。
2. **还清贷款**：自筹或用买方首付还清按揭贷款。
3. **办理解押**：到银行办理抵押注销，拿回房产证。
4. **户口迁出**：按合同约定时间迁出户口。

#### 第四步：过户与交房

1. **办理过户**：到不动产登记中心办理产权转移。
2. **税费缴纳**：契税、增值税、个税等，按合同约定由谁承担。
3. **物业交割**：水电气暖物业费结算，钥匙移交。
4. **交房完成**：买方验收，卖方收到全部房款。

### 先买后卖流程（先买后卖）

#### 第一步：寻找目标房源

1. **明确需求**：面积、位置、学区、配套等。
2. **看房选房**：多看多比，锁定目标。
3. **签约购房**：与卖方签订购房合同，支付定金。
4. **资金安排**：自筹首付或过桥资金，准备过户。

#### 第二步：同步挂牌旧房

1. **同步挂牌**：在签约新房后立即挂牌旧房。
2. **加速成交**：定价略低于市场价，争取快速成交。
3. **优先全款客户**：全款客户成交快，减少贷款等待时间。

#### 第三步：新房过户与旧房回款

1. **新房过户**：按合同约定时间办理过户。
2. **旧房回款**：旧房买家付款后，资金用于填补新房款项。
3. **时间衔接**：两套房过户时间尽量接近，减少资金占用。

#### 第四步：完成置换

1. **新房交房**：验收新房，办理入住。
2. **旧房交房**：按合同约定时间交房给买家。
3. **资金结算**：所有款项结清，交易完成。

## 七、税费计算详解

### 卖房税费

| 税费项目 | 税率/金额 | 免征条件 |
|---------|----------|---------|
| 增值税 | 5.3%（含附加） | 满2年免征（普通住宅） |
| 个人所得税 | 差额20%或全额1% | 满五唯一免征 |
| 中介费 | 成交价1%-3% | 无 |
| 评估费 | 评估价0.1%-0.5% | 无 |
| 抵押注销费 | 约100-500元 | 无 |

### 买房税费

| 税费项目 | 税率/金额 | 备注 |
|---------|----------|------|
| 契税 | 首套≤90平1%，>90平1.5%；二套1%-2% | 各城市不同 |
| 中介费 | 成交价1%-3% | 无 |
| 贷款服务费 | 数百至数千元 | 视银行而定 |
| 产权登记费 | 80-550元 | 住宅类 |

### 税费节省策略

- **满五唯一**：卖房前确认持有年限和唯一住房，免个税。
- **满2年**：普通住宅满2年免增值税。
- **合理定价**：合理定价减少增值部分，降低税费。
- **合同约定**：明确约定税费由谁承担，避免纠纷。

## 八、贷款衔接安排

### 贷款类型选择

| 贷款类型 | 利率 | 额度 | 适合人群 |
|---------|------|------|---------|
| 公积金贷款 | 2.6%左右 | 40-120万 | 缴存公积金职工 |
| 商业贷款 | LPR+加点 | 无上限 | 所有购房者 |
| 组合贷款 | 混合利率 | 公积金+商贷 | 公积金额度不足 |

### 贷款申请要点

- **收入证明**：月供不超过月收入的50%。
- **征信记录**：近2年无严重逾期。
- **负债率**：总负债不超过资产的70%。
- **流水要求**：提供6个月以上银行流水。

### 公积金贷款衔接

- **连续缴存**：贷款申请时需连续缴存6-12个月。
- **账户余额**：余额影响贷款额度，尽量保持较高余额。
- **断缴影响**：已放款一般不影响，新申请需恢复缴存。

### 过桥资金使用

- **适用情况**：先买后卖，旧房未回款需资金周转。
- **成本**：过桥资金利息较高，通常按日计息。
- **风险**：旧房卖慢或卖低，可能导致资金链断裂。
- **建议**：尽量避免使用过桥资金，或控制使用时间。

## 九、时间规划建议

### 先卖后买时间线

| 阶段 | 时间 | 主要事项 |
|------|------|---------|
| 评估挂牌 | 1-2周 | 房产评估、定价、挂牌 |
| 带看成交 | 1-3个月 | 配合看房、议价、签约 |
| 收款解押 | 1-2个月 | 收款、还贷、解押 |
| 过户交房 | 1个月 | 办理过户、税费缴纳、交房 |
| 买房过户 | 1-2个月 | 看房、签约、过户 |
| **总计** | **4-8个月** | 完成整个置换周期 |

### 先买后卖时间线

| 阶段 | 时间 | 主要事项 |
|------|------|---------|
| 看房签约 | 1-2个月 | 寻找目标、签约购房 |
| 同步挂牌 | 签约后立即 | 旧房挂牌销售 |
| 新房过户 | 1-2个月 | 办理新房过户 |
| 旧房回款 | 2-4个月 | 旧房成交、回款 |
| 完成交割 | 1个月 | 两套房交割完成 |
| **总计** | **5-8个月** | 完成整个置换周期 |

### 时间衔接技巧

- **预留缓冲期**：各环节预留1-2周缓冲，避免时间紧张。
- **同步操作**：能同时进行的环节尽量同步，缩短总时间。
- **提前准备**：贷款申请、资料准备等提前完成，不耽误进度。
- **中介协调**：让中介协助协调各方时间，提高效率。

## 十、资金安排详解

### 资金缺口计算

- **旧房净回款**=成交价-贷款余额-税费-中介费。
- **新房总成本**=成交价+税费+中介费+装修费。
- **资金缺口**=新房总成本-旧房净回款-自筹资金。

### 资金来源渠道

| 渠道 | 优势 | 劣势 | 适合情况 |
|------|------|------|---------|
| 自有资金 | 无成本 | 占用流动资金 | 资金充足 |
| 家人借款 | 无息或低息 | 欠人情 | 短期周转 |
| 过桥资金 | 快速到账 | 利息高 | 紧急情况 |
| 信用贷款 | 门槛低 | 利率较高 | 小额缺口 |

### 资金安全措施

- **资金监管**：购房款存入监管账户，保障资金安全。
- **定金托管**：定金由中介或银行托管，不直接给个人。
- **分阶段付款**：按进度付款，避免一次性支付大额资金。
- **合同约定**：明确违约责任，保障自身权益。

## 十一、风险控制要点

### 市场风险

- **房价波动**：置换期间房价可能上涨或下跌。
- **应对策略**：合理定价、加快成交、避免追高。

### 资金风险

- **资金链断裂**：旧房卖慢或卖低，新房需付款。
- **应对策略**：预留缓冲资金、避免过度杠杆、准备备用方案。

### 时间风险

- **交房延迟**：过户、贷款等环节可能出现延迟。
- **应对策略**：预留缓冲时间、同步操作、提前准备资料。

### 法律风险

- **合同纠纷**：条款不清、违约等情况。
- **应对策略**：请律师审核合同、明确约定、保留证据。

### 信用风险

- **贷款被拒**：征信问题、收入不足等。
- **应对策略**：提前了解征信、准备充分资料、选择合适银行。

---

*置换涉及大额资金与法律节点，建议请正规中介/律师把关合同；政策以当地最新为准。*
