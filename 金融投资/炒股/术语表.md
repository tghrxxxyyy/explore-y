# 炒股 · 术语表

> 从基础到进阶，覆盖市场结构、估值、技术、交易与风险类术语。结合上下文理解，比死记更有效。

## 市场与交易类
| 术语 | 含义 |
| --- | --- |
| A股 | 在中国大陆注册、上市的股票（沪/深/北交所）。 |
| 一级市场 / 二级市场 | 公司募资发行的市场 / 投资者日常买卖交易的市场。 |
| IPO | 首次公开发行股票并上市。 |
| 主板 / 创业板(300) / 科创板(688) / 北交所(8xx) | 不同上市板块，涨跌幅与门槛各异（见入门篇表）。 |
| T+1 | 当天买入，下一交易日才能卖出。 |
| 集合竞价 | 开盘(9:15–9:25)/收盘(14:57–15:00)集中撮合。 |
| 涨停 / 跌停 | 当日涨跌幅达到上限/下限。 |
| 换手率 | 成交股数 ÷ 流通股本，衡量活跃度。 |
| 成交量 / 成交额 | 一定时间成交股数 / 金额。 |
| 融资融券 | 向券商借钱买股（融资）/借券卖出（融券），带杠杆。 |
| ST / *ST | 财务异常特别处理 / 退市风险警示（涨跌幅限 5%）。 |
| 退市 | 触发条件后摘牌，归零风险真实存在。 |

## 估值与财务类
| 术语 | 含义 |
| --- | --- |
| 市值 | 股价 × 总股本；总市值=公司规模，流通市值=可交易部分。 |
| 市盈率 PE | 股价 ÷ 每股收益，多少年回本；比行业/历史分位才有意义。 |
| 市净率 PB | 股价 ÷ 每股净资产，重资产/银行股常用。 |
| 市销率 PS | 市值 ÷ 营收，轻资产/未盈利成长股参考。 |
| PEG | PE ÷ 盈利增速，<1 相对合理（成长股）。 |
| EV/EBITDA | 企业价值 ÷ 息税折旧摊销前利润，周期股估值常用。 |
| 股息率 | 每股分红 ÷ 股价，衡量"收租"回报。 |
| EPS | 每股收益。 |
| ROE | 净资产收益率，盈利效率核心（长期>15% 优秀）。 |
| ROA | 总资产收益率。 |
| 毛利率 / 净利率 | 毛利/营收、净利/营收，反映盈利质量。 |
| 自由现金流 | 经营现金流减资本开支，持续为正更健康。 |
| DCF | 现金流折现估值法，最严谨但对假设敏感。 |
| 商誉 | 并购溢价，过高有减值暴雷风险。 |

## 技术类
| 术语 | 含义 |
| --- | --- |
| K线 | 开/收/最髙/最底，A股红涨绿跌。 |
| 均线 MA | 一段时间收盘价均值，判趋势；金叉/死叉。 |
| 多头/空头排列 | 短中长均线依次向上/向下，强势/弱势。 |
| MACD | 趋势与动能指标，金叉/死叉、顶底背离。 |
| RSI | 相对强弱，>70 超买、<30 超卖。 |
| 布林带 BOLL | 中轨±2σ，触及上/下轨提示超买/超卖，收窄预示变盘。 |
| OBV | 能量潮，用成交量验证趋势。 |
| ATR | 平均真实波幅，衡量波动，用于按波动设止损。 |
| 支撑 / 阻力 | 前期密集成交区或高低点，突破/跌破有信号意义。 |
| 量价背离 | 价涨量缩等，提示动能不足。 |
| 头肩顶/底、双顶/底 | 经典反转形态。 |

## 策略与风险类
| 术语 | 含义 |
| --- | --- |
| 仓位 | 投入资金占总资金比例。 |
| 建仓 / 加仓 / 减仓 / 清仓 | 首次买入/增持/减持/全卖。 |
| 止损 | 设亏损线，破位离场控制风险。 |
| 止盈 | 达目标或逻辑破坏时兑现。 |
| 套牢 | 买入后下跌、亏损未卖出。 |
| 割肉 | 亏损卖出止损。 |
| 做多 / 做空 | 看涨买入 / 借券卖出（A股做空受限）。 |
| 北向资金 | 外资经沪深港通净买入，情绪指标。 |
| 最大回撤 | 历史最大跌幅，衡量极端风险。 |
| 夏普比率 | 每单位风险换来的超额收益，越高越好。 |
| 安全边际 | 内在价值与市价之间的缓冲空间。 |
| 过拟合 | 策略参数过度贴合历史，未来失效。 |

## 更多股票术语

### 涨停板与跌停板

| 术语 | 含义 |
| --- | --- |
| 涨停板 | 当日涨幅达到上限（主板10%，创业板/科创板20%），停止上涨。 |
| 跌停板 | 当日跌幅达到下限（主板10%，创业板/科创板20%），停止下跌。 |
| 涨停封单 | 涨停时买一档的挂单量，反映买方力量。 |
| 跌停封单 | 跌停时卖一档的挂单量，反映卖方力量。 |
| 一字涨停 | 开盘即涨停，全天未打开。 |
| 一字跌停 | 开盘即跌停，全天未打开。 |

### 龙虎榜

| 术语 | 含义 |
| --- | --- |
| 龙虎榜 | 交易所公布的异常波动股票买卖数据。 |
| 上榜条件 | 涨跌幅偏离值累计达7%、换手率达20%、振幅达15%等。 |
| 机构席位 | 机构投资者（基金、券商自营等）的专用席位。 |
| 游资席位 | 活跃游资的常用席位，如"宁波桑田路"、"上海溧阳路"等。 |
| 净买入 | 买入金额减去卖出金额，正值表示资金流入。 |
| 净卖出 | 卖出金额减去买入金额，正值表示资金流出。 |

### 融资融券

| 术语 | 含义 |
| --- | --- |
| 融资 | 向券商借钱买入股票，看涨做多。 |
| 融券 | 向券商借入股票卖出，看跌做空。 |
| 融资余额 | 融资买入后未偿还的金额，反映市场看多情绪。 |
| 融券余额 | 融券卖出后未偿还的市值，反映市场看空情绪。 |
| 维持担保比例 | 资产/负债，低于130%可能被强制平仓。 |
| 强制平仓 | 维持担保比例不足时，券商强制卖出股票。 |

### 转融通

| 术语 | 含义 |
| --- | --- |
| 转融资 | 证券金融公司借钱给券商，券商再借给客户。 |
| 转融券 | 证券金融公司借股票给券商，券商再借给客户。 |
| 转融通余额 | 转融资+转融券的总余额。 |
| 意义 | 扩大融资融券规模，增加市场流动性。 |

### 大宗交易

| 术语 | 含义 |
| --- | --- |
| 大宗交易 | 单笔交易量达到规定标准的交易（A股为50万股或300万元）。 |
| 折价成交 | 成交价低于当日收盘价，可能表示卖方急售。 |
| 溢价成交 | 成交价高于当日收盘价，可能表示买方看好。 |
| 盘后交易 | 收盘后进行的大宗交易，不影响当日股价。 |

### 股权质押

| 术语 | 含义 |
| --- | --- |
| 股权质押 | 股东将股票抵押给券商或银行，获取资金。 |
| 质押率 | 质押股票市值/贷款金额，通常30%-50%。 |
| 平仓线 | 股价下跌至质押市值不足时，需追加担保或被平仓。 |
| 风险 | 股价下跌可能导致被动减持，影响股价。 |

### 回购

| 术语 | 含义 |
| --- | --- |
| 股票回购 | 公司用现金买入自家股票并注销，减少股本。 |
| 回购目的 | 提升股价、员工激励、市值管理。 |
| 回购预案 | 公司宣布回购计划，通常利好股价。 |
| 回购实施 | 公司实际执行回购，按期公告进展。 |

### 其他重要术语

| 术语 | 含义 |
| --- | --- |
| 换手率 | 成交股数/流通股本，衡量交易活跃度。 |
| 量比 | 当日成交量/过去5日平均成交量，反映成交变化。 |
| 委比 | (委买-委卖)/(委买+委卖)，反映买卖力量对比。 |
| 内盘/外盘 | 以买价成交/以卖价成交的股数，反映主动买卖。 |
| 主力/散户 | 大资金/小资金，通常通过单笔成交金额区分。 |
| 游资 | 短线活跃资金，追求快速获利。 |
| 北向资金 | 外资通过沪深港通流入A股的资金。 |
| 南向资金 | 内地资金通过港股通流入港股的资金。 |

## 市场情绪指标

| 术语 | 含义 |
| --- | --- |
| 两融余额 | 融资余额+融券余额，反映市场杠杆水平。 |
| 保证金比例 | 投资者缴纳的保证金/融资买入证券市值。 |
| 新增投资者 | 每周新增开户数，反映市场参与热度。 |
| 换手率 | 成交股数/流通股本，反映交易活跃度。 |
| 涨停家数 | 当日涨停的股票数量，反映市场赚钱效应。 |
| 跌停家数 | 当日跌停的股票数量，反映市场亏钱效应。 |
| 涨跌比 | 上涨家数/下跌家数，反映市场整体强弱。 |

## 资金流向指标

| 术语 | 含义 |
| --- | --- |
| 主力净流入 | 大单买入金额-大单卖出金额。 |
| 超大单净流入 | 超大单买入金额-超大单卖出金额。 |
| 融资净买入 | 融资买入金额-融资偿还金额。 |
| 北向资金净流入 | 沪股通+深股通买入金额-卖出金额。 |
| ETF资金流向 | ETF申购金额-赎回金额。 |

## 技术分析术语

| 术语 | 含义 |
| --- | --- |
| 金叉 | 短期均线上穿长期均线，买入信号。 |
| 死叉 | 短期均线下穿长期均线，卖出信号。 |
| 背离 | 价格走势与指标走势相反，预示反转。 |
| 顶背离 | 价格创新高但指标未创新高，预示见顶。 |
| 底背离 | 价格创新低但指标未创新低，预示见底。 |
| 超买 | 指标超过80，预示可能回调。 |
| 超卖 | 指标低于20，预示可能反弹。 |

## 财务分析术语

| 术语 | 含义 |
| --- | --- |
| 毛利率 | (营收-营业成本)/营收，反映盈利能力。 |
| 净利率 | 净利润/营收，反映最终盈利能力。 |
| 资产负债率 | 总负债/总资产，反映财务杠杆。 |
| 流动比率 | 流动资产/流动负债，反映短期偿债能力。 |
| 速动比率 | (流动资产-存货)/流动负债，反映快速偿债能力。 |
| 存货周转率 | 营业成本/平均存货，反映存货管理效率。 |
| 应收账款周转率 | 营收/平均应收账款，反映回款效率。 |

## 更多专业术语

### 市盈率 TTM

| 术语 | 含义 |
| --- | --- |
| 市盈率 TTM | 滚动市盈率，以最近 4 个季度的每股收益计算，比静态市盈率更反映当前估值。 |
| 静态市盈率 | 以上一年度每股收益计算，滞后性强。 |
| 动态市盈率 | 以预测的未来一年每股收益计算，含主观预测成分。 |
| 用途 | TTM 常用于股票实时估值，是投资者最常用的市盈率指标。 |

### 市净率 PB

| 术语 | 含义 |
| --- | --- |
| 市净率 PB | 股价 ÷ 每股净资产，反映市场对资产价值的溢价程度。 |
| 适用行业 | 重资产行业（银行、地产、钢铁），破净（PB < 1）可能被低估。 |
| 局限性 | 轻资产公司净资产少，PB 参考价值有限。 |
| 历史分位 | 结合历史 PB 分位判断高估或低估，比绝对值更有意义。 |

### 股息率

| 术语 | 含义 |
| --- | --- |
| 股息率 | 每股分红 ÷ 股价，衡量"收租"回报。 |
| 与市盈率关系 | 股息率 = 盈利收益率 × 分红比例。 |
| 用途 | 高股息策略（如红利基金）的核心筛选指标。 |
| 注意 | 高股息可能是股价下跌导致，需结合公司基本面判断。 |

### 换手率

| 术语 | 含义 |
| --- | --- |
| 换手率 | 成交股数 ÷ 流通股本，衡量交易活跃度。 |
| 低换手（<1%） | 交投冷清，关注度低。 |
| 正常换手（1%-5%） | 正常交易。 |
| 高换手（>10%） | 交投活跃，可能是热点或主力异动。 |
| 超高换手（>20%） | 异常活跃，警惕短线炒作。 |

### 量比

| 术语 | 含义 |
| --- | --- |
| 量比 | 当日成交量 ÷ 过去 5 日平均成交量，反映成交变化。 |
| 量比 > 2 | 成交放大，可能有资金介入。 |
| 量比 < 0.5 | 成交萎缩，关注度下降。 |
| 用途 | 结合价格走势判断资金动向。 |

### 委比

| 术语 | 含义 |
| --- | --- |
| 委比 | (委买手数 - 委卖手数) ÷ (委买手数 + 委卖手数) × 100% |
| 委比 > 0 | 买方力量强，短期可能上涨。 |
| 委比 < 0 | 卖方力量强，短期可能下跌。 |
| 局限性 | 可被主力挂单操纵，仅作参考。 |

### 内盘与外盘

| 术语 | 含义 |
| --- | --- |
| 内盘 | 以买一或更低价格成交的股数，反映主动卖出力量。 |
| 外盘 | 以卖一或更高价格成交的股数，反映主动买入力量。 |
| 外盘 > 内盘 | 买方主动买入多，短期可能上涨。 |
| 内盘 > 外盘 | 卖方主动卖出多，短期可能下跌。 |
| 注意 | 可被对敲操纵，需结合成交量综合判断。 |

> 来源：沪深交易所《交易规则》

## 量化交易术语

### Alpha 与 Beta

| 术语 | 含义 |
| --- | --- |
| Beta (β) | 投资组合相对市场的系统性风险敞口。β = 1 表示与市场同步，β > 1 波动更大，β < 1 波动更小。 |
| Alpha (α) | 投资组合相对基准的超额收益，代表基金经理的选股/择时能力。 |
| 两者关系 | 总收益 = Alpha + Beta × 市场收益。 |
| 用途 | 评估基金经理能力：高 Alpha 说明选股能力强，高 Beta 说明波动大。 |

### 夏普比率

| 术语 | 含义 |
| --- | --- |
| 夏普比率 | (组合收益率 - 无风险利率) ÷ 组合波动率 |
| 含义 | 每承担一单位风险所获得的超额收益，越高越好。 |
| 参考标准 | 夏普 > 1 为良好，> 2 为优秀，< 0 说明收益不及无风险利率。 |
| 局限性 | 假设收益正态分布，对极端风险（尾部风险）不敏感。 |

### 最大回撤

| 术语 | 含义 |
| --- | --- |
| 最大回撤 | 从历史最高点到最低点的最大跌幅，衡量极端风险。 |
| 用途 | 评估投资组合的最坏情况承受能力。 |
| 参考标准 | 一般主动基金最大回撤 > 30% 需警惕。 |
| 与夏普互补 | 夏普衡量收益/波动比，最大回撤衡量极端风险。 |

### 年化波动率

| 术语 | 含义 |
| --- | --- |
| 年化波动率 | 投资组合收益率的标准差年化值，衡量价格波动程度。 |
| 用途 | 评估投资组合的风险水平。 |
| 参考标准 | A 股宽基指数年化波动率约 20%-30%，债券基金约 3%-8%。 |
| 与仓位关系 | 波动率高时可降低仓位，低时可提高仓位。 |

### 其他量化术语

| 术语 | 含义 |
| --- | --- |
| 信息比率 | (组合收益 - 基准收益) ÷ 跟踪误差，衡量主动管理能力。 |
| 跟踪误差 | 组合收益与基准收益的差异程度，越小说明越贴近基准。 |
| 胜率 | 盈利交易次数 ÷ 总交易次数，衡量策略的稳定性。 |
| 盈亏比 | 平均盈利 ÷ 平均亏损，衡量风险收益比。 |
| 持仓集中度 | 最大持仓占总资产比例，衡量风险集中度。 |

> 来源：CFA Institute、量化投资教科书
