# 炒股 · 术语表

| 术语 | 含义 |
| --- | --- |
| A股 | 在中国大陆注册、上市的股票（沪/深）。 |
| 蓝筹股 | 规模大、业绩稳、分红好的龙头公司。 |
| 白马股 | 业绩优良、信息透明、增长稳定的公司。 |
| 成长股 | 高增速、高估值预期的公司。 |
| 市盈率 PE | 股价/每股收益，衡量估值贵贱。 |
| 市净率 PB | 股价/每股净资产，重资产行业常用。 |
| ROE | 净资产收益率，盈利效率核心指标。 |
| 成交量/额 | 一定时间的成交股数/金额，看活跃度。 |
| 均线 MA | 一段时间内收盘价平均，判趋势。 |
| 金叉/死叉 | 短均线破长均线上行/下行。 |
| 套牢 | 买入后下跌、亏损未卖出。 |
| 止损 | 设定亏损线，破位离场控制风险。 |
| 仓位 | 投入资金占总资金的比例。 |
| 做多/做空 | 看涨买入/借券卖出（A股做空受限）。 |
| 北向资金 | 外资经沪深港通净买入，情绪指标。 |
| 涨停/跌停 | 当日涨跌幅达到上限/下限。 |
