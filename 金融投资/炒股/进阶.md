# 炒股 · 进阶概念

> 目标：从「会买卖」到「有方法体系」。本文覆盖**宏观→行业→个股**三层研究框架、基本面估值、技术分析指标、仓位与风险管理、常见策略与交易心理，并给出可落地的量化工具清单。

---

## 一、研究框架：从宏观到个股（自上而下）

### 1. 宏观层（大环境）
- **经济指标**：GDP（增长）、CPI（通胀）、PMI（制造业荣枯，>50 扩张）、PPI、利率、社融。
- **货币政策**：降准降息 → 流动性宽松，利好估值；收紧则反之。
- **经济周期**：复苏 → 过热 → 滞胀 → 衰退，不同周期优势资产不同（参考"美林时钟"）。
- **市场情绪**：北向资金流向、融资余额、新基金发行量、VIX 恐慌指数等，判断市场"温度"。

### 2. 行业层（赛道）
- **行业生命周期**：初创 → 成长 → 成熟 → 衰退；成长期估值容忍度高、波动大。
- **竞争格局**：用**波特五力**（供应商议价、买方议价、新进入者威胁、替代品、行业内竞争）判断赛道好不好赚钱。
- **政策与供需**：产业政策支持（如新能源、半导体）、供需格局变化（涨价逻辑）。

### 3. 个股层（标的）
- **商业模式**：公司靠什么赚钱？是否可持续？
- **护城河**：品牌、网络效应、成本优势、转换成本、特许经营权、专利壁垒。
- **市场地位**：份额排名、客户粘性、核心业务营收占比。
- **治理风险**：管理层稳定与诚信、股权质押比例、关联交易、财务造假嫌疑。

## 二、基本面分析（买好公司、买得便宜）

### 1. 三大财报穿透式分析
围绕**盈利性 / 成长性 / 安全性**三维度，看"趋势 + 同行对比"：

| 维度 | 看什么 | 健康信号 |
| --- | --- | --- |
| 盈利性 | 毛利率、净利率、ROE | 稳定或提升，且高于行业均值 |
| 成长性 | 营收增速、扣非净利润增速 | 营收与利润同步增长 |
| 安全性 | 资产负债率、经营现金流 | 负债合理，经营现金流覆盖净利润 |

- **利润表**：营收、净利润、毛利率（产品竞争力）。
- **资产负债表**：资产、负债、应收账款质量（警惕应收飙升、存货积压）。
- **现金流量表**：经营现金流是否为正、能否覆盖净利润（利润"含金量"）。

### 2. 核心指标
- **ROE**：长期 >15% 通常优秀（巴菲特标准）。
- **PE / PB**：横向比同行、纵向比历史分位（如当前 PE 处近 5 年 30% 分位以下偏便宜）。
- **毛利率/净利率**：越高越有定价权。
- **自由现金流**：持续为正更健康。
- **资产负债率、商誉**：警惕高杠杆与高商誉暴雷。

### 3. 估值方法（判断贵贱）
- **相对估值**：
  - 价值股看 **PE / PB**（低于历史分位或行业均值 = 便宜）。
  - 成长股看 **PEG = PE / 盈利增速**，<1 相对合理。
  - 周期股看 **EV/EBITDA**；轻资产看 **PS（市销率）**。
- **绝对估值**：
  - **DCF 现金流折现**：预测未来自由现金流按折现率折算当下价值，最严谨但对假设敏感。
  - 经验法则：普通企业合理价打 5–7 折为买入参考，优秀企业可给溢价。

> 估值不是算命，而是建立"安全边际"——好公司也要好价格。

## 三、技术分析（看价格行为、找买卖点）

假设"价格反映一切已知信息"，用图表辅助**择时**（不是预言）。

### 1. 基础工具
- **K线**：开/收/最髙/最底，A股红涨绿跌；十字星、长上下影各有含义。
- **均线 MA**：MA20/MA60/MA200；**金叉**（短上穿长）偏多，**死叉**偏空；价格在 MA 上方且均线向上 = 多头排列。
- **MACD**：趋势与动能，金叉/死叉、顶/底背离。
- **成交量**：放量突破更可靠，缩量回调更健康；**量价背离**是警示。

### 2. 进阶指标
- **RSI**：相对强弱，>70 超买、<30 超卖（震荡市好用，趋势市易钝化）。
- **布林带（BOLL）**：中轨为均线，上下轨为 ±2 倍标准差；收窄 = 变盘前兆，触及上轨超买、下轨超卖。
- **OBV**：能量潮，用成交量验证价格趋势强度。
- **ATR**：平均真实波幅，衡量波动性，常用于**按波动设止损**（止损 = 入场价 − n×ATR）。
- **支撑/阻力**：前期密集成交区、均线位、前期高低点；突破/跌破有信号意义。
- **形态**：头肩顶/底、双顶/底、三角形整理等。

> 技术面是"概率"而非"确定"。务必结合仓位与止损；量能是确认信号的关键。

## 四、仓位与风险管理（保命优先）

- **永远不满仓**：留子弹应对波动与机会。
- **金字塔/倒金字塔**：下跌分批买（金字塔加仓），上涨分批卖（倒金字塔减仓）。
- **固定风险法（仓位公式）**：
  - 单笔可亏 = 总资金 × 风险%（如 1%–2%）
  - 每股风险 = 入场价 − 止损价
  - 可买股数 = 单笔可亏 ÷ 每股风险
  - 例：资金 50 万、风险 1% = 5000 元；买 25 元、止损 22.5 元（每股风险 2.5 元）→ 买 2000 股。
- **止损**：单笔亏损控制在总资金 1%–3%；破位即走，不摊平亏损。可用 ATR 或固定比例（8%–10%）。
- **止盈**：目标收益率 / 逻辑破坏 / 均线破位分批兑现；可用移动止损锁利。
- **分散**：单只 ≤ 总仓 10%–30%，单行业 ≤ 20%。
- **组合最大回撤**：设阈值（如 15%）触发复盘与降仓。

## 五、常见投资策略

| 策略 | 思路 | 适合 |
| --- | --- | --- |
| 价值投资 | 低估买好公司长期持有，重安全边际 | 有耐心、善读财报 |
| 成长投资 | 押注高增速赛道与公司 | 能承受高波动 |
| 股息/收租 | 高股息率蓝筹，稳定现金流 | 稳健型、退休配置 |
| 趋势跟踪 | 顺势突破买入，右侧交易 | 纪律强、机械化 |
| 指数定投 | 买宽基 ETF 长期摊薄成本 | 没时间研究个股 |
| 网格交易 | 震荡市高抛低吸（见实战案例） | 有震荡区间的品种 |
| 事件/短线 | 抓题材与连板（高风险） | 短线高手，新手慎入 |

## 六、量化与工具入门（用代码验证想法）

把"盘感"变成可复现的脚本，是避免被情绪与噪音忽悠的最佳方式。

**数据层（A股友好）**
- **[akfamily/akshare](https://github.com/akfamily/akshare)**：纯 Python、无依赖，覆盖 A股/港股/期货/基金实时与历史数据。
- **[waditu/tushare](https://github.com/waditu/tushare)（TuShare）**：中文用户首选，A股/基金/宏观数据，Pro 版需积分。
- **[OpenBB-finance/OpenBB](https://github.com/OpenBB-finance/OpenBB)**：开源版"彭博终端"，统一股票/宏观接口，还能跑 MCP 让 AI Agent 查数据。

**回测/框架层**
- **[backtrader/backtrader](https://github.com/backtrader/backtrader)**：事件驱动回测框架，约 50 行跑一个双均线策略，配 TA-Lib 算指标。
- **[microsoft/qlib](https://github.com/microsoft/qlib)**：微软开源 AI 量化平台，内置因子库与 ML 模板（LightGBM/Transformer），偏研究。
- **[vnpy/vnpy](https://github.com/vnpy/vnpy)（VeighNa）**：国产最成熟框架，支持 CTP 期货等；实盘需自担合规与风控。
- **[rqalpha/rqalpha](https://github.com/rqalpha/rqalpha)（RQAlpha）**：米筐开源版，A股回测 API 优雅，适合教学。
- **[bbfamily/abu](https://github.com/bbfamily/abu)（Abu）**：对 A股/美股友好的量化框架，内置风控模块。
- **[wilsonfreitas/awesome-quant](https://github.com/wilsonfreitas/awesome-quant)**：量化资源大全（框架/数据/指标/书籍），入门导航必收藏。

**绩效与组合**
- **quantstats / empyrical**：夏普、索提诺、最大回撤等绩效报告。
- **PyPortfolioOpt**：马科维茨均值-方差优化、Black-Litterman。

> ⚠️ 合规红线：A股未经许可不得程序化自动向券商报单。个人用开源框架多只做"信号提醒 + 人工按键"；碰实盘接口前先确认券商合规，别赌。先回测再实盘，警惕**过拟合**（参数扫太多历史好看、未来失效）。

## 七、交易心理（最难的一课）

- **损失厌恶**：亏钱的痛苦 ≈ 赚钱快乐的两倍，导致死扛亏损、过早止盈。→ 严守止损。
- **过度自信**：连赢后加码，把牛市红利当自己实力。→ 保持仓位纪律。
- **FOMO（错失恐惧）**：怕踏空追高。→ 等回调，不追暴涨。
- **锚定**：死记买入价。→ 关注企业价值与当下逻辑，而非成本。
- **复盘**：每笔交易记录"赚/亏的原因"，建立自己的错误清单。

> 长期稳定盈利 = **胜率 × 赔率 × 频率** 的系统 + 执行力，而非运气或内幕。
