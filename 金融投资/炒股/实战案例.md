# 炒股 · 实战案例

> 以下为**方法演示**，非真实买卖建议。所有数字均为示意，请用模拟盘先跑一遍。

---

## 案例一：用「PE + ROE + 现金流」初筛好公司（价值/质量法）
1. **设条件**：连续 3 年 ROE ≥ 15%，当前 PE 处近 5 年历史 30% 分位以下，经营现金流为正。
2. **筛选**：在行情软件/财经网站或 `akshare` 拉数据，得到候选池（如部分消费、医药龙头）。
3. **读年报**：看营收/利润是否真实增长、现金流是否覆盖净利润、负债率是否合理、有无高商誉/质押。
4. **分散买入** 3–5 只，单只 ≤ 25% 仓位；设止损（如 −10% 或逻辑破坏）。
5. **持有与复盘**：每年复盘一次基本面，逻辑变坏（ROE 连续下滑、造假嫌疑）即减仓。

---

## 案例二：宽基指数定投（懒人法）
1. **选标的**：沪深300 ETF（如 510300）或中证500 ETF。
2. **固定投入**：每月某日投固定金额（如 1000 元），无视短期涨跌。
3. **微笑曲线**：下跌时自动买更多份额，上涨时份额变少——天然摊低成本。
4. **止盈**：整体收益 ≥ 30% 或 PE 进入历史 70% 分位以上，分批卖出。
5. **坚持 3 年以上**，穿越一轮牛熊。

---

## 案例三：用「固定风险法」确定仓位（风控法）
- 总资金 50 万，单笔风险 1% = 5000 元。
- 计划买入价 25 元，止损价 22.5 元（每股风险 2.5 元）。
- 可买股数 = 5000 ÷ 2.5 = **2000 股**（约 5 万元，占总资金 10%）。
- 若触发止损，最大亏损恰好 5000 元（1%），不影响全局。

> 纪律：先定止损再下单，绝不在亏损后"补仓摊平"。

---

## 案例四：网格交易（震荡市高抛低吸）
- **适用**：波动大但无明确趋势的标的（如某 ETF、周期性个股）。
- **做法**：以当前价为中心，每下跌 5% 挂单买一份，每上涨 5% 挂单卖一份，资金分成 10–20 等份循环。
- **例**：基准 1.000，跌到 0.95 买、0.90 再买；反弹到 1.05 卖、1.10 再卖，赚取波段差价。
- **风险**：单边下跌会"满仓被套"，需设总仓位上限与底线止损；不适合长期向上趋势中频繁卖出。

## 案例五：技术择时辅助（趋势 + 量能）
- 条件：价格 > MA60 且 MA20 向上；RSI 在 50 附近（非超买）；突破前高**放量**确认。
- 入场：放量站上前高；止损：跌破 MA20 或入场价 −2×ATR。
- 退出：跌破均线/放量长上影/逻辑破坏。
- 本质是用技术面优化**买点**，仍须以基本面确认"买什么"。

## 案例七：A股投资案例分析

### 价值投资案例

#### 案例：消费龙头股投资

- **背景**：投资者看好消费行业，想长期持有消费龙头。
- **选股**：选择ROE>15%、PE<30倍、现金流稳定的消费龙头。
- **买入**：在市场恐慌时分批买入，平均成本较低。
- **持有**：长期持有3年，期间分红再投资。
- **收益**：3年累计收益约80%，年化约22%。
- **经验**：价值投资需要耐心，好公司好价格是关键。

#### 价值投资常见错误

- **价值陷阱**：买入看似便宜但基本面恶化的公司。
- **缺乏耐心**：短期不涨就卖出，错失长期收益。
- **过度集中**：重仓单一公司，风险集中。
- **忽视行业**：只看个股，忽视行业趋势。

#### 价值投资经验总结

- **选股标准**：ROE>15%、PE合理、现金流稳定、行业龙头。
- **买入时机**：市场恐慌时分批买入。
- **持有策略**：长期持有，分红再投资。
- **卖出条件**：基本面恶化、估值过高、发现更好机会。

### 趋势交易案例

#### 案例：趋势跟踪交易

- **背景**：投资者想通过趋势交易获取收益。
- **策略**：价格>MA60且MA20向上时买入，跌破MA20时卖出。
- **执行**：严格执行策略，不主观判断。
- **结果**：抓住了一波上涨趋势，收益约30%。
- **经验**：趋势交易需要纪律，严格执行是关键。

#### 趋势交易常见错误

- **主观判断**：不严格执行策略，主观判断市场。
- **频繁交易**：频繁买卖，增加成本和错误率。
- **追涨杀跌**：趋势反转时没有及时止损。
- **忽视风险**：只看收益，忽视风险控制。

#### 趋势交易经验总结

- **策略清晰**：制定清晰的交易策略。
- **严格执行**：按策略执行，不主观判断。
- **风险控制**：设置止损点，控制风险。
- **持续优化**：根据市场变化优化策略。

### 打新股案例

#### 案例：新股申购

- **背景**：投资者想通过打新股获取收益。
- **策略**：持有市值，参与新股申购。
- **执行**：坚持申购，不放弃任何机会。
- **结果**：中签率低，但中签后收益可观。
- **经验**：打新股是低风险收益，贵在坚持。

#### 打新股常见错误

- **期望过高**：期望每次都能中签，忽视低概率。
- **频繁操作**：为增加中签率频繁买卖股票。
- **忽视风险**：打新股有破发风险，不是稳赚。
- **不及时卖出**：中签后不及时卖出，利润回吐。

#### 打新股经验总结

- **坚持申购**：每次申购都参与，不放弃机会。
- **持有市值**：保持一定市值，增加中签机会。
- **及时卖出**：中签后及时卖出，锁定利润。
- **理性看待**：打新股是低风险收益，不是暴富机会。

## 案例八：常见错误分析

### 错误一：追涨杀跌

- **表现**：市场高点追加买入，市场低点恐慌卖出。
- **后果**：高买低卖，亏损严重。
- **纠正**：制定交易计划，按计划执行。

### 错误二：频繁交易

- **表现**：频繁买卖股票，追逐热点。
- **后果**：增加交易成本，错失长期收益。
- **纠正**：减少交易频率，坚持长期投资。

### 错误三：过度集中

- **表现**：重仓单一股票，忽视风险。
- **后果**：风险集中，下行时损失惨重。
- **纠正**：分散投资，配置多只股票。

### 错误四：不设止损

- **表现**：买入后下跌不止损，死扛。
- **后果**：亏损扩大，可能被深套。
- **纠正**：设定止损点，严格执行。

### 错误五：盲目跟风

- **表现**：听到"内幕消息"就买，不研究。
- **后果**：买入不熟悉的股票，亏损概率大。
- **纠正**：独立研究，投资自己懂的股票。

### 错误六：情绪化交易

- **表现**：因市场涨跌而恐慌或贪婪。
- **后果**：做出非理性决策。
- **纠正**：保持冷静，按计划执行。

## 案例九：经验教训总结

### 投资前

1. **学习知识**：了解股票市场基本知识。
2. **制定计划**：明确投资目标、策略、风险控制。
3. **模拟练习**：先用模拟盘跑通策略。
4. **准备资金**：用闲钱投资，不借钱炒股。

### 投资中

1. **严格执行**：按策略执行，不主观判断。
2. **风险控制**：设置止损点，控制风险。
3. **分散投资**：不把鸡蛋放一个篮子里。
4. **持续学习**：了解市场，提升投资能力。

### 投资后

1. **记录复盘**：记录交易决策，定期复盘。
2. **总结经验**：总结成功和失败的经验。
3. **调整策略**：根据市场变化调整策略。
4. **保持心态**：保持良好心态，不因涨跌影响生活。

### 长期投资心态

- **接受亏损**：投资有亏损是正常的，不要恐慌。
- **忽略噪音**：不要被短期消息影响长期判断。
- **保持耐心**：投资是长跑，不是短跑。
- **享受过程**：投资不只是为了赚钱，也是学习和成长的过程。

## 案例十四：投资纪律建立

### 投资纪律清单

1. **仓位纪律**：单只≤25%总仓位，单笔风险≤1%总资产。
2. **止损纪律**：买入前设止损点，触发即执行，不犹豫。
3. **止盈纪律**：达到目标收益率分批止盈，不贪心。
4. **频率纪律**：每月交易不超过3次，避免频繁操作。
5. **复盘纪律**：每季度复盘一次投资决策，总结经验教训。

### 纪律执行方法

| 方法 | 说明 |
|------|------|
| 写下交易计划 | 买入前写下买入理由、止损点、止盈点 |
| 设置提醒 | 在券商APP设置止损提醒 |
| 记录交易日志 | 记录每笔交易的决策过程和结果 |
| 定期复盘 | 每月回顾交易记录，分析错误原因 |
| 找人监督 | 与朋友互相监督，执行纪律 |

### 长期投资心态

- **接受亏损**：投资有亏损是正常的，不要恐慌。
- **忽略噪音**：不要被短期消息影响长期判断。
- **保持耐心**：投资是长跑，不是短跑。
