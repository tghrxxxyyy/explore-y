# AI 换脸与新型骗局

> AI 让"眼见为实"不再成立：视频里的亲友可能是假的，官网上的 APP 可能是山寨的。学会几条新规则，胜过十次"侥幸"。

## 一、AI 换脸 / 换声诈骗

- **剧本**：骗子用 AI 换脸/克隆声音，冒充亲友、领导、子女打视频/电话，以"急用钱、出事、被抓"为由让你转账；或冒充"投资导师"视频直播荐股。
- **特征**：视频画面轻微卡顿、五官边缘模糊、说话口型对不上；催促转账、拒绝多聊、要"保密"。
- **验证**：
  - 视频通话要求对方**转头、挥手、眨眼睛**——AI 换脸在侧脸和动态下明显失真。
  - 换一个没被"关联"的号码打回去核实；或线下见一面。
  - 约定家庭"暗号"（事前约定只有家人知道的词句），陌生人假扮立刻穿帮。
- **原则**：只要涉及转账，视频里"认识"不作数，必须独立渠道核实。

## 二、高仿投资 APP（山寨券商/银行）

- **剧本**：给你"内部通道/机构席位/低佣金"，引导下载**和真券商同名的 APP** 或"升级版"，资金进的是骗子控制的假盘，行情可随意操纵。
- **识别**：
  - 只在**官方应用商店**下载，核对开发者名称与官网一致；扫码安装的 .apk 一律不装。
  - 登录前到券商/银行官网查客服电话，打过去核实"这个 APP 是不是你们的"。
  - 入金账户必须与 APP 所属机构一致的**对公托管账户**；私人账户/第三方个人收款 = 诈骗。
- **教训**：假盘里"赚多少"都是数字，提现时才会真相大白。

## 三、数字人民币骗局

- **剧本**：谎称"数字人民币内测名额/数字人民币理财高息"，诱导下载"数字人民币"假冒 APP 或共享屏幕，转走你的真钱。
- **识别**：
  - 数字人民币由央行运营，**官方 APP 只有"数字人民币"一个**（应用商店可查），从不打电话邀请"内测"。
  - 数字人民币**不计息、无理财功能**——任何"数币理财、数币挖矿"都是骗局。
  - 开通钱包不索要验证码、不要求共享屏幕。
- **红线**：凡是要你"共享屏幕、录屏、报验证码"的客服，立即挂断。

## 四、"内部额度""绿色通道"类

- **剧本**：贷款/理财/大额存单/额度审批，"内部有关系、绿色通道、加急提额"，先交"手续费、保证金、验资款"。
- **识别**：正规金融机构**先审批后放款，事前零收费**；一切"先交钱才能办事"的都是诈骗。
- **典型**：征信修复、贷款提额、社保/公积金代缴、考证包过——交钱即失联。

## 五、快递理赔诈骗

- **剧本**：包裹"丢失/破损"，客服主动理赔，让你下载会议 APP 开启屏幕共享，或去"理赔中心"刷流水。
- **识别**：理赔金额远超实际价值（三倍赔付）就是诱饵；退款只原路返回，绝不让你"先转钱"。
- **做法**：收到理赔通知，打开购物 APP 看物流与官方客服，别信短信里的链接。

## 六、AI 荐股群

- **剧本**：AI 生成"精准预测""每日涨停"截图，群内气氛火热，AI 客服"一对一"带你操作，最终导向虚拟盘或带单收费。
- **识别**：任何"AI 能预测涨跌"都是谎言——AI 不能预测市场；"收益截图"一键生成，群里的托是真人或 AI。
- **做法**：投资只走持牌券商/公募基金官方渠道，详见 [荐股杀猪盘](荐股杀猪盘.md)。

## 七、通用防线

1. **视频可造假**：涉及转账，用"转头/挥手/暗号/另打一个电话"多重验证。
2. **收益截图可疑**：截图可 P、可生成，只看官方对账/持仓。
3. **只认官方**：APP 走应用商店、客服打官网电话、入金核对对公账户。
4. **大额二次确认**：单笔大额转账前，线下/电话/家人多方确认，至少冷却 24 小时。
5. **遇事挂断再查**：对方自称任何官方，都挂断后主动回拨官方号码。

## 八、被骗补救流程

1. 立即停手：不再转账、关闭共享屏幕、卸载不明 APP。
2. 电话 96110/110 报警，报骗子账号与金额，争取止付冻结。
3. 联系银行挂失卡片；涉及支付账户的同步冻结。
4. 收集证据：转账记录、聊天记录、APP 名称、对方账号，整理成时间线交警方。
5. 事后防二次诈骗：任何"付费帮你追回"的都是骗子，只信警方与银行。

## 九、AI换脸原理与技术

### 技术基础

- **深度学习**：通过大量人脸数据训练模型，学习人脸特征。
- **生成对抗网络（GAN）**：两个神经网络对抗训练，生成逼真假脸。
- **人脸关键点检测**：识别眼睛、鼻子、嘴巴等关键位置，实现精准换脸。
- **实时渲染**：在视频通话中实时替换人脸，技术已相当成熟。

### 技术发展

- **早期**：需要大量照片训练，效果一般。
- **现在**：只需一张照片即可换脸，效果逼真。
- **未来**：技术会越来越成熟，识别难度会越来越大。

### 应用场景

- **影视制作**：演员换脸、特效制作。
- **娱乐应用**：换脸APP、搞笑视频。
- **诈骗犯罪**：冒充亲友、领导进行诈骗。

## 十、常见AI骗局详解

### 假视频通话诈骗

- **剧本**：骗子用AI换脸冒充亲友、领导打视频电话，以"急用钱、出事"为由让你转账。
- **特征**：视频画面轻微卡顿、五官边缘模糊、说话口型对不上。
- **识别**：要求对方转头、挥手、眨眼睛——AI换脸在动态下容易失真。
- **案例**：某公司财务被骗"老板视频要求转账"，损失50万。

### 假语音诈骗

- **剧本**：骗子用AI克隆声音，打电话冒充亲友、领导，以"急事"为由让你转账。
- **特征**：声音逼真但可能有轻微失真，语气可能不自然。
- **识别**：用没被"关联"的号码打回去核实；或约定家庭"暗号"。
- **案例**：某老人被骗"儿子被抓"，转账20万到"赎金账户"。

### 假新闻/假视频诈骗

- **剧本**：AI生成虚假新闻视频，冒充权威媒体报道，诱导你投资或转账。
- **特征**：视频画面逼真，但细节可能有问题（如字幕错误、背景不一致）。
- **识别**：查看新闻来源，到官方网站核实；不轻信社交软件传播的新闻。
- **案例**：某投资者被骗"某公司暴雷"，恐慌抛售股票。

### 假直播荐股诈骗

- **剧本**：AI生成"投资导师"直播视频，推荐股票或投资平台。
- **特征**：导师口型可能对不上，背景可能模糊，推荐的平台是假的。
- **识别**：投资只走持牌平台，不认识的人推荐的一律不信。
- **案例**：某股民被骗"导师直播荐股"，投入假平台损失30万。

### 假身份诈骗

- **剧本**：骗子用AI生成虚假身份照片，在社交软件上冒充美女/帅哥，诱导投资或转账。
- **特征**：照片可能过于完美，聊天中可能回避视频通话。
- **识别**：视频通话要求对方转头、挥手；不轻信网上认识的人。
- **案例**：某男性被骗"网恋对象推荐投资"，损失20万。

## 十一、AI骗局识别方法

### 视频通话识别

| 异常表现 | 可能问题 | 验证方法 |
|---------|---------|---------|
| 画面轻微卡顿 | AI渲染延迟 | 要求快速转头 |
| 五官边缘模糊 | 换脸痕迹 | 注意观察细节 |
| 口型对不上 | 音频不同步 | 要求大声说话 |
| 背景模糊或变形 | AI生成背景 | 要求展示周围环境 |
| 表情不自然 | AI学习不足 | 要求做复杂表情 |

### 语音识别

- **声音失真**：AI克隆的声音可能有轻微失真。
- **语气不自然**：AI可能无法完全模仿说话人的语气和情绪。
- **回避核实**：骗子可能拒绝电话或视频核实。

### 文本识别

- **语法错误**：AI生成的文本可能有语法错误。
- **用词不当**：AI可能使用不恰当的词汇。
- **逻辑不通**：AI生成的文本可能逻辑不通顺。

### 行为识别

- **急于转账**：骗子通常制造紧迫感，催促转账。
- **拒绝核实**：骗子可能拒绝电话、视频或当面核实。
- **要求保密**：骗子可能要求"保密"，不让告诉别人。

## 十二、防范建议

### 个人防范

1. **视频可造假**：涉及转账，用"转头/挥手/暗号/另打一个电话"多重验证。
2. **收益截图可疑**：截图可P、可生成，只看官方对账/持仓。
3. **只认官方**：APP走应用商店、客服打官网电话、入金核对对公账户。
4. **大额二次确认**：单笔大额转账前，线下/电话/家人多方确认，至少冷却24小时。
5. **遇事挂断再查**：对方自称任何官方，都挂断后主动回拨官方号码。

### 家庭防范

1. **约定暗号**：与家人约定只有家人知道的暗号，陌生人假扮立刻穿帮。
2. **相互核实**：大额转账前通过其他渠道核实。
3. **提醒老人**：老年人更容易被骗，多提醒。
4. **保管信息**：不随意透露个人信息给陌生人。

### 技术防范

1. **不随意视频通话**：不与陌生人视频通话。
2. **不随意授权**：不授权APP访问摄像头和麦克风。
3. **保护照片**：不随意在社交软件上发布清晰正面照。
4. **更新软件**：及时更新操作系统和APP，修复安全漏洞。

### 应对策略

1. **冷静核实**：涉及转账，先冷静，通过其他渠道核实。
2. **不碍于情面**：即使对方是"领导""亲友"，也要核实。
3. **及时报警**：发现被骗，立即报警。
4. **传播知识**：向身边人普及AI骗局知识。

## 十三、实操案例分析

### 案例一：冒充老板视频诈骗

- **背景**：某公司财务接到"老板"视频电话，要求转账50万。
- **过程**：视频中"老板"长相、声音都很像，但说话有些不自然。
- **识别**：财务要求"老板"做个复杂手势，发现画面卡顿。
- **结果**：财务挂断电话，打老板手机核实，发现是骗局。
- **教训**：涉及转账，必须多重核实。

### 案例二：冒充子女语音诈骗

- **背景**：某老人接到"儿子"电话，说被抓了需要20万赎金。
- **过程**：声音很像，但语气有些不自然，老人着急没注意。
- **识别**：老人没核实就转账，事后发现被骗。
- **结果**：损失20万，追回困难。
- **教训**：老人更需要家人提醒，涉及转账要核实。

### 案例三：假投资导师直播

- **背景**：某投资者在社交软件上看到"投资导师"直播，推荐股票。
- **过程**：导师口型有些对不上，但推荐的股票确实涨了。
- **识别**：投资者没注意细节，跟着投资假平台。
- **结果**：投入30万，发现无法提现。
- **教训**：投资只走持牌平台，不认识的人推荐的一律不信。

| 注意异常 | 声音有轻微失真、语气不自然、回避视频通话 |

### 案例警示

| 操作 | 观察面部边缘是否清晰自然 |
| 局限 | 技术进步后边缘处理更好 |

### 综合识别

| 方法 | 说明 |

| 要求转头 | 快速转头时AI渲染延迟明显 |

| 配合调查 | 积极配合警方调查，提供详细信息 |
| 追回难度 | 资金已转出或洗钱后追回困难，预防为主 |

### 二次诈骗防范

| 警示 | 说明 |
|------|------|
| 付费追回 | 任何"付费帮你追回"的都是骗子 |
| 黑客追回 | 声称"黑客可追回"的都是骗子 |
| 内部关系 | 声称"有内部关系可追回"的都是骗子 |
| 正规渠道 | 只信警方与银行，不轻信任何"追回机构" |

## 十九、AI语音克隆骗局详解

### 技术原理与实现

| 要素 | 说明 |
|------|------|
| 技术基础 | 通过少量语音样本（几秒到几分钟）克隆人声 |
| 逼真程度 | 可模仿音色、语调、说话习惯，逼真度高 |
| 获取渠道 | 社交媒体、短视频、语音消息等公开语音 |
| 应用场景 | 冒充亲友、领导、客服打电话诈骗 |

### 识别方法详解

| 方法 | 说明 |
|------|------|
| 回拨核实 | 用没被"关联"的号码打回去核实 |
| 约定暗号 | 与家人约定只有家人知道的暗号 |
| 多问细节 | 问一些只有本人知道的细节问题 |
| 注意异常 | 声音有轻微失真、语气不自然、回避视频通话 |

### 案例警示

- **案例**：某老人接到"儿子"电话，声音很像，说被抓了需要20万赎金
- **过程**：老人着急没注意细节，转账到"赎金账户"
- **结果**：损失20万，追回困难
- **教训**：涉及转账，必须多重核实，不碍于情面

## 十五、AI骗局防范方法

### 15.1 技术防范措施

| 措施 | 说明 | 重要性 |
|------|------|--------|
| 活体检测 | 视频通话时要求对方做特定动作 | 高 |
| 声音验证 | 视频通话前先电话确认 | 高 |
| 信息核实 | 通过官方渠道核实信息 | 极高 |
| 隐私保护 | 限制个人生物信息收集 | 高 |

- **活体检测**：视频通话时要求对方做眨眼、摇头、张嘴等特定动作，AI换脸技术难以实时生成自然的人脸动作，可有效识别AI换脸。
- **声音验证**：接到"亲人求救"、"领导指示"电话时，先挂断电话，通过原有联系方式回拨确认，避免被AI克隆声音误导。
- **信息核实**：遇到"名人代言"、"新闻报道"等信息时，通过官方渠道（官网、官微、官方APP）核实，不轻信社交平台传播的信息。

### 15.2 行为防范策略

| 策略 | 说明 | 适用场景 |
|------|------|---------|
| 不轻信 | 不轻信陌生人的身份与说辞 | 所有场景 |
| 不转账 | 未确认身份前不转账 | 涉及转账场景 |
| 多核实 | 通过多渠道核实信息 | 涉及资金场景 |
| 及时报警 | 发现被骗立即报警 | 所有诈骗场景 |

- **不轻信**：对陌生人的身份、说辞保持警惕，即使对方能提供"证据"（照片、视频、录音），也可能是AI伪造的。
- **不转账**：在未通过其他渠道确认对方身份前，不进行任何转账操作，即使对方声称"紧急情况"。
- **多核实**：涉及资金时，通过电话、视频、当面等多种方式核实对方身份，确认无误后再进行操作。
- **及时报警**：发现被骗后立即报警（拨打96110），保存好聊天记录、转账记录等证据，配合警方调查。

### 15.3 社会防范机制

| 机制 | 说明 | 参与主体 |
|------|------|---------|
| 公众教育 | 普及AI诈骗防范知识 | 政府、媒体、社区 |
| 技术防御 | 开发AI检测工具 | 科技公司、研究机构 |
| 法律打击 | 严厉打击AI诈骗 | 公检法机关 |
| 行业自律 | 平台加强内容审核 | 互联网平台 |

- **公众教育**：政府、媒体、社区应加强AI诈骗防范知识普及，提高公众识别与防范AI诈骗的能力。
- **技术防御**：科技公司与研究机构应开发AI检测工具，帮助用户识别AI换脸、AI克隆声音等技术伪造的内容。
- **法律打击**：公检法机关应严厉打击AI诈骗犯罪，提高犯罪成本，形成震慑效应。
- **行业自律**：互联网平台应加强内容审核，及时删除AI诈骗相关内容，封禁诈骗账号。
