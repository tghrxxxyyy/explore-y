# 荐股杀猪盘

> 股民是杀猪盘最爱的人群——因为"想赚钱"的心理最容易被利用。本文拆穿从加群到亏光的全流程。

## 一、典型剧本

1. **引流**：短视频/股吧/微信"免费领牛股""老师带单"引你加群/关注公众号。
2. **养信**：群里"老师"每天晒战绩、托儿晒盈利，免费课建立权威感。
3. **诱导开户**：以"内部通道""新平台""机构席位"为由，让你去**非正规平台**开户入金（关键一步：钱进了骗子控制的虚假盘）。
4. **收割**：先给点甜头（虚增账面盈利），诱你加仓，然后"老师"反向喊单或平台拔网线，本金归零。
5. **消失**：提现失败、群解散、客服失联。

## 二、关键识别

- **正规证券交易只能通过持牌券商**（证监会公布的证券公司），资金进银行第三方存管。**任何让钱进"老师指定账户/不明 APP/虚拟盘"的都是诈骗。**
- "内幕消息""机构通道""稳赚不赔"——证券市场没有这些，有也是违法且不会外泄给你。
- 直播间/微信群里一片叫好，几乎必有托。
- 平台无法在官方应用商店搜到、需扫码下载.apk——高危。

## 三、为什么有人信

- 真亏过、想回本，急于找"高手"带。
- 群内从众氛围 + 权威包装（头衔/战绩图可伪造）。
- 先小赚确认，放松警惕后大入金。

## 四、防御清单

1. 只在**持牌券商**交易，资金走银行存管；不向任何个人/不明平台转账。
2. 不轻信"免费牛股""老师带单"，真有本事早自己赚发了。
3. 群里赚钱截图 = 一键生成，不当真。
4. 下载 APP 只走官方应用商店；陌生.apk 不装。
5. 已入金无法提现——立即停投、保留聊天/转账证据、报警 96110。

## 五、合法替代

- 想学投资：看 ../炒股 ../基金 的系统方法，自己建立能力，而非找"带单"。
- 想跟投：选正规公募基金（基金业协会可查备案），走银行/券商/官方平台。

## 六、杀猪盘完整流程拆解（五步走）

### 1. 寻猪（社交平台引流）

| 渠道 | 手法 | 目标画像 |
| --- | --- | --- |
| **抖音/快手** | "老师带单赚了XX万"短视频，评论区引流 | 30–50岁有一定积蓄 |
| **微信群** | 朋友拉进"股票交流群"，实为话术群 | 相信熟人推荐 |
| **陌陌/探探** | 伪装成功人士，聊感情后聊投资 | 情感空虚、信任异性 |
| **股吧/雪球** | 发"内幕消息"帖子，私信引流 | 亏钱想回本的股民 |
| **Telegram/QQ** | "量化带单群""VIP群" | 对技术有兴趣的年轻人 |

### 2. 养猪（建立信任）

- **第一阶段（1–2周）**：嘘寒问暖、分享生活、建立人设（金融精英/成功企业家/温柔姐姐）。
- **第二阶段（2–4周）**：偶尔"不小心"提到自己在做投资，展示盈利截图（PS/模拟盘）。
- **第三阶段**："我有个朋友/老师/内部渠道在带单，你要不要一起？"——引到假平台。

### 3. 杀猪（假平台收割）

- **假平台特征**：
  - 域名与正规券商相似但不同（如"国泰海通"→"国泰海通国际"）。
  - 需要扫描二维码下载.apk安装包，不在官方应用商店上架。
  - 入金到"对公账户"或个人银行卡，不是银证转账。
- **操作手法**：
  - 先让你小赚几次（虚增盈利），建立信心。
  - 诱导加大投入（"这次机会很大，我带你重仓"）。
  - 反向操作或直接拔网线，亏损全部归你。

### 4. 喂猪（持续榨取）

- "亏了没关系，再入金我帮你赚回来"——二次收割。
- "需要升级VIP/缴纳保证金/解锁出金权限"——连环骗。
- 假装自己也亏了，博取同情继续骗。

### 5. 杀猪完成（消失）

- 平台关闭、APP无法登录。
- 群解散、客服失联、"老师"拉黑你。
- 资金通过多层账户洗出境外，追回极其困难。

## 七、伪私募骗局

### 1. 典型特征

| 特征 | 说明 |
| --- | --- |
| **保本承诺** | "年化12%–18%，保本保收益"——正规私募不允许承诺收益 |
| **高收益诱惑** | 远超市场合理水平的收益率 |
| **虚假备案** | 在基金业协会查不到备案编号，或用其他产品信息冒充 |
| **资金池运作** | 新投资者的钱付老投资者利息（庞氏特征） |
| **个人账户收款** | 资金转入实控人个人账户而非托管银行 |

### 2. 正规私募 vs 伪私募

| 维度 | 正规私募 | 伪私募 |
| --- | --- | --- |
| **备案** | 基金业协会可查 | 查不到或信息不符 |
| **投资者门槛** | 100万起+合格投资者认证 | 1万、10万均可参与 |
| **收益承诺** | 不承诺 | 保本保收益 |
| **资金托管** | 银行托管 | 个人账户/不明对公 |
| **信息披露** | 定期报告 | 无或虚假 |

### 3. 识别方法

- **查备案**：登录中国证券投资基金业协会（amac.org.cn），输入产品名称或编码查询。
- **查管理人**：管理人是否有基金业协会登记的私募基金管理人资格。
- **查托管**：合同是否明确托管银行名称，资金是否进入托管账户。
- **查业绩**：要求提供经审计的财务报告，而非自制Excel表格。

## 八、电信诈骗（投资理财类）

### 1. 刷单诈骗（从购物到投资）

**流程**：招聘兼职刷单 → 第1–2单返小利 → 第3单开始"做任务"（下载虚假APP/充值） → 金额越来越大 → 无法提现。

- **变种**：刷单+赌博+投资三合一，以"做任务赚佣金"为名，实质引流到虚假投资平台。
- **识别**：任何要你先垫钱再返利的都是刷单诈骗，无一例外。

### 2. 冒充公检法

**流程**：来电自称XX公安局/检察院 → 说你涉嫌洗钱/非法投资 → 要求配合"资金清查" → 转入"安全账户"。

- **识别**：公检法不会电话办案，不会要求转账到"安全账户"，更不会索要银行卡密码和验证码。
- **应对**：直接挂断，拨打110核实。

### 3. 虚假投资平台（泛亚/善林金融类）

- 以"P2P""区块链""数字交易所"为名。
- 平台数据完全造假，涨跌由后台控制。
- 早期允许小额提现（建立信任），大额入金后关闭通道。
- **案例**：善林金融非法集资736亿元，庞氏骗局持续数年。

## 九、庞氏骗局与传销

### 1. 庞氏骗局核心逻辑

- **本质**：用新投资者的钱支付老投资者的收益，没有真实投资业务。
- **崩盘信号**：
  - 要求"拉人头"才能获得更高收益。
  - 提现越来越慢，以"系统升级""银行审核"拖延。
  - 频繁更换公司名称、法人、办公地址。
  - 收益率异常稳定（真实投资必然有波动）。

### 2. 传销三特征（法律定义）

1. **入门费**：缴纳入会费或购买商品才能加入。
2. **拉人头**：收入主要来自发展下线人数。
3. **层级返利**：按层级计提报酬，上线吃下线。

### 3. 常见包装形式

| 类型 | 伪装 | 实质 |
| --- | --- | --- |
| **消费返利** | "消费全返""0元购" | 资金盘 |
| **虚拟货币** | "百倍币""XX公链" | 发空气币圈钱 |
| **养老投资** | "以房养老""养老山庄" | 非法集资 |
| **原始股** | "马上上市""股权翻倍" | 股权骗局 |
| **慈善公益** | "公益理财""爱心投资" | 传销+庞氏 |

## 十、AI骗局（新型威胁）

### 1. 深度伪造（Deepfake）

| 技术 | 应用场景 | 防范 |
| --- | --- | --- |
| **AI换脸** | 视频通话冒充亲友/领导 | 要求对方做"约定动作"（如摸鼻子、挥手） |
| **AI合成语音** | 电话冒充亲人"出事了急需钱" | 回拨本人电话核实 |
| **AI生成文本** | 高仿账号发私信"我是XX" | 核实账号真实性 |

### 2. AI辅助诈骗特征

- **话术更自然**：AI生成的对话逻辑清晰、语法正确，不再是"境外口音+错别字"。
- **反应更即时**：AI聊天机器人24小时在线回复，不给你冷静时间。
- **个性化攻击**：通过社交媒体获取你的信息，定制化话术（如知道你最近买了某只股票）。

### 3. 防范AI骗局的核心原则

- **多重验证**：涉及转账，必须通过本人电话/视频双重确认。
- **约定暗号**：与家人约定一个"安全词"，AI无法知道。
- **警惕"完美人设"**：网上认识不久就聊投资/感情的，九成有问题。
- **截图溯源**：盈利截图可用AI生成，不要相信任何"晒单"。
- **延迟决策**：任何要求立即转账的，强制自己等待30分钟再决定。

## 十一、被骗后的补救措施

### 1. 黄金30分钟

| 步骤 | 行动 | 说明 |
| --- | --- | --- |
| **1. 停止转账** | 立即停止一切操作 | 防止损失扩大 |
| **2. 保留证据** | 截图聊天记录、转账记录、平台信息 | 越多越好 |
| **3. 报警** | 拨打110或到派出所报案 | 获取报案回执 |
| **4. 联系银行** | 冻结相关账户 | 尝试拦截资金 |
| **5. 拨打96110** | 反诈专线 | 专业指导 |

### 2. 资金追回难度

- **黄金时间**：转账后30分钟内报警，资金冻结拦截概率最高。
- **跨境难度**：资金一旦出境，追回极其困难。
- **现实**：大部分电信诈骗资金追回率<20%，核心在预防。

### 3. 心理修复

- 被骗后自责、焦虑、抑郁是正常反应，必要时寻求心理咨询。
- 不要因为"想回本"再次被骗（二次被骗率极高）。
- 向信任的人倾诉，不要独自承受。

## 十五、亲友被骗怎么办

### 1. 识别信号

- 突然频繁操作手机/电脑，回避家人询问。
- 账户资金异常流出，或向陌生账户转账。
- 情绪波动大（兴奋于"投资收益"或焦虑于"亏损"）。
- 提到"老师""内部消息""稳赚"等关键词。

### 2. 干预方法

- **不要指责**：被骗者往往自责内疚，指责会使其更加封闭。
- **冷静沟通**：表达关心而非质问，引导其回忆细节。
- **专业帮助**：陪同报警、拨打96110反诈专线。
- **财产隔离**：必要时暂时控制家庭大额资金，防止继续被骗。
- **心理支持**：被骗是严重心理创伤，必要时寻求专业心理咨询。

### 3. 法律途径

- **报案**：携带证据到派出所报案，获取报案回执。
- **民事诉讼**：如能确定诈骗者身份，可提起民事诉讼追偿。
- **刑事附带民事**：在刑事案件中提出赔偿请求。
- **现实**：跨境诈骗追偿难度极大，预防远比补救重要。

| 无法出金 | 设置"系统维护""银行审核"等借口拖延 |
| 数据篡改 | 交易记录、K线图均可后台修改 |
| 服务器在境外 | 跨境执法难度大，追回困难 |

### 假平台运营模式

| 阶段 | 操作 | 目的 |
|------|------|------|
| 搭建期 | 购买域名、搭建网站/APP | 准备诈骗工具 |
| 引流期 | 社交平台拉人进群 | 获取目标客户 |
| 信任期 | 伪造盈利截图、假导师带单 | 建立信任 |
| 收割期 | 诱导大额入金后拔网线 | 诈骗资金 |
| 跑路期 | 平台关闭、人员失联 | 逃避追捕 |

### 如何识别假平台

- **查域名**：正规券商域名固定，假平台域名常变化。
- **查应用商店**：假平台通常不在官方应用商店上架。
- **查资金通道**：正规平台走银证转账，假平台进个人/对公账户。
- **查行情数据**：对比正规行情软件，数据是否一致。
- **查客服**：假平台客服通常在境外，无法提供实体地址。

> 来源：公安部《网络诈骗犯罪案件审判指引》

## 十八、假导师话术库

### 常见话术类型

| 话术类型 | 具体话术 | 目的 |
|---------|---------|------|
| 权威包装 | "我是XX证券首席分析师""我有10年操盘经验" | 建立信任 |
| 业绩展示 | "上周带大家抓了3个涨停""这个月收益40%" | 诱发贪婪 |
| 紧迫催促 | "今天必须买入，晚了就没了""最后机会" | 制造紧迫感 |
| 内幕暗示 | "我有内部消息""机构马上要拉升" | 暗示稳赚 |
| 情感绑架 | "我是为你好""你不信任我吗" | 施加压力 |
| 恐吓打压 | "你不跟着做会后悔""你自己的操作太差" | 打击自信 |

### 话术应对策略

| 话术 | 正确应对 |
|------|---------|
| "今天必须买入" | 不着急，让我先考虑一下 |
| "我有内部消息" | 内部消息是违法的，我不参与 |
| "你不信任我吗" | 我信任你，但我需要独立判断 |
| "你看别人赚了多少" | 每个人的情况不同，我需要谨慎 |
| "最后机会了" | 如果是好机会，不会因为我晚一天就消失 |

### 心理操控手法

| 手法 | 说明 | 应对 |
|------|------|------|
| 从众效应 | "群里大家都买了" | 群里可能有托 |
| 损失厌恶 | "你不买就亏了" | 冲动决策更危险 |
| 确认偏误 | 只让你看到盈利案例 | 亏损案例被隐藏 |
| 权威效应 | "专家说的" | 专家不会公开荐股 |
| 稀缺性 | "名额有限" | 制造紧迫感的骗局 |

### 识别假导师的关键

- **真正的专家不会公开荐股**：合法的基金经理不能公开推荐个股。
- **真正的专家不会承诺收益**：投资有风险，承诺收益是违法的。
- **真正的专家不会催促交易**：正规投资建议需要时间研究。
- **真正的专家不会要你转账到个人账户**：资金必须走银证转账。

> 来源：证监会《关于加强证券公司研究业务监管的通知》

## 十九、资金流向追踪

### 诈骗资金流向

| 阶段 | 资金流向 | 追回难度 |
|------|---------|---------|
| 入金 | 受害者→假平台对公账户 | 可冻结 |
| 拆分 | 对公账户→多个个人账户 | 追踪困难 |
| 转移 | 个人账户→境外账户 | 极难追回 |
| 洗白 | 境外账户→现金/房产/虚拟货币 | 几乎无法追回 |

### 资金追踪方法

| 方法 | 说明 | 效果 |
|------|------|------|
| 银行冻结 | 报警后公安机关冻结账户 | 需要快速反应 |
| 资金流向分析 | 追踪资金在多个账户间的流转 | 需要专业工具 |
| 跨境协作 | 通过国际刑警组织追境外资金 | 效率低、难度大 |
| 虚拟货币追踪 | 追踪资金转换为虚拟货币后的流向 | 技术难度高 |

### 追回难度分析

| 情况 | 追回概率 | 说明 |
|------|---------|------|
| 资金未转移 | 较高（>50%） | 公安机关可冻结账户追回 |
| 资金已转移至国内账户 | 中等（20%-50%） | 需追踪多个账户 |
| 资金已转移至境外 | 极低（<10%） | 跨境执法难度大 |
| 资金已转换为虚拟货币 | 极低（<5%） | 匿名性强，追踪困难 |
| 资金已被挥霍 | 无法追回 | 资金已消耗 |

### 报案后注意事项

- **保留所有证据**：聊天记录、转账凭证、平台截图。
- **配合调查**：按公安机关要求提供信息。
- **关注进展**：定期了解案件侦破进展。
- **心理准备**：追回周期长，可能需要数月甚至数年。

> 来源：公安部《网络诈骗犯罪案件审判指引》

## 二十、受害者心理分析

### 受害者心理阶段

| 阶段 | 心理状态 | 典型表现 |
|------|---------|---------|
| 投入期 | 贪婪+从众 | 相信高收益，忽略风险信号 |
| 盈利期 | 兴奋+自信 | 加大投入，向亲友推荐 |
| 质疑期 | 焦虑+否认 | 发现异常但不愿承认被骗 |
| 崩盘期 | 恐慌+愤怒 | 立即停投，但已无法挽回 |
| 崩盘后 | 自责+抑郁 | 自责、失眠、社交退缩 |

### 二次被骗风险

| 骗局类型 | 手法 | 识别方法 |
|---------|------|---------|
| 追回骗局 | "有关系能帮你追回资金，先付手续费" | 正规追回不需要先付费 |
| 维权骗局 | "集体维权需要交律师费" | 正规律师先服务后收费 |
| 投资回本 | "跟着我做能赚回来" | 二次投资风险更高 |
| 信息贩卖 | 出售受害者信息给其他骗子 | 保护个人信息 |

### 心理干预建议

- **允许情绪释放**：被骗是严重心理创伤，允许自己悲伤、愤怒。
- **不要独自承受**：向信任的人倾诉，或加入受害者互助群。
- **专业帮助**：持续失眠、抑郁、有自伤倾向时，务必寻求心理咨询。
- **停止自责**：被骗不是你的错，骗子是专业的犯罪团伙。
- **向前看**：生活还要继续，从教训中学习，重建财务安全。

### 防止二次被骗

- **不轻信"追回"承诺**：正规追回不需要先付费。
- **不急于"回本"**：被骗后急于回本的心态更容易被骗。
- **不泄露个人信息**：保护好身份证、银行卡等信息。
- **咨询专业人士**：报警、咨询律师是最可靠的途径。

> 来源：中国心理卫生协会、反诈中心心理援助热线

## 二十一、报案与追回实操

### 报案流程

| 步骤 | 操作 | 注意事项 |
|------|------|---------|
| 第一步 | 立即停止一切操作 | 防止损失扩大 |
| 第二步 | 保留所有证据 | 聊天记录、转账记录、平台信息 |
| 第三步 | 拨打110或到派出所报案 | 获取报案回执 |
| 第四步 | 联系银行冻结账户 | 尝试拦截资金 |
| 第五步 | 拨打96110反诈专线 | 专业指导 |
| 第六步 | 向监管部门举报 | 金融监管、网信办 |

### 证据清单

| 证据类型 | 具体内容 | 重要性 |
|---------|---------|--------|
| 聊天记录 | 微信/QQ/Telegram对话 | 极高 |
| 转账记录 | 银行转账凭证、支付宝/微信支付记录 | 极高 |
| 平台信息 | APP截图、网站截图、平台名称 | 高 |
| 合同文件 | 投资合同、服务协议 | 高 |
| 人证 | 其他受害者证词、推荐人信息 | 中 |

### 追回时间线

| 时间 | 行动 | 预期效果 |
|------|------|---------|
| 24小时内 | 报警+银行冻结 | 资金拦截概率最高 |
| 1周内 | 联合受害者+向监管部门举报 | 增强案件影响力 |
| 1个月内 | 咨询律师+配合调查 | 了解法律途径 |
| 持续 | 关注案件进展 | 等待追回结果 |

### 追回现实

- **黄金时间**：转账后30分钟内报警，资金冻结拦截概率最高。
- **跨境难度**：资金一旦出境，追回极其困难。
- **现实**：大部分电信诈骗资金追回率<20%，核心在预防。
- **心理准备**：追回是长期过程，可能需要数月甚至数年。

## 防范荐股杀猪盘核心要点

### 识别特征

| 特征 | 说明 |
|------|------|
| 高收益承诺 | 承诺稳赚不赔、日赚斗金 |
| 群内氛围 | 群内都是托，营造赚钱氛围 |
| 导师神预测 | 每次预测都准，实际是事后编辑 |
| 催促转账 | 限时优惠、名额有限，制造紧迫感 |

### 防范措施

| 措施 | 说明 |
|------|------|
| 不轻信陌生人 | 不相信网络上的投资导师 |
| 不贪小便宜 | 不相信高收益零风险投资 |
| 核实平台 | 只在持牌平台投资 |
| 及时报警 | 发现被骗立即报警 |

### 投资核心原则

- **投资只走正规渠道**：不认识的人推荐的APP一律不装。
- **不贪高收益**：承诺高收益的都是骗局。
- **保护个人信息**：不向他人透露银行卡号、验证码。
- **及时止损**：发现被骗立即停止转账并报警。

> 来源：公安部《网络诈骗犯罪案件审判指引》、各地金融办

### 投资心态管理

| 心态 | 说明 |
|------|------|
| 长期思维 | 投资是长期行为，不要被短期波动影响 |
| 纪律执行 | 坚持投资计划，不被市场情绪左右 |
| 风险意识 | 任何时候都要把风险控制放在第一位 |
| 持续学习 | 市场在变化，需要不断学习新知识 |

### 投资核心原则总结

- **不贪高收益**：承诺高收益的都是骗局。
- **分散投资**：不把所有资金投入单一品种。
- **长期持有**：优质资产需要时间兑现价值。
- **及时止损**：发现异常立即停止操作并报警。

### 杀猪盘案例分析

#### 案例二：投资群杀猪盘

- **受害者**：50岁男性，有投资经验。

- **损失**：投入50万，全部损失。
- **教训**：投资群可能是骗局，不要轻信他人。

#### 案例三：荐股杀猪盘

- **受害者**：40岁男性，炒股亏损急于回本。
- **过程**：被荐股老师诱导，投入"稳赚不赔"的平台。
- **损失**：投入30万，全部损失。
- **教训**：荐股老师可能是骗子，不要轻信。
