# 荐股杀猪盘

> 股民是杀猪盘最爱的人群——因为"想赚钱"的心理最容易被利用。本文拆穿从加群到亏光的全流程。

## 一、典型剧本

1. **引流**：短视频/股吧/微信"免费领牛股""老师带单"引你加群/关注公众号。
2. **养信**：群里"老师"每天晒战绩、托儿晒盈利，免费课建立权威感。
3. **诱导开户**：以"内部通道""新平台""机构席位"为由，让你去**非正规平台**开户入金（关键一步：钱进了骗子控制的虚假盘）。
4. **收割**：先给点甜头（虚增账面盈利），诱你加仓，然后"老师"反向喊单或平台拔网线，本金归零。
5. **消失**：提现失败、群解散、客服失联。

## 二、关键识别

- **正规证券交易只能通过持牌券商**（证监会公布的证券公司），资金进银行第三方存管。**任何让钱进"老师指定账户/不明 APP/虚拟盘"的都是诈骗。**
- "内幕消息""机构通道""稳赚不赔"——证券市场没有这些，有也是违法且不会外泄给你。
- 直播间/微信群里一片叫好，几乎必有托。
- 平台无法在官方应用商店搜到、需扫码下载.apk——高危。

## 三、为什么有人信

- 真亏过、想回本，急于找"高手"带。
- 群内从众氛围 + 权威包装（头衔/战绩图可伪造）。
- 先小赚确认，放松警惕后大入金。

## 四、防御清单

1. 只在**持牌券商**交易，资金走银行存管；不向任何个人/不明平台转账。
2. 不轻信"免费牛股""老师带单"，真有本事早自己赚发了。
3. 群里赚钱截图 = 一键生成，不当真。
4. 下载 APP 只走官方应用商店；陌生.apk 不装。
5. 已入金无法提现——立即停投、保留聊天/转账证据、报警 96110。

## 五、合法替代

- 想学投资：看 ../炒股 ../基金 的系统方法，自己建立能力，而非找"带单"。
- 想跟投：选正规公募基金（基金业协会可查备案），走银行/券商/官方平台。
