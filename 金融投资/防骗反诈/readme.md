# 防骗反诈

> 投资路上，不亏钱比赚快钱重要。本板块总结最高频的金融骗局套路与识别方法——尤其针对股民、基民、想"搞钱"的人。

> 原则：**天上不会掉馅饼，"高收益零风险"必是骗局。** 遇可疑先停手、查资质、问身边人。

## 通用识别信号（红色预警）

1. 承诺"保本保收益""稳赚""每月固定返"
2. 收益高得离谱（年化 20%+ 还零风险）
3. 拉人头返佣、层级提成（传销特征）
4. 要求转钱到"私人账户/境外平台/不明 APP"
5. 资质查不到或伪造（证监会/基金业协会无备案）
6. 制造紧迫感"最后机会、限额"
