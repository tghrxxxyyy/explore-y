# 基金 · 实战案例

> 方法演示，非投资建议。

## 案例一：上班族宽基定投
- 标的：沪深300联接 + 中证500联接（各 50%）。
- 方式：每周四定投 500 元，自动扣款。
- 止盈：账户年化收益 > 12% 或沪深300 PE 分位 > 70%，赎回 1/3 落袋。
- 周期：坚持 3 年以上，不因短期浮亏停止。

## 案例二：用指标筛选主动基金
1. 看长期：近 3 年、5 年年化收益位于同类前 1/3。
2. 看稳定：最大回撤小于同类平均，夏普比率高于同类。
3. 看经理：任职 ≥ 3 年，投资风格稳定不漂移。
4. 看规模：50 亿-200 亿较舒适，避免迷你基（< 2 亿有清盘风险）。
5. 看费用：管理费 + 托管费合计越低越好（指数类尤甚）。
6. 分散持有 3-5 只，单只 ≤ 30%。

> 定投的本质是用时间换空间，别试图抄底逃顶。
