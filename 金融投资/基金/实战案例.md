# 基金 · 实战案例

> 方法演示，非投资建议。所有数字均为示意。

---

## 案例一：上班族宽基估值定投
- **标的**：沪深300联接 + 中证500联接（各 50%），长期趋势向上。
- **方式**：
  - 基础：每周四定投 500 元，自动扣款。
  - 估值增强：查沪深300 PE 历史分位——<30% 时加倍（投 1000），>70% 时减半（投 250）甚至暂停。
- **止盈**：账户年化 >12% 或 PE 分位 >70%，赎回 1/3 落袋；回落后开启新一轮。
- **周期**：坚持 3 年以上，不因短期浮亏停止（微笑曲线需要时间）。

---

## 案例二：核心-卫星组合（平衡型）
- **核心（70%）**：沪深300 ETF（40%）+ 中证500 ETF（30%）。
- **卫星（30%）**：消费/医药行业 ETF（15%）+ 美股 QDII 标普500（10%）+ 黄金 ETF（5%）。
- **再平衡**：每年一次，股涨超配则卖股买债/黄金，回到目标比例。
- **效果**：单一市场回撤时被其他资产缓冲，长期波动更低、体验更好。

## 案例三：用指标筛选主动基金
1. **看长期**：近 3 年、5 年年化收益位于同类前 1/3。
2. **看稳定**：最大回撤小于同类平均，夏普比率高于同类。
3. **看经理**：任职 ≥3 年，投资风格稳定不漂移。
4. **看规模**：50 亿–200 亿较舒适，避免迷你基（<2 亿清盘风险）。
5. **看费用**：管理费+托管费合计越低越好（指数类尤甚）。
6. **分散**持有 3–5 只，单只 ≤30%。

## 案例四：网格交易（场内 ETF）
- **适用**：宽基/品种在震荡区间（如 0.9–1.1 之间来回）。
- **做法**：基准价 1.000，资金分 10 份；每跌 5%（0.95/0.90…）买 1 份，每涨 5%（1.05/1.10…）卖 1 份，循环赚取波段。
- **风控**：总仓位设上限（如 70%），跌破区间下沿且有基本面恶化则暂停并评估；单边下跌会满仓，需备用金或止损线。
- **优势**：不依赖预测方向，靠纪律赚波动；适合没时间盯盘、但能挂条件单的投资者。

## 案例五：用开源数据做定投决策
- 用 `akshare` 拉指数估值分位，决定本期多投还是少投：
  ```python
  import akshare as ak
  # 沪深300指数近十年PE
  pe = ak.index_value_name_funddb(symbol="沪深300")
  # 计算当前PE在历史中的分位
  pct = (pe["pe"] < pe["pe"].iloc[-1]).mean()
  print("当前PE历史分位:", round(pct*100, 1), "%")
  # 分位<30% 加倍投，>70% 减半
  ```
- 让"估值定投"从口号变成可执行的脚本，避免情绪化择时。
