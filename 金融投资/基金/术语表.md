# 基金 · 术语表

> 从基础到进阶，覆盖类型、净值、费用、风险与策略类术语。

## 类型与结构类
| 术语 | 含义 |
| --- | --- |
| 基金管理人 | 基金公司，负责投资决策。 |
| 基金托管人 | 商业银行，保管资产并监督运作。 |
| 货币基金 | 投短期货币工具，极低风险（如余额宝）。 |
| 债券基金 | 以债券为主（≥80% 债），低风险。 |
| 股票基金 | 以股票为主（≥80% 股），高风险。 |
| 混合基金 | 股债混合，风险居中。 |
| 指数基金 | 跟踪某指数，被动投资。 |
| ETF | 交易所交易指数基金，费用低、实时买卖。 |
| 联接基金 | 主要投某 ETF 的场外基金，便于定投。 |
| LOF | 场内场外均可交易的开放式基金。 |
| QDII | 投资境外市场，含汇率风险。 |
| FOF | 买其他基金的基金，二次分散。 |
| REITs | 不动产投资信托，分红+价格波动。 |
| 主动 / 被动 | 经理选股 / 复制指数。 |
| Smart Beta | 按因子（红利/低波/价值）编制的策略指数。 |

## 净值与交易类
| 术语 | 含义 |
| --- | --- |
| 单位净值 NAV | 每份基金单位价值，每日更新。 |
| 累计净值 | 单位净值 + 历史分红，看总回报。 |
| 申购 / 赎回 | 买入 / 卖出基金份额（场外）。 |
| 申购费 | 买入手续费（平台常打 1 折）。 |
| 管理费 / 托管费 | 每年从净值扣除。 |
| 赎回费 | 卖出费，持有越短越高。 |
| 销售服务费 | C 类按日计提，替代申购费。 |
| 红利再投资 | 分红自动再买份额，复利更优。 |
| A 类 / C 类 | A 收申购费、C 收销售服务费，长持选 A、短持选 C。 |

## 指标与风险类
| 术语 | 含义 |
| --- | --- |
| 夏普比率 | 每单位风险换来的超额收益，越高越好。 |
| 索提诺比率 | 只考虑下行风险的回报。 |
| 最大回撤 | 历史最大跌幅，衡量抗跌。 |
| 跟踪误差 | 指数基金偏离标的程度，越小越准。 |
| 信息比率 | 主动基金相对基准的超额/跟踪误差。 |
| 年化收益 | 长期平均回报（结合风险看）。 |
| 规模 | 基金体量，避免迷你基清盘风险。 |
| 换手率 | 持仓周转频率，过高或暗示高成本。 |
| 风险等级 R1–R5 | 低到高五档。 |

## 策略类
| 术语 | 含义 |
| --- | --- |
| 定投 | 定期定额买入，摊薄成本。 |
| 微笑曲线 | 定投先跌后涨，低位积累份额获利。 |
| 估值定投 | 按 PE/PB 分位低多买、高少买。 |
| 均线偏离法 | 指数低于长期均线时加投。 |
| 止盈 | 达目标/估值高位/回撤阈值时卖出。 |
| 再平衡 | 定期把股债比例调回目标。 |
| 核心-卫星 | 核心宽基 + 卫星行业/主题。 |
| 股债性价比 | 股息率/国债收益率，判断股债贵贱。 |
| 美林时钟 | 按经济周期配置大类资产。 |
| 网格交易 | 震荡区间高抛低吸。 |
| 杠铃策略 | 防御+进攻两端配置，中段过渡。 |

---

*术语仅为学习辅助，不构成投资建议。*
