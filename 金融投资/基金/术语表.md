# 基金 · 术语表

| 术语 | 含义 |
| --- | --- |
| 净值 NAV | 每份基金的单位价值，每日更新。 |
| 申购/赎回 | 买入/卖出基金份额。 |
| 申购费 | 买入手续费（平台常打 1 折）。 |
| 管理费 | 每年从净值扣除（指数基金更低）。 |
| 赎回费 | 卖出费，持有越短越高。 |
|  ETF | 交易所交易指数基金，费用低、实时买卖。 |
| 联接基金 | 主要投资于某 ETF 的场外基金，便于定投。 |
| 夏普比率 | 每单位风险换来的超额收益，越高越好。 |
| 最大回撤 | 历史最大跌幅，衡量抗跌。 |
| 跟踪误差 | 指数基金偏离标的程度，越小越准。 |
| 微笑曲线 | 定投先跌后涨，低位积累份额获利。 |
| 再平衡 | 定期把股债比例调回目标。 |
| 股债性价比 | 用股息率/国债收益率判断股债贵贱。 |
| FOF | 买其他基金的基金，二次分散。 |
| QDII | 投资境外市场的基金，含汇率风险。 |
