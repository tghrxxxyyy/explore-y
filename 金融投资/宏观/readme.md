# 宏观

> 炒股/基金的人，不懂宏观等于盲猜。本板块把最常见的宏观指标和政策语言翻译成"对我投资有什么用"。

> ⚠️ 宏观是概率与背景，不是精准预测；本板块为科普，**不构成投资建议**。

## 核心思路

1. **宏观定"水位"**：流动性松紧、经济冷热，决定权益/债券/商品的大环境。
2. **指标看组合、看趋势**：单月数据噪声大，连看 3–6 个月方向才有意义。
3. **预期差最重要**：市场提前交易"预期"，真数据符合/超预期才动；利好出尽是利空。
4. **普通人用法**：别试图精确择时，用宏观判断"大类仓位倾向"（股多些还是债多些）。
