# 政策与美联储

> 资产价格长期看业绩、中期看流动性、短期看情绪。货币政策是流动性的总开关。本文讲中国的货币政策框架，以及为什么美联储牵动全球。

## 一、中国货币政策工具

- **降准（下调存款准备金率）**：银行可贷资金变多，释放长期流动性，偏"总量宽松"。
- **降息（调政策利率/MLF/LPR）**：降低融资成本，刺激借贷与消费投资。LPR 下行直接影响房贷（见 ../房产/房贷选择）。
- **公开市场操作（OMO/MLF）**：央行日常调节短期与中期流动性，"麻辣粉"(MLF) 是 LPR 定价锚之一。
- **结构性工具**：定向支持小微、绿色、科创——精准滴灌而非大水漫灌。

## 二、财政政策（和货币配合）

- 减税降费、专项债、基建投资——财政扩张直接托需求，利好相关产业链。
- "宽财政 + 宽货币"组合对风险资产最友好；"紧财政 + 紧货币"则压制。

## 三、为什么美联储最重要

- 美元是世界储备/融资货币，**美联储是全球流动性的总闸**。美债收益率（无风险利率之锚）影响全球资产定价。
- **美联储加息** → 美元走强、全球资金回流美国、新兴市场承压、黄金/成长股估值受压。
- **美联储降息** → 流动性外溢、风险偏好回升、新兴市场与黄金受益。
- **中美利差**：美债收益率高 → 人民币承压、资本外流压力，约束我国降息空间（"不可能三角"取舍）。

## 四、怎么观察

- 盯**美联储点阵图/议息会议**、**非农/CPI/PCE**（美国通胀与就业）、**美债 10 年收益率**、**美元指数 DXY**。
- 国内盯**政治局会议/中央经济工作会议**（定调）、**央行季度货政报告**、**LPR 报价日**、**社融与金融数据**。

## 五、对普通投资者的含义

1. 全球收紧周期（美联储加息）：权益谨慎、现金/货基/短债更舒服，黄金有对冲。
2. 转向宽松（美联储降息+国内降准降息）：风险资产估值修复窗口，债牛延续。
3. 别赌单次会议：看"方向+持续性"，政策底→市场底常有时滞。
4. 用仓位表达观点，而非满仓押方向；宏观是背景板不是点金棒。
