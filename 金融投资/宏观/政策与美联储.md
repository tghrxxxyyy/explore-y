# 政策与美联储

> 资产价格长期看业绩、中期看流动性、短期看情绪。货币政策是流动性的总开关。本文讲中国的货币政策框架，以及为什么美联储牵动全球。

## 一、中国货币政策工具

- **降准（下调存款准备金率）**：银行可贷资金变多，释放长期流动性，偏"总量宽松"。
- **降息（调政策利率/MLF/LPR）**：降低融资成本，刺激借贷与消费投资。LPR 下行直接影响房贷（见 ../房产/房贷选择）。
- **公开市场操作（OMO/MLF）**：央行日常调节短期与中期流动性，"麻辣粉"(MLF) 是 LPR 定价锚之一。
- **结构性工具**：定向支持小微、绿色、科创——精准滴灌而非大水漫灌。

## 二、财政政策（和货币配合）

- 减税降费、专项债、基建投资——财政扩张直接托需求，利好相关产业链。
- "宽财政 + 宽货币"组合对风险资产最友好；"紧财政 + 紧货币"则压制。

## 三、为什么美联储最重要

- 美元是世界储备/融资货币，**美联储是全球流动性的总闸**。美债收益率（无风险利率之锚）影响全球资产定价。
- **美联储加息** → 美元走强、全球资金回流美国、新兴市场承压、黄金/成长股估值受压。
- **美联储降息** → 流动性外溢、风险偏好回升、新兴市场与黄金受益。
- **中美利差**：美债收益率高 → 人民币承压、资本外流压力，约束我国降息空间（"不可能三角"取舍）。

## 四、怎么观察

- 盯**美联储点阵图/议息会议**、**非农/CPI/PCE**（美国通胀与就业）、**美债 10 年收益率**、**美元指数 DXY**。
- 国内盯**政治局会议/中央经济工作会议**（定调）、**央行季度货政报告**、**LPR 报价日**、**社融与金融数据**。

## 五、对普通投资者的含义

1. 全球收紧周期（美联储加息）：权益谨慎、现金/货基/短债更舒服，黄金有对冲。
2. 转向宽松（美联储降息+国内降准降息）：风险资产估值修复窗口，债牛延续。
3. 别赌单次会议：看"方向+持续性"，政策底→市场底常有时滞。
4. 用仓位表达观点，而非满仓押方向；宏观是背景板不是点金棒。

## 六、美联储核心工具详解

### 联邦基金利率

| 要素 | 说明 |
|------|------|
| 定义 | 银行间隔夜拆借利率，美联储的政策目标利率 |
| 调整方式 | FOMC（联邦公开市场委员会）每 6 周议息一次，投票决定利率目标区间 |
| 传导路径 | 联邦基金利率 → 银行间利率 → 贷款利率/存款利率/债券收益率 → 企业融资成本/消费信贷 |
| 历史区间 | 0%-0.25%（2008、2020）→ 5.25%-5.50%（2023-2024 峰值）→ 4.25%-4.50%（2026 年中） |

- **点阵图**：18 位委员对未来利率路径的匿名预测，每季度更新一次，市场据此判断加息/降息终点。
- **市场预期**：CME FedWatch 工具实时反映市场对下次会议的利率概率预期，与点阵图对照看"预期差"。

> 来源：美联储（Federal Reserve）、CME Group

### 量化宽松（QE）

| 要素 | 说明 |
|------|------|
| 定义 | 央行在利率已近零时，通过购买国债和 MBS 向市场注入流动性 |
| 目的 | 压低长端利率、提振资产价格、刺激信贷 |
| 历史操作 | 2008 年 QE1-QE3，2020 年无限量 QE |
| 退出方式 | 逐步减少购买（Taper）→ 停止购买 → 缩表（QT） |

### 量化紧缩（QT）

| 要素 | 说明 |
|------|------|
| 定义 | 美联储缩减资产负债表，收回市场流动性 |
| 方式 | 到期国债/MBS 不再再投资，被动缩表 |
| 影响 | 流动性收紧、长端利率上行、风险资产承压 |
| 历史 | 2017-2019 年首次 QT，2022 年 6 月启动本轮 QT，2024 年 6 月放缓 |

- **QT 对市场影响**：初期影响温和，但缩表规模累积后会推升市场利率，2019 年 9 月隔夜回购利率飙升即为 QT 后遗症。
- **QT 与 QE 对称**：QE 推动资产价格上行，QT 则逆向操作；但市场对 QT 的敏感度通常低于 QE。

> 来源：美联储《资产负债表正常化计划》

## 七、加息与降息周期

### 历史周期复盘

| 周期 | 时间 | 背景 | 利率区间 | 对资产影响 |
|------|------|------|----------|------------|
| 加息周期 | 2004-2006 | 经济复苏、通胀上升 | 1% → 5.25% | 美股先涨后跌、美元走强、新兴市场承压 |
| 降息周期 | 2007-2008 | 次贷危机、金融海啸 | 5.25% → 0-0.25% | 美股先跌后涨、黄金大涨、美元先强后弱 |
| 加息周期 | 2015-2018 | 经济复苏、通胀温和 | 0-0.25% → 2.25-2.50% | 美股持续上涨、新兴市场波动 |
| 降息周期 | 2019-2020 | 贸易摩擦+新冠疫情 | 2.25-2.50% → 0-0.25% | 美股 V 型反弹、黄金创新高 |
| 加息周期 | 2022-2023 | 通胀飙升（CPI 最高 9.1%） | 0-0.25% → 5.25-5.50% | 美股回调、美元指数破 110、黄金震荡 |
| 降息周期 | 2024-至今 | 通胀回落、经济软着陆 | 5.25-5.50% → 4.25-4.50%（预估） | 美股新高、债市反弹 |

### 周期判断框架

| 信号 | 含义 |
|------|------|
| 点阵图显示降息路径 | 政策方向已转 |
| 非农就业持续走弱 | 劳动力市场降温，支持降息 |
| 核心 PCE 降至 2% 附近 | 通胀目标接近达成 |
| 美联储官员频繁"放鸽" | 市场预期管理，为降息铺路 |

> 来源：美联储历史议息会议记录、FOMC 声明

## 八、中美利差详解

| 要素 | 说明 |
|------|------|
| 定义 | 中国国债收益率 - 美国国债收益率（通常看 10 年期） |
| 当前状态（2026） | 中 10 年约 2.0%-2.3%，美 10 年约 4.0%-4.3%，利差约 -2%（中低于美） |
| 影响路径 | 利差 → 资本流动 → 汇率 → 央行政策空间 |

### 利差对投资的影响

| 利差情况 | 资本流动 | 汇率影响 | 政策约束 |
|----------|----------|----------|----------|
| 中美利差收窄（中升美降） | 外资流入中国债市/股市 | 人民币升值 | 央行降息空间扩大 |
| 中美利差倒挂（中低于美） | 资本外流压力 | 人民币贬值 | 央行降息受约束 |
| 利差大幅倒挂 | 外资减持中国债券 | 汇率承压明显 | 央行需动用其他工具维稳 |

- **历史经验**：2022-2023 年中美利差大幅倒挂，北向资金阶段性流出 A 股，人民币从 6.3 贬至 7.3 附近。
- **2026 年趋势**：美联储处于降息周期，中国维持宽松，利差有望逐步收窄。

> 来源：中国人民银行、美国财政部、Wind 数据

## 九、资本流动影响

### 跨境资本流动渠道

| 渠道 | 说明 | 影响市场 |
|------|------|----------|
| 北向资金（陆股通） | 外资通过沪/深股通买入 A 股 | A 股大盘蓝筹、消费、科技 |
| 南向资金（港股通） | 内地资金通过港股通买入港股 | 港股科技、医药、高股息 |
| 债券通 | 外资买入中国债券 | 国债、政策性金融债 |
| QFII/RQFII | 机构投资者配额 | 股票、债券、衍生品 |
| 直接投资（FDI） | 外商直接投资 | 实体经济、汇率 |

### 资本流动与资产价格

| 资本流动方向 | 对 A 股影响 | 对港股影响 | 对债券影响 |
|--------------|-------------|------------|------------|
| 外资大幅流入 | 蓝筹/消费/科技上涨 | 港股估值修复 | 债券收益率下行 |
| 外资大幅流出 | 蓝筹承压、情绪传导 | 港股调整 | 债券收益率上行 |
| 内资出海配置 | A 股流动性减弱 | 港股受益 | — |

- **跟踪工具**：Wind/Choice 的北向资金实时数据、央行国际收支平衡表（季度）、外管局跨境资金流动数据。

> 来源：中国证监会、中国人民银行、国家外汇管理局

## 十、美联储政策与中国投资者的实操建议

### 不同美联储政策阶段的应对

| 美联储阶段 | 中国资产表现（历史规律） | 建议配置 |
|------------|--------------------------|----------|
| 加息初期 | A 股承压、港股调整、债券偏弱 | 降低权益仓位，增加现金/短债 |
| 加息末期 | A 股筑底、港股超跌反弹机会 | 逐步布局权益 |
| 降息初期 | A 股估值修复、港股弹性大、债牛延续 | 增加权益（尤其港股）、加长久期债券 |
| 降息中后期 | A 股可能出现过热、债市反转风险 | 逐步减仓权益、缩短债券久期 |

### 关键跟踪指标

- **美债 10 年收益率**：全球资产定价之锚，上行压制成长股估值。
- **美元指数（DXY）**：美元走强利空新兴市场，走弱利好。
- **CME FedWatch**：市场对美联储会议的利率概率预期。
- **点阵图与经济预测**：每季度更新，判断政策终点。

### "不可能三角"与中国政策空间

- **理论**：固定汇率、资本自由流动、独立货币政策三者不可兼得。
- **中国实践**：有限资本管制 + 汇率弹性增加 + 保持货币政策独立性。
- **实际影响**：美联储大幅降息时，中国降息空间更大；美联储大幅加息时，中国降息受约束但可通过降准等工具释放流动性。

> 来源：美联储、中国人民银行、IMF《国际金融统计》

## 十一、美联储历史上的关键决策

### 沃尔克时刻（1979-1982）

| 要素 | 说明 |
|------|------|
| 背景 | 美国通胀飙升至 14% 以上（石油危机叠加财政扩张） |
| 决策 | 美联储主席保罗·沃尔克激进加息至 **20%** |
| 结果 | 美国陷入严重衰退，但通胀被压下，奠定此后 40 年低通胀基础 |
| 教训 | 央行信誉比短期经济更重要；通胀一旦失控，治理代价极高 |

### 格林斯潘泡沫（1987-2006）

| 要素 | 说明 |
|------|------|
| 特点 | 低利率环境催生互联网泡沫（2000）和房地产泡沫（2008） |
| 格林斯潘看跌期权 | 市场相信美联储会在大跌时救市，助长投机 |
| 教训 | 过度宽松的货币政策会积累系统性风险 |

### 伯南克与量化宽松（2008-2014）

| 要素 | 说明 |
|------|------|
| 背景 | 金融危机，利率已降至零仍不足以刺激经济 |
| 创新 | 推出 QE1/QE2/QE3，美联储资产负债表从 9000 亿扩至 4.5 万亿美元 |
| 教训 | 零利率下非常规工具有用，但会推高资产价格、加剧贫富分化 |

### 鲍威尔与通胀之战（2022-2024）

| 要素 | 说明 |
|------|------|
| 背景 | 新冠疫情叠加供应链危机，CPI 最高达 9.1%（40 年最高） |
| 决策 | 2022 年 3 月起连续加息 11 次，累计 525 个基点 |
| 结果 | 通胀从 9.1% 降至 3% 以下，经济软着陆 |
| 教训 | 延迟行动代价更大，激进加息可压通胀但需承受经济放缓 |

> 来源：美联储历史档案、FOMC 会议记录、《沃尔克：行动与原则》

## 十二、中美政策协调与博弈

| 维度 | 中美政策互动 |
|------|--------------|
| 美联储加息期 | 中国降息受约束（利差倒挂），但可通过降准、结构性工具释放流动性 |
| 美联储降息期 | 中国降息空间扩大，可更积极地宽松 |
| 中美贸易摩擦 | 关税影响出口，货币政策需对冲外需走弱 |
| 汇率联动 | 美联储政策直接影响美元指数，间接影响人民币汇率 |

| 2024 下半年 | 开启降息 | 维持宽松 | 利差收窄，A 股港股估值修复 |
| 2025 年 | 继续降息 | 适度宽松 | 风险偏好回升，债券牛市延续 |
| 2026 年 | 降息尾声 | 视经济恢复力度 | 关注政策转向信号 |

> 来源：美联储、中国人民银行、IMF《世界经济展望》

| 2024-至今 | 利差逐步收窄 | 外资回流 | 蓝筹修复 |

### 投资启示

| 启示 | 说明 |
|------|------|
| 利差收窄期 | 外资流入，利好A股蓝筹和港股 |
| 利差倒挂期 | 外资流出，A股承压，关注防御板块 |
| 利差修复期 | 外资回流，风险资产受益 |

## 十五、中国央行货币政策工具

### 常规工具

| 工具 | 说明 | 作用 |
|------|------|------|
| 降准 | 下调存款准备金率 | 释放长期流动性 |
| 降息 | 调整MLF/LPR利率 | 降低融资成本 |
| 公开市场操作 | OMO/MLF/SLF | 调节短期流动性 |
| 再贷款 | 向金融机构提供资金 | 定向支持特定领域 |

### 结构性工具

| 工具 | 说明 | 支持领域 |
|------|------|----------|
| 碳减排支持工具 | 支持碳减排项目 | 绿色发展 |
| 科技创新再贷款 | 支持科技创新 | 科技企业 |
| 普惠养老专项再贷款 | 支持普惠养老 | 养老产业 |
| 交通物流专项再贷款 | 支持交通物流 | 物流行业 |

### 传导路径

| 工具 | 传导路径 | 影响 |
|------|----------|------|

| 降息 | 融资成本下降 → 借贷增加 | 经济刺激 |
| 结构性工具 | 定向支持特定领域 | 精准滴灌 |

## 十六、汇率与利率联动

### 联动机制

| 维度 | 说明 |
|------|------|
| 利率平价 | 利率差异影响汇率预期 |
| 资本流动 | 利差变化引发资本流动，影响汇率 |
| 央行干预 | 央行通过利率和汇率工具维护稳定 |

### 历史案例

| 时期 | 利率变化 | 汇率变化 | 原因 |
|------|----------|----------|------|
| 2018 | 美联储加息 | 人民币贬值 | 中美利差倒挂 |
| 2022-2023 | 美联储激进加息 | 人民币大幅贬值 | 利差大幅倒挂 |
| 2024-至今 | 美联储降息 | 人民币企稳 | 利差收窄 |

### 投资影响

| 利率变化 | 汇率影响 | 资产影响 |
|----------|----------|----------|
| 美联储加息 | 美元走强，人民币承压 | A股承压，港股承压 |
| 美联储降息 | 美元走弱，人民币升值 | A股受益，港股受益 |
| 中国降息 | 人民币承压 | 国内经济刺激 |
