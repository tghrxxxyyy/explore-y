# 行业景气跟踪

> 选股选基先看"这个行业的生意现在好不好、将来好不好"。景气度就是行业的体温计，配合估值决定出手时机。

## 一、行业景气度怎么看

- **供需**：需求增速 > 供给增速 → 供不应求、景气向上；产能过剩、打价格战 → 景气下行。
- **库存**：行业库存处于低位、补库启动 → 景气修复；库存高位、去库不畅 → 压制盈利（见 经济周期与资产配置.md 的库存周期）。
- **价格**：产品涨价是景气最直接的信号（PPI 相关行业：上游资源、化工、钢铁等）。
- **产能利用率**：利用率高（如超 80%）说明供给紧张、盈利强；长期低于 70% 意味着产能过剩。
- **盈利与订单**：毛利率、新签订单、预收款/合同负债、在手订单——财报里最能"提前看"的科目。

## 二、领先 / 同步 / 滞后指标

| 类型 | 代表指标 | 说明 |
| ---- | ---- | ---- |
| 领先 | 新订单、社融流向、政策文件、草根调研 | 提前 1–2 个季度反映方向 |
| 同步 | 产量、开工率、出货量、收入增速 | 与行业景气同步变化 |
| 滞后 | 利润、资本开支、产能投放 | 确认景气，但行情往往已走完 |

- 实用技巧：**用领先指标找方向、用同步指标做确认、用滞后指标避风险**（景气顶点往往伴随一轮密集扩产公告）。

## 三、行业轮动的三种驱动力

- **政策驱动**：产业政策（新能源、半导体、AI、医药集采）直接改变行业盈利与估值预期，关注重大会议定调与部委文件。
- **周期驱动**：资源、化工、养殖等强周期行业，跟着库存周期与商品价格走，看 PPI 与大宗商品价格即可。
- **技术驱动**：新产品渗透率从 1% 到 50% 的过程（智能手机→电动车→AI），景气由"渗透率曲线"决定，看销量增速而非存量。

## 四、个人投资者的实用数据源

- **国家统计局**：规模以上工业增加值、PPI 分行业价格、工业企业利润、产能利用率。
- **海关总署**：出口分商品数据，看外需行业（家电、纺服、电子代工、新能源车）。
- **行业协会与交易所**：汽车（乘联会）、半导体（月销售额）、能源化工等行业协会月度数据。
- **上市公司财报**：季度营收/利润增速、毛利率、合同负债、存货——注意与去年同季比（同比）并剔除一次性因素。
- **调研纪要/业绩说明会**：公司和管理层对订单、价格、产能的口径，是景气判断的"一手信息"。
- **卖方研报与行业周报**：可看逻辑与数据，但观点有立场，交叉验证后自用。
- **查询顺序建议**：先宏观月报（统计局）→ 再行业月报（协会/海关）→ 后公司季报与纪要，由粗到细逐层确认。

## 五、几个行业的景气跟踪要点（举例）

- **新能源车**：看月度销量与渗透率、动力电池装机量、行业排产——需求端数据最灵敏。
- **光伏/风电**：看装机量、组件招标价、行业产能与出清进度——价格战阶段景气与盈利背离。
- **半导体**：看全球半导体销售额、国产替代进度、下游手机/PC/服务器出货。
- **生猪养殖**：看能繁母猪存栏（领先）、猪价、行业成本线——典型强周期，关注去产能拐点。
- **白酒/家电等消费**：看动销（渠道库存）、终端价格、居民收入与消费信心。
- **地产链**：看新房销售、竣工面积、政策放松节奏——数据滞后，政策信号反而更领先。

## 六、把景气度用于选基选股

1. **景气 + 低估值 = 机会**：行业景气向上、估值仍在历史低位（分位数 30% 以下），是性价比最高的区间。
2. **景气 + 高估值 = 谨慎**：业绩兑现快但估值已透支，波动大，适合止盈而非追高。
3. **景气向下 + 低估值 = 陷阱**：便宜有便宜的理由（"价值陷阱"），等景气拐点信号再说。
4. **景气不明 + 低估值 = 观察**：方向看不清时宁可少参与，等领先指标给出信号再动手。
5. **操作顺序**：先看宏观（信用/政策环境）→ 再看行业景气（领先指标）→ 最后看个股/基金估值，三层过滤。
6. **跟踪频率**：月度看行业数据、季度看财报、不定期看调研纪要；行业景气切换以季度计，不用天天盯。
7. **避坑**：单一行业数据易被龙头扰动，看行业整体中位数；卖方一致看好到极致时，往往离拐点不远。

## 七、行业景气指标详解

### 宏观先行指标

- **PMI（采购经理指数）**：50以上为扩张，低于50为收缩，新订单指数领先产出1-2个月。
- **社融规模**：社会融资规模增量，反映实体经济融资需求，领先经济活动2-3个月。
- **用电量与货运量**：工业用电量、货运量与工业增加值高度相关，是经济活动的同步指标。
- **M1与M2剪刀差**：M1增速>M2增速，表明资金活化，经济向好；反之资金沉淀，经济偏弱。

### 行业特定指标体系

| 行业 | 核心指标 | 数据来源 | 更新频率 |
|------|---------|---------|---------|
| 新能源车 | 月度销量、渗透率、动力电池装机量 | 中汽协、乘联会 | 月度 |
| 光伏 | 装机量、组件招标价、产能利用率 | 国家能源局、行业协会 | 月度/季度 |
| 半导体 | 全球半导体销售额、国产替代率 | SIA、海关总署 | 月度 |
| 生猪养殖 | 能繁母猪存栏、猪价、行业成本线 | 农业农村部 | 月度 |
| 白酒 | 渠道库存、终端价格、经销商打款 | 渠道调研、上市公司 | 季度 |
| 地产 | 新房销售面积、竣工面积、土地出让 | 统计局、自然资源部 | 月度 |

### 数据查询方法

1. **国家统计局官网**：每月15-18日发布上月工业增加值、PMI等数据。
2. **中国人民银行官网**：每月10-15日发布上月社融、M1/M2等金融数据。
3. **行业协会网站**：中汽协、乘联会、光伏行业协会等发布行业专项数据。
4. **上市公司公告**：月度经营数据、季报、年报中的行业分析部分。
5. **第三方数据平台**：Wind、Choice、同花顺iFinD等，数据全面但需付费。

### 数据解读技巧

- **同比vs环比**：同比反映趋势变化，环比反映短期波动，两者结合看更准确。
- **季节性调整**：某些行业有明显季节性（如白酒的Q4旺季），需考虑季节因素。
- **基数效应**：去年基数高或低会影响今年同比数据，需结合两年平均增速判断。
- **龙头效应**：行业数据可能被龙头企业扭曲，需关注中位数或剔除龙头后的数据。

## 八、不同行业跟踪方法

### 周期性行业跟踪

#### 上游资源（煤炭、有色金属）

- **核心逻辑**：价格驱动盈利，关注大宗商品价格。
- **跟踪指标**：PPI生产资料分项、大宗商品价格指数、港口库存。
- **数据源**：海关总署（进出口数据）、行业协会月报、期货交易所库存。
- **关键信号**：价格突破前高+库存低位=景气上行；价格高位+库存累积=景气见顶。

#### 中游制造（机械、化工）

- **核心逻辑**：产能利用率和订单决定盈利。
- **跟踪指标**：产能利用率、新接订单、毛利率变化。
- **数据源**：上市公司月度经营数据、行业协会统计。
- **关键信号**：产能利用率>80%+订单增长=景气向上；产能利用率<70%+价格战=景气向下。

#### 下游消费（食品饮料、家电）

- **核心逻辑**：需求驱动，关注终端动销和居民收入。
- **跟踪指标**：渠道库存、终端价格、消费者信心指数。
- **数据源**：渠道调研、上市公司经销商会议纪要。
- **关键信号**：库存低位+提价成功=景气向上；库存高位+促销频繁=景气承压。

### 成长型行业跟踪

#### TMT（科技、媒体、通信）

- **核心逻辑**：技术迭代和产品创新驱动，关注渗透率变化。
- **跟踪指标**：新产品销量、渗透率、技术突破进展。
- **数据源**：IDC、Gartner等研究机构报告，上市公司产品发布。
- **关键信号**：渗透率从10%向50%快速提升=高景气；渗透率>50%增速放缓=景气见顶。

#### 医药行业

- **核心逻辑**：政策驱动（集采、医保谈判），关注创新药管线。
- **跟踪指标**：集采中标情况、研发管线进展、医院采购量。
- **数据源**：国家医保局、CDE（药品审评中心）、上市公司公告。
- **关键信号**：集采后销量增长弥补价格下降=景气恢复；创新药获批上市=新增长点。

### 防御型行业跟踪

#### 公用事业（电力、水务）

- **核心逻辑**：稳定现金流，关注政策调价和产能扩张。
- **跟踪指标**：用电量增速、电价调整政策、产能利用率。
- **数据源**：国家能源局、上市公司公告。
- **关键信号**：用电量稳定增长+电价上调=盈利改善；产能过剩+电价下调=盈利承压。

#### 交通运输

- **核心逻辑**：经济活动的"晴雨表"，关注货运量和客运量。
- **跟踪指标**：货运量、集装箱吞吐量、航运运价指数。
- **数据源**：交通运输部、海关总署、波罗的海交易所。
- **关键信号**：货运量增长+运价上涨=经济活跃；货运量下滑+运价下跌=经济放缓。

## 九、行业轮动规律

### 经济周期中的行业轮动

| 周期阶段 | 领先行业 | 同步行业 | 滞后行业 |
|---------|---------|---------|---------|
| 复苏初期 | 金融、地产、汽车 | 有色金属、钢铁 | 消费、医药 |
| 复苏中期 | 可选消费、科技 | 中游制造 | 防御行业 |
| 过热期 | 资源、能源 | 周期行业 | 消费、医药 |
| 滞胀期 | 现金、短债 | 防御行业 | 周期、成长 |
| 衰退期 | 债券、公用事业 | 必选消费 | 周期、金融 |

### 政策驱动轮动

- **产业政策**：新能源补贴、半导体扶持、AI发展规划等直接改变行业预期。
- **财政政策**：基建投资加码利好建筑、建材、机械；减税降费利好消费。
- **货币政策**：降准降息利好金融、地产；收紧利好银行净息差。
- **监管政策**：行业整顿（如互联网反垄断、教培双减）改变行业格局。

### 技术驱动轮动

- **渗透率曲线**：新产品从1%到50%渗透率的过程是成长股的黄金期。
- **技术突破**：新技术商业化（如AI、量子计算）可能催生新行业。
- **国产替代**：政策推动下，国产化率提升带来行业机会。

### 资金流向与轮动

- **北向资金**：外资偏好消费、金融龙头，其流向反映市场情绪。
- **融资余额**：杠杆资金增加表明市场情绪升温。
- **ETF资金流向**：行业ETF资金流入流出反映机构对行业的看法变化。

## 十、实操案例分析

### 案例：新能源车行业跟踪

1. **数据收集**：每月关注中汽协销量数据、动力电池装机量、充电桩建设。
2. **景气判断**：2023年渗透率突破30%，增速仍快，景气向上。
3. **估值分析**：龙头企业PE处于历史中位数，估值合理。
4. **投资决策**：通过新能源车ETF配置，设止盈线（PE>历史70%分位）。
5. **跟踪调整**：2024年渗透率接近40%，增速放缓，逐步减仓。

### 案例：半导体行业跟踪

1. **数据收集**：关注全球半导体销售额、国产替代政策、下游手机/PC出货。
2. **景气判断**：2023年全球半导体周期触底，2024年进入复苏期。
3. **细分选择**：设备、材料国产化率低，增长空间大，优于设计环节。
4. **投资决策**：通过半导体ETF布局，关注估值分位。
5. **风险控制**：美国出口管制政策变化可能影响行业，设止损线。

## 十一、常见误区与避坑

### 数据解读误区

- **只看同比不看环比**：同比数据可能受基数影响，环比更能反映短期趋势。
- **忽视季节性**：某些行业数据有明显季节性，如白酒的Q4旺季。
- **混淆龙头与行业**：行业数据可能被龙头公司扭曲，需关注整体情况。

### 投资决策误区

- **追高买入**：行业景气高点时估值往往也高，追高风险大。
- **忽视估值**：只看景气不看估值，可能买在山顶。
- **过度集中**：单一行业配置过高，行业下行时损失惨重。
- **频繁交易**：行业轮动以季度计，频繁交易增加成本和错误率。

### 工具使用误区

- **过度依赖单一数据源**：多个数据源交叉验证更可靠。
- **忽视数据质量**：非官方数据可能不准确，需核实来源。
- **过度解读短期波动**：行业景气变化以季度计，月度波动可能是噪音。

## 十二、A股行业轮动历史复盘

### 2005-2024年行业轮动

| 时期 | 领先行业 | 背景 | 特征 |
|------|---------|------|------|
| 2005-2007 | 金融、地产、有色 | 股权分置改革+经济高速增长 | 大盘蓝筹主导 |
| 2008 | 防御、债券 | 全球金融危机 | 避险为主 |
| 2009-2010 | 基建、地产、汽车 | 四万亿刺激 | 政策驱动 |
| 2011-2013 | 消费、医药 | 经济放缓+政策收紧 | 防御为王 |
| 2014-2015 | TMT、金融 | 杠杆牛市+改革预期 | 成长主导 |
| 2016-2017 | 周期、消费 | 供给侧改革+经济回暖 | 价值回归 |
| 2018 | 防御、债券 | 去杠杆+中美贸易摩擦 | 避险为主 |
| 2019-2020 | 消费、科技 | 疫情后宽松+科技牛 | 核心资产 |
| 2021 | 资源、新能源 | 经济强+通胀升 | 周期+成长 |
| 2022-2023 | 红利、债券 | 地产风险+经济放缓 | 防御+确定性 |
| 2024 | 红利、科技 | 政策宽松+AI主题 | 稳健+成长 |

### 轮动规律总结

| 规律 | 说明 |
|------|------|
| 政策驱动 | A股市场对政策变化敏感，政策转向往往先于经济数据 |
| 盈利周期 | 企业盈利变化滞后于经济周期，但领先于市场预期调整 |
| 估值周期 | 估值扩张与压缩周期叠加，放大市场波动 |
| 情绪周期 | 散户市场情绪容易极端化，追涨杀跌现象明显 |

### 实操建议

| 建议 | 说明 |
|------|------|
| 不追热点 | 行业轮动以季度计，追热点往往买在高点 |
| 提前布局 | 关注景气拐点信号，提前布局 |
| 分散配置 | 不押注单一行业，分散风险 |
| 长期视角 | 行业轮动是常态，保持长期视角 |

### 轮动操作要点

| 要点 | 说明 |

### 常见轮动错误

| 错误 | 表现 | 后果 | 纠正 |
|------|------|------|------|
| 追涨杀跌 | 行业高点追入 | 亏损严重 | 不追热点，提前布局 |

| 忽视估值 | 只看景气不看估值 | 买在山顶 | 景气+估值综合判断 |

## 十四、行业轮动风险控制

### 风控要点

| 要点 | 说明 |
|------|------|
| 仓位管理 | 单一行业配置不超过30%，避免过度集中 |
| 止盈纪律 | 行业估值进入历史70%分位以上时逐步止盈 |
| 止损纪律 | 行业景气拐点确认时及时止损 |
| 分散配置 | 跨行业、跨风格分散，降低单一行业风险 |

### 常见轮动风险

| 风险类型 | 说明 | 应对 |
|----------|------|------|
| 政策风险 | 产业政策突然转向 | 关注政策信号，提前调整 |
| 周期风险 | 行业景气见顶回落 | 关注领先指标，提前布局 |
| 估值风险 | 行业估值过高 | 估值+景气综合判断 |
| 情绪风险 | 市场情绪极端化 | 逆向思维，不追涨杀跌 |
