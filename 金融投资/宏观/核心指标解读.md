# 核心指标解读

> 新闻里的 GDP、CPI、M2 到底啥意思、和你的钱有什么关系？本文逐一翻译成人话。

## 一、增长类

- **GDP（国内生产总值）**：一国一段时间内生产的全部最终商品服务价值。看**同比**（今年 vs 去年同季）和**环比**（本季 vs 上季折年率）。
  - 对个人：GDP 强 → 企业盈利预期好 → 股市情绪偏暖；弱 → 政策可能加码宽松。
- **PMI（采购经理指数）**：荣枯线 50。>50 扩张、<50 收缩，是 GDP 的先行指标（月初就出）。
  - 对个人：连续低于 50 提示经济偏冷，权益谨慎、债券/黄金占优。

## 二、价格类

- **CPI（居民消费价格）**：物价总水平，衡量通胀。食品（猪价）权重影响大，波动有季节噪音。
  - 对个人：CPI 高 → 央行难大放水、储蓄实际利率下降；低/通缩 → 可能降息降准。
- **PPI（工业生产者出厂价格）**：工业品出厂价，上游冷暖。PPI 向 CPI 有传导但不完全。
  - 对个人：PPI 负 → 企业利润承压、周期股弱；转正回升 → 顺周期板块改善。

## 三、货币与信用类

- **M2（广义货币）**：M1（活钱）+ 定存等。M2 增速看"钱多不多"。
  - M1-M2 剪刀差：M1 快 → 企业和居民更愿意花/投（活化）；反之钱趴在定期（信心弱）。
- **社融（社会融资规模）**：实体经济从金融体系拿到的钱总量，最贴近"真实信用扩张"。
  - 对个人：社融回升 → 经济动能改善信号；持续塌方 → 权益承压、政策可能出手。
- **LPR / 政策利率**：央行引导的贷款定价基准（见 ../房产/房贷选择）。降 → 宽松、利好资产价格；升 → 收紧。

## 四、对外类

- **汇率（USD/CNY）**：人民币升贬值。贬值利好出口、利空进口与海外消费；升值反之。
  - 对个人：贬值期海外资产/黄金有对冲意味；留学换汇趁升值。
- **外汇储备 / 进出口**：顺差支撑汇率与外储；贸易摩擦影响相关行业。

## 五、怎么用（普通人版）

1. **看方向不看单点**：连降的 CPI/PPI + 弱 PMI → 宽松可期，债券/红利占优；回升 → 周期/成长弹性大。
2. **信用比货币更关键**：M2 涨但社融不涨 = 钱在银行空转；社融真起来才是信用扩张。
3. **别精确择时**：用宏观判断大类倾向（股/债/商品比例），而不是猜明天涨跌。
4. **预期差**：市场已 price in 的利好，落地反易跌；超预期才动。

## 六、GDP 详解

| 要素 | 说明 |
|------|------|
| 定义 | 一定时期内（通常为一年或一季度）一国境内生产的全部最终商品和服务的市场价值总和 |
| 计算方式 | 生产法（各行业增加值之和）/ 支出法（消费 + 投资 + 政府支出 + 净出口） |
| 发布频率 | **季度**（初值、修正值、终值），年度汇算 |
| 发布机构 | 国家统计局 |

### 重要细分指标

| 指标 | 含义 | 投资意义 |
|------|------|----------|
| GDP 同比 | 与去年同期比较，反映增长趋势 | 同比 >5% 经济偏热，<4% 偏冷 |
| GDP 环比折年率 | 与上季度比较并年化 | 环比连续两季负增长 = 技术性衰退 |
| 人均 GDP | GDP / 总人口 | 衡量居民生活水平，人均超过 1 万美元为中等收入 |
| 最终消费贡献率 | 消费对 GDP 增长的拉动 | 消费驱动型经济更健康可持续 |
| 固定资产投资 | 基建 + 制造业 + 房地产投资 | 基建投资反映财政力度，房地产投资反映行业景气 |

> 来源：国家统计局《国内生产总值核算方法》

## 七、CPI 详解

| 要素 | 说明 |
|------|------|
| 定义 | 居民消费价格指数，衡量一篮子消费品和服务价格变动 |
| 发布频率 | **月度**，通常次月 9-12 日发布 |
| 发布机构 | 国家统计局 |
| 权重构成 | 食品烟酒约 28%、居住约 23%、交通通信约 13%、教育文化娱乐约 11% |

### CPI 解读要点

| 情形 | 经济含义 | 政策影响 |
|------|----------|----------|
| CPI > 3%（温和通胀） | 物价上涨偏快 | 央行可能收紧货币 |
| CPI 1%-2%（温和通胀） | 经济正常运行 | 政策中性 |
| CPI < 1%（低通胀） | 需求不足 | 可能降息降准刺激 |
| CPI < 0（通缩） | 经济衰退信号 | 大幅宽松预期增强 |

- **核心 CPI**：剔除食品和能源（波动大），更能反映真实通胀趋势。
- **猪周期影响**：猪肉价格波动大，单独看 CPI 可能被猪价"绑架"，需关注核心 CPI。
- **中美 CPI 对比**：中国 CPI 中食品权重高，美国 CPI 中住房权重高，直接比较需注意结构差异。

> 来源：国家统计局《居民消费价格指数编制方案》

## 八、PPI 详解

| 要素 | 说明 |
|------|------|
| 定义 | 工业生产者出厂价格指数，衡量工业品出厂价格变动 |
| 发布频率 | **月度**，与 CPI 同日发布 |
| 发布机构 | 国家统计局 |

### PPI 与投资

| PPI 走势 | 经济含义 | 行业影响 |
|----------|----------|----------|
| PPI 持续正增长 | 工业品需求旺盛，企业盈利改善 | 周期股（钢铁、煤炭、化工）受益 |
| PPI 持续负增长 | 工业品需求疲软，企业利润承压 | 周期股承压，政策可能托底 |
| PPI-CPI 剪刀差扩大 | 上游涨价未传导至下游 | 上游企业利润好、下游利润被挤压 |
| PPI-CPI 剪刀差收窄 | 上游成本压力缓解 | 下游企业利润改善 |

- **传导链条**：PPI → 工业品出厂价 → 企业利润 → 财税收入 → 就业与消费。
- **领先指标**：PPI 转正通常领先企业盈利改善 1-2 个季度。

> 来源：国家统计局《工业生产者出厂价格指数编制方法》

## 九、PMI 详解

| 要素 | 说明 |
|------|------|
| 定义 | 采购经理指数，通过对制造业/非制造业采购经理问卷调查编制 |
| 荣枯线 | **50**，高于 50 扩张，低于 50 收缩 |
| 发布频率 | **月度**，通常月末或次月 1 日发布 |
| 发布机构 | 国家统计局（官方）+ 财新/Markit（民间） |

### PMI 分项解读

| 分项 | 含义 | 关注点 |
|------|------|--------|
| 新订单 | 未来需求 | 领先指标，新订单 >50 预示景气向上 |
| 新出口订单 | 外需 | 反映出口企业接单情况 |
| 生产 | 当前产出 | >50 产出扩张 |
| 原材料库存 | 补库意愿 | 主动补库 → 经济复苏 |
| 产成品库存 | 销售情况 | 被动累库 → 需求走弱 |
| 就业 | 劳动力需求 | 长期低于 50 预示就业压力 |
| 价格 | 原材料价格 | 反映通胀压力 |

- **官方 vs 财新**：官方 PMI 样本偏大中型企业，财新 PMI 样本偏中小企业；两者背离时关注中小企业状况。
- **季节性**：春节前后 PMI 波动大，需看同比变化而非绝对值。

> 来源：国家统计局、财新传媒

## 十、M2 详解

| 要素 | 说明 |
|------|------|
| 定义 | 广义货币供应量，包括 M0（流通中现金）+ 企业活期存款（M1）+ 定期存款 + 居民储蓄存款等 |
| 发布频率 | **月度**，通常次月 10-15 日发布 |
| 发布机构 | 中国人民银行 |

### M2 增速解读

| M2 增速 | 经济含义 | 政策信号 |
|---------|----------|----------|
| >10%（显著高于 GDP 增速） | 货币宽松，流动性充裕 | 利好资产价格 |
| 8%-10%（与 GDP+通胀匹配） | 中性 | 政策平稳 |
| <8%（低于 GDP 增速） | 货币偏紧 | 利空资产价格 |

### M1-M2 剪刀差

- **M1 增速 > M2 增速**（剪刀差为正）：企业活期存款增加，资金"活化"，经济活跃度上升。
- **M1 增速 < M2 增速**（剪刀差为负）：资金"沉淀"在定期存款，企业和居民投资消费意愿弱。
- **投资信号**：M1-M2 剪刀差由负转正，通常预示股市和房市回暖。

> 来源：中国人民银行《货币供应量统计与公布办法》

## 十一、社融详解

| 要素 | 说明 |
|------|------|
| 定义 | 社会融资规模，实体经济从金融体系获得的资金总量 |
| 发布频率 | **月度**，通常次月 10-15 日发布 |
| 发布机构 | 中国人民银行 |

### 社融构成

| 分项 | 说明 | 占比趋势 |
|------|------|----------|
| 人民币贷款 | 最大分项，约 60% | 传统信贷仍是主力 |
| 企业债券融资 | 企业直接融资 | 占比约 10% |
| 政府债券 | 国债 + 地方专项债 | 财政发力时占比上升 |
| 委托贷款/信托贷款 | 表外融资 | 监管趋严后占比下降 |
| 股票融资 | IPO + 增发 | 占比小但反映资本市场活跃度 |

### 社融解读要点

| 情形 | 经济含义 | 投资信号 |
|------|----------|----------|
| 社融存量增速回升 | 信用扩张，经济回暖 | 利好股市、利空债市 |
| 社融存量增速持续下行 | 信用收缩，经济走弱 | 利好债市、利空股市 |
| 社融增速-M2 增速差 | 反映资金"脱虚向实"程度 | 差值扩大 → 资金流入实体经济 |

- **比 M2 更准确**：社融包含表外融资、直接融资等 M2 未覆盖的信用渠道。
- **预期差驱动市场**：社融数据超/低于预期，往往引发股债短期波动。

> 来源：中国人民银行《社会融资规模统计监测指标》

## 十二、失业率详解

| 指标 | 定义 | 发布频率 | 关注点 |
|------|------|----------|--------|
| 城镇调查失业率 | 抽样调查城镇常住人口中失业人数占比 | 月度 | 官方主要指标 |
| 16-24 岁青年失业率 | 16-24 岁劳动力中失业占比 | 月度（按在校否分） | 反映青年就业压力 |
| 城镇登记失业率 | 主动登记的失业人数 / 城镇从业人数 | 季度 | 参考价值有限 |

### 失业率与投资

| 失业率走势 | 经济含义 | 政策影响 |
|------------|----------|----------|
| 失业率持续下降 | 就业改善，消费有望回升 | 政策可能中性或收紧 |
| 失业率上升 | 经济走弱，消费承压 | 政策宽松预期增强 |
| 青年失业率高企 | 结构性就业问题 | 人才密集型行业受压 |

> 来源：国家统计局《劳动力调查统计制度》

## 十三、汇率详解

| 要素 | 说明 |
|------|------|
| 定义 | 一国货币兑换另一国货币的比率（中国关注 USD/CNY） |
| 发布频率 | 每日中间价（央行公布），市场交易价实时变动 |
| 影响因素 | 中美利差、贸易顺逆差、资本流动、央行干预 |

### 汇率变动影响

| 情形 | 对投资的影响 |
|------|--------------|
| 人民币贬值 | 利好出口企业、利空进口企业；外资可能流出 A 股；黄金/美元资产有对冲价值 |
| 人民币升值 | 利好进口企业、外资流入 A 股；海外消费/留学成本降低 |
| 汇率大幅波动 | 增加不确定性，企业汇率风险管理需求上升 |

- **央行工具**：逆周期因子、离岸央票、外汇存款准备金率、远期售汇风险准备金率。
- **"7" 的心理关口**：2019、2022、2023 年多次破 7，市场已逐渐适应。

> 来源：中国人民银行、国家外汇管理局

## 十四、数据日历与实战应用

### 每月必看数据

| 时间 | 数据 | 投资意义 |
|------|------|----------|
| 月末 | 制造业 PMI | 经济先行信号 |
| 次月 9-12 日 | CPI / PPI | 通胀与企业利润 |
| 次月 10-15 日 | M2 / 社融 / 信贷 | 信用扩张/收缩 |
| 次月 15 日左右 | 工业增加值 / 固投 / 消费 | 经济三驾马车 |
| 次月 16-18 日 | 70 城房价 | 房地产市场温度 |

### 宏观数据驱动资产配置

| 宏观环境 | 特征 | 配置倾向 |
|----------|------|----------|
| 经济复苏 + 通胀温和 | PMI 回升、CPI 适中、社融放量 | 权益 > 债券 > 商品 |
| 经济过热 + 通胀上行 | CPI >3%、PPI 高企、PMI >55 | 商品 > 权益 > 债券 |
| 经济放缓 + 通胀下行 | PMI <50、CPI 下行、社融萎缩 | 债券 > 权益 > 商品 |
| 经济衰退 + 通缩风险 | GDP 负增长、CPI <0、失业率上升 | 现金/短债 > 债券 > 权益 |

> 来源：国家统计局、中国人民银行、海关总署定期发布数据
