# 三星（Samsung）

> 韩国"财阀"式综合巨头的核心旗舰：全球最大的半导体与显示面板厂商之一、安卓手机第一品牌，横跨存储、芯片代工与消费电子。

## 一、公司简介与地位

- **成立时间**：1938 年成立，1969 年进入电子业，总部位于韩国水原（Suwon）与首尔；三星集团旗下最核心的上市公司为三星电子（Samsung Electronics）。
- **市值**：2024-2025 年市值约 4000-5000 亿美元，是韩国市值第一的公司，占韩国股市权重极大。
- **营收与利润**：2024 年三星电子营收约 300 万亿韩元（约 2200 亿美元），营业利润约 30-35 万亿韩元（约 250 亿美元），利润随存储芯片周期剧烈波动。
- **全球地位**：全球存储芯片（DRAM/NAND）市占率第一（约四成），智能手机出货量全球第一，OLED 显示面板全球第一，代工业务全球第二。
- **一句话概括**：韩国经济的"顶梁柱"，半导体周期与手机市场的双重风向标。
- **集团背景**：三星集团旗下还有重工、建筑、保险、物产等上市公司，三星电子是其中的利润核心，占集团净利大头。
- **历史转折**：1980 年代切入半导体后持续逆周期投资，1990-2000 年代超越日本厂商成为存储霸主，奠定今天的地位。

## 二、核心业务与收入结构

| 业务板块 | 大致收入占比 | 说明 |
| --- | --- | --- |
| 半导体（存储、代工、系统 LSI） | 约 40-45% | 利润波动最大的部门，存储涨价时贡献大部分利润 |
| 移动设备（Galaxy 手机、平板、可穿戴） | 约 25-30% | 全球出货量第一，旗舰 S 系列与折叠屏是利润主力 |
| 显示面板（SDC，OLED） | 约 8-10% | 手机 OLED 几乎垄断，供苹果等客户 |
| 家电与消费电子（电视、冰箱等） | 约 10% | 电视全球市占率常年第一 |
| 其他（网络设备、数字解决方案等） | 约 5-10% | 含 5G 设备与显示屏等 |

- **近年增长点**：HBM（高带宽内存）借 AI 热潮成为新爆点，向英伟达等供货；折叠屏手机维持高端差异化；代工追赶台积电。
- **收入结构趋势**：半导体占比随存储周期在 30-50% 之间摆动，是公司利润的"周期发动机"。
- **分部利润观察**：存储景气时半导体部门贡献公司八成以上利润，存储低迷时则由手机与家电部门"兜底"，分部对冲是集团模式的优点。

## 三、商业模式与护城河

- **怎么赚钱**：以规模制造+技术领先卖存储芯片（周期品，量价齐升时暴赚），以品牌与渠道卖手机、电视等高毛利消费电子，再以垂直整合摊薄成本。
- **护城河一：存储霸主**：DRAM/NAND 全球市占率第一，先进制程领先，周期底部敢逆势扩产挤压对手（历史上挤垮多家日企）。
- **护城河二：垂直整合**：从芯片、面板到整机的全产业链自制，成本、供应与新品节奏全面可控。
- **护城河三：品牌与渠道**：全球品牌价值前十，渠道覆盖全球几乎所有国家，折叠屏、高端电视的品牌认知领先。
- **护城河四：研发投入**：年研发投入超 250 亿美元（全球前五），专利储备深厚。
- **护城河五：集团协同**：三星集团横跨金融、重工、化工等，形成"财阀"生态与风险分担能力。
- **护城河六：制造与良率**：数十年积累的晶圆制造经验与良率管理能力，是新进入者（包括中国厂商）短期难以跨越的工程壁垒。
- **经营哲学**："市场不好时对手收缩、它扩产"的反周期打法，历史上多次靠此挤垮对手、在复苏期吃下最大份额。

## 四、竞争格局

| 竞争对手 | 定位 | 相对三星的差异 |
| --- | --- | --- |
| SK 海力士 | 存储第二 | 在 HBM 上反超三星，抢先供货英伟达 |
| 美光 | 存储第三 | 规模较小，跟随周期 |
| 台积电 | 代工第一 | 三星代工长期居第二，先进制程良率与客户信任有差距 |
| 苹果 | 高端手机 | 三星手机最大利润来自安卓旗舰，苹果在高端挤压其利润空间 |
| 华为/小米/OPPO/vivo | 中国手机阵营 | 出货量竞争激烈，尤其在中低端与折叠屏市场 |
| 京东方等中国面板厂 | 显示面板 | 液晶面板份额被中国厂商蚕食，三星转向 OLED 高端 |

- **竞争要点**：三星的挑战是多线作战——存储上与 SK 海力士在 HBM 正面对决、代工上追赶台积电、手机上防御中国厂商高端化，任何一线失守都会影响集团整体估值。
- **份额趋势**：存储份额相对稳定，但中国存储厂商（长江存储、长鑫存储）在成熟制程持续扩产，长期价格压力存在。

## 五、产业链位置

- **上游**：光刻机（ASML，EUV 独家）、硅片、半导体材料与设备（日本、美国供应商）；存储与代工产能自建为主。
- **中游**：自建晶圆厂与面板厂（韩国为主，中国、美国、越南设厂布局），是"设备买进、芯片卖出"的典型制造商。
- **下游**：存储芯片卖给手机/PC/服务器厂商（苹果、英伟达、云厂商等）；手机直面全球消费者；OLED 面板供苹果等手机厂商。
- **行业地位**：处于"设备买家 + 芯片/面板卖家"的双重位置，对上游设备议价能力强，对下游有周期定价权；同时是苹果供应链中少数能"反向议价"的巨头。

## 六、财务与增长指标（约数）

| 指标 | 数值（2024-2025 财年） |
| --- | --- |
| 营收 | 约 300 万亿韩元（约 2200 亿美元） |
| 营业利润 | 约 30-35 万亿韩元（约 250 亿美元） |
| 营业利润率 | 约 10%，随存储周期在 0-20% 间大幅波动 |
| 存储市占率 | DRAM 约 40-45%，NAND 约 35-40% |
| 手机出货量 | 约 2.5 亿部/年（全球第一） |
| 研发投入 | 约 30-35 万亿韩元/年（约 250 亿美元） |
| 半导体资本开支 | 每年数百亿美元级，全球前二 |

- **财务特点**：利润高度依赖存储周期（2023 年存储暴跌时利润近乎归零，2024-2025 年 AI 带动 HBM 后大幅回升），是典型的强周期股。
- **资产负债表**：净现金充裕、负债率低，能支撑逆周期扩产的巨额资本开支（每年数百亿美元）。

## 七、风险与争议

- **周期风险**：存储芯片价格周期性强，景气下行时利润可骤降八成以上，股价随之大幅波动。
- **代工差距**：与台积电的先进制程差距（良率、客户订单）未缩小，3nm 以下竞争吃力。
- **地缘政治**：韩国夹在中美科技博弈之间，美国芯片补贴附加条件、中国市场份额流失（对华存储出口受限）双重承压。
- **法律与治理**：会长李在镕多次卷入司法案件（行贿、合并争议），财阀治理结构长期受批评；劳工权益与工会问题引发争议。
- **中国竞争**：存储与面板领域中国产能扩张（长鑫、长江存储、京东方），长期价格压力持续。
- **罢工与劳资**：2024 年半导体部门爆发罕见的大规模罢工，劳资关系紧张对"无工会文化"的韩国财阀模式构成新挑战。

## 八、对我们的意义

- **消费视角**：Galaxy 手机是全球安卓高端代表，折叠屏至今体验领先；选购时可对比国产旗舰的性价比与生态；三星电视、存储（移动硬盘/内存条）在消费市场口碑扎实。
- **就业视角**：三星系是韩国就业与工程师培养的"黄埔军校"，中国电子产业链（面板、存储、手机代工）大量人才与工艺路线源自三星模式；存储/半导体制程工程师是薪酬高地。
- **投资视角**（不构成建议）：三星是理解"强周期股"的标准教材——利润与股价跟着存储价格走，适合学习周期判断而非"买入持有"；关注 HBM 份额与代工进展是核心变量。
- **产业视角**：它同时是观察"AI 硬件周期"与"中国半导体追赶"两条主线的交叉点，存储涨价与 HBM 出货是行业景气度的先行指标。
