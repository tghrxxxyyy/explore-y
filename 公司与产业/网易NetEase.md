# 网易（NetEase）
> 中国最"低调且赚钱"的互联网公司之一，靠自研游戏贡献八成以上收入，毛利率长期维持在 60% 以上，以"精品自研 + 长线运营"对抗腾讯的渠道与规模优势。

## 一、公司概况

### 1.1 基本信息

| 项目 | 内容 |
| --- | --- |
| 公司全称 | 网易公司（NetEase, Inc.） |
| 成立时间 | 1997 年 6 月（广州） |
| 总部所在地 | 中国杭州（主要办公地；起家于广州） |
| 创始人 | 丁磊（现任 CEO 兼董事，1997 年创立至今仍在任） |
| 上市情况 | 2000 年 6 月美国纳斯达克上市（NTES）；2020 年 6 月香港二次上市（09999） |
| 最新市值 | 港股约 5,790 亿港元（2026 年 9 月）；美股约 820–880 亿美元区间 |
| 最新营收 | 2025 年净收入约 1,126 亿元人民币，同比增长约 7% |
| 最新利润 | 2025 年归母净利润约 337 亿元，同比增长约 14% |
| 毛利率 | 约 64.3%（2025 年） |
| 核心业务 | 游戏及相关增值服务、有道、网易云音乐、创新及其他业务（严选、传媒等） |

> 数据口径：除特别说明外，均为**人民币/模拟人民币口径的近似值**、**2025 自然财年**（截至 2025 年 12 月 31 日）。网易在美国与香港两地上市，按自然年财年披露，官方以美元与人民币双口径列示，部分数据源以港元列示，**本文数字为折算后的约数**。

### 1.2 地位速览

- **游戏地位**：中国第二大游戏公司（仅次于腾讯），是全球游戏收入第一梯队厂商。
- **收入结构**：2025 年游戏及相关增值服务收入占比约 81.8%，是绝对的现金牛。
- **毛利率**：2025 年毛利率约 64.3%，远高于腾讯、阿里、京东等综合互联网公司。
- **净利率**：2025 年净利率约 30%，盈利能力在大型互联网公司中位居前列。
- **海外产品**：《燕云十六声》（Where Winds Meet）累计玩家超 8,000 万，《漫威争锋》（Marvel Rivals）全球影响力扩大。
- **股东回报**：2025 年分红支付率约 40.7%，每股派息约 2.96 美元/ADS。
- **旗下上市子公司**：有道（NYSE: DAO）、网易云音乐（HKEX: 9899）。

### 1.3 为什么网易值得研究

- 它是**"精品自研 + 长线运营"模式的最佳样本**：不靠渠道垄断，靠产品品质与用户口碑。
- 它是**中国游戏出海的另一条路径**：腾讯靠收购全球工作室，网易靠自研产品（《燕云十六声》《漫威争锋》）直接出海。
- 它是**"少而精"的组织典范**：员工规模远小于腾讯、阿里，但人均收入与利润极高。
- 它是**创始人长期在任的样本**：丁磊从 1997 年至今一直掌舵，公司战略相对稳定。
- 它是**多元化布局的样本**：游戏、教育（有道）、音乐、电商（严选）、传媒等并行。

### 2.2 阶段划分

**第一阶段（1997–2002）：门户与邮箱时代**
- 网易以免费邮箱与门户网站起家，是中国最早的互联网公司之一。
- 2000 年上市后遭遇互联网泡沫，股价一度暴跌。
- 2001 年转型游戏，找到真正的商业模式。

**第二阶段（2003–2012）：端游黄金期**
- 《大话西游》《梦幻西游》成为长期现金牛，端游时代建立基础。
- 2009 年代理《魔兽世界》，与暴雪建立长期合作。
- 门户与邮箱业务逐步边缘化。

**第三阶段（2013–2018）：手游与多元化转型**
- 2013 年推出网易云音乐，2016 年《阴阳师》成为现象级手游。
- 有道、严选、传媒等业务布局成型。
- 从单一游戏公司向多元化互联网公司转型。

**第四阶段（2019 年至今）：出海与精品化**
- 《永劫无间》《燕云十六声》《漫威争锋》等产品验证自研与出海能力。
- 暴雪合作经历终止与恢复，代理业务波动。
- AI 全面融入研发与运营，毛利率与效率持续提升。

### 2.3 关键决策复盘

| 决策 | 当时的选择 | 事后评价 |
| --- | --- | --- |
| 2001 年转型游戏 | 从门户转向网游 | 极其正确，奠定二十年利润基础 |
| 坚持自研 | 不做纯代理发行 | 正确，形成产品能力与 IP 资产 |
| 代理《魔兽世界》 | 与暴雪长期合作 | 双刃剑，2023 年合作中断冲击业绩 |
| 布局云音乐/有道/严选 | 多元化扩展 | 部分成功，游戏仍是绝对主体 |
| 重金投入出海自研 | 用产品而非收购出海 | 初步验证（燕云、漫威争锋） |
| 全面 AI 化 | 把 AI 嵌入研发与玩法 | 提升效率，但短期难量化 |

## 四、商业模式与盈利来源

### 4.1 赚钱逻辑

- **第一层：自研游戏内购**。玩家购买虚拟道具、皮肤、抽卡等，边际成本极低，毛利率高。
- **第二层：长线运营复利**。经典 IP（梦幻西游系列）持续更新内容，收入稳定、生命周期长。
- **第三层：代理游戏分成**。代理暴雪游戏，收入分成稳定。
- **第四层：音乐与教育的订阅/广告**。云音乐会员、有道课程与广告。
- **第五层：电商与传媒**。严选自营商品、传媒广告。
- **第六层：海外发行**。自研产品直接出海，获取全球用户收入。

### 4.2 收入与成本结构（2025 年）

| 项目 | 数值 | 说明 |
| --- | --- | --- |
| 净收入 | 约 1,126 亿元 | 同比约 +7% |
| 毛利 | 约 724 亿元 | 毛利率约 64.3% |
| 营业利润 | 约 358 亿元 | 营业利润率约 31.8% |
| 归母净利润 | 约 337 亿元 | 净利率约 30% |
| 总营业费用 | — | 增速约 10.9%（Q4 口径） |

- **高毛利率的来源**：自研游戏收入占比高，虚拟道具边际成本极低。
- **费用结构**：研发费用（游戏研发投入大）、销售费用（新游宣发）、管理费用。
- **利润弹性**：新游爆款或代理业务变化会显著影响利润。

### 4.3 与腾讯游戏的模式对照

| 维度 | 网易 | 腾讯 |
| --- | --- | --- |
| 战略 | 精品自研 + 长线运营 | 自研 + 全球投资并购 |
| 渠道 | 依赖自有产品与第三方渠道 | 微信/QQ/应用宝自带渠道 |
| 游戏收入规模 | 国内第二 | 国内第一、全球第一 |
| 出海方式 | 自研产品出海 | 收购 Riot、Supercell 等 |
| 毛利率 | 约 64% | 游戏分部毛利率高，但集团整体低 |
| 组织规模 | 精简 | 庞大 |

- **核心差异**：腾讯靠"流量 + 投资"，网易靠"产品 + 运营"。
- **网易的劣势**：缺乏自有流量入口，新游获客成本高。
- **网易的优势**：产品品质与用户口碑，长线 IP 的生命周期更长。

### 4.4 成本结构

| 成本项 | 特征 |
| --- | --- |
| 游戏研发 | 人力密集、周期长，是最大投入 |
| 内容与版权 | 音乐版权、代理分成 |
| 销售与营销 | 新游上线期宣发投入大 |
| 履约成本 | 电商（严选）等业务的物流成本 |

## 六、竞争格局

### 6.1 中国游戏市场格局（约数）

| 公司 | 国内市场份额（约） | 特点 |
| --- | --- | --- |
| 腾讯 | 约 40% | 社交渠道 + 全球投资并购 |
| 网易 | 约 15% | 精品自研 + 长线运营 |
| 米哈游 | 约 8% | 二次元 + 出海 |
| 三七互娱、世纪华通等 | 各约 3%–5% | 买量型与传奇 IP |
| 字节跳动（游戏） | 约 5% | 发行能力强，自研较弱 |

> 市场份额为机构估算的约数，不同口径差异较大。

### 6.2 主要对手对比

| 对手 | 竞争领域 | 相对网易的差异 |
| --- | --- | --- |
| 腾讯 | 游戏全品类 | 渠道与规模优势，投资版图庞大 |
| 米哈游 | 二次元、出海 | 二次元赛道领先，海外收入占比高 |
| 莉莉丝、叠纸 | 细分赛道 | 各有特色品类 |
| 网易 vs 暴雪 | 代理合作 | 合作关系，也有分成博弈 |
| 腾讯音乐 | 音乐 | 版权与用户规模领先 |
| 好未来、猿辅导 | 教育 | 有道在智能学习与硬件方向差异化 |

### 6.3 竞争格局要点

- **腾讯 vs 网易是主旋律**：两家合计占中国游戏市场约一半份额。
- **网易的差异化在"产品"**：不靠渠道，靠品质与用户运营。
- **米哈游是最大变量**：在二次元与全球化上领先，是网易出海的主要对手。
- **代理业务不稳定**：暴雪合作的终止与恢复说明代理业务存在断档风险。
- **音乐与教育是次要战场**：规模小、竞争激烈，但对生态有补充作用。

### 6.4 竞争焦点

| 战场 | 网易的位置 | 关键变量 |
| --- | --- | --- |
| 端游 IP | 强（梦幻西游系列） | 生命周期延长 |
| 自研手游 | 强 | 新品爆款能力 |
| 出海 | 追赶者 | 《燕云十六声》《漫威争锋》表现 |
| 代理业务 | 稳定 | 与暴雪合作关系 |
| 音乐 | 第二 | 版权与付费率 |
| 教育 | 细分 | 硬件与 AI |

## 七、护城河与核心优势

### 7.1 护城河评估

| 护城河 | 强度 | 说明 |
| --- | --- | --- |
| 自研产品能力 | 极强 | 网易游戏以品质著称，用户口碑好 |
| 长线 IP 资产 | 极强 | 《梦幻西游》系列等运营超 20 年 |
| 高毛利商业模式 | 强 | 毛利率约 64%，净利率约 30% |
| 研发团队稳定性 | 强 | 自研团队规模大、经验深 |
| 出海产品能力 | 中强 | 自研产品直接出海获验证 |
| 现金流与股东回报 | 强 | 持续分红，分红率约 40% |
| 多元化业务 | 中 | 音乐、教育、电商补充生态 |

### 7.2 逐条分析

- **精品自研是根本**：网易不做"买量换皮"的低质产品，而是投入长周期自研，形成产品口碑与 IP 资产。
- **长线运营复利**：《梦幻西游》系列运营超过二十年，仍在贡献稳定收入，这是游戏行业罕见的资产。
- **高毛利的本质**：自研游戏收入占比高，虚拟道具边际成本极低，因此毛利率稳定在 60% 以上。
- **AI 提效**：AI 已全流程融入游戏研发（美术、程序、动画、QA），提升产出效率与内容规模。
- **出海验证**：《燕云十六声》累计玩家超 8,000 万、《漫威争锋》全球走红，证明自研产品具备全球竞争力。
- **组织精简**：员工规模远小于腾讯，人均创收与创利高，决策效率相对高。

### 7.3 护城河的边界

- **缺乏自有流量入口**：网易没有微信、QQ 级别的渠道，新游获客依赖外部投放。
- **代理业务波动**：暴雪合作中断曾造成明显收入缺口。
- **二次元赛道落后**：米哈游在这一高增长赛道领先。
- **海外收入占比仍低**：相比米哈游，网易游戏海外收入占比仍有提升空间。
- **爆款依赖**：新游成功与否对业绩影响大，存在周期性波动。

- **AI 投入的回报**：AI 提效明显，但难以单独量化收入贡献。

## 十五、产业链位置与价值链分配

### 15.1 网易在游戏产业链中的位置

| 环节 | 参与者 | 网易的角色 |
| --- | --- | --- |
| 上游（研发） | 自研工作室、美术外包、音乐外包 | 网易自研为主，外包为辅 |
| 上游（IP） | 自有 IP、授权 IP（漫威等） | 自有 IP 为主，逐步引入授权 |
| 中游（发行/运营） | 网易、渠道平台（应用商店） | 自研自发的研运一体 |
| 下游（玩家） | 国内玩家、海外玩家 | 直接面向全球玩家 |
| 平台 | 安卓应用商店、App Store、Steam 等 | 需支付渠道分成 |

### 15.2 价值链分配特征

| 参与方 | 获得 | 面临的问题 |
| --- | --- | --- |
| 研发团队 | 项目分成、薪资 | 长周期、高不确定性 |
| 渠道平台 | 应用商店分成（约 30%） | 反垄断与"苹果税"争议 |
| 玩家 | 娱乐体验 | 消费机制与沉迷争议 |
| 网易 | 游戏内购收入 | 版号、监管、爆款依赖 |
| 外包供应商 | 美术、音频外包订单 | 价格竞争 |

- **渠道分成是重要成本**：移动游戏在应用商店的分成比例高，直接影响利润率。
- **研运一体的优势**：自研自发可以控制品质与运营节奏，获取更高价值链份额。
- **PC/主机渠道分成较低**：Steam 等的分成比例低于移动应用商店。

### 15.3 与上下游关系

| 关系方 | 合作方式 | 张力 |
| --- | --- | --- |
| 研发工作室 | 内部工作室独立研发 | 资源分配与考核 |
| IP 授权方 | 漫威等授权合作 | 授权费用与创意边界 |
| 渠道平台 | 上架与分发 | 分成比例 |
| 暴雪 | 代理合作 | 分成与续约风险 |
| 音乐版权方 | 版权采购 | 版权成本 |

| 主要品类 | MMORPG、竞技、SLG | MOBA、FPS、全品类 | 二次元开放世界 | 3A 独占 |
| 毛利率 | 约 64% | 高（游戏分部） | 高 | 中 |
| 用户规模 | 国内为主 | 全球最大 | 全球年轻用户 | 主机玩家 |

### 17.3 启示

- **网易的路径最"纯粹"**：不做平台、不靠渠道，靠产品本身取胜。
- **米哈游是最大威胁**：在二次元与全球化上，米哈游比网易更彻底。
- **腾讯的模式最难复制**：腾讯靠社交渠道 + 全球投资形成"规模 + 生态"双壁垒。
- **长线运营是共同追求**：索尼、任天堂、网易都靠长青 IP 获取稳定现金流。

## 小结

- **网易的本质是"精品自研游戏的复利机器"**：靠产品品质与长线运营，把单款游戏的生命周期拉到十年以上。
- **2025 年业绩稳健**：净收入约 1,126 亿元（+约 7%），归母净利润约 337 亿元（+约 14%），毛利率约 64.3%、净利率约 30%。
- **游戏是绝对主体**：游戏及相关增值服务收入占比约 81.8%，非游戏业务规模有限。
- **长线 IP 是核心资产**：《梦幻西游》系列运营超 20 年仍贡献稳定收入，是行业罕见的资产。
- **出海取得突破**：《燕云十六声》累计玩家超 8,000 万，《漫威争锋》全球走红，验证自研产品全球竞争力。
- **AI 全面融入**：从美术、程序、动画到 QA 全流程应用 AI，提升研发效率并解锁新玩法。
- **短板在于流量入口**：缺乏微信、QQ 级别的渠道，新游获客成本高于腾讯；二次元赛道落后于米哈游。
- **对我们的意义**：网易是理解"自研产品力""长线运营复利""高毛利游戏商业模式"与"中国游戏出海路径"的最佳样本之一。
