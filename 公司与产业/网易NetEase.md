# 网易（NetEase）
> 中国最"低调且赚钱"的互联网公司之一，靠自研游戏贡献八成以上收入，毛利率长期维持在 60% 以上，以"精品自研 + 长线运营"对抗腾讯的渠道与规模优势。

## 一、公司概况

### 1.1 基本信息

| 项目 | 内容 |
| --- | --- |
| 公司全称 | 网易公司（NetEase, Inc.） |
| 成立时间 | 1997 年 6 月（广州） |
| 总部所在地 | 中国杭州（主要办公地；起家于广州） |
| 创始人 | 丁磊（现任 CEO 兼董事，1997 年创立至今仍在任） |
| 上市情况 | 2000 年 6 月美国纳斯达克上市（NTES）；2020 年 6 月香港二次上市（09999） |
| 最新市值 | 港股约 5,790 亿港元（2026 年 9 月）；美股约 820–880 亿美元区间 |
| 最新营收 | 2025 年净收入约 1,126 亿元人民币，同比增长约 7% |
| 最新利润 | 2025 年归母净利润约 337 亿元，同比增长约 14% |
| 毛利率 | 约 64.3%（2025 年） |
| 核心业务 | 游戏及相关增值服务、有道、网易云音乐、创新及其他业务（严选、传媒等） |

> 数据口径：除特别说明外，均为**人民币/模拟人民币口径的近似值**、**2025 自然财年**（截至 2025 年 12 月 31 日）。网易在美国与香港两地上市，按自然年财年披露，官方以美元与人民币双口径列示，部分数据源以港元列示，**本文数字为折算后的约数**。

### 1.2 地位速览

- **游戏地位**：中国第二大游戏公司（仅次于腾讯），是全球游戏收入第一梯队厂商。
- **收入结构**：2025 年游戏及相关增值服务收入占比约 81.8%，是绝对的现金牛。
- **毛利率**：2025 年毛利率约 64.3%，远高于腾讯、阿里、京东等综合互联网公司。
- **净利率**：2025 年净利率约 30%，盈利能力在大型互联网公司中位居前列。
- **海外产品**：《燕云十六声》（Where Winds Meet）累计玩家超 8,000 万，《漫威争锋》（Marvel Rivals）全球影响力扩大。
- **股东回报**：2025 年分红支付率约 40.7%，每股派息约 2.96 美元/ADS。
- **旗下上市子公司**：有道（NYSE: DAO）、网易云音乐（HKEX: 9899）。

### 1.3 为什么网易值得研究

- 它是**"精品自研 + 长线运营"模式的最佳样本**：不靠渠道垄断，靠产品品质与用户口碑。
- 它是**中国游戏出海的另一条路径**：腾讯靠收购全球工作室，网易靠自研产品（《燕云十六声》《漫威争锋》）直接出海。
- 它是**"少而精"的组织典范**：员工规模远小于腾讯、阿里，但人均收入与利润极高。
- 它是**创始人长期在任的样本**：丁磊从 1997 年至今一直掌舵，公司战略相对稳定。
- 它是**多元化布局的样本**：游戏、教育（有道）、音乐、电商（严选）、传媒等并行。

### 2.2 阶段划分

**第一阶段（1997–2002）：门户与邮箱时代**
- 网易以免费邮箱与门户网站起家，是中国最早的互联网公司之一。
- 2000 年上市后遭遇互联网泡沫，股价一度暴跌。
- 2001 年转型游戏，找到真正的商业模式。

**第二阶段（2003–2012）：端游黄金期**
- 《大话西游》《梦幻西游》成为长期现金牛，端游时代建立基础。
- 2009 年代理《魔兽世界》，与暴雪建立长期合作。
- 门户与邮箱业务逐步边缘化。

**第三阶段（2013–2018）：手游与多元化转型**
- 2013 年推出网易云音乐，2016 年《阴阳师》成为现象级手游。
- 有道、严选、传媒等业务布局成型。
- 从单一游戏公司向多元化互联网公司转型。

**第四阶段（2019 年至今）：出海与精品化**
- 《永劫无间》《燕云十六声》《漫威争锋》等产品验证自研与出海能力。
- 暴雪合作经历终止与恢复，代理业务波动。
- AI 全面融入研发与运营，毛利率与效率持续提升。

### 2.3 关键决策复盘

| 决策 | 当时的选择 | 事后评价 |
| --- | --- | --- |
| 2001 年转型游戏 | 从门户转向网游 | 极其正确，奠定二十年利润基础 |
| 坚持自研 | 不做纯代理发行 | 正确，形成产品能力与 IP 资产 |
| 代理《魔兽世界》 | 与暴雪长期合作 | 双刃剑，2023 年合作中断冲击业绩 |
| 布局云音乐/有道/严选 | 多元化扩展 | 部分成功，游戏仍是绝对主体 |
| 重金投入出海自研 | 用产品而非收购出海 | 初步验证（燕云、漫威争锋） |
| 全面 AI 化 | 把 AI 嵌入研发与玩法 | 提升效率，但短期难量化 |

## 四、商业模式与盈利来源

### 4.1 赚钱逻辑

- **第一层：自研游戏内购**。玩家购买虚拟道具、皮肤、抽卡等，边际成本极低，毛利率高。
- **第二层：长线运营复利**。经典 IP（梦幻西游系列）持续更新内容，收入稳定、生命周期长。
- **第三层：代理游戏分成**。代理暴雪游戏，收入分成稳定。
- **第四层：音乐与教育的订阅/广告**。云音乐会员、有道课程与广告。
- **第五层：电商与传媒**。严选自营商品、传媒广告。
- **第六层：海外发行**。自研产品直接出海，获取全球用户收入。

### 4.2 收入与成本结构（2025 年）

| 项目 | 数值 | 说明 |
| --- | --- | --- |
| 净收入 | 约 1,126 亿元 | 同比约 +7% |
| 毛利 | 约 724 亿元 | 毛利率约 64.3% |
| 营业利润 | 约 358 亿元 | 营业利润率约 31.8% |
| 归母净利润 | 约 337 亿元 | 净利率约 30% |
| 总营业费用 | — | 增速约 10.9%（Q4 口径） |

- **高毛利率的来源**：自研游戏收入占比高，虚拟道具边际成本极低。
- **费用结构**：研发费用（游戏研发投入大）、销售费用（新游宣发）、管理费用。
- **利润弹性**：新游爆款或代理业务变化会显著影响利润。

### 4.3 与腾讯游戏的模式对照

| 维度 | 网易 | 腾讯 |
| --- | --- | --- |
| 战略 | 精品自研 + 长线运营 | 自研 + 全球投资并购 |
| 渠道 | 依赖自有产品与第三方渠道 | 微信/QQ/应用宝自带渠道 |
| 游戏收入规模 | 国内第二 | 国内第一、全球第一 |
| 出海方式 | 自研产品出海 | 收购 Riot、Supercell 等 |
| 毛利率 | 约 64% | 游戏分部毛利率高，但集团整体低 |
| 组织规模 | 精简 | 庞大 |

- **核心差异**：腾讯靠"流量 + 投资"，网易靠"产品 + 运营"。
- **网易的劣势**：缺乏自有流量入口，新游获客成本高。
- **网易的优势**：产品品质与用户口碑，长线 IP 的生命周期更长。

### 4.4 成本结构

| 成本项 | 特征 |
| --- | --- |
| 游戏研发 | 人力密集、周期长，是最大投入 |
| 内容与版权 | 音乐版权、代理分成 |
| 销售与营销 | 新游上线期宣发投入大 |
| 履约成本 | 电商（严选）等业务的物流成本 |

## 六、竞争格局

### 6.1 中国游戏市场格局（约数）

| 公司 | 国内市场份额（约） | 特点 |
| --- | --- | --- |
| 腾讯 | 约 40% | 社交渠道 + 全球投资并购 |
| 网易 | 约 15% | 精品自研 + 长线运营 |
| 米哈游 | 约 8% | 二次元 + 出海 |
| 三七互娱、世纪华通等 | 各约 3%–5% | 买量型与传奇 IP |
| 字节跳动（游戏） | 约 5% | 发行能力强，自研较弱 |

> 市场份额为机构估算的约数，不同口径差异较大。

### 6.2 主要对手对比

| 对手 | 竞争领域 | 相对网易的差异 |
| --- | --- | --- |
| 腾讯 | 游戏全品类 | 渠道与规模优势，投资版图庞大 |
| 米哈游 | 二次元、出海 | 二次元赛道领先，海外收入占比高 |
| 莉莉丝、叠纸 | 细分赛道 | 各有特色品类 |
| 网易 vs 暴雪 | 代理合作 | 合作关系，也有分成博弈 |

| 好未来、猿辅导 | 教育 | 有道在智能学习与硬件方向差异化 |

### 6.3 竞争格局要点

- **腾讯 vs 网易是主旋律**：两家合计占中国游戏市场约一半份额。
- **网易的差异化在"产品"**：不靠渠道，靠品质与用户运营。
- **米哈游是最大变量**：在二次元与全球化上领先，是网易出海的主要对手。
- **代理业务不稳定**：暴雪合作的终止与恢复说明代理业务存在断档风险。
- **音乐与教育是次要战场**：规模小、竞争激烈，但对生态有补充作用。

### 6.4 竞争焦点

| 战场 | 网易的位置 | 关键变量 |
| --- | --- | --- |
| 端游 IP | 强（梦幻西游系列） | 生命周期延长 |
| 自研手游 | 强 | 新品爆款能力 |
| 出海 | 追赶者 | 《燕云十六声》《漫威争锋》表现 |
| 代理业务 | 稳定 | 与暴雪合作关系 |
| 音乐 | 第二 | 版权与付费率 |
| 教育 | 细分 | 硬件与 AI |

## 七、护城河与核心优势

### 7.1 护城河评估

| 护城河 | 强度 | 说明 |
| --- | --- | --- |
| 自研产品能力 | 极强 | 网易游戏以品质著称，用户口碑好 |
| 长线 IP 资产 | 极强 | 《梦幻西游》系列等运营超 20 年 |
| 高毛利商业模式 | 强 | 毛利率约 64%，净利率约 30% |
| 研发团队稳定性 | 强 | 自研团队规模大、经验深 |
| 出海产品能力 | 中强 | 自研产品直接出海获验证 |
| 现金流与股东回报 | 强 | 持续分红，分红率约 40% |
| 多元化业务 | 中 | 音乐、教育、电商补充生态 |

### 7.2 逐条分析

- **精品自研是根本**：网易不做"买量换皮"的低质产品，而是投入长周期自研，形成产品口碑与 IP 资产。
- **长线运营复利**：《梦幻西游》系列运营超过二十年，仍在贡献稳定收入，这是游戏行业罕见的资产。
- **高毛利的本质**：自研游戏收入占比高，虚拟道具边际成本极低，因此毛利率稳定在 60% 以上。
- **AI 提效**：AI 已全流程融入游戏研发（美术、程序、动画、QA），提升产出效率与内容规模。
- **出海验证**：《燕云十六声》累计玩家超 8,000 万、《漫威争锋》全球走红，证明自研产品具备全球竞争力。
- **组织精简**：员工规模远小于腾讯，人均创收与创利高，决策效率相对高。

### 7.3 护城河的边界

- **缺乏自有流量入口**：网易没有微信、QQ 级别的渠道，新游获客依赖外部投放。
- **代理业务波动**：暴雪合作中断曾造成明显收入缺口。
- **二次元赛道落后**：米哈游在这一高增长赛道领先。
- **海外收入占比仍低**：相比米哈游，网易游戏海外收入占比仍有提升空间。
- **爆款依赖**：新游成功与否对业绩影响大，存在周期性波动。

- **AI 投入的回报**：AI 提效明显，但难以单独量化收入贡献。

## 十五、产业链位置与价值链分配

### 15.1 网易在游戏产业链中的位置

| 环节 | 参与者 | 网易的角色 |
| --- | --- | --- |
| 上游（研发） | 自研工作室、美术外包、音乐外包 | 网易自研为主，外包为辅 |
| 上游（IP） | 自有 IP、授权 IP（漫威等） | 自有 IP 为主，逐步引入授权 |
| 中游（发行/运营） | 网易、渠道平台（应用商店） | 自研自发的研运一体 |
| 下游（玩家） | 国内玩家、海外玩家 | 直接面向全球玩家 |
| 平台 | 安卓应用商店、App Store、Steam 等 | 需支付渠道分成 |

### 15.2 价值链分配特征

| 参与方 | 获得 | 面临的问题 |
| --- | --- | --- |
| 研发团队 | 项目分成、薪资 | 长周期、高不确定性 |
| 渠道平台 | 应用商店分成（约 30%） | 反垄断与"苹果税"争议 |
| 玩家 | 娱乐体验 | 消费机制与沉迷争议 |
| 网易 | 游戏内购收入 | 版号、监管、爆款依赖 |
| 外包供应商 | 美术、音频外包订单 | 价格竞争 |

- **渠道分成是重要成本**：移动游戏在应用商店的分成比例高，直接影响利润率。
- **研运一体的优势**：自研自发可以控制品质与运营节奏，获取更高价值链份额。
- **PC/主机渠道分成较低**：Steam 等的分成比例低于移动应用商店。

### 15.3 与上下游关系

| 关系方 | 合作方式 | 张力 |
| --- | --- | --- |
| 研发工作室 | 内部工作室独立研发 | 资源分配与考核 |
| IP 授权方 | 漫威等授权合作 | 授权费用与创意边界 |
| 渠道平台 | 上架与分发 | 分成比例 |
| 暴雪 | 代理合作 | 分成与续约风险 |
| 音乐版权方 | 版权采购 | 版权成本 |

| 主要品类 | MMORPG、竞技、SLG | MOBA、FPS、全品类 | 二次元开放世界 | 3A 独占 |
| 毛利率 | 约 64% | 高（游戏分部） | 高 | 中 |
| 用户规模 | 国内为主 | 全球最大 | 全球年轻用户 | 主机玩家 |

### 17.3 启示

- **网易的路径最"纯粹"**：不做平台、不靠渠道，靠产品本身取胜。
- **米哈游是最大威胁**：在二次元与全球化上，米哈游比网易更彻底。
- **腾讯的模式最难复制**：腾讯靠社交渠道 + 全球投资形成"规模 + 生态"双壁垒。
- **长线运营是共同追求**：索尼、任天堂、网易都靠长青 IP 获取稳定现金流。

## 二十、游戏长线运营方法论深读

长线运营不是"不停出新活动"，而是一套把版本节奏、内容分层、社区关系、经济系统与流失干预组织成闭环的系统工程。本章从网易产品实践中抽取可复用的通用方法论：《梦幻西游》系列运营超 20 年、《第五人格》海外长线、《蛋仔派对》社交扩张、《逆水寒》端手游双线、《率土之滨》赛季制 SLG，恰好覆盖了不同品类的运营范式。

### 20.1 版本节奏：把内容排期变成可预期的"心跳"

| 版本类型 | 更新重点 | 运营目的 |
| --- | --- | --- |
| 大版本（资料片 / 赛季级） | 新地图、新门派或职业、主线剧情 | 制造回归理由，拉回流失用户，形成传播事件 |
| 中版本（月度 / 活动周期） | 限时活动、IP 联动、新玩法模式 | 维持活跃峰值，制造社区话题与社交货币 |
| 小版本（周度 / 热修） | 数值平衡、Bug 修复、体验优化 | 传递"游戏仍被用心维护"的信号，抑制隐性流失 |

- **可预期性本身即留存工具**：固定节奏让用户形成"下次更新再回来"的心理契约，减少"这游戏是不是没人管了"的猜疑。
- **大小版本交替形成呼吸感**：大版本负责拉新与召回，中版本负责活跃峰值，小版本负责体验兜底；三者叠加才是完整的心跳。
- **叙事包装赋予版本意义**：资料片主题、赛季故事线把数值更新包装成"世界在推进"，老玩家回归的动机从"补进度"升级为"补剧情"。
- **《逆水寒》的双线参照**：端游靠大型资料片维持重度玩家，手游靠高频玩法迭代适配碎片时间，同 IP 用两种节奏服务两类人群。
- **《梦幻西游》系列的节点运营**：以周年庆、资料片为固定节点，节奏稳定到玩家可以自行规划投入，这是运营超 20 年的产品才积累得出的信任。

### 20.2 内容更新分层：消耗型、结构型、社交型与情感型

| 内容层 | 特征与作用 | 文中产品对应 |
| --- | --- | --- |
| 消耗型内容 | 短周期、低门槛，如限时活动、日常副本，决定"每天为什么上线" | 各产品的日常任务与节庆活动体系 |
| 结构型内容 | 改变玩法结构：新职业、新地图、新赛季规则，重置进度追求 | 《逆水寒》资料片、赛季制产品的赛季更迭 |
| 社交型内容 | 组队玩法、公会战、UGC 关卡，把关系沉淀为离开成本 | 《蛋仔派对》自制关卡、《率土之滨》同盟玩法 |
| 情感型内容 | 剧情更新、角色塑造、联动，提供非数值的留存理由 | 《阴阳师》IP 化运营、《第五人格》角色叙事 |

- **消耗型内容保日活，结构型内容保生命周期**：前者决定短期 DAU 曲线的平稳度，后者决定产品两年后是否还有"从头玩一遍"的价值。
- **UGC 是内容供给的杠杆**：当内容生产从团队外置到玩家，供给规模摆脱研发产能约束；《蛋仔派对》用户规模大、社交属性强，自制关卡既延长生命周期又天然产生传播素材。
- **内容与经济必须联动**：新内容若直接产出可交易稀缺物，会冲击存量物价；成熟做法是新内容配新货币、新回收口，让新旧经济圈层并行。
- **情感型内容是性价比最高的更新**：剧情与角色的边际成本远低于新玩法系统，却能支撑同人创作、联动与回归动机，是二次元与 IP 型产品的留存底牌。

### 20.3 社区与赛事：把玩家关系沉淀为长期资产

| 维度 | 常用手段 | 产生的作用 |
| --- | --- | --- |
| 反馈回路 | 官方社区、版本意见征集、开发者日志 | 让玩家有参与感，降低改动推行的抵触 |
| 内容生态 | 攻略作者、同人创作、主播直播 | 降低新玩家学习成本，二次延长内容生命周期 |
| 赛事体系 | 职业赛事、全民赛、观赛奖励与竞猜 | 为竞技品类提供"不玩也能看"的理由，维持品牌热度 |
| 关系网络 | 公会、师徒、同盟、好友组队 | 形成迁出成本：离开游戏等于离开一群人 |

- **赛事的正向循环**：观赛 → 模仿高水平打法 → 排位活跃度上升 → 更多观众，竞技品类的赛事不是成本中心，而是活跃度放大器。
- **《第五人格》的样本价值**：非对称竞技品类天然适合观赏与二创，其海外长线运营正是"赛事 + 同人文化 + 角色叙事"三件套支撑的结果。
- **《率土之滨》的社交沉淀**：SLG 的核心资产是同盟关系与赛季共同记忆，迁服、赛季结算等机制本质是在制造"集体叙事"，让关系链成为最强防流失网。
- **社区管理的要害是回应速度与透明度**：版本争议期，官方是否及时说明"为什么这么改"比发多少宣传帖更重要；沉默会被解读为傲慢。
- **赛事投入要匹配品类体量**：网易的竞技品类更适合精众化、垂直化的赛事矩阵，而非用渠道型打法烧钱堆大联盟——这与其缺乏微信、QQ 级别流量入口的结构一致。

### 20.4 经济系统：长线运营的隐形骨架

| 设计要素 | 设计要点 | 失衡风险 |
| --- | --- | --- |
| 货币结构 | 分层货币：免费产出货币、付费货币、绑定与非绑定资产各司其职 | 层级过多导致玩家困惑，兑换黑箱引发不信任 |
| 产出与回收 | 日常产出配消耗口：强化、修理、合成、限时兑换形成闭环 | 产出大于回收引发通货膨胀，道具贬值侵蚀保值预期 |
| 交易与流通 | 自由交易、摆摊或合规的官方交易平台，控制权留在官方手中 | 工作室与外挂涌入、通胀、合规风险 |
| 付费深度 | 外观、便利、数值三者的配比，数值付费需谨慎 | 数值付费破坏平衡，外观付费更可持续 |

- **端游时代已验证的结论**：稳定的虚拟经济与交易体系是端游长线运营的关键，网易在《梦幻西游》系列上积累的经济系统经验，是其长线运营方法论中最难被复制的部分。
- **保值预期是一种心理账户**：MMORPG 玩家把投入的时间视为"资产"，一旦预期资产贬值，流失速度会远快于数值设计上的推演；经济稳定的本质是守住这份预期。
- **SLG 的经济即战争**：《率土之滨》类产品的资源产出与掠夺规则直接决定对抗烈度与赛季走势，经济平衡就是玩法平衡。
- **派对游戏走轻经济路线**：《蛋仔派对》的付费以外观与社交展示为主，没有重数值对抗，经济系统简单反而拓宽了用户年龄层。
- **经济系统的改动是最高风险操作**：任何产出、回收、交易规则的调整都应灰度推进并提前沟通，因为经济信任一旦破损，修复成本远高于功能回滚。

### 20.5 防流失机制：识别、干预、召回的三段链路

| 阶段 | 典型信号 | 常用干预手段 |
| --- | --- | --- |
| 流失预警期 | 登录频次下降、公会参与减少、日活任务中断 | 定向推送、专属回归任务、老友召回邀请 |
| 真实流失期 | 长期未登录 | 召回活动、回归礼包、版本速览与追赶指引 |
| 回归脆弱期 | 回归后看不懂版本、进度差距过大 | 快速追赶机制、回归向导、回归专属匹配缓冲 |

- **流失根源有排序**：社交断裂、目标感消失、数值挫败、新品分流，四者由重到轻；只靠发礼包召回而不修复社交与目标感，召回率注定低下。
- **追赶机制不是施舍**：它的作用是抹平回归者的沉没成本门槛，让"回来"的决策成本接近于零；赛季制则更进一步，用干净的重新开始提供结构性防流失。
- **合规是底线而非运营手段**：防沉迷系统、实名认证、时长与消费限制属于未成年人保护义务，与商业化的召回机制必须严格区分。
- **接受自然衰退**：长线运营的目标是延长平台期与抬高衰退曲线的面积，而非阻止一切流失；强行用高强度促销挽留，往往以经济系统与品牌口碑为代价。
- **数据驱动的干预**：预警信号应当可量化、可分层触达，使同一名玩家在预警、流失、回归三个阶段各只收到一种最相关的干预，避免多头打扰造成二次劝退。

### 20.6 可复用的"五问"框架

| 关键问题 | 健康状态的信号 |
| --- | --- |
| 玩家下周为什么回来？ | 有可预期、可传播的版本节奏 |
| 半年后为什么还在？ | 结构型内容持续重置目标，社交关系已沉淀 |
| 钱花出去为什么后悔不了？ | 付费以外观与情感为主，数值付费克制 |
| 经济为什么没有崩？ | 产出与回收闭环，官方掌握交易控制权 |
| 流失为什么可控？ | 预警—干预—召回三段链路完整且互不打扰 |

这套五问适用于任何品类的自检：五项中有两项失守，产品就会进入缓慢衰退；有三项失守，衰退会加速为断崖。网易各产品线的差异，本质上是对这五个问题给出了不同权重的答案——MMO 重经济与社交，派对游戏重节奏与 UGC，SLG 重关系与赛季，竞技品类重赛事与平衡。

## 二十一、出海战略专题：网易 vs 米哈游 vs 腾讯路径对比

中国游戏出海已从"把国内成功产品翻译出去"进入"组织能力全球竞争"阶段。三家头部公司给出了三种机制截然不同的打法：网易以自研产品直接海外发行（《燕云十六声》累计玩家超 8,000 万、《漫威争锋》全球走红、《永劫无间》多平台扩展、《第五人格》海外长线），米哈游以二次元旗舰全球同步发行建立品牌心智，腾讯以投资收购（Riot、Supercell 等）叠加自有发行网络覆盖全球。本章拆解三种路径的机制差异、优劣势、适用条件与风险。

### 21.1 三种路径总览

| 维度 | 网易 | 米哈游 | 腾讯 |
| --- | --- | --- | --- |
| 核心机制 | 自研产品直接海外发行 | 自研二次元旗舰全球同步发行 | 投资或收购成熟工作室，叠加全球发行网络 |
| 资本姿态 | 轻资产：研发投入前置，发行自建 | 轻资产：集中资源做长周期旗舰 | 重资产：以股权绑定团队与 IP |
| 品类抓手 | MMORPG、竞技、SLG、派对多线并行 | 单品类深做，定义二次元开放世界 | 全品类覆盖：MOBA、FPS 及多元组合 |
| 国内与海外关系 | 国内为基本盘，海外为增量（海外收入占比相较米哈游仍有提升空间） | 国内海外并重，全球年轻用户心智 | 国内基本盘雄厚（腾讯游戏收入超 2,000 亿元），海外靠版图扩张 |

### 21.2 机制差异的深层拆解

| 机制层 | 网易 | 米哈游 | 腾讯 |
| --- | --- | --- | --- |
| 组织形态 | 工作室制多线自研，发行能力逐步自建 | 集中式投入，围绕旗舰产品统一调度 | 投资并购 + 自研并行，被投团队保留独立性 |
| 风险分布 | 研发风险自担，单款新品成败影响大 | 风险集中于旗舰产品与其接棒作品 | 多点下注分散单款风险，换取覆盖面 |
| 资产负债表语言 | 研发费用与项目储备 | 长周期内容产能 | 商誉、股权资产与生态协同 |
| 品牌建立方式 | 靠产品口碑与品类内口碑扩散 | 靠旗舰产品建立全球品牌 | 靠被投 IP 的全球影响力与平台分发 |

- **决策链条不同**：米哈游式的集中投入利于"一个产品打穿一个品类"，但要求极高的战略定力；网易的工作室制利于多点开花，代价是资源分散、单品规模受限；腾讯的平台化打法让任何单一产品失败都不伤根本，但协同效果需要长期经营。
- **发行能力的位置不同**：网易正处在"发行自建"的过程中，海外本地化与投放能力是补课项；米哈游从第一天就是全球同步发行，发行是基因的一部分；腾讯的发行网络经过多市场验证，是其收购之外的第二重优势。
- **IP 所有权结构不同**：自研路径下 IP 完全自主，续约、改编、联动皆可自主决策；收购路径下需处理被投公司文化与总部意志的磨合；代理路径则天然存在合作关系波动风险——网易与暴雪合作的中断与恢复已说明这一点。

### 21.3 优劣势对比

| 路径 | 优势 | 劣势 |
| --- | --- | --- |
| 网易：自研直接出海 | IP 自主可控；高毛利结构（毛利率约 64.3%）可随产品复制到海外；产品品质形成的口碑可跨文化传播 | 缺乏自有流量入口，海外获客依赖外部投放；本地化与发行体系需自建；爆款依赖，新品成败波动大 |
| 米哈游：单点旗舰全球发行 | 品类定义者地位带来的全球品牌心智；国内市场份额约 8% 仍能以海外放大整体盘子；内容驱动的用户忠诚度高 | 风险集中：单品类依赖与接棒作品压力；内容产能要求极高，更新节奏一旦失守口碑反噬快 |
| 腾讯：投资并购 + 发行网络 | 多点下注分散风险；被投产品即刻获得成熟 IP 与团队；国内基本盘（国内市场份额约 40%）为海外试错提供现金流 | 商誉与整合成本；地缘环境对跨境股权结构的审视日趋严格；被投协同的实际效果并非自动发生 |

### 21.4 适用条件：什么样的公司适合哪条路

| 路径 | 前提条件 | 不适用的情形 |
| --- | --- | --- |
| 自研直接出海 | 产品具备跨文化普适性；内容品质足以在海外硬碰硬；现金流能支撑长周期研发与自建发行 | 产品高度依赖国内渠道特有生态；缺乏海外本地化与投放的组织能力储备 |
| 单点旗舰全球发行 | 拥有品类定义级的创作能力；资本有耐心等待长周期回报；团队能维持高强度内容产能 | 缺乏差异化、只能做跟随式产品；无法承受旗舰产品失利的后果 |
| 投资并购出海 | 现金充裕；具备投后治理与协同经验；愿意接受相对慢的整合周期 | 投后管理缺位导致"买了也协同不起来"；所在赛道面临严格的跨境监管审查 |

- **三条路径并非互斥**：网易也在推进全球多平台发行与海外工作室布局；腾讯同样保有大量自研；米哈游也在以旗舰产品带动全球化品牌运营。真正的差异在于资源投入的优先级与风险的主承担方式。
- **路径选择受国内禀赋约束**：腾讯先有社交渠道才谈得上"用渠道换投资标的"；米哈游没有渠道包袱，反而把资源全部押在产品上；网易介于两者之间——有产品力、无渠道，因此"产品直接面对全球市场"反而是其禀赋下的自然选择。

### 21.5 风险与失效模式

| 路径 | 典型失效场景 | 值得观察的信号 |
| --- | --- | --- |
| 网易 | 本地化不足导致水土不服；买量成本侵蚀利润；新品在海外未能复制国内口碑 | 海外收入占比能否持续提升；《燕云十六声》《漫威争锋》后续产品的接力情况 |
| 米哈游 | 内容更新跟不上玩家预期；品类审美迁移；接棒作品不及旗舰 | 新品能否承接品牌；内容产能与更新节奏是否稳定 |
| 腾讯 | 跨境监管与地缘环境变化影响股权安排；被投团队与总部战略脱节；收购 IP 的代际更替 | 海外监管与并购环境；被投产品与发行网络的协同深度 |

- **对网易的启示一：补渠道不如补"到达能力"**：没有微信、QQ 级入口的前提下，海外市场的应用商店、主机平台与社区平台是相对公平的起跑线，自建发行与平台关系是必答题。
- **对网易的启示二：用长线运营做后发深耕**：买量决战不利于缺流量入口的玩家，但把已验证的长线运营能力——版本节奏、经济系统、社区沉淀——复制到海外市场，可以在产品上线后持续拉高留存曲线，摊薄获客成本。
- **对网易的启示三：AI 是边际利好**：AI 已全流程融入研发（美术、程序、动画、QA），对以自研为主、内容消耗量大的出海路径而言，内容生产成本下降会直接改善投入产出比。
- **竞争坐标不会静止**：米哈游在二次元与全球化上的领先使其仍是网易出海的最大变量；腾讯的规模与生态（两家合计约占中国游戏市场一半份额）意味着出海竞争从来不是三家的规则之外——全球厂商同样是对手。
- **三条路径的共同底线**：产品品质。无论资本结构如何，海外用户最终用下载与付费投票；这也是网易坚持精品自研的战略在出海语境下的延续。

### 21.6 结论速览

| 厂商 | 出海一句话概括 | 关键胜负手 |
| --- | --- | --- |
| 网易 | 把长线运营能力复制到全球市场 | 新品成功率、海外本地化与自建发行的成熟速度 |
| 米哈游 | 用一个品类建立全球年轻用户心智 | 内容产能的可持续性与旗舰的接棒作品 |
| 腾讯 | 用资本买下赛道，用网络卖向全球 | 投后整合效果与跨境监管环境的变化 |

## 小结

- **网易的本质是"精品自研游戏的复利机器"**：靠产品品质与长线运营，把单款游戏的生命周期拉到十年以上。
- **2025 年业绩稳健**：净收入约 1,126 亿元（+约 7%），归母净利润约 337 亿元（+约 14%），毛利率约 64.3%、净利率约 30%。
- **游戏是绝对主体**：游戏及相关增值服务收入占比约 81.8%，非游戏业务规模有限。
- **长线 IP 是核心资产**：《梦幻西游》系列运营超 20 年仍贡献稳定收入，是行业罕见的资产。
- **出海取得突破**：《燕云十六声》累计玩家超 8,000 万，《漫威争锋》全球走红，验证自研产品全球竞争力。
- **AI 全面融入**：从美术、程序、动画到 QA 全流程应用 AI，提升研发效率并解锁新玩法。
- **短板在于流量入口**：缺乏微信、QQ 级别的渠道，新游获客成本高于腾讯；二次元赛道落后于米哈游。
- **对我们的意义**：网易是理解"自研产品力""长线运营复利""高毛利游戏商业模式"与"中国游戏出海路径"的最佳样本之一。
