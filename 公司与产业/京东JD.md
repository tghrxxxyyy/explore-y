# 京东（JD）
> 中国最大的自营式电商与供应链基础设施公司，以"自建物流 + 正品行货"构建护城河，靠超 90 万员工的"重资产"体系提供确定性服务，2025 年切入外卖与即时零售。

## 一、公司概况

### 1.1 基本信息

| 项目 | 内容 |
| --- | --- |
| 公司全称 | 京东集团（JD.com, Inc.） |
| 成立时间 | 1998 年 6 月（刘强东在中关村创立京东，2004 年转型线上电商） |
| 总部所在地 | 中国北京 |
| 创始人 | 刘强东（现任董事局主席） |
| 现任 CEO | 许冉（Sandy Xu，2023 年 5 月接任集团 CEO） |
| 上市情况 | 2014 年 5 月美国纳斯达克上市（JD）；2020 年 6 月香港二次上市（09618 / 89618） |

| 最新利润 | 2025 年归母净利润 196 亿元，同比下降约 52.5%；非 GAAP 净利润 270 亿元，同比下降 43.5% |
| 员工规模 | 体系员工超 90 万人（含兼职、实习生及生态关联岗位），为《财富》世界 500 强中员工最多的中国民营企业 |
| 核心业务 | 京东零售、京东物流、京东健康、京东工业、京东产发、京东科技、外卖、京喜、国际业务 |

> 数据口径：除特别说明外，均为**人民币**、**2025 自然财年**（截至 2025 年 12 月 31 日）。京东采用自然年财年。

### 1.2 地位速览

- **营收规模**：2025 年营收 13,091 亿元，是中国营收规模最大的民营企业之一。
- **世界 500 强**：2026 年《财富》世界 500 强第 41 位，连续 11 年上榜，连续 3 年位居中国大陆民营企业第一。
- **员工规模**：体系员工超 90 万人，2025 年人力资源总支出 1572 亿元。
- **零售基本盘**：京东零售 2025 年营收 11,264 亿元，同比增长 10.9%，经营利润率 4.6%。
- **物流网络**：京东物流海外仓、保税仓、直邮仓已近 200 个，覆盖全球 25 个国家。
- **股东回报**：2025 年回购约 30 亿美元（约占流通股 6.3%），年度现金分红约 14 亿美元，总回报率约 10%。

### 1.3 为什么京东值得研究

- 它是**中国"重资产电商"的唯一成功样本**：用自建物流与自营采购换来"快"与"正品"心智，代价是极低的利润率与极高的员工规模。
- 它是**供应链能力的极致体现**：从 3C 家电到日用百货，从零售到工业品，供应链是公司所有业务的底层能力。
- 它是**中国民营企业用工规模之最**：90 万员工、直接签约与五险一金，是理解平台经济劳动关系的另一面。
- 它是**2025 年即时零售大战的发起者之一**：以外卖入局，改变了美团、阿里、京东的三方格局。
- 它是**利润与规模矛盾的样本**：营收最高但利润率最低，如何提升盈利是长期课题。

## 二、发展历程

### 2.1 关键时间线

| 时间 | 事件 | 意义 |
| --- | --- | --- |

| 2004 年 | 转型线上电商（京东商城） | 从线下柜台转向互联网零售 |
| 2007 年 | 自建物流 | 决定公司命运的"重资产"选择 |
| 2014 年 5 月 | 纳斯达克上市 | 获得资本支持扩张 |

| 2017 年 | 京东物流独立运营 | 物流从成本中心变为独立业务 |
| 2018 年 | 组织架构调整，确立"零售 + 物流 + 数科" | 从单一电商转向集团化 |
| 2020 年 6 月 | 香港二次上市 | 回归港股 |

| 2026 年 | 《财富》500 强第 41 位 | 连续 11 年上榜 |

### 2.2 阶段划分

**第一阶段（1998–2006）：从线下代理到线上零售**
- 从中关村光磁产品代理起步，2003 年"非典"期间尝试线上销售，发现线上效率更高。
- 2004 年正式转型电商，聚焦 3C 与家电。

**第二阶段（2007–2013）：自建物流与正品心智**
- 2007 年决定自建物流，这在当时被视为疯狂的决定。
- 用"211 限时达""货到付款""正品行货"建立差异化心智。
- 代价是连年亏损与巨额资本开支。

**第三阶段（2014–2019）：上市与集团化**
- 2014 年上市，与腾讯合作获得移动端流量入口。
- 京东物流、京东健康、京东数科等业务逐步成型。
- 与阿里巴巴形成"平台 vs 自营"的两大电商模式对照。

**第四阶段（2020–2024）：多资产证券化与提效**
- 京东健康、京东物流相继上市，集团资产证券化。
- 战略聚焦"供应链 + 服务"，强调利润率提升。
- 2024 年非 GAAP 净利润达 478 亿元，创历史高点。

**第五阶段（2025 年至今）：即时零售大战与利润承压**
- 2025 年京东外卖上线，与美团、淘宝闪购正面竞争。
- 新业务投入导致 2025 年利润大幅下滑（归母净利润 196 亿元，-52.5%）。
- 2026 年公司强调"新业务亏损逐季收窄"。

### 2.3 关键决策复盘

| 决策 | 当时的选择 | 事后评价 |
| --- | --- | --- |
| 2007 年自建物流 | 用重资产换时效与体验 | 极其正确，构成核心护城河 |
| 与腾讯结盟 | 用股权换微信入口 | 正确，获得移动端关键流量 |
| 拆分物流、健康独立上市 | 资产证券化、独立融资 | 正确，释放资产价值 |
| 2025 年做外卖 | 切入即时零售 | 争议中，短期大幅侵蚀利润 |
| 坚持自营为主 | 不做纯平台 | 保证品质与体验，但利润率受限 |

## 四、商业模式与盈利来源

### 4.1 赚钱逻辑

- **第一层：自营零售赚差价**。京东自营采购商品再销售给消费者，赚取进销差价，毛利率低但规模大。
- **第二层：平台服务收入**。向第三方商家收取佣金、广告费、仓储配送费，毛利率高于自营。
- **第三层：物流服务收入**。京东物流对外提供一体化供应链服务，赚取服务费。
- **第四层：金融与技术服务**。京东科技提供消费金融、供应链金融与企业数字化服务。
- **第五层：健康与工业等垂直业务**。在垂直领域提供专业化的商品与服务。

### 4.2 收入与利润结构

| 收入类型 | 特征 | 毛利率 |
| --- | --- | --- |
| 自营商品销售收入 | 占比最大 | 低（约 10%–15%） |
| 平台及广告服务收入 | 占比提升中 | 高 |
| 物流服务收入 | 对外服务 | 中 |
| 其他服务收入 | 健康、工业、科技 | 中高 |

- **整体毛利率**：2025 年约 15.95%，远低于拼多多（约 56%）与阿里，这是自营模式的必然结果。
- **净利率**：2025 年约 1.5%，属于典型"薄利多销"。

### 4.3 成本结构

| 成本项 | 特征 | 影响 |
| --- | --- | --- |
| 商品采购成本 | 自营最大成本 | 直接决定毛利 |
| 履约费用（仓储、配送） | 重资产成本 | 时效与体验的代价 |
| 人力成本 | 体系员工超 90 万人 | 2025 年人力支出 1572 亿元 |
| 销售与营销费用 | 新业务补贴 | 2025 年大幅上升 |
| 研发投入 | 供应链科技、AI | 长期能力建设 |

- **人力是最大刚性成本**：京东为数十万一线员工直接签订劳动合同并缴纳五险一金，这在中国民营企业中极为罕见，也是利润率的长期约束。
- **自营模式的代价**：低毛利 + 高履约 + 高人力，使得净利率长期在 1%–3% 区间。

### 4.4 与阿里、拼多多的模式对照

| 维度 | 京东 | 阿里巴巴 | 拼多多 |
| --- | --- | --- | --- |
| 模式 | 自营为主 + 平台 | 平台 + 自营 + 云 | 轻资产平台 |
| 物流 | 自建（京东物流） | 菜鸟（协同） | 依赖第三方 |
| 员工 | 超 90 万 | 数万至十万量级 | 数万量级 |
| 毛利率 | 约 16% | 中高 | 约 56% |
| 净利率 | 约 1.5% | 中 | 约 23% |
| 核心心智 | 快 + 正品 | 万能 | 便宜 |

## 六、竞争格局

### 6.1 中国电商格局

| 平台 | 核心心智 | 主要优势 | 主要劣势 |
| --- | --- | --- | --- |
| 京东 | 快 + 正品 | 供应链、物流、服务 | 利润率低、内容弱 |
| 阿里巴巴（淘天） | 万能的淘宝 | 品牌、生态、云、支付 | 增长放缓 |
| 拼多多 | 最便宜 | 低价、供应链直连、高利润 | 品牌弱、物流弱 |
| 抖音电商 | 兴趣电商 | 流量、内容种草 | 供应链与物流弱 |
| 快手电商 | 老铁经济 | 社区信任、直播 | 规模较小 |

### 6.2 即时零售与外卖格局（2025 年）

| 平台 | 外卖订单份额（2025 年底） | 特征 |
| --- | --- | --- |
| 美团 | 约 50%–51% | 履约网络最强 |
| 淘宝闪购（原饿了么） | 约 42% | 阿里生态支持 |
| 京东外卖 | 约 7%–8% | 新入局者，全职骑手模式 |

- **京东的差异化**：首个与全职骑手直接签劳动合同的平台，用"正规用工"作为差异化标签。
- **代价**：全职骑手的社保与管理成本远高于众包模式，短期亏损明显。

### 6.3 物流竞争格局

| 公司 | 定位 | 相对京东物流的差异 |
| --- | --- | --- |
| 顺丰 | 高端时效快递 | 时效与服务质量领先，仓配一体弱 |
| 菜鸟 | 阿里生态物流协同 | 平台协同强，自有运力较弱 |
| 通达系 | 电商件主力 | 单价低，服务体验弱 |
| 京东物流 | 一体化供应链 | 仓配一体 + 时效确定性 |

### 6.4 竞争格局要点

- **电商三强 + 内容电商**：京东、阿里、拼多多构成基本盘，抖音电商快速逼近。
- **即时零售成为新战场**：美团、阿里、京东三强混战，补贴激烈。
- **京东位置**：在"确定性服务"上领先，在"低价"与"内容"上落后。
- **利润压力最大**：自营模式 + 新业务投入，使京东在三家中的利润弹性最小。

## 七、护城河与核心优势

### 7.1 护城河评估

| 护城河 | 强度 | 说明 |
| --- | --- | --- |
| 自建物流网络 | 极强 | 全国仓配体系，时效与服务领先 |
| 供应链能力 | 强 | 从采购、库存到履约的全链条能力 |
| 正品心智 | 强 | 3C 家电等高客单价品类的信任基础 |
| 用户基础 | 强 | 高消费力用户群体 |
| 一体化服务 | 中强 | 零售 + 物流 + 健康的协同 |
| 员工与组织 | 中强 | 90 万员工的服务网络，但也是成本包袱 |
| 股东回报 | 中强 | 持续回购 + 分红 |

### 7.2 逐条分析

- **物流是京东的"根"**：2007 年自建物流的决定，使京东在时效、服务、售后上建立了竞争对手难以复制的优势。
- **供应链能力可外溢**：京东物流向第三方提供一体化供应链服务，京东工业服务企业采购，供应链从成本中心变成收入来源。
- **正品与信任**：在 3C、家电等高客单价品类，京东的"正品 + 售后"心智是重要壁垒。
- **用户质量高**：京东用户以一二线城市、高消费力人群为主，客单价与复购高于行业。
- **员工体系的稳定性**：直接签约 + 五险一金带来更高的服务稳定性，也形成较高的员工忠诚度。
- **资本的耐心**：2025 年利润大幅下滑，但公司通过回购与分红维持股东回报。

### 7.3 护城河的边界

- **低价心智缺失**：在价格敏感的下沉市场，京东弱于拼多多与淘宝。
- **内容与流量弱**：缺乏抖音、微信级别的流量入口，获客依赖外部渠道。
- **利润率结构性偏低**：自营 + 重资产 + 高人力，长期压制净利率。
- **外卖是新战场而非优势领域**：履约网络与美团差距明显，短期难盈利。

### 8.4 其他挑战

- **人力成本刚性**：为一线员工缴纳五险一金是长期承诺，也是长期成本。

- **国际业务不确定**：Joybuy 在欧洲面对亚马逊等强敌。
- **组织规模**：90 万人的组织管理与效率维持难度极大。

## 十五、产业链位置与价值链分配

### 15.1 京东在产业链中的位置

| 环节 | 参与者 | 京东的角色 |
| --- | --- | --- |
| 上游（品牌/工厂） | 品牌商、制造商、农户 | 京东是采购方与渠道方，议价能力强 |
| 中游（流通） | 京东物流、第三方快递 | 京东自建仓配，缩短流通环节 |
| 下游（消费者） | 中高消费力用户 | 提供"快 + 正品"的确定性服务 |
| 企业客户 | 制造、能源、建筑企业 | 京东工业提供工业品供应链 |
| 配套 | 支付、云、广告技术 | 京东科技自研或合作 |

### 15.2 价值链分配特征

| 参与方 | 获得 | 面临的问题 |
| --- | --- | --- |
| 品牌商/工厂 | 稳定渠道、快速回款 | 平台议价与促销压力 |
| 京东物流 | 履约服务收入 | 重资产、人力成本高 |
| 消费者 | 时效、正品、售后 | 价格通常高于拼多多 |
| 第三方商家 | 流量、仓配服务 | 佣金与广告成本 |
| 京东 | 进销差价 + 平台服务费 | 净利率极低 |

- **"减少中间环节"是京东的核心逻辑**：自营 + 自建物流，把品牌与消费者之间的层层分销压缩为"品牌—京东仓—消费者"。
- **代价是重资产**：仓、配、人构成了巨额固定成本，必须靠规模摊薄。

### 15.3 与供应链上下游的关系

| 关系方 | 合作方式 | 张力 |
| --- | --- | --- |
| 品牌商 | 直采、包销、联合营销 | 促销力度与价格体系 |
| 工厂/产业带 | 京喜、白牌直供 | 低价与品质平衡 |
| 农户 | 农产品上行 | 标准化与冷链 |
| 第三方商家 | 平台入驻 + 仓配服务 | 佣金、广告、竞争 |
| 快递同行 | 部分场景合作 | 竞争为主 |

| 广告业务 | 增长中，占比小 | 全球第三大广告平台 |
| 会员体系 | PLUS 会员 | Prime（全球标杆） |
| 国际化 | 起步（Joybuy） | 全球化运营 |
| 净利率 | 约 1.5% | 高（云与广告驱动） |

### 17.2 关键差异

- **亚马逊有 AWS 与广告作为利润引擎**，京东缺少同等量级的高毛利业务。
- **亚马逊的国际化远超京东**，京东海外业务仍处早期。
- **京东的物流是行业内最强的差异化**，在时效与服务上可与亚马逊 FBA 对标。
- **京东的员工规模是独特变量**：直接雇佣数十万一线的模式在成本上更重，但在服务稳定性上有优势。

### 17.3 启示

- **高毛利业务决定估值**：亚马逊的高估值来自 AWS 与广告，京东要提升估值需要培育高毛利业务。
- **供应链是长期资产**：两者的共同点是都把供应链视为核心资产。
- **国际化难度极高**：京东出海面临亚马逊、本地玩家的双重竞争。

## 小结

- **京东的本质是"供应链公司"**：自建物流 + 自营采购 + 一体化服务，用重资产换取时效、品质与信任。
- **规模最大、利润率最低**：2025 年营收 13,091 亿元（+13.0%），但归母净利润仅 196 亿元（-52.5%），净利率约 1.5%。
- **核心基本盘稳固**：京东零售 2025 年收入 11,264 亿元（+10.9%），经营利润率提升至 4.6%，日用百货连续 5 个季度双位数增长。
- **新业务是利润杀手**：2025 年外卖与即时零售投入导致 Q4 净亏损，但公司口径为亏损逐季收窄。
- **护城河在物流与供应链**：这是竞争对手最难复制的资产，也是京东"快"的心智来源。
- **90 万员工既是资产也是成本**：直接签约 + 五险一金带来服务稳定性与员工忠诚，也构成长期利润约束。
- **股东回报稳定**：2025 年回购约 30 亿美元 + 分红约 14 亿美元，总回报率约 10%。
- **对我们的意义**：京东是理解"重资产电商""供应链价值"与"平台劳动用工"的最佳样本之一。
