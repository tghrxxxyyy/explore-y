# 贵州茅台（Kweichow Moutai）
> 中国高端白酒的绝对龙头，用赤水河畔的稀缺产能与"国酒"心智做出毛利率超 90% 的生意，2025 年却迎来上市以来首次营收与利润"双降"，标志着白酒行业进入深度调整期。

## 一、公司概况

### 1.1 基本信息

| 项目 | 内容 |
| --- | --- |
| 公司全称 | 贵州茅台酒股份有限公司（Kweichow Moutai Co., Ltd.） |
| 起源 | 1951 年组建国营茅台酒厂（茅台镇酿酒历史可追溯数百年） |
| 公司成立 | 1999 年（贵州茅台酒股份有限公司设立） |
| 上市时间 | 2001 年 8 月在上海证券交易所上市，代码 600519 |
| 总部所在地 | 中国贵州省仁怀市茅台镇 |
| 控股股东 | 中国贵州茅台酒厂（集团）有限责任公司（茅台集团） |
| 现任董事长 | 陈华（2025 年上任） |
| 最新市值 | 约 1.54 万亿元（2026 年 9 月末）；2026 年 4 月曾约 1.76–1.83 万亿元 |
| 最新营收 | 2025 年营业总收入 1,720.54 亿元；营业收入 1,688.38 亿元，同比下降 1.21% |
| 最新利润 | 2025 年归母净利润 823.20 亿元，同比下降 4.53% |
| 核心业务 | 茅台酒（以飞天茅台为核心）、酱香系列酒（茅台 1935、茅台王子酒等） |

> 数据口径：除特别说明外，均为**人民币**、**2025 自然财年**（截至 2025 年 12 月 31 日）。贵州茅台在 A 股上市，采用自然年财年。

### 1.2 地位速览

- **行业地位**：中国高端白酒的绝对龙头，长期被视为 A 股核心资产与"股王"。
- **盈利能力**：2025 年毛利率 91.18%、净利率 50.53%、ROE 32.53%，盈利能力在 A 股制造业公司中位居最前列。
- **市值规模**：总市值约 1.54 万亿元（2026 年 9 月末），是 A 股市值最大的消费类公司之一。
- **分红水平**：2025 年全年累计现金分红 650.33 亿元，分红率 79%，创历史新高。
- **产能与销量**：2025 年茅台酒销量 58,473.16 吨（+0.73%），系列酒销量 38,353.48 吨（+3.88%）。
- **现金储备**：2025 年末现金余额 1,264.26 亿元，几乎无有息负债压力。
- **历史性转折**：2025 年是贵州茅台自 2001 年上市以来**首次出现营业收入与归母净利润"双降"**，终结了持续二十余年的正增长纪录。

### 1.3 为什么贵州茅台值得研究

- 它是**中国消费品中"定价权"最极致的样本**：出厂价与市场价的巨大价差，反映了稀缺性带来的品牌溢价。
- 它是**"品牌 + 稀缺 + 社交货币"三合一的商业模式**：茅台不仅是酒，更是礼赠、宴请、收藏的载体。
- 它是**A 股价值投资的标志性资产**：高 ROE、高毛利、高分红、低负债，是长期资金的核心持仓。
- 它是**理解中国消费周期的窗口**：2025 年的"双降"是白酒行业深度调整的缩影，也是观察高端消费意愿的重要指标。
- 它是**国企治理与公司治理的样本**：控股股东为国资，管理层更替、渠道改革、市场化转型都牵动股价。

### 2.2 阶段划分

**第一阶段（1951–2000）：品牌沉淀与公司化**
- 国营茅台酒厂整合茅台镇酒坊，形成统一品牌。
- 凭借"国酒"定位与稀缺产能，建立高端白酒的心智基础。
- 1999 年设立股份公司，2001 年上市。

**第二阶段（2001–2012）：黄金十年**
- 受益于经济高速增长与政务商务宴请需求，高端白酒量价齐升。
- 2005 年净利润超越五粮液，成为行业利润龙头。
- 出厂价与市场价价差持续扩大，渠道利润丰厚。

**第三阶段（2013–2016）：限制"三公消费"冲击期**
- 2013 年限制"三公消费"政策出台，高端白酒需求骤降、价格倒挂。
- 行业进入深度调整，多数酒企利润下滑。
- 茅台凭借品牌力保持正增长，龙头地位进一步巩固。

**第四阶段（2017–2024）：渠道改革与直营化**
- 提出"茅台酒 + 系列酒"双轮驱动，推出茅台 1935 等系列酒大单品。
- 2022 年上线"i 茅台"，推动直营化，提升出厂价与终端价的连接。
- 2023 年飞天茅台出厂价上调，市值一度突破 2 万亿元。

**第五阶段（2025 年至今）：深度调整与市场化转型**
- 2025 年营收与利润首次双降，白酒行业进入深度调整期。
- 公司提出"坚持以消费者为中心、全面推进市场化转型"，推进"三个转型"与"三端变革"。
- 2025 年维持高比例分红（79%），并通过注销式回购与股东增持稳定市场预期。
- 2026 年 3 月飞天茅台提价，优化价格体系、提升盈利能力。

### 2.3 关键决策复盘

| 决策 | 当时的选择 | 事后评价 |
| --- | --- | --- |
| 坚持"国酒"品牌定位 | 不做低价放量 | 正确，奠定定价权基础 |
| 2017 年做系列酒 | 培育第二增长曲线 | 部分成功，2025 年系列酒出现下滑 |
| 做直营与 i 茅台 | 减少对经销商依赖 | 正确，提升价格掌控力 |
| 2023 年出厂价上调 | 提升盈利 | 正确，但终端需求走弱后承压 |
| 2025 年不"放量冲业绩" | 主动控量稳价 | 短期牺牲增速，换取渠道健康 |
| 高比例分红 + 回购 | 强化股东回报 | 正确，稳定市场预期 |

### 3.2 茅台酒：绝对核心

| 维度 | 情况 |
| --- | --- |
| 代表产品 | 飞天茅台（53%vol 500ml）、茅台年份酒、生肖酒、精品茅台 |
| 2025 年营收 | 1,465 亿元（+0.39%） |
| 2025 年销量 | 58,473.16 吨（+0.73%） |
| 出厂价（飞天，2026 年 3 月起） | 1,269 元/瓶（原 1,169 元） |
| 自营体系零售价 | 1,539 元/瓶（原 1,499 元） |
| 特征 | 产能稀缺、品牌溢价、社交属性 |

- **"压舱石"作用**：在行业寒冬中，茅台酒业务仍实现微增（+0.39%），成功守住基本盘。
- **价格体系**：出厂价、指导零售价、市场实际批价三者之间的关系，是观察茅台经营的关键。
- **产能稀缺**：茅台镇特定产区的产能受地理条件限制，供给端天然稀缺。
- **产品结构**：以飞天为核心，通过生肖、年份、精品等产品提升结构与价格带。

### 3.3 酱香系列酒：第二增长曲线

| 维度 | 情况 |
| --- | --- |
| 代表产品 | 茅台 1935、茅台王子酒、茅台迎宾酒、汉酱等 |
| 2025 年营收 | 222.75 亿元（-9.76%） |
| 2025 年销量 | 38,353.48 吨（+3.88%） |
| 特征 | 量增价减（销量 +3.88% 但营收 -9.76%） |
| 战略 | 聚焦茅台 1935 等大单品，淘汰价值感弱、渠道利润薄的产品 |

- **主动"做减法"**：系列酒营收下滑可能部分是主动收缩产品线、聚焦大单品的结果。
- **量增价减的含义**：销量增长但收入下降，说明产品结构下移或价格承压。
- **第二曲线的挑战**：系列酒品牌力弱于茅台酒，在行业调整期承压更明显。

### 3.4 渠道体系

| 渠道 | 特征 |
| --- | --- |
| 经销商（传统） | 传统主力渠道，长期享受价差红利 |
| 直营（自营店） | 公司直接控制终端价格 |
| i 茅台（数字平台） | 2022 年上线，直营化与平价放量 |
| 商超、电商 | 补充渠道 |
| 团购客户 | 2025 年累计发展超 5,000 家团购客户 |

- **直营化改革**：通过 i 茅台与自营渠道提升公司对终端价格与利润的掌控。
- **渠道生态健康**：公司强调通过 i 茅台平价放量挤压渠道泡沫，短期牺牲报表增速换取批价稳定与渠道健康。
- **"坐商"到"行商"**：推动渠道商从被动等客转向主动拓客、发现新场景。

## 四、商业模式与盈利来源

### 4.1 赚钱逻辑

- **第一层：品牌溢价**。茅台酒出厂价与市场价存在价差，品牌力带来超额定价权。
- **第二层：稀缺产能**。茅台镇特定产区产能受限，供给稀缺支撑价格。
- **第三层：社交与收藏属性**。茅台是礼赠、宴请、投资的载体，需求超越"饮酒"本身。
- **第四层：高毛利结构**。2025 年毛利率 91.18%，成本占收入比例极低。
- **第五层：预收款（合同负债）模式**。经销商先打款后发货，形成优质现金流。

- **利润下滑幅度大于收入**：2025 年收入 -1.21%，但归母净利润 -4.53%，说明费用或结构变化影响更大。

- **2026 年提价**：出厂价上调 100 元（约 +8.6%），是自 2023 年 11 月以来的首次，反映公司优化价格体系、提升盈利能力的意图。

## 六、竞争格局

### 6.1 中国白酒行业格局

| 第三梯队（中低端） | 地方酒企、光瓶酒品牌 | 大众消费 |

### 6.2 高端白酒主要对手对比

| 对手 | 定位 | 相对茅台的差异 |
| --- | --- | --- |
| 五粮液 | 浓香型高端 | 产能更大、价格带更低，品牌溢价弱于茅台 |

| 习酒、郎酒 | 酱香型 | 同为酱香，是系列酒的直接竞争者 |

### 6.3 行业调整期的竞争特征

| 特征 | 说明 |
| --- | --- |
| 需求走弱 | 商务与礼赠需求下降，动销放缓 |
| 价格承压 | 批价下行，部分产品出现价格倒挂 |
| 库存高企 | 渠道库存偏高，去库存周期拉长 |

### 6.4 竞争格局要点

- **茅台的龙头地位未变**：在行业寒冬中，茅台酒业务仍保持微增，基本盘稳固。
- **系列酒承压更明显**：系列酒营收同比下降 9.76%，说明品牌力弱的价位带受影响更大。
- **行业集中度提升**：调整期加速中小酒企出清，头部品牌相对受益。
- **竞争焦点转向动销**：从"渠道压货"转向"终端动销"，品牌与渠道健康度成为关键。

## 七、护城河与核心优势

### 7.1 护城河评估

| 护城河 | 强度 | 说明 |
| --- | --- | --- |
| 品牌心智 | 极强 | "国酒"认知与社交货币属性 |
| 产区稀缺性 | 极强 | 茅台镇特定产区，产能受地理条件限制 |
| 工艺与时间壁垒 | 极强 | 基酒需 5 年周期，产能无法短期扩张 |
| 定价权 | 极强 | 出厂价与市场价长期存在价差 |
| 现金流模式 | 强 | 经销商先款后货，应收账款极低 |
| 盈利能力 | 极强 | 毛利率 91%、净利率 50%、ROE 32% |
| 股东回报 | 强 | 分红率 79% + 注销式回购 |

### 7.2 逐条分析

- **品牌是最核心的护城河**：茅台在礼赠、宴请、收藏场景中的地位难以替代，这是二十年品牌沉淀与历史事件共同塑造的结果。
- **产区稀缺性无法复制**：茅台镇特定产区、气候、水质与微生物环境共同决定品质，异地无法复制。
- **时间壁垒**：酱香型白酒的基酒需要 5 年储存，意味着产能无法通过投资快速扩张。
- **定价权的体现**：出厂价与市场价的长期价差，说明产品处于"供不应求"的定价状态。
- **极致的财务质量**：毛利率 91.18%、净利率 50.53%、ROE 32.53%、资产负债率 16.42%，是 A 股制造业中最好的财务结构之一。
- **渠道改革提升掌控力**：i 茅台与直营化让公司更直接地连接消费者，减少对经销商的依赖。
- **股东回报的制度化**：分红率承诺不低于 75%，实际 2025 年达 79%，并配合注销式回购。

### 7.3 护城河的边界

- **需求侧不是护城河能控制的**：2025 年营收利润双降说明品牌力无法完全对冲需求下行。
- **批价是市场情绪的晴雨表**：批价下行意味着金融属性与囤货动机减弱。
- **系列酒品牌力不足**：在次高端价格带的竞争中，茅台系列酒并不具备绝对优势。
- **消费群体更替风险**：年轻一代的饮酒习惯与消费偏好变化是长期隐忧。
- **政策与舆论**：高端白酒与宴请文化的社会观感、政策导向会影响需求。

- **批价承压**：市场批价下行意味着囤货与投资需求减弱，进一步影响终端动销。

- **"股王"宝座易主**：2026 年 4 月曾出现被源杰科技超越股价的报道，反映市场情绪的转变。

## 十五、行业格局与渠道体系深度解析

### 15.1 白酒行业的"金字塔"结构

中国白酒行业并非同质化竞争，而是一个按价格带分层、按香型分流、按区域割据的复杂金字塔：

| 层级 | 价格带（终端） | 代表品牌 | 竞争特征 |
| --- | --- | --- | --- |
| 超高端 | 1,000 元以上 | 飞天茅台、五粮液普五、国窖 1573 | 品牌垄断，供给受限，价格即身份 |
| 高端 | 600–1,000 元 | 汾酒青花、洋河梦之蓝 M6+、剑南春水晶剑 | 区域龙头与全国化博弈 |
| 次高端 | 300–600 元 | 舍得、水井坊、古井贡年份原浆 | 商务宴请主力，最受经济周期影响 |
| 中端 | 100–300 元 | 老白干、牛栏山（部分）、地方酒 | 大众消费，区域割据 |
| 大众 | 100 元以下 | 光瓶酒、二锅头 | 走量为主，利润率低 |

**关键理解**：茅台的位置决定了它的"竞争对手"其实不是另一个品牌，而是**"其他资产"**——当经济预期转弱、商务活动收缩时，高端白酒首先被压缩预算；当流动性充裕、资产荒时，高端白酒又被当作"实物资产"被囤积。这解释了为什么茅台的需求波动幅度远大于大众消费品。

### 15.2 香型分化：酱酒的崛起与降温

| 香型 | 代表 | 特征 | 周期位置（2025–2026） |
| --- | --- | --- | --- |
| 酱香 | 茅台、习酒、郎酒、国台 | 工艺复杂、产能周期长、易被赋予收藏属性 | 从"酱酒热"高点回落，去库存中 |
| 浓香 | 五粮液、泸州老窖、洋河 | 产能大、受众广、价格带覆盖全 | 稳中承压，龙头集中 |
| 清香 | 汾酒、牛栏山 | 出酒率高、成本低、口感接受度高 | 结构性受益于大众消费 |

酱香型白酒的产能特点是"**时间刚性**"：以茅台镇核心产区的传统工艺为例，基酒从投料、蒸煮、发酵、取酒，到分型贮存、勾调、再贮存出厂，是一个跨越数年、无法被资本快速压缩的物理过程。这既是护城河，也是"无法在需求高峰快速放量"的天花板。

### 15.3 贵州茅台的传统酿造工艺（公开常识性描述）

- **"12987"工艺**：一年一个生产周期，两次投料，九次蒸煮，八次发酵，七次取酒。
- **基酒贮存**：新酒需长期贮存老熟，茅台酒从基酒到成品出厂的时间跨度通常在数年以上。
- **勾调**：以不同轮次、不同酒龄、不同典型体的基酒按比例勾兑，不加任何外来物质（"以酒勾酒"）。
- **产区限定**：核心产区的地理、气候、水质、微生物群落被认为是不可复制的生产要素。

> 工艺细节是茅台"稀缺性叙事"的物理基础：**离开茅台镇酿不出茅台酒**，这一说法虽带有营销色彩，但产能受产区与时间双重约束是事实。

### 15.4 渠道体系的演进与三层价格

理解茅台的关键之一，是分清**三个价格**：

| 价格类型 | 含义 | 决定方 | 2026 年 3 月调整后 |
| --- | --- | --- | --- |
| 出厂价 | 公司卖给经销商的价格 | 公司 | 飞天 1,269 元 |
| 自营零售价 | 公司自营渠道的建议售价 | 公司 | 1,539 元 |
| 市场批价 | 市场流通环节的实际成交价 | 供需 | 由供需决定，波动最大 |

**渠道结构**：茅台渠道大致分为两块——

| 渠道 | 形态 | 特点 |
| --- | --- | --- |
| 直销 | i 茅台 App、自营店、团购、电商直营 | 价格可控、利润留存高、可直接触达消费者 |
| 批发代理 | 经销商、商超、部分电商平台 | 覆盖广、回款稳定，但价格管理难度大 |

直销占比的提升，是茅台过去数年利润弹性优于收入弹性的重要原因：**同样的酒，通过自营渠道卖出去，公司拿到的收入显著高于批发渠道**。因此直销占比的变化，是观察茅台盈利能力的一个关键变量。

### 15.5 批价为何是"最重要的民间指标"

- 批价是渠道的真实温度计：它反映的是**经销商、黄牛、消费者三方对未来的预期**，而非公司的账面收入。
- 批价长期低于出厂价时，渠道会亏损、抛货、退出，公司的压货能力随之下降。
- 批价高于出厂价时，价差成为渠道利润，公司具备"提价回收价差"的空间。
- 因此**"批价—出厂价的价差"本质上是公司未来提价空间的度量**，也是市场情绪的直接映射。

### 15.6 行业集中度与"茅五泸"格局

- 白酒行业整体产量连年下滑（2025 年全国规模以上白酒产量 354.9 万千升，同比 -12.1%，为连续第九年下滑），但**龙头企业的收入与利润集中度持续提升**。
- 高端白酒的竞争格局高度稳定：茅台、五粮液、泸州老窖构成"茅五泸"三强，长期占有千元以上价格带。
- 与啤酒、乳业不同，白酒行业**不存在通过价格战争夺份额的现实空间**——价格是品牌的一部分，降价会伤害长期资产。这决定了龙头之间的竞争主要是"心智战"和"渠道战"，而非"价格战"。

## 十六、国际化尝试与年轻化探索

### 16.1 国际化的现实与天花板

| 维度 | 现状 | 原因 |
| --- | --- | --- |
| 出口历史 | 早自 20 世纪 50 年代即有出口创汇记录 | 历史上的外汇贡献者 |
| 海外收入占比 | 长期较低，以公司披露口径为准 | 白酒消费高度依赖中餐文化与社交场景 |
| 主要销往地 | 海外华人社区、免税渠道、部分高端餐饮 | 华人是核心客群，本地化渗透有限 |
| 核心障碍 | 烈酒税负、饮用文化、餐酒搭配习惯 | 与威士忌、白兰地的饮酒场景差异大 |

**判断**：国际化是长期方向，但短期难以成为主要增长来源。更现实的路径是"服务海外华人 + 借势中餐出海"，而非正面挑战国际烈酒巨头的本土市场。

### 16.2 年轻化：把品牌"翻译"给下一代

茅台近年最受关注的实验，是把高度白酒的品牌资产向年轻客群延伸：

| 尝试 | 时间（公开报道） | 目的 |
| --- | --- | --- |
| 茅台冰淇淋 | 2022 年起 | 用低门槛产品触达年轻人，建立"尝过茅台"的首次体验 |
| 与咖啡品牌联名 | 2023 年起 | 借高频消费场景放大话题度 |
| 与巧克力品牌联名 | 2023 年起 | 拓展礼品与社交场景 |
| 数字营销平台（i 茅台） | 2022 年起 | 直接掌握年轻用户的数字化触点 |

**理性看待**：联名产品的直接收入有限，其价值主要在**品牌曝光与心智预埋**。真正的年轻化难题在于——白酒的核心消费场景（商务宴请、礼赠）与年轻人的饮酒偏好存在结构性错位，这并非几款联名产品可以解决。

### 16.3 产能与时间：茅台的"慢变量"

- 高端酒产能的扩张受制于产区资源、基酒贮存周期与质量标准，**无法在短期内大幅提升**。
- 这意味着茅台的增长曲线天然是"平滑而缓慢"的，既不可能是爆发式增长，也不容易出现产能过剩的崩塌。
- 对投资者而言，**"产量—销量—吨价"三者的拆解**，比看总营收数字更能看清增长质量。

## 十七、分析框架与关键判断清单

### 17.1 一页纸理解贵州茅台

| 问题 | 结论 |
| --- | --- |
| 它卖的是什么？ | 不是白酒，而是**稀缺性 + 社交货币 + 品牌溢价** |
| 它的产能能扩张吗？ | 能，但受产区与时间约束，是慢变量 |
| 它的定价权从哪来？ | 长期供不应求形成的品牌共识与渠道价差空间 |
| 它的利润为什么高于同行？ | 品牌溢价 + 直销占比提升 + 极低财务成本 |
| 它的最大风险是什么？ | 需求端（经济周期、消费习惯变化）而非供给端 |
| 它的估值锚是什么？ | PE、股息率、以及"核心资产"的流动性溢价 |

### 17.2 跟踪清单（建议按季度更新）

**必看指标**

| 指标 | 为什么要看 |
| --- | --- |
| 营业总收入 / 营业收入增速 | 区分口径，判断真实增长 |
| 归母净利润增速 | 利润弹性是否仍在 |
| 茅台酒 vs 系列酒拆分 | 基本盘与第二曲线的强弱 |
| 直销 / 批发收入占比 | 利润率变化的结构性原因 |
| 市场批价 | 渠道真实温度与未来提价空间 |
| 经营活动现金流 | 收入的"含金量" |
| 分红率与回购 | 股东回报的确定性 |
| 合同负债 | 渠道打款意愿的先行指标 |

### 17.3 容易踩的三个认知陷阱

1. **把批价当股价**：批价反映渠道情绪，股价反映二级市场预期，两者相关但不等价。
2. **把高毛利当护城河**：高毛利是结果，护城河是"产区 + 时间 + 品牌共识"的组合，前者消失得比后者快。
3. **把历史增速当未来增速**：2025 年的"双降"已经证明，没有任何一家公司能免疫周期，茅台也不例外。

### 17.4 与其他板块的关联

| 关联板块 | 关联逻辑 |
| --- | --- |
| 消费与零售 | 高端白酒是可选消费的"温度计" |
| 宏观经济与政策 | 商务活动、流动性、居民资产负债表影响需求 |
| 金融与投资 | 茅台是 A 股核心资产定价体系的标杆样本之一 |
| 公司与产业（其他篇目） | 与可口可乐对照理解"品牌资产"；与平安、招行对照理解"高 ROE 商业模式" |

## 小结

- **贵州茅台的本质是"稀缺产能 + 品牌心智 + 定价权"的生意**：毛利率 91.18%、净利率 50.53%、ROE 32.53%，是 A 股财务质量最好的公司之一。
- **2025 年是历史性转折**：营业总收入 1,720.54 亿元、营业收入 1,688.38 亿元（-1.21%）、归母净利润 823.20 亿元（-4.53%），为上市以来首次营收与利润"双降"。
- **结构上"茅台酒稳、系列酒弱"**：茅台酒营收 1,465 亿元（+0.39%）守住基本盘，系列酒 222.75 亿元（-9.76%）明显承压。
- **行业进入深度调整**：2025 年全国规模以上白酒产量 354.9 万千升（-12.1%），连续第九年下滑；需求走弱、批价承压、渠道去库存。
- **财务极其稳健**：资产负债率 16.42%、现金余额 1,264.26 亿元、流动比率 5.09，几乎没有财务风险。
- **股东回报创历史新高**：2025 年分红 650.33 亿元、分红率 79%，并配合注销式回购与大股东增持。
- **价格体系调整**：2026 年 3 月飞天茅台出厂价由 1,169 元上调至 1,269 元，自营零售价由 1,499 元上调至 1,539 元。
- **对我们的意义**：贵州茅台是理解"品牌定价权""稀缺性经济学""高端消费周期"与"A 股核心资产估值"的最佳样本之一。
