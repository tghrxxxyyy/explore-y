# 中国平安（Ping An）
> 中国最大的综合金融集团之一，以保险为根基，通过"综合金融 + 医疗养老"双轮驱动，把寿险、产险、银行、资管、科技与医疗服务装进一个体系，靠 13.9 万亿元总资产搭建起庞大的金融生态。

### 1.2 地位速览

- **资产规模**：总资产 13.90 万亿元（2025 年末），是中国最大的综合金融集团之一。
- **股东权益**：归母股东权益 1.00 万亿元（10,004.19 亿元）。
- **盈利能力**：2025 年归母净利润 1,347.78 亿元，同比增长 6.45%；ROE 13.97%。
- **每股指标**：每股收益 7.68 元，每股净资产 55.25 元。
- **现金流**：2025 年经营活动现金流量净额 6,586.32 亿元，自由现金流充沛。
- **业务结构**：以寿险及健康险为核心，产险、银行、资管、科技、医疗养老协同。
- **估值特征**：A 股 PB 约 0.94 倍（破净），PE 约 5–6 倍，股息率约 5%，是典型的低估值高分红金融股。

### 1.3 为什么中国平安值得研究

- 它是**中国综合金融模式的开创者**：把保险、银行、资管、科技、医疗装进一个集团，形成跨业务协同。
- 它是**中国寿险改革的样本**：从"人海战术"转向"高质量代理人"，经历痛苦的转型期。
- 它是**"保险 + 医疗养老"战略的实践者**：把医疗服务作为保险的差异化竞争力。
- 它是**低估值高分红金融资产的代表**：PB 破净、股息率约 5%，是理解中国金融股估值逻辑的关键样本。
- 它是**科技孵化的先行者**：陆金所、金融壹账通、平安好医生等曾独立上市，是保险集团科技化的少数案例。

### 2.2 阶段划分

**第一阶段（1988–2003）：从财险到综合金融**
- 从深圳一家财险公司起步，1994 年进入寿险。
- 逐步获得银行、信托、证券等牌照，向综合金融集团演进。
- 建立以"平安文化"著称的强执行力组织。

**第二阶段（2004–2010）：两地上市与银行布局**
- 2004 年港股上市、2007 年 A 股上市，资本实力大幅增强。
- 2008 年金融危机中投资富通集团巨亏，成为重要教训。
- 2010 年入股深发展，后整合为平安银行，补齐银行短板。

**第三阶段（2011–2018）：科技驱动与生态扩张**
- 提出"科技引领金融"，孵化陆金所、平安好医生、金融壹账通等平台。
- 形成"金融服务 + 医疗健康 + 汽车服务 + 房产服务"的生态。
- 代理人队伍规模扩张，保费高速增长。

**第四阶段（2019 年至今）：寿险改革与价值回归**
- 2019 年起启动寿险改革，从"人海战术"转向"高质量代理人"。
- 改革阵痛期：代理人脱落、新业务价值承压。
- 2023 年提出"综合金融 + 医疗养老"双轮驱动。
- 2024–2025 年新业务价值回升，业绩重回稳健增长。

| 维度 | 情况 |

- **非车险扩张**：责任险、农险、健康险等非车险业务是增长方向。

## 四、商业模式与盈利来源

### 4.1 保险公司的赚钱逻辑

- **第一层：承保利润**。保费收入减去赔付与费用，即"承保盈亏"（产险看综合成本率）。
- **第二层：投资收益**。把保费形成的保险资金投资于债券、股票、不动产等，赚取投资收益。
- **第三层：利差**。长期寿险的预定利率与投资收益之间的利差，是寿险利润的核心来源。
- **第四层：综合金融协同**。寿险、产险、银行、资管、科技之间交叉销售，降低获客成本。
- **第五层：医疗养老服务收入**。健康管理、养老服务本身的收入与客户黏性价值。

### 4.2 中国平安的独特模式

| 特征 | 说明 |
| --- | --- |
| 综合金融 | 一个客户、多种产品、一站式服务 |
| 交叉销售 | 保险、银行、资管客户互相转化 |
| 统一品牌 | 平安品牌覆盖全业务线 |
| 科技赋能 | 数字化平台提升效率与风控 |
| 医疗养老 | 差异化服务提升客户黏性 |
| 强执行力 | 以"平安文化"著称的组织能力 |

### 4.4 利润的三个口径

| 口径 | 含义 | 用途 |
| --- | --- | --- |
| 归母净利润 | 会计口径的当期利润 | 反映当期经营结果 |
| 营运利润 | 剔除短期投资波动与一次性因素 | 反映核心经营能力 |
| 内含价值 | 现有业务未来利润的现值 | 衡量寿险价值 |

- **为什么区分**：保险公司利润受投资市场波动影响大，营运利润与内含价值更能反映核心经营。
- **关注重点**：寿险看新业务价值（NBV）与内含价值（EV），产险看综合成本率，集团看营运利润。

## 六、竞争格局

### 6.1 中国保险业格局

| 类型 | 代表公司 | 特征 |

| 产险 | 人保财险、平安产险、太保产险 | 车险与非车险 |
| 综合金融 | 中国平安 | 保险 + 银行 + 资管 + 科技 |
| 互联网保险 | 众安在线、水滴等 | 线上获客，规模较小 |
| 外资/合资 | 友邦、中意人寿等 | 高端市场与细分领域 |

### 6.2 主要寿险对手对比

| 公司 | 特点 | 相对平安的差异 |
| --- | --- | --- |
| 中国人寿 | 规模最大，国资背景 | 渠道以个险 + 银保为主，综合金融弱 |
| 中国太保 | 稳健经营 | 综合金融程度低于平安 |
| 新华保险 | 专注寿险 | 业务单一 |
| 友邦中国 | 高端代理人 | 高端市场强，规模较小 |
| 平安寿险 | 综合金融 + 医疗养老 | 交叉销售与生态优势 |

### 6.3 主要产险对手对比

| 公司 | 地位 | 相对平安产险的差异 |
| --- | --- | --- |
| 人保财险 | 中国第一 | 规模最大，车险份额领先 |
| 平安产险 | 中国第二 | 集团协同 + 科技能力 |
| 太保产险 | 第三 | 稳健增长 |
| 众安在线 | 互联网 | 纯线上，规模较小 |

### 6.4 竞争格局要点

- **寿险竞争转向"价值"**：从规模竞争转向新业务价值与代理人质量竞争。
- **产险竞争在车险**：车险费改后，综合成本率与渠道效率成为关键。
- **综合金融是平安的独特性**：跨业务协同与交叉销售是其他保险集团难以复制的。
- **医疗养老是差异化**：把医疗服务与保险结合，提升客户黏性与获客效率。
- **估值是共同压力**：整个中国保险板块都面临 PB 破净与估值中枢下移。

## 七、护城河与核心优势

### 7.1 护城河评估

| 护城河 | 强度 | 说明 |
| --- | --- | --- |
| 综合金融牌照 | 极强 | 保险、银行、资管、信托、证券多牌照 |
| 交叉销售能力 | 强 | 2 亿级客户在体系内互相转化 |
| 品牌与规模 | 强 | 中国最大的综合金融集团之一 |
| 代理人体系 | 强 | 经历改革后向高质量转型 |
| 投资能力 | 强 | 保险资金投资管理与风控 |
| 医疗养老生态 | 中强 | 差异化服务提升客户黏性 |
| 科技能力 | 中强 | 数字化平台与风控技术 |

### 7.2 逐条分析

- **综合金融是最大差异化**：一个客户可以在平安体系内购买寿险、产险、银行、资管产品，获客成本低、客户价值高。
- **交叉销售的数据基础**：统一的客户体系与数据平台使交叉销售可量化、可优化。
- **庞大的保险资金**：13.9 万亿元总资产中的保险资金是长期资本，可配置长久期资产。
- **代理人队伍的转型**：改革后代理人数量下降但产能提升，人均价值贡献上升。
- **医疗养老的黏性**：医疗服务（家庭医生、在线问诊、养老社区）使保险从"一次性交易"变成"长期服务关系"。
- **科技能力的内化**：陆金所、金融壹账通等孵化出的技术能力，反哺集团风控与运营效率。

### 7.3 护城河的边界

- **寿险改革尚未完成**：代理人转型仍需时间，新业务价值增长仍需验证。
- **投资端波动大**：保险利润高度依赖资本市场表现，波动明显。
- **银行板块竞争力有限**：平安银行在股份行中并非最优秀，零售信贷资产质量承压。
- **科技子公司盈利难**：陆金所、金融壹账通等面临盈利与估值压力。
- **估值中枢下移**：整个保险板块估值承压，平安也难以独善其身。

## 八、风险与挑战

### 8.1 风险清单

| 风险类型 | 具体表现 | 影响程度 |
| --- | --- | --- |
| 利率下行 | 压制投资收益与利差 | 极高 |
| 投资端波动 | 资本市场波动直接影响利润 | 高 |
| 寿险改革不及预期 | 新业务价值增长不确定 | 高 |
| 资产质量 | 银行与地产敞口 | 中高 |
| 监管合规 | 保险、银行、科技多牌照监管 | 中高 |
| 房地产风险 | 不动产投资敞口 | 中高 |
| 银行竞争 | 平安银行竞争力与息差 | 中 |
| 科技子公司 | 盈利与估值压力 | 中 |

### 8.2 利率与投资风险

- **利差损风险**：长期寿险的预定利率若高于投资收益率，会形成"利差损"，是寿险公司最大的长期风险。
- **投资波动**：2025 年一季度归母净利润同比下降 26.4%，即受投资端波动影响。
- **资产配置**：保险公司需要在长久期债券、权益、不动产之间平衡收益与风险。
- **应对**：下调产品预定利率、优化资产配置、发展保障型产品。

### 8.3 寿险改革风险

| 风险 | 说明 |
| --- | --- |
| 代理人脱落 | 改革削减低效代理人，短期保费承压 |
| 新业务价值波动 | 转型期新业务价值增长不稳定 |
| 竞争加剧 | 同业也在推进高质量转型 |
| 客户需求变化 | 保障型与储蓄型产品需求结构变化 |

### 8.4 其他挑战

- **房地产敞口**：保险公司在不动产与地产债上的投资敞口是市场关注点。
- **银行板块**：平安银行的零售信贷资产质量与息差压力。
- **科技子公司**：陆金所、金融壹账通等的盈利与估值问题。
- **合规成本**：多牌照经营意味着多线监管，合规成本高。

## 十五、保险行业核心指标详解

### 15.1 寿险核心指标

| 指标 | 含义 | 关注点 |
| --- | --- | --- |
| 新业务价值（NBV） | 新签保单未来利润的现值 | 反映增长质量 |
| 内含价值（EV） | 现有业务未来利润的现值 + 调整后净资产 | 衡量寿险业务价值 |
| 新业务价值率 | 新业务价值 / 新单保费 | 反映产品盈利能力 |
| 代理人产能 | 人均新业务价值或保费 | 反映队伍质量 |
| 13 个月留存率 | 代理人 13 个月后仍在职比例 | 反映队伍稳定性 |
| 预定利率 | 产品定价假设的投资收益率 | 决定利差损风险 |

### 15.2 产险核心指标

| 指标 | 含义 | 判断标准 |
| --- | --- | --- |
| 综合成本率 | 赔付率 + 费用率 | 低于 100% 为承保盈利 |
| 赔付率 | 赔付支出 / 已赚保费 | 反映风险定价 |
| 费用率 | 费用支出 / 已赚保费 | 反映渠道效率 |
| 车险综合成本率 | 车险业务的承保盈亏 | 费改后竞争关键 |

### 15.3 集团层面指标

| 指标 | 含义 |
| --- | --- |
| 营运利润 | 剔除短期投资波动与一次性因素的核心利润 |
| ROE | 反映股东资本的回报效率 |
| 内含价值（集团） | 集团层面寿险价值的综合衡量 |
| 综合偿付能力充足率 | 反映资本充足程度 |
| 保险资金投资收益率 | 反映投资端能力 |

### 15.4 为什么不能只看净利润

- **投资波动干扰**：保险公司利润受资本市场波动影响极大，单年净利润可能大幅偏离经营实质。
- **寿险利润递延**：长期寿险的利润在保单生命周期内逐步释放，当期利润无法反映全部价值。
- **多口径对照**：应同时看归母净利润、营运利润、新业务价值与内含价值。

| 养老金融政策 | 利好养老与健康业务 |
| 房地产政策 | 影响不动产投资敞口 |

### 16.3 政策敏感点

- **预定利率**：直接决定寿险产品的定价与利差损风险。
- **报行合一**：影响银保渠道的规模与费用结构。
- **偿付能力**：决定资本使用效率与分红能力。
- **养老金融**：个人养老金等政策打开增量空间。

## 二十、综合金融与交叉销售机制深读

### 20.1 客户迁徙的机制逻辑

综合金融不是"把几家公司放在一起"，而是让同一个客户在体系内多次成交。其底层机制可以拆成四层：

| 机制层 | 内容 | 作用 |
| --- | --- | --- |
| 身份层 | 统一客户号与统一账户，一个客户对应唯一标识 | 让"同一人"在各子公司可被识别 |
| 数据层 | 客户资产、负债、保单、交易行为在合规前提下形成画像 | 让交叉销售从"盲打"变成"有依据的推荐" |
| 渠道层 | 代理人、银保网点、社区网格、线上平台共用客户触点 | 一个触点可承接多条产品线的销售动作 |
| 激励层 | 考核与分润机制让A业务的员工愿意推荐B业务的产品 | 解决"谁来卖"的动力问题 |

客户迁徙本质上是**信任的复用**：客户对平安某一环节（如一张保单、一张信用卡）建立信任后，向银行理财、资管产品、车险、医疗养老服务扩散时的决策成本显著低于从零获客。文件中"一个客户、多种产品、一站式服务"的表述，指的就是这条迁徙链。

### 20.2 交叉销售漏斗

把交叉销售理解为一个漏斗，每一段都有独立的损耗原因：

| 漏斗环节 | 关键动作 | 主要损耗来源 |
| --- | --- | --- |
| 触达 | 通过既有保单服务、账单、APP、代理人联系客户 | 客户失联、触达渠道单一 |
| 识别 | 判断客户缺什么产品（保障缺口、闲置资金、车险到期） | 数据不全、画像失真 |
| 推荐 | 由合适的渠道（代理人/理财经理/线上）给出方案 | 渠道能力不匹配、打扰式营销引发反感 |
| 转化 | 完成投保、开户或签约 | 产品力不足、价格无优势、合规适当性未通过 |
| 留存 | 服务期内持续经营，形成第二次迁徙 | 服务体验差、理赔纠纷、竞品替代 |

几个关键判断：

- **漏斗的瓶颈通常不在"触达"而在"识别"与"转化"**。平安拥有大量存量客户，真正稀缺的是"在正确的时间向正确的人推荐正确的产品"的能力。
- **交叉销售的经济学**：新增一个客户的边际获客成本高，而在存量客户身上卖第二件产品的成本低得多。这就是文件中"获客成本低、客户价值高"的机制来源。
- **漏斗的负外部性**：过度交叉销售会变成骚扰式营销，损害品牌与客户信任，甚至触发销售适当性合规问题——因此成熟的交叉销售体系必然伴随频控与合规审查。

### 20.3 各业务线的迁徙方向与互补性

| 迁徙方向 | 驱动力 | 客户价值变化 |
| --- | --- | --- |
| 寿险 → 财险 | 家庭形成后出现车险、家财险需求 | 从单张保单到家庭保单组合 |
| 寿险 → 银行 | 保单贷款、年金给付、储蓄迁移 | 资产端沉淀，银行获得低成本存款 |
| 银行 → 寿险 | 银保渠道客户的保障与养老配置 | 银行为保险公司提供分销场景 |
| 保险/银行 → 资管 | 高净值客户的财富管理需求 | 管理费收入，增强客户黏性 |
| 保险 → 医疗养老 | 保障型客户对健康管理与养老服务的天然需求 | 从"赔付方"升级为"服务方" |
| 医疗养老 → 保险 | 健康服务使用中识别出保障缺口 | 以服务场景反向带动保险销售 |

值得注意的是迁徙的**不对称性**：银行客户向保险迁徙（银保）路径成熟、规模大，但价值率通常低于个险渠道；而保险客户向医疗养老迁徙更多体现为黏性与留存，而非直接保费。两类迁徙的经营目标不同，不能用同一套 KPI 衡量。

### 20.4 代理人渠道改革与交叉销售的关系

代理人改革与综合金融是同一战略的两条线，其耦合点在于：

| 维度 | 改革前（人海战术） | 改革后（高质量） |
| --- | --- | --- |
| 队伍逻辑 | 靠人数堆保费，增员即增长 | 靠人均产能，优胜劣汰 |
| 客户经营 | 单次成交，关系随离职中断 | 长期客户经营，一个代理人服务一个客户群 |
| 交叉销售 | 代理人只卖自家寿险产品 | 具备向客户配置多产品能力，成为综合金融入口 |
| 关键指标 | 代理人数量、保费规模 | 人均产能、留存率、新业务价值 |
| 与生态关系 | 服务是售后成本 | 医疗养老服务成为销售与留存的工具 |

机制上，**高质量代理人是交叉销售最好的载体**：低质量代理人连单一产品都难以讲清，更不可能做跨产品配置；只有能长期服务同一客户的代理人，才可能把客户从一张保单带到家庭整体方案。这也解释了为什么文件把"代理人从人海转向高质量"与"综合金融"放在同一战略框架下——前者是后者的组织前提。

同时要看到改革的约束：代理人数量收缩期间，交叉销售的"人手"本身在减少，短期会压制交叉销售的绝对规模；改革红利只有在代理人质量提升后才能兑现。

### 20.5 成本协同：综合金融为什么可能更便宜

| 成本项 | 独立公司模式 | 综合金融模式 | 协同来源 |
| --- | --- | --- | --- |
| 获客成本 | 各业务线各自投放广告、各自建渠道 | 一次获客多次复用 | 统一品牌与存量客户池 |
| 品牌成本 | 多品牌各自建设 | 单一"平安"品牌覆盖全业务 | 品牌资产复用 |
| IT 与数据成本 | 每家自建核心系统与数据平台 | 平台能力共享 | 科技中台复用 |
| 合规与风控成本 | 分散建设 | 集中化风控与合规体系 | 规模摊薄 |
| 客户服务成本 | 多套客服、多套 APP | 统一入口与统一服务 | 服务资源整合 |

但协同不是免费的，它有三类隐性成本，分析时必须一起看：

- **内部转移定价成本**：A业务给B业务导流，如何分润？定价不公会引发内部博弈，甚至导致激励扭曲。
- **管理复杂度成本**：多牌照意味着矩阵式管理、多线监管、多套资本约束，集团层面的管理费用与协调成本高于单一业务公司。
- **风险传染成本**：各业务通过资金往来与客户关联绑定，任一板块出问题（如银行资产质量、地产敞口）会波及整体声誉与估值——文件中"监管合规：保险、银行、科技多牌照监管"被列为中高影响风险，正是这一点的体现。

因此判断协同是否真实成立，应看**交叉销售的增量毛利是否覆盖上述隐性成本**，而非只看保费或客户数的表面加总。

### 20.6 监管约束：综合金融的边界在哪里

综合金融的监管逻辑是"牌照隔离 + 关联交易穿透 + 资本独立"，主要约束有：

| 约束类型 | 具体表现 | 对交叉销售的影响 |
| --- | --- | --- |
| 牌照分业 | 保险、银行、证券、信托分属不同监管条线 | 产品不能随意跨线销售，需各自持牌主体展业 |
| 关联交易监管 | 集团内部交易需公允定价、披露 | 分润与资金往来须可审计，限制"左手倒右手" |
| 客户信息保护 | 个人信息保护与金融数据合规 | 数据共享必须取得授权，画像能力受边界约束 |
| 销售适当性 | 各类产品有各自的适当性要求 | 跨产品推荐必须匹配客户风险承受能力 |
| 偿付能力与资本约束 | 保险资本占用独立核算 | 各子公司不能无限制互相输送资本 |
| 反垄断与竞争政策 | 大型集团市场力量受关注 | 排他性捆绑销售的空间被压缩 |

一个常被忽略的判断：**监管约束实际上决定了交叉销售漏斗的"转化率上限"**。数据不能自由打通，推荐就做不到精准；资本不能自由调拨，协同就只能靠业务层面的分润而非集团层面的补贴。换句话说，综合金融的成本优势天然比理论上限要小——研究平安的协同效应时，应把它当作"受监管约束的协同"，而非教科书式的完全协同。

### 20.7 综合金融机制的评估框架

评估交叉销售与协同是否真正创造价值，可用以下框架（全部为定性判断维度）：

| 观察维度 | 正向信号 | 警示信号 |
| --- | --- | --- |
| 客户数与客均产品数 | 存量客户人均持有产品数持续提升 | 客户数增长但产品数不增 |
| 获客结构 | 新客户中有相当比例来自老客户推荐 | 依然高度依赖外部投放 |
| 渠道产能 | 代理人产能随综合金融推进提升 | 产能提升只来自单产品涨价 |
| 内部博弈 | 分润机制清晰、业务线主动协同 | 各业务各自为战、导流需行政摊派 |
| 客户体验 | 一站式服务减少客户摩擦 | 骚扰式营销、投诉上升 |
| 风险隔离 | 各板块风险事件未扩散 | 单一板块风险拖累集团估值 |

## 二十一、保险+医疗养老生态专题

### 21.1 战略定位：为什么保险集团要做医疗养老

保险与医疗养老之间存在天然的业务耦合，这不是跨界噱头，而是由保险产品的本质决定的：

| 耦合点 | 保险方的诉求 | 医疗养老方的诉求 |
| --- | --- | --- |
| 风险数据 | 健康数据帮助核保与定价 | 稳定的支付方与客户来源 |
| 支付能力 | 保险资金是医疗服务的长期支付方 | 养老与医疗服务需要可信赖的付费方 |
| 客户生命周期 | 健康险、养老险对应客户全生命周期 | 医疗养老需要持续活跃的客户群 |
| 黏性与留存 | 服务型保单降低退保与流失 | 高频服务接触带来持续需求 |
| 差异化竞争 | 纯产品竞争陷入价格战 | 服务难以被纯金融对手复制 |

核心逻辑可以概括为：**保险卖的是"事后赔付"，医疗养老提供的是"事前预防 + 事中服务"，二者结合后，保险从一次性交易变成长期服务关系**。文件中"买保险送服务"的表述，正是这层机制的通俗说法。

### 21.2 健康险与医疗服务闭环

健康险的经营难点在于：赔付率不可控、逆选择、客户在健康时感知不到价值。医疗服务的引入针对的正是这三个问题：

| 环节 | 纯健康险 | 健康险 + 医疗服务闭环 |
| --- | --- | --- |
| 获客 | 依赖比价与渠道 | 以服务入口（问诊、体检、健康管理）切入 |
| 核保定价 | 依赖有限的健康告知与历史数据 | 可结合持续的健康管理数据理解风险 |
| 风控理赔 | 事后审核，被动控费 | 事前干预、事中控费，降低不必要的医疗支出 |
| 客户感知 | 平时无感，出险才用 | 日常可用，服务频率远高于理赔频率 |
| 客户留存 | 保障到期即流失 | 服务关系延续，续保与加保概率提高 |

闭环的关键在于**医疗服务既是成本项也是风控工具**：健康管理做得好，理论上可以降低出险率与赔付强度，使"控费"与"客户体验"不再对立。但这一机制的前提是服务方与保险方的利益一致——若服务按项目收费，反而可能诱发过度医疗。因此闭环是否有效，取决于支付与激励机制的设计，而非服务项目数量本身。

需要强调的分析边界：健康险的赔付规律、医疗服务的控费效果，均受地区医疗环境、人口结构与监管政策影响，本节只做机制层面的定性分析，不给出任何效果量化判断。

### 21.3 居家养老与高端养老社区：两种模式对比

文件披露平安在养老上同时布局"管家式居家养老服务"与"高品质养老社区"。两条路线的机制差异如下：

| 维度 | 居家养老 | 高端养老社区 |
| --- | --- | --- |
| 服务场景 | 客户家中，依托上门与远程服务 | 机构化社区，集中式居住与照护 |
| 资产属性 | 轻资产，服务网络与调度能力为主 | 重资产或重运营，涉及物业、设施与人力 |
| 覆盖客群 | 更广，覆盖大多数居家养老的存量老人 | 高净值或高支付意愿客群 |
| 客户痛点 | 日常照护、紧急响应、就医陪同 | 专业照护、社交陪伴、医疗配套 |
| 与保险的连接 | 作为保单附加服务提升黏性 | 可与养老年金、长期护理保障形成组合 |
| 规模化难度 | 服务标准化与供给端管理难 | 单点投资大、周期长、入住率爬坡慢 |
| 风险特征 | 服务质量参差、供给分散 | 资本占用与运营风险更高 |

两种模式并非替代关系，而是**客群分层**：居家养老承接"大多数人的大多数时光"，养老社区承接"需要专业照护的阶段"。对保险集团而言，二者的共同价值在于把养老从"概念"变成"可交付的服务"，从而支撑养老年金、长期护理类产品的销售与留存——服务本身未必是利润中心，但可能是产品销售的杠杆。

同时应注意，养老服务供给（护理人力、社区运营、医疗配套）在中国仍属稀缺资源，**供给能力往往是瓶颈而非需求**。养老生态的实际成效，最终取决于服务网络能否稳定交付，而非战略表述的完整度。

### 21.4 平安好医生（平安健康）在生态中的角色

| 角色 | 具体功能 | 对集团的价值 |
| --- | --- | --- |
| 流量入口 | 在线问诊、健康管理、家庭医生触达客户 | 高频接触点，为低频金融产品提供触达场景 |
| 服务交付方 | 承接保险保单附带的健康管理服务 | 让"保险 + 服务"可落地，而非停留在条款 |
| 数据节点 | 记录健康行为与服务使用 | 在合规前提下丰富客户画像 |
| 品牌与生态位 | 互联网医疗品牌 | 补齐"医疗"这一环，使双轮战略完整 |
| 独立资本市场定位 | 港股上市主体 | 科技与医疗板块的价值可被独立观察 |

分析其角色时要区分两个层面：

- **作为业务**：在线医疗本身盈利模式（问诊、药品、健康管理、企业服务）面临激烈的互联网医疗竞争，其经营质量需要单独评估——文件也把"科技子公司普遍面临盈利压力"列为挑战。
- **作为生态组件**：即使该板块自身盈利贡献有限，它对保险主业的价值也可能体现在降低获客成本、提升留存与差异化定价上。**生态价值与并表利润是两回事**，评估时不能只看其单独损益。

另一个常见误区是把互联网医疗等同于医疗生态的全部。实际上，线下医疗资源（医院、医生、药品供应、养老机构）的合作深度，往往比 APP 的活跃度更决定"保险 + 医疗"闭环的成色。线上平台更像枢纽，而非全部资产。

### 21.5 双轮驱动的耦合机制：医疗养老如何反哺综合金融

"综合金融 + 医疗养老"双轮并非两条平行线，其耦合方式可拆解为：

| 耦合路径 | 机制描述 |
| --- | --- |
| 服务 → 保险 | 医疗养老服务创造接触场景，在场景中识别保障缺口并转化保险销售 |
| 保险 → 服务 | 保险保单附带健康与养老服务，提高产品溢价能力与续保率 |
| 服务 → 银行 | 养老与医疗支付场景沉淀资金与账户，为银行带来结算与储蓄机会 |
| 数据 → 风控 | 合规的健康与服务数据辅助核保、理赔与风险定价 |
| 品牌 → 获客 | "综合金融 + 医疗养老"的完整叙事降低单一保险产品的同质化竞争 |

其对估值的间接意义在于：当利率下行压制保险利差时，"不依赖利差的客户价值"（服务黏性、生态收入、交叉销售增量）成为市场观察平安能否摆脱纯利差依赖的窗口——这也呼应文件把医疗养老列为"战略新引擎"的定位。

### 21.6 生态战略的风险与验证要点

任何生态战略都容易停留在叙事层面，判断其是否兑现，应关注以下定性信号：

| 风险/疑问 | 机制解释 | 观察角度 |
| --- | --- | --- |
| 服务成本吞噬保险利润 | 服务若按项目付费且无法控费，附加服务等于变相打折 | 服务是带来溢价还是侵蚀价值率 |
| 供给端交付不稳定 | 医疗与养老人力供给稀缺，扩张快于交付能力会损害体验 | 服务投诉与履约质量 |
| 协同变现周期长 | 从"服务客户"到"转化为高价值保单"需要多年经营周期 | 客户迁徙是否形成持续路径而非一次性营销 |
| 各板块利益不一致 | 服务板块要收入、保险板块要成本控制，内部博弈可能抵消协同 | 分润机制与考核设计 |
| 监管与数据合规 | 健康数据属敏感个人信息，共享与使用受限 | 数据使用的授权与合规边界 |
| 独立板块盈利压力 | 平安好医生等自身盈利难度影响生态可持续性 | 板块自身经营质量 |
| 外部竞争 | 互联网医疗、地产养老、专业健康险公司均在竞争 | 平安服务是否难以被复制 |

综合来看，医疗养老生态的**战略方向与保险主业高度契合，但兑现路径长、变量多**。定性判断上，它更适合作为"护城河的加深机制"而非"当期利润的直接来源"——这与文件将其列为"中强"护城河、"尚在验证"的表述一致。

## 小结

- **中国平安的本质是"综合金融 + 医疗养老"双轮驱动的金融集团**：以保险为根基，向银行、资管、科技、医疗养老延伸。
- **2025 年稳健增长**：营业收入 10,505.06 亿元，归母净利润 1,347.78 亿元（+6.45%），总资产 13.90 万亿元，归母股东权益 1.00 万亿元。
- **盈利质量较高**：ROE 13.97%、ROA 1.18%，经营活动现金流净额 6,586.32 亿元。
- **寿险是核心价值来源**：经历多年改革，代理人从"人海"转向"高质量"，新业务价值是核心观察指标。
- **产险是稳健基本盘**：平安产险为中国第二大财产保险公司，车险为核心，综合成本率决定承保盈亏。
- **医疗养老是差异化竞争**："保险 + 医疗养老"提升客户黏性，是区别于同业的关键。
- **估值处于历史低位**：PB 约 0.94 倍（破净）、PE 约 5–6 倍、股息率约 5.1%，是典型的低估值高分红金融资产。
- **对我们的意义**：中国平安是理解"综合金融模式""寿险改革""保险资金投资"与"低估值金融股定价"的最佳样本之一。
