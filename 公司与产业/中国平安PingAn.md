# 中国平安（Ping An）
> 中国最大的综合金融集团之一，以保险为根基，通过"综合金融 + 医疗养老"双轮驱动，把寿险、产险、银行、资管、科技与医疗服务装进一个体系，靠 13.9 万亿元总资产搭建起庞大的金融生态。

### 1.2 地位速览

- **资产规模**：总资产 13.90 万亿元（2025 年末），是中国最大的综合金融集团之一。
- **股东权益**：归母股东权益 1.00 万亿元（10,004.19 亿元）。
- **盈利能力**：2025 年归母净利润 1,347.78 亿元，同比增长 6.45%；ROE 13.97%。
- **每股指标**：每股收益 7.68 元，每股净资产 55.25 元。
- **现金流**：2025 年经营活动现金流量净额 6,586.32 亿元，自由现金流充沛。
- **业务结构**：以寿险及健康险为核心，产险、银行、资管、科技、医疗养老协同。
- **估值特征**：A 股 PB 约 0.94 倍（破净），PE 约 5–6 倍，股息率约 5%，是典型的低估值高分红金融股。

### 1.3 为什么中国平安值得研究

- 它是**中国综合金融模式的开创者**：把保险、银行、资管、科技、医疗装进一个集团，形成跨业务协同。
- 它是**中国寿险改革的样本**：从"人海战术"转向"高质量代理人"，经历痛苦的转型期。
- 它是**"保险 + 医疗养老"战略的实践者**：把医疗服务作为保险的差异化竞争力。
- 它是**低估值高分红金融资产的代表**：PB 破净、股息率约 5%，是理解中国金融股估值逻辑的关键样本。
- 它是**科技孵化的先行者**：陆金所、金融壹账通、平安好医生等曾独立上市，是保险集团科技化的少数案例。

### 2.2 阶段划分

**第一阶段（1988–2003）：从财险到综合金融**
- 从深圳一家财险公司起步，1994 年进入寿险。
- 逐步获得银行、信托、证券等牌照，向综合金融集团演进。
- 建立以"平安文化"著称的强执行力组织。

**第二阶段（2004–2010）：两地上市与银行布局**
- 2004 年港股上市、2007 年 A 股上市，资本实力大幅增强。
- 2008 年金融危机中投资富通集团巨亏，成为重要教训。
- 2010 年入股深发展，后整合为平安银行，补齐银行短板。

**第三阶段（2011–2018）：科技驱动与生态扩张**
- 提出"科技引领金融"，孵化陆金所、平安好医生、金融壹账通等平台。
- 形成"金融服务 + 医疗健康 + 汽车服务 + 房产服务"的生态。
- 代理人队伍规模扩张，保费高速增长。

**第四阶段（2019 年至今）：寿险改革与价值回归**
- 2019 年起启动寿险改革，从"人海战术"转向"高质量代理人"。
- 改革阵痛期：代理人脱落、新业务价值承压。
- 2023 年提出"综合金融 + 医疗养老"双轮驱动。
- 2024–2025 年新业务价值回升，业绩重回稳健增长。

| 维度 | 情况 |
| --- | --- |
| 定位 | 集团的核心利润来源 |

- **渠道多元化**：代理人、银保、社区网格化等渠道并行。

- **非车险扩张**：责任险、农险、健康险等非车险业务是增长方向。

## 四、商业模式与盈利来源

### 4.1 保险公司的赚钱逻辑

- **第一层：承保利润**。保费收入减去赔付与费用，即"承保盈亏"（产险看综合成本率）。
- **第二层：投资收益**。把保费形成的保险资金投资于债券、股票、不动产等，赚取投资收益。
- **第三层：利差**。长期寿险的预定利率与投资收益之间的利差，是寿险利润的核心来源。
- **第四层：综合金融协同**。寿险、产险、银行、资管、科技之间交叉销售，降低获客成本。
- **第五层：医疗养老服务收入**。健康管理、养老服务本身的收入与客户黏性价值。

### 4.2 中国平安的独特模式

| 特征 | 说明 |
| --- | --- |
| 综合金融 | 一个客户、多种产品、一站式服务 |
| 交叉销售 | 保险、银行、资管客户互相转化 |
| 统一品牌 | 平安品牌覆盖全业务线 |
| 科技赋能 | 数字化平台提升效率与风控 |
| 医疗养老 | 差异化服务提升客户黏性 |
| 强执行力 | 以"平安文化"著称的组织能力 |

### 4.4 利润的三个口径

| 口径 | 含义 | 用途 |
| --- | --- | --- |
| 归母净利润 | 会计口径的当期利润 | 反映当期经营结果 |
| 营运利润 | 剔除短期投资波动与一次性因素 | 反映核心经营能力 |
| 内含价值 | 现有业务未来利润的现值 | 衡量寿险价值 |

- **为什么区分**：保险公司利润受投资市场波动影响大，营运利润与内含价值更能反映核心经营。
- **关注重点**：寿险看新业务价值（NBV）与内含价值（EV），产险看综合成本率，集团看营运利润。

## 六、竞争格局

### 6.1 中国保险业格局

| 类型 | 代表公司 | 特征 |

| 产险 | 人保财险、平安产险、太保产险 | 车险与非车险 |
| 综合金融 | 中国平安 | 保险 + 银行 + 资管 + 科技 |
| 互联网保险 | 众安在线、水滴等 | 线上获客，规模较小 |
| 外资/合资 | 友邦、中意人寿等 | 高端市场与细分领域 |

### 6.2 主要寿险对手对比

| 公司 | 特点 | 相对平安的差异 |
| --- | --- | --- |
| 中国人寿 | 规模最大，国资背景 | 渠道以个险 + 银保为主，综合金融弱 |
| 中国太保 | 稳健经营 | 综合金融程度低于平安 |
| 新华保险 | 专注寿险 | 业务单一 |
| 友邦中国 | 高端代理人 | 高端市场强，规模较小 |
| 平安寿险 | 综合金融 + 医疗养老 | 交叉销售与生态优势 |

### 6.3 主要产险对手对比

| 公司 | 地位 | 相对平安产险的差异 |
| --- | --- | --- |
| 人保财险 | 中国第一 | 规模最大，车险份额领先 |
| 平安产险 | 中国第二 | 集团协同 + 科技能力 |
| 太保产险 | 第三 | 稳健增长 |
| 众安在线 | 互联网 | 纯线上，规模较小 |

### 6.4 竞争格局要点

- **寿险竞争转向"价值"**：从规模竞争转向新业务价值与代理人质量竞争。
- **产险竞争在车险**：车险费改后，综合成本率与渠道效率成为关键。
- **综合金融是平安的独特性**：跨业务协同与交叉销售是其他保险集团难以复制的。
- **医疗养老是差异化**：把医疗服务与保险结合，提升客户黏性与获客效率。
- **估值是共同压力**：整个中国保险板块都面临 PB 破净与估值中枢下移。

## 七、护城河与核心优势

### 7.1 护城河评估

| 护城河 | 强度 | 说明 |
| --- | --- | --- |
| 综合金融牌照 | 极强 | 保险、银行、资管、信托、证券多牌照 |
| 交叉销售能力 | 强 | 2 亿级客户在体系内互相转化 |
| 品牌与规模 | 强 | 中国最大的综合金融集团之一 |
| 代理人体系 | 强 | 经历改革后向高质量转型 |
| 投资能力 | 强 | 保险资金投资管理与风控 |
| 医疗养老生态 | 中强 | 差异化服务提升客户黏性 |
| 科技能力 | 中强 | 数字化平台与风控技术 |

### 7.2 逐条分析

- **综合金融是最大差异化**：一个客户可以在平安体系内购买寿险、产险、银行、资管产品，获客成本低、客户价值高。
- **交叉销售的数据基础**：统一的客户体系与数据平台使交叉销售可量化、可优化。
- **庞大的保险资金**：13.9 万亿元总资产中的保险资金是长期资本，可配置长久期资产。
- **代理人队伍的转型**：改革后代理人数量下降但产能提升，人均价值贡献上升。
- **医疗养老的黏性**：医疗服务（家庭医生、在线问诊、养老社区）使保险从"一次性交易"变成"长期服务关系"。
- **科技能力的内化**：陆金所、金融壹账通等孵化出的技术能力，反哺集团风控与运营效率。

### 7.3 护城河的边界

- **寿险改革尚未完成**：代理人转型仍需时间，新业务价值增长仍需验证。
- **投资端波动大**：保险利润高度依赖资本市场表现，波动明显。
- **银行板块竞争力有限**：平安银行在股份行中并非最优秀，零售信贷资产质量承压。
- **科技子公司盈利难**：陆金所、金融壹账通等面临盈利与估值压力。
- **估值中枢下移**：整个保险板块估值承压，平安也难以独善其身。

## 八、风险与挑战

### 8.1 风险清单

| 风险类型 | 具体表现 | 影响程度 |
| --- | --- | --- |
| 利率下行 | 压制投资收益与利差 | 极高 |
| 投资端波动 | 资本市场波动直接影响利润 | 高 |
| 寿险改革不及预期 | 新业务价值增长不确定 | 高 |
| 资产质量 | 银行与地产敞口 | 中高 |
| 监管合规 | 保险、银行、科技多牌照监管 | 中高 |
| 房地产风险 | 不动产投资敞口 | 中高 |
| 银行竞争 | 平安银行竞争力与息差 | 中 |
| 科技子公司 | 盈利与估值压力 | 中 |

### 8.2 利率与投资风险

- **利差损风险**：长期寿险的预定利率若高于投资收益率，会形成"利差损"，是寿险公司最大的长期风险。
- **投资波动**：2025 年一季度归母净利润同比下降 26.4%，即受投资端波动影响。
- **资产配置**：保险公司需要在长久期债券、权益、不动产之间平衡收益与风险。
- **应对**：下调产品预定利率、优化资产配置、发展保障型产品。

### 8.3 寿险改革风险

| 风险 | 说明 |
| --- | --- |
| 代理人脱落 | 改革削减低效代理人，短期保费承压 |
| 新业务价值波动 | 转型期新业务价值增长不稳定 |
| 竞争加剧 | 同业也在推进高质量转型 |
| 客户需求变化 | 保障型与储蓄型产品需求结构变化 |

### 8.4 其他挑战

- **房地产敞口**：保险公司在不动产与地产债上的投资敞口是市场关注点。
- **银行板块**：平安银行的零售信贷资产质量与息差压力。
- **科技子公司**：陆金所、金融壹账通等的盈利与估值问题。
- **合规成本**：多牌照经营意味着多线监管，合规成本高。

## 十五、保险行业核心指标详解

### 15.1 寿险核心指标

| 指标 | 含义 | 关注点 |
| --- | --- | --- |
| 新业务价值（NBV） | 新签保单未来利润的现值 | 反映增长质量 |
| 内含价值（EV） | 现有业务未来利润的现值 + 调整后净资产 | 衡量寿险业务价值 |
| 新业务价值率 | 新业务价值 / 新单保费 | 反映产品盈利能力 |
| 代理人产能 | 人均新业务价值或保费 | 反映队伍质量 |
| 13 个月留存率 | 代理人 13 个月后仍在职比例 | 反映队伍稳定性 |
| 预定利率 | 产品定价假设的投资收益率 | 决定利差损风险 |

### 15.2 产险核心指标

| 指标 | 含义 | 判断标准 |
| --- | --- | --- |
| 综合成本率 | 赔付率 + 费用率 | 低于 100% 为承保盈利 |
| 赔付率 | 赔付支出 / 已赚保费 | 反映风险定价 |
| 费用率 | 费用支出 / 已赚保费 | 反映渠道效率 |
| 车险综合成本率 | 车险业务的承保盈亏 | 费改后竞争关键 |

### 15.3 集团层面指标

| 指标 | 含义 |
| --- | --- |
| 营运利润 | 剔除短期投资波动与一次性因素的核心利润 |
| ROE | 反映股东资本的回报效率 |
| 内含价值（集团） | 集团层面寿险价值的综合衡量 |
| 综合偿付能力充足率 | 反映资本充足程度 |
| 保险资金投资收益率 | 反映投资端能力 |

### 15.4 为什么不能只看净利润

- **投资波动干扰**：保险公司利润受资本市场波动影响极大，单年净利润可能大幅偏离经营实质。
- **寿险利润递延**：长期寿险的利润在保单生命周期内逐步释放，当期利润无法反映全部价值。
- **多口径对照**：应同时看归母净利润、营运利润、新业务价值与内含价值。

| 养老金融政策 | 利好养老与健康业务 |
| 房地产政策 | 影响不动产投资敞口 |

### 16.3 政策敏感点

- **预定利率**：直接决定寿险产品的定价与利差损风险。
- **报行合一**：影响银保渠道的规模与费用结构。
- **偿付能力**：决定资本使用效率与分红能力。
- **养老金融**：个人养老金等政策打开增量空间。

## 小结

- **中国平安的本质是"综合金融 + 医疗养老"双轮驱动的金融集团**：以保险为根基，向银行、资管、科技、医疗养老延伸。
- **2025 年稳健增长**：营业收入 10,505.06 亿元，归母净利润 1,347.78 亿元（+6.45%），总资产 13.90 万亿元，归母股东权益 1.00 万亿元。
- **盈利质量较高**：ROE 13.97%、ROA 1.18%，经营活动现金流净额 6,586.32 亿元。
- **寿险是核心价值来源**：经历多年改革，代理人从"人海"转向"高质量"，新业务价值是核心观察指标。
- **产险是稳健基本盘**：平安产险为中国第二大财产保险公司，车险为核心，综合成本率决定承保盈亏。
- **医疗养老是差异化竞争**："保险 + 医疗养老"提升客户黏性，是区别于同业的关键。
- **估值处于历史低位**：PB 约 0.94 倍（破净）、PE 约 5–6 倍、股息率约 5.1%，是典型的低估值高分红金融资产。
- **对我们的意义**：中国平安是理解"综合金融模式""寿险改革""保险资金投资"与"低估值金融股定价"的最佳样本之一。
