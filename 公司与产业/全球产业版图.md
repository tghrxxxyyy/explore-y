# 全球产业版图

> 先看地图再看公司：全球主要产业（半导体 / AI / 新能源汽车 / 消费 / 金融 / 先进制造）的格局、关键玩家与产业链关系，是理解各公司档案的前提。本文是「公司与产业」板块的总览篇。

## 一、六大产业的版图速览

| 产业 | 产业链核心 | 全球关键玩家 | 中国的角色 | 周期与趋势 |
| --- | --- | --- | --- | --- |
| 半导体 | 设计 → 制造 → 封测 → 设备材料 | 英伟达、台积电、三星、ASML、英特尔 | 设计强（华为海思）、制造追赶（中芯国际） | 强周期 + AI 拉动 |
| AI 与云 | 算力 → 模型 → 应用 | 微软、谷歌、英伟达、OpenAI、亚马逊 | 华为、阿里、字节、百度、DeepSeek | 高增长、资本开支竞赛 |
| 新能源汽车 | 电池 → 整车 → 充电网络 | 特斯拉、比亚迪、丰田、大众 | 全球最大市场与产能 | 增速放缓、洗牌期 |
| 消费品牌 | 品牌 → 渠道 → 供应链 | 苹果、可口可乐、麦当劳、耐克 | 出海品牌崛起（安克等） | 低增长、护城河为王 |
| 金融 | 存款 → 信贷 → 投行 → 资管 | 摩根大通、伯克希尔、黑石 | 工农中建、招行、平安 | 周期敏感、利率驱动 |
| 先进制造 | 上游材料 → 核心部件 → 整机 | 丰田、三星、西门子、霍尼韦尔 | 全球最大制造基地、升级中 | 跟随全球贸易与地缘 |

## 二、半导体：算力时代的"石油"

- **链条**：芯片设计（英伟达/苹果）→ 晶圆代工（台积电/三星/中芯）→ 封测 → 上游设备（ASML 光刻机）与材料。
- **关键事实**：先进制程（7nm 以下）全球能做的只有台积电、三星、英特尔三家；AI 芯片（GPU）需求爆发让英伟达与台积电成为 2023-2025 最大赢家。
- **中国视角**：设计端已有全球竞争力，制造端受设备限制仍在追赶；芯片自给率提升是国家战略，也是长期投资主题。
- **普通人关注点**：手机/电脑价格、显卡价格、AI 应用成本——都跟着这条链走。

## 三、AI 与云：正在重塑所有产业

- **三层结构**：算力层（英伟达 GPU、数据中心）→ 模型层（OpenAI、谷歌 Gemini、开源 DeepSeek）→ 应用层（搜索、办公、客服、编程）。
- **云是底座**：微软 Azure、亚马逊 AWS、谷歌云、阿里云——AI 大部分在云上跑，云厂商是"卖铲人"。
- **中国玩家**：华为（昇腾芯片+盘古）、阿里（通义）、字节（豆包）、百度（文心）；国产算力与开源模型并行发展。
- **普通人关注点**：AI 工具选哪家、岗位会不会被替代、AI 相关行业机会——本板块档案逐一展开。

## 四、新能源汽车：中国换道超车的主战场

- **格局**：中国贡献全球约 60% 的新能源车销量；比亚迪全球销量第一，特斯拉靠品牌与智能化维持高端。
- **产业链**：电池（宁德时代全球份额约 1/3）→ 整车 → 智能化（座舱、智驾）；垂直整合（比亚迪自造电池）是成本优势来源。
- **风险**：2025 年起行业进入价格战与淘汰期，二线品牌洗牌；欧美关税与本地化建厂是出海的新考题。
- **普通人关注点**：买车决策（油电之争）、充电体验、电池寿命与二手车保值。

## 五、消费品牌：护城河在"心智"不在工厂

- **规律**：全球消费巨头（可口可乐、麦当劳、耐克、苹果）的护城河是**品牌心智 + 渠道网络 + 供应链规模**，产品本身容易被模仿，心智很难。
- **特许经营模式**：麦当劳、肯德基卖的不只是汉堡，是加盟体系与地产；可口可乐靠"浓缩液+灌装商"轻资产扩张。
- **中国视角**：新消费出海（手机、小家电、游戏、跨境电商）正在复制这套路径；内需消费是长期主线之一。
- **普通人关注点**：消费选择、国货 vs 外资、通胀环境下品牌定价权。

## 六、金融：经济的血液循环系统

- **银行**：赚利差（存款利息 < 贷款利息），规模与风控是命脉；摩根大通是全球标杆，中国四大行规模全球前列。
- **保险与资管**：伯克希尔用"浮存金"（保费先收后赔）做长期投资，是巴菲特模式的基石；黑石代表另类资产。
- **中国视角**：利率下行压缩银行利差；居民财富从存款转向理财/基金/保险是长期趋势。
- **普通人关注点**：存款利率、贷款成本、理财收益——都受这个产业的定价规则影响。

## 七、先进制造：从"世界工厂"到"高端突围"

- **日本**（丰田、索尼、佳能）、**韩国**（三星、LG）、**德国**（西门子、宝马）各守阵地；中国在光伏、电池、家电、造船已全球领先，正向半导体设备、工业软件、高端机床攻坚。
- **产业链特点**：上游材料与核心零部件利润最高，整机组装利润最薄——"微笑曲线"两端才是高价值区。
- **普通人关注点**：就业机会（制造业升级需要工程师）、国货品质信任度。

## 八、怎么用本板块

1. **先读本文**建立产业地图，再进各公司档案看细节。
2. **公司档案八节结构**：简介地位 → 收入结构 → 商业模式 → 竞争格局 → 产业链 → 财务 → 风险 → 对我们的意义。
3. 档案中的数字均为约数，用于建立量级感，**不构成投资建议**；想深入了解再查年报与官方公告。
