## 使用建议

1. **先总览后档案**：从《全球产业版图》建立产业地图，再深入具体公司。
2. **按需求阅读**：换工作看对应行业公司档案的「对我们的意义」；学投资先看商业模式与护城河两节；聊行业话题看竞争格局与产业链。
3. **档案结构统一**：简介地位 → 收入结构 → 商业模式 → 竞争格局 → 产业链 → 财务 → 风险 → 对我们的意义，方便横向对比。
