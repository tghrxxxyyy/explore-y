# 亚马逊（Amazon）

> 全球最大电商与云计算公司，以"飞轮"模式著称：电商规模、Prime 会员、AWS 云服务互相强化。

## 一、公司简介与地位

- **成立时间**：1994 年，总部位于美国华盛顿州西雅图（Seattle）。
- **市值**：2024-2025 年市值约 2 万亿美元级。
- **营收与利润**：2024 年营收约 6300-6400 亿美元（全球科技公司营收第一），净利润约 500-600 亿美元，净利率约 8-9%。
- **全球地位**：全球最大电商平台（除中国），全球云市场份额第一（AWS 约 30%），美国在线广告第三极。
- **一句话概括**：把"零售的薄利"和"云的厚利"放在同一家公司，用规模与物流构筑别人难以复制的壁垒。
- **发展历程**：网上书店 → 全品类电商 → Prime + 自建物流 → AWS 云帝国 → 广告与 AI，始终用"长期主义"把利润再投入新业务。

## 二、核心业务与收入结构

| 业务板块 | 大致收入占比 | 说明 |
| --- | --- | --- |
| 线上商店（自营零售） | 约 40% | 规模大但毛利低，是流量与飞轮起点 |
| 第三方卖家服务（佣金、物流 FBA） | 约 25% | 高毛利增长点，平台化转型核心 |
| AWS（云服务） | 约 15-17% | 利润主力，贡献大部分营业利润 |
| 广告业务 | 约 9-10% | 增速最快，利润率极高的"意外惊喜" |
| 订阅（Prime 会员）与其他 | 约 8-10% | Prime 是生态粘性的核心 |

- **近年增长点**：AWS 重回两位数增长并由 AI 云需求带动；广告业务年增 20%+；第三方卖家与物流服务（Buy with Prime）持续扩张；AI 助手 Rufus 与生成式 AI 服务（Bedrock）落地。
- **收入结构趋势**：自营零售占比缓慢下降，第三方服务、广告、云等高毛利业务占比上升，利润结构持续改善。
- **海外市场**：北美与欧洲为主，印度、中东增长快；中国等市场以"卖家供货"方式参与而非直接运营。

## 三、商业模式与护城河

- **怎么赚钱**：零售薄利引流，靠 Prime 订阅锁定用户、第三方佣金与物流费赚钱，利润大头来自 AWS 与广告。
- **护城河一：飞轮效应**：低价 + 海量选品 → 更多用户 → 更多卖家 → 更低成本 → 更低价格，正反馈循环难以打破。
- **护城河二：物流基建**：全球自建仓储与配送网络（当日达/次日达），重资产投入形成长期壁垒。
- **护城河三：Prime 生态**：会员订阅绑定购物、视频、音乐等权益，用户留存与消费频次极高。
- **护城河四：AWS 规模与技术**：云市场份额第一，功能广度、价格与生态领先，规模效应显著。
- **护城河五：数据与推荐**：用户购物行为数据驱动的个性化推荐，提升转化率与客单价。
- **护城河六：现金流模型**：把"应付账款 + 预售"的运营现金流投向新业务，用别人的钱扩张，是财务设计上的独门武器。

## 四、竞争格局

| 竞争对手 | 定位 | 相对亚马逊的差异 |
| --- | --- | --- |
| 沃尔玛 | 线下 + 线上零售巨头 | 线下网络强，电商与物流追赶中 |
| Temu/Shein（拼多多系） | 极致低价跨境电商 | 价格战侵蚀低价市场份额，供应链直连 |
| 微软 Azure / 谷歌云 | 云市场份额二三位 | 在云市场与 AWS 正面竞争，AI 服务各有优势 |
| Shopify 等 | 独立站 SaaS | 帮卖家"脱离亚马逊"，分走平台佣金 |
| TikTok/Instagram 电商 | 内容电商 | 争夺冲动消费与广告预算 |

- **竞争要点**：零售端最凶的对手来自中国跨境电商（Temu/Shein），云市场则要同时应对微软与谷歌的 AI 云攻势。
- **零售技术投入**：机器人仓储、无人机配送、AI 库存预测等自动化投入，是其在物流效率上保持领先的长期赌注。
- **Prime 全球化**：Prime 会员已覆盖数十个国家，权益不断扩展，是"以订阅锁定消费"商业模式的全球样本。

## 五、产业链位置

- **上游**：全球数百万第三方卖家（中国卖家占比高）、品牌供应商、物流与包装供应商；AWS 上游是芯片（英伟达、自研 Trainium）与数据中心。
- **下游**：全球 C 端消费者、中小企业（云与电商基础设施客户）、广告主。
- **行业地位**：对卖家有极强议价权（佣金 + 广告 + 物流多重收费，卖家"不得不做"）；对消费者定价权弱（电商比价激烈）；AWS 对客户议价权强但面临云厂商降价战。
- **卖家生态**：数百万第三方卖家贡献过半商品成交额，平台抽成与广告体系已形成"亚马逊税"式收入结构。

## 六、财务与增长指标（约数）

| 指标 | 数值（2024 年） |
| --- | --- |
| 营收 | 约 6300-6400 亿美元 |
| 净利润 | 约 500-600 亿美元 |
| 毛利率 | 整体约 40-50%（零售拖累，AWS 超 60%） |
| 净利率 | 约 8-9% |
| AWS 利润率 | 营业利润率约 30%+ |
| 研发投入 | 约 900 亿美元级（含资本开支） |
| 员工人数 | 约 150 万+ |

- **财务特点**：营收全球最大但净利率低（零售拉低），利润高度依赖 AWS 与广告，属于"规模换利润"的典型。
- **利润率波动**：物流投入与裁员等经营决策对季度利润影响大，财报"利润率能见度"较低，是理解其估值的难点。

## 七、风险与争议

- **反垄断**：美国 FTC 起诉其垄断电商（强制卖家绑定物流等）；欧盟《数字市场法》将其列为"守门人"监管。
- **劳工争议**：仓库工作强度、员工待遇与工会化运动（美国首个仓库工会成立）。
- **零售利润薄**：零售业务长期低毛利甚至亏损波动，依赖 AWS 输血，若云增长放缓整体承压。
- **中国电商冲击**：Temu/Shein 的低价策略直接侵蚀其低价盘与广告预算。
- **AI 时代压力**：AWS 面对微软/谷歌 AI 云竞争，若算力需求被竞争对手分流，增长叙事受损。
- **治理与口碑**：疫情期间"仓库虐待"报道、2019 年取消纽约总部等事件，反映其在公众与政治层面经常"吃力不讨好"。

## 八、对我们的意义

- **消费视角**：Prime 会员"订阅换便利"是典型消费决策样本——高频购物才划算；比价时注意第三方卖家与自营差异；中国跨境平台（Temu 等）让"亚马逊购物"有了更便宜替代。
- **就业视角**：电商运营、物流管理、AWS 云架构师是热门岗位；大量跨境卖家与仓储就业与平台规则强相关，卖家需评估"平台依赖"风险。
- **投资视角**（不构成建议）：亚马逊是"零售利润薄 + 云与广告利润厚"的复合体，理解它的关键是指标拆分（AWS 与广告的利润贡献），而不是整体营收；跟踪 AWS 增速、反垄断进展与中国对手冲击。

## 九、核心产品线深度解析

### 9.1 电商业务

| 业务模式 | 特点 | 收入占比（约） |
| --- | --- | --- |
| 自营零售（1P） | 亚马逊自己采购并销售商品 | 约 40% |
| 第三方卖家（3P） | 商家入驻，亚马逊提供平台+物流 | 约 25% |
| 广告 | 卖家竞价推广（Sponsored Products） | 约 9-10% |
| Prime 会员 | 年费订阅，绑定购物+视频+音乐权益 | 约 5-6% |

- **全球覆盖**：在 20+ 个国家运营电商站点，覆盖北美、欧洲、日本、澳大利亚、印度等核心市场。
- **商品品类**：从书籍起家，如今覆盖 3.5 亿+ SKU，涵盖电子产品、服装、家居、食品等全品类。
- **价格策略**：以低价+便捷为核心竞争力，常年"赔本卖货"引流，靠广告与服务赚钱。

### 9.2 AWS 云服务详解

| 服务类型 | 核心产品 | 市场地位 |
| --- | --- | --- |
| 计算 | EC2、Lambda（无服务器） | 全球第一，功能最全 |
| 存储 | S3（对象存储）、EBS（块存储） | 行业标准 |
| 数据库 | RDS、DynamoDB、Aurora | 多种数据库引擎选择 |
| AI/ML | SageMaker、Bedrock、Trainium | 企业级 AI 平台 |
| 容器 | EKS（Kubernetes）、Fargate | 容器化部署领先 |
| 物联网 | IoT Core、Greengrass | IoT 平台 |

- **收入规模**：2024 年 AWS 收入约 1050 亿美元，年增约 19%，营业利润率约 30%+。
- **客户结构**：超 100 万活跃客户，覆盖初创公司、大型企业、政府机构；Netflix、Airbnb、NASA 等为标杆客户。
- **AI 服务**：Amazon Bedrock（托管多模型 API）、Trainium/Inferentia（自研 AI 芯片）是差异化竞争点。

### 9.3 Prime 会员生态

- **全球会员数**：约 2 亿+付费会员，主要分布在美国、欧洲、日本。
- **核心权益**：免费两日/当日达配送、Prime Video（流媒体）、Prime Music、Prime Reading、Amazon Photos、早期折扣。
- **会员价值**：Prime 会员年均消费约 1400 美元，是非会员的约 2 倍；会员续费率约 90%+。
- **国际扩张**：印度、巴西、中东等新兴市场 Prime 会员快速增长，通过本地化权益（如印度独家体育赛事转播）拉动渗透。

### 9.4 硬件产品线

| 产品 | 定位 | 市场表现 |
| --- | --- | --- |
| Kindle | 电子书阅读器 | 全球电子书市场主导地位 |
| Fire 平板 | 低价安卓平板 | 入门级市场有价格优势 |
| Echo / Alexa | 智能音箱+语音助手 | 美国智能音箱市场第一 |
| Fire TV | 流媒体电视棒 | 与 Roku、Apple TV 竞争 |
| Ring | 智能门铃/安防 | 智能家居安防领先品牌 |
| Blink | 室内/室外摄像头 | 低成本安防方案 |

- **硬件逻辑**：硬件本身利润极低甚至亏损，核心目的是"锁定用户进入亚马逊生态"——Kindle 锁定阅读、Echo 锁定购物与智能家居、Fire TV 锁定内容消费。
- **Alexa 语音助手**：月活超 1 亿，但商业化进展缓慢（语音购物场景有限），正在接入生成式 AI 能力。

## 十、物流网络深度解析

### 10.1 全球物流基础设施

| 设施类型 | 数量/规模（约） | 说明 |
| --- | --- | --- |
| 运营中心/仓库 | 1000+ 座 | 覆盖全球，核心在北美与欧洲 |
| 配送站 | 3000+ 个 | 最后一公里配送 |
| 飞机 | 100+ 架（Amazon Air） | 自有货运航空机队 |
| 卡车/货车 | 数万辆 | 干线运输与城市配送 |
| 机器人 | 75 万+ 台（Proteus/Sequoia） | 仓储自动化 |

- **当日/次日达覆盖**：全球超 3 亿+ 商品支持当日或次日达，美国 Prime 会员约 60%+ 订单可实现当日达。
- **物流成本优势**：规模效应使单件配送成本约 3-5 美元，低于行业平均的 5-8 美元。

### 10.2 FBA（Fulfillment by Amazon）

- **服务模式**：卖家将商品送至亚马逊仓库，由亚马逊负责存储、拣货、包装、配送与客服。
- **收入来源**：仓储费+配送费+长期库存费，FBA 是第三方卖家服务收入的核心。
- **卖家依赖**：约 70%+ 第三方卖家使用 FBA，FBA 是获得"Prime 标签"（高曝光+高转化）的前提条件。
- **争议**：卖家投诉 FBA 费用持续上涨、库存管理不透明，形成"亚马逊税"式成本负担。

### 10.3 Buy with Prime

- **模式**：允许第三方网站（Shopify 商家等）使用亚马逊物流与支付，将 Prime 会员体验延伸到亚马逊之外。
- **战略意义**：将亚马逊物流能力"平台化"，直接挑战 Shopify 自有物流与 FedEx/UPS。
- **增长**：2023 年推出后快速扩张，2024 年已有数万商家接入，是亚马逊物流变现的新渠道。

### 10.4 物流技术与自动化

- **仓储机器人**：Proteus（首个可与人协同工作的自主移动机器人）、Sequoia（新一代分拣系统）、Sparrow（AI 机械臂拣选）。
- **无人机配送**：Prime Air 无人机配送在美国部分地区试运营，目标实现 30 分钟内轻量包裹配送。
- **AI 预测**：基于用户行为预测下单，提前将商品调配至离用户最近的仓库（"预期配送"），缩短配送时间。

> 来源：亚马逊物流年报、MWPVL International 物流数据、Wall Street Journal 物流报道

## 十一、AI 布局

### 11.1 Alexa 与生成式 AI

- **升级方向**：Alexa 正从"语音助手"升级为"对话式 AI 助手"，接入 LLM（大语言模型）实现自然对话与复杂任务。
- **付费订阅**：Alexa+（增强版）计划推出付费订阅，是 Alexa 商业化的重要尝试。
- **挑战**：用户主要用 Alexa 播放音乐、控制家居，"语音购物"场景渗透率低，商业化路径不清晰。

### 11.2 Amazon Bedrock

- **产品定位**：托管式 AI 基础模型 API 平台，开发者可通过 API 调用多家模型（Anthropic Claude、Meta Llama、Stability AI 等）。
- **差异化**：不只提供自家模型，而是做"模型超市"，让企业客户自由选择最适合的模型。
- **增长**：2024 年 Bedrock 客户数与 API 调用量均实现数倍增长，是 AWS AI 服务收入的核心增长点。

### 11.3 自研 AI 芯片

| 芯片 | 用途 | 特点 |
| --- | --- | --- |
| Trainium | 模型训练 | 成本比英伟达 GPU 低约 40-50% |
| Inferentia | 模型推理 | 高吞吐、低延迟推理优化 |
| Trainium 2 | 下一代训练芯片 | 2025 年量产，性能大幅提升 |

- **战略意义**：降低 AWS 对英伟达的依赖，同时为客户降低成本——AI 算力成本是企业上云的核心考量之一。

> 来源：AWS re:Invent 2024 大会、The Verge Alexa 报道、AnandTech 芯片分析

## 十二、反垄断监管

### 12.1 美国 FTC 诉讼

- **诉讼内容**：2023 年 FTC 起诉亚马逊垄断电商，指控其通过惩罚使用非亚马逊物流的卖家、强制 FBA 绑定等手段维持垄断。
- **核心争议**："Buy Box"算法偏向亚马逊自营商品、FBA 费用持续上涨、Prime 排他性条款。
- **潜在后果**：若败诉可能面临业务拆分或运营模式强制改变，对电商生态影响深远。

### 12.2 欧盟监管

- **DMA 守门人**：亚马逊被列为"守门人"平台，需遵守数据可携、第三方卖家公平待遇等义务。
- **反垄断调查**：欧盟对亚马逊第三方卖家数据使用、Buy Box 算法等展开多项调查。

### 12.3 劳工与社会争议

- **仓库工作条件**：多次被曝仓库工人高强度工作、工伤率高、监控严格；2022 年纽约仓库成为美国首个投票成立工会的亚马逊仓库。
- **碳排放**：承诺 2040 年实现净零碳排放，但物流扩张与数据中心能耗使碳排放总量持续增长。
- **政治争议**：贝索斯个人财富、太空旅行与《华盛顿邮报》收购等事件引发公众与政界持续关注。

## 十三、领导层与企业文化

### 13.1 Andy Jassy 时代

- **接班背景**：2021 年贝索斯卸任 CEO，由 AWS 创始人 Andy Jassy 接任，标志着亚马逊从"创始人驱动"转向"职业经理人治理"。
- **战略延续**：Jassy 延续"长期主义"，加大 AI（Bedrock/Trainium）与物流投入，同时推动成本优化（2023 年裁员约 2.7 万人）。
- **领导风格**：强调"Day 1"心态（永远像创业公司一样运转），推动内部"Working Backwards"（从客户需求倒推产品）方法论。

### 13.2 企业文化特点

- **领导力准则**：14 条领导力准则（Customer Obsession、Ownership、Bias for Action 等）是内部决策与招聘的核心框架。
- **单线程团队**：每个重要项目由独立团队全权负责（"单线程领导"），减少跨部门协调成本。
- **争议文化**：高强度工作文化（"Pip 文化"）引发员工满意度争议，但也被认为是保持执行力的关键。
- **多元化承诺**：2024 年女性与少数族裔管理层占比提升至约 45%，持续推进职场多元化目标。

### 13.3 可持续发展

- **气候承诺**：2040 年实现净零碳排放（比巴黎协定提前 10 年），已订购 10 万辆 Rivian 电动送货车。

- **当日/次日达覆盖**：全球超3亿+商品支持当日或次日达，美国Prime会员约60%+订单可实现当日达。
- **物流成本优势**：规模效应使单件配送成本约3-5美元，低于行业平均的5-8美元。

### 二十一、FBA（Fulfillment by Amazon）

- **服务模式**：卖家将商品送至亚马逊仓库，由亚马逊负责存储、拣货、包装、配送与客服。
- **收入来源**：仓储费+配送费+长期库存费，FBA是第三方卖家服务收入的核心。
- **卖家依赖**：约70%+第三方卖家使用FBA，FBA是获得"Prime标签"（高曝光+高转化）的前提条件。
- **争议**：卖家投诉FBA费用持续上涨、库存管理不透明，形成"亚马逊税"式成本负担。

### 二十二、物流技术与自动化

- **仓储机器人**：Proteus（首个可与人协同工作的自主移动机器人）、Sequoia（新一代分拣系统）、Sparrow（AI机械臂拣选）。
- **无人机配送**：Prime Air无人机配送在美国部分地区试运营，目标实现30分钟内轻量包裹配送。
- **AI预测**：基于用户行为预测下单，提前将商品调配至离用户最近的仓库（"预期配送"），缩短配送时间。

## 二十三、Prime会员生态详解

### 二十四、会员权益与价值

- **模式**：允许第三方网站（Shopify商家等）使用亚马逊物流与支付，将Prime会员体验延伸到亚马逊之外。

- **增长**：2023年推出后快速扩张，2024年已有数万商家接入，是亚马逊物流变现的新渠道。

## 三十、反垄断监管详解

### 三十一、美国FTC诉讼

### 三十三、劳工与社会争议

- **政治争议**：贝索斯个人财富、太空旅行与《华盛顿邮报》收购等事件引发公众与政界持续关注。
