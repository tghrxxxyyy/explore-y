# 可口可乐（Coca-Cola）

> 全球最大的饮料公司：靠"秘方品牌 + 无处不在的渠道"卖出全球每秒钟上万瓶可乐，是消费股"护城河"的教科书。

## 一、公司简介与地位

- **成立时间**：1886 年诞生于美国亚特兰大，1892 年正式注册成立，总部位于美国佐治亚州亚特兰大（Atlanta）。
- **市值**：2024-2025 年市值约 2500-3000 亿美元，是美股消费板块市值最高的公司之一。
- **营收与利润**：2024 年营收约 470 亿美元，净利润约 100-110 亿美元，净利率约 20%+。
- **全球地位**：全球碳酸饮料市占率第一，品牌价值常居全球前三；产品销往全球 200 多个国家，日均售出约 20 亿杯。
- **一句话概括**：卖的不是糖水，是"品牌心智 + 渠道网络"两种不可复制的资产。
- **历史与符号**：诞生于美国药剂师之手，二战后随美军走向全球；圣诞老人形象、经典红白瓶身都是其营销资产的一部分。
- **股权结构**：股权高度分散、无控股股东，机构投资者为主，治理稳定；巴菲特旗下伯克希尔是其长期大股东。

## 二、核心业务与收入结构

| 业务板块 | 大致收入占比 | 说明 |
| --- | --- | --- |
| 汽水类（可口可乐、雪碧、芬达等） | 约 55-60% | 经典基本盘，含无糖可乐等健康化产品 |
| 瓶装水与运动饮料（纯悦、美汁源、Powerade） | 约 10-15% | 补水与运动场景 |
| 咖啡与茶（Costa、淳茶舍、gold peak） | 约 10% | 收购 Costa 咖啡布局现饮赛道 |
| 果汁、乳饮与其他 | 约 15-20% | 多品牌组合，含新兴低糖/无糖品类 |

- **近年增长点**：无糖产品（零度可乐）增速快于含糖；涨价与包装精简（小瓶化）驱动单箱收入；咖啡与功能性饮料是新赛道。
- **收入结构趋势**：从"可乐公司"转向"全品类饮料公司"，碳酸占比缓慢下降，健康化与多元化品类占比上升。
- **地域观察**：北美与欧洲贡献大部分利润，非洲、东南亚与拉丁美洲是销量增长引擎但单价低、汇率风险大。

## 三、商业模式与护城河

- **怎么赚钱**：把浓缩液卖给全球瓶装伙伴（特许经营体系），自己赚高毛利浓缩液钱，瓶装厂赚辛苦的渠道钱——"轻资产收品牌税"模式。
- **护城河一：品牌资产**："可口可乐"是全球认知度最高的品牌之一，百年广告投放沉淀的心智（快乐、庆典、美国文化符号）几乎无法复制。
- **护城河二：渠道网络**：全球 200 多个国家的瓶装与分销体系，货架、冰柜、餐饮渠道无处不在——"想喝就有"是最大的壁垒。
- **护城河三：特许经营模式**：与瓶装商绑定（部分持股），以极轻资产撬动全球分销，资本开支低、现金流稳定。
- **护城河四：配方与标准化**：浓缩液配方保密百年，全球口味一致；供应链与质量控制体系成熟。
- **护城河五：提价能力**：品牌忠诚度使其拥有持续提价权，即使销量持平也能靠涨价维持利润增长。
- **护城河六：营销传统**：百年来全球顶级体育赛事（奥运会、世界杯）的赞助与广告体系，让"可乐=快乐场景"的联想不断被强化。
- **护城河七：定价与规模**：全球采购、规模化生产摊薄单瓶成本，低价也能保持高毛利，新品牌几乎不可能在成本端挑战。

## 四、竞争格局

| 竞争对手 | 定位 | 相对可口可乐的差异 |
| --- | --- | --- |
| 百事可乐 | 全球饮料第二 | 产品同质，价格战激烈；百事零食业务（乐事等）互补 |
| 雀巢 | 全球食品饮料巨头 | 水与咖啡业务竞争，渠道与品类互补 |
| 元气森林/农夫山泉等中国品牌 | 本土新势力 | 在中国市场无糖茶、气泡水赛道抢份额 |
| 星巴克等现制咖啡 | 现饮场景 | 分流"提神饮料"心智，但场景不同 |
| 自有品牌（超市货） | 低价替代 | 价格敏感消费者被分流，靠品牌与渠道守住溢价 |

- **竞争要点**：可乐与百事在"口味、价格、渠道"上长期贴身肉搏，但双寡头格局反而强化了彼此的渠道壁垒，新进入者两边都打不进去。
- **结构性变化**：真正的份额流失来自"品类转移"——消费者从碳酸转向茶饮、气泡水、电解质水，这是两家巨头共同的敌人。

## 五、产业链位置

- **上游**：糖（果葡糖浆）、咖啡豆、果汁原料、PET 瓶原料（原油衍生）等大宗原料；铝罐、玻璃瓶供应商。
- **中游**：浓缩液生产高度集中于总部与少数工厂（高毛利），瓶装与分销交由全球特许瓶装伙伴（可口可乐多持股但不并表经营）。
- **下游**：超市、便利店、餐饮（麦当劳等）、自动售货机、电商等多渠道；餐饮与即时零售渠道是增长点。
- **瓶装体系**：全球瓶装伙伴（如北美、亚太的瓶装集团）承担重资产运营，可口可乐以持股与品牌授权掌控标准与利润分配。
- **行业地位**：处于产业链最顶端——掌握品牌与配方（微笑曲线两端），把制造与物流的"重资产低毛利"环节交给瓶装伙伴，自己赚取稳定高毛利。

## 六、财务与增长指标（约数）

| 指标 | 数值（2024-2025 财年） |
| --- | --- |
| 营收 | 约 470 亿美元 |
| 净利润 | 约 100-110 亿美元 |
| 毛利率 | 约 60%（浓缩液模式天然高毛利） |
| 净利率 | 约 22% |
| 日均销量 | 约 20 亿杯 |
| 品牌数量 | 全球 200+ 品牌 |
| 分红历史 | 连续 60+ 年提高股息，股息率约 3% |

- **财务特点**：营收增长平淡（个位数），但利润率、现金流与分红极其稳定，是"股息贵族"（连续几十年提高股息）代表。
- **现金回报**：每年通过分红与回购向股东返还百亿美元级现金，回购是支撑每股收益增长的重要工具。

## 七、风险与争议

- **健康化趋势**：含糖饮料受肥胖与健康消费趋势冲击，多国征收"糖税"、限制广告，核心品类长期承压。
- **原材料与汇率**：糖、铝、油价波动挤压成本，新兴市场货币贬值影响当地利润。
- **增长天花板**：汽水品类饱和，靠提价与并购维持增长，量增乏力；新兴市场（非洲、东南亚）是少数增量。
- **环保与社会争议**：塑料瓶污染受批评，减塑承诺执行进度受监督；部分市场被指水权垄断与劳工问题。
- **中国市场挑战**：中国市场份额被本土品牌（农夫山泉、元气森林、东鹏等）持续侵蚀，可乐在"瓶装水与茶饮"心智上不占优。
- **并购整合风险**：大举收购（Costa 咖啡等）后若整合不力，会摊薄毛利与品牌聚焦度，历史上有过失败案例。

## 八、对我们的意义

- **消费视角**：可乐的品牌溢价客观存在——同配方白牌糖水便宜得多，但"品牌 + 冰镇 + 场景"的体验值不值差价由你决定；无糖版本是健康化下的折中选择，但代糖争议仍在。
- **就业视角**：可乐体系（瓶装厂、渠道、营销）在全球创造大量就业，其"品牌营销 + 分销管理"的方法论是快消行业标杆；对中国从业者而言，本土品牌的崛起提供了可乐之外的职业选择。
- **投资视角**（不构成建议）：可口可乐是"防御型消费股"的经典样本——增长慢但稳定、分红厚、提价权强，适合理解"护城河与股息"概念；风险在于健康化趋势与量增停滞，属于"躺赢但难爆发"的资产。
- **商业教材视角**：它是商学院研究"品牌、渠道与特许经营"的必读案例，读懂它也就读懂了大多数快消巨头的生意本质。
