## 阅读建议

1. 按 1→5 顺序阅读，知识由近及远、由具体到宏大。
2. 第 1–2 篇建立「天体与恒星」基础；第 3 篇上升到宇宙尺度；第 4 篇深入极端物理；第 5 篇回到人类自身的探索行动。
3. 每篇末尾「主要参考来源」列出核实依据，可进一步溯源。

## 主要参考来源（贯穿全子类）

- **NASA**：太阳/行星概况页、阿波罗与旅行者任务页、国际空间站、轨道力学与火箭原理、黑洞与中子星科普。
- **IAU（国际天文联合会）**：2006 年行星定义决议。
- **EHT（事件视界望远镜）**：M87*（2019）、人马座 A*（2022）黑洞图像。
- **Planck 2018 / PDG 2024**：宇宙学参数（年龄、哈勃常数、CMB 温度、暗能量/暗物质占比）。
- **LIGO 科学合作组**：GW150914 引力波事件。
- **ESA CESAR、Britannica、Stanford Solar Center、HyperPhysics、Lumen Learning**：恒星演化与太阳系数据。
- **COBE/FIRAS**：宇宙微波背景温度测量。
