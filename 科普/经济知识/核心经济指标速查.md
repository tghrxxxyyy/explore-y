# 核心经济指标速查

> 开车看仪表盘，看经济看指标。本文用"仪表盘"类比，帮你快速理解 9 个最核心的经济指标。

## 一、仪表盘类比

经济就像一辆车：

- **速度表** = GDP（经济跑多快）
- **油温表** = CPI / PPI（通胀冷热）
- **发动机状态灯** = PMI（制造业景气）
- **油量表** = M2 / 社融（货币弹药够不够）
- **轮胎气压** = 失业率（社会是否稳当）
- **汇率显示屏** = 汇率 / 外汇储备（对外"购买力"）

看到仪表盘亮红灯，说明经济某个环节出了状况，需要关注。

## 二、核心指标详解

### 1. GDP（国内生产总值）

| 维度 | 说明 |
|------|------|
| 是什么 | 一国在一定时期内生产的所有最终商品和服务的市场价值总和 |
| 怎么读 | 看**总量**（经济体量大小）和**增速**（增长快慢） |
| 三驾马车 | 消费、投资、出口——GDP 的三个拉动引擎 |
| 哪查 | 国家统计局（每季度公布） |
| 日常关联 | GDP 强 = 就业好、收入涨、消费信心强；弱则相反 |

### 2. CPI（居民消费价格指数）

| 维度 | 说明 |
|------|------|
| 是什么 | 衡量居民日常购买的一篮子商品和服务价格变动的指标 |
| 怎么读 | 同比上涨 = 物价比去年贵了；连续上涨 = 通货膨胀 |
| 权重 | 食品烟酒约 30%，居住约 23%——猪价涨对 CPI 影响大 |
| 哪查 | 国家统计局（每月公布） |
| 日常关联 | 菜篮子、房租、出行成本，直接影响"钱够不够花" |

### 3. PPI（工业生产者出厂价格指数）

| 维度 | 说明 |
|------|------|
| 是什么 | 衡量工业品出厂价格变动的指标 |
| 怎么读 | PPI 高 = 上游涨价，企业成本上升；低 = 需求不足 |
| 传导 | PPI → CPI（上游涨价会逐步传导到消费品，但不完全） |
| 哪查 | 国家统计局（每月公布） |
| 日常关联 | PPI 负增长 → 企业利润承压 → 可能裁员降薪 |

### 4. PMI（采购经理指数）

| 维度 | 说明 |
|------|------|
| 是什么 | 通过对采购经理的月度调查汇总而成的扩散指数 |
| 怎么读 | **50 为荣枯线**：>50 扩张，<50 收缩 |
| 优势 | 比 GDP 早一个月出，是**先行指标** |
| 哪查 | 国家统计局 / 财新（每月 1 号公布） |
| 日常关联 | 连续低于 50 → 经济偏冷信号 → 就业市场承压 |

### 5. M1 与 M2（货币供应量）

| 维度 | M1 | M2 |
|------|----|----|
| 定义 | 现金 + 活期存款（随时能花的钱） | M1 + 定期存款 + 储蓄存款等 |
| 类比 | 你钱包里的现金 + 银行卡余额 | 上面 + 你定期存款 + 理财 |
| 怎么读 | M1 增速高 = 钱在"活化"，经济活跃 | M2 增速高 = 市场钱多 |
| 剪刀差 | M1 增速 > M2 → 经济活跃；反之 → 钱"趴窝" |
| 哪查 | 中国人民银行（每月公布） |

### 6. 社融（社会融资规模）

| 维度 | 说明 |
|------|------|
| 是什么 | 实体经济从金融体系获得的资金总量 |
| 怎么读 | 社融回升 = 实体经济真的拿到了钱（信用扩张） |
| 关键点 | M2 涨但社融不涨 = 钱在银行空转，没有进实体 |
| 哪查 | 中国人民银行（每月公布） |
| 日常关联 | 社融持续萎缩 → 经济收缩信号 → 政策可能出手 |

### 7. 失业率

| 维度 | 说明 |
|------|------|
| 是什么 | 劳动力中没有工作但正在寻找工作的人占比 |
| 怎么读 | 失业率上升 → 就业市场恶化；下降 → 改善 |
| 注意 | 中国公布的是"城镇调查失业率"，不含农村 |
| 哪查 | 国家统计局（每月公布） |
| 日常关联 | 直接关系到收入、消费信心、社会稳定 |

### 8. 汇率

| 维度 | 说明 |
|------|------|
| 是什么 | 两种货币之间的兑换比率（如 USD/CNY = 7.2） |
| 怎么读 | 数字上升 = 人民币贬值；下降 = 人民币升值 |
| 影响 | 贬值利好出口、利空进口；升值反之 |
| 哪查 | 中国外汇交易中心、中国人民银行 |
| 日常关联 | 留学换汇、海淘成本、出国旅游 |

### 9. 外汇储备

| 维度 | 说明 |
|------|------|
| 是什么 | 一国央行持有的外币资产总和 |
| 怎么读 | 储备充足 = 应对国际支付和金融风险的"弹药库" |
| 中国 | 约 3.2 万亿美元，全球第一 |
| 哪查 | 国家外汇管理局（每月公布） |
| 日常关联 | 保障汇率稳定、进口支付能力、外债偿还能力 |

## 三、怎么用（普通人版）

1. **看方向不看单点**：连续 3 个月的数据趋势比单月数据更有意义。
2. **指标组合着看**：PMI 下降 + CPI 走低 + 社融萎缩 → 经济偏冷，政策可能宽松。
3. **不用全记**：日常关注 GDP（季度）、CPI/PMI（月度）、M2/社融（月度）即可。
4. **查数据习惯**：养成每月初看上月经济数据的习惯，信息差就是认知优势。
