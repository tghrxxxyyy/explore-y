# 核心经济指标速查

> 开车看仪表盘，看经济看指标。本文用"仪表盘"类比，帮你快速理解 9 个最核心的经济指标。

## 一、仪表盘类比

经济就像一辆车：

- **速度表** = GDP（经济跑多快）
- **油温表** = CPI / PPI（通胀冷热）
- **发动机状态灯** = PMI（制造业景气）
- **油量表** = M2 / 社融（货币弹药够不够）
- **轮胎气压** = 失业率（社会是否稳当）
- **汇率显示屏** = 汇率 / 外汇储备（对外"购买力"）

看到仪表盘亮红灯，说明经济某个环节出了状况，需要关注。

## 二、核心指标详解

### 1. GDP（国内生产总值）

| 维度 | 说明 |
|------|------|
| 是什么 | 一国在一定时期内生产的所有最终商品和服务的市场价值总和 |
| 怎么读 | 看**总量**（经济体量大小）和**增速**（增长快慢） |
| 三驾马车 | 消费、投资、出口——GDP 的三个拉动引擎 |
| 哪查 | 国家统计局（每季度公布） |
| 日常关联 | GDP 强 = 就业好、收入涨、消费信心强；弱则相反 |

### 2. CPI（居民消费价格指数）

| 维度 | 说明 |
|------|------|
| 是什么 | 衡量居民日常购买的一篮子商品和服务价格变动的指标 |
| 怎么读 | 同比上涨 = 物价比去年贵了；连续上涨 = 通货膨胀 |
| 权重 | 食品烟酒约 30%，居住约 23%——猪价涨对 CPI 影响大 |
| 哪查 | 国家统计局（每月公布） |
| 日常关联 | 菜篮子、房租、出行成本，直接影响"钱够不够花" |

### 3. PPI（工业生产者出厂价格指数）

| 维度 | 说明 |
|------|------|
| 是什么 | 衡量工业品出厂价格变动的指标 |
| 怎么读 | PPI 高 = 上游涨价，企业成本上升；低 = 需求不足 |
| 传导 | PPI → CPI（上游涨价会逐步传导到消费品，但不完全） |
| 哪查 | 国家统计局（每月公布） |
| 日常关联 | PPI 负增长 → 企业利润承压 → 可能裁员降薪 |

### 4. PMI（采购经理指数）

| 维度 | 说明 |
|------|------|
| 是什么 | 通过对采购经理的月度调查汇总而成的扩散指数 |
| 怎么读 | **50 为荣枯线**：>50 扩张，<50 收缩 |
| 优势 | 比 GDP 早一个月出，是**先行指标** |
| 哪查 | 国家统计局 / 财新（每月 1 号公布） |
| 日常关联 | 连续低于 50 → 经济偏冷信号 → 就业市场承压 |

### 5. M1 与 M2（货币供应量）

| 维度 | M1 | M2 |
|------|----|----|
| 定义 | 现金 + 活期存款（随时能花的钱） | M1 + 定期存款 + 储蓄存款等 |
| 类比 | 你钱包里的现金 + 银行卡余额 | 上面 + 你定期存款 + 理财 |
| 怎么读 | M1 增速高 = 钱在"活化"，经济活跃 | M2 增速高 = 市场钱多 |
| 剪刀差 | M1 增速 > M2 → 经济活跃；反之 → 钱"趴窝" |
| 哪查 | 中国人民银行（每月公布） |

### 6. 社融（社会融资规模）

| 维度 | 说明 |
|------|------|
| 是什么 | 实体经济从金融体系获得的资金总量 |
| 怎么读 | 社融回升 = 实体经济真的拿到了钱（信用扩张） |
| 关键点 | M2 涨但社融不涨 = 钱在银行空转，没有进实体 |
| 哪查 | 中国人民银行（每月公布） |
| 日常关联 | 社融持续萎缩 → 经济收缩信号 → 政策可能出手 |

### 7. 失业率

| 维度 | 说明 |
|------|------|
| 是什么 | 劳动力中没有工作但正在寻找工作的人占比 |
| 怎么读 | 失业率上升 → 就业市场恶化；下降 → 改善 |
| 注意 | 中国公布的是"城镇调查失业率"，不含农村 |
| 哪查 | 国家统计局（每月公布） |
| 日常关联 | 直接关系到收入、消费信心、社会稳定 |

### 8. 汇率

| 维度 | 说明 |
|------|------|
| 是什么 | 两种货币之间的兑换比率（如 USD/CNY = 7.2） |
| 怎么读 | 数字上升 = 人民币贬值；下降 = 人民币升值 |
| 影响 | 贬值利好出口、利空进口；升值反之 |
| 哪查 | 中国外汇交易中心、中国人民银行 |
| 日常关联 | 留学换汇、海淘成本、出国旅游 |

### 9. 外汇储备

| 维度 | 说明 |
|------|------|
| 是什么 | 一国央行持有的外币资产总和 |
| 怎么读 | 储备充足 = 应对国际支付和金融风险的"弹药库" |
| 中国 | 约 3.2 万亿美元，全球第一 |
| 哪查 | 国家外汇管理局（每月公布） |
| 日常关联 | 保障汇率稳定、进口支付能力、外债偿还能力 |

## 三、怎么用（普通人版）

1. **看方向不看单点**：连续 3 个月的数据趋势比单月数据更有意义。
2. **指标组合着看**：PMI 下降 + CPI 走低 + 社融萎缩 → 经济偏冷，政策可能宽松。
3. **不用全记**：日常关注 GDP（季度）、CPI/PMI（月度）、M2/社融（月度）即可。
4. **查数据习惯**：养成每月初看上月经济数据的习惯，信息差就是认知优势。

## 四、PMI 详解

### 4.1 PMI 分项解读

| 分项 | 含义 | 权重（约） | 解读要点 |
|------|------|-----------|---------|
| **新订单** | 未来需求 | 30% | >50 表示需求扩张，是经济领先指标 |
| **生产** | 当前产出 | 25% | >50 表示生产扩张 |
| **从业人员** | 就业状况 | 20% | >50 表示企业招人，<50 表示裁员 |
| **供应商配送** | 供应链效率 | 15% | <50 表示配送加快（需求弱），>50 表示配送变慢（需求强） |
| **原材料库存** | 库存水平 | 10% | 上升可能表示被动补库存（需求弱） |

### 4.2 制造业 PMI vs 非制造业 PMI

| 维度 | 制造业 PMI | 非制造业 PMI |
|------|-----------|-------------|
| 调查对象 | 制造业企业采购经理 | 服务业企业（零售、餐饮、金融等） |
| 荣枯线 | 50 | 50 |
| 波动性 | 较大（受周期影响） | 较小（相对稳定） |
| 经济意义 | 反映工业景气 | 反映服务业景气 |

### 4.3 财新 PMI vs 官方 PMI

| 维度 | 官方 PMI | 财新 PMI |
|------|---------|---------|
| 发布机构 | 国家统计局 | 财新传媒 |
| 样本 | 3000家大中型企业 | 400家中小型企业 |
| 侧重 | 大企业、国企 | 中小企业、民企 |
| 发布时间 | 每月最后一天 | 每月第一个工作日 |

- **背离情况**：当官方 PMI 与财新 PMI 走势相反时，说明大企业与中小企业景气分化

> 来源：国家统计局《中国制造业采购经理指数编制说明》、财新传媒

## 五、社会融资规模详解

### 5.1 社融的组成

| 分项 | 含义 | 重要性 |
|------|------|--------|
| **人民币贷款** | 实体经济获得的人民币贷款 | 最大分项（约 60%） |
| **外币贷款** | 实体经济获得的外币贷款 | 受汇率影响 |
| **委托贷款** | 企业间委托银行发放的贷款 | 规模较小 |
| **信托贷款** | 通过信托公司获得的贷款 | 影子银行部分 |
| **未贴现银行承兑汇票** | 企业间商业信用 | 反映企业间信用 |
| **企业债券** | 企业发行的债券 | 直接融资 |
| **政府债券** | 国债、地方政府债 | 财政政策体现 |
| **非金融企业股票融资** | IPO、增发 | 权益融资 |

### 5.2 社融与 M2 的关系

| 维度 | 社融 | M2 |
|------|------|-----|
| 衡量对象 | 实体经济从金融体系获得的资金 | 银行体系的货币供应 |
| 关系 | 社融 = 信贷 + 直接融资 + 其他 | M2 是信贷的派生结果 |
| 背离含义 | M2 增但社融不增 = 钱在银行空转 | 社融增但 M2 不增 = 直接融资替代信贷 |

### 5.3 新增人民币贷款解读

| 类型 | 含义 | 经济信号 |
|------|------|---------|
| 企业中长期贷款 | 企业用于投资的贷款 | >5000亿 = 投资意愿强 |
| 居民中长期贷款 | 主要是房贷 | 反映房地产市场热度 |
| 票据融资 | 企业短期融资 | 大幅增加 = 信贷需求弱（票据冲量） |

> 来源：中国人民银行《社会融资规模统计数据报告》

## 六、工业企业利润

| 维度 | 说明 |
|------|------|
| 定义 | 规模以上工业企业（年营收 2000 万以上）的利润总额 |
| 公布频率 | 每月（累计值），每季度（单季值） |
| 行业分布 | 上游（采矿）、中游（制造业）、下游（公用事业） |
| 经济意义 | 反映企业盈利状况，是经济同步指标 |

**利润分析框架**：

| 因素 | 影响 |
|------|------|
| PPI 上涨 | 上游企业利润增加，下游承压 |
| 成本上升 | 利润率下降 |
| 需求旺盛 | 量价齐升，利润增长 |
| 汇率贬值 | 出口企业利润增加，进口企业承压 |

> 来源：国家统计局《工业企业利润月度报告》

## 七、固定资产投资

| 维度 | 说明 |
|------|------|
| 定义 | 以货币形式表现的建造和购置固定资产的工作量 |
| 三大类 | 基础设施投资、制造业投资、房地产投资 |
| 公布频率 | 每月（累计同比） |
| 经济意义 | 反映未来产能扩张意愿，是经济先行指标 |

**各类投资解读**：

| 类型 | 驱动因素 | 经济信号 |
|------|---------|---------|
| 基建投资 | 政策驱动（稳增长） | 增速上升 = 政府在发力 |
| 制造业投资 | 企业自主决策 | 增速上升 = 企业看好未来 |
| 房地产投资 | 房企投资意愿 | 增速上升 = 房地产回暖 |

> 来源：国家统计局《固定资产投资月度报告》

## 八、社会消费品零售总额

| 维度 | 说明 |
|------|------|
| 定义 | 企业（单位）通过交易售给个人和社会集团的实物商品金额 |
| 范围 | 实物商品（不含服务），包括网上零售 |
| 公布频率 | 每月 |
| 经济意义 | 反映消费景气，是经济同步指标 |

**解读要点**：

| 要点 | 说明 |
|------|------|
| 名义增速 vs 实际增速 | 实际增速剔除价格因素，更真实 |
| 网上零售占比 | 反映消费渠道变化 |
| 汽车零售 | 波动大，对总额影响显著 |
| 餐饮收入 | 反映服务消费景气 |

> 来源：国家统计局《社会消费品零售总额月度报告》

## 九、进出口数据详解

### 9.1 基本概念

| 概念 | 含义 |
|------|------|
| 出口 | 本国商品卖给外国 |
| 进口 | 外国商品买进来 |
| 贸易顺差 | 出口 > 进口（赚外汇） |
| 贸易逆差 | 出口 < 进口（花外汇） |
| 贸易差额 | 出口 - 进口 |

### 9.2 中国贸易结构

| 贸易伙伴 | 出口占比（约） | 进口占比（约） |
|----------|---------------|---------------|
| 东盟 | 16% | 15% |
| 欧盟 | 15% | 13% |
| 美国 | 14% | 6% |
| 日本 | 5% | 7% |
| 韩国 | 4% | 8% |

### 9.3 进出口数据解读

| 指标 | 含义 |
|------|------|
| 出口增速 | 反映外需强弱 |
| 进口增速 | 反映内需强弱 |
| 贸易顺差 | 外汇来源，影响汇率 |
| PMI 新出口订单 | 出口的领先指标 |

> 来源：海关总署《进出口数据月度报告》

## 十、财政收支详解

### 10.1 财政收入

| 来源 | 含义 | 占比（约） |
|------|------|-----------|
| 税收收入 | 增值税、企业所得税、个人所得税等 | 85% |
| 非税收入 | 行政事业性收费、国有资本经营收入 | 15% |

### 10.2 财政支出

| 类型 | 含义 |
|------|------|
| 一般公共预算支出 | 教育、医疗、社保、国防等 |
| 政府性基金预算支出 | 主要是土地出让金相关支出 |
| 国有资本经营预算支出 | 国企利润分配 |

### 10.3 赤字率

- **定义**：财政赤字 / GDP × 100%
- **国际警戒线**：3%（欧盟马斯特里赫特条约）
- **中国实际情况**：名义赤字率约 3%，但广义赤字率（含专项债、政策性金融债等）约 7-8%

### 10.4 土地财政

| 维度 | 说明 |
|------|------|
| 含义 | 地方政府依靠土地出让金获取财政收入 |
| 占比 | 土地出让金占地方政府性基金收入约 85% |
| 风险 | 房地产下行→土地出让金减少→地方财政压力 |
| 转型方向 | 房产税、消费税改革、提高直接税比重 |

> 来源：财政部《财政收支月度报告》

| 因素 | 说明 |
|------|------|

| 人口结构 | 中国老龄化加速，美国相对年轻 |
| 政策框架 | 中国强调"稳增长"，美国强调"就业优先" |

> 来源：IMF《World Economic Outlook 2024》、各国统计局官方数据

## 十五、GDP 深度解读

### 名义 GDP vs 实际 GDP

| 概念 | 定义 | 用途 |
|------|------|------|
| 名义 GDP | 按当年价格计算 | 反映经济总量 |
| 实际 GDP | 扣除通胀，按基期价格 | 反映真实增长 |
| GDP 平减指数 | 名义 GDP / 实际 GDP | 衡量整体物价水平 |

### GDP 三种计算方法

- **生产法**：各行业增加值之和（第一/二/三产业）
- **支出法**：消费 + 投资 + 净出口（C+I+G+NX）
- **收入法**：工资 + 利润 + 利息 + 租金 + 间接税

### GDP 局限性

- **不反映分配**：人均 GDP 不能代表普通人收入
- **不计环境成本**：污染、资源耗竭未扣除
- **不计家务劳动**：无偿家务不计入 GDP
- **幸福感脱钩**：GDP 增长 ≠ 幸福感提升

> 来源：国家统计局 GDP 核算制度、世界银行《世界发展指标》

## 十六、CPI 与通胀

### CPI 构成权重（中国 2023 年）

| 类别 | 权重 | 说明 |
|------|------|------|
| 食品烟酒 | 28.2% | 猪肉、蔬菜、粮食 |
| 居住 | 23.4% | 租金、水电、物业 |
| 交通通信 | 13.2% | 油价、车辆、通信 |
| 教育文化娱乐 | 10.9% | 学费、旅游、娱乐 |
| 医疗保健 | 10.2% | 药品、医疗服务 |
| 其他用品服务 | 14.1% | 服装、日用品等 |

### CPI 统计口径差异

- **中国 CPI**：不含房价（租金计入），食品权重较高
- **美国 CPI**：含房价（业主等价租金），服务权重较高
- **核心 CPI**：扣除食品和能源，更能反映趋势性通胀

### 通胀对个人的影响

| 通胀率 | 100 万购买力 | 实际建议 |
|--------|------------|---------|
| 2% | 82 万 | 定投可跑赢 |
| 3% | 74 万 | 需要投资 |
| 5% | 61 万 | 必须投资 |
| 8% | 46 万 | 高风险投资 |

> 来源：国家统计局 CPI 统计方案、BLS CPI 计算方法

## 十七、PPI 与企业盈利

### PPI 传导链

原材料涨价 → PPI上游上涨 → 中游传导 → 下游消费品涨价 → CPI上涨

### PPI 与股市关系

- **PPI上行+需求旺盛**：企业盈利改善，利好周期股
- **PPI上行+需求疲软**：企业利润被挤压
- **PPI下行**：上游成本降低，下游企业受益

> 来源：国家统计局工业生产者价格指数

## 十八、PMI 行业分析

| 分项 | 权重 | 含义 |
|------|------|------|
| 新订单 | 30% | 未来需求 |
| 生产 | 25% | 当前产出 |
| 从业人员 | 20% | 就业情况 |
| 供应商配送 | 15% | 供应链效率 |
| 原材料库存 | 10% | 补库存意愿 |

- **PMI连续3月>50**：经济扩张确认
- **PMI连续3月<50**：经济收缩预警

> 来源：国家统计局PMI统计制度

## 十九、M2 与货币环境

| M2增速 | 经济含义 | 资产表现 |
|--------|---------|---------|
| >10% | 宽松 | 股市楼市受益 |
| 8–10% | 中性 | 资产价格温和 |
| <8% | 偏紧 | 资产价格承压 |

- **M2增速>GDP增速+CPI**：流动性过剩
- **社融>M2**：直接融资活跃

> 来源：中国人民银行货币供应量统计

## 二十、汇率与跨境资金

| 因素 | 人民币升值 | 人民币贬值 |
|------|-----------|-----------|
| 经济增长 | GDP增速高于预期 | GDP增速低于预期 |
| 利率差异 | 美联储降息 | 美联储加息 |
| 贸易顺差 | 出口强劲 | 出口疲软 |
| 资本流动 | 外资流入 | 资本外流 |

> 来源：中国人民银行、国家外汇管理局公开数据

## 二十一、领先指标与同步指标

### 21.1 指标分类

| 类型 | 定义 | 代表指标 | 用途 |
|------|------|---------|------|
| **领先指标** | 变化先于经济整体变动 | PMI、社融、M1增速、新房开工 | 预判经济拐点 |
| **同步指标** | 与经济变动同步 | GDP、工业增加值、用电量 | 确认当前经济状态 |
| **滞后指标** | 变化晚于经济整体变动 | 失业率、CPI、企业利润 | 确认经济趋势 |

### 21.2 领先指标组合信号

| 信号组合 | 经济含义 | 应对策略 |
|---------|---------|---------|
| **PMI↑ + 社融↑ + M1↑** | 经济复苏确认 | 增加权益资产配置 |
| **PMI↓ + 社融↓ + M1↓** | 经济衰退信号 | 增加现金和债券 |
| **PMI↑ + CPI↓ + 社融平** | 温和复苏，通胀可控 | 适度均衡配置 |
| **PMI↓ + CPI↑ + 社融↑** | 滞胀风险 | 关注大宗商品对冲 |

> 来源：国家统计局景气监测中心、中国人民银行

## 二十二、经济周期与资产配置

### 22.1 美林投资时钟

| 周期阶段 | GDP趋势 | 通胀趋势 | 最优资产 | 次优资产 |
|---------|---------|---------|---------|---------|
| **复苏期** | ↑ | ↓ | 股票 | 债券 |
| **过热期** | ↑ | ↑ | 大宗商品 | 股票 |
| **滞胀期** | ↓ | ↑ | 现金 | 大宗商品 |
| **衰退期** | ↓ | ↓ | 债券 | 现金 |

### 22.2 中国经济周期特征

| 特征 | 说明 |
|------|------|
| **政策周期影响大** | 货币政策和财政政策对经济周期有显著影响 |
| **库存周期短** | 约3-4年一个库存周期，企业补/去库存驱动 |
| **房地产周期长** | 约18年一个房地产长周期，政策调控频繁 |
| **出口周期外生** | 受全球经济和贸易政策影响较大 |

### 22.3 周期判断方法

- **PMI连续3个月方向性变化**：确认经济趋势转折
- **社融-M2剪刀差**：扩大预示经济活跃，缩小预示经济放缓
- **M1-M2剪刀差**：M1增速持续高于M2预示经济复苏
- **信用利差**：信用利差收窄预示风险偏好上升，经济向好

> 来源：美林证券《The Investment Clock》、中国宏观经济研究院

## 二十三、指标之间的传导关系

### 23.1 货币政策传导链

| 环节 | 传导机制 | 滞后期 |
|------|---------|--------|
| **央行→银行** | 降准降息增加银行可贷资金 | 即时 |
| **银行→企业** | 企业获得贷款增加投资 | 1-3个月 |
| **企业→就业** | 投资增加带动招聘 | 3-6个月 |
| **就业→消费** | 收入增加带动消费 | 6-12个月 |
| **消费→GDP** | 消费增长拉动经济 | 6-12个月 |

### 23.2 通胀传导链

| 环节 | 传导方向 | 滞后期 |
|------|---------|--------|
| **PPI→CPI** | 上游涨价传导至消费品 | 3-6个月 |
| **M2→CPI** | 货币超发推动物价上涨 | 6-18个月 |
| **汇率→CPI** | 贬值推高进口商品价格 | 1-3个月 |
| **工资→CPI** | 工资上涨推动成本上升 | 6-12个月 |

### 23.3 经济指标关联矩阵

| 指标A → 指标B | 正相关 | 负相关 | 滞后期 |
|-------------|--------|--------|--------|
| **PMI → GDP** | 是 | — | 1个月 |
| **M2 → CPI** | 是 | — | 6-12个月 |
| **社融 → GDP** | 是 | — | 1-2个季度 |
| **失业率 → 消费** | — | 是 | 3-6个月 |
| **PPI → 企业利润** | 是 | — | 1个季度 |

> 来源：中国人民银行货币政策分析小组、国家统计局

## 二十四、投资决策中的指标应用

### 24.1 股市投资者关注指标

| 指标 | 关注要点 | 历史验证 |
|------|---------|---------|
| **社融增速** | 社融回升领先股市约2-3个季度 | 2019年、2020年验证 |
| **M1-M2剪刀差** | M1增速反超M2预示股市向好 | 2016年、2019年验证 |
| **PMI新订单** | 新订单>50且持续上升预示经济复苏 | 领先GDP约1个月 |
| **信贷脉冲** | 新增信贷大幅增加预示流动性改善 | 领先股市约1-2个季度 |

### 24.2 债市投资者关注指标

| 指标 | 关注要点 |
|------|---------|
| **通胀预期** | CPI上行预期→利率上行→债券价格下跌 |
| **货币政策** | 降准降息→利率下行→债券价格上涨 |
| **经济基本面** | 经济下行→避险需求增加→国债收益率下行 |
| **信用利差** | 信用利差收窄→市场风险偏好上升→信用债相对占优 |

### 24.3 房地产投资者关注指标

| 指标 | 关注要点 |
|------|---------|
| **房贷利率** | LPR下调→购房成本降低→需求释放 |
| **M2增速** | M2高增长→流动性充裕→资产价格支撑 |
| **人口流入** | 人口净流入城市→住房需求持续 |
| **土地供应** | 土地供应增加→供给端压力→房价承压 |

> 来源：中国证券业协会、中国房地产业协会公开数据

## 二十五、普通人看指标的实操清单

### 25.1 每月必看指标

| 指标 | 公布时间 | 关注要点 |
|------|---------|---------|
| **CPI/PPI** | 每月9-12日 | 通胀趋势、PPI-CPI剪刀差 |
| **PMI** | 每月1日 | 荣枯线、新订单分项 |
| **社融/M2** | 每月10-15日 | 信用扩张方向 |
| **进出口** | 每月7-10日 | 外需与内需强弱 |

### 25.2 每季度必看指标

| 指标 | 公布时间 | 关注要点 |
|------|---------|---------|
| **GDP** | 季后15天左右 | 增速与三驾马车拆分 |
| **工业企业利润** | 季后25天左右 | 企业盈利改善情况 |
| **固定资产投资** | 季后15天左右 | 基建、制造业、房地产三分法 |

### 25.3 看数据的三个原则

- **看趋势不看单点**：连续3个月数据方向一致才有意义
- **看组合不看孤立**：PMI+CPI+社融组合判断经济冷热
- **看预期不看绝对值**：数据好于或差于市场预期才是关键

> 来源：国家统计局数据发布日历、中国人民银行公开数据
