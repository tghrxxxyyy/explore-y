## 本板块说明

- 本板块偏**科普**，力求通俗易懂、有据可查，把经济学核心概念和运行机制讲清楚。
- 与「金融投资/宏观」板块（投资视角）互补：那边侧重"对我投资有什么用"，本板块侧重**认知与原理**。
- 所有数字均引用国家统计局、央行、IMF、世界银行等官方或权威来源，以官方最新发布为准。
- 本板块**不构成任何投资建议**，仅供学习参考。
