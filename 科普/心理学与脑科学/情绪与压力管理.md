## 导语：情绪不是敌人，压力也不是

情绪（emotion）是心理学中最贴近日常体验、也最难精确定义的概念之一。美国心理学会（APA）把情绪描述为一种包含**主观体验、生理唤醒、认知评价与行为表达**的复合反应模式；它通常由具体刺激触发、持续时间较短（几秒到几分钟），与持续时间更长、缺乏明确对象的**心境（mood）**相区别（来源：APA 词典；Paul Ekman Group 对情绪特征的说明）。

压力（stress）同样容易误解。它并不是"外界事件"本身，而是**个体与环境的交互过程**：同样的加班、考试、争吵，对不同人产生的压力强度可以相差极大（来源：Lazarus & Folkman, 1984 压力交互作用模型）。压力也不全是坏事——短暂、可控、有挑战性的压力能提升注意与动员能量（见后文"皮质醇的双面性"）。

1. 基本情绪理论——从离散情绪到维度模型

3. 压力反应——交感-肾上腺髓质轴（SAM）与 HPA 轴、皮质醇
4. 压力的经典理论——Selye 的一般适应综合征与 Lazarus 的认知评价

6. 情绪调节策略——Gross 过程模型与实证支持的技巧
7. 睡眠与情绪——互相拖累的双向循环
8. 常见误区与把知识用起来

## 一、基本情绪理论：从"离散"到"维度"

### 1.1 什么是"基本情绪"

**基本情绪理论（basic emotion theory）**主张：人类拥有一组**先天、跨文化可识别、具有独特生理与表达特征**的情绪类别。这些情绪被称为"离散的（discrete）"，因为它们被认为可以通过面部表情与生理过程相区分（来源：情绪分类研究综述；Ekman, 1992 跨文化研究）。

### 1.2 埃克曼的六种基本情绪

保罗·埃克曼（Paul Ekman）及其同事在跨文化研究中发现，某些情绪表情在包括前文字社会在内的多种文化中都得到一致识别，据此提出六种基本情绪（来源：Ekman 1992 跨文化表情研究；UWA Online 基本情绪综述）。

| 情绪 | 英文 | 典型面部表达 | 可能的适应功能 |
|------|------|--------------|----------------|
| 快乐 | Happiness | 微笑、眼周肌肉收缩 | 促进社会联结与重复有益行为 |
| 悲伤 | Sadness | 皱眉、目光失焦、流泪 | 发出求助信号、促进反思与休整 |
| 恐惧 | Fear | 睁大双眼、面部紧绷 | 触发战斗-逃跑反应、回避危险 |
| 愤怒 | Anger | 瞪视、眉压低、唇紧抿 | 排除阻碍、维护边界与地位 |
| 惊讶 | Surprise | 眉上扬、张口、吸气 | 中断当前加工、为新信息让路 |
| 厌恶 | Disgust | 皱鼻、作呕反应、回避视线 | 排斥可能致病的物质与他人 |

### 1.3 情绪的扩展清单与争议

埃克曼本人在后期认为基本情绪可能不止六种。其学生 Daniel Cordaro 与 Dacher Keltner 主导的跨文化研究，为**娱乐、敬畏、满足、欲望、尴尬、痛苦、宽慰、同情**等情绪的普遍性提供了面部与声音表达证据，也为**无聊、困惑、兴趣、自豪、羞耻**的面部表达与**轻蔑、宽慰、胜利**的声音表达提供了证据（来源：跨文化情绪研究综述）。

需要强调：基本情绪理论并非没有争议。**建构主义（constructionist）**取向认为，情绪是"核心情感（效价＋唤醒）"与概念知识共同建构的产物，不同情绪未必有专属的神经定位或生理签名（来源：情绪分类研究的理论争议综述）。目前的学界状况是：离散观点与维度观点并存，各自解释不同层面的现象。

### 1.4 其他代表性理论

| 理论 | 提出者 | 核心主张 |
|------|--------|----------|
| 情绪之轮 | Robert Plutchik | 八种基本情绪成对对立：快乐-悲伤、愤怒-恐惧、信任-厌恶、惊讶-期待；可混合出复杂情绪 |
| 三种维度 | Wilhelm Wundt（1897） | 愉快-不愉快、唤醒-抑制、紧张-放松 |
| 三维度命名 | Harold Schlosberg（1954） | 愉快-不愉快、注意-拒绝、激活水平 |
| 核心情感系统 | Jaak Panksepp | 七种生物性情感系统：SEEKING、FEAR、RAGE、LUST、CARE、PANIC/GRIEF、PLAY |
| 成分过程模型 | Klaus Scherer | 情绪由多成分（评价、体感、行动倾向、表达、感受）在短时间内同步协调而成 |

### 1.5 维度模型：效价与唤醒

多数维度模型使用两个核心轴（来源：情绪维度模型综述）：

- **效价（valence）**：体验是愉快还是不愉快；
- **唤醒（arousal）**：体验是 energized 还是 enervated（激动还是低沉）。

| 象限 | 效价 | 唤醒 | 典型状态 |
|------|------|------|----------|
| 高唤醒-正效价 | 正 | 高 | 兴奋、狂喜、雀跃 |
| 低唤醒-正效价 | 正 | 低 | 平静、满足、安宁 |
| 高唤醒-负效价 | 负 | 高 | 愤怒、恐惧、焦虑 |
| 低唤醒-负效价 | 负 | 低 | 悲伤、沮丧、倦怠 |

> 维度模型的好处：可以刻画"说不清是什么情绪，但就是很难受"这类状态；也便于量化研究（如情绪自评量表）。

### 1.6 情绪的成分与功能

从成分视角看，一次情绪事件通常包含五个成分同步变化（来源：情绪成分过程模型）：

| 成分 | 内容 |
|------|------|
| 认知评价 | 对事件与自身目标关系的快速评估 |
| 主观感受 | "我感到……"的体验本身 |
| 生理反应 | 心率、呼吸、皮电、激素变化 |
| 表达行为 | 面部表情、声调、姿态 |
| 行动倾向 | 想要靠近、逃离、攻击或僵住 |

情绪的核心功能是**适应**：它为重复出现的祖先级问题提供了快速解决方案，并高效地向他人传递"什么对我重要"的信号（来源：情绪功能研究综述）。

### 1.7 情绪 ≠ 感受 ≠ 心境 ≠ 气质

| 概念 | 持续时间 | 有无明确对象 | 说明 |
|------|----------|--------------|------|
| 情绪 | 秒到分 | 有 | 由具体事件触发，成分同步 |
| 感受 | 与情绪同步 | 可有可无 | 对情绪的主观表征，私人化 |
| 心境 | 小时到天 | 常无 | 强度较低、弥散、无明确刺激 |
| 情绪特质/气质 | 长期稳定 | 无 | 如"易怒的人"更容易被激惹 |

## 二、情绪的生理机制

### 2.1 自主神经系统：快反应通道

情绪的身体动员主要由**自主神经系统（ANS）**完成，它分两支（来源：生理心理学教科书；HPA 轴相关综述）：

| 分支 | 主要递质 | 主要效应 |
|------|----------|----------|
| 交感神经 | 去甲肾上腺素、肾上腺素 | 心率加快、支气管扩张、瞳孔放大、血流重分配至骨骼肌、消化抑制 |
| 副交感神经（迷走为主） | 乙酰胆碱 | 心率减慢、消化恢复、休息与修复 |

**战斗-逃跑反应（fight-or-flight）**由交感-肾上腺髓质轴（SAM 轴）在**数秒内**启动，是应对急性威胁最快的通路（来源：应激生理综述；GAS 相关文献）。

### 2.2 两大应激通路对照

| 通路 | 全称 | 起效时间 | 主要激素 | 典型作用 |
|------|------|----------|----------|----------|
| SAM 轴 | 交感-肾上腺髓质轴 | 秒级 | 肾上腺素、去甲肾上腺素 | 即刻动员能量，心率血压上升 |
| HPA 轴 | 下丘脑-垂体-肾上腺轴 | 分钟至小时级 | 皮质醇（人类） | 持续供能、代谢重排、免疫与情绪调节 |

### 2.3 情绪的脑网络（简化版）

| 脑区 | 与情绪的关联 |
|------|--------------|
| 杏仁核 | 威胁探测与情绪显著性标记，恐惧学习的关键 |
| 前额叶（尤其内侧前额叶） | 自上而下的情绪调控、情境化与抑制 |
| 岛叶 | 内感受（心跳、胃部感觉）与"感受"的整合 |
| 前扣带回 | 冲突监测、情绪与认知的界面 |
| 伏隔核/纹状体 | 奖赏、动机与愉悦 |
| 海马 | 情境记忆、压力负反馈调节中枢 |
| 蓝斑 | 去甲肾上腺素来源，警觉与应激反应 |

> 重要提示：情绪**没有单一"情绪中心"**。把"杏仁核＝恐惧"这类说法当成科普简化即可，不宜过度还原（来源：情绪神经科学综述；Walker 睡眠研究团队对杏仁核-前额叶通路的描述）。

### 2.4 主要神经递质与调质（定性描述）

| 分子 | 常被关联的功能 |
|------|----------------|
| 多巴胺 | 动机、期待、奖赏学习（"想要"多于"喜欢"） |
| 5-羟色胺 | 情绪与冲动调节、睡眠、食欲（抗抑郁药的重要靶点之一） |
| 去甲肾上腺素 | 警觉、应激动员 |
| γ-氨基丁酸（GABA） | 中枢主要抑制性递质，与焦虑调节相关 |
| 谷氨酸 | 中枢主要兴奋性递质 |
| 内源性阿片肽 | 疼痛抑制与愉悦 |
| 催产素 | 依恋、信任、社会联结（效应受情境调节，勿神化） |

> 上述关联均为**定性**概括。单一递质与单一情绪之间不存在简单的"一一对应"，任何"某种物质决定某种情绪"的说法都不准确。

## 三、压力反应：SAM 轴与 HPA 轴

### 3.1 应激源、应激反应与压力

| 术语 | 含义 |
|------|------|
| 应激源（stressor） | 引发应激反应的刺激（高温、疼痛、噪声、人际冲突、截止日期） |
| 应激反应（stress response） | 机体为维持内环境稳态而发生的非特异性适应性反应 |
| 压力（stress） | 个体与环境的交互过程，取决于评价与应对资源 |

（来源：应激生理综述；Lazarus & Folkman, 1984）

### 3.2 HPA 轴的完整链条

下丘脑-垂体-肾上腺轴（hypothalamic-pituitary-adrenal axis, HPA）是神经内分泌系统的核心构成（来源：HPA 轴综述；应激生理学文献）。

| 步骤 | 部位 | 事件 |
|------|------|------|
| 1 | 下丘脑室旁核（PVN） | 小细胞神经元释放 CRH（促肾上腺皮质激素释放激素）与 AVP（精氨酸加压素） |
| 2 | 垂体门脉系统 | 两种肽激素运至垂体前叶 |
| 3 | 垂体前叶 | 促皮质激素细胞合成并分泌 ACTH（促肾上腺皮质激素） |
| 4 | 肾上腺皮质束状带 | ACTH 刺激利用胆固醇合成糖皮质激素（人类为皮质醇） |
| 5 | 全身靶组织 | 皮质醇经糖皮质激素受体（GR）与部分盐皮质激素受体（MR）发挥作用 |
| 6 | 负反馈 | 皮质醇抑制下丘脑与垂体，减少 CRH 与 ACTH 释放，实现自我调节 |

> 海马是 HPA 轴的主要调控中心之一，其糖皮质激素受体密度很高（来源：HPA 轴解剖与功能综述）。

### 3.3 皮质醇是"双面激素"

| 皮质醇水平模式 | 典型效应 |
|----------------|----------|
| 短时快速升高后回落 | 增强注意与记忆、快速动员能量，提升应对效率 |
| 长期持续偏高 | 内分泌紊乱、海马功能受损、执行功能下降、情绪调节困难、免疫抑制 |
| 过低 / 昼夜节律紊乱 | 疲乏、情绪低落、代谢与睡眠异常 |

**皮质醇觉醒反应（CAR, Cortisol Awakening Response）**：多数人醒来后一小时内皮质醇迅速升高到达当日峰值，随后回落，有助于清醒与投入（来源：应激生理科普综述）。

### 3.4 慢性压力的恶性循环（机制示意）

1. 慢性压力 ⇒ HPA 轴持续激活 ⇒ 皮质醇长期偏高；
2. 高皮质醇抑制前额叶（执行功能、情绪调控）；
3. 前额叶对杏仁核的抑制减弱 ⇒ 杏仁核激活升高；
4. 杏仁核进一步激活 HPA 轴 ⇒ 皮质醇更多；
5. 形成"越焦虑越难自我调节、越难调节越焦虑"的循环。

（来源：应激与脑功能研究综述；有氧运动与正念冥想被认为对打破该循环较有效）

### 3.5 压力对认知与健康的已知影响

| 领域 | 影响 |
|------|------|
| 记忆 | 海马受体丰富，长期高皮质醇与记忆下降、海马体积改变相关 |
| 执行功能 | 压力状态下前额叶控制下降，"知道该做却做不动" |
| 免疫 | 长期应激可激活炎症反应，炎性因子参与应激相关精神障碍 |
| 心血管 | 长期高唤醒与高血压、心血管风险相关 |
| 睡眠 | 皮质醇节律紊乱与入睡困难、早醒互为因果 |
| 情绪 | 慢性压力是焦虑、抑郁的重要风险因素 |

（来源：应激与免疫、应激与认知的相关综述）

### 3.6 压力的"剂量"视角

| 压力剂量 | 典型体验 | 结果 |
|----------|----------|------|
| 无 / 过低 | 无聊、缺乏挑战 | 动机不足、成长停滞 |
| 适度（急性、可控） | 紧张但专注 | 表现提升（"适度压力反而提高效率"） |
| 过高 / 长期 | 失控、耗竭 | 功能受损、身心疾病风险上升 |

> 结论：目标不是"消灭压力"，而是**控制压力的强度与持续时间**（来源：应激管理研究综述）。

## 四、压力的经典理论

### 4.1 Selye 的一般适应综合征（GAS）

加拿大心理学家汉斯·塞利（Hans Selye）在 1930 年代提出**一般适应综合征（general adaptation syndrome, GAS）**，认为机体对持续应激源的反应可划分为三阶段（来源：Selye, 1950；科普中国词条）。

| 阶段 | 名称 | 主要生理变化 | 现象 |
|------|------|--------------|------|
| 一 | 警戒期（Alarm） | 交感-肾上腺髓质系统激活，儿茶酚胺释放 | 心率呼吸加快、血糖升高、血流重分配；抵抗力短暂低于正常 |
| 二 | 抵抗期（Resistance） | HPA 轴主导，糖皮质激素持续分泌 | 外观可能正常，但对新应激源的应对能力下降 |
| 三 | 衰竭期（Exhaustion） | 适应机制失代偿 | 免疫抑制、组织损伤、疾病甚至死亡风险上升 |

**评价**：三阶段框架至今仍是理解压力的实用工具，但其"非特异性"假设在 1960 年代受到质疑——Mason 等研究者指出，多数实验情境都包含心理不适，**心理因素**可能才是垂体-肾上腺反应的主要中介（来源：应激研究史综述）。

### 4.2 Lazarus 与 Folkman 的认知评价理论

Richard Lazarus 与 Susan Folkman（1984）提出**压力的交互作用模型（transactional model of stress and coping）**，核心是"压力不取决于事件本身，而取决于评价"（来源：Lazarus & Folkman, 1984；科普中国"认知评价"词条）。

| 评价阶段 | 内容 | 三种可能结论 |
|----------|------|--------------|
| 初级评价（primary appraisal） | 事件与我是否有利害关系 | 无关 / 有益（良性-积极）/ 有压力 |
| 次级评价（secondary appraisal） | 我有什么资源可以应对 | 可改变 → 问题聚焦应对；不可改变 → 情绪聚焦应对 |
| 再评价（reappraisal） | 基于新信息对应对策略的重新评估 | 反馈性调整 |

### 4.3 两种应对策略

| 策略 | 定义 | 适用情境 | 常见做法 |
|------|------|----------|----------|
| 问题聚焦应对 | 直接处理压力源 | 压力源可改变 | 收集信息、制定计划、沟通协商 |
| 情绪聚焦应对 | 调节由压力源引发的情绪 | 压力源不可改变 | 倾诉、放松练习、正念、认知重评 |

**适应性 vs 非适应性应对**（来源：Lazarus & Folkman 模型综述）：

| 类型 | 例子 |
|------|------|
| 适应性 | 问题解决、寻求社会支持、放松技术、积极重构 |
| 非适应性 | 否认、物质滥用、暴饮暴食、社会退缩 |

### 4.4 认知评价的影响因素

- 人格特质（如悲观归因风格会提高"应激性"判断）
- 价值观与信念
- 既往经历与经验
- 当时的情绪状态与健康状态
- 社会支持水平
- 事件的客观属性（可控性、可预测性、强度）

> "仁者见仁，智者见智"——同一事件对不同人意义不同，这是认知评价理论的核心洞察。

### 4.5 压力理论与情绪的关系

| 视角 | 关注点 | 代表 |
|------|--------|------|
| 生理应激 | 非特异性生理反应 | Selye |
| 认知评价 | 主观解释决定压力 | Lazarus & Folkman |
| 情绪成分 | 多成分同步生成情绪 | Scherer |
| 双因素理论 | 生理唤醒＋认知标签 | Schachter & Singer |

## 五、焦虑与抑郁的科普

### 5.1 先分清：情绪 ≠ 症状 ≠ 障碍

来自国家卫生健康委 2024 年 12 月新闻发布会的专家说明，判断焦虑抑郁情绪是否成为"病态"，有两个实用标准（来源：国家卫生健康委新闻发布会，北京大学第六医院、上海市精神卫生中心专家发言）：

| 标准 | 焦虑 | 抑郁 |
|------|------|------|
| 时间标准 | 每天都出现，持续 1 个月以上需重视 | 每天出现，持续 2 周以上需考虑 |
| 严重程度标准 | 本人痛苦，且影响正常学习/工作/生活 | 同左 |

> 关键区分：**一过性负性情绪**（常与压力大、睡眠差、熬夜、内分泌波动有关）与**需要专科诊断的抑郁障碍**不是一回事。网络上流传的"青少年抑郁症患病率 15%–20%"属于夸大；根据权威流行病学调查，我国青少年抑郁症患病率约为 2% 左右（来源：国家卫生健康委新闻发布会专家说明）。

### 5.2 焦虑的普遍性与功能

焦虑本身具有适应价值：它提示潜在威胁、促进准备与回避危险。**适度焦虑提升表现**，过高则损害工作记忆与执行功能（与耶克斯-多德森定律的描述一致）。

### 5.3 常见焦虑相关障碍的 DSM-5 要点（科普归纳）

以下内容依据《精神障碍诊断与统计手册》第五版（DSM-5，美国精神医学学会）及临床指南整理，**仅供理解概念，不用于自我诊断**（来源：American Psychiatric Association, DSM-5；VA/DoD 焦虑障碍治疗手册；DSM-5 GAD 诊断标准原文）。

| 障碍 | 核心特征 | 时间要求 |
|------|----------|----------|
| 广泛性焦虑障碍（GAD） | 对诸多事件活动过度焦虑担心、难以控制，伴 6 项症状中至少 3 项（坐立不安、易疲倦、注意力难集中或头脑空白、易怒、肌肉紧张、睡眠障碍） | 多数日子存在，至少 6 个月 |
| 惊恐障碍（Panic Disorder） | 反复的、不可预期的惊恐发作，并持续担心再次发作或其后果，或行为改变 | 症状持续 1 个月以上 |
| 社交焦虑障碍（SAD） | 对可能被负面评价的社交情境显著恐惧，回避或极度痛苦忍受 | 至少 6 个月 |
| 创伤后应激障碍（PTSD） | 创伤后出现侵入、回避、认知与情绪负性改变、警觉与反应性改变四类症状 | 至少 1 个月 |
| 强迫症（OCD） | 强迫思维与/或强迫行为，耗时显著 | 每天超过 1 小时，且造成显著痛苦或功能损害 |

> 注意：DSM-5 起，OCD 与 PTSD 已从"焦虑障碍"中独立，分别归入"强迫及相关障碍"与"创伤及应激相关障碍"（来源：DSM-5 分类说明）。

### 5.4 抑郁发作的 DSM-5 要点

**重性抑郁发作（major depressive episode）**诊断要求在**同一 2 周内**出现以下 9 项症状中的**至少 5 项**，且代表与既往功能相比的变化，并且**至少包含第 1 项或第 2 项之一**（来源：DSM-5 诊断标准；DSM-5-TR）。

| 序号 | 症状 |
|------|------|
| 1 | 抑郁心境，一天中大部分时间、几乎每天（儿童青少年可为易激惹） |
| 2 | 对几乎所有活动兴趣或愉悦显著减退（快感缺失） |
| 3 | 显著体重变化（一个月内超过 5%）或食欲显著改变 |
| 4 | 几乎每天失眠或嗜睡 |
| 5 | 精神运动性激越或迟滞（他人可观察） |
| 6 | 几乎每天疲乏或精力丧失 |
| 7 | 无价值感或过度/不恰当的罪恶感 |
| 8 | 思考或集中注意能力下降、犹豫不决 |
| 9 | 反复出现死亡念头、自杀意念、自杀计划或自杀企图 |

附加条件：症状引起**临床显著痛苦或功能损害**；排除物质或躯体疾病所致；排除精神分裂症谱系等更好解释；且**从无躁狂或轻躁狂发作**（来源：DSM-5-TR；Psychiatry Online 权威章节）。

> 第 9 项症状出现时属于**紧急情况**，须立即寻求专业帮助（见文首求助渠道）。

### 5.5 我国精神障碍流行病学数据

中国首次全国性精神障碍流行病学调查（中国精神卫生调查，CMHS）结果于 2019 年发表于《柳叶刀·精神病学》（来源：Huang Y, et al. Lancet Psychiatry, 2019；中国疾控中心文献解读）。

| 类别 | 终生加权患病率 | 12 个月加权患病率 |
|------|----------------|-------------------|
| 任何一种精神障碍（不含老年期痴呆） | 16.6% | 9.3% |
| 焦虑障碍 | 7.6% | 5.0% |
| 心境障碍 | 7.4% | 4.1% |
| 酒精/药物使用障碍 | 4.7% | 1.9% |
| 冲动控制障碍 | 1.5% | 1.2% |
| 精神分裂症及相关精神病性障碍 | 0.7% | — |
| 进食障碍 | 0.1% | <0.1% |
| 65 岁及以上人群老年期痴呆 | 5.6% | — |

> 样本来自 31 个省、自治区、直辖市 157 个疾病监测点，共 32 552 人完成调查（2013 年 7 月—2015 年 3 月）。这组数据说明：**"一生中约六分之一的人会经历某种精神障碍"**，心理问题并不罕见，把它"疾病化"而非"道德化"是科学应对的第一步。

### 5.6 抑郁的认知与习得性无助视角

| 理论 | 提出者 | 核心 |
|------|--------|------|
| 认知三联征 | Aaron Beck | 对自我、世界、未来的负性信念模式 |
| 习得性无助 | Martin Seligman（1967 动物实验） | 反复不可控的失败经验后，即使环境改变也不再尝试 |
| 归因风格 | Abramson, Seligman | 把负性事件归因为内部、稳定、普遍的原因，与抑郁风险相关 |
| 反刍思维 | Nolen-Hoeksema | 反复被动地思考痛苦本身与其原因，而非解决问题 |

> 这些理论为**认知行为疗法（CBT）**提供了重要基础（详见《心理健康与求助》篇）。

### 5.7 何时该寻求专业帮助（自查清单）

出现以下任一项，建议尽快就诊或咨询专业人士：

- 情绪低落或焦虑**每天出现、持续两周以上**；
- 明显影响工作、学习、睡眠、进食、人际关系；
- 出现**自伤、自杀**想法或计划（立即求助）；
- 出现幻觉、妄想等精神病性症状；
- 物质（酒精、药物）依赖，或以此"自我治疗"；
- 反复的身体不适但检查未见明确病因。

## 六、情绪调节策略

### 6.1 Gross 的情绪调节过程模型

James Gross（1998）提出**情绪调节过程模型（process model of emotion regulation）**，把调节策略按"发生在情绪反应之前还是之后"分为两大类（来源：Gross, 1998；Gross, 2002；中国科学院心理研究所综述）。

| 大类 | 英文 | 发生时机 | 具体策略 |
|------|------|----------|----------|
| 先行关注调节 | antecedent-focused | 情绪反应激活之前 | 情境选择、情境修正、注意分配、认知改变 |
| 反应关注调节 | response-focused | 情绪已产生之后 | 表达抑制、宣泄等 |

| 策略 | 说明 | 例子 |
|------|------|------|
| 情境选择 | 选择是否进入某情境 | 回避总让你暴躁的饭局 |
| 情境修正 | 改变环境以改变其情绪影响 | 提前说明自己需要安静两小时 |
| 注意分配 | 把注意力朝向或离开某个刺激 | 从"他会怎么看我"转向"我要讲什么" |
| 认知改变（认知重评） | 重新解释情境的意义 | "他在反馈内容，不是在否定我这个人" |
| 表达抑制 | 抑制正在发生的情绪表达 | 生气但面无表情、语气如常 |

### 6.2 认知重评优于表达抑制（实证结论）

Gross 及其同事的系列研究发现（来源：Gross 情绪调节研究；《中国社会科学》情绪调节综述；科普中国情绪调节文章）：

| 策略 | 主观体验 | 生理唤醒 | 外部表达 | 长期关联 |
|------|----------|----------|----------|----------|
| 认知重评 | 有效降低消极体验 | 有效降低 | 降低 | 更高幸福感、更低抑郁、更好人际关系与生活满意度 |
| 表达抑制 | **未能降低**（甚至增强） | 未降低（心血管激活反而升高） | 降低 | 更多抑郁症状、更差记忆质量、更低关系满意度、更高社交焦虑 |

> 通俗说法："压下去是把情绪捂在身体里；换看法是让情绪根本不那么成型。"

### 6.3 认知重评的四步操作（通俗版）

1. **先命名情绪**：把"我很难受"具体化为"我有点委屈＋羞耻"——命名本身就是调节的开始；
2. **找自动思维**：问自己"我脑子里刚才闪过的那句话是什么？"
3. **换个角度想**：五年后回看还重要吗？朋友遇到我会怎么安慰他？有没有第三种解释？
4. **行动验证**：新解释能否带出可以做的下一步。

**边界提示**：认知重评适用于多数日常情绪困扰，**不适用于重大创伤与急性危机**——这类情境需要的是专业支持与安全环境，而不是"换个看法"。若某个自动思维反复出现多年且与现实证据不符，可能需要更系统的 CBT（来源：科普中国情绪调节专题）。

### 6.4 其他有实证支持的情绪调节方法

| 方法 | 机制 | 证据强度 |
|------|------|----------|
| 正念（MBSR/MBCT） | 非评判觉察、减少自动化反应 | 较多 RCT 支持，减压与降低复发风险 |
| 有氧运动 | 改善情绪、降低焦虑抑郁症状 | 较多证据，常被列为有效的压力管理手段 |
| 呼吸与渐进式肌肉放松 | 降低交感激活 | 中等，操作简单 |
| 表达性写作 | 结构化书写促进认知加工 | 多项研究支持（Pennebaker 系列） |
| 社会支持 | 缓冲压力、提供实际帮助 | 较强证据 |
| 行为激活 | 通过增加正向活动改善情绪 | 抑郁治疗的一线成分 |
| 睡眠卫生 | 恢复情绪调节能力 | 与情绪双向关联，见第七章 |

### 6.5 情绪调节中的"策略灵活性"

研究提示：**只使用单一策略**或随机使用策略的个体，比能根据情境有计划地切换策略的个体，报告更高的焦虑水平与更多身心症状（来源：情绪调节与心理健康综述）。因此，重要的不是"哪一招最好"，而是**策略与情境的匹配**。

| 情境 | 更合适的策略 |
|------|--------------|
| 可控的问题（项目延期） | 问题聚焦＋情境修正 |
| 不可控的问题（已发生的损失） | 情绪聚焦＋认知重评＋接纳 |
| 社交评价压力 | 注意分配＋认知重评 |
| 强烈生理唤醒（惊恐） | 呼吸调节＋接纳，避免压抑 |
| 长期慢性压力 | 生活方式调整＋社会支持＋正念 |

### 6.6 情绪智力（EI）简述

情绪智力通常包括：识别自己与他人情绪、理解情绪、运用情绪信息、管理情绪。学界对"EI 是否独立于一般智力与人格"存在不同观点，对各类"情商测试"的商业宣传宜保持审慎（来源：APA 对情绪智力的词条说明；情绪智力研究综述）。

## 七、睡眠与情绪

### 7.1 睡眠的基本结构与功能

| 睡眠阶段 | 英文 | 特点 | 主要关联功能 |
|----------|------|------|--------------|
| 非快速眼动 1–2 期 | N1–N2 | 浅睡，N2 有睡眠纺锤波 | 入睡过渡、感觉门控 |
| 慢波睡眠 | N3（SWS） | 深睡，慢波活动多 | 陈述性记忆巩固、身体修复 |
| 快速眼动睡眠 | REM | 眼球快速运动、生动梦境 | 程序性记忆与情绪记忆加工 |

（来源：睡眠医学与记忆巩固研究综述；Matt Walker 团队研究）

### 7.2 睡眠剥夺与情绪的经典实验

Walker 及其同事（2007，发表于 Current Biology）招募 26 名 18–30 岁健康大学生，分为正常睡眠组与**连续约 35 小时不睡**组，随后在 fMRI 中观看 100 张由中性逐渐变为负性（如鲨鱼、毒蛇、烧伤者）的图片（来源：Walker et al., 2007, Current Biology；Scientific American、Medscape、New Scientist 报道）。

| 发现 | 内容 |
|------|------|
| 杏仁核反应 | 睡眠剥夺组在面对负性图片时，杏仁核活动比正常组高约 **60%** |
| 前额叶通讯 | 睡眠剥夺者杏仁核与内侧前额叶的通讯中断 |
| 代偿耦合 | 杏仁核转而与蓝斑（去甲肾上腺素来源）耦合，更接近原始的战斗-逃跑模式 |
| 比喻 | 内侧前额叶像"情绪的刹车"，睡眠不足时这个自上而下的抑制连接被切断 |

> Walker 的表述："当我们睡眠不足时，大脑真的像是在退回更原始的行为。" 也有研究提示，过度解读为"睡眠不足必然导致精神疾病"并不严谨，但睡眠与情绪的**双向因果**关系已有较多证据。

### 7.3 睡眠与情绪的双向循环

| 方向 | 机制 |
|------|------|
| 睡眠 → 情绪 | 睡眠不足削弱前额叶对杏仁核的调控，情绪反应性升高、易怒、情绪波动 |
| 情绪 → 睡眠 | 焦虑与反刍让人入睡困难；抑郁常伴早醒；创伤后噩梦与睡眠碎片化 |
| 共同风险 | 失眠是抑郁与焦虑的重要风险与维持因素；失眠治疗（如 CBT-I）可改善情绪症状 |

### 7.4 改善睡眠的循证建议（睡眠卫生）

| 建议 | 说明 |
|------|------|
| 固定作息 | 每天相近时间上床与起床，周末差别不宜过大 |
| 保证时长 | 多数成年人需要约 7 小时以上；个体差异存在 |
| 光照管理 | 早晨接受自然光，睡前一小时减少强光与屏幕蓝光 |
| 咖啡因与酒精 | 午后避免咖啡因；酒精虽助入睡但破坏后半夜睡眠结构 |
| 睡前降唤醒 | 温水澡、呼吸放松、正念、阅读纸质书 |
| 床只用于睡眠 | 减少"床上刷手机-清醒"的条件化联结 |
| 睡不着就起身 | 躺床 20 分钟仍清醒则起身做安静活动，有困意再回床 |
| 白天运动 | 规律有氧运动改善睡眠质量（睡前 2–3 小时避免剧烈运动） |
| 午睡控制 | 20–30 分钟可恢复警觉；超过 60 分钟可能影响夜间睡眠 |

> 若长期失眠（每周 ≥3 晚、持续 ≥3 个月）并影响日间功能，属于**失眠障碍**范畴，失眠认知行为治疗（CBT-I）是国际指南推荐的一线治疗（来源：睡眠障碍临床指南；国家卫生健康委 2024 年 12 月新闻发布会专家说明）。

### 7.5 睡眠与情绪调节的日常闭环

```
睡眠充足 → 前额叶调控能力好 → 情绪稳定、认知重评更容易
情绪稳定 → 入睡顺利、夜间觉醒少 → 睡眠更充足
（反之，任一环断裂都可能形成恶性循环）
```

## 八、压力管理的实操框架

### 8.1 三层干预模型

| 层级 | 目标 | 手段 |
|------|------|------|
| 一级：减少压力源 | 降低暴露 | 时间管理、边界设定、任务重组、环境调整 |
| 二级：改变评价 | 改变对事件的解释 | 认知重评、现实检验、降低绝对化要求 |
| 三级：改善反应 | 降低生理与情绪唤醒 | 呼吸、运动、正念、睡眠、社会支持 |

### 8.2 时间与边界管理要点

- **把"不可控"与"可控"分开**：只对可控部分制定行动；
- **任务分解**：把模糊大任务拆成 15–30 分钟可完成的具体动作；
- **缓冲时间**：日程不要排满，预留 20% 弹性；
- **沟通边界**：明确非工作时段、拒绝非必要请求；
- **减少切换**：一次只做一件事，关掉非必要通知。

### 8.3 急性压力的即时工具（数分钟内可用）

| 工具 | 做法 |
|------|------|
| 延长呼气呼吸 | 吸 4 秒、呼 6–8 秒，重复 5–10 次 |
| 5-4-3-2-1 落地法 | 说出 5 个看到的、4 个触到的、3 个听到的、2 个闻到的、1 个尝到的 |
| 生理性叹息 | 两次短吸一次长呼，快速降低唤醒 |
| 命名情绪 | "这是焦虑，不是危险"——标注可降低杏仁核反应 |
| 短暂活动 | 快走 5–10 分钟打断反刍 |

### 8.4 长期压力管理的证据较强的做法

| 做法 | 证据 |
|------|------|
| 规律有氧运动 | 常被列为见效较快、持续时间较长的压力管理方法之一 |
| 正念减压（MBSR） | 8 周标准化课程，多项 RCT 支持减压与改善生活质量 |
| 充足睡眠 | 恢复情绪调节能力的基础 |
| 社会联结 | 缓冲压力、降低孤独感 |
| 认知行为技能 | 改变非适应性评价与行为模式 |
| 限制酒精与"逃避式"应对 | 避免形成新的问题 |

### 8.5 常见"看似减压实则有害"的方式

国家卫生健康委新闻发布会专家特别提醒，以下方式不仅不能消除问题，还可能带来更多身心健康与适应问题（来源：国家卫生健康委 2024 年 12 月发布会专家发言）：

- 酗酒；
- 过度购物；
- 暴饮暴食；
- 沉迷网络与游戏。

## 九、常见误区辨析

| 误区 | 更准确的说法 |
|------|--------------|
| "负面情绪是坏的，应该消灭" | 情绪有适应功能；目标是调节而非消灭 |
| "情绪是理性的对立面" | 情绪参与决策，腹内侧前额叶受损者做决定反而更困难（达马西奥等人研究） |
| "焦虑都是病" | 焦虑是正常情绪，需按时间＋严重程度标准判断 |
| "抑郁就是矫情/想不开" | 抑郁障碍是有诊断标准、可治疗的疾病；与道德意志无关 |
| "睡眠不足补周末就行" | 作息紊乱本身会损害昼夜节律；规律性比一次性补觉更重要 |
| "把情绪压下去就没事了" | 表达抑制未能降低生理与主观唤醒，长期与更差结果相关 |
| "正能量就是不能难过" | 接纳与允许负性情绪存在，是更有效的调节前提 |
| "压力越大越有动力" | 只有适度、可控、短期的压力提升表现 |
| "深呼吸随时都有效" | 对惊恐发作等情境，过快深呼吸可能加重不适；延长呼气更稳妥 |
| "某种食物/保健品能治好抑郁" | 不能；中重度抑郁需规范医疗干预 |

1. 固定起床时间（含周末），误差不超过 1 小时；

4. 睡前 1 小时不看工作消息与短视频；

## 十一、积极情绪与拓展-建构理论

### 11.1 理论的提出

芭芭拉·弗雷德里克森（Barbara Fredrickson）在 1998 年、2001 年提出**拓展-建构理论（broaden-and-build theory）**，其核心主张是（来源：Fredrickson, 1998, 2001；百度百科"芭芭拉·弗雷德里克森"词条；《中国社会科学》积极情绪综述）：

| 命题 | 内容 |
|------|------|
| 拓展（broaden） | 积极情绪拓宽个体的注意、认知与行为资源库，让人更愿意探索与尝试 |
| 建构（build） | 拓宽效应长期累积，形成持久的身体、智力、人际与心理资源 |
| 抵消效应（undoing effect） | 积极情绪能"撤销"消极情绪引发的生理唤醒，加速从紧张中恢复 |
| 螺旋上升 | 资源增加使未来更易获得积极体验，形成正向循环 |

对照组实验：观看激发积极情绪视频的参与者，能列出更多想做的事，且从消极状态中恢复更快（来源：Fredrickson 团队实验研究；科普报道）。

### 11.2 十种核心积极情绪

弗雷德里克森列出十种核心积极情绪（来源：Fredrickson《Positivity》2009）：喜悦、感激、宁静、兴趣、希望、自豪、逗趣、激励、敬佩、爱。

### 11.3 需要谨慎对待的"3:1 比例"

弗雷德里克森早期与合作者曾提出"积极情绪与消极情绪约 3:1 为最佳比例"。这一具体数值后来在方法学层面受到质疑，相关论文也曾作出更正。因此：

- **理论方向**（积极情绪有累积建设作用）有较多证据支持；
- **具体倍数**不宜当作硬性标准或考核指标。

（来源：积极情绪研究的方法学讨论；科普评论）

### 11.4 消极情绪的适应功能

不要误解为"消极情绪全是坏的"。消极情绪通常**收窄**认知与行为范围，以便迅速动员能量应对威胁，其适应功能是**短暂且有代价**的；积极情绪则具有**可持续的适应性**（来源：积极情绪与心理弹性综述；Block & Kremen 关于心理弹性的描述）。

| 维度 | 消极情绪 | 积极情绪 |
|------|----------|----------|
| 认知范围 | 收窄 | 拓宽 |
| 行为倾向 | 特定（战斗/逃跑/僵住） | 多样、探索 |
| 时间特征 | 短暂、消耗 | 可持续、积累 |
| 长期作用 | 生存 | 成长与资源建构 |

### 11.5 培养积极情绪的实证做法

| 做法 | 说明 |
|------|------|
| 感恩记录 | 每周写下若干件值得感激的事（Emmons & McCullough 相关研究） |
| 善意行为 | 主动为他人做小事，提升自身积极情绪 |
| 品味（savoring） | 有意延长对美好体验的注意与回味 |
| 建立关系 | 高质量社会联结是积极情绪最稳定的来源之一 |
| 身体活动 | 运动与户外光照改善情绪 |
| 心流活动 | 投入与技能匹配的挑战性活动 |

## 十二、共情、情绪传染与社会情绪

### 12.1 共情的成分

共情（empathy）通常被拆为几个相对独立的成分（来源：社会心理学与共情研究综述）：

| 成分 | 含义 | 例子 |
|------|------|------|
| 情绪共情（experience sharing） | 感受他人的情绪 | 看到别人哭自己也想哭 |
| 认知共情 / 心理理论 | 推断他人的想法与感受 | 猜到对方生气是因为被忽视 |
| 共情关怀（empathic concern） | 因他人处境而产生关心 | 想帮他做点什么 |
| 个人痛苦（personal distress） | 因他人痛苦而自身不适 | 慌乱、想逃离现场 |

> 研究提示：**情绪共情与共情关怀**较多与助人行为相关；而**个人痛苦**有时与回避行为相关。共情不等于"替别人难受"，而是理解并关心。

### 12.2 情绪传染

**情绪传染（emotional contagion）**指情绪在人际间自动传播的现象：面部模仿、语调同步、姿势趋同是重要机制（来源：情绪传染研究综述）。它有双重含义：

| 正面 | 负面 |
|------|------|
| 团队士气提升、亲密感增加 | 焦虑与敌意在群体中扩散 |
| 咨询、教育中的情感共鸣 | 长期照护者、服务岗位的情绪耗竭 |

### 12.3 情绪劳动

**情绪劳动（emotional labor）**由 Arlie Hochschild 提出，指为满足工作要求而管理自身情绪表达的过程（来源：情绪劳动研究综述）。

| 策略 | 做法 | 常见后果 |
|------|------|----------|
| 表层扮演（surface acting） | 只改变外在表情与语气，内心感受不变 | 情绪失调、耗竭、去人格化风险升高 |
| 深层扮演（deep acting） | 通过认知重评等方式改变内在感受 | 相对更少的耗竭，真实感更强 |

> 这与 Gross 的结论一致：**只压外表（表达抑制/表层扮演）代价更高；改变解释（认知重评/深层扮演）代价更低。**

### 12.4 社会支持与情绪

社会支持通常分为四类（来源：社会支持研究综述）：

| 类型 | 内容 |
|------|------|
| 情感支持 | 被关心、被理解、被接纳 |
| 工具支持 | 实际的帮助（代班、跑腿、经济） |
| 信息支持 | 建议、指导、参考经验 |
| 评价支持 | 反馈与自我价值的确认 |

社会支持是**压力缓冲**的重要资源，但需注意：低质量、冲突性关系反而可能增加压力。

## 十三、愤怒与冲动管理

### 13.1 愤怒的适应功能与代价

愤怒是基本情绪之一，其适应功能是排除阻碍、维护边界（来源：基本情绪理论；APA 情绪词条）。但愤怒的长期高表达与心血管风险、关系损害、冲动决策相关。

### 13.2 常见误区：宣泄（catharsis）

| 流行说法 | 研究结论 |
|----------|----------|
| "生气就砸、就吼，发泄出来就好了" | 反复宣泄愤怒行为往往会**强化**攻击倾向，而非降低；短期内可能感觉好受，但长期效果相反 |
| 有效做法 | 降低生理唤醒（延长呼气、离开现场、运动）、认知重评、问题解决、表达性写作 |

（来源：攻击行为与宣泄假说研究综述）

### 13.3 愤怒管理操作范式

| 步骤 | 具体做法 |
|------|----------|
| 1 识别预警信号 | 身体（胸闷、握拳、发热）、思维（"他凭什么"）、行为（提高音量） |
| 2 暂停 | 物理离开 10–20 分钟，或约定"稍后再说" |
| 3 降低唤醒 | 延长呼气呼吸、冷水洗脸、快走 |
| 4 命名与重评 | "我现在很生气，因为我觉得被轻视"；寻找第二解释 |
| 5 表达需求 | 用"我"句式："当你……我感到……我希望……" |
| 6 事后复盘 | 触发点是什么？下次能否提前规避？ |

### 13.4 冲动行为的通用延迟技巧

- **10 分钟规则**：想立即行动时先等 10 分钟；
- **"如果-那么"计划**（实施意向）："如果我想立刻回怼，那么我先离开房间喝杯水"；
- **环境摩擦**：让冲动行为变得更难执行；
- **替代行为**：给同一需求一个更安全的出口。

## 十四、职业倦怠（burnout）

### 14.1 定义与三维度

职业倦怠由 Christina Maslach 等人在 1970–80 年代系统研究；世界卫生组织在《国际疾病分类》第十一次修订本（ICD-11）中将其列为**与职业情境相关的现象**（occupational phenomenon，非独立疾病分类）（来源：Maslach & Leiter, 2017；NCBI《Key Dimensions of Burnout》；ICD-11 相关说明；Maslach Burnout Inventory 研究）。

| 维度 | 英文 | 表现 |
|------|------|------|
| 情绪衰竭 | emotional exhaustion | 被工作"榨干"，情绪与体力资源耗尽 |
| 去人格化 / 犬儒 | depersonalization / cynicism | 对工作对象与同事冷漠、疏离、玩世不恭 |
| 个人成就感降低 | reduced personal efficacy | 觉得自己无能、没有成果、工作无意义 |

三维度**相对独立**，可不同组合出现；Maslach 认为三者常按"衰竭 → 疏离 → 无效能感"的顺序发展。

### 14.2 主要工作特征性风险因素（六类）

| 风险类别 | 说明 |
|----------|------|
| 工作负荷过重 | 要求超出能力与资源 |
| 缺乏控制 / 自主 | 无法决定"怎么做" |
| 奖励不足 | 内外在回报与期待不符，缺乏认可 |
| 社交支持不足 | 缺少团队、亲密与归属 |
| 公平与尊重缺失 | 感到被不公正对待 |
| 价值观冲突 | 个人价值与组织价值不匹配 |

（来源：Maslach 倦怠理论综述；工作需求-资源（JD-R）模型）

### 14.3 个体差异

元分析提示高神经质、高内向、低尽责性、低宜人性与倦怠相关（来源：Alarcon 等元分析，转引自倦怠综述）。但倦怠的首要驱动通常在**组织与工作设计**，而非个人缺陷（Maslach："倦怠者是煤矿里的金丝雀"）。

### 14.4 倦怠 vs 抑郁

| 特征 | 职业倦怠 | 抑郁 |
|------|----------|------|
| 领域 | 主要限于工作情境 | 弥漫到生活各领域 |
| 核心 | 对工作的衰竭与疏离 | 广泛的心境低落与快感缺失 |
| 关系 | 倦怠可增加抑郁风险，二者相关但不等同 | 需按诊断标准判断 |

### 14.5 干预方向

| 层级 | 措施 |
|------|------|
| 组织层面 | 合理工作量、增加自主、改善公平与认可、团队支持、价值澄清 |
| 团队层面 | 明确分工、定期反馈、心理安全 |
| 个体层面 | 边界设定、睡眠与运动、恢复期（recovery）、寻求专业帮助 |
| 就医信号 | 持续两周以上的心境低落、兴趣丧失、明显功能受损 → 精神科评估 |

## 十五、情绪与心身健康

### 15.1 心身关系的基本立场

现代心身医学的共识是：**心理与躯体通过神经、内分泌、免疫三条通路双向交互**（来源：心身医学综述；应激与免疫研究）。这既反对"心理问题都是想出来的"，也反对"所有躯体不适都源于情绪"。

| 通路 | 机制 | 例子 |
|------|------|------|
| 神经通路 | 自主神经支配内脏 | 焦虑时心率快、肠蠕动改变 |
| 内分泌通路 | HPA 轴与皮质醇 | 长期压力下代谢与免疫改变 |
| 免疫通路 | 炎性细胞因子 | 长期应激与炎症、抑郁相关 |

### 15.2 常见的"情绪-躯体"关联

| 躯体表现 | 常见关联情绪 |
|----------|--------------|
| 紧张性头痛、肌肉酸痛 | 焦虑、长期紧张 |
| 功能性胃肠不适（IBS 等） | 焦虑、抑郁、压力 |
| 心悸、胸闷、气短 | 惊恐、焦虑（须先排除器质性疾病） |
| 睡眠障碍 | 焦虑、抑郁、反刍 |
| 慢性疲乏 | 抑郁、倦怠、睡眠不足 |

> 重要原则：**先排除器质性疾病**，再考虑心理因素；两者也可并存。

### 15.3 心理弹性（resilience）

心理弹性指在逆境中维持或恢复良好功能的能力。研究一致发现：高心理弹性者积极情绪水平更高，且更擅长使用**原因聚焦**（认知重评、增强评价）的情绪调节策略（来源：情绪调节与心理弹性综述；Block & Kremen 相关研究）。

| 弹性资源 | 说明 |
|----------|------|
| 社会支持 | 稳定、可信赖的关系 |
| 认知灵活 | 多角度解释事件 |
| 情绪调节技能 | 重评、接纳、宣泄 |
| 身体健康 | 睡眠、运动、营养 |
| 意义感 | 目标、价值、信仰 |
| 既往成功经验 | "我曾挺过来"的自我效能 |

## 十六、情绪测量与自评工具

### 16.1 常用量表（科普介绍，非诊断工具）

| 工具 | 用途 | 说明 |
|------|------|------|
| PANAS | 正负情绪量表 | 分别测正性情绪与负性情绪两个维度 |
| PSS | 感知压力量表（Cohen 等，1983） | 测主观压力感受，而非客观事件数量 |

## 十七、情绪发展的毕生视角

### 17.1 儿童期情绪发展要点

| 阶段 | 典型进展 |
|------|----------|
| 婴儿期 | 出现基本情绪表达；社会性微笑；情绪调节主要依赖照料者 |
| 幼儿期 | 出现自我意识情绪（羞耻、内疚、自豪）；学会命名情绪 |
| 学龄期 | 理解混合情绪与情绪规则；开始使用认知策略调节 |
| 青春期 | 情绪强度升高、对同伴评价敏感；调节能力仍在发展中 |

### 17.2 青春期的情绪特点与神经基础

青春期情绪反应增强与大脑发育的**不同步**有关：奖赏相关回路较早成熟，而负责冲动控制与长远判断的前额叶皮层是最晚成熟的区域之一，其结构成熟会延续到二十多岁（来源：Giedd 等 NIMH 纵向 MRI 研究；Steinberg 双系统/成熟不平衡模型；青少年脑发育综述）。

| 现象 | 机制解释 |
|------|----------|
| 情绪波动大、易激动 | 奖赏与情绪系统敏感度升高，控制系统仍在发育 |
| 对同伴评价极敏感 | 社会奖赏敏感性高 |
| 冒险行为增多 | 高估奖励、低估风险，尤其在同伴在场时 |
| 深夜情绪低落 | 昼夜节律后移＋睡眠不足 |

> 严谨性提示：把"前额叶 25 岁才成熟"当作"青少年无法为自己的选择负责"的依据，是对研究的**过度简化**。更准确的说法是：脑发育与环境、情境、社会条件**交互作用**，外部的结构与可预期的后果对青少年尤其重要。

### 17.3 成年期的情绪

- 情绪稳定性总体随年龄提升；
- 情绪调节策略从"抑制"更多转向"重评与接纳"；
- 责任感与角色压力（工作、育儿、照护老人）成为主要应激源。

### 17.4 老年期情绪：社会情绪选择理论与"积极效应"

劳拉·卡斯滕森（Laura Carstensen）提出**社会情绪选择理论（socioemotional selectivity theory, SST）**：人对"未来还剩多少时间"的知觉决定了社交目标的优先顺序（来源：Carstensen, 1993, 2006；Carstensen et al., 1999；《Current Directions in Psychological Science》2021 综述；科普中国词条）。

| 时间知觉 | 优先目标 | 社交特征 |
|----------|----------|----------|
| 未来充裕（典型青年） | 知识获取、规划未来、扩展关系 | 网络大、伙伴多样 |
| 未来有限（典型老年） | 情绪满足与意义 | 网络小、集中在亲密关系 |

**积极效应（positivity effect）**：老年人对积极信息的注意与记忆优于消极信息，情绪控制更好、日常消极情绪更少。研究还显示，当把任务目标从"记住尽可能多"改为"尽可能准确"时，年龄差异会消失，提示该效应是**动机性**的而非能力缺陷（来源：Carstensen 实验室系列研究；Stanford Medicine 报道）。

> 另一个重要更正：**老年期的心理健康总体优于青年期**——除痴呆外，抑郁、焦虑与多数精神疾病的发生率更低（来源：Carstensen 访谈；美国国家科学院《When I'm 64》相关章节）。

### 17.5 情绪调节能力的毕生发展小结

| 年龄阶段 | 主要调节资源 | 主要挑战 |
|----------|--------------|----------|
| 婴幼儿 | 照料者协助 | 生理需求、依恋安全 |
| 儿童 | 语言命名、规则学习 | 情绪理解不足 |
| 青少年 | 同伴支持、自主探索 | 情绪强度与冲动 |
| 成年 | 认知重评、问题解决、社会支持 | 多重角色压力 |
| 老年 | 情绪优先、经验智慧、选择性投入 | 丧失与健康变化 |

## 十八、跨文化与个体差异

### 18.1 表达规则的跨文化差异

基本情绪的面部表情具有跨文化可识别性，但**表达规则（display rules）**——何种场合可以表达何种情绪——受文化强烈塑造（来源：情绪跨文化研究；APA 情绪词条）。集体主义文化通常更强调情绪抑制以维护关系和谐；个体主义文化更鼓励情绪表达。

### 18.2 情绪的社会建构

不同语言对情绪的切分不同（如某些文化缺少与"焦虑"完全对应的词），提示情绪的**概念化**本身有文化成分。这不否定基本情绪的生物学基础，而是说明"情绪体验如何被理解与命名"深受文化影响。

### 18.3 个体差异的来源

| 因素 | 说明 |
|------|------|
| 气质 | 婴儿期即表现出的反应性与自我调节差异 |
| 依恋经历 | 早期照料质量影响情绪调节的内在工作模型（见《社会心理学与人格》《发展心理学》篇） |
| 人格特质 | 高神经质者更易体验负性情绪；低神经质更情绪稳定 |
| 学习经历 | 家庭与学校如何回应情绪表达 |
| 生理因素 | 睡眠、激素、疾病、药物 |
| 社会处境 | 经济压力、歧视、社会支持水平 |

### 18.4 情绪与决策

情绪不是理性的对立面。一方面，情绪会引入偏差（如焦虑导致高估风险、愤怒导致乐观与冒险）；另一方面，情绪对决策不可或缺——腹内侧前额叶受损的患者智力与逻辑测验正常，却难以做出正常的生活决策（达马西奥等人的研究，来源：情绪与决策研究综述）。

| 情绪状态 | 对判断的典型影响 |
|----------|------------------|
| 焦虑 | 高估威胁概率、偏好确定性 |
| 愤怒 | 低估风险、倾向冒险、更依赖刻板判断 |
| 悲伤 | 更细致加工、更愿改变现状 |
| 积极情绪 | 更灵活、更富创造性，但也可能更依赖启发式 |

## 十九、常见情绪相关流行说法的核查

| 说法 | 核查结果 |
|------|----------|
| "情绪需要被彻底控制" | 情绪无法也无需被消灭；调节的目标是**功能适应**，压抑代价更高 |
| "生气就发泄有益健康" | 反复宣泄愤怒行为往往**强化**攻击倾向，长期结果更差 |
| "喝点酒能缓解焦虑" | 酒精短期抑制中枢，长期加重焦虑、破坏睡眠，且易形成依赖 |
| "微笑能让人立刻变快乐" | 面部反馈效应存在但效应较小，且原始研究曾遇复制困难；宜视为"可能的辅助"，而非万能方法 |
| "深呼吸一定能止住惊恐" | 过快深呼吸可能加重过度换气；对惊恐发作，**延长呼气**与接纳更稳妥 |
| "积极情绪越多越好，要一直正能量" | 积极情绪的累积有建设作用，但强迫"正能量"会阻碍真实情绪的处理 |
| "压力都是坏的" | 适度、可控、短期的压力可提升表现 |
| "熬夜无所谓，睡够总量就行" | 昼夜节律与睡眠规律性本身重要，作息紊乱直接损害情绪调节 |
| "心理问题靠自己就能扛过去" | 轻度困扰可通过自我调节缓解；持续两周以上或影响功能应及时求助 |

## 小结

- 情绪是包含主观体验、生理唤醒、认知评价与行为表达的复合反应；Ekman 提出六种基本情绪（快乐、悲伤、恐惧、愤怒、惊讶、厌恶），Plutchik 提出八种成对情绪的"情绪之轮"，维度模型则用效价与唤醒两轴刻画情绪。
- 情绪的生理基础包括自主神经系统（SAM 轴，秒级）与神经内分泌轴（HPA 轴，分钟至小时级）；HPA 轴链条为下丘脑 CRH/AVP → 垂体 ACTH → 肾上腺皮质皮质醇，并经负反馈自我调节。
- 皮质醇是"双面激素"：短时升高增强应对能力，长期偏高损害海马、前额叶与免疫，形成"压力-皮质醇-情绪"恶性循环。
- Selye 的一般适应综合征把压力反应分为警戒、抵抗、衰竭三阶段；Lazarus 与 Folkman 强调认知评价（初级评价、次级评价、再评价）与两类应对策略。
- 判断焦虑抑郁是否为病态，可参考"时间标准＋严重程度标准"；重性抑郁发作要求 2 周内 9 项症状中至少 5 项（含抑郁心境或兴趣丧失之一）。我国成人任何精神障碍终生患病率为 16.6%，其中焦虑障碍 7.6%、心境障碍 7.4%（CMHS, 2019）。
- Gross 情绪调节过程模型区分为先行关注（含认知重评）与反应关注（含表达抑制）；实证结果显示认知重评长期优于表达抑制。
- 睡眠与情绪呈双向关系：Walker 等（2007）发现 35 小时睡眠剥夺使杏仁核反应升高约 60%，并使杏仁核-前额叶通讯中断。失眠认知行为治疗（CBT-I）是慢性失眠的一线治疗。
- 压力管理应聚焦"强度与持续时间"而非"完全消除"；有氧运动、正念、睡眠、社会支持、认知技能是证据较充分的长期手段；酗酒、暴食、过度购物、沉迷网络是常见的有害"伪减压"。

> 再次提醒：本文为科普，**不构成心理诊疗建议**。若出现持续两周以上的情绪困扰、功能受损，或任何自伤自杀念头，请寻求专业心理/精神科帮助，或拨打**全国心理援助热线 12356**、联系当地精神卫生中心。
