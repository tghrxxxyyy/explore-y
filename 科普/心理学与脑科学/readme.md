# 科普 · 心理学与脑科学

> 用科学视角认识「自己」：我们如何注意、记忆、学习与决策，大脑如何工作，情绪从何而来。本板块面向成人通识，把实验室结论翻译成日常可用的知识，并澄清流行心理学误区。

## 阅读建议

1. 从《认知与记忆》起步：注意 → 知觉 → 记忆 → 学习，构成认知科学的主干。
2. 每篇配「常见误区」与「把知识用起来」章节，学完即可对照自己的生活习惯做调整。
3. 本板块将持续扩展：情绪与动机、发展与人格、社会心理学、睡眠科学等方向。
