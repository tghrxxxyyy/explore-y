# 科普 · 心理学与脑科学

> 用科学视角认识「自己」：我们如何注意、记忆、学习与决策，大脑如何工作，情绪从何而来，人如何在社会中彼此影响，又如何在生命全程中变化。本板块面向成人通识，把实验室结论翻译成日常可用的知识，并澄清流行心理学误区。

## 阅读建议

1. 入门顺序推荐：**认知与记忆 → 情绪与压力管理 → 行为与习惯养成**，先理解"认知—情绪—行为"这条主干。
2. 想理解人与人的关系，读**社会心理学与人格**；想理解"人为什么会变成今天这样"，读**发展心理学（毕生发展）**。
3. **心理健康与求助**不必按顺序读：如需应急，直接跳至「危机干预」与「如何求助」两章。
4. 每篇配「常见误区」与「把知识用起来」章节，学完即可对照自己的生活习惯做调整。
