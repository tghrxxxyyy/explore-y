# 科普 · 微生物

> 肉眼难见、却主宰地球生命——细菌、古菌、病毒与微观真菌。作为与动物/植物/真菌并列的生物学第四支柱，本板块补全"看不见的多数"。

## 子模块导航

- [微生物（细菌/古菌/病毒）](微生物（细菌/古菌/病毒）.md) — 三域系统与病毒定位、细菌形态结构（有益/有害）、古菌极端环境、病毒增殖与噬菌体、微生物组、发酵与抗生素、耐药危机

## 本板块说明

- 微生物是**跨类的集合概念**：含原核的细菌与古菌、非细胞的病毒，以及真核的酵母/霉菌/部分原生生物（后两者分别在《真菌与地衣》《原生动物与海绵动物》中）。
- 本板块与"动物""植物"并列，构成生物学的完整骨架；真菌独立成界的内容见植物板块下的《真菌与地衣》。
- 病毒不属三域（非细胞），单独说明其位置。
- 图片指向 Wikimedia Commons 等公共版权图库，可按描述检索使用。
- 本板块**不构成任何诊断、用药或防疫建议**；疾病与用药请咨询医生与疾控部门。
