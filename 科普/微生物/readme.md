## 本板块说明

- 微生物是**跨类的集合概念**：含原核的细菌与古菌、非细胞的病毒，以及真核的酵母/霉菌/部分原生生物（后两者分别在《真菌与地衣》《原生动物与海绵动物》中）。
- 本板块与"动物""植物"并列，构成生物学的完整骨架；真菌独立成界的内容见植物板块下的《真菌与地衣》。
- 病毒不属三域（非细胞），单独说明其位置。
- 本板块**不构成任何诊断、用药或防疫建议**；疾病与用药请咨询医生与疾控部门。各篇已在文首标明对应免责声明。
