## 一、什么是化学反应

**化学反应** 是原有物质（反应物）变成新物质（生成物）的过程，本质是**原子的重新组合**，反应前后原子种类与数目不变（质量守恒）。

- **物理变化**（如水结冰）不生成新物质；**化学变化**（如纸燃烧）生成新物质。
- 判断标志：产生气体、沉淀、颜色变化、放热/吸热、生成新气味等（注意：这些只是征象，非绝对）。

| 对比 | 物理变化 | 化学变化 |
|------|----------|----------|
| 是否有新物质 | 否 | 是 |
| 例子 | 冰融化、玻璃破碎 | 铁生锈、食物腐败 |
| 可逆性 | 多易恢复 | 多难恢复 |

> **生活联想**：煮鸡蛋时蛋白凝固，是蛋白质分子结构变化（化学变化）；水沸腾变成水蒸气，只是状态改变（物理变化）。

## 二、化学键：原子如何「握手」

原子要结合成分子或晶体，靠的是**化学键**——原子间的相互作用力。主要有三种：离子键、共价键、金属键。

### 2.1 离子键（电子的「捐赠」）

- **形成**：金属原子**失去**电子成阳离子，非金属原子**得到**电子成阴离子，靠静电引力结合。
- **特点**：多见于金属+非金属（如 NaCl 食盐）。
- **性质**：通常易溶于水、熔融或溶于水后能导电（有自由离子）。

**实例**：钠（Na）把 1 个电子送给氯（Cl），形成 Na⁺ 与 Cl⁻，靠静电吸引成食盐晶体。

### 2.2 共价键（电子的「共享」）

- **形成**：两个非金属原子**共用**电子对。
- **特点**：常见于非金属之间（如 H₂、O₂、H₂O、CO₂）。
- **极性 vs 非极性**：共用电子对偏移（如 H–O）为极性键；不偏移（如 O=O）为非极性键。

**实例**：一个水分子 H₂O 中，氧与两个氢各共用一对电子，呈 V 形结构。

### 2.3 金属键（电子的「海洋」）

- **形成**：金属原子释放出的价电子在整块金属中自由游动，形成「电子海」，把正离子「胶」在一起。
- **解释**：为何金属良导电导热、有延展性——自由电子可移动、原子层可滑动而不破裂。

| 化学键 | 参与原子 | 结合方式 | 典型物质 | 性质特征 |
|--------|----------|----------|----------|----------|
| 离子键 | 金属+非金属 | 静电吸引（得失电子） | NaCl、CaO | 硬脆、熔融导电 |
| 共价键 | 非金属+非金属 | 共用电子对 | H₂O、CO₂、金刚石 | 多为分子或原子晶体 |
| 金属键 | 金属原子间 | 电子海 | Fe、Cu、Al | 导电、延展 |

> **常见误区①**：「所有的盐都是离子键。」澄清：多数盐是离子键，但有些含共价键（如 NH₄Cl 中 NH₄⁺ 内部为共价键）。

## 三、四大基本反应类型

按反应物与生成物的组合方式，化学反应分为四类（来源：中学化学通识分类）。

### 3.1 化合反应（多变一）

> A + B → AB

- 实例：碳燃烧 `C + O₂ → CO₂`；生石灰遇水 `CaO + H₂O → Ca(OH)₂`。
- 生活：铁在氧气中点燃生成四氧化三铁（火星四射）。

### 3.2 分解反应（一变多）

> AB → A + B

- 实例：水电解 `2H₂O → 2H₂↑ + O₂↑`；石灰石煅烧 `CaCO₃ → CaO + CO₂↑`。
- 生活：过氧化氢（双氧水）分解制氧气，常用于消毒与实验室。

### 3.3 置换反应（单换单）

> A + BC → AC + B

- 实例：铁放入硫酸铜 `Fe + CuSO₄ → FeSO₄ + Cu`（湿法炼铜原理）。
- 生活：活泼金属（如 Zn）与酸反应放出氢气 `Zn + 2HCl → ZnCl₂ + H₂↑`。

### 3.4 复分解反应（双交换）

> AB + CD → AD + CB

- 条件：生成**沉淀、气体或水**之一，反应才能发生。
- 实例：盐酸与氢氧化钠中和 `HCl + NaOH → NaCl + H₂O`；小苏打与醋（见下篇）。
- 生活：用含 Ca(OH)₂ 的石灰水检验 CO₂：`Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O`（变浑浊）。

| 类型 | 通式 | 例子 |
|------|------|------|
| 化合 | A+B→AB | 硫燃烧成 SO₂ |
| 分解 | AB→A+B | 氯酸钾受热分解 |
| 置换 | A+BC→AC+B | 铁换铜 |
| 复分解 | AB+CD→AD+CB | 酸碱中和 |

## 四、氧化还原反应：电子的转移

并非所有反应都属于上述四类——**氧化还原反应**是按「电子是否转移」的另一条主线，贯穿燃烧、呼吸、腐蚀、电池。

### 4.1 核心概念

- **氧化**：失去电子（或化合价升高）。
- **还原**：得到电子（或化合价降低）。
- **口诀**：「还（原）原（剂）得电子被还原；氧（化）化（剂）失电子被氧化。」常记为「升失氧、降得还」。
- 氧化与还原**同时发生**，有得必有失。

### 4.2 实例

**燃烧（以甲烷为例）**

```
CH₄ + 2O₂ → CO₂ + 2H₂O
```

碳的化合价从 −4 升到 +4（被氧化），氧从 0 降到 −2（被还原）。

**铁生锈（电化学腐蚀）**

```
4Fe + 3O₂ + xH₂O → 2Fe₂O₃·xH₂O （铁锈，主要成分为水合氧化铁）
```

铁失去电子被氧化，氧气得到电子被还原（来源：Rust/Wikipedia 电化学腐蚀机制；全球腐蚀年成本超 2.5 万亿美元，约占 GDP 3.4%）。

**电池**：锌锰干电池、锂电池都是利用氧化还原反应把化学能变电能。

| 过程 | 电子 | 化合价 | 例子 |
|------|------|--------|------|
| 氧化 | 失去 | 升高 | 燃料燃烧、金属腐蚀 |
| 还原 | 得到 | 降低 | 金属冶炼、呼吸 |

> **生活联想**：我们呼吸时，葡萄糖被氧气氧化释放能量——这是生命版的氧化还原反应。

## 五、化学反应速率：快慢由什么决定

**反应速率** 表示单位时间内反应物消耗或生成物增加的快慢。同一反应，有时瞬间完成（爆炸），有时极慢（铁变锈需时日）。

### 影响速率的主要因素

| 因素 | 影响 | 生活例子 |
|------|------|----------|
| 浓度 | 越大越快 | 木柴在纯氧中比在空气中烧得更旺 |
| 温度 | 越高越快（约每升 10℃ 速率翻倍） | 食物冷藏保鲜 |
| 接触面积 | 越大越快 | 煤粉比煤块烧得快；切小的菜易熟 |
| 催化剂 | 改变速率 | 见下节 |
| 压强（气体） | 越大越快 | 增大压强促进合成氨 |

- 经验规律：温度每升高约 10 K，许多反应速率约增加 1–2 倍（范特霍夫规则）。

> **常见误区②**：「放热反应就一定快。」澄清：快慢看速率，与吸热/放热（看能量）是两回事。有的放热反应极慢（如 H₂ 与 O₂ 常温混合可长期不变，需点火引发）。

## 六、催化剂：反应的「加速器」

**催化剂** 是能改变化学反应速率、而本身在反应前后质量和化学性质不变的物质。多数加快反应（正催化），少数减慢（负催化/抑制剂）。

### 6.1 催化剂的特点

- **不改变化学平衡**，只缩短到达平衡的时间。
- **有选择性**：一种催化剂通常只对特定反应有效。
- **可能中毒失活**：杂质（如硫）可使催化剂失效。

### 6.2 生活与工业中的催化剂

| 场景 | 催化剂 | 作用 |
|------|--------|------|
| 汽车尾气净化 | 三元催化器（Pt、Pd、Rh） | 把 CO、NOₓ、HC 转化为 CO₂、N₂、H₂O |
| 合成氨 | 铁系催化剂 | 温和条件下固氮制化肥 |
| 生物体 | 酶（蛋白质） | 消化、代谢的高效催化剂 |
| 石油裂解 | 沸石分子筛 | 重油转为汽油 |
| 双氧水消毒 | 自身或酶催化 | 分解产生活性氧杀菌 |

> **生活实例——酶**：唾液中的淀粉酶把淀粉变糖（嚼馒头越嚼越甜）；酿酒靠酵母菌的酶把糖变酒精。酶是「生物催化剂」，条件温和、效率极高，但怕高温（煮鸡蛋让酶失活）。

> **绿色化学关联**：Anastas 与 Warner 提出的绿色化学 12 原则之一即「**催化**优于化学计量试剂」——催化能大幅减少废弃物（详见《环境与绿色化学》）。

## 七、生活实例与常见误区

### 7.1 厨房里的反应

- **小苏打 + 醋冒泡**：酸碱复分解（详见《酸碱盐与日常化学》）。
- **酵母发面**：酵母菌分解糖产 CO₂，使面团蓬松（生物化学反应）。
- **美拉德反应**：烧烤时肉表面褐变、产生香气，是氨基酸与糖的复杂反应（非单纯焦化）。

### 7.2 常见误区澄清

**误区 1：催化剂参与反应后就没了。**
澄清：催化剂参与中间过程，但反应结束又「再生」，总质量和化学性质不变。

**误区 2：氧化反应必须要有氧气。**
澄清：「氧化」原指与氧结合，但现代定义为「失电子/化合价升高」。例如 `Zn + Cu²⁺ → Zn²⁺ + Cu` 中锌被氧化，全程无氧气。

**误区 3：燃烧一定需要氧气。**
澄清：多数燃烧是和氧气，但镁可在二氧化碳或氮气中燃烧，氯气中氢气也能燃烧——只要发生剧烈的氧化还原并放热发光即可。

**误区 4：所有化学反应都伴随明显现象。**
澄清：很多反应「悄无声息」，如铁缓慢生锈、食物在体内的代谢，肉眼难察。

## 八、小结

- 化学反应是**原子重组**，遵循质量守恒。
- 三种基本化学键：**离子键（得失）、共价键（共用）、金属键（电子海）**，决定物质性质。
- 四大反应类型：化合、分解、置换、复分解；另有一条主线——**氧化还原反应（电子转移）**。
- 反应速率受**浓度、温度、接触面积、催化剂、压强**影响。
- **催化剂**高效、可循环、有选择性，是绿色化学的重要抓手。
- 从厨房到工厂，从呼吸到电池，化学反应无处不在。

## 九、化学键的深入详解

### 9.1 离子键的结构与性质

离子键由正负离子间的静电引力形成，其强度由晶格能衡量：

| 参数 | 说明 | 影响因素 |
|------|------|----------|
| 晶格能 | 离子晶体解离为气态离子所需能量 | 离子电荷越高、半径越小，晶格能越大 |
| 硬度 | 取决于离子间作用力 | NaCl 较软，MgO 极硬 |
| 熔点 | 晶格能越大，熔点越高 | NaCl 801°C，MgO 2852°C |
| 溶解性 | 极性溶剂（如水）可溶解 | 水合能与晶格能的竞争 |

常见离子晶体的熔点对比：

| 离子化合物 | 晶格能 (kJ/mol) | 熔点 (°C) |
|------------|-----------------|-----------|
| NaCl | 864 | 801 |
| KBr | 671 | 734 |
| MgO | 3850 | 2852 |
| CaF2 | 2630 | 1418 |
| Al2O3 | 15916 | 2072 |

### 9.2 共价键的类型

共价键可按多种方式分类：

| 分类方式 | 类型 | 说明 |
|----------|------|------|
| 按电子对重叠方式 | sigma 键 | 电子云沿键轴方向头碰头重叠 |
|  | pi 键 | 电子云沿键轴方向肩并肩重叠 |
|  | delta 键 | 电子云面对面重叠（金属-金属多重键） |
| 按极性 | 非极性共价键 | 电负性相同（H-H、O=O） |
|  | 极性共价键 | 电负性不同（H-O、C-O） |
|  | 配位键 | 一对电子全部来自一个原子（NH4+） |
| 按共享电子数 | 单键（σ） | H-H |
|  | 双键（σ+π） | O=O |
|  | 三键（σ+2π） | N≡N |

> **生活联想**：氮气 N2 的三键（N≡N）键能高达 945 kJ/mol，是自然界最强的化学键之一，这解释了氮气为何如此稳定——闪电和高温高压才能打破它（来源：化学键能表）。

### 9.3 金属键的量子力学解释

金属键的现代解释基于能带理论：

| 概念 | 说明 |
|------|------|
| 能带形成 | 金属原子紧密排列时，原子轨道重叠形成能带 |
| 价带 | 电子占据的最高能带 |
| 导带 | 未被电子完全填充的能带，电子可自由移动 |
| 自由电子 | 导带中的电子在整个金属中运动，导电导热 |
| 金属光泽 | 自由电子吸收并重新发射光子 |

### 9.4 分子间作用力

除化学键外，分子间作用力对物质性质有重要影响：

| 作用力 | 强度 (kJ/mol) | 存在范围 | 影响 |
|--------|---------------|----------|------|
| 氢键 | 10–40 | 含 H-F、H-O、H-N 的分子间 | 水的异常沸点、DNA 双螺旋 |
| 偶极-偶极力 | 2–10 | 极性分子间 | 影响沸点、溶解性 |
| 伦敦色散力 | 0.05–40 | 所有分子间 | 随分子量增大而增强 |
| 离子-偶极力 | 50–200 | 离子与极性分子间 | 盐溶解过程 |

> **水的异常**：水分子间的氢键使水的沸点（100°C）远高于同族类似物 H2S（-60°C），这是生命能在地球存在的关键（来源：化学教材）。

## 十、反应速率的理论基础

### 10.1 碰撞理论

反应发生的必要条件：

| 条件 | 说明 |
|------|------|
| 有效碰撞 | 分子必须碰撞才可能发生反应 |
| 能量门槛 | 碰撞能量 ≥ 活化能（Ea） |
| 正确取向 | 分子必须以合适方向碰撞 |

### 10.2 阿伦尼乌斯方程

描述温度与反应速率常数的关系：

> k = A · exp(-Ea/RT)

| 参数 | 含义 |
|------|------|
| k | 速率常数 |
| A | 指前因子（碰撞频率与取向因子） |
| Ea | 活化能 (J/mol) |
| R | 气体常数 8.314 J/(mol·K) |
| T | 绝对温度 (K) |

| 温度变化 | 速率变化（Ea=50 kJ/mol） |
|----------|--------------------------|
| 升高 10 K | 约增加 2 倍 |
| 升高 20 K | 约增加 4 倍 |
| 升高 30 K | 约增加 8 倍 |
| 升高 100 K | 约增加 1000 倍 |

### 10.3 活化能的物理意义

活化能是反应物转化为产物所需克服的最低能量障碍：

| 反应类型 | 典型活化能 (kJ/mol) | 反应速率 |
|----------|---------------------|----------|
| 离子反应（水溶液中） | < 40 | 极快（瞬间） |
| 多数有机反应 | 60–250 | 中等 |
| 酶催化反应 | 20–80 | 快 |
| 聚合物降解 | 100–300 | 慢 |
| 煤的自燃 | 约 150 | 极慢（需积热） |

## 十一、化学平衡

### 11.1 平衡常数

可逆反应达到动态平衡时，正逆反应速率相等：

> aA + bB ⇌ cC + dD

平衡常数表达式：

> Kc = [C]^c[D]^d / [A]^a[B]^b

| Kc 值 | 含义 |
|--------|------|
| Kc >> 1 | 平衡偏向产物（正反应有利） |
| Kc << 1 | 平衡偏向反应物（逆反应有利） |
| Kc ≈ 1 | 产物与反应物浓度相当 |

### 11.2 勒夏特列原理

当平衡系统受到外界扰动时，平衡会向减弱扰动的方向移动：

| 扰动 | 平衡移动方向 | 例子 |
|------|--------------|------|
| 增加反应物浓度 | 向产物方向 | 工业合成氨加过量氮气 |
| 增加温度 | 向吸热方向 | — |
| 增加压强 | 向气体体积减小方向 | 合成氨高压有利于正反应 |
| 移除产物 | 向产物方向 | 不断分离出产物 |

### 11.3 工业应用实例

| 工业过程 | 关键平衡 | 工艺条件 |
|----------|----------|----------|
| 合成氨（Haber 法） | N2+3H2 ⇌ 2NH3 | 400–500°C，15–25 MPa，铁催化剂 |
| 接触法制硫酸 | 2SO2+O2 ⇌ 2SO3 | 400–500°C，V2O5 催化 |
| 酯化反应 | 酸+醇 ⇌ 酯+水 | 浓硫酸催化，移除水 |

## 十二、催化剂的深入原理

### 12.1 催化剂降低活化能

催化剂通过提供替代反应路径，降低活化能：

| 反应 | 无催化剂 Ea | 有催化剂 Ea | 速率提升倍数 |
|------|-------------|-------------|--------------|
| H2O2 分解 | 75 kJ/mol | 58 kJ/mol（MnO2） | 约 1000 |
| 合成氨 | 230 kJ/mol | 160 kJ/mol（Fe） | 约 10^6 |
| 汽车尾气净化 | — | 120–150 kJ/mol（Pt/Pd/Rh） | 大幅提升 |

### 12.2 催化剂的中毒与再生

| 中毒类型 | 毒物 | 机理 | 再生方法 |
|----------|------|------|----------|
| 暂时中毒 | CO、水 | 可逆吸附 | 高温吹扫 |
| 永久中毒 | As、Pb、S 化合物 | 不可逆吸附或反应 | 需重新制备 |
| 结焦失活 | 积碳覆盖活性位 | 碳沉积 | 氧化再生 |

### 12.3 多相催化机例

以汽车三元催化器为例：

| 污染物 | 催化剂 | 转化反应 |
|--------|--------|----------|
| CO | Pt/Pd | 2CO + O2 → 2CO2 |
| HC | Pt/Pd | CxHy + O2 → CO2 + H2O |
| NOx | Rh | 2NO + 2CO → N2 + 2CO2 |

## 十三、日常生活中的化学反应

### 13.1 厨房化学

| 现象 | 化学反应 | 反应类型 |
|------|----------|----------|
| 铁锅生锈 | 4Fe + 3O2 + xH2O → 2Fe2O3·xH2O | 电化学腐蚀 |
| 铝锅变暗 | 4Al + 3O2 → 2Al2O3 | 氧化（钝化保护） |
| 鸡蛋变硬 | 蛋白质变性（肽链展开交联） | 化学变化 |
| 牛奶变酸 | 乳糖 → 乳酸（微生物发酵） | 生物化学 |
| 面包发酵 | C6H12O6 → 2C2H5OH + 2CO2 | 酶催化分解 |
| 茶水变色 | 茶多酚氧化聚合 | 氧化反应 |

### 13.2 家庭清洁中的化学

| 清洁场景 | 涉及化学 | 注意事项 |
|----------|----------|----------|
| 除水垢 | CaCO3 + 2HCl → CaCl2 + H2O + CO2 | 酸与碳酸盐反应 |
| 84 消毒液 | NaClO + 2HCl → Cl2 + NaCl + H2O | 严禁与洁厕灵混用 |
| 小苏打去油 | NaHCO3 碱性水解油脂 | 温和去污 |
| 醋除铁锈 | Fe2O3 + 6CH3COOH → 2(CH3COO)3Fe + 3H2O | 弱酸溶解氧化物 |

### 13.3 电池中的氧化还原

| 电池类型 | 负极（氧化） | 正极（还原） | 特点 |
|----------|--------------|--------------|------|
| 锌锰干电池 | Zn → Zn2+ + 2e- | MnO2 + H2O + e- → MnOOH + OH- | 一次性，低成本 |
| 碱性电池 | Zn → Zn2+ + 2e- | MnO2 + H2O + e- → MnOOH + OH- | 容量更大 |
| 锂离子电池 | LiC6 → Li+ + e- + C6 | Li1-xCoO2 + xLi+ + xe- → LiCoO2 | 可充电，高能量密度 |
| 氢氧燃料电池 | H2 → 2H+ + 2e- | O2 + 4H+ + 4e- → 2H2O | 清洁，仅排水 |

> **生活联想**：手机锂电池的充电-放电过程就是锂离子在正负极间反复嵌入-脱出的过程，本质上是可逆的氧化还原反应。
