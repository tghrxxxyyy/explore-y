## 关键事实速查（均联网核实）

- 已确认元素共 **118 种**（IUPAC）。
- 周期表：7 个周期、18 个族（IUPAC 1988 编号）；现代周期律以原子序数为依据。
- pH 由 **Sørensen 于 1909 年**提出，`pH = −log[H⁺]`，25 ℃ 时 7 为中性。
- 绿色化学 **12 原则**由 **Anastas 与 Warner（1998）**提出。
- **2024 年全球大气 CO₂ 浓度约 422.8 ppm（NOAA）/ 423.9 ppm（WMO），创历史新高**；较工业化前（~278 ppm）升高约 52%。
- 全球腐蚀年成本超 **2.5 万亿美元**（约占 GDP 3.4%），钢铁是用量最大的金属。
