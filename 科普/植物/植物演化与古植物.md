# 植物演化与古植物

> 植物如何从绿藻爬上陆地、如何用种子征服荒原、又用花朵"收买"昆虫称霸地球？本篇是《史前动物》的植物对应篇，串起 4.7 亿年的绿色史诗，并解释煤与石油的植物之源。

## 一、登陆：从水到陆

### 1.1 上岸的挑战

水生绿藻登陆须解决四大难题：**支撑**（无浮力）、**失水**（气生干燥）、**获取物质**（无水中营养流动）、**繁殖**（精子需水游动）。

### 1.2 关键创新

- **角质层与气孔**：减少失水并调控气体交换
- **维管组织（导管/筛管）**：远程运水运糖，支持"长高"
- **根**：固着并吸收，加速土壤形成
- **孢子带气囊/花粉**：摆脱对水的繁殖依赖

### 1.3 最早陆生植物

- 约 4.7 亿年前（奥陶纪）出现苔藓状陆生植物
- **库克逊蕨（*Cooksonia*）**：最早维管植物化石之一，仅数厘米、无叶无根，却开启陆地绿化
- 同期苔藓类（非维管）先登陆，奠定先锋角色

> 来源：Kenrick & Crane《陆地植物的早期演化》、维基百科"植物登陆"词条

## 二、维管植物兴起与"煤森林"

### 2.1 石松类与真蕨类繁盛

- 早泥盆世维管植物辐射；**原始鳞木（*Protolenes*）**等早期类型
- 晚泥盆—石炭纪：石松类、楔叶类、真蕨组成高大森林

### 2.2 煤森林主角

| 古植物 | 特征 | 今迹 |
|--------|------|------|
| 鳞木（*Lepidodendron*） | 高 30—40 米、树皮鳞片状、乔木石松 |  veget 成煤主力 |
| 封印木（*Sigillaria*） | 柱状、叶痕印章状 | 同属成煤 |
| 芦木（*Calamites*） | 高大楔叶类（木贼亲缘） | 成煤、硅化木 |
| 大羽羊齿（*Gigantopteris*） | 二叠纪热带巨型叶 | 东亚特色 |

- 石炭纪高氧（~35%）与暖湿，造就**巨型化**（见史前动物篇的巨虫）
- **煤的形成**：死亡植物淹积缺氧、经泥炭→褐煤→烟煤，如今煤层即古森林"压缩包"

> 冷知识：今日燃烧的动力煤，本质是 3 亿年前石松森林的遗体。

> 来源：Taylor《古植物学》、维基百科"石炭纪""鳞木"词条

## 三、种子革命

### 3.1 孢子 vs 种子

- **孢子**：单倍体、需水萌发、脆弱
- **种子**：包裹胚+营养+保护壳，耐旱耐储，是登陆深化的关键

### 3.2 种子植物的崛起

- **种子蕨（Pteridosperm）**：最早种子植物，外形似蕨却结籽（过渡类群）
- **裸子植物**繁盛于二叠—三叠纪：苏铁、银杏、松柏、买麻藤
- **优势**：种子耐旱，使之挺进干旱内陆，取代孢子植物主导地位

> 来源：维基百科"种子植物""种子蕨"词条

## 四、花的胜利：被子植物

### 4.1 起源与爆发

- 被子植物（开花植物）约 **1.3 亿年前**（白垩纪早期）出现，随后快速辐射
- 早白垩已有确证化石（如 Arcest 等），晚白垩已多样性爆发

### 4.2 为何所向无敌

- **花**：高效吸引动物传粉，精准投送花粉（对比风媒浪费）
- **双受精+果实**：胚乳供胚、果实护种并借动物传播
- **导管更高效**：多数具导管（对比裸子管胞），输水更强
- **协同演化**：与昆虫、鸟类形成"花—传粉者"军备竞赛，互相成就

### 4.3 称霸

白垩纪末大灭绝后，裸子植物受挫，被子植物借生态空位迅速成为全球植被主力（今占植物物种绝大多数）。

> 来源：Crepet 花演化、Friis 被子植物起源、维基百科"被子植物"词条

## 六、煤与石油的植物之源

- **煤**：主要来自石炭—二叠纪孢子植物森林（鳞木、封印木等）
- **石油/天然气**：部分源自更晚的浮游藻类与微生物有机质，经深埋热解而成
- **意义**：今日能源很大程度是"远古光合作用"的储蓄

> 来源：维基百科"成煤作用""石油成因"词条

## 八、与动物的协同演化

- **大气改造**：植物光合放氧，使动物有氧呼吸成为可能；土壤由地衣/苔藓/根共创
- **食物网底座**：植物固定能量，支撑全部陆生动物
- **双向塑造**：食草动物驱动植物防御（刺、毒素）；传粉动物塑造花形色彩；二者共进化

> 来源：Beerling《植物的发明》、维基百科"陆地植物"词条

## 九、大灭绝中的植物

- **二叠纪末**：气候干热，煤森林崩溃，裸子接棒
- **白垩纪末**：恐龙灭绝同时，部分植物（尤其北方针叶、蕨类"灾难蕨"）快速回弹，被子继续扩张
- **今天**：第六次灭绝中，植物多样性受栖息地丧失威胁，种子库（如千年种子库）成"诺亚方舟"

> 来源：维基百科"生物集群灭绝"词条

### 11.3 辽宁古果

| 特征 | 说明 |
|------|------|
| 学名 | *Archaefructus* |
| 发现 | 中国辽宁热河生物群 |
| 年代 | 约1.25亿年前（白垩纪早期） |

### 11.4 始祖鸟与被子植物

- **始祖鸟**：1.5亿年前，侏罗纪晚期，爬行动物向鸟类过渡

- **意义**：鸟类演化早于被子植物大爆发，花与鸟的协同演化更晚

## 十二、植物登陆过程详解

### 12.1 从水到陆的挑战

| 挑战 | 水生环境 | 陆生解决方案 |
|------|----------|--------------|
| 支撑 | 浮力支撑 | 细胞壁、机械组织 |
| 失水 | 水中不蒸发 | 角质层、气孔 |
| 气体交换 | 溶解于水 | 气孔、叶绿体 |
| 繁殖 | 精子游泳 | 花粉、种子 |
| 营养吸收 | 水中离子 | 根系、菌根共生 |

### 12.2 关键创新出现时间

| 创新 | 出现时间 | 意义 |
|------|----------|------|
| 角质层 | 约4.7亿年前 | 防止失水 |
| 气孔 | 约4.7亿年前 | 气体交换 |
| 维管束 | 约4.3亿年前 | 远程运输 |
| 根 | 约4.0亿年前 | 固着、吸收 |
| 种子 | 约3.6亿年前 | 耐旱、传播 |
| 花 | 约1.3亿年前 | 高效传粉 |

### 12.3 菌根的关键作用

- **最早共生**：4亿年前化石已见菌根结构
- **功能**：真菌帮助早期植物吸收磷等矿质，植物供糖
- **意义**：没有菌根，植物可能无法成功登陆

> 来源：Kenrick & Crane《陆地植物的早期演化》

## 十三、植物与地质事件

### 13.1 二叠纪大灭绝（2.5亿年前）

- **原因**：西伯利亚火山喷发，全球变暖、海洋缺氧
- **植物响应**：热带煤森林崩溃，90%以上植物物种灭绝
- **后果**：裸子植物接棒成为陆地植被主导

### 13.2 恐龙灭绝与被子植物崛起（6600万年前）

- **小行星撞击**：墨西哥希克苏鲁伯陨石坑
- **植物响应**："蕨类脉冲"——撞击后蕨类快速繁殖（阳光充足、竞争者消失）
- **长期趋势**：被子植物借生态空位辐射，成为现代植被主体

### 13.3 第四纪冰期与植物迁移（250万年前至今）

| 现象 | 影响 |
|------|------|
| 冰盖扩张 | 温带植物南迁 |
| 间冰期回暖 | 植物北迁、向上迁移 |
| 遗传瓶颈 | 分布区缩小导致遗传多样性下降 |
| 活化石留存 | 避难所（如中国西南）保存孑遗种 |

> 来源：维基百科"二叠纪大灭绝""白垩纪-古近纪灭绝事件"词条

## 十四、古植物学研究方法

### 14.1 化石记录

| 方法 | 材料 | 信息 |
|------|------|------|
| 压型化石 | 叶片、果实印痕 | 形态、脉序 |
| 铸型化石 | 石化木材、种子 | 内部结构 |
| 孢粉分析 | 土壤中的孢子花粉 | 古植被、古气候 |
| 琥珀包裹体 | 完整体 | 生态场景复原 |

### 14.2 现代技术

| 技术 | 应用 | 优势 |
|------|------|------|
| DNA条形码 | 物种鉴定 | 快速、准确 |
| 分子钟 | 估算分化时间 | 结合化石校准 |
| CT扫描 | 化石内部结构 | 无损检测 |
| 同位素分析 | 古气候重建 | 碳氧同位素 |

### 14.3 孢粉学

- **原理**：花粉/孢子外壁耐腐，可在沉积物中保存数百万年
- **应用**：重建古植被、古气候，辅助地层对比
- **局限**：花粉鉴定到属/科，难以精确到种

> 来源：Taylor《古植物学》、维基百科"古植物学"词条
