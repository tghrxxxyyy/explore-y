# 科普 · 植物

> 从藻类到高等被子植物，按门纲目科属种的分类体系认识植物世界：演化脉络、科属特征、代表物种、经济价值——看懂"植物进化树"的全貌。

## 子模块导航

### 分类主线

#### 低等植物与蕨类

- [藻类植物](藻类植物.md) — 无根茎叶分化的光合生物（绿藻/海带/紫菜/硅藻），含微藻生物技术与赤潮绿潮
- [苔藓植物](苔藓植物.md) — 无维管束的矮小植物（地钱/葫芦藓/泥炭藓），含微景观养护与苔藓文化
- [蕨类植物](蕨类植物.md) — 有维管束无种子的孢子植物（肾蕨/桫椤/卷柏），含食用药用蕨类与煤的形成
- [裸子植物](裸子植物.md) — 种子裸露的常绿乔木（松/柏/银杏/红豆杉/苏铁），含紫杉醇与中国名松

#### 被子植物

- [被子植物总论与单子叶植物](被子植物总论与单子叶植物.md) — 花的结构、禾本科（粮/竹/蔗）/兰科/棕榈科/百合科与室内绿植
- [双子叶植物-蔷薇类](双子叶植物-蔷薇类.md) — 蔷薇科（月季/果树）/豆科（大豆/花生）/仙人掌科/大戟科
- [双子叶植物-菊类与蔷薇以外的重要科](双子叶植物-菊类与蔷薇以外的重要科.md) — 菊科（青蒿素）/茄科（番茄/土豆/辣椒）/十字花科（白菜/油菜）/唇形科香草/伞形科/茜草科（咖啡）
- [双子叶植物-经济与观赏植物专题](双子叶植物-经济与观赏植物专题.md) — 茶文化/柑橘家族/木兰/樟/桑/葫芦科/葡萄猕猴桃与中国特有珍稀植物

- [观赏植物与园林艺术](观赏植物与园林艺术.md) — 中国十大名花、四季赏花地图、室内绿植、多肉、园林与盆景

## 本板块说明

- 本板块按**植物分类体系**组织：界→门→纲→目→科→属→种，被子植物遵循 APG 分子系统学分类。
- 分类主线 8 篇覆盖**藻类→苔藓→蕨类→裸子→被子植物**的完整演化脉络，每篇含代表物种表与科属鉴别要点。
- 实用专题 3 篇从**药用、观赏、食用安全**三个与生活最相关的角度深入。
- **真菌与地衣**单列为独立界内容（真菌非植物），并补充**生理繁殖、生态植被、食虫与寄生、演化古植物、农作物经济植物**五篇横向科普，覆盖"活着—繁衍—群居—特例—历史—人用"的完整框架。
- 分类学名参照 WFO（World Flora Online）、USDA PLANTS 数据库与维基百科。
- 图片指向 Wikimedia Commons 等公共版权图库，可按描述检索使用。
- 本板块**不构成任何食用或药用建议**，部分植物有毒，仅供科普学习参考。
