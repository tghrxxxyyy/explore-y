# 科普 · 植物

> 从藻类到高等被子植物，按门纲目科属种的分类体系认识植物世界：演化脉络、科属特征、代表物种、经济价值——看懂"植物进化树"的全貌。

## 子模块导航

### 低等植物与蕨类

- [藻类植物](藻类植物.md) — 无根茎叶分化的光合生物（绿藻/海带/紫菜/硅藻）
- [苔藓植物](苔藓植物.md) — 无维管束的矮小植物（地钱/葫芦藓/泥炭藓）

## 本板块说明

- 本板块按**植物分类体系**组织：界→门→纲→目→科→属→种，被子植物遵循 APG 分子系统学分类。
- 每篇包含**代表物种表（学名/俗名/科属/主要特征/经济价值）+ 科属鉴别要点**。
- 分类学名参照 WFO（World Flora Online）、USDA PLANTS 数据库与维基百科。
- 图片指向 Wikimedia Commons 等公共版权图库，可按描述检索使用。
- 本板块**不构成任何食用或药用建议**，部分植物有毒，仅供科普学习参考。
