## 本板块说明

- 本板块按**时间线 + 文明区域**双线组织：时间轴总览是总入口，各文明/时代独立成篇，从古代到当代依次展开。
- 每篇设有**"同期中国对照"小节**：以对比表格标注该阶段与同时期中国朝代（如罗马帝国≈两汉、牛顿≈康熙），并对比制度、科技与文化成就。
- 中国内容仅出现在对照小节中，主线叙述以世界史为主，可与「中华历史」板块互参。
- 纪年采用学术界通行说法（如"约公元前"），各流派纪年差异以权威著作为准。
- 图片指向 Wikimedia Commons 等公共版权图库，可按描述检索使用。
