# 动物演化与分类总论

> 为什么鲸鱼不是鱼、蝙蝠是哺乳动物？动物界 38 亿年的家谱如何展开？读懂这篇，你就能顺畅导航本板块的任意一篇分类文章。

## 一、什么是演化

### 1.1 演化的核心机制

演化（evolution）指种群基因频率在世代间的改变。现代综合论（modern synthesis）认定 **自然选择** 是演化的主要驱动力，辅以突变、基因漂变、基因流动等机制：

- **可遗传变异**：DNA 复制错误产生突变，有性生殖通过重组制造新组合，是演化的原材料
- **自然选择**：在有限资源下，更适应环境的个体留下更多后代，有利性状在种群中累积
- **隔离**：地理隔离或生殖隔离使种群分化，最终形成新物种
- **时间尺度**：微小变化经数百万年积累，足以从单细胞祖先走出今天的动物界

### 1.2 演化的关键证据

| 证据类型 | 说明 | 例子 |
|----------|------|------|
| 化石记录 | 地层中保存的远古生物遗体与遗迹 | 始祖鸟兼具爬行类与鸟类特征 |
| 比较解剖 | 同源器官揭示共同祖先 | 鲸鳍、蝙蝠翼、人臂骨骼结构同源 |
| 胚胎学 | 早期胚胎相似暗示亲缘 | 脊椎动物早期均有鳃裂与尾 |
| 分子生物学 | DNA/蛋白质相似度量化亲缘 | 人类与黑猩猩基因约 98.8% 相同 |
| 生物地理 | 分布格局受大陆漂移塑造 | 有袋类集中分布于澳新大陆 |
| 人工选择 | 人工选育直观展示选择力量 | 狼经选育分化出数百种犬 |

> 📷 [达尔文雀：加拉帕戈斯群岛的喙形差异是自然选择的经典例证]（图片来源：Wikimedia Commons）

> 来源：Darwin《物种起源》、Dobzhansky 现代综合论、美国自然历史博物馆（AMNH）演化教育资料、维基百科"演化"词条

## 二、生命之树：动物在何处

### 2.1 三域系统与真核生物

当代生物学把生命分为 **三域**（Woese, 1990）：古菌域（Archaea）、细菌域（Bacteria）、真核域（Eukarya）。动物属于真核域下的一个**界**（Animalia），与植物、真菌、原生生物并列。

- **古菌/细菌**：原核生物，无成形的细胞核，但代谢极其多样
- **真核生物**：细胞具细胞核与细胞器（线粒体、叶绿体等）
- **关键事件**：约 20 亿年前，一个原核生物"吞入"另一个并长期共生，演化出线粒体——真核生物的起点

### 2.2 动物在真核生物中的位置

真核域包含若干"超类群"（supergroup），动物与真菌、领鞭毛虫同属 **后鞭毛生物（Opisthokonta）**——也就是说，**动物最近的亲戚其实是真菌**，而非植物。这一结论来自分子系统学，颠覆了"动物和植物更接近"的直觉。

> 冷知识：海绵动物的领细胞（choanocyte）与领鞭毛虫（choanoflagellate）形态几乎一致，提示动物直接起源于这类单细胞生物。

> 来源：Woese 三域系统、Adl et al. 真核生物分类、Tree of Life Web Project

## 三、动物界的起源

### 3.1 从单细胞到多细胞

- **元古宙**：约 18 亿年前出现最早的多细胞生物（红藻化石）
- **埃迪卡拉纪（约 6.35—5.41 亿年前）**：出现软躯体、叶状、分叉的埃迪卡拉生物群（Ediacaran biota），多为辐射对称、固着生活，多数与现代动物门类关系不明
- **寒武纪大爆发（约 5.41 亿年前起）**：在短短千万至数千万年内，绝大多数现生动物门类集中出现，眼睛、外壳、捕食关系一并登场

### 3.2 动物共同祖先的特征

分子与化石证据指向动物共同祖先是一只 **海洋、两侧对称、具纤毛的滤食性小生物**，近似今天的**扁盘动物/领鞭毛虫**过渡形态。所有现生动物（除海绵、刺胞等少数基部类群）都是它的后代。

| 时间节点 | 事件 |
|----------|------|
| 约 8 亿年前 | 动物最早分化（基因钟推算） |
| 约 6.4 亿年前 | 埃迪卡拉生物群 |
| 约 5.41 亿年前 | 寒武纪大爆发，硬体化石骤增 |
| 约 5.3 亿年前 | 伯吉斯页岩保存软躯体精细结构 |

> 来源：Erwin & Valentine《寒武纪大爆发》、Nature 古生物学综述、维基百科"动物"词条

## 四、分类学基础：如何给动物上户口

### 4.1 分类阶梯

从宏观到微观依次为 **界（Kingdom）→ 门（Phylum）→ 纲（Class）→ 目（Order）→ 科（Family）→ 属（Genus）→ 种（Species）**。可借助口诀"界门纲目科属种，脊索动物哺乳纲"记忆。

- **种**：能相互交配并产生可育后代的自然种群（生物学物种概念）
- **属以上**：多依形态特征与系统发育划分
- **门**：身体蓝图的根本差异，如脊索动物门（具脊索/脊椎）、节肢动物门（分节+外骨骼）

### 4.2 双名法与三域之外的命名

瑞典博物学家林奈（Linnaeus, 1758）创立 **双名法**：属名 + 种加词，如智人 *Homo sapiens*。学名用拉丁化斜体，首字母大写。本板块各篇的物种均标注中文名与拉丁学名。

### 4.3 系统发育 vs 林奈阶梯

分子生物学揭示，许多传统"目/纲"并非单系群（即不包含共同祖先的全部后代）。现代分类更强调 **单系（monophyly）**，并以**支序图（cladogram）**表达亲缘。例如"鱼类"不是一个自然类群——鲨鱼与金枪鱼的亲缘，远不如金枪鱼与青蛙、人类近。

> 来源：林奈《自然系统》、ITIS 分类数据库、WoRMS 世界海洋物种名录

## 五、动物界的重大演化革新

按时间顺序，以下"身体蓝图"的升级塑造了今天的动物多样性：

| 革新 | 意义 | 首次出现于 |
|------|------|------------|
| 多细胞化 | 细胞分工、体型增大 | 元古宙 |
| 组织与器官 | 功能专一化 | 刺胞动物起 |
| 两侧对称 | 头尾分化、定向运动 | 扁形动物起 |
| 体腔（coelom） | 内脏独立悬浮、循环空间 | 环节动物起 |
| 分节 | 重复单元、运动高效 | 环节/节肢动物 |
| 原口/后口分化 | 胚胎发育路线分叉 | 两侧对称动物基部 |
| 脊索/脊椎 | 支撑大型活跃身体 | 脊索动物门 |
| 颌的出现 | 主动捕食、食物网升级 | 有颌鱼类 |
| 四肢登陆 | 占领陆地 | 早期四足类 |
| 羊膜卵 | 离水繁殖 | 爬行类/鸟类/哺乳类 |
| 恒温与胎生 | 稳定体温、育儿投入 | 鸟类/哺乳动物 |

### 5.1 原口动物与后口动物

两侧对称动物在胚胎发育上分为两支：

- **原口动物（Protostomia）**：口由胚孔形成，包括节肢动物、软体动物、环节动物、扁形/线形动物
- **后口动物（Deuterostomia）**：肛门由胚孔形成、口 later 形成，包括脊索动物（含脊椎动物）、棘皮动物（海星、海胆）

> 冷知识：海星看起来和脊椎动物毫无关系，但作为后口动物，它和人类的亲缘比和昆虫更近。

> 来源：《普通动物学》（刘凌云/郑光美）、Pivot 发育生物学、维基百科"后口动物"词条

## 七、常见分类误区

- **"冷血动物"≠ 低等**：变温（ectotherm）只是能量策略，昆虫、鱼类、爬行动物均变温，且在各自生态位极度成功
- **鲸不是鱼**：鲸、海豚是哺乳动物（胎生、哺乳、用肺呼吸），与牛羊的亲缘近于与鲨鱼
- **蝙蝠是鸟？**：蝙蝠是唯一真正飞行的哺乳动物，具毛发与翼膜而非羽毛
- **"鱼"是并系群**：鲨鱼（软骨鱼）、金枪鱼（辐鳍鱼）、肺鱼、腔棘鱼亲缘各异，没有单一共同祖先把它们和四足动物分开
- **珊瑚是植物？**：珊瑚虫是刺胞动物，其"骨骼"由虫体分泌，共生藻类才提供颜色与能量
- **章鱼是鱼？**：章鱼属软体动物门头足纲，与蜗牛、蛤蜊同源

> 来源：本板块各分类篇、维基百科"并系群""后口动物"词条

## 八、生物分类学详解

### 8.1 界门纲目科属种

生物分类学采用层级系统，从大到小依次为：

| 分类阶元 | 拉丁文 | 含义 | 举例（以狮为例） |
|----------|--------|------|------------------|
| 界 | Regnum | 最高阶元 | 动物界 Animalia |
| 门 | Phylum | 身体蓝图差异 | 脊索动物门 Chordata |
| 纲 | Class | 主要特征群 | 哺乳纲 Mammalia |
| 目 | Order | 形态与生态分化 | 食肉目 Carnivora |
| 科 | Family | 更近的亲缘 | 猫科 Felidae |
| 属 | Genus | 一组近缘种 | 豹属 Panthera |
| 种 | Species | 基本分类单位 | 狮 Panthera leo |

### 8.2 林奈双名法

- 瑞典博物学家林奈（Carl Linnaeus, 1707-1778）创立双名法
- 格式：**属名 + 种加词**，如 *Homo sapiens*（智人）
- 规则：学名用拉丁化斜体，属名首字母大写，种加词全小写
- 作用：全球统一命名，消除俗名混乱（如"山猫"在不同地区指不同动物）

### 8.3 分类学的现代挑战

- **隐存种（cryptic species）**：形态几乎一致但基因不同的物种，分子手段才可识别
- **杂交与基因渗透**：不同"种"可杂交并产生可育后代，物种边界模糊
- **系统发育物种概念**：以最小可辨识的种群为种，导致物种数"膨胀"
- 全球已描述物种约 200 万种，估计实际 800-1000 万种

> 来源：林奈《自然系统》、ITIS 分类数据库、维基百科"分类学"词条

## 九、演化证据深入

### 9.1 化石记录

- 化石是已灭绝生物的直接证据，保存形式包括：实体化石（骨骼/壳）、遗迹化石（足迹/洞穴）、印痕化石（叶片印迹）
- 化石记录不完整（软躯体难保存），但足以显示演化趋势
- 过渡化石（transitional fossils）是关键证据：
  - **始祖鸟**（*Archaeopteryx*）：爬行类→鸟类过渡
  - **提塔利克鱼**（*Tiktaalik*）：鱼类→四足类过渡
  - **始祖马**（*Hyracotherium*）：犬大小→现代马过渡

### 9.2 比较解剖学

- **同源器官**：结构来源相同但功能不同（如人的手、蝙蝠翼、鲸鳍），揭示共同祖先
- **同功器官**：功能相似但来源不同（如鸟翼与昆虫翅），是趋同演化的结果
- **痕迹器官**：退化残留结构（如人的阑尾、鲸的后肢残骨），证明曾有功能

### 9.3 胚胎学证据

- 脊椎动物早期胚胎均具有：咽裂、脊索、背神经管、肛后尾
- 越是亲缘近的物种，胚胎期相似度越高
- 重演律（recapitulation）：个体发育大致重演系统发育，但过于绝对化已被修正

### 9.4 分子生物学与 DNA 证据

| 比较对象 | 基因组相似度 | 演化分离时间 |
|----------|-------------|-------------|
| 人类 vs 黑猩猩 | ~98.8% | ~600-700 万年前 |
| 人类 vs 大猩猩 | ~98.4% | ~800-900 万年前 |
| 人类 vs 猩猩 | ~96.9% | ~1200-1400 万年前 |
| 人类 vs 猫 | ~90% | ~9000 万年前 |
| 人类 vs 果蝇 | ~60% | ~7-8 亿年前 |
| 人类 vs 酵母 | ~30% | ~15 亿年前 |

- **DNA 分子钟**：突变速率相对恒定，可估算物种分化时间
- **线粒体 DNA**：母系遗传，用于追溯母系谱系（如"线粒体夏娃"）

> 来源：Darwin《物种起源》、维基百科"演化证据"词条

## 十、自然选择详解

### 10.1 自然选择的四个条件

| 条件 | 说明 |
|------|------|
| 变异 | 种群内个体在性状上存在差异 |
| 遗传 | 变异必须可遗传（非环境获得） |
| 差异繁殖 | 不同个体留下后代数量不同 |
| 适应 | 有利变异在种群中频率增加 |

### 10.2 选择类型

| 类型 | 定义 | 例子 |
|------|------|------|
| 定向选择 | 偏好极端值 | 长颈鹿颈越来越长 |
| 稳定选择 | 偏好中间值 | 人类新生儿体重过大过小均不利 |
| 分裂选择 | 偏好两个极端 | 非洲维多利亚湖慈鲷快速分化 |
| 性选择 | 偏好吸引异性的特征 | 孔雀尾羽、鹿角 |
| 频率依赖选择 | 稀有表型占优 | 贝茨拟态中稀有拟态型更安全 |

### 10.3 适应辐射（Adaptive Radiation）

- 一个祖先物种在短时间内分化出多个形态和生态各异的后代
- 经典案例：
  - **达尔文雀**：13 种喙形各异，适应不同食物（加拉帕戈斯群岛）
  - **夏威夷蜜旋木雀**：约 50 种，喙形从细长到粗短不等
  - **非洲维多利亚湖慈鲷**：约 500 种，从同一祖先分化，生态位极度多样
  - **哺乳动物白垩纪大灭绝后辐射**：腾出生态位，哺乳类快速分化

> 来源：Darwin《物种起源》、维基百科"自然选择""适应辐射"词条

## 十一、物种形成

### 11.1 地理隔离（异域物种形成）

- 同一种群被地理障碍（山脉、河流、海洋）分隔
- 两侧独立演化，基因流动中断，最终形成生殖隔离
- 例子：达尔文雀从南美大陆飞至加拉帕戈斯群岛后分化

### 11.2 生殖隔离机制

| 机制 | 类型 | 例子 |
|------|------|------|
| 生态隔离 | 栖息地不同 | 同域但不同高度 |
| 时间隔离 | 繁殖期不同 | 蛙类不同季节鸣叫 |
| 行为隔离 | 求偶信号不同 | 萤火虫闪光频率 |
| 机械隔离 | 生殖器不匹配 | 昆虫外生殖器差异 |
| 配子隔离 | 配子无法结合 | 海胆精子无法入卵 |
| 杂种不活/不育 | 杂交后代不可活或不育 | 马×驴→骡（不育） |

### 11.3 同域物种形成

- 不需要地理隔离，通过生态位分化或染色体突变快速形成新种
- **多倍化（polyploidy）**：植物中常见，染色体加倍导致生殖隔离
  - 约 15% 的被子植物物种形成与多倍化有关
  - 动物中罕见，但某些蜥蜴和鱼类通过多倍化产生新种

> 来源：Mayr《动物物种与演化》、维基百科"物种形成"词条

## 十二、灭绝事件详解

### 12.1 五大灭绝

| 次序 | 名称 | 距今（百万年） | 灭绝比例 | 主因 |
|------|------|----------------|----------|------|
| 1 | 奥陶纪末 | 444 | ~85% 海洋种 | 冰川—海平面下降 |
| 2 | 晚泥盆世 | 372 | ~75% | 缺氧、植物登陆改气候 |
| 3 | 二叠纪末（最严重） | 252 | ~90-96% | 西伯利亚火山、酸化缺氧 |
| 4 | 三叠纪末 | 201 | ~80% | 火山、海洋酸化 |
| 5 | 白垩纪末 | 66 | ~76% | 小行星撞击 + 火山 |

### 12.2 二叠纪末"大死亡"

- 史上最严重灭绝，96% 海洋物种、70% 陆地脊椎动物消失
- 主因：西伯利亚大规模火山喷发（暗色岩）→ CO₂ 飙升 → 海洋酸化与缺氧
- 陆地恢复花了约 1000 万年
- 若无此次浩劫，主龙类（恐龙祖先）或仍主导，哺乳动物难有辐射机会

### 12.3 人类世第六次大灭绝

- 当前物种灭绝速率约为背景灭绝率的 100-1000 倍
- 主因：栖息地丧失（农业/城市化）、气候变化、过度开发、入侵物种、污染
- IUCN 红色名录评估：约 28% 的已评估物种面临灭绝威胁
- 两栖类受威胁比例最高（约 41%），因其皮肤透水、对环境变化敏感

> 来源：Benton《当生命几乎消失》、维基百科"生物集群灭绝"词条

## 十三、动物地理分布

### 13.1 六大地理界

动物学家将全球陆地分为六个动物地理界（Realms），各有独特动物组成：

| 地理界 | 范围 | 特有类群 |
|--------|------|----------|
| 古北界 | 欧亚大陆北部、北非 | 鹿、熊、鹰、猞猁 |
| 东洋界 | 南亚、东南亚 | 虎、亚洲象、猩猩、眼镜蛇 |
| 非洲界 | 撒哈拉以南非洲 | 狮、长颈鹿、大猩猩、河马 |
| 新北界 | 北美 | 麝牛、美洲野牛、响尾蛇 |
| 新热带界 | 中南美洲 | 美洲豹、树懒、蜂鸟、箭毒蛙 |
| 澳新界 | 澳大利亚、新西兰 | 袋鼠、考拉、鸭嘴兽、几维鸟 |

### 13.2 特有种与分布格局

- **特有种（endemic species）**：仅分布于特定区域的物种
- 澳大利亚特有种比例极高：袋鼠、考拉、鸭嘴兽均为特有
- 马达加斯加：约 90% 的物种为特有（狐猴）
- 加拉帕戈斯群岛：达尔文雀、巨龟均为特有

### 13.3 分布格局的成因

- **大陆漂移**：板块分裂导致动物区系隔离（如南美与非洲分离后独立演化）
- **气候变迁**：冰期-间冰期循环驱动物种迁徙与分化
- **地理障碍**：山脉、河流、海峡阻隔基因流动
- **人类活动**：入侵物种打破原有分布格局

> 来源：Wallace《动物的地理分布》、维基百科"动物地理学"词条
