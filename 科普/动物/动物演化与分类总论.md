# 动物演化与分类总论

> 为什么鲸鱼不是鱼、蝙蝠是哺乳动物？动物界 38 亿年的家谱如何展开？读懂这篇，你就能顺畅导航本板块的任意一篇分类文章。

## 一、什么是演化

### 1.1 演化的核心机制

演化（evolution）指种群基因频率在世代间的改变。现代综合论（modern synthesis）认定 **自然选择** 是演化的主要驱动力，辅以突变、基因漂变、基因流动等机制：

- **可遗传变异**：DNA 复制错误产生突变，有性生殖通过重组制造新组合，是演化的原材料
- **自然选择**：在有限资源下，更适应环境的个体留下更多后代，有利性状在种群中累积
- **隔离**：地理隔离或生殖隔离使种群分化，最终形成新物种
- **时间尺度**：微小变化经数百万年积累，足以从单细胞祖先走出今天的动物界

### 1.2 演化的关键证据

| 证据类型 | 说明 | 例子 |
|----------|------|------|
| 化石记录 | 地层中保存的远古生物遗体与遗迹 | 始祖鸟兼具爬行类与鸟类特征 |
| 比较解剖 | 同源器官揭示共同祖先 | 鲸鳍、蝙蝠翼、人臂骨骼结构同源 |
| 胚胎学 | 早期胚胎相似暗示亲缘 | 脊椎动物早期均有鳃裂与尾 |
| 分子生物学 | DNA/蛋白质相似度量化亲缘 | 人类与黑猩猩基因约 98.8% 相同 |
| 生物地理 | 分布格局受大陆漂移塑造 | 有袋类集中分布于澳新大陆 |
| 人工选择 | 人工选育直观展示选择力量 | 狼经选育分化出数百种犬 |

> 来源：Darwin《物种起源》、Dobzhansky 现代综合论、美国自然历史博物馆（AMNH）演化教育资料、维基百科"演化"词条

## 二、生命之树：动物在何处

### 2.1 三域系统与真核生物

当代生物学把生命分为 **三域**（Woese, 1990）：古菌域（Archaea）、细菌域（Bacteria）、真核域（Eukarya）。动物属于真核域下的一个**界**（Animalia），与植物、真菌、原生生物并列。

- **古菌/细菌**：原核生物，无成形的细胞核，但代谢极其多样
- **真核生物**：细胞具细胞核与细胞器（线粒体、叶绿体等）
- **关键事件**：约 20 亿年前，一个原核生物"吞入"另一个并长期共生，演化出线粒体——真核生物的起点

### 2.2 动物在真核生物中的位置

真核域包含若干"超类群"（supergroup），动物与真菌、领鞭毛虫同属 **后鞭毛生物（Opisthokonta）**——也就是说，**动物最近的亲戚其实是真菌**，而非植物。这一结论来自分子系统学，颠覆了"动物和植物更接近"的直觉。

> 冷知识：海绵动物的领细胞（choanocyte）与领鞭毛虫（choanoflagellate）形态几乎一致，提示动物直接起源于这类单细胞生物。

> 来源：Woese 三域系统、Adl et al. 真核生物分类、Tree of Life Web Project

## 三、动物界的起源

### 3.1 从单细胞到多细胞

- **元古宙**：约 18 亿年前出现最早的多细胞生物（红藻化石）
- **埃迪卡拉纪（约 6.35—5.41 亿年前）**：出现软躯体、叶状、分叉的埃迪卡拉生物群（Ediacaran biota），多为辐射对称、固着生活，多数与现代动物门类关系不明
- **寒武纪大爆发（约 5.41 亿年前起）**：在短短千万至数千万年内，绝大多数现生动物门类集中出现，眼睛、外壳、捕食关系一并登场

### 3.2 动物共同祖先的特征

分子与化石证据指向动物共同祖先是一只 **海洋、两侧对称、具纤毛的滤食性小生物**，近似今天的**扁盘动物/领鞭毛虫**过渡形态。所有现生动物（除海绵、刺胞等少数基部类群）都是它的后代。

| 时间节点 | 事件 |
|----------|------|
| 约 8 亿年前 | 动物最早分化（基因钟推算） |
| 约 6.4 亿年前 | 埃迪卡拉生物群 |
| 约 5.41 亿年前 | 寒武纪大爆发，硬体化石骤增 |
| 约 5.3 亿年前 | 伯吉斯页岩保存软躯体精细结构 |

> 来源：Erwin & Valentine《寒武纪大爆发》、Nature 古生物学综述、维基百科"动物"词条

## 四、分类学基础：如何给动物上户口

### 4.1 分类阶梯

从宏观到微观依次为 **界（Kingdom）→ 门（Phylum）→ 纲（Class）→ 目（Order）→ 科（Family）→ 属（Genus）→ 种（Species）**。可借助口诀"界门纲目科属种，脊索动物哺乳纲"记忆。

- **种**：能相互交配并产生可育后代的自然种群（生物学物种概念）
- **属以上**：多依形态特征与系统发育划分
- **门**：身体蓝图的根本差异，如脊索动物门（具脊索/脊椎）、节肢动物门（分节+外骨骼）

### 4.2 双名法与三域之外的命名

瑞典博物学家林奈（Linnaeus, 1758）创立 **双名法**：属名 + 种加词，如智人 *Homo sapiens*。学名用拉丁化斜体，首字母大写。本板块各篇的物种均标注中文名与拉丁学名。

### 4.3 系统发育 vs 林奈阶梯

分子生物学揭示，许多传统"目/纲"并非单系群（即不包含共同祖先的全部后代）。现代分类更强调 **单系（monophyly）**，并以**支序图（cladogram）**表达亲缘。例如"鱼类"不是一个自然类群——鲨鱼与金枪鱼的亲缘，远不如金枪鱼与青蛙、人类近。

> 来源：林奈《自然系统》、ITIS 分类数据库、WoRMS 世界海洋物种名录

## 五、动物界的重大演化革新

按时间顺序，以下"身体蓝图"的升级塑造了今天的动物多样性：

| 革新 | 意义 | 首次出现于 |
|------|------|------------|
| 多细胞化 | 细胞分工、体型增大 | 元古宙 |
| 组织与器官 | 功能专一化 | 刺胞动物起 |
| 两侧对称 | 头尾分化、定向运动 | 扁形动物起 |
| 体腔（coelom） | 内脏独立悬浮、循环空间 | 环节动物起 |
| 分节 | 重复单元、运动高效 | 环节/节肢动物 |
| 原口/后口分化 | 胚胎发育路线分叉 | 两侧对称动物基部 |
| 脊索/脊椎 | 支撑大型活跃身体 | 脊索动物门 |
| 颌的出现 | 主动捕食、食物网升级 | 有颌鱼类 |
| 四肢登陆 | 占领陆地 | 早期四足类 |
| 羊膜卵 | 离水繁殖 | 爬行类/鸟类/哺乳类 |
| 恒温与胎生 | 稳定体温、育儿投入 | 鸟类/哺乳动物 |

### 5.1 原口动物与后口动物

两侧对称动物在胚胎发育上分为两支：

- **原口动物（Protostomia）**：口由胚孔形成，包括节肢动物、软体动物、环节动物、扁形/线形动物
- **后口动物（Deuterostomia）**：肛门由胚孔形成、口 later 形成，包括脊索动物（含脊椎动物）、棘皮动物（海星、海胆）

> 冷知识：海星看起来和脊椎动物毫无关系，但作为后口动物，它和人类的亲缘比和昆虫更近。

> 来源：《普通动物学》（刘凌云/郑光美）、Pivot 发育生物学、维基百科"后口动物"词条

## 六、如何阅读本板块

本板块采用"**分类主线 + 实用专题**"双线结构：

- **无脊椎动物五大门**：原生动物与海绵动物 → 刺胞动物与栉水母 → 扁形动物与线形动物 → 环节动物与软体动物 → 节肢动物
- **脊椎动物五大纲**：鱼类 → 两栖动物 → 爬行动物 → 鸟类 → 哺乳动物
- **实用专题**：中国珍稀动物与保护、危险动物与野外安全、动物之最与趣味冷知识
- **横向科普（本篇及后续）**：动物行为学、动物感官与生理、史前动物与生命演化史

建议读法：先读本篇建立"家谱"框架，再按兴趣深入某一门类；遇到"为什么动物会这样做"看行为学，"身体怎么运转"看生理篇，"它们的祖先什么样"看史前篇。

## 七、常见分类误区

- **"冷血动物"≠ 低等**：变温（ectotherm）只是能量策略，昆虫、鱼类、爬行动物均变温，且在各自生态位极度成功
- **鲸不是鱼**：鲸、海豚是哺乳动物（胎生、哺乳、用肺呼吸），与牛羊的亲缘近于与鲨鱼
- **蝙蝠是鸟？**：蝙蝠是唯一真正飞行的哺乳动物，具毛发与翼膜而非羽毛
- **"鱼"是并系群**：鲨鱼（软骨鱼）、金枪鱼（辐鳍鱼）、肺鱼、腔棘鱼亲缘各异，没有单一共同祖先把它们和四足动物分开
- **珊瑚是植物？**：珊瑚虫是刺胞动物，其"骨骼"由虫体分泌，共生藻类才提供颜色与能量
- **章鱼是鱼？**：章鱼属软体动物门头足纲，与蜗牛、蛤蜊同源

> 来源：本板块各分类篇、维基百科"并系群""后口动物"词条
