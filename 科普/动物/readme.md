# 科普 · 动物

> 从单细胞的原生动物到最高等的哺乳动物，按门纲目科属种的分类体系认识动物世界：代表物种、形态特征、生活习性、生态价值——一文看懂动物界的"家谱"。

## 子模块导航

### 无脊椎动物

- [原生动物与海绵动物](原生动物与海绵动物.md) — 单细胞动物与最原始的多细胞动物（草履虫/变形虫/海绵）
- [刺胞动物与栉水母](刺胞动物与栉水母.md) — 辐射对称与刺细胞（水母/珊瑚/海葵/水螅）
- [扁形动物与线形动物](扁形动物与线形动物.md) — 身体扁平与线形（涡虫/血吸虫/蛔虫/秀丽隐杆线虫）
- [环节动物与软体动物](环节动物与软体动物.md) — 分节身体与软体（蚯蚓/沙蚕/贝类/章鱼/乌贼）
- [节肢动物](节肢动物.md) — 动物界最大门类（昆虫/蜘蛛/虾蟹/蜈蚣/鲎）

### 脊椎动物

- [鱼类](鱼类.md) — 软骨鱼纲与辐鳍鱼纲（鲨鱼/鲸鲨/金枪鱼/鲤鱼/肺鱼），含淡水鱼产业/渔业/观赏鱼/鲨鱼保护
- [两栖动物](两栖动物.md) — 水陆过渡的变温动物（青蛙/蟾蜍/蝾螈/大鲵），含蛙壶菌危机与大鲵保护
- [爬行动物](爬行动物.md) — 真正陆生的羊膜动物（蜥蜴/蛇/龟鳖/鳄鱼/楔齿蜥），含蛇毒医学与急救
- [鸟类](鸟类.md) — 恒温卵生的飞行者（麻雀/丹顶鹤/天鹅/鹰/孔雀），含观鸟入门/飞行原理/濒危保护
- [哺乳动物](哺乳动物.md) — 最高等的动物类群（鸭嘴兽/袋鼠/鲸/狮/大熊猫），含中国特有物种保护与鲸类

- [危险动物与野外安全](危险动物与野外安全.md) — 毒蛇/毒蜘蛛/海洋危险生物/人兽冲突，急救方法与非接触原则
- [动物之最与趣味冷知识](动物之最与趣味冷知识.md) — 体型/速度/感官/智慧之最，伪装共生与动物文化

## 本板块说明

- 本板块按**生物学分类体系**组织：界→门→纲→目→科→属→种，从低等到高等循序渐进。
- 分类主线 10 篇覆盖**无脊椎动物五大门 + 脊椎动物五大纲**，每篇含代表物种表与生态价值。
- 实用专题 3 篇从**保护、安全、趣味**三个角度深入动物世界。
- 分类学名参照 ITIS（美国集成分类信息系统）、WoRMS（世界海洋物种名录）与维基百科。
- 图片指向 Wikimedia Commons 等公共版权图库，可按描述检索使用。
- 本板块**不构成任何医疗或养殖建议**，野外遇险请以官方急救指南为准。
