# 科普 · 计算机与 AI

> 从「机器如何思考」到「数据如何被造、被传、被保护」：认识计算机的硬件骨架、操作系统的调度、互联网协议的分工、人工智能从符号时代到深度学习时代的演化，以及软件是怎么写出来的、算法为什么有快慢、云计算与大数据如何协作。面向成人通识，重原理与思想，少代码细节。

## 阅读建议

1. **零基础**：按 计算机 → 互联网 → AI 顺序：先懂机器，再懂连接，最后懂智能。之后可按兴趣选读：关心「怎么做出软件」读《编程与软件开发入门》，关心「为什么有的程序快」读《算法与数据结构》，关心「数据放哪、会不会被偷」读《数据安全与隐私保护》与《云计算与大数据》。
2. **按需查阅**：想看懂「为什么手机卡」读《互联网与网络协议》；想弄懂「GPU 为什么贵」读《计算机原理与组成》；想分清「AI/机器学习/大模型」的区别读《人工智能与机器学习》；想搞懂「HTTPS 小锁到底保证了什么」读《数据安全与隐私保护》；想知道「云上到底谁负责安全」读《云计算与大数据》。
3. **交叉关联**：
   - 大模型训练：GPU 并行（《计算机原理与组成》）+ 分布式网络（《互联网与网络协议》）+ 分布式计算框架（《云计算与大数据》）。
   - 云计算：硬件虚拟化（《计算机原理与组成》）+ 网络传输（《互联网与网络协议》）+ 容器与分布式原理（《云计算与大数据》）。
   - 数据合规：加密与访问控制（《数据安全与隐私保护》）+ 数据分类分级与跨境（《云计算与大数据》）。
   - 算法落地：数据结构与复杂度（《算法与数据结构》）→ 语言与工程实现（《编程与软件开发入门》）→ 大规模分布式执行（《云计算与大数据》）。
   - 安全左移：安全编码与供应链（《数据安全与隐私保护》）+ 测试与 CI/CD（《编程与软件开发入门》）。

## 本板块说明

- 七篇均为「成人通识」体例：导语 + 分章节（概念→原理→实例→常见误区）+ 术语速查表 + 小结，关键事实标注来源（IEEE、NIST、IETF RFC、W3C、ISO/IEC、CLRS、Hennessy & Patterson《计算机组成与设计》等）。
- 技术演进快，文中版本号与产品名以写作时为准，原理层面长期有效。
- 本板块**不构成任何技术选型、法律意见或投资建议**。
