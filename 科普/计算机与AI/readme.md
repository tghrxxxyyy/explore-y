# 科普 · 计算机与 AI

> 从「机器如何思考」到「网络如何连通」：认识计算机的硬件骨架、操作系统的调度、互联网协议的分工，以及人工智能从符号时代到深度学习时代的演化。面向成人通识，重原理与思想，少代码细节。

## 阅读建议

1. **零基础**：按 计算机 → 互联网 → AI 顺序：先懂机器，再懂连接，最后懂智能。
2. **按需查阅**：想看懂「为什么手机卡」读《互联网与网络协议》；想弄懂「GPU 为什么贵」读《计算机原理与组成》；想分清「AI/机器学习/大模型」的区别读《人工智能与机器学习》。
3. **交叉关联**：
   - 大模型训练：GPU 并行（《计算机原理与组成》）+ 分布式网络（《互联网与网络协议》）。
   - 云计算：硬件虚拟化（《计算机原理与组成》）+ 网络传输（《互联网与网络协议》）。
