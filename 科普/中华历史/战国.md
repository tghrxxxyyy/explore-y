# 战国（前 475 年—前 221 年）

> 七雄争霸、变法图强的东周后期，百家争鸣达到高潮；二百五十余年间列国兼并，终由秦并六国、天下一统。

## 一、三家分晋与七雄格局

战国起始年代学界有前 476 年（周元王即位）与前 475 年两说，本卷取前 475 年。东周前期春秋五霸争雄的局面，至战国演变为七雄并立的兼并战争。

### 1.1 三家分晋

- **背景**：春秋末期晋国卿族长期把持国政，互相吞并，最终仅余韩、赵、魏三家
- **分晋**：前 403 年周威烈王正式册封韩、赵、魏三家为诸侯，晋国名存实亡
- **意义**：《资治通鉴》以此为开篇，史学界多以此为战国开始的标志性事件

### 1.2 田氏代齐

- **过程**：齐国卿族田氏数代经营，渐夺姜氏齐国大权
- **完成**：前 386 年周安王册封田和为齐侯，姜氏齐国为田氏取代，史称"田氏代齐"

### 1.3 战国七雄势力表

| 国家 | 都城 | 主要特征 |
|------|------|---------|
| **秦国** | 咸阳 | 商鞅变法，国力最强 |
| **楚国** | 郢 | 疆域最广，文化独特 |
| **齐国** | 临淄 | 东方大国，稷下学宫 |
| **燕国** | 蓟 | 北方强国 |
| **赵国** | 邯郸 | 胡服骑射 |
| **魏国** | 大梁 | 李悝变法，战国初期霸主 |
| **韩国** | 新郑 | 申不害变法 |

- **周室名存实亡**：七雄相继称王，王畿缩为洛邑周边一隅，周天子仅存虚名；前 256 年周赧王卒，东周为秦所灭

## 三、各国变法

战国变法浪潮自魏国李悝变法发端，吴起变法（楚）、商鞅变法（秦）等先后登场，以富国强兵为共同目标，秦国改革最为彻底，最终在竞争中胜出。

### 3.1 商鞅变法（秦国）

- **徙木立信**：商鞅立三丈木于南门，募能徙者赏五十金，有人徙木果然得赏，以此取信于民
- **军功爵制**：实行二十等爵制，斩敌一首赐爵一级，无论出身，按军功定爵禄田宅
- **什伍连坐**：五家为伍、十家为什，相互监督，一家犯法，邻里连坐
- **废井田开阡陌**：承认土地私有、允许买卖，国家按亩征收赋税
- **废世卿世禄**：宗室贵族无军功者不得入属籍，彻底铲除旧贵族特权
- **结果**：前 356 年、前 350 年两次变法，秦国"兵强而地广"，为统一六国奠定基础；商鞅晚年车裂而死，新法不废

### 3.2 赵武灵王胡服骑射（赵国）

- **背景**：赵国北邻林胡、楼烦等游牧部族，屡受侵扰，传统车战难敌骑射
- **内容**：前 307 年力排众议下令改穿胡服、学习骑射，组建中国第一支正规骑兵部队
- **效果**：赵国"辟地千里"，灭中山国，成为东方强国

### 3.3 吴起变法（楚国）

- **内容**：罢无能之官、裁撤疏远公族，封君子孙三代之后收回爵禄；明法审令，禁纵横家游说
- **结局**：楚悼王死后贵族作乱，吴起伏于王尸上被射杀，变法夭折；楚国一度"南平百越，北并陈蔡"

### 3.4 申不害术治（韩国）

- **内容**：以"术"驾驭群臣——君主深藏不露、因任而授官、循名而责实，用权术考核臣下
- **效果**：韩昭侯任申不害为相十五年，"内修政教，外应诸侯"，韩国国治兵强，诸侯不敢加兵

### 3.5 邹忌讽齐王纳谏（齐国）

- **典故**：邹忌以妻、妾、客奉承自己"美于徐公"之事类比，劝齐威王勿受蒙蔽
- **效果**：齐威王下令"群臣吏民能面刺寡人之过者，受上赏"，齐国政治清明，"战胜于朝廷"，燕赵韩魏闻之皆朝于齐

## 四、重要战争

战国战争由春秋的车战礼战，发展为规模空前的歼灭战与攻城战，动辄数十万大军对决：

- **伊阙之战（前 293）**：秦将白起大破韩、魏联军，歼灭韩魏军 24 万，打通东进中原之路，"战神"之名由此而起
- **桂陵之战（前 353）**：前 354 年魏军围赵都邯郸，齐将孙膑避实击虚，直攻魏都大梁以解围，又于桂陵设伏大败魏军，"围魏救赵"成为军事学经典战法
- **马陵之战（前 341）**：孙膑以"减灶诱敌"之计，在马陵道设伏，魏将庞涓自刎，魏国由盛转衰，齐国称雄东方
- **长平之战（前 260）**：秦相范雎行反间计换下赵将廉颇，赵括"纸上谈兵"取代之；白起佯败诱敌、断粮合围，赵军四十余万降卒被坑杀，为战国最大惨剧之一，秦国自此确立统一优势
- **邯郸之战（前 259—前 257）**：秦军乘长平之胜进围赵都邯郸，赵国坚守三年；前 257 年魏公子信陵君窃符救赵，与楚军合力大败秦军，邯郸解围，秦统一进程一度受挫

## 五、百家争鸣

春秋末孔子、老子开其端，战国时思想学术进入全盛，儒、墨、道、法、兵、纵横诸家并起，史称"百家争鸣"，奠定此后两千年中华思想的基本格局。

| 学派 | 代表人物 | 核心主张 | 代表作 |
|------|---------|---------|--------|
| **儒** | 孔子、孟子、荀子 | 仁政礼治、性善/性恶，积极入世 | 《论语》《孟子》 |
| **道** | 老子、庄子 | 无为而治、道法自然、逍遥齐物 | 《道德经》《庄子》 |
| **墨** | 墨子 | 兼爱非攻、尚贤节用，苦行救世 | 《墨子》 |
| **法** | 商鞅、韩非 | 以法治国、法术势并重、中央集权 | 《韩非子》 |
| **兵** | 孙武、孙膑 | 不战而屈人之兵、避实击虚 | 《孙子兵法》《孙膑兵法》 |
| **纵横** | 苏秦、张仪 | 合纵连横、以谋略游说诸侯 | 《战国策》所载策士言行 |

- **孟荀之争**：孟子主性善，倡"四端"说与"民贵君轻"；荀子主性恶，"人之性恶，其善者伪也"，须以礼义法度矫正，故隆礼重法
- **庄子逍遥**：《逍遥游》鲲鹏扶摇九万里，《齐物论》万物齐一；"庄周梦蝶"喻物我两忘，文风汪洋恣肆，为浪漫文学之祖
- **韩非集大成**：与李斯同出荀子门下，吸收商鞅之"法"、申不害之"术"、慎到之"势"，主张"以法为教，以吏为师"；其书传入秦国，嬴政叹"寡人得见此人与之游，死不恨矣"，然韩非入秦后遭李斯构陷，死于狱中
- **稷下学宫**：齐都临淄设稷下学宫，汇集各国学者"不治而议论"，为百家争鸣的重要舞台
- **屈原与楚辞**：屈原（约前 340—前 278）创"楚辞"体，著《离骚》等名篇，以香草美人比兴寄志，前 278 年白起拔郢后投汨罗江

## 六、经济与社会

- **铁器普及**：铁器牛耕普及，生产力大幅提升；战国以后石磨推广，麦始由"粒食"变为"面食"
- **都江堰**：秦昭王时蜀郡守李冰主持修建于岷江之上，由鱼嘴分水堤、飞沙堰、宝瓶口三大主体构成无坝引水工程；成都平原自此"水旱从人，不知饥馑"，号称"天府之国"，两千余年不废，2000 年列入世界遗产名录
- **郑国渠**：前 246 年韩国派水工郑国赴秦，欲以修渠"疲秦"、耗其国力；工程引泾水入洛水，全长约 300 里，灌溉关中盐碱地四万余顷，"疲秦之计"反成"强秦之策"，关中"为沃野，无凶年"
- **商业与城市**：各诸侯国铸行布币、刀币、圜钱等不同形制货币；临淄、邯郸、大梁、郢等大都会相继兴起，其中齐都临淄为东方最大都会，兼为稷下学宫所在
- **手工业巅峰**：出土于湖北随州的曾侯乙编钟（战国早期，约前 433 年）全套 65 件，可发"一钟双音"，为青铜铸造与乐律理论的巅峰之作

## 七、秦并六国

- **远交近攻**：秦昭王时范雎献"远交近攻"之策——与远方之国结好，集中力量攻伐近邻的韩、魏，步步蚕食；范雎又行反间计离间赵国君臣，为长平之胜铺路
- **东进基础**：白起先后经伊阙之战、长平之战等役，削弱韩魏、重创赵国；前 278 年攻拔楚都郢，楚国被迫东迁，秦国尽占江汉之地
- **统一进程**：秦王嬴政即位后，从前 230 年起十年间并灭六国：

| 年份 | 灭国 | 说明 |
|------|------|------|
| 前 230 | 灭韩 | 七雄中疆域最小的韩国最先灭亡 |
| 前 228 | 灭赵 | 长平之战后赵国一蹶不振，邯郸陷落 |
| 前 225 | 灭魏 | 秦军围攻大梁，魏国灭亡 |
| 前 223 | 灭楚 | 疆域最广、抵抗最烈，秦倾全国之力方克 |
| 前 222 | 灭燕 | 燕国僻处北方，望风而降 |
| 前 221 | 灭齐 | 齐为最后灭亡之国，天下一统 |

- **终结**：前 221 年秦并六国，秦王嬴政自称"始皇帝"，二百五十余年的战国时代结束（详见[秦朝](秦朝.md)）

## 八、速记要点

- 战国起讫：前 475—前 221 年（一说前 476 年始），东周后期，周室名存实亡
- 前 403 年三家分晋、前 386 年田氏代齐，战国七雄格局成形
- 七雄：齐、楚、燕、韩、赵、魏、秦；秦都咸阳，楚疆最广，齐拥稷下学宫
- 变法浪潮：魏李悝、楚吴起、秦商鞅、韩申不害、赵武灵王胡服骑射、齐威王纳谏；商鞅变法最彻底，奠定秦的统一根基
- 名战：桂陵（前 353"围魏救赵"）、马陵（前 341 庞涓自刎）、长平（前 260 坑降卒四十余万）、邯郸（前 257 窃符救赵）
- 百家争鸣：儒（孟荀）、道（庄）、墨（墨子）、法（韩非）、兵（孙膑）、纵横（苏秦张仪）六家并立
- 水利双璧：都江堰（李冰，至今沿用）、郑国渠（"疲秦"反成"强秦"）
- 秦并六国：范雎"远交近攻"，前 230—前 221 年灭韩赵魏楚燕齐，前 221 年嬴政称"始皇帝"，天下一统
