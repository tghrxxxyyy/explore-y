## 本板块说明

- 本板块按**时间线 + 专题纵览**双线组织：朝代篇覆盖从远古传说到 20 世纪的主要朝代与历史事件，专题篇从帝王、战争、科技、经济、书画等维度纵向贯穿。
- 每篇包含**朝代更替脉络 + 重要人物 + 文化成就**三要素，力求脉络清晰。
- 人物写实（姓名、生卒年、主要成就），不演绎戏说，不编造细节。
- 与「公司与产业」（现代商业）、「金融投资」（经济周期）互补：本板块侧重**历史认知与文化素养**。
- 所有内容参考教育部纪年表、维基百科、《史记》《汉书》《资治通鉴》等权威来源。
