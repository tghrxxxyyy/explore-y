# 地形地貌与自然灾害

> 成人通识科普 · 地球与地理子类之四
> 数据来源：USGS、中国气象局、Smithsonian 全球火山计划、UNCCD、IPCC、NASA 等，详见正文括号标注。

## 导语

地球表面并非平坦，而是被内力（板块运动、火山、地震）与外力（流水、风、冰川、海浪）雕刻出千姿百态：**山地、平原、盆地、三角洲、火山**……这些地形既是人类家园，也潜藏着**干旱、洪涝、台风、滑坡**等自然灾害。理解地形如何形成、灾害如何发生，是防灾减灾的第一步。

本文分七章：地形分类总览、山地与平原、盆地与三角洲、火山、干旱与洪涝、台风、滑坡与综合防灾。每章配表格与要点。

## 第一章 地形地貌分类总览

### 1.1 按成因分类

| 大类 | 成因 | 典型形态 |
|---|---|---|
| 构造地貌 | 板块运动、断裂、褶皱 | 山脉、裂谷、盆地 |
| 火山地貌 | 岩浆活动 | 火山、熔岩台地 |
| 流水地貌 | 河流侵蚀/堆积 | 峡谷、平原、三角洲 |
| 风成地貌 | 风力 | 沙丘、雅丹 |
| 冰川地貌 | 冰川侵蚀/堆积 | U 谷、冰碛、角峰 |
| 海岸地貌 | 海浪、潮汐 | 海崖、沙滩、潟湖 |

### 1.2 按海拔高度与起伏

| 类型 | 海拔特征 | 例子 |
|---|---|---|
| 平原 | 海拔低（多 < 200 m）、起伏小 | 亚马孙平原、东欧平原 |
| 丘陵 | 200–500 m、起伏缓和 | 江南丘陵 |
| 山地 | > 500 m、起伏大 | 喜马拉雅、安第斯 |

## 第二章 山地与平原

### 2.1 山地

山地多由**板块碰撞造山**或**火山活动**形成（见《地球结构与板块运动》）。按成因：

| 类型 | 成因 | 代表 |
|---|---|---|
| 褶皱山 | 陆-陆碰撞 | 喜马拉雅、阿尔卑斯 |
| 火山弧山 | 俯冲带岩浆 | 安第斯、日本列岛 |
| 断块山 | 断裂抬升 | 华山、庐山 |
| 侵蚀山 | 流水/冰川切割 | 各类山地 |

**世界最高山脉**（海拔参考）：
- 喜马拉雅：珠峰 8848.86 m（2020 中尼联合公布）。
- 安第斯：最高活火山科托帕克希 5896 m（地质教材）。
- 阿尔卑斯：勃朗峰 4808 m。

### 2.2 平原

平原是河流冲积或地壳沉降形成的低平广阔地形，往往是人口与农业重心。

| 平原 | 面积/特征 | 意义 |
|---|---|---|
| 亚马孙平原 | 世界最大冲积平原 | 热带雨林核心 |
| 东欧平原 | 欧洲最大 | 人口密集 |
| 西西伯利亚平原 | 亚洲北部广大 | 油气、冻土 |
| 长江中下游平原 | 中国重要粮仓 | 鱼米之乡 |
| 北美大平原 | 玉米带、小麦带 | 商品粮基地 |

### 2.3 山地与平原的对照

| 维度 | 山地 | 平原 |
|---|---|---|
| 形成 | 抬升、挤压 | 沉降、堆积 |
| 人类利用 | 林业、牧业、水能、旅游 | 农业、城市、交通 |
| 灾害 | 滑坡、雪崩、山洪 | 洪涝、内涝 |
| 生态 | 垂直带谱丰富 | 生物多样性较单一但生产力高 |

## 第三章 盆地与三角洲

### 3.1 盆地

盆地是四周高、中间低的盆状地形，成因包括构造断陷、侵蚀、火山口等。

| 盆地 | 类型/特征 | 资源或意义 |
|---|---|---|
| 四川盆地 | 构造盆地，紫色土肥沃 | 农业、"天府之国" |
| 塔里木盆地 | 内陆干旱盆地 | 油气、沙漠 |
| 刚果盆地 | 赤道盆地 | 热带雨林 |
| 中西伯利亚高原（台地） | 古老地块 | 矿产、冻土 |
| 柴达木盆地 | 高原盆地 | 盐湖、矿产 |

### 3.2 三角洲

**三角洲**是河流入海口因流速骤减、泥沙堆积形成的低平三角状陆地，土地肥沃、人口密集，但也最易受洪涝与海平面上升威胁。

| 三角洲 | 所在河流 | 特征/风险 |
|---|---|---|
| 长江三角洲 | 长江 | 中国经济核心，地面沉降+海平面上升 |
| 珠江三角洲 | 珠江 | 粤港澳大湾区，台风风暴潮风险 |
| 湄公河三角洲 | 湄公河 | 越南粮仓，海水入侵 |
| 尼罗河三角洲 | 尼罗河 | 埃及人口重心，沙漠中绿洲 |
| 恒河-布拉马普特拉三角洲 | 恒河 | 世界最大， cyclone 与洪涝频发 |

### 3.3 三角洲的"双刃剑"

- 利：泥沙肥沃、水运便利、人口集聚。
- 弊：地势低平、排水不畅、风暴潮与海平面上升首当其冲。

## 第四章 火山

### 4.1 火山类型（Smithsonian 全球火山计划）

| 类型 | 形态 | 喷发特征 | 例子 |
|---|---|---|---|
| 盾火山 | 平缓如盾 | 流动性玄武岩，较温和 | 夏威夷冒纳罗亚（世界最大活火山） |
| 层状火山（成层火山） | 陡峭锥形 | 黏性岩浆，爆炸式 | 富士山、圣海伦斯 |
| 火山渣锥 | 小锥 | 碎屑堆积 | 各地常见 |
| 破火山口 | 塌陷大坑 | 灾难性喷发 | 黄石、托巴 |

### 4.2 活火山分布

全球约 **1650 座潜在活火山**，约 500 座历史时期喷发（Smithsonian）。两大类火山带：

- **环太平洋火山带**：约 693 座全新世火山（约 57%），如富士山、喀拉喀托。
- **阿尔卑斯-喜马拉雅（地中海）带**：约 94 座（约 18%），如埃特纳、维苏威。
- 其他：洋中脊、热点（夏威夷、冰岛）。

### 4.3 火山灾害与益处

| 灾害 | 表现 |
|---|---|
| 熔岩流 | 吞噬地表，但流速慢 |
| 火山灰 | 航空中断、房屋压垮、呼吸危害 |
| 火山碎屑流 | 高温高速，最致命 |
| 火山泥流（lahar） | 暴雨触发，沿河谷下泄 |
| 气候效应 | 全球降温（如 1991 皮纳图博使全球降约 0.7℃ 数年） |

**益处**：肥沃土壤（火山灰）、地热、矿产、景观旅游。

### 4.4 历史警示

- 1815 坦博拉：最强喷发，1816"无夏之年"（EVS Institute）。
- 1883 喀拉喀托：海啸与全球气候效应。
- 1991 皮纳图博：现代最成功撤离之一，挽救大量生命。

## 第五章 干旱与洪涝

### 5.1 干旱

**干旱**是长期降水显著少于常态、水分收支失衡的现象。常与副热带高压、异常环流相关。

| 类型 | 定义 |
|---|---|
| 气象干旱 | 降水持续偏少 |
| 农业干旱 | 土壤墒情不足影响作物 |
| 水文干旱 | 河流湖泊蓄水偏少 |
| 社会经济干旱 | 供需失衡影响人类社会 |

**数据**：UNCCD 指出全球约 **40%** 土地已退化，影响近一半人口；每秒相当于 4 个足球场大小的健康土地退化，每年退化约 **1 亿公顷**（UNCCD、国家林草局）。干旱使全球超 **18 亿人** 面临水资源短缺（UNCCD）。

### 5.2 洪涝

**洪涝**是积水淹没通常干燥土地的现象，分河洪、山洪、城市内涝、风暴潮洪。

| 类型 | 成因 | 应对 |
|---|---|---|
| 河流洪水 | 持续强降雨、融雪 | 堤防、水库、分洪 |
| 山洪 | 山区短时暴雨 | 预警、避让 |
| 城市内涝 | 下垫面硬化、排水不足 | 海绵城市 |
| 风暴潮洪 | 台风+天文大潮 | 海堤、撤离 |

**气候变化关联**：暖空气持水增强，极端降水更频；同时干旱区更旱，呈现"旱涝急转"与"旱涝并存"（IPCC）。

### 5.3 旱涝对照

| 维度 | 干旱 | 洪涝 |
|---|---|---|
| 直接损失 | 减产、缺水、荒漠化 | 淹没、冲毁、伤亡 |
| 缓发性 | 慢、累积 | 快、突发 |
| 主要影响区 | 副热带、内陆 | 季风区、三角洲、城市 |

## 第六章 台风（热带气旋）

### 6.1 什么是台风

台风是发生在**西北太平洋和南海**的强烈热带气旋；在大西洋和东太平洋称"飓风"，印度洋称"气旋风暴"（中国气象局）。本质是暖洋面上形成的低压涡旋，中心附近最大持续风速 ≥ **32.7 m/s（12 级）** 才称台风（中国气象局、湖北省气象局）。

### 6.2 等级划分（中国气象局）

| 等级 | 底层中心附近最大平均风力 |
|---|---|
| 热带低压 | 6–7 级 |
| 热带风暴 | 8–9 级 |
| 强热带风暴 | 10–11 级 |
| 台风 | 12–13 级 |
| 强台风 | 14–15 级 |
| 超强台风 | 16 级及以上 |

> 世界气象组织（WMO）将热带气旋分四级：热带低压、热带风暴、强热带风暴、台风（12 级以上），我国进一步细分（中国气象局）。

### 6.3 生成与活动统计（中国气象局）

- 西北太平洋和南海 1949–2023 年共生成台风 **2005 个**，年均 **27 个**（中国气象局）。
- 生成最多为 1967 年（40 个），最少为 1998、2010 年（各 14 个）。
- 约 **1/4** 的台风登陆或影响我国（中国气象局）。
- 2024 年共生成 26 个，与多年平均（26.7 个）接近；其中超强台风 8 个（气候平均 4.6 个），占比明显偏多（国家气象中心）。
- 秋台风（9–11 月）平均每年 11.38 个、登陆我国 2.26 个；夏台风（6–8 月）生成 11.62 个、登陆 4.36 个（中国气象局）。

### 6.4 台风的成因与结构

- **生成条件**：海表温度 ≥ 26.5℃、充足水汽、弱垂直风切变、一定地转偏向力（中国气象局）。
- **结构**：眼（中心晴朗）、眼墙（最强风雨）、螺旋雨带。
- **直径**：小者 300–400 km，大者 1000–2000 km（中国气象局）。
- **消亡**：登陆后受地面摩擦与能量断供迅速减弱（中国气象局）。

### 6.5 台风灾害与应对

| 次生灾害 | 成因 |
|---|---|
| 狂风 | 直接破坏房屋、设施 |
| 暴雨洪涝 | 特大降水 |
| 风暴潮 | 低压+强风抬升海面 |
| 地质灾害 | 暴雨诱发滑坡、泥石流 |

**应对**：监测预警（风云卫星、雷达、浮标）、路径预报、分级响应（蓝/黄/橙/红预警）、人员转移、海堤与排涝。

## 第七章 滑坡与综合防灾减灾

### 7.1 滑坡与泥石流

滑坡是斜坡岩土体在重力下沿软弱面滑动的现象；泥石流是泥、沙、石与水混合的高密度洪流。

| 诱因 | 说明 |
|---|---|
| 暴雨 | 最常见触发（尤其台风、季风强降雨） |
| 地震 | 破坏斜坡稳定 |
| 人类活动 | 切坡、采矿、弃土 |
| 融雪/冻融 | 高纬高山区 |

### 7.2 灾害链

自然灾害常"链式"发生：

```
地震 → 滑坡/堰塞湖 → 溃决洪水
台风 → 暴雨 → 山洪/滑坡 → 河道淤塞
干旱 → 植被退化 → 沙尘暴/荒漠化
火山 → 火山灰/泥流 → 气候与农业影响
```

### 7.3 综合防灾减灾

| 环节 | 措施 |
|---|---|
| 监测 | 气象卫星、地震台网、GNSS、雨量站 |
| 预警 | 多灾种早期预警系统（108 国已建，WMO） |
| 工程 | 堤防、水库、护坡、海堤、海绵城市 |
| 非工程 | 规划避让、预案、演练、保险 |
| 生态修复 | 植树造林、退耕还林还草、固沙 |

### 7.4 中国实践

- 三北防护林、京津风沙源治理防治荒漠化与风沙（国家林草局）。
- 台风预警与转移安置体系成熟，路径预报准确率持续提升（中国气象局）。
- 地质灾害群测群防与工程治理结合。

## 第九章 河流地貌：V形谷、冲积扇、三角洲

## 第十章 喀斯特地貌

### 10.1 喀斯特地貌的形成

喀斯特地貌是可溶性岩石（石灰岩、白云岩等）受流水溶蚀作用形成的地貌（中国地质调查局）：

| 形成条件 | 说明 |
|---|---|
| 可溶性岩石 | 石灰岩、白云岩等碳酸盐岩 |
| 流水溶蚀 | 水中CO₂与碳酸盐反应 |
| 裂隙发育 | 便于水渗透 |
| 气候湿热 | 促进化学反应 |

### 10.2 喀斯特地貌类型

| 类型 | 地表/地下 | 特征 |
|---|---|---|
| 石芽、石林 | 地表 | 石灰岩被溶蚀成柱状 |
| 溶蚀洼地 | 地表 | 圆形或椭圆形洼地 |
| 落水洞 | 地表 | 地表水流入地下的通道 |
| 溶洞 | 地下 | 地下水溶蚀形成的空洞 |
| 石钟乳、石笋 | 地下 | 碳酸钙沉积形成 |
| 天生桥 | 地表 | 溶洞顶部坍塌残留 |

### 10.3 中国喀斯特地貌

| 区域 | 特征 |
|---|---|
| 桂林山水 | 峰林、峰丛，"桂林山水甲天下" |
| 云南石林 | 高大石柱，世界自然遗产 |
| 贵州荔波 | 喀斯特森林，世界自然遗产 |
| 重庆武隆 | 天生桥、天坑地缝 |

### 10.4 喀斯特地貌的利用与问题

| 方面 | 内容 |
|---|---|
| 旅游价值 | 景观独特，旅游资源丰富 |
| 水资源 | 地下水丰富但易渗漏 |
| 工程问题 | 地基不稳定，隧道施工困难 |
| 生态脆弱 | 土层薄，植被破坏后难恢复 |

> 来源：中国地质调查局、UNESCO

## 小结

1. 地形分**构造、火山、流水、风成、冰川、海岸**等类型；山地、平原、盆地、三角洲各具成因与用途。
2. **三角洲**土地肥沃但低平，最易受洪涝与海平面上升威胁（长江、湄公河、尼罗河等）。
3. 全球约 **1650 座**潜在活火山，约 75% 在环太平洋带（Smithsonian）。
4. **干旱**影响全球 40% 土地、18 亿人缺水；**洪涝**随气候变暖更极端（UNCCD、IPCC）。
5. 西北太平洋年均生成 **27 个**台风，超强台风（≥16 级）占比近年偏高；防灾靠"监测—预警—工程—生态"综合体系（中国气象局、WMO）。
6. 喀斯特地貌以可溶性岩石溶蚀为特征，中国桂林、云南石林、贵州荔波为代表。
7. 冰川地貌包括U形谷、角峰、刃脊等侵蚀地貌和冰碛丘陵等堆积地貌。
8. 自然灾害常呈链式发生，综合防御需监测、预警、工程、生态多措并举。
