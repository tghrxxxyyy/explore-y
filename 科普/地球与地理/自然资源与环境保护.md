# 自然资源与环境保护

> 成人通识科普 · 地球与地理子类之五
> 数据来源：FAO、IUCN、UNEP-WCMC、UNCCD、IPCC、USGS、EIA、NASA 等，详见正文括号标注。

## 导语

地球为人类提供了赖以生存与发展的**自然资源**：地下的矿产、地上的森林、耕作的土地、滋养生命的生物多样性。但人口膨胀与过度索取，正使土地退化、森林锐减、物种消失。如何在利用与保护之间取得平衡，是"可持续发展"的核心命题。

本文分七章：自然资源总览、矿产资源、森林资源、土地资源与荒漠化、生物多样性、自然保护地、可持续发展路径。每章配表格与要点。

## 第一章 自然资源总览

### 1.1 分类

| 类别 | 举例 | 可再生性 |
|---|---|---|
| 矿产资源 | 煤、石油、铁、铜、稀土 | 不可再生 |
| 森林资源 | 木材、林产品、碳汇 | 可更新（若合理经营） |
| 土地资源 | 耕地、草地、建设用地 | 有限、可退化 |
| 水资源 | 河、湖、地下、冰川 | 可更新（总量守恒） |
| 生物资源 | 物种、基因、生态系统 | 可更新但易丧失 |
| 气候资源 | 太阳能、风能 | 可再生 |

### 1.2 人类生态足迹

据中科院院刊转载研究：1900 年全球人口 16.5 亿，2024 年达 **80.5 亿**（增约 388%）；人均地表占有由 9 公顷降至 1.82 公顷；2024 年人类生态足迹约 **2.7 个地球**，即消耗速度为地球再生能力的约 1.7 倍（UNEP-WCMC/IUCN 数据推算）。这提示资源压力空前。

## 第二章 矿产资源

### 2.1 矿产资源的不可再生性

矿产是地质年代形成的富集物，开采速度远快于生成，属**不可再生资源**。关键矿产（锂、钴、镍、稀土）更是能源转型（电池、电机）的战略基础。

### 2.2 全球煤炭储量（EIA、BP 口径）

全球探明可采煤炭储量约 **1.16 万亿短吨**（2021，EIA）；另有文献称约 1.074 万亿吨（2020，中国煤炭杂志）。前五大国家占约 75%：

| 国家 | 占全球探明储量比（约） | 储采比（年） |
|---|---|---|
| 美国 | 22% | 约 514 |
| 俄罗斯 | 15% | 约 407 |
| 澳大利亚 | 14% | 约 315 |
| 中国 | 14% | 约 37（远低于世界均值） |
| 印度 | 11% | 约 147 |

> 中国煤炭储采比仅约 37 年，远低于全球平均约 139 年，提示结构性资源约束（中国煤炭杂志）。

### 2.3 石油与天然气（能研智库 2025）

| 资源 | 储量第一国 | 备注 |
|---|---|---|
| 石油 | 委内瑞拉（约 3038 亿吨） | 受开采条件限制，产量低 |
| 天然气 | 俄罗斯（约 37.4 万亿 m³） | 市场与地缘影响大 |

> 储量排名≠供应能力，**储采比**才是战略价值的真实标尺（能研智库）。

### 2.4 关键矿产与能源转型

| 矿产 | 主要用途 | 关切 |
|---|---|---|
| 锂 | 电池 | 需求激增、集中于少数国 |
| 钴 | 电池、合金 | 集中于刚果（金） |
| 稀土 | 永磁、电子 | 供需与地缘 |
| 铜 | 电网、EV | 长期短缺风险 |

### 2.5 矿产开发的环境代价

开采伴随**地表破坏、尾矿、酸性废水、粉尘、生态破碎**。可持续采矿强调：复垦、尾矿库安全、社区利益、循环经济（回收再利用）。

## 第三章 森林资源

### 3.1 全球森林概况（FAO 2020）

| 指标 | 数值 |
|---|---|
| 全球森林面积 | 约 40.6 亿公顷 |
| 占陆地面积 | 约 31%（2020） |
| 森林面积变化 | 2000 年 32.5% → 2020 年 30.8%（FAO FRA 2020） |
| 年毁林速率（2015–2020） | 约 1000 万公顷/年 |
| 1990–2020 累计转用 | 约 4.2 亿公顷 |

> 森林覆盖率从 2000 年 31.9% 缓降至 2020 年 31.2%，虽减速但仍在净减少（联合国 SDG 报告）。

### 3.2 森林类型与分布

| 森林域 | 占比 | 分布 |
|---|---|---|
| 热带林 | 约 45% | 南美、非洲、东南亚 |
| 寒温带（北方针叶）林 | 约 27% | 俄、加、北欧 |
| 温带林 | 约 16% | 欧、中、美 |
| 亚热带/山地林 | 约 12% | 印度、墨西哥等 |

全球超一半森林集中于**巴西、加拿大、中国、俄罗斯、美国**五国（FAO）。

### 3.3 森林的生态价值

- 森林庇护了**80% 两栖类、75% 鸟类、68% 哺乳类**物种（FAO SOFO 2020）。
- 约 60% 维管植物见于热带森林（FAO）。
- 森林是最大"陆地碳库"，含约 80% 陆地植物生物量（FAO 相关汇总）。
- 直接支撑约 **16 亿人** 生计，7000 万原住民高度依赖森林（FAO、WWF 汇总）。

### 3.4 森林面临的威胁

| 威胁 | 表现 |
|---|---|
| 毁林开荒 | 热带农业扩张为主因 |
| 野火 | 2023 年火灾排放 CO₂ 约 66.87 亿吨（FAO SOFO 2024 转引） |
| 虫害与病害 | 气候变化加剧 |
| 破碎化 | 栖息地连通性下降 |

## 第四章 土地资源与荒漠化

### 4.1 土地资源的有限性

土地是粮食、生态与人居之本。但**土地退化**正使其生产力流失。

### 4.2 荒漠化与土地退化（UNCCD、国家林草局）

| 指标 | 数值 |
|---|---|
| 全球退化土地占比 | 约 40%，影响近一半人口 |
| 退化速率 | 每秒约 4 个足球场大小的健康土地 |
| 年退化面积 | 约 1 亿公顷/年 |
| 干旱影响人口 | 全球超 18 亿人缺水 |
| 年经济损失 | 近 9000 亿美元（土地退化、荒漠化、干旱合计） |

> 《联合国防治荒漠化公约》（UNCCD）将荒漠化称为"地球癌症"。全球约 70% 的 52 亿公顷旱地农业用地已退化或受威胁（UNCCD FAQ）。

### 4.3 荒漠化成因

| 成因 | 说明 |
|---|---|
| 自然 | 气候干旱、风蚀 |
| 过度放牧 | 植被破坏 |
| 不合理开垦 | 表土暴露 |
| 水资源过度开采 | 地下水位下降 |
| 气候变化 | 干旱频率与强度上升（2000 年来增近 30%） |

### 4.4 中国治沙实践（国家林草局）

- 在全球率先实现土地退化"零增长"，53% 可治理沙化土地有效治理（国家林草局）。
- 三北工程、京津风沙源治理、光伏治沙、"麦草方格"等模式。
- 塔克拉玛干沙漠边缘锁边"合龙"、毛乌素沙地生态逆转（国家林草局）。
- 森林覆盖率超 25%，人工林面积世界首位，贡献全球约 25% 新增绿化面积（国家林草局）。

## 第五章 生物多样性

### 5.1 什么是生物多样性

**生物多样性**包含基因、物种、生态系统三个层次，是地球生命支持系统的根基。

### 5.2 受威胁现状（IUCN 红色名录）

| 指标 | 数值 |
|---|---|
| 已评估物种 | 超 17.59 万种（IUCN） |
| 受威胁物种 | 超 4.95 万种，占已评估约 28% |
| 受威胁类群 | 两栖类、哺乳动物、珊瑚、鲨鳐等比例高 |

> IUCN 红色名录将物种分为 9 级：无危、近危、易危、濒危、极危、野外灭绝、灭绝等（IUCN）。

### 5.3 生物多样性丧失驱动因素

| 驱动 | 说明 |
|---|---|
| 栖息地丧失 | 毁林、开垦、城市化首要原因 |
| 气候变化 | 分布区退缩、物候错位 |
| 过度利用 | 过度捕捞、盗猎 |
| 污染 | 化肥、塑料、农药 |
| 外来入侵种 | 挤占本土种 |
| 疾病 | 两栖类等受威胁 |

### 5.4 关键生态系统

| 生态系统 | 价值/风险 |
|---|---|
| 珊瑚礁 | 支撑 1/4 海洋物种，白化严重 |
| 热带雨林 | 物种最丰富，弹性下降 |
| 湿地 | 调蓄洪水、净化水质，消失最快之一 |
| 极地/高山 | 对升温极敏感 |

### 5.5 物种灭绝速率

背景灭绝速率（自然）极低；现今速率被估计为自然背景的**数十至数百倍**，被称为"第六次大灭绝"（科学 consensus，IUCN/IPCC 相关）。IPCC 指出升温 2–3℃ 时，珊瑚礁、北极、山地等生态系统将达"难以适应的硬极限"（IPCC 2023）。

## 第六章 自然保护地

### 6.1 什么是保护地

**自然保护地**是依法划定的、长期保护自然生态系统与生物多样性的陆域或海域，包括国家公园、自然保护区、自然公园等（UNEP-WCMC 数据说明）。

### 6.2 全球保护地规模（UNEP-WCMC / IUCN，2023）

| 类型 | 数量 | 覆盖 |
|---|---|---|
| 陆地保护地 | 约 27 万个 | 陆地面积约 17% |
| 海洋保护地 | 约 1.8 万个 | 海洋面积约 8% |
| 含 OECM 的总保护 | — | 陆地约 17.1%、海洋约 8.3% |

> 中国保护地：截至 2020 年底约 1.18 万个，占陆域面积 18% 以上；2021 年设首批 5 个国家公园（三江源、东北虎豹、大熊猫、海南热带雨林、武夷山），总面积约 23.3 万 km²（中科院院刊、应用生态学报）。

### 6.3 保护地的成效与局限

- 正面：部分关键生态系统得到有效保护，局部成功显著。
- 局限：全球生物多样性下降趋势**未被扭转**；研究指出 2003–2019 年 73% 保护地内栖息地仍退化，保护地有效性仅比非保护地高约 33%（中科院院刊转引研究）。
- 启示：仅靠扩面积不够，需提升**连通性、管理有效性、周边压力治理**。

### 6.4 昆明-蒙特利尔全球生物多样性框架（GBF）

2022 年通过的"昆蒙框架"设定目标，包括：

| 目标 | 内容 |
|---|---|
| 30×30 | 2030 年保护 30% 陆地与 30% 海洋 |
| 修复 | 恢复退化生态系统 |
| 资金 | 增加保护资金、减少有害补贴 |
| 可持续利用 | 农业、渔业、林业可持续化 |

## 第七章 可持续发展路径

### 7.1 什么是可持续发展

**可持续发展**指满足当代需求而不损害后代满足其需求的能力，涵盖经济、社会、环境三大支柱。

### 7.2 主要路径

| 路径 | 举措 |
|---|---|
| 能源转型 | 风光水核替代化石，减排 CO₂ |
| 循环经济 | 减量化、再利用、回收 |
| 保护性农业 | 保水保土、减少化肥 |
| 生态恢复 | 植树、退耕还林还草、湿地修复 |
| 海洋可持续 | 限额捕捞、减塑、海洋保护地 |
| 城市绿色化 | 海绵城市、绿色建筑、公交 |

### 7.3 全球协同机制

| 公约/协定 | 主题 |
|---|---|
| UNFCCC / 《巴黎协定》 | 气候 |
| CBD / 昆蒙框架 | 生物多样性 |
| UNCCD | 荒漠化 |
| SDGs（2030 议程） | 综合可持续发展 |

### 7.4 个人可为之事

- 节能降碳：公共交通、节电、减少一次性用品。
- 支持可持续产品：认证木材、可持续海鲜。
- 保护本地生态：植树、护水、参与公民科学。
- 传播意识：科普与政策关注。

## 第九章 水资源分布与危机

### 9.1 全球水资源分布

| 区域 | 水资源特征 |
|---|---|
| 亚洲 | 总量丰富，人均较低 |
| 南美洲 | 总量最丰富 |
| 欧洲 | 总量中等，分布不均 |
| 非洲 | 干旱区广，缺水严重 |
| 北美洲 | 总量充足，局部短缺 |

### 9.2 水资源危机现状

| 指标 | 数据 |
|---|---|
| 全球缺水人口 | 约22亿人（UNESCO） |
| 水资源压力国家 | 约40%人口生活在缺水地区 |
| 地下水超采 | 全球主要含水层普遍下降 |
| 水污染 | 发展中国家80%污水未经处理排放 |

### 9.3 水资源利用结构

| 用水部门 | 占比（约） | 主要问题 |
|---|---|---|
| 农业灌溉 | 70% | 效率低，浪费严重 |
| 工业用水 | 20% | 污染问题 |
| 生活用水 | 10% | 分配不均 |

### 9.4 水资源保护措施

| 措施 | 说明 |
|---|---|
| 节水灌溉 | 滴灌、喷灌提高效率 |
| 污水处理 | 再生水利用 |
| 海水淡化 | 中东、以色列经验 |
| 流域管理 | 统一调配上下游用水 |
| 水价改革 | 促进节约用水 |

> 来源：UNESCO、世界水理事会

## 第十章 土地资源退化

### 10.1 土地退化的类型

| 类型 | 成因 | 表现 |
|---|---|---|
| 水土流失 | 植被破坏、暴雨冲刷 | 表土流失、肥力下降 |

## 第十一章 环境保护措施：碳中和、生态修复与循环经济

### 11.1 碳中和路径

| 路径 | 措施 |
|---|---|
| 能源转型 | 发展风电、光伏、核电 |
| 提高能效 | 建筑、交通、工业节能 |
| 碳捕获 | CCS/CCUS技术 |
| 增加碳汇 | 植树造林、保护湿地 |
| 碳交易 | 建立碳排放权市场 |

### 11.2 生态修复工程

| 类型 | 项目 | 效果 |
|---|---|---|

## 小结

1. 自然资源分**矿产（不可再生）、森林、土地、水、生物、气候**等类；人类生态足迹约 2.7 个地球（UNEP-WCMC/IUCN 推算）。
2. **矿产**不可再生：全球煤储量前五国占约 75%，中国储采比仅约 37 年（EIA、中国煤炭杂志）。
3. **森林**覆盖约 31% 陆地，年毁林约 1000 万公顷，庇护 80% 两栖类与 68% 哺乳类（FAO）。
4. **荒漠化**致全球 40% 土地退化、年损 1 亿公顷；中国治沙走在前列（UNCCD、国家林草局）。
5. 超 4.95 万种物种受威胁（IUCN）；全球保护地覆盖陆地约 17%、海洋约 8%，目标 30×30（IUCN、昆蒙框架）。可持续发展需能源转型、循环经济与全球协同。
6. 金属矿产以铁、铜、铝为主，稀有金属（锂、钴、稀土）是能源转型的战略基础。
7. 全球约22亿人面临水资源短缺，农业灌溉占用水70%，节水灌溉是关键。
8. 碳中和需能源转型、碳捕获、碳汇增加多措并举，循环经济是资源可持续利用的模式。

> 本子类五篇（地球结构与板块运动、大气与气候系统、海洋与水文循环、地形地貌与自然灾害、自然资源与环境保护）构成地球与地理的通识脉络，相互印证、层层递进。

### 十三、碳中和技术路径

**碳捕集与封存（CCS）**：
- 燃烧后捕集：从烟气中分离CO₂
- 燃烧前捕集：气化后分离CO₂
- 直接空气捕集：从大气中直接捕获CO₂
- 地质封存：注入地下岩层

**碳利用技术**：
- CO₂矿化：与矿物反应生成碳酸盐
- CO₂加氢：合成甲醇、甲烷
- CO₂聚合：生产聚碳酸酯
- 微生物转化：藻类固碳

**负排放技术**：
- 生物质能碳捕集（BECCS）
- 直接空气碳捕集（DAC）
- 增强风化
- 海洋碱度增加
