## 阅读建议

1. **零基础**：按 地球结构 → 大气 → 海洋 → 地形 → 资源环境 顺序：先懂家园的组成，再懂其上的过程，最后落到人类与地球的关系。
2. **按需查阅**：看地震新闻读 1、4；读气候报道读 2；关心水资源读 3；理解环保政策读 5。
3. **交叉关联**：板块运动（1）造出地形（4）；海洋环流（3）影响气候（2）；资源开发（5）牵动三者。
