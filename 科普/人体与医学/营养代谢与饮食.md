# 营养代谢与饮食

> ⚠️ **免责声明**：本文为科普内容，由非医学专业人士整理编写，旨在帮助普通成人建立科学饮食与代谢常识。**本文不能替代专业医疗诊断、营养评估或医嘱**。如您有糖尿病、肾病、代谢疾病、进食障碍或特殊生理状态（孕、乳、病），请遵医嘱或咨询注册营养师。文中膳食推荐引用《中国居民膳食指南（2022）》（中国营养学会编著、国家卫健委指导）及国家卫健委慢性病监测数据。

---

## 一、导语：你吃进去的，正在塑造你

"人如其食"（You are what you eat）并非夸张。食物经消化、吸收、代谢，变成能量、结构和信号分子，影响体重、血糖、免疫乃至情绪。但信息爆炸时代，"生酮""轻断食""排毒""酵素"让人眼花缭乱。

本文用权威指南（中国居民膳食指南 2022）为锚，讲清：三大营养素、维生素矿物质、膳食宝塔、身体如何代谢、肥胖与科学减脂，以及常见误区。

## 二、能量与营养素总览

人体需要三大类**宏量营养素**和多种**微量营养素**：

| 类别 | 成员 | 主要功能 |
|------|------|----------|
| 碳水化合物 | 米面糖、蔬果纤维 | 主要能量来源 |
| 蛋白质 | 肉蛋奶豆 | 构建组织、酶、抗体 |
| 脂肪 | 油、坚果、肥肉 | 储能、膜结构、激素原料 |
| 维生素 | 维A/B/C/D/E/K 等 | 调节代谢 |
| 矿物质 | 钙铁锌碘钠等 | 结构/信号/电解质 |
| 水 | —— | 一切反应的介质 |
| 膳食纤维 | 蔬果全谷豆类 | 促蠕动、养菌、稳血糖 |

**能量换算（通用）**：碳水与蛋白质约 **4 kcal/g**，脂肪约 **9 kcal/g**，酒精约 **7 kcal/g**（空热量，无营养）。

## 三、三大宏量营养素详解

### 3.1 碳水化合物：首选"优质来源"
- **推荐**：全谷物、薯类、豆类、蔬果中的天然碳水+纤维；
- **限制**：添加糖（奶茶、甜点、含糖饮料）。
- 指南建议每天谷类食物 **200–300 g**，其中全谷物和杂豆 **50–150 g**、薯类 **50–100 g**（来源：中国居民膳食指南 2022）。
- 精制糖摄入过多与肥胖、龋齿、脂肪肝相关。

### 3.2 蛋白质：身体的"砖块"
- 成人每日推荐：鱼禽蛋瘦肉平均 **120–200 g**（来源：膳食指南 2022）；
- 优质蛋白来源：鱼虾、禽肉、蛋、奶、大豆制品；
- 鸡蛋营养丰富，**不弃蛋黄**（胆固醇顾虑对多数健康人已被修正，但相关慢病者遵医嘱）；
- 植物蛋白（豆）与动物蛋白搭配更均衡。

### 3.3 脂肪：不是敌人，但挑种类
- 烹调油推荐 **25–30 g/天**（来源：膳食指南 2022）；
- 优先不饱和脂肪（橄榄油、鱼油、坚果），限制饱和脂肪（肥肉、黄油），**反式脂肪酸 ≤2 g/天**（来源：膳食指南 2022）；
- 警惕加工食品中的"部分氢化油"（反式脂肪主要来源）。

## 四、维生素：微量但关键

| 维生素 | 主要作用 | 常见来源 | 缺乏表现 |
|--------|----------|----------|----------|
| 维A | 视力、免疫、皮肤 | 肝、胡萝卜、深绿菜 | 夜盲、干眼 |
| 维B1 | 能量代谢、神经 | 杂粮、瘦肉 | 脚气病（神经/心） |
| 维B12 | 神经、红细胞 | 肉蛋奶 | 贫血、神经损害（素食者风险） |
| 叶酸 | 细胞分裂、防畸 | 绿叶菜、豆类 | 贫血；孕早期缺乏致神经管畸形 |
| 维C | 抗氧化、胶原、免疫 | 柑橘、蔬菜 | 坏血病、牙龈出血 |
| 维D | 钙吸收、骨、免疫 | 日照、鱼、强化奶 | 佝偻病、骨软、肌少 |
| 维E | 抗氧化 | 坚果、植物油 | 罕见 |
| 维K | 凝血、骨 | 绿叶菜 | 出血倾向 |

> 脂溶性（A/D/E/K）可在体内储存，过量易中毒；水溶性（B/C）多随尿排出，但B12可储量较大。补剂需慎重。

| 矿物质 | 作用 | 来源 | 注意 |
|--------|------|------|------|
| 钙 | 骨牙、神经肌肉 | 奶、豆制品、深绿菜 | 国人普遍摄入不足 |
| 铁 | 血红素、携氧 | 红肉、动物血、菠菜 | 缺铁致贫血（女性常见） |

## 六、《中国居民膳食指南（2022）》八准则

国家卫健委指导、中国营养学会编著的指南提出 **8 条平衡膳食准则**（来源：中国居民膳食指南 2022）：

| 准则 | 核心推荐要点 |
|------|--------------|
| 一、食物多样，合理搭配 | 每天 ≥12 种、每周 ≥25 种食物；谷类为主 |
| 二、吃动平衡，健康体重 | 每周 ≥5 天中等强度活动、累计 ≥150 分钟；每天 6000 步 |
| 三、多吃蔬果、奶类、全谷、大豆 | 蔬菜 ≥300 g（深色占 1/2）、水果 200–350 g、奶 ≥300 ml |
| 四、适量吃鱼禽蛋瘦肉 | 平均 120–200 g/天；优先鱼，少吃加工肉 |
| 五、少盐少油，控糖限酒 | 盐 ≤5 g、油 25–30 g、添加糖 ≤50 g（最好 ≤25 g）、反式脂肪 ≤2 g |
| 六、规律进餐，足量饮水 | 三餐定时、每天饮水量男 1700 ml / 女 1500 ml（温和气候低活动） |
| 七、会烹会选，会看标签 | 读营养标签、选新鲜高营养密度食物 |
| 八、公筷分餐，杜绝浪费 | 生熟分开、公筷、珍惜食物 |

**关键数字一览（成人每日）**：
- 食盐 **≤5 g**（我国2023年调查家庭人均烹调用盐仍达 **9.3 g**，差距大，来源：国家卫健委《中国居民营养与慢性病状况报告》）；
- 烹调油 **25–30 g**（调查达 **43.2 g**，超半数超上限）；
- 添加糖 **≤50 g**，最好 **≤25 g**；
- 饮水 **1500–1700 ml**（少量多次，白水/茶水优先）。

## 七、平衡膳食宝塔（2022）速记

| 层 | 食物 | 推荐量 |
|----|------|--------|
| 谷薯类底层 | 谷类 200–300 g（全谷杂豆 50–150 g）、薯类 50–100 g | 主食基础 |
| 蔬果 | 蔬菜 300–500 g、水果 200–350 g | 餐餐有菜 |
| 动物性 | 120–200 g/天 | 鱼禽蛋瘦肉 |
| 奶豆 | 奶 300–500 g、大豆坚果 25–35 g | 补钙优质蛋白 |
| 油盐顶层 | 油 25–30 g、盐 ≤5 g | 越少越好（在限内） |

> 宝塔原则：**底层多吃、顶层少吃**；每餐蔬菜占盘一半是简便方法。

## 八、身体如何"代谢"

### 8.1 能量平衡
- **摄入 > 消耗 → 增重**；**摄入 < 消耗 → 减重**；长期平衡 → 体重稳定。
- 消耗 = 基础代谢（占 60–70%）+ 活动 + 食物热效应。

### 8.2 血糖与胰岛素
- 碳水消化为葡萄糖入血（血糖）；
- 胰腺分泌**胰岛素**帮细胞摄取葡萄糖；
- 2 型糖尿病：细胞对胰岛素"抵抗"，血糖居高不下（来源：糖尿病防治指南共识）。

### 8.3 脂肪代谢
- 多余能量以甘油三酯形式存于脂肪组织；
- 长期过剩→肥胖、脂肪肝、胰岛素抵抗。

## 九、肥胖：如何判断与为何危险

### 9.1 BMI 与腰围
| 指标 | 中国标准（成人） | 说明 |
|------|------------------|------|
| BMI | 18.5–23.9 正常；24–27.9 超重；≥28 肥胖 | 中国成人超重肥胖标准 |
| 腰围 | 男 ≥90 cm、女 ≥85 cm 为中心性肥胖 | 腹型肥胖更伤代谢 |

> BMI = 体重(kg) / 身高(m)²。肌肉量大者 BMI 可能偏高但非真胖，需结合体脂。

### 9.2 现状严峻
国家卫健委 2023 年报告显示，我国 18 岁及以上居民**超重率 34.3%、肥胖率 16.4%**（来源：国家卫健委《中国居民营养与慢性病状况报告》）。这与高油盐、少动、含糖饮料（18.9% 中小学生经常饮用，来源同上）密切相关。

### 9.3 肥胖的健康风险
- 2 型糖尿病、高血压、血脂异常（"三高"）；
- 脂肪肝、心脑血管病、某些癌症；
- 睡眠呼吸暂停、关节负担、心理影响。

## 十、科学减脂：不靠"魔法"靠"平衡"

| 原则 | 做法 |
|------|------|
| 适度热量缺口 | 每日亏 300–500 kcal，慢减（0.5–1 kg/周）更可持续 |
| 高蛋白 | 保肌肉、增饱腹（鱼禽蛋豆） |
| 控精制糖油 | 戒含糖饮料、少油炸糕点 |
| 多纤维 | 蔬菜全谷，稳血糖、延饱 |
| 力量+有氧 | 抗阻保肌、有氧燃脂 |
| 睡够 | 缺觉升饥饿素、降抑制力 |
| 可持续 | 不极端、不报复性进食 |

⚠️ 不推荐：极端节食（掉肌肉、反弹）、不明减肥药（伤心肝肾）、"排毒"产品（多泻剂）。

## 十一、常见饮食误区

| 误区 | 真相 |
|------|------|
| 不吃主食能瘦 | 短期掉水/肌肉，易反弹，脑能量不足 |
| 水果代餐减肥 | 果糖不少，缺蛋白脂肪，营养不良 |
| 喝减肥茶排毒 | 多含泻药，丢水非减脂，伤肠道 |
| 蛋黄升胆固醇不能吃 | 健康人适量吃蛋无妨，弃黄浪费营养 |
| 蛋白粉人人要喝 | 饮食够蛋白者无需，过量伤肾风险 |
| 酵素减肥 | 多为酶/益生菌，无直接燃脂证据 |

## 十五、小结

- 营养 = 宏量（碳水/蛋白/脂肪）+ 微量（维/矿）+ 水 + 纤维，**均衡多样**是核心。
- 跟随《中国居民膳食指南（2022）》八准则：少盐（≤5g）少油（25–30g）、多蔬果奶谷、吃动平衡。
- 代谢本质是能量与物质的平衡；**肥胖是多因素慢病之源**，科学减脂靠可持续缺口而非魔法。
- 警惕"排毒/酵素/极端节食"营销，回归生活方式基本面。

> 再次提醒：本文为科普，不能替代医生或营养师。有特殊健康状况请专业指导。

## 十六、宏量营养素深入解析

### 16.1 碳水化合物的分类与代谢

| 类型 | 例子 | 消化速度 | 对血糖影响 |
|------|------|----------|------------|
| 单糖 | 葡萄糖、果糖 | 最快 | 快速升高 |
| 双糖 | 蔗糖、乳糖 | 较快 | 较快升高 |
| 寡糖 | 低聚果糖 | 部分消化 | 中等 |
| 多糖（淀粉） | 米饭、土豆 | 较慢 | 平缓升高 |
| 抗性淀粉 | 冷却米饭、生香蕉 | 不消化 | 几乎不影响 |

- **血糖生成指数（GI）**：衡量食物升高血糖速度的指标。GI <55 为低GI，适合糖尿病患者。
- **膳食纤维**：不被消化的碳水化合物，分可溶性（燕麦β-葡聚糖）和不溶性（麦麸纤维素）。
- **全谷物**保留麸皮和胚芽，比精制谷物多含 B 族维生素、矿物质和纤维。

### 16.2 蛋白质的氨基酸谱

蛋白质由 20 种氨基酸组成，其中 **9 种为必需氨基酸**（人体不能合成，必须从食物获取）：

| 必需氨基酸 | 优质来源 |
|------------|----------|
| 亮氨酸 | 乳清蛋白、大豆 |
| 异亮氨酸 | 肉类、蛋 |
| 缬氨酸 | 花生、奶酪 |
| 赖氨酸 | 鱼、肉、豆 |
| 蛋氨酸 | 鱼、蛋、芝麻 |
| 苯丙氨酸 | 肉、奶、坚果 |
| 苏氨酸 | 奶酪、小麦胚芽 |
| 色氨酸 | 火鸡、牛奶 |
| 组氨酸 | 肉类、大豆 |

- **蛋白质互补**：谷类缺赖氨酸、豆类缺蛋氨酸，两者搭配可提高整体营养价值。
- **蛋白质消化率校正氨基酸评分（PDCAAS）**：乳清蛋白 1.0（满分），大豆蛋白 0.91，牛肉 0.92。

### 16.3 脂肪酸的详细分类

| 类型 | 结构特点 | 来源 | 健康影响 |
|------|----------|------|----------|
| 饱和脂肪酸 | 无双键 | 动物脂肪、椰子油 | 升 LDL，适量即可 |
| 单不饱和脂肪酸 | 1 个双键 | 橄榄油、牛油果 | 降 LDL，升 HDL |
| 多不饱和脂肪酸（ω-3） | 多个双键（末端第 3 位） | 深海鱼、亚麻籽 | 抗炎、护心 |
| 多不饱和脂肪酸（ω-6） | 多个双键（末端第 6 位） | 植物油 | 适量有益，过多促炎 |
| 反式脂肪酸 | 人工氢化产生 | 部分氢化油 | 升 LDL、降 HDL，最应避免 |

- **ω-6/ω-3 比例**：现代饮食常达 15–20:1，理想应接近 4:1（来源：中国居民膳食指南 2022）。
- **DHA/EPA**：ω-3 长链脂肪酸，对大脑和心血管有保护作用，主要来源为深海鱼。

> 来源：中国居民膳食指南（2022）；美国心脏协会（AHA）膳食建议。

## 十七、微量营养素深入解析

### 17.1 脂溶性维生素

| 维生素 | 功能 | 缺乏表现 | 过量风险 | 推荐摄入量（成人） |
|--------|------|----------|----------|---------------------|
| 维A | 视觉、免疫、上皮完整 | 夜盲、干眼、免疫低下 | 头痛、肝损伤、致畸 | 男 800μgRAE/天 |
| 维D | 钙吸收、骨矿化、免疫 | 佝偻病、骨软化、肌无力 | 高钙血症、肾结石 | 10μg（400IU）/天 |
| 维E | 抗氧化、保护细胞膜 | 罕见（神经病变） | 出血风险增加 | 14mgα-TE/天 |
| 维K | 凝血、骨代谢 | 凝血障碍 | 罕见（干扰抗凝药） | 80μg/天 |

### 17.2 水溶性维生素

| 维生素 | 功能 | 缺乏表现 | 特点 |
|--------|------|----------|------|
| 维B1 | 能量代谢、神经 | 脚气病 | 全谷、瘦肉 |
| 维B2 | 能量代谢、皮肤 | 口角炎、舌炎 | 奶、蛋 |
| 维B3 | 能量代谢、DNA 修复 | 糙皮病 | 肉、全谷 |
| 维B6 | 蛋白质代谢、神经递质 | 贫血、皮炎 | 肉、香蕉 |
| 维B12 | 神经、红细胞 | 贫血、神经损害 | 仅动物性来源，素食者必补 |
| 叶酸 | DNA 合成、防畸 | 巨幼贫；孕缺致神经管畸形 | 绿叶菜，孕前补 |
| 维C | 抗氧化、胶原合成、促铁吸收 | 坏血病 | 柑橘、猕猴桃 |

## 十八、人体代谢过程详解

### 18.1 糖酵解（Glycolysis）

- **场所**：细胞质
- **过程**：1 分子葡萄糖（6C）分解为 2 分子丙酮酸（3C）
- **净产出**：2 ATP + 2 NADH
- **特点**：不需要氧气（无氧代谢），是所有细胞获取能量的基础途径

### 18.2 三羧酸循环（TCA 循环/柠檬酸循环）

- **场所**：线粒体基质
- **过程**：丙酮酸→乙酰辅酶 A→进入循环→产生 CO₂
- **每圈产出**：3 NADH + 1 FADH₂ + 1 GTP（等效 ATP）
- **意义**：碳水、脂肪、蛋白质代谢的共同通路，是能量代谢的"枢纽"

### 18.3 氧化磷酸化（电子传递链）

- **场所**：线粒体内膜
- **过程**：NADH 和 FADH₂ 的电子经复合体 I→II→III→IV 传递，泵出 H⁺建立梯度，驱动 ATP 合酶合成 ATP
- **产出**：每分子葡萄糖约产生 30–32 ATP
- **效率**：约 34%（其余为热量，维持体温）

### 18.4 脂肪代谢

- 脂肪→甘油 + 脂肪酸
- 脂肪酸经 **β-氧化** 生成乙酰辅酶 A，进入三羧酸循环
- 1g 脂肪可产生约 9 kcal 能量（蛋白质和碳水约 4 kcal/g）
- 过量糖和蛋白质可转化为脂肪储存

### 18.5 蛋白质代谢

- 蛋白质→氨基酸
- 氨基酸脱氨基后碳骨架进入三羧酸循环
- 含氮部分→尿素→肾脏排出
- **不可储存**：多余氨基酸不能像糖和脂肪那样大量储存，多余部分转化为脂肪或氧化供能

> 来源：《生物化学》教材（王镜岩版）；Lehninger《生物化学原理》。

## 十九、特殊人群营养详解

### 19.1 孕妇与哺乳期

| 营养素 | 推荐 | 说明 |
|--------|------|------|
| 叶酸 | 600μg/天 | 孕前 3 月开始补，防神经管畸形 |
| 铁 | 20–29mg/天 | 支持胎儿和血容量增长 |
| 钙 | 1000–1200mg/天 | 胎儿骨骼发育 |
| DHA | 200mg/天 | 胎儿大脑和视网膜发育 |
| 碘 | 230μg/天 | 甲状腺功能、胎儿神经发育 |
| 蛋白质 | 在孕前基础上 +25g/天 | 支持胎儿组织生长 |

### 19.2 儿童与青少年

- **生长突增期**（女孩 10–12 岁，男孩 12–14 岁）：能量和蛋白质需求显著增加。
- **钙**：青春期是骨量积累关键期，推荐 1000–1200mg/天。
- **铁**：青春期女孩月经来潮后铁需求增加。
- **限制**：含糖饮料、油炸食品、高盐零食。

### 19.3 老年人

| 要点 | 说明 |
|------|------|
| 蛋白质 | 1.0–1.2g/kg/天（高于成人 0.8g），防肌少症 |
| 维D | 15μg/天（600IU），比年轻人多 50% |
| 维B12 | 吸收随年龄下降，必要时口服补充 |
| 水 | 口渴感减退，主动饮水 1500ml/天 |
| 食物加工 | 质地软烂、小份多餐 |

### 19.4 素食者

| 风险营养素 | 补充建议 |
|------------|----------|
| 维B12 | 必须从强化食品或补剂获取 |
| 铁 | 多吃豆类、全谷，配合维C促吸收 |
| 锌 | 坚果、种子、全谷 |
| 钙 | 豆腐（卤水点）、强化植物奶 |
| ω-3（DHA） | 藻油补剂 |
| 蛋白质 | 谷豆搭配互补 |

### 19.5 运动员与高强度体力活动者

- 能量需求增加 30–70%（取决于运动强度和时长）。
- 蛋白质：1.2–2.0g/kg/天。
- 碳水：6–10g/kg/天（耐力运动优先补糖）。
- 水和电解质：运动前中后补水，大量出汗补钠。

> 来源：中国居民膳食指南（2022）；美国运动医学会（ACSM）运动营养指南。

## 二十、功能性食品与膳食补充剂

### 20.1 什么是功能性食品

声称具有特定健康功效的食品（如降血脂、增强免疫），但不等于药品。各国监管标准不同。

### 20.2 常见补充剂评估

| 补充剂 | 证据等级 | 说明 |
|--------|----------|------|
| 维D | 强 | 缺乏者补充有益，日照不足者必要 |
| 铁 | 强 | 缺铁性贫血者必需，不缺勿补 |
| 钙 | 中 | 膳食不足者补充，配合维D |
| 鱼油（ω-3） | 中 | 心血管保护有一定证据，食物优先 |
| 益生菌 | 中 | 特定菌株对特定腹泻/便秘有辅助 |
| 蛋白粉 | 低–中 | 饮食够蛋白者无需额外补充 |
| 维C | 低 | 不能预防感冒，缺乏者补 |
| 胶原蛋白 | 低 | 口服分解为氨基酸，美容效果证据弱 |
| 酵素（酶） | 低 | 口服后被消化，无直接保健证据 |

### 20.3 安全提醒

- **食补优先**：均衡饮食通常能满足营养需求。
- **不可替代药物**：有疾病应遵医嘱治疗。
- **过量风险**：脂溶性维生素（A/D/E/K）和矿物质（铁/硒）过量可中毒。
- **药物相互作用**：如维K影响华法林抗凝效果。

> 来源：中国营养学会科普；美国国立卫生研究院（NIH）膳食补充剂办公室。

## 二十一、饮食与慢性病预防

| 慢性病 | 饮食策略 |
|--------|----------|
| 2 型糖尿病 | 低 GI 饮食、控制总能量、增加纤维、限糖 |
| 高血压 | DASH 饮食（多蔬果、低钠高钾、低脂） |
| 心血管病 | 限饱和脂肪、增 ω-3、多蔬果全谷、限盐 |
| 骨质疏松 | 充足钙、维D、蛋白质，负重运动 |
| 某些癌症 | 多蔬果、少红肉加工肉、限酒、戒烟 |
| 痛风 | 限高嘌呤食物（内脏、海鲜）、限酒、多水 |

**DASH 饮食要点**：多吃蔬菜水果、全谷物、低脂乳制品；少吃红肉、甜食、盐。研究表明可降低血压 8–14 mmHg（来源：NIH DASH 研究）。

> 来源：WHO 慢性病预防指南；NIH DASH 饮食研究；中国慢性病防治规划。

## 二十二、食品安全与营养标签解读

### 22.1 营养标签必看项目

| 项目 | 关注点 |
|------|--------|
| 能量（kJ/kcal） | 控制总摄入 |
| 蛋白质 | 越高越好（同类食品比较） |
| 脂肪 | 总脂肪、饱和脂肪、反式脂肪越低越好 |
| 碳水化合物 | 注意添加糖含量 |
| 钠 | 越低越好（<120mg/100g 为低钠） |

### 22.2 配料表解读

- 配料按含量从多到少排列。
- 前三位含糖/油/精制面粉的食品应少选。
- "部分氢化油"= 反式脂肪来源，应避免。
- "果葡糖浆""蔗糖""麦芽糊精"都是添加糖的不同名称。

> 来源：GB 28050-2011《预包装食品营养标签通则》；消费者报道科普。
