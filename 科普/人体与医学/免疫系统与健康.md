# 免疫系统与健康

> ⚠️ **免责声明**：本文为科普内容，由非医学专业人士整理编写，旨在帮助普通成人了解免疫学基础知识。**本文不能替代专业医疗诊断、治疗或医嘱**。如果您有过敏、反复感染、自身免疫病或疫苗接种相关疑问，请务必咨询执业医生或疾控中心/接种门诊。文中部分数据引用世界卫生组织（WHO）、中国疾控中心等公开资料，医学进展持续更新，请以最新指南与医生意见为准。

---

## 一、导语：免疫是什么

"免疫力"是近年最常被提起、也最容易被神化的词。商家说"某某产品提升免疫力"，朋友圈说"感冒是排毒"。但免疫到底是什么？

简单说，**免疫系统是身体识别"自己"与"非己"，清除病原体和异常细胞、保护健康的防御体系**。它既不是越强越好（过强会过敏、自身免疫病），也不是越弱越好（易感染、易长肿瘤）。平衡，才是关键。

本文分五部分：免疫的两大分支、疫苗原理、炎症、过敏、以及"提升免疫力"的常见误区。

---

## 二、免疫系统的两大分支

免疫系统分为**先天免疫（innate immunity）**和**适应性免疫（adaptive immunity）**。

| 维度 | 先天免疫 | 适应性免疫 |
|------|----------|------------|
| 是否生来就有 | 是（遗传获得） | 出生后接触抗原才建立 |
| 反应速度 | 数分钟至数小时 | 数天（初次），再次更快 |
| 特异性 | 非特异（广谱） | 高度特异（针对特定病原体） |
| 记忆性 | 无 | 有（记忆细胞） |
| 组成 | 皮肤、黏膜、吞噬细胞、自然杀伤细胞、补体 | T 细胞、B 细胞、抗体 |
| 比喻 | 边境巡逻 + 快速反应部队 | 精准特种兵 + 情报档案 |

两者并非割裂：先天免疫先"拖住"敌人并释放警报信号，引导适应性免疫精准打击，并形成记忆以备再战。

## 三、先天免疫的"第一道防线"

### 3.1 物理与化学屏障
- **皮肤**：角质层是致密城墙，pH 偏酸抑制菌类。
- **黏膜**：呼吸道、消化道黏膜分泌黏液捕获病原体；泪液、唾液含溶菌酶。
- **纤毛**：气道纤毛把异物向上扫出（见人体系统总览）。

### 3.2 细胞卫士
| 细胞 | 职责 |
|------|------|
| 中性粒细胞 | 最常见的吞噬细胞，冲向感染灶"吃"细菌 |
| 巨噬细胞 | 大个子吞噬者，兼做抗原提呈（报警） |
| 自然杀伤细胞（NK） | 识别并杀死被病毒感染或癌变的细胞 |
| 树突状细胞 | "抗原提呈"，把敌情报告给 T 细胞 |

### 3.3 补体系统
一组血浆蛋白，像"爆破小队"：可标记病原体（调理作用）、直接击穿其膜、吸引吞噬细胞。这是先天免疫的重要化学武器。

## 四、适应性免疫：精准与记忆

### 4.1 主角：T 细胞与 B 细胞
两者都源自骨髓，B 细胞在骨髓成熟，T 细胞迁往**胸腺**成熟（故"胸腺"是 T 细胞的军校）。

| 细胞 | 功能 |
|------|------|
| 辅助 T 细胞（Th） | 指挥中枢，释放信号激活其他免疫细胞 |
| 细胞毒性 T 细胞（CTL） | 直接杀死被病毒感染的细胞 |
| B 细胞 | 分化为浆细胞，分泌**抗体（免疫球蛋白）** |
| 记忆 T/B 细胞 | 长期留存"敌人档案"，再遇时快速反应 |

### 4.2 抗体如何工作
抗体（如 IgG、IgM、IgA）像"定位导弹"，能：
- **中和**：堵住病毒进入细胞的位点；
- **调理**：给病原体"贴标签"方便吞噬；
- **激活补体**：引发爆破。

### 4.3 免疫记忆 = 疫苗与"曾得过病后不易再得"的基础
得过麻疹康复后通常终身免疫，正是因为记忆细胞长期驻守。疫苗正是"模拟"这一过程。

## 五、疫苗：用"假敌人"训练真防线

### 5.1 疫苗的基本原理
疫苗把**无害的病原体信息**（灭活的、减毒的、或仅其片段/指令）送入体内，让免疫系统提前演练并产生记忆细胞。等真病原体来袭，防线已就位。

世界卫生组织（WHO）将疫苗设计归纳为几类（来源：WHO《疫苗是如何研发的》）：

| 类型 | 做法 | 例子 |
|------|------|------|
| 灭活疫苗 | 用化学/热/辐射杀死病原体，保留抗原 | 流感灭活疫苗、脊髓灰质炎灭活疫苗 |
| 减毒活疫苗 | 弱化活病原体，模拟自然感染、反应强 | 麻疹、腮腺炎、风疹、水痘疫苗；鼻喷流感 |
| 病毒载体疫苗 | 用安全病毒作"快递"递送抗原指令 | 部分埃博拉疫苗、新冠腺病毒载体疫苗 |
| 亚单位/重组疫苗 | 只用病原体关键片段（如表面蛋白） | 重组乙肝疫苗、重组流感疫苗 |
| 核酸疫苗（mRNA/DNA） | 递送"制造抗原的说明书" | mRNA 新冠疫苗 |

### 5.2 为什么流感疫苗要每年打？
流感病毒是 RNA 病毒，变异快（抗原漂移/转换）。WHO 每年 **2 月（北半球）和 9 月（南半球）**根据全球监测更新疫苗毒株组合（来源：WHO 与 CDC 监测体系）。同时，接种后抗体约每 1–2 个月下降 2%–5%，6–8 个月后保护力明显衰减（来源：流感疫苗科普资料）。两因素叠加，故推荐"每年一针"。

### 5.3 接种后多久起效、保护多久？
- 接种后约 **10–14 天**产生保护性抗体；
- 抗体峰值维持约 **3–4 个月**；
- **6–8 个月后**保护力明显下降（来源：流感疫苗技术指南科普）。
- 因此建议在流感季前（如北方 9–10 月）完成接种。

### 5.4 疫苗安全性要点
- 灭活/亚单位疫苗不含活病毒，**不会导致相应疾病**；
- 常见反应为接种部位酸痛、低热，多 1–2 天缓解；
- 严重过敏极罕见，故接种后需**留观 30 分钟**；
- 禁忌人群（如严重过敏史、急性疾病期、免疫功能缺陷者某些活疫苗禁用）应遵医嘱。

### 5.5 常见疫苗一览（成人也别忘）

| 疫苗 | 推荐人群 | 说明 |
|------|----------|------|
| 流感疫苗 | ≥6 月龄、无禁忌者，老人/慢病/孕妇优先 | 每年一针 |
| 新冠疫苗 | 按当时国家方案与风险 | 关注官方更新 |
| 肺炎球菌疫苗 | 老年人、慢病患者 | 降低重症肺炎 |
| 乙肝疫苗 | 未感染且未抗体达标者 | 可补种 |
| 带状疱疹疫苗 | 中老年（按说明书年龄） | 降低疱疹与后遗神经痛 |
| HPV 疫苗 | 适龄女性/男性按方案 | 预防相关癌症 |

## 六、炎症：免疫的"双刃剑"

### 6.1 急性炎症——有益的警报
受伤或感染时，局部出现**红、热、肿、痛、功能障碍**，这是免疫系统调兵遣将的表现：血管扩张、通透性增加、白细胞渗出。目的：隔离并清除威胁、启动修复。多数急性炎症数天至数周痊愈。

### 6.2 慢性炎症——沉默的杀手
当炎症持续不退（数月到数年），会成为多种慢病的土壤：
- 动脉粥样硬化（血管内皮慢性炎症）
- 2 型糖尿病（脂肪组织低度炎症）
- 脂肪肝、某些癌症、神经退行病

**可控的慢性炎症风险因素**：肥胖、高糖高脂饮食、久坐、吸烟、长期压力、睡眠缺乏、牙周病。

### 6.3 发烧是敌是友？
发烧是体温调定点上移的防御反应，适度升温可抑制部分病原体复制、增强免疫。一般**成人腋温 ≥38.5℃ 或明显不适**可考虑退热，但持续高热、精神差、呼吸困难等须就医。不要盲目"捂汗"。

## 七、过敏：免疫"误伤友军"

### 7.1 过敏的本质
过敏是免疫系统对**无害物质（过敏原）**产生过度反应，多由 **IgE 抗体**介导。常见过敏原：花粉、尘螨、宠物皮屑、海鲜、坚果、药物（如青霉素）、蜂毒。

### 7.2 常见过敏性疾病

| 疾病 | 表现 |
|------|------|
| 过敏性鼻炎 | 打喷嚏、流清涕、鼻痒、眼痒 |
| 哮喘 | 反复喘息、胸闷、咳嗽（气道高反应） |
| 特应性皮炎（湿疹） | 皮肤干燥、瘙痒、皮疹 |
| 食物过敏 | 荨麻疹、呕吐，重则过敏性休克 |
| 药物过敏 | 皮疹到休克不等 |

### 7.3 严重过敏：过敏性休克
可危及生命，表现为迅速出现的皮疹、喉头水肿、喘息、血压下降。急救关键是立即肌注**肾上腺素**（自动注射笔）并拨打急救电话。有严重过敏史者需随身带笔并就医制定预案。

### 7.4 过敏能"根治"吗？
多数不能"断根"，但可：**回避过敏原 + 规范用药（抗组胺、吸入激素等）+ 部分人脱敏治疗（免疫治疗）**控制。网络偏方风险高，请遵医嘱。

## 八、"提升免疫力"的六大误区

### 误区 1：吃某保健品能"增强免疫"
市面上灵芝、蛋白粉、维生素片常被宣传为"增强免疫"。事实：对健康、饮食均衡者，**额外补充多数并无额外益处**；过量某些成分（如大剂量维生素 A、E）反而有害。营养应优先从食物获取。

### 误区 2：免疫力"越强越好"
错。过强会过敏、哮喘、自身免疫病（如类风湿、红斑狼疮）。目标不是"最强"，而是"平衡"。

### 误区 3：生病是"排毒"
感冒发烧是感染或免疫应答，不是"排毒"。硬扛可能延误（如流感并发症、肺炎）。

### 误区 4：不生病 = 免疫力强
不生病也可能只是暴露少、运气好，或症状被忽略。健康行为比"赌运气"靠谱。

### 误区 5：出入无菌环境最安全
适度接触正常微生物有助于免疫系统"练兵"（卫生假说）。过度消毒、滥用抗生素反而破坏菌群平衡。当然，**该洗手时认真洗手，该消毒时消毒**。

### 误区 6：靠"排毒疗程"清免疫
所谓淋巴排毒、灌肠排毒多无证据，甚至伤身。肝、肾本就负责清除代谢废物。

## 九、真正有助于免疫平衡的生活方式

基于权威机构（WHO、各国疾控与营养指南）的共识：

| 措施 | 作用 | 建议 |
|------|------|------|
| 均衡饮食 | 提供免疫细胞原料 | 多样、足蔬果、适量蛋白、少油盐糖 |
| 充足睡眠 | 免疫修复与抗体生成 | 成人 7–9 小时（见神经系统专文） |
| 规律运动 | 促进循环、抗炎 | 每周中等强度 ≥150 分钟 |
| 接种疫苗 | 建立特异性记忆 | 按国家免疫程序与医生建议 |
| 管理压力 | 慢性压力抑制免疫 | 冥想、社交、兴趣 |
| 戒烟限酒 | 减少黏膜与免疫损伤 | 烟草全戒，酒精限量 |
| 讲卫生 | 减少病原入侵 | 勤洗手、安全饮食、生熟分开 |
| 慎用抗生素 | 保护菌群、防耐药 | 遵医嘱使用，不自行买药 |

## 十、免疫相关常见疾病速览

| 类别 | 疾病举例 | 核心问题 |
|------|----------|----------|
| 感染 | 流感、新冠、结核、肝炎 | 病原体入侵 |
| 过敏 | 鼻炎、哮喘、湿疹 | 免疫过度反应 |

## 十一、什么时候该看医生

- 反复感染（如一年多次肺炎、长期不愈）；
- 感染后恢复极慢、伴高热不退；
- 过敏症状重或首次严重反应；
- 出现自身免疫疑似表现（关节痛、皮疹、乏力长期）；
- 疫苗接种前后有特殊健康状况（如免疫抑制、妊娠）。

## 十二、常见 Q&A

| 问题 | 回答 |
|------|------|
| 感冒要不要用抗生素？ | 普通感冒多为病毒，抗生素无效；是否用由医生判断。 |
| 维生素 C 能防感冒吗？ | 不能预防，可能略缩短病程；食补优先。 |
| 益生菌有用吗？ | 对部分腹泻/菌群紊乱有辅助作用，非"万能"。 |
| 压力大真的易生病？ | 是，慢性压力激素会抑制免疫。 |
| 老人免疫弱怎么办？ | 疫苗、营养、运动、防跌倒与感染。 |

## 十三、免疫与年龄：从婴儿到老年的变化

| 阶段 | 免疫特点 | 注意 |
|------|----------|------|
| 新生儿 | 从母体获得部分抗体（IgG 经胎盘、IgA 经母乳），自身尚弱 | 按时接种疫苗，提倡母乳 |
| 儿童 | 免疫系统在反复接触中"练兵"成熟 | 普通感染多为学习过程，但重症状就医 |
| 成年 | 免疫处高峰，但受生活方式影响大 | 平衡作息、控慢病 |
| 老年（免疫衰老） | 胸腺退化、T 细胞减少、反应变慢 | 更需疫苗、营养、防感染 |

**免疫衰老（immunosenescence）**解释为何老人与婴幼儿是流感、肺炎的高危人群。这也是老年人推荐接种流感、肺炎、带状疱疹疫苗的原因。

## 十四、自身免疫病：当防线"认友为敌"

正常情况下免疫能区分"自己/非己"。出错时会攻击自身组织，称**自身免疫病**。

| 疾病 | 主要受累 |
|------|----------|
| 类风湿关节炎 | 关节 |
| 系统性红斑狼疮 | 多系统（肾、皮肤、关节） |
| 1 型糖尿病 | 胰岛 β 细胞 |
| 桥本甲状腺炎 | 甲状腺 |
| 多发性硬化 | 神经髓鞘 |
| 银屑病 | 皮肤 |

特点：常慢性、反复、需长期规范治疗；切勿信"断根秘方"。免疫抑制治疗需在医生指导下权衡感染风险。

## 十五、免疫缺陷：防线薄弱时

- **先天性（原发性）**：遗传导致某类免疫细胞/分子缺失，婴幼儿期反复严重感染。
- **获得性**：如 HIV 攻击 CD4+T 细胞导致艾滋病；也可由药物（化疗、长期大剂量激素）引起。
- 表现：感染频繁、严重、难愈，或机会性感染（正常人不易得）。

---

## 十六、肿瘤与免疫：身体的"内部叛变"

免疫系统有**免疫监视**功能，可识别并清除癌变细胞。但肿瘤细胞会"伪装"或抑制免疫（免疫逃逸）。近年**免疫检查点抑制剂**通过"松开刹车"重启 T 细胞攻击肿瘤，是癌症治疗重大突破。这属于专业肿瘤治疗范畴，由医生评估。

## 十七、疫苗常见疑虑 Q&A（扩展）

| 疑虑 | 事实 |
|------|------|
| "疫苗有病毒会让我生病" | 灭活/亚单位疫苗不含活病毒；减毒活疫苗对免疫正常者安全，特定人群禁用。 |
| "我身体好不用打" | 健康人也可能被传染并传染他人；疫苗护己也护脆弱人群（群体免疫）。 |
| "打完发烧是不是坏了" | 低热、酸痛是正常免疫应答，多 1–2 天好；高烧不退就医。 |
| "多种疫苗能一起打吗" | 多数可同日或按程序接种，以接种门诊指引为准。 |
| "过了季节还能打流感吗" | 整个流行季都可，早打早保护。 |

## 十八、免疫相关"数字"小卡片

- 成人静息时，免疫系统每秒产生约 **数百万**个新免疫细胞（量级说法）。
- 人体约 **70%** 的免疫细胞分布在肠道相关淋巴组织（"肠脑免疫轴"受关注）。
- 记忆细胞可在体内留存**数年乃至数十年**。
- 接种流感疫苗可降低 **40%–60%** 感染风险并显著减少重症（来源：流感科普资料）。

## 十九、名词小词典

- **抗原（Antigen）**：引发免疫反应的异物或分子。
- **抗体（Antibody/Ig）**：B 细胞分泌的、识别特定抗原的蛋白质。
- **细胞因子（Cytokine）**：免疫细胞间传递信号的"信使"蛋白。
- **免疫耐受**：对"自己"不反应、避免自伤的状态。
- **自身免疫（Autoimmunity）**：免疫系统攻击自身组织。
- **免疫记忆（Immunological memory）**：再次遇同抗原时反应更快更强。
- **佐剂（Adjuvant）**：疫苗中增强免疫反应的成分。

## 二十二、免疫与肠道微生态

约 **70%** 的免疫细胞分布在肠道相关淋巴组织，肠道菌群与免疫发育、抗炎、抗感染密切相关。膳食纤维（喂养益生菌）、发酵食品、减少不必要抗生素，有助于维持菌群与免疫平衡。这是"吃什么影响免疫力"最靠谱的解释之一。

## 二十三、疫苗的全球公共卫生成就

- **天花**：1980 年 WHO 宣布全球根除，是疫苗史上最辉煌的胜利（来源：WHO）。
- **脊髓灰质炎**：全球病例较高峰下降超 99%，多区域已无野生脊灰（来源：WHO/全球根除倡议）。
- **麻疹、乙肝、破伤风**等通过疫苗大幅减少发病与死亡。

这些成就提醒我们：疫苗不是新事物，而是经过长期验证、拯救数亿生命的公共卫生工具。

## 二十四、环境与免疫：日常可做的几件小事

- **空气**：雾霾天减少户外剧烈运动，必要时戴口罩；室内常通风。
- **水质与食物**：喝清洁水、食物煮熟煮透，生熟分开，防食源性感染。
- **宠物**：接触后洗手；有过敏史者先评估再养。
- **旅行**：前往疫区前咨询国际旅行医学门诊，按需接种疫苗（如黄热、伤寒）。
- **伤口**：小伤口清洁消毒包扎；红肿热痛加重、发热须就医，警惕破伤风（何时需打破伤风针由医生判断）。

## 二十五、一句话要点卡

- 免疫贵"平衡"，非"越强越好"。
- 疫苗=提前演练，流感需每年打。
- 慢性炎症是慢病温床，靠生活方式对抗。
- 过敏可致命，重症备肾上腺素笔。
- 保健品不等于免疫力，饭吃对、觉睡够、苗接好最实在。

## 二十六、小结

- 免疫分**先天（快速广谱）**与**适应性（精准有记忆）**两大分支，协同防御。
- **疫苗**用"假敌人"训练记忆细胞，是性价比最高的预防手段之一；流感疫苗因病毒变异需每年接种。
- **炎症**是防御反应，但慢性低度炎症是多种慢病的推手。
- **过敏**是免疫"误伤"，重者可致命（过敏性休克需肾上腺素）。
- 提升免疫靠**平衡的生活方式**，而非神化保健品或"排毒"。

## 二十七、免疫增强的科学方法

### 27.1 营养与免疫

| 营养素 | 免疫作用 | 来源 |
|--------|----------|------|
| 蛋白质 | 抗体和免疫细胞的原料 | 鱼禽蛋豆 |
| 维生素 A | 维护皮肤黏膜屏障、T细胞功能 | 肝、胡萝卜 |
| 维生素 C | 增强吞噬细胞功能、抗氧化 | 柑橘、蔬菜 |
| 维生素 D | 调节先天与适应性免疫 | 日照、鱼、蛋 |
| 锌 | T细胞发育和功能 | 贝类、肉 |
| 铁 | 免疫细胞增殖所需 | 红肉、动物血 |
| 硒 | 抗氧化、抗病毒 | 巴西坚果、海鲜 |
| ω-3 脂肪酸 | 调节炎症反应 | 深海鱼、亚麻籽 |

### 27.2 运动与免疫

- **适度有氧运动**（每周 150 分钟中等强度）可提升 NK 细胞活性和抗体反应。
- **过度运动**（马拉松等极端强度）反而暂时抑制免疫（"开窗期"），感染风险升高。
- 运动后 3–72 小时免疫功能增强，长期坚持者免疫衰老延缓。

### 27.3 睡眠与免疫

- 睡眠期间免疫细胞释放细胞因子，T 细胞功能增强。
- 睡眠不足（<6 小时）者接种疫苗后抗体产生减少（来源：Carpenter 等研究）。
- 慢性失眠与炎症标志物（CRP、IL-6）升高相关。

### 27.4 压力管理与免疫

- 慢性压力使皮质醇持续升高，抑制 T 细胞功能和抗体产生。
- 正念冥想、社交互动、兴趣爱好可降低压力激素水平。
- 社会孤立与免疫功能下降、慢性炎症相关。

### 27.5 菌群与免疫

- 肠道菌群参与免疫系统"训练"和调节。
- 膳食纤维喂养有益菌，产生短链脂肪酸（如丁酸），调节肠道免疫。
- 抗生素滥用破坏菌群平衡，可能增加过敏和自身免疫风险。

> 来源：WHO 免疫增强指南；Nature Immunology 综述；中国营养学会免疫营养共识。

## 二十八、自身免疫病深入

### 28.1 为什么会攻击自身

正常情况下免疫系统通过**中枢耐受**（胸腺中删除自身反应性 T 细胞）和**外周耐受**（调节性 T 细胞抑制）避免攻击自身。自身免疫病是耐受机制失败的结果。

### 28.2 常见自身免疫病详解

| 疾病 | 受累组织 | 主要抗体 | 典型表现 |
|------|----------|----------|----------|
| 类风湿关节炎 | 关节滑膜 | RF、抗 CCP | 晨僵、对称性关节肿痛 |
| 系统性红斑狼疮 | 多系统 | 抗核抗体（ANA） | 蝶形红斑、关节痛、肾损害 |
| 1 型糖尿病 | 胰岛 β 细胞 | 抗 GAD、抗 IA-2 | 胰岛素绝对缺乏 |
| 桥本甲状腺炎 | 甲状腺 | 抗 TPO、抗 TG | 甲减为主 |
| 多发性硬化 | 中枢神经髓鞘 | — | 视力障碍、肢体无力 |
| 银屑病 | 皮肤 | — | 红斑、鳞屑、关节炎 |

### 28.3 治疗原则

| 方法 | 作用 |
|------|------|
| 免疫抑制剂 | 降低整体免疫活性（如甲氨蝶呤、糖皮质激素） |
| 生物制剂 | 靶向特定细胞因子（如 TNF-α 抑制剂） |
| JAK 抑制剂 | 阻断细胞内信号通路 |
| 对症治疗 | 缓解症状、保护器官功能 |

关键原则：**规范治疗、长期管理、不可自行停药**。切勿信"断根秘方"。

### 28.4 诱发因素

- **遗传易感性**：某些 HLA 基因型风险更高（如 HLA-B27 与强直性脊柱炎）。
- **环境触发**：感染（分子模拟）、紫外线、药物、吸烟。
- **肠道菌群失调**：近年研究发现与多种自身免疫病相关。
- **激素**：女性发病率显著高于男性（约 3:1），提示性激素参与。

> 来源：《凯利风湿病学》；Nature Reviews Immunology 自身免疫综述；中华医学会风湿病学分会指南。

## 二十九、过敏反应的免疫机制

### 29.1 过敏反应的四个类型

| 类型 | 机制 | 时间 | 例子 |
|------|------|------|------|
| I 型（速发型） | IgE 介导，肥大细胞脱颗粒 | 数分钟 | 荨麻疹、过敏性休克 |
| II 型（细胞毒型） | IgG/IgM 靶向细胞表面抗原 | 数小时 | 输血反应、药物过敏 |
| III 型（免疫复合物型） | 抗原-抗体复合物沉积 | 数小时–天 | 血清病、类风湿 |
| IV 型（迟发型） | T 细胞介导 | 24–72 小时 | 接触性皮炎、结核菌素试验 |

日常所说的"过敏"主要指 **I 型速发过敏**。

### 29.2 过敏进程（Atopic March）

许多过敏性疾病按一定顺序在生命早期出现：

湿疹（婴儿期）→ 食物过敏 → 过敏性鼻炎 → 哮喘

早期干预（回避过敏原、规范治疗湿疹）可能降低后续过敏风险。

### 29.3 过敏原检测

| 方法 | 原理 | 优缺点 |
|------|------|--------|
| 皮肤点刺试验 | 皮内注入微量过敏原，观察风团反应 | 快速、灵敏，但可能假阳性 |
| 血清特异性 IgE | 检测血液中针对特定过敏原的 IgE | 安全、不受药物影响 |
| 激发试验 | 直接接触过敏原观察反应 | 最准确，但有风险，需在医院进行 |

> 来源：AAAAI（美国过敏哮喘免疫学会）指南；EAACI（欧洲变态反应与临床免疫学会）文件。

| 阶段 | 参与细胞 | 作用机制 |
|------|----------|----------|
| **0-4小时** | 物理屏障、化学屏障 | 阻止病原体入侵 |
| **4-96小时** | 吞噬细胞、NK细胞 | 非特异性清除 |

### 18.2 适应性免疫应答

| 阶段 | 参与细胞 | 作用机制 |
|------|----------|----------|
| **识别** | T细胞、B细胞 | 通过TCR/BCR识别特异性抗原 |
| **活化** | 辅助T细胞 | 提供共刺激信号 |
| **效应** | 细胞毒性T细胞、浆细胞 | 杀伤感染细胞或产生抗体 |
| **记忆** | 记忆T细胞、记忆B细胞 | 快速响应再次感染 |

## 二十、免疫增强与调节

### 20.1 生活方式调节

| 因素 | 建议 | 科学依据 |
|------|------|----------|
| **睡眠** | 7-9小时/晚 | 睡眠期间免疫细胞再分布，细胞因子分泌增加 |
| **运动** | 每周150分钟中等强度 | 增加NK细胞、T细胞循环 |
| **压力管理** | 冥想、瑜伽 | 长期压力抑制免疫功能 |
| **社交** | 保持联系 | 孤独感与炎症标志物升高相关 |

### 20.2 营养与免疫

| 营养素 | 作用 | 食物来源 |
|--------|------|----------|
| **维生素C** | 促进白细胞功能 | 柑橘、草莓、西兰花 |
| **维生素D** | 调节T细胞功能 | 阳光、鱼类、蛋黄 |
| **锌** | 免疫细胞发育 | 牡蛎、瘦肉、坚果 |
| **硒** | 抗氧化、抗病毒 | 巴西坚果、海鲜 |

### 20.3 免疫训练（Trained Immunity）

| 概念 | 说明 |
|------|------|
| **定义** | 固有免疫细胞通过表观遗传重编程，获得对后续感染的增强反应能力 |
| **机制** | 组蛋白修饰、DNA甲基化变化 |
| **应用** | BCG疫苗可非特异性增强抗病毒免疫 |
