## 阅读建议

1. **零基础**：先看《人体系统总览与器官》建立全景，再按兴趣深入免疫/神经/遗传/营养。
2. **按需查阅**：体检后想搞懂指标可读 总览+营养；打疫苗有疑虑读 免疫；失眠健忘读 神经；家族史担忧读 遗传。
3. **交叉关联**：肠道微生态（免疫）—脑肠轴（神经）—营养物质（营养）三条线在本板块交汇。
4. 每篇附「名词小词典」「健康自评」「把知识用起来」，学完即可落到生活习惯。
