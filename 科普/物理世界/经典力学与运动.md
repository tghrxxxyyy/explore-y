# 经典力学与运动

> 经典力学是研究「宏观、低速」物体运动规律的基础物理学分支。它从伽利略、牛顿时代奠基，至今仍是工程、航天、体育乃至日常生活的底层逻辑。本文面向成人通识，力求把核心思想讲清，避免繁琐数学推导。

## 导语

你扔出一块石头，它划出一道弧线落地；你踩刹车，身体会往前倾；月球绕着地球转，地球绕着太阳转——这些现象背后，是同一套力学法则。经典力学（也称牛顿力学）给出了描述「力如何改变运动」的系统框架。

它有两个适用边界：
- **宏观**：研究对象比分子、原子大得多（量子效应可忽略）。
- **低速**：速度远小于光速（约 3×10⁸ m/s，来源：国际计量局 BIPM 定义值）。

超过边界时，需要用量子力学或相对论，但经典力学在日常生活尺度上极其精确，是几乎所有工程技术的基石。

## 一、力学的基本概念

### 1.1 物质、质量与重量

| 概念 | 含义 | 单位 | 易混淆点 |
| --- | --- | --- | --- |
| 质量 m | 物体含物质的多少，惯性大小的量度 | 千克（kg） | 不随位置改变 |
| 重量 G | 物体受到的重力大小，G = mg | 牛（N） | 月球上重量约为地球 1/6，质量不变 |
| 密度 ρ | 单位体积的质量，ρ = m/V | kg/m³ | 与轻重有关，但轻的东西不一定密度小（如泡沫） |

重力加速度 g 在地球表面约为 **9.8 m/s²**（标准值 9.80665 m/s²，来源：国际计量局；人教版高中物理取 9.8 或 10 简化计算）。

### 1.2 位移、速度与加速度

| 概念 | 含义 | 公式 | 例子 |
| --- | --- | --- | --- |
| 位移 s | 起点到终点的有向线段 | 矢量 | 绕操场跑一圈，位移为 0 |
| 速度 v | 位移随时间的变化率 | v = Δs/Δt | 高铁匀速 300 km/h |
| 加速度 a | 速度随时间的变化率 | a = Δv/Δt | 自由落体 a = g |

**关键提醒**：加速度描述「速度变化快慢」，不等于「速度快慢」。高速巡航的飞机加速度为 0，刚起步的汽车加速度很大。

### 1.3 矢量与标量

力、速度、加速度都是**矢量**（有大小有方向）；质量、温度、路程都是**标量**（只有大小）。力学计算常需分解方向，这是很多初学者的难点。

## 二、牛顿三大运动定律

牛顿在 1687 年《自然哲学的数学原理》中提出三大定律（来源：人教版高中物理、维基百科）。它们是经典力学的支柱。

### 2.1 第一定律：惯性定律

> 任何物体在不受外力或合外力为零时，总保持静止或匀速直线运动状态。

**核心思想：惯性**。物体有「维持现状」的 tendency。
- 例子：急刹车时人往前倾——车停了，身体还想保持前进。
- 例子：锤子松了，把柄朝下磕地，锤头因惯性继续向下套紧。

**常见误区**：「有力才有运动」。错。匀速直线运动不需要力维持，力改变的是运动状态（加速度），不是运动本身。

### 2.2 第二定律：加速度定律

> 物体的加速度与合外力成正比，与质量成反比，方向与合外力方向相同。

公式：**F = ma**（更严格地，F = dp/dt，p 为动量）

| 要素 | 说明 |
| --- | --- |
| F | 合外力（所有力的矢量和） |
| m | 物体质量（惯性量度） |
| a | 产生的加速度 |

- 同样推力，空车比满载加速快（质量小 → 加速度大）。
- 质量越大越「难推动」，正是惯性大的体现。

**应用**：火箭发动机推力、汽车碰撞安全（减速时间越长，受力越小）、电梯超重报警。

### 2.3 第三定律：作用力与反作用力

> 两物体间的作用力与反作用力，总是大小相等、方向相反、作用在同一直线上。

| 要点 | 说明 |
| --- | --- |
| 同时性 | 力总是成对出现，无先后 |
| 异物性 | 作用在不同物体上，不能抵消 |
| 同性 | 同为引力、同为弹力等 |

- 你推墙，墙也推你（所以你能离开墙）。
- 走路靠地面给脚的反作用力。
- 火箭向后喷气，气体给火箭向前的反作用力（太空中也能推进）。

**常见误区**：「马拉车，车也拉马，为何车会动？」因为两力作用在不同物体上。车动是因为地面对车的摩擦力（与马拉力方向一致）大于阻力，合外力不为零。

## 三、万有引力定律

牛顿发现：宇宙中任意两质点相互吸引。

公式：**F = G·m₁m₂ / r²**

| 符号 | 含义 | 数值 |
| --- | --- | --- |
| G | 万有引力常数 | 6.67430(15)×10⁻¹¹ m³·kg⁻¹·s⁻²（来源：NIST CODATA 2022） |
| m₁, m₂ | 两物体质量 | — |
| r | 两质点距离 | — |

### 3.1 关键性质

- 与质量乘积成正比、与距离平方成反比（**平方反比律**）。
- 与物质成分、中间介质无关。
- 距离越远引力越弱：卫星越高，地球引力越小但仍存在。

### 3.2 重力从哪来

地球表面的重力近似来自地球引力：g = G·M地 / R地² ≈ 9.8 m/s²。

| 现象 | 解释 |
| --- | --- |
| 苹果落地 | 地球吸引苹果 |
| 月球绕地 | 引力提供圆周运动向心力 |
| 潮汐 | 月球（及太阳）引力对海水差异吸引 |
| 行星轨道 | 太阳引力束缚行星（开普勒定律的基础） |

### 3.3 历史意义

万有引力第一次把「天上」与「地上」统一在同一套定律下——这是科学史上最伟大的综合之一（来源：维基百科「万有引力定律」）。

## 四、动量守恒

**动量 p = mv**（质量×速度，矢量）。

> 一个系统若不受外力（或合外力为零），总动量保持不变。

公式：m₁v₁ + m₂v₂ = m₁v₁′ + m₂v₂′（碰撞前后总动量相等）

### 4.1 典型实例

| 场景 | 说明 |
| --- | --- |
| 撞球 | 动量从一球传给另一球 |
| 火箭 | 喷出气体向后，火箭向前（总动量守恒） |
| 炸弹爆炸 | 碎片总动量仍为零（原静止） |
| 滑冰推人 | 两人反向运动，动量大小相等 |

### 4.2 与牛顿第三定律的关系

动量守恒可由牛顿第三定律推出：内力总是成对抵消，不改变系统总动量；只有外力能改变它。

**常见误区**：以为「动量守恒」意味着每个物体速度不变。错，是总和不变，个体可以剧烈变化。

## 五、能量守恒

> 能量既不会凭空产生，也不会凭空消失，只能从一种形式转化为另一种形式，或从一个物体转移到另一个物体，总量保持不变。（来源：人教版高中物理）

### 5.1 常见能量形式

| 形式 | 例子 |
| --- | --- |
| 动能 | 运动的汽车、流动的河水 |
| 势能（重力） | 举高的重物、水库蓄水 |
| 弹性势能 | 拉开的弓、压缩的弹簧 |
| 内能 | 分子热运动 |
| 电能、化学能、光能 | 电池、燃烧、灯泡 |

### 5.2 动能与势能

- 动能：**E_k = ½mv²**（速度平方关系，所以高速碰撞破坏力剧增）
- 重力势能：**E_p = mgh**

### 5.3 机械能守恒

若只有重力/弹力做功（无摩擦、无空气阻力），机械能（动能+势能）守恒。

- 过山车从高处滑下：势能→动能，速度变大。
- 蹦极：势能↔动能↔弹性势能循环。

**现实情况**：摩擦把机械能转为内能（发热），总能量仍守恒，只是「可用机械能」减少。

### 5.4 功率

**功率 P = W/t**（单位时间做功），单位瓦特（W）。汽车马力、电器瓦数都指功率。

## 六、抛体运动

将物体以一定初速度斜向上/水平抛出，只受重力（忽略空气阻力），轨迹为**抛物线**。

### 6.1 运动分解

| 方向 | 运动性质 | 加速度 |
| --- | --- | --- |
| 水平 | 匀速直线 | 0 |
| 竖直 | 匀变速（自由落体） | g 向下 |

### 6.2 实例

- 投篮弧线、炮弹弹道、喷泉水流。
- 最远投掷角：45°（理想无空气阻力）。
- 节日烟花、跳水动作都可视作抛体。

**常见误区**：「水平抛出的物体会立即垂直下落。」错。它同时有水平速度，所以沿抛物线前进，落地时间只由高度决定。

## 七、圆周运动

物体沿圆周运动，速度方向不断改变（指向切线），因此存在**向心加速度**。

公式：**a = v²/r = ω²r**，向心力 **F = mv²/r**

| 概念 | 含义 |
| --- | --- |
| 向心加速度 | 始终指向圆心，改变速度方向 |
| 向心力 | 维持圆周运动的合外力，指向圆心 |
| 角速度 ω | 单位时间转过的角度 |

### 7.1 生活实例

| 现象 | 向心力来源 |
| --- | --- |
| 汽车转弯 | 地面摩擦力 |
| 绳子拴球旋转 | 绳子拉力 |
| 地球绕日 | 太阳引力 |
| 洗衣机脱水 | 内壁支持力 |
| 过山车圆环顶部 | 重力+支持力 |

### 7.2 离心现象

当向心力不足，物体「甩出去」——并非受到「离心力」推，而是惯性使它想走直线。

- 旋转雨伞甩水珠。
- 铁路弯道外轨略高，靠支持力分力提供向心力。

## 八、参考系

> 描述运动必须选定参照物，即**参考系**。同一运动在不同参考系下描述不同。

| 例子 | 说明 |
| --- | --- |
| 车内乘客看司机 | 静止（以车为参考系） |
| 路边人看司机 | 运动（以地面为参考系） |
| 太阳看地球 | 地球绕日转 |
| 地球看太阳 | 太阳东升西落 |

### 8.1 惯性参考系

牛顿定律成立的参考系叫惯性系（如静止或匀速直线运动的地面近似）。加速的车是非惯性系，会出现「假想力」（如转弯时的离心感）。

### 8.2 伽利略相对性原理

在所有惯性系中，力学规律相同（来源：维基百科「伽利略变换」）。这是爱因斯坦狭义相对论的前身。

## 九、摩擦力：无处不在的「阻力」

摩擦力是两个接触面相对运动或有相对运动趋势时产生的阻碍力。它既「讨厌」（耗能发热）又「必不可少」（没它人走不了路、车刹不住）。

### 9.1 三类摩擦

| 类型 | 条件 | 例子 |
| --- | --- | --- |
| 静摩擦 | 有相对运动趋势但未动 | 推不动的箱子、人走路 |
| 滑动摩擦 | 相对滑动 | 刹车、滑雪 |
| 滚动摩擦 | 滚动 | 车轮（比滑动小得多） |

### 9.2 滑动摩擦公式

**f = μN**

| 符号 | 含义 |
| --- | --- |
| μ | 动摩擦因数（与接触面材料、粗糙程度有关） |
| N | 接触面间的正压力（垂直于接触面，不一定等于重力） |

### 9.3 易错点

- 摩擦力方向「阻碍相对运动趋势」，不一定与运动方向相反。人走路时地面给脚的静摩擦向前，恰恰是动力。
- 最大静摩擦略大于滑动摩擦，所以「启动比维持更难」。
- 滚动摩擦远小于滑动摩擦，因此用轮子搬运省力（轴承原理）。

## 十、力矩与转动

物体除了平动，还会转动。转动效果由**力矩**决定。

公式：**M = F × L**（力 × 力臂，力臂是转轴到力作用线的垂直距离）

| 概念 | 说明 | 例子 |
| --- | --- | --- |
| 力矩 | 使物体转动的原因 | 用扳手拧螺母，柄越长越省力 |
| 转动平衡 | 顺时针力矩 = 逆时针力矩 | 天平、跷跷板 |
| 转动惯量 | 转动中的「质量」，抗拒角加速度变化 | 花样滑冰收臂转更快 |

### 10.1 角动量守恒

> 不受外力矩时，系统角动量守恒。

- 花样滑冰运动员收拢手臂→转动惯量减小→转速增大。
- 陀螺进动、太阳系角动量分布。

## 十一、简谐运动与振动

物体在回复力（与位移成正比、指向平衡位置）作用下做**简谐运动（SHM）**。

公式：**F = -kx**（k 为劲度系数，x 为偏离平衡位置位移）

| 现象 | 说明 |
| --- | --- |
| 弹簧振子 | 经典 SHM 模型 |
| 单摆（小角度） | 周期 T = 2π√(L/g)，与质量无关 |
| 秋千 | 近似 SHM |
| 乐器弦 | 驻波与振动 |

**周期与频率**：T 是完成一次振动的时间，f = 1/T 是频率。单摆周期只与摆长和 g 有关——这正是重力测量与钟摆计时原理。

## 十二、流体力学初步：浮力与压强

### 12.1 压强

**p = F/S**（单位面积上的力），单位帕斯卡（Pa）。

- 针尖易刺入：面积小→压强大。
- 液压机：帕斯卡原理（密闭液体压强处处相等）可放大力量。

### 12.2 阿基米德原理

> 浸在流体中的物体受到向上的浮力，大小等于排开流体的重量。（来源：维基百科「阿基米德原理」）

| 情形 | 结果 |
| --- | --- |
| 浮力 > 重力 | 上浮（木块、气球） |
| 浮力 = 重力 | 悬浮 |
| 浮力 < 重力 | 下沉（铁块） |

- 轮船靠空心增大排水体积获得足够浮力。
- 热气球靠加热空气减小密度上浮。
- 曹冲称象即用等效排水思想。

### 12.3 伯努利原理

> 流体流速大处压强小。（来源：维基百科「伯努利定律」）

- 飞机机翼：上表面流速快→压强小→产生升力。
- 火车站黄线：列车驶过带快气流，压强差可能把人「吸」向列车。
- 喷雾器、球场弧线球（马格努斯效应相关）。

## 十三、力学单位制与量纲

国际单位制（SI）中力学基本量：长度（米 m）、质量（千克 kg）、时间（秒 s）。

| 派生量 | 单位 | 由基本量构成 |
| --- | --- | --- |
| 速度 | m/s | L·T⁻¹ |
| 加速度 | m/s² | L·T⁻² |
| 力 | N = kg·m/s² | M·L·T⁻² |
| 能量/功 | J = N·m | M·L²·T⁻² |
| 功率 | W = J/s | M·L²·T⁻³ |

量纲检查能帮助发现公式错误（左右量纲必须一致）。

## 十五、常见误区汇总

| 误区 | 正解 |
| --- | --- |
| 有力才有运动 | 力改变运动状态，匀速运动无需力维持 |
| 速度大加速度就大 | 匀速巡航加速度为 0 |
| 作用力与反作用力会抵消 | 作用在不同物体，不抵消 |
| 重的物体下落更快 | 真空中同时落地（伽利略比萨斜塔传说；实际由空气阻力造成差异） |
| 圆周运动有向外的离心力 | 是惯性表现，并非真实外力 |
| 动量守恒=每个物体不变 | 是系统总和不变 |

## 十七、小结

- 牛顿三定律（惯性、F=ma、作用反作用）是经典力学的骨架。
- 万有引力统一了天体与地面运动，平方反比律解释了行星轨道。
- 动量守恒与能量守恒是自然界最普适的规律之一，适用于从撞球到宇宙碰撞。
- 抛体运动可分解为水平匀速 + 竖直匀变速；圆周运动需要指向圆心的向心力。
- 运动描述依赖参考系，牛顿定律在惯性系中成立。
- 经典力学在宏观低速下精确可靠，是工程技术的根基；极端情形交给定子力学与相对论。

## 十八、日常物理现象的力学解释

| 现象 | 力学原理 |
| --- | --- |
| 乘公交急刹身体前倾 | 惯性：脚随车停，上身仍向前运动 |
| 安全带保护作用 | 延长减速时间，减小冲击力（F=ma） |
