# 量子力学入门

> 量子力学是描述微观世界（原子、电子、光子）的物理学理论。它诞生于 20 世纪初对黑体辐射与光电效应的追问，用一个多世纪彻底改写了人类对「实在」「测量」「信息」的理解。本文面向成人通识，重概念与思想实验，轻数学推导，力求把最反直觉的部分讲得可理解。

## 导语

经典物理有一个隐含信念：**只要知道初始条件，未来就被完全决定**。拉普拉斯曾设想一个全知精灵，能由粒子的位置与速度推算整个宇宙的过去与未来。量子力学动摇了这个图景。

它带来的几个结论，至今仍让物理学家争论不休：

- 能量不是连续的，而是一份一份的（**量子化**）。
- 微观客体既是粒子又是波（**波粒二象性**）。
- 一个粒子可以同时处于多个状态（**叠加态**），测量时才会「坍缩」到某个确定结果。
- 位置与动量不可能同时精确（**不确定性原理**）。
- 两个粒子可以形成超越空间距离的关联（**量子纠缠**）。

请注意一个重要的分寸：量子力学的**数学预言精度极高**，是当代最精确的物理理论之一（如电子磁矩、氢光谱的计算精度可达十亿分之一量级）；而非议集中在**如何理解这个数学**——即「诠释」问题。本文会明确区分「已被实验确立的结论」与「仍在争论的解释」。

## 一、经典物理的危机

19 世纪末，物理学被普遍认为已接近完成：牛顿力学管天与地，麦克斯韦方程组管电磁与光，热力学管能量与熵。开尔文在 1900 年的一次演讲中提到，物理学的天空只剩「两朵乌云」。

| 乌云 | 内容 | 最终结局 |
| --- | --- | --- |
| 第一朵：以太与光速 | 迈克尔逊－莫雷实验未测到以太 | 催生狭义相对论（1905） |
| 第二朵：黑体辐射 | 经典理论给出荒谬结果 | 催生量子论（1900） |

### 1.1 经典理论的三次失效

| 现象 | 经典预言 | 实际观测 |
| --- | --- | --- |
| 黑体辐射高频段 | 能量密度趋于无限（「紫外灾难」） | 高频段迅速下降 |
| 光电效应 | 光强越大电子动能越大 | 动能只与频率有关 |
| 原子稳定性 | 绕核电子应辐射能量并坠入核 | 原子稳定存在，光谱是离散线状 |

### 1.2 关键时间线

## 二、能量量子化与普朗克

### 2.1 普朗克的「无奈之举」

1900 年 12 月，普朗克为拟合黑体辐射谱，不得不假设：**空腔壁上的振子能量只能取分立值**，即

**E = n hν**（n = 0, 1, 2, …）

也就是说，能量交换的最小单位是 **ε = hν**，称为「能量子」。

| 符号 | 含义 | 数值 |
| --- | --- | --- |
| h | 普朗克常数 | 6.626 070 15×10⁻³⁴ J·s（2019 年 SI 精确定义值，来源：BIPM / NIST） |
| ν | 频率 | Hz |
| n | 量子数 | 正整数 |

**历史意义**：普朗克本人最初把它当作「数学技巧」，多年后仍试图回归连续能量。但这个假设是一切量子理论的起点，故 1900 年 12 月常被称为「量子力学的生日」。

### 2.2 常数 h 的量纲直觉

h 的数值极小，约为 6.6×10⁻³⁴ J·s。这意味着单个光子的能量极小：绿光（532 nm）光子能量约 3.7×10⁻¹⁹ J（约 2.33 eV）。

**为什么日常看不到量子化？** 因为宏观物体涉及的能量比 hν 大得多，离散的「台阶」相对于总能量小到无法察觉——就像台阶极密时看起来像斜坡。

| 场景 | 能量的「台阶」占比 | 是否感觉到量子化 |
| --- | --- | --- |
| 吊灯（约百瓦） | 微不足道 | 否 |
| 单个原子跃迁 | 台阶即全部 | 是 |
| 单光子探测 | 只能整份 | 是 |

## 三、黑体辐射

### 3.1 什么是黑体

黑体是理想的吸收体：对任何波长的入射辐射全部吸收、无反射无透射。它同时是最理想的发射体。带小孔的空腔近似黑体。

### 3.2 两条经验定律

| 定律 | 公式 | 含义 |
| --- | --- | --- |
| 斯特藩－玻尔兹曼定律 | M = σT⁴ | 总辐射功率与 T 的四次方成正比 |
| 维恩位移定律 | λ_max T = b | 温度越高，谱峰波长越短 |

| 常数 | 数值 | 来源 |
| --- | --- | --- |
| 斯特藩－玻尔兹曼常数 σ | 5.670 374 419×10⁻⁸ W·m⁻²·K⁻⁴ | NIST CODATA / BIPM |
| 维恩位移常数 b | 2.897 771 955×10⁻³ m·K | NIST CODATA |

**日常验证**：加热铁块先暗红（约 800 K）、再橙黄、再白亮——谱峰随温度向短波移动，肉眼看到的是「红→黄→白→蓝白」的次序。

| 物体 | 温度 | 谱峰波长 | 呈现 |
| --- | --- | --- | --- |
| 人体 | 约 310 K | 约 9.3 μm | 红外（肉眼不可见） |
| 白炽灯丝 | 约 2800 K | 约 1.0 μm | 近红外偏暗红 |
| 太阳表面 | 约 5778 K | 约 500 nm | 绿蓝之间（整体呈白） |
| 蓝超巨星 | 约 30 000 K | 约 100 nm | 紫外为主 |

### 3.3 紫外灾难

瑞利－金斯公式基于经典能量均分定理，给出 **ρ(ν) ∝ ν²T**，在高频段趋于无穷——这意味着任何物体都会瞬间辐射出无限能量，显然荒谬。这个矛盾被称为「紫外灾难」。

普朗克公式则在整个频段与实验完美吻合：

**ρ(ν, T) = (8πhν³/c³) · 1/(e^(hν/k_BT) − 1)**

| 常数 | 数值 |
| --- | --- |
| 玻尔兹曼常数 k_B | 1.380 649×10⁻²³ J/K（SI 精确值） |
| 普朗克常数 h | 6.626 070 15×10⁻³⁴ J·s |

低频（hν ≪ k_BT）时普朗克公式退化为瑞利－金斯公式；高频时指数因子压制，避免发散。这一步「回归经典极限」正是新理论正确的标志。

**宇宙学应用**：宇宙微波背景辐射是极精确的黑体谱，温度约 2.725 K，是宇宙大爆炸的余晖——黑体辐射公式因此成为现代宇宙学的工具。

## 四、光电效应

详见《光学与波动》第十六节，此处从量子力学的视角补充。

### 4.1 爱因斯坦光量子方程

**hν = W + E_k(max)**

| 符号 | 含义 |
| --- | --- |
| W | 逸出功（材料属性，典型 2–5 eV） |
| E_k(max) | 光电子最大初动能 |
| 截止（红限）频率 | ν₀ = W/h |
| 遏止电压 | eU = E_k(max) |

### 4.2 为什么它「无法被经典解释」

| 特征 | 经典波动说 | 光子说 |
| --- | --- | --- |
| 存在红限 | 无法解释 | 自然：单光子能量不足 |
| 动能与频率线性关系 | 无法解释 | hν − W 直接给出 |
| 光强只影响电子数 | 与「能量连续累积」矛盾 | 光子数多→电子多 |
| 瞬时发射 | 需累积时间 | 一对一吸收，瞬时完成 |

### 4.3 验证与荣誉

| 年份 | 事件 | 人物 |
| --- | --- | --- |
| 1887 | 发现现象 | 赫兹 |
| 1902 | 测出动能与频率有关、与光强无关 | 莱纳德 |
| 1905 | 提出光子假说 | 爱因斯坦 |
| 1916 | 精密验证并测 h | 密立根 |
| 1921 | 诺贝尔物理学奖（光电效应） | 爱因斯坦 |
| 1923 | 诺贝尔物理学奖（基本电荷与光电效应） | 密立根 |

### 4.4 日常与工业应用

| 应用 | 原理 |
| --- | --- |
| 太阳能电池 | 光子激发电子-空穴对 |
| 光电倍增管 | 光电子倍增放大微弱光 |
| 数码相机 CCD/CMOS | 光电转换成像 |

## 五、康普顿散射

1923 年，康普顿发现 X 射线被石墨散射后，散射光中除原波长外还出现更长的波长，且偏移量随散射角增大而增大。

| 要点 | 说明 |
| --- | --- |
| 经典波动说 | 只能解释同波长散射，无法解释波长变长 |
| 光子说 | 把光子当有动量的粒子与电子弹性碰撞 |
| 波长偏移公式 | Δλ = (h/m_e c)(1 − cosθ) |
| 电子康普顿波长 | h/m_e c ≈ 2.43×10⁻¹² m |
| 意义 | 直接证实光子有动量与能量，是粒子性的铁证 |
| 荣誉 | 康普顿获 1927 年诺贝尔物理学奖 |

**中国物理学家的贡献**：1926 年，吴有训对不同散射物质做了系统研究，验证并推广了康普顿效应的规律，为该理论被广泛接受作出重要贡献（来源：科普中国相关条目）。

## 六、原子模型与玻尔的突破

### 6.1 模型演进

| 模型 | 提出者/年代 | 内容 | 缺陷 |
| --- | --- | --- | --- |
| 实心球模型 | 道尔顿，1803 | 原子不可分 | 无法解释电现象 |
| 葡萄干模型 | 汤姆孙，1904 | 正电荷均匀分布 + 电子嵌其中 | 无法解释大角散射 |
| 核式模型 | 卢瑟福，1911 | 正电荷与质量集中于极小核 | 经典电磁学预言电子会坠入核 |
| 玻尔模型 | 玻尔，1913 | 电子在特定轨道、能量量子化 | 只适合氢与类氢离子 |
| 量子力学模型 | 1926 后 | 电子由波函数描述、概率分布 | — |

### 6.2 玻尔的三个假设

| 假设 | 内容 |
| --- | --- |
| 定态假设 | 电子只能在特定能量轨道上运动，不辐射 |
| 跃迁假设 | 跃迁时吸收或发射光子，能量差 **ΔE = hν** |
| 角动量量子化 | 轨道角动量为 ħ 的整数倍 |

### 6.3 氢光谱

| 谱系 | 所属波段 | 归向能级 |
| --- | --- | --- |
| 赖曼系 | 紫外 | n = 1 |
| 巴耳末系 | 可见光（Hα、Hβ…） | n = 2 |
| 帕申系 | 近红外 | n = 3 |
| 布拉开系 | 红外 | n = 4 |

玻尔模型首次成功解释了巴耳末系的经验公式，让离散光谱有了物理机制。但它的「轨道」图景后来被波函数取代——电子没有确定轨迹，只有概率云。

## 七、德布罗意波与物质波

### 7.1 逆向思考

爱因斯坦说「波有粒子性」；1924 年，德布罗意反问：**粒子是否也有波动性？**

### 7.2 德布罗意关系

**λ = h / p**（p 为动量），另有 **ν = E / h**

| 粒子 | 速度 | 德布罗意波长 |
| --- | --- | --- |
| 电子（100 eV） | 约 5.9×10⁶ m/s | 约 0.12 nm（与原子间距同量级） |
| 电子（54 eV） | — | 约 0.165 nm |
| 质子（1 eV） | — | 约 0.03 nm |
| 尘埃（1 μg，1 mm/s） | 1 mm/s | 约 6.6×10⁻²⁵ m（无法探测） |
| 棒球（150 g，40 m/s） | 40 m/s | 约 10⁻³⁴ m（无意义） |

**关键直觉**：宏观物体的德布罗意波长小到荒谬，所以看不到波动性；而电子、原子、中子、甚至大分子的波长可与原子间距或实验结构相比，波动性显著。近年已用约 10⁴ 个原子质量的大分子（约 2000 个原子）观察到干涉——量子性与「大小」之间没有硬性分界，只有波长与环境的对比。

### 7.3 实验验证

| 年份 | 实验 | 内容 |
| --- | --- | --- |
| 1927 | 戴维森－革末实验 | 54 eV 电子射向镍单晶，散射角 50° 出现强峰，与布拉格衍射计算一致 |
| 1927 | 汤姆孙（G. P.）实验 | 高速电子穿过多晶金属箔，得到类似 X 射线的衍射环 |
| 1930s 起 | 中子衍射 | 用于研究晶体与磁性结构 |
| 1990s 起 | 原子/分子干涉 | 冷原子、大分子干涉 |

| 荣誉 | 年份 |
| --- | --- |
| 德布罗意获诺贝尔物理学奖 | 1929 |
| 戴维森与 G. P. 汤姆孙共享诺贝尔物理学奖 | 1937 |

### 7.4 波粒二象性的统一表述

| 图像 | 描述 |
| --- | --- |
| 粒子图像 | 探测时呈现为一份一份的计数（单个点） |
| 波图像 | 大量事件的概率分布呈现干涉条纹 |
| 统计诠释 | 波的强度 ∝ 找到粒子的概率 |

**电子双缝实验的震撼**：即使一次只发射一个电子，长时间累积仍出现干涉条纹；而一旦测量「电子走了哪条缝」，条纹立刻消失。这是量子力学最著名也最深刻的实验。

## 八、波函数与薛定谔方程

### 8.1 波函数 ψ

量子态由**波函数** ψ(r, t) 描述，它是一个复值函数，本身没有直接物理意义，但其模平方给出**概率密度**：

**|ψ(r, t)|² dV = 在体积 dV 内找到粒子的概率**

这一诠释由玻恩 1926 年提出（玻恩获 1954 年诺贝尔物理学奖）。

### 8.2 薛定谔方程（1926）

**iħ ∂ψ/∂t = Ĥψ**

| 符号 | 含义 |
| --- | --- |
| i | 虚数单位 |
| ħ | 约化普朗克常数 = h/2π ≈ 1.054 571 817×10⁻³⁴ J·s |
| Ĥ | 哈密顿算符（对应总能量） |
| ψ | 波函数 |

定态情形化为 **Ĥψ = Eψ**（本征值方程），能量 E 只能取本征值——**量子化自然地从方程中涌现**，无需额外假设。这是 1926 年理论相对 1913 年玻尔模型的巨大进步。

### 8.3 波函数的性质

| 性质 | 说明 |
| --- | --- |
| 归一化 | 全空间积分 |ψ|² dV = 1 |
| 叠加性 | ψ 的线性组合仍是合法量子态 |
| 相位重要 | 相位差决定干涉结果 |
| 确定性演化 | 未测量时，ψ 按薛定谔方程确定演化 |
| 测量时随机 | 测量结果按 |ψ|² 概率随机 |

### 8.4 常见的量子态

| 概念 | 含义 |
| --- | --- |
| 基态 | 能量最低态 |
| 激发态 | 能量高于基态的定态 |
| 简并 | 不同态有相同能量 |
| 束缚态 | 粒子局限在有限区域（如原子中的电子） |
| 散射态 | 粒子可以自由远离（如自由电子） |

**尺度感**：氢原子基态电子云半径约 0.053 nm（玻尔半径），电子并非「绕圈运动」，而是以球对称概率云分布。所谓「轨道」早已被「轨道（orbital）」取代。

## 九、叠加态与测量问题

### 9.1 叠加原理

若 ψ₁ 与 ψ₂ 都是可能状态，则 **c₁ψ₁ + c₂ψ₂** 也是可能状态。这就是「同时处于多个状态」的准确含义。

| 例子 | 叠加内容 |
| --- | --- |
| 双缝 | 同时经过两条缝的概率幅叠加 |
| 自旋 | 自旋同时沿「上」与「下」（相对某轴） |
| 能级 | 激发态与基态的相干叠加（如拉比振荡） |
| 薛定谔猫 | 活与死的宏观叠加（思想实验） |
| 量子比特 | α|0⟩ + β|1⟩ |

### 9.2 测量与「坍缩」

标准（哥本哈根）描述中，测量使叠加态随机坍缩到某个本征态，概率由 |cᵢ|² 给出。这个过程**不可逆、不可预测**（只可给概率）。

| 阶段 | 规律 |
| --- | --- |
| 未测量 | 薛定谔方程，确定性、可逆、西（幺正）演化 |
| 测量瞬间 | 随机、不可逆、非幺正（坍缩） |

这个「两套规则」是量子力学最深的分裂：为什么有测量？什么算测量？观察者是否特殊？

### 9.3 薛定谔猫

1935 年薛定谔设计的思想实验：把猫与一个由放射性衰变触发的毒气装置关在箱中。若衰变是量子随机事件，则按严格叠加描述，猫处于「活与死的叠加」。薛定谔本意是嘲讽「量子叠加用于宏观物体」的荒谬，但它精确地把测量问题摆上台面。

| 需要区分的三个问题 | 内容 |
| --- | --- |
| 实验事实 | 微观叠加已被大量实验证实（干涉、纠缠） |
| 退相干 | 宏观物体与环境的强耦合极快破坏叠加（时间可短至 10⁻²⁰ s 量级，视系统而定） |
| 诠释问题 | 「坍缩」是否真实？还是多世界/隐变量/关系性解释？ |

**退相干的作用**：它解释了为什么我们**看不到**宏观叠加（如猫），但退相干本身并不直接选出「唯一结果」，因此没有完全解决测量问题。这是活跃的研究领域，不宜当作已定论。

## 十、不确定性原理

### 10.1 海森堡关系（1927）

**Δx · Δp ≥ ħ/2**

| 符号 | 含义 |
| --- | --- |
| Δx | 位置的不确定度（标准差） |
| Δp | 动量的不确定度 |
| ħ/2 | 约 5.27×10⁻³⁵ J·s |

另有能量－时间关系 **ΔE · Δt ≥ ħ/2**（对寿命与谱线宽度的解释尤为常用）。

### 10.2 关键澄清

| 误解 | 正解 |
| --- | --- |
| 是仪器不够好 | 是**原理性**限制，与仪器精度无关 |
| 是「看」的时候撞偏了 | 不是测量扰动导致，而是量子态本身没有同时确定的值 |
| 可以靠巧妙设计绕过 | 已被理论与实验严格检验 |
| 影响日常生活 | 对宏观物体影响极小，可忽略 |

### 10.3 不确定性原理是「傅里叶性质」

一个非常重要的直觉：**波包越窄，其动量成分就越宽**——这是傅里叶分析的数学定理，不是量子力学独有的「魔法」。量子力学只是把「波包」对应到「粒子」。

| 波包特征 | 位置 | 动量 |
| --- | --- | --- |
| 极窄（近点） | 很确定 | 极不确定 |
| 极宽（近平面波） | 极不确定 | 很确定 |
| 高斯最小波包 | 恰好取 ħ/2 | 恰好取 ħ/2 |

### 10.4 应用与后果

| 应用/后果 | 说明 |
| --- | --- |
| 原子稳定 | 电子若不运动会被束缚得极紧，动能剧增，故不能坠入核 |
| 零点能 | 束缚系统最低能量不为零（谐振子基态能 ħω/2） |
| 谱线自然宽度 | 激发态寿命有限 → 能级有宽度 |
| 原子核稳定性 | 核子动能与势能平衡 |
| 单光子/单电子源 | 波包与能量展宽权衡 |
| 量子成像与压缩态 | 通过「压缩」一边不确定性降低另一边（不违反原理） |

**「零点能」的宏观证据**：液氦在绝对零度附近仍保持液态（不凝固），正是因为零点运动使原子无法完全静止——这是不确定性原理在宏观物质上的可见脚印。

## 十一、量子隧穿

### 11.1 什么是隧穿

经典粒子无法越过比自身能量更高的势垒；量子粒子却有**非零概率「穿过」**势垒，称为量子隧穿。

| 要素 | 说明 |
| --- | --- |
| 势垒高度 | 高于粒子能量 |
| 穿透概率 | 对矩形势垒近似指数衰减 ∝ e^(−2κa)，κ ∝ √(V−E) |
| 敏感性 | 势垒宽度 a 变化一点点，概率变化数量级 |
| 条件 | 势垒越薄、粒子越轻，越易穿透 |

### 11.2 隧穿的应用与现象

| 现象/技术 | 隧穿的作用 |
| --- | --- |
| α 衰变 | 核内 α 粒子隧穿出核势垒（伽莫夫 1928 解释） |
| 恒星核聚变 | 质子隧穿库仑势垒，使太阳得以发光 |
| 扫描隧道显微镜（STM） | 针尖－样品隧穿电流对间距极其敏感，可达原子分辨 |
| 隧道二极管 | 负阻特性 |
| 闪存（Flash） | 电子隧穿注入/擦除浮栅，决定写入寿命 |
| 约瑟夫森结 | 超导库珀对隧穿，用于超导量子比特与 SQUID |
| 酶催化中的质子隧穿 | 生物化学中的量子效应 |
| DNA 突变 | 质子隧穿导致碱基错配（理论与实验研究领域） |

**量级感受**：STM 的隧穿电流每变化一个原子高度（约 0.1 nm）可变化约一个数量级——这正是它能「触摸」单个原子的原因。

## 十二、量子纠缠

### 12.1 定义

两个或多个粒子的量子态不能各自独立描述，必须作为一个整体描述，这种关联即为**纠缠**。

| 特征 | 说明 |
| --- | --- |
| 非分离性 | 整体态无法写成各自态的乘积 |
| 关联强度 | 超过任何经典「预先约定」能产生的关联 |
| 测量关联 | 测一个粒子，立即知道另一个的相应属性 |
| 传递信息？ | **不能**用它超光速传递信息（关键澄清） |

### 12.2 经典纠缠态例子

以自旋（或偏振）为例，两个粒子处于「自旋相反」的纠缠态：测得 A 为「上」，则 B 必为「下」，无论相隔多远。但请注意：

| 常见误读 | 正解 |
| --- | --- |
| 纠缠可以超光速通信 | 不能。单边测量结果随机，只有比对双方结果才显现关联 |
| 纠缠是「心灵感应」 | 是量子态的非分离性，不是信号传递 |
| 纠缠很脆弱 | 确实脆弱（易退相干），但已有成熟技术维持与分发 |
| 纠缠不能用于加密 | 可用于量子密钥分发，且安全性有物理保证 |

### 12.3 爱因斯坦的质疑

1935 年，爱因斯坦、波多尔斯基、罗森（EPR）发表论文，指出若量子力学是完备的，就存在「超距作用」；若不存在，则量子力学不完备。爱因斯坦称纠缠为「鬼魅般的超距作用」。这场争论持续了近三十年，直到贝尔给出可实验检验的不等式。

## 十三、贝尔不等式与实验验证

### 13.1 贝尔的关键一步（1964）

贝尔证明：如果存在**局域隐变量**（每个粒子携带预先设定的「指令」，且不受远距离影响），那么大量测量的关联程度必须满足某个不等式上限；而量子力学预言会**违反**该不等式。

| 结果 | 含义 |
| --- | --- |
| 不等式成立 | 量子力学可被局域隐变量理论取代 |
| 不等式被违反 | 局域隐变量理论不成立（量子力学胜出） |

### 13.2 实验接力

| 年份 | 实验/人物 | 贡献 |
| --- | --- | --- |
| 1972 | 克劳泽（与弗里德曼） | 首次用钙原子级联光子实现贝尔检验，结果违反不等式 |
| 1982 | 阿斯佩 | 改进装置，在纠缠光子离开源**之后**切换测量设置，堵住重要漏洞 |
| 1990s–2010s | 蔡林格等 | 更多严格检验（含用遥远星系信号选择设置）、量子隐形传态 |
| 2015 起 | 「无漏洞」贝尔实验 | 多个团队同时堵住探测效率与局域性漏洞 |
| 2022 | 诺贝尔物理学奖 | 阿斯佩、克劳泽、蔡林格，表彰「纠缠光子实验、验证违反贝尔不等式、开创量子信息科学」 |

（来源：NobelPrize.org 2022 年物理学奖新闻公报；新华社、中国科学院相关报道。）

### 13.3 结论的分寸

实验排除了**局域**隐变量理论。至于「非局域的隐变量」（如玻姆力学）或「多世界」等诠释，仍与实验相符——因此准确的说法是：**自然不允许「局域实在论」**，而量子力学的形式体系经受住了全部检验。

## 十四、量子信息与量子计算

### 14.1 量子比特（qubit）

| 比较 | 经典比特 | 量子比特 |
| --- | --- | --- |
| 取值 | 0 或 1 | α|0⟩ + β|1⟩ 的叠加 |
| 状态数（n 位） | 1 个确定值 | 2ⁿ 个幅度的叠加 |
| 操作 | 逻辑门 | 量子门（酉变换） |
| 读出 | 直接读 | 测量后坍缩为 0 或 1 |
| 复制 | 可任意复制 | **不可克隆**（不可克隆定理） |

**注意分寸**：叠加并不意味着「一次算出所有答案再挑出对的」。要将量子并行性转化为可读结果，需要**干涉**让错误答案的概率相消、正确答案的概率相长——这正是量子算法设计的关键难点。

### 14.2 关键算法

| 算法 | 年份 | 加速类型 | 用途 |
| --- | --- | --- | --- |
| Deutsch–Jozsa | 1992 | 指数（特定问题） | 概念验证 |
| Shor | 1994 | 指数 | 大整数分解、离散对数（威胁 RSA/ECC） |
| Grover | 1996 | 平方根 | 无序搜索、优化 |
| HHL | 2009 | 指数（条件性） | 线性方程组（含限制） |
| 变分量子算法（VQE/QAOA） | 2010s | 启发式 | 化学、组合优化（NISQ 时代） |

| 影响 | 说明 |
| --- | --- |
| 对 RSA | Shor 算法理论上可在多项式时间分解大数，威胁现行公钥体系 |
| 应对 | 后量子密码（基于格、编码、哈希等，已有 NIST 标准征选） |
| 对对称加密 | Grover 使密钥有效强度减半，加倍密钥长度即可应对 |
| 时间尺度 | 需要容错、数百万物理比特量级；短期内不是现实威胁 |

## 十六、量子力学的诠释之争

这是量子力学中最「不物理」也最引人入胜的部分。请记住：**所有诠释给出相同的实验预言**，分歧在于如何理解形式体系。

| 诠释 | 核心主张 | 代价/特点 |
| --- | --- | --- |
| 哥本哈根 | 波函数是概率工具，测量导致坍缩 | 需引入「经典测量装置」，边界模糊 |
| 多世界（艾弗雷特） | 无坍缩，所有分支都实现 | 分支数量爆炸，概率来源需额外解释 |
| 退相干 + 量子达尔文主义 | 环境导致优选基，解释经典表观 | 仍未单独选出唯一结果 |
| 玻姆力学（导波） | 粒子有确定轨迹，由波引导 | 明显非局域，需初始条件特殊分布 |
| 关系性量子力学 | 态是相对观察者的关系 | 对「观察者」定义有新要求 |
| 客观坍缩（GRW 等） | 存在物理坍缩机制 | 可实验检验（已有实验收紧参数） |
| 量子贝叶斯（QBism） | 波函数是主观信念度 | 与「客观实在」的关系有争议 |

**实践建议**：作为学习者，先把「形式体系 + 实验事实」学扎实，再读诠释争论；否则容易在哲学迷雾中失去对物理的把握。

## 十八、常见误区汇总

| 误区 | 正解 |
| --- | --- |
| 量子力学说明「一切都不确定」 | 波函数演化完全确定，随机性只在测量结果上 |
| 观测者意识导致坍缩 | 主流观点认为「测量」是物理相互作用，与意识无关 |
| 叠加态就是「不知道是哪个」 | 是真正同时处于两者，可干涉（与经典无知不同） |
| 不确定性原理是仪器不够好 | 是原理性限制，量子态本身不具同时确定值 |
| 纠缠可以超光速传信息 | 不能，只有比对双方结果才显现关联 |
| 隧穿是「借用能量」再还 | 通俗说法，严格说是波函数在势垒内指数衰减但非零 |
| 量子计算机能瞬间破解一切密码 | 只对特定算法（如 Shor）有指数加速，且需容错硬件 |
| 量子计算就是「同时试所有可能」 | 关键在干涉使正确解概率放大 |
| 量子比特可以复制 | 不可克隆定理禁止任意复制 |
| 薛定谔猫证明量子力学荒谬 | 是揭示测量问题的思想实验，宏观叠加极快退相干 |
| 电子绕核「转圈」 | 无确定轨迹，只有概率分布（原子轨道） |
| 光子有静质量 | 静质量为零 |
| 量子效应只存在于极低温 | 常温下也有（光合作用、酶催化、半导体器件） |

### 23.1 由浅入深的四个台阶

### 23.2 常见学习困惑

| 困惑 | 解答思路 |
| --- | --- |
| 波函数到底是什么 | 是计算概率的工具（不可直接观测），不必强行想象成物质波 |
| 为什么测量特殊 | 这是诠释问题；实验上只需把「测量」当作与宏观环境的强耦合 |
| 概率是不是我们不知道 | 不是「不知道」，叠加态可干涉，与经典无知有本质区别 |
| 复数为什么出现 | 形式体系需要相位，相位差决定干涉；复数是最自然的表达 |
| 不确定性怎么和「波」联系 | 波包越窄，频谱越宽——傅里叶定理 |
| 自旋是什么在转 | 不是经典自转，是内禀角动量，只有量子描述 |
| 纠缠是不是超光速 | 不是，不能传信息，只有关联 |
| 量子力学是否推翻了因果 | 演化是确定的，测量结果是随机的；「随机」不等于「无规律」 |

## 二十五、读懂量子力学所需的数学直觉

不必精通数学也能理解核心思想，但掌握以下四组直觉，会显著提升理解深度。

| 数学工具 | 在量子力学中的作用 | 一句话直觉 |
| --- | --- | --- |
| 复数与相位 | 概率幅是复数 | 相位差决定加强还是抵消 |
| 傅里叶分析 | 波包与动量分布 | 窄波包 = 宽频谱，是不确定性原理的数学根源 |
| 线性代数（矢量、矩阵） | 量子态是矢量、观测量是算符 | 叠加就是矢量相加，测量就是投影 |
| 概率论 | 玻恩规则 | 概率 = 幅度模平方 |

### 25.1 概率幅与概率的区别

| 概念 | 运算规则 | 后果 |
| --- | --- | --- |
| 经典概率 | 直接相加 | 概率只会变大，不能相消 |
| 概率幅（复数幅度） | 先相加，再取模平方 | 可以相消 → 出现干涉暗纹 |

这是「量子叠加」与「经典无知」最本质的差别：**只有幅度能相消，概率不能相消**。

### 25.2 算符与本征值

| 术语 | 含义 | 例子 |
| --- | --- | --- |
| 观测量 | 可被测量的物理量 | 位置、动量、能量、自旋 |
| 算符 | 作用在态上的数学操作 | 位置算符、动量算符 −iħ∇ |
| 本征态 | 算符作用后只被数乘的态 | 能量本征态 |
| 本征值 | 那个数乘因子 | 允许的能量值 |

**关键结论**：测量结果只能是本征值——这就是「能量量子化」「自旋只能取上/下」的数学来源，而不是人为规定。

### 25.3 对易关系

**位置与动量不对易**：[x, p] = iħ。这一条代数关系直接推出 Δx·Δp ≥ ħ/2。因此不确定性原理不是「经验限制」，而是形式体系的**定理**。

## 小结

- **量子力学的起点是「量子化」**：普朗克 1900 年为拟合黑体辐射提出 E = hν，能量不再是连续的。这一步解决了「紫外灾难」，也定义了 h = 6.626 070 15×10⁻³⁴ J·s（SI 精确值）。
- **黑体辐射的两条经验定律**：M = σT⁴（σ = 5.670 374 419×10⁻⁸ W·m⁻²·K⁻⁴）与 λ_max T = b（b ≈ 2.898×10⁻³ m·K）。
- **光电效应是光量子说的决定性证据**：hν = W + E_k(max)，动能只取决于频率；爱因斯坦获 1921 年诺贝尔奖，密立根 1916 年精密验证。
- **波粒二象性适用于一切物质**：德布罗意 1924 年给出 λ = h/p，1927 年电子衍射实验证实；宏观物体波长小到不可观测。
- **波函数的模平方给出概率密度**（玻恩），薛定谔方程 iħ∂ψ/∂t = Ĥψ 决定未测量时的确定性演化，能量量子化由此自然涌现。
- **叠加态是真实的同时存在**，可用干涉检验；测量时按 |cᵢ|² 随机坍缩；宏观叠加被环境退相干极快压制，但退相干没有完全解决测量问题。
- **不确定性原理 Δx·Δp ≥ ħ/2** 是量子态的内在性质（本质上是傅里叶性质），它带来原子稳定性、零点能、谱线自然宽度。
- **量子隧穿**解释了 α 衰变、恒星核聚变，并催生 STM、闪存、约瑟夫森结等技术。
- **量子纠缠不允许超光速通信**，但它违反了贝尔不等式，实验（阿斯佩、克劳泽、蔡林格，2022 诺贝尔奖）排除了局域隐变量理论。
- **量子计算的核心是干涉放大正确解**：Shor 算法威胁 RSA，Grover 算法平方根加速搜索；当前处于 NISQ 阶段，容错是最大瓶颈。
- **要区分「实验事实」「数学形式」与「诠释争论」**：前两者精度极高、已成工程基础；后者仍开放，是活跃研究而非已决问题。
