# 电磁学

> 电磁学研究电荷、电场、磁场及其相互作用，以及它们如何统一为电磁波。从闪电到手机，从电动机到 GPS，电磁学是现代文明的底层物理。本文面向成人通识，重思想与实例。

## 导语

电和磁曾被认为是两种独立现象。19 世纪，奥斯特发现电生磁，法拉第发现磁生电，麦克斯韦用一组方程把它们统一，并预言光就是电磁波。今天我们知道：可见光、无线电、X 射线本质相同，只是频率不同。电磁学是物理学最漂亮的统一之一。

## 一、电荷与电场

### 1.1 电荷的基本性质

| 性质 | 说明 |
| --- | --- |
| 两种电荷 | 正、负（富兰克林命名） |
| 量子化 | 电荷是元电荷的整数倍 |
| 守恒 | 电荷总量守恒，不能凭空产生 |
| 异号相吸、同号相斥 | 库仑定律 |

**元电荷 e = 1.602176634×10⁻¹⁹ C**（2019 SI 重定义后精确值，来源：NIST CODATA 2022）。

### 1.2 库仑定律

**F = k·q₁q₂ / r²**（k = 1/(4πε₀)）

| 符号 | 含义 |
| --- | --- |
| q₁, q₂ | 点电荷电量 |
| r | 距离 |
| ε₀ | 真空介电常数 |

**真空介电常数 ε₀ = 8.8541878128(13)×10⁻¹² F/m**（来源：NIST CODATA 2022）。

### 1.3 电场

电荷周围存在电场，对其他电荷施加力。**电场强度 E = F/q**。

- 电场线从正电荷出发、终止于负电荷。
- 静电场的高斯定律：穿过闭合曲面的电通量正比于包围的净电荷（来源：维基百科「高斯定律」）。

## 二、电势与电容

### 2.1 电势（电压）

电势差是单位电荷的电势能差，单位伏特（V）。**1 V = 1 J/C**。

- 电池提供电势差（如 1.5 V、9 V、220 V）。
- 电势差驱动电荷移动形成电流。

### 2.2 电容

电容 C 储存电荷：Q = C·U，单位法拉（F）。

| 应用 | 说明 |
| --- | --- |
| 电容器 | 滤波、储能、调谐 |
| 闪光灯 | 瞬间放电 |
| 电脑内存 | 暂存比特 |

---

## 三、电流与电路

### 3.1 电流

电荷的定向移动形成电流，单位安培（A）。**1 A = 1 C/s**。

### 3.2 欧姆定律

**I = U/R**（电流 = 电压 / 电阻）

| 符号 | 含义 | 单位 |
| --- | --- | --- |
| I | 电流 | A |
| U | 电压 | V |
| R | 电阻 | Ω（欧姆） |

### 3.3 电阻与电阻率

R = ρL/A（ρ 为电阻率，随温度变）。

| 材料 | 电阻率 | 用途 |
| --- | --- | --- |
| 铜 | 低 | 导线 |
| 橡胶 | 极高 | 绝缘 |
| 炭 | 中 | 电阻器 |

### 3.4 电功率

**P = UI = I²R = U²/R**，单位瓦（W）。

- 大功率电器电流大，需粗导线。
- 焦耳热：电能→内能（Q = I²Rt），电炉、白炽灯原理。

### 3.5 串并联

| 连接 | 电流 | 电压 | 等效电阻 |
| --- | --- | --- | --- |
| 串联 | 相同 | 分压 | 相加 R总 = R₁+R₂ |
| 并联 | 分流 | 相同 | 1/R总 = 1/R₁+1/R₂ |

## 四、磁场

### 4.1 磁的基本现象

- 磁极：N、S，同极相斥异极相吸。
- 不存在孤立磁单极（磁场高斯定律：磁通量恒为 0，来源：维基百科）。
- 地球是巨大磁体，指南针指向地磁极。

### 4.2 电流的磁效应（奥斯特，1820）

通电导线周围产生磁场——电生磁。

| 装置 | 原理 |
| --- | --- |
| 螺线管（电磁铁） | 电流产生强磁场，可开关 |
| 电动机 | 通电导体在磁场受力转动 |
| 扬声器 | 电流→磁场力→振动发声 |

### 4.3 安培力与洛伦兹力

- 通电导线在磁场受力：**F = BIL**（B 为磁感应强度，单位特斯拉 T）。
- 运动电荷受力（洛伦兹力）：F = qvB，方向由左手定则。

## 五、电磁感应（法拉第）

> 闭合回路中磁通量变化，会产生感应电动势。（来源：维基百科「法拉第电磁感应定律」、阿里云物理定律汇总）

**ε = −dΦ/dt**（负号体现楞次定律：感应电流总是阻碍磁通变化）。

### 5.1 应用

| 装置 | 原理 |
| --- | --- |
| 发电机 | 线圈在磁场转动→感应电 |
| 变压器 | 互感改变电压 |
| 感应炉 | 涡流加热 |
| 信用卡读头 | 磁条变化感应信号 |

### 5.2 发电机 vs 电动机

- 电动机：电→磁→机械运动。
- 发电机：机械运动→磁变化→电。
- 本质互为逆过程。

### 5.3 麦克斯韦的突破

麦克斯韦加入「位移电流」，预言变化的电场产生磁场，从而电磁波可自我维持传播。1865 年统一电磁学（来源：IASPoint、维基百科「麦克斯韦方程组」）。

## 六、电磁波谱

变化的电磁场在空间以光速传播，即电磁波。所有频率的电磁波在真空都以 **c = 299792458 m/s** 传播（来源：BIPM 精确值）。

**c = 1/√(μ₀ε₀) ≈ 3×10⁸ m/s**

波速、波长、频率关系：**c = λ·f**，光子能量 **E = hf = hc/λ**（h 为普朗克常数）。

### 6.1 波段一览

| 波段 | 波长 | 频率 | 主要来源/应用 |
| --- | --- | --- | --- |
| 无线电波 | > 1 mm（可达 km） | < 300 GHz | 广播、电视、通信、雷达、GPS |
| 微波 | 1 mm – 1 m | 300 MHz – 300 GHz | 微波炉、Wi-Fi、卫星通信 |
| 红外 | 750 nm – 1 mm | 300 GHz – 400 THz | 遥控、热成像、夜视 |
| 可见光 | 约 380–780 nm | 约 400–790 THz | 人眼视觉、 photosynthesis |
| 紫外 | 10 – 400 nm | 750 THz – 30 PHz | 杀菌、荧光、维生素 D |
| X 射线 | 0.01 – 10 nm | 30 PHz – 30 EHz | 医学影像、安检、晶体学 |
| 伽马射线 | < 0.01 nm | > 30 EHz | 核过程、放疗、天文 |

（波长/频率边界为惯例划分，非严格物理界限；来源：GoPhotonics、IASPoint、维基百科「电磁频谱」）

### 6.2 电离与非电离

- 紫外（强）、X、伽马属**电离辐射**，可使原子失电子、损伤 DNA，需防护。
- 无线电、微波、红外、可见光为**非电离**，一般只加热。

### 6.3 光速为什么是上限

电磁波由 Maxwell 方程定出速度 c，与光源运动无关——这直接催生了狭义相对论（见《相对论与时空》）。

## 七、家用电路与安全

### 7.1 交流电与直流电

| 类型 | 特点 | 应用 |
| --- | --- | --- |
| 直流 DC | 方向不变 | 电池、电子、电动车 |
| 交流 AC | 方向周期变（50/60 Hz） | 市电、输电（易变压） |

我国家用市电为 **220 V、50 Hz**（来源：国标；人教版物理）。

### 7.2 家庭配电基本元件

| 元件 | 作用 |
| --- | --- |
| 火线/零线/地线 | 火线带电，零线回路，地线保命 |
| 断路器（空气开关） | 过流自动跳闸 |
| 漏电保护器 | 漏电（火零电流差）跳闸 |
| 保险丝 | 过流熔断 |
| 接地 | 把漏电导入大地，防触电 |

### 7.3 安全要点

- 湿手不碰电：水导电，电阻骤降→电流大增。
- 不超负荷：多电器同插排易过载起火。
- 金属外壳接地：一旦漏电，电流走地线而非人体。
- 远离高压：电弧可跨越空气。
- 雷雨天避开阔地、不靠金属。

### 7.4 功率与电流估算

220 V 下，1000 W 电器电流约 4.5 A（I = P/U）。大功率（空调、电热水器）需专线。

### 7.5 常见误区

| 误区 | 正解 |
| --- | --- |
| 零线不带电可随意碰 | 断零或故障零线可能带电 |
| 电压高才危险 | 电流才是致命关键（毫安级可致命） |
| 绝缘手套湿了仍安全 | 湿手套导电失效 |
| 拔插头拉电线 | 易损线皮引发短路 |

## 八、电场深入：电势能与电场线

### 8.1 电势能

电荷在电场中具有电势能，移动电荷电场力做功等于电势能变化。电势（电压）是单位电荷的电势能。

### 8.2 电场线规则

- 起于正电荷、止于负电荷（或无穷远）。
- 不相交；密处场强、疏处场弱。
- 是人为辅助工具，非真实线。

### 8.3 静电屏蔽

导体空腔可屏蔽外部电场（法拉第笼）——内部电场为零。应用：电梯/车厢信号弱、屏蔽服、机房防干扰。

### 8.4 静电现象

| 现象 | 原因 |
| --- | --- |
| 梳子吸纸 | 摩擦起电 |
| 闪电 | 云层电荷积累放电 |
| 复印/喷墨 | 静电吸附墨粉 |
| 油罐车拖铁链 | 导走静电防起火 |

## 十、电磁波的产生与传播

### 10.1 怎么产生

加速的电荷辐射电磁波。天线中交变电流→变化的电场→变化的磁场→自我维持向外传播（来源：IASPoint）。

### 10.2 横波结构

电场 E 与磁场 B 互相垂直，且都垂直于传播方向——电磁波是**横波**。

### 10.3 在介质中

- 真空最快 c；入介质变慢（v = c/n，n 为折射率）。
- 频率由源决定，传播中不变；波长随速度变。
- 折射、反射、干涉、衍射都适用于电磁波（详见《光学与波动》）。

### 10.4 能量与动量

电磁波携能流（坡印廷矢量）与动量，照到物体有微弱辐射压力（太阳帆原理）。

## 十一、输电与变压器

### 11.1 为何用交流高压输电

输电线损耗 P_损 = I²R。为减小损耗，升压降电流（P = UI 不变），到户再降压。变压器靠互感实现交流变压（来源：维基百科「变压器」）。

### 11.2 直流输电补充

长距离特高压直流（HVDC）损耗更低、无需同步，现代电网混合使用。

## 十七、小结

- 电荷量子化，库仑定律描述静电力；电场是电荷周围的作用场。
- 电流由电压驱动（欧姆定律），电阻决定难易；电功率 P = UI。
- 电流产生磁场（奥斯特），磁场变化感应电流（法拉第），二者由麦克斯韦方程组统一。
- 电磁波以光速传播，频谱从无线电到伽马射线连续；可见光只是其中窄带。
- 家庭用电 220 V/50 Hz，安全靠接地、漏保、不超载。
- 电磁学支撑了发电、通信、医疗影像、交通等现代文明全部关键领域。

## 十八、麦克斯韦方程组详解

麦克斯韦方程组是电磁学的数学核心，由四个方程统一描述电场与磁场的关系（来源：维基百科「麦克斯韦方程组」）。

| 方程 | 名称 | 物理含义 |
| --- | --- | --- |
| ∮E·dA = Q/ε₀ | 高斯电场定律 | 电荷是电场的源，电场线从正电荷出发终止于负电荷 |
| ∮B·dA = 0 | 高斯磁场定律 | 不存在磁单极，磁力线永远闭合 |
| ∮E·dl = −dΦ_B/dt | 法拉第电磁感应定律 | 变化的磁场产生电场（电动机/发电机原理） |
| ∮B·dl = μ₀I + μ₀ε₀·dΦ_E/dt | 安培-麦克斯韦定律 | 电流和变化的电场都能产生磁场 |

- **位移电流**：麦克斯韦的关键创新——变化的电场等效为电流，使方程组自洽。
- **电磁波预言**：从方程组可推导出电磁波速度 v = 1/√(μ₀ε₀) ≈ c，证明光就是电磁波。
- **对称性**：四个方程体现了电场与磁场的高度对称，只有磁单极缺失导致不对称。

> 来源：维基百科「麦克斯韦方程组」；费曼物理学讲义第二卷。

## 十九、无线电通信原理

无线电通信利用电磁波传递信息，核心过程为**调制→发射→传播→接收→解调**。

| 步骤 | 说明 |
| --- | --- |
| 调制 | 将低频信号（声音/数据）加载到高频载波上 |
| 发射 | 天线将交变电流转化为电磁波辐射 |
| 传播 | 电磁波经地波、天波或视距传播 |
| 接收 | 天线感应电磁波产生微弱电流 |
| 解调 | 从载波中提取原始信号 |

**调制方式对比**：

| 方式 | 原理 | 特点 |
| --- | --- | --- |
| AM（调幅） | 改变载波振幅 | 简单、覆盖远、易受干扰 |
| FM（调频） | 改变载波频率 | 抗干扰强、音质好、覆盖较近 |
| 数字调制 | 改变相位/幅度编码 0/1 | 高效、保密、支持数据业务 |

- **频段分配**：各国政府统一管理频谱资源，避免互扰。例如 FM 广播 88–108 MHz，Wi-Fi 2.4/5 GHz。
- **5G 通信**：使用毫米波（24–100 GHz）实现高速率，但覆盖距离短、穿透力弱。

> 来源：维基百科「无线电通信」；ITU 频谱分配文件。

## 二十、超导体简介

某些材料在降温到**临界温度 T_c**以下时，电阻突然降为零，同时完全排斥磁场（迈斯纳效应），称为**超导体**（来源：维基百科「超导电性」）。

| 特性 | 说明 |
| --- | --- |
| 零电阻 | 电流无损耗流动，可产生极强磁场 |
| 迈斯纳效应 | 磁场被完全排出体外，可实现磁悬浮 |
| 临界温度 T_c | 不同材料差异极大（汞 4.2 K，铜氧化物可达 130 K 以上） |
| 临界磁场 H_c | 超过此值超导态被破坏 |

**超导体分类**：

| 类型 | 特点 | 例子 |
| --- | --- | --- |
| Ⅰ型（低温） | 完全排斥磁场 | 汞、铅、铌 |
| Ⅱ型（高温） | 允许磁通以量子涡旋形式穿透 | YBCO、铁基超导 |

**应用前景**：

| 领域 | 应用 |
| --- | --- |
| 医疗 | MRI 超导磁体 |
| 交通 | 超导磁悬浮列车 |
| 科研 | 粒子加速器超导磁体 |
| 能源 | 超导输电（零损耗） |
| 计算 | 超导量子比特（量子计算） |

**室温超导的追求**：目前尚未实现常压室温超导，2023 年 LK-99 事件引发热议但未被证实。

> 来源：维基百科「超导电性」；中科院物理研究所超导科普。

## 二十一、等离子体：物质的第四态

物质在极高温度或强电场下，原子中的电子脱离核束缚，形成由**自由电子和离子**组成的电离气体，称为**等离子体**（来源：维基百科「等离子体」）。

| 特性 | 说明 |
| --- | --- |
| 电中性 | 整体呈电中性，但微观高度电离 |
| 导电性 | 可导电，受电磁场强烈影响 |
| 集体行为 | 表现出波、振荡等集体运动 |

**常见等离子体**：

| 来源 | 温度 | 例子 |
| --- | --- | --- |
| 太阳/恒星 | 数百万 K | 太阳风、日冕 |
| 闪电 | ~30000 K | 闪电通道 |
| 荧光灯/霓虹灯 | 数千 K | 气体放电 |
| 核聚变实验 | 上亿 K | 托卡马克装置 |

**应用**：

| 应用 | 原理 |
| --- | --- |
| 等离子电视 | 紫外激发荧光粉发光 |
| 等离子切割 | 高温等离子弧熔化金属 |
| 芯片制造 | 等离子刻蚀纳米级电路 |
| 核聚变 | 磁约束等离子体实现聚变反应 |

> 来源：维基百科「等离子体」；《等离子体物理导论》。
