# 光学与波动

> 光学研究光的产生、传播、与物质相互作用以及成像规律。它既是最古老的物理学科之一，也是量子力学与相对论的两大发源地——光的速度定义了时空的尺度，光的量子性开启了微观世界的大门。本文面向成人通识，从「看得见的反射折射」讲到「看不见的激光与光纤」，重思想与实例，轻繁琐推导。

## 导语

你每天睁眼的第一件事就是接收光。阳光穿过大气变蓝，镜子反射你的脸，眼镜矫正视力，手机屏幕用偏振片控制明暗，光纤把亿万条信息送进你的路由器——这些现象背后，是同一套「光的物理学」。

光学有一个特殊之处：它同时需要两套描述方式。

- 当光与尺度远大于波长的物体打交道时（镜子、透镜、水面），用**光线模型**（几何光学）就够了，简单、精确、可计算。
- 当光遇到与波长可比的微小结构时（细缝、光栅、薄膜），必须用**波动模型**（波动光学）才能解释干涉、衍射、偏振。
- 当光与单个原子、电子交换能量时（光电效应、荧光、激光），又必须用**粒子模型**（光子）——这是量子力学的起点。

三种模型不是互相取代，而是**互补**。本文的脉络是：先讲光的本性之争，再讲几何光学（成像），然后讲波动光学（干涉衍射偏振），接着讲颜色与光谱，最后落到两项改变世界的技术——激光与光纤。

## 一、光是什么：一部认识史

人类对光的理解经历了三次大转折，每次转折都改写了一个时代的物理学。

| 阶段 | 主流观点 | 代表人物/年代 | 关键证据 |
| --- | --- | --- | --- |
| 古代—17 世纪 | 视觉由眼睛发出「视线」 | 欧几里得、托勒密 | 直觉与几何作图 |
| 17 世纪 | 微粒说 vs 波动说 | 牛顿（微粒，1704《光学》）vs 惠更斯（波动，1690） | 直线传播 vs 干涉 |
| 19 世纪初 | 波动说胜出 | 托马斯·杨（1801 双缝干涉）、菲涅耳 | 干涉、衍射、偏振 |
| 19 世纪中 | 光是电磁波 | 麦克斯韦（1865 理论）、赫兹（1887 实验） | 电磁波速度等于光速 |
| 20 世纪初 | 波粒二象性 | 普朗克（1900）、爱因斯坦（1905） | 黑体辐射、光电效应 |

### 1.1 惠更斯原理

> 波前上的每一点都可看作新的子波源，这些子波的包络面就是新的波前。（来源：维基百科「惠更斯－菲涅耳原理」）

这个看似简单的几何构造，能推出反射定律、折射定律（斯涅尔定律），也能解释衍射——波为什么会「绕过」障碍物边缘。它是波动光学的第一块基石。

### 1.2 光速：宇宙的速度上限

| 项目 | 数值 | 来源 |
| --- | --- | --- |
| 真空光速 c | **299 792 458 m/s** | 2019 年 SI 定义为精确值（BIPM / NIST SP 330） |
| 近似值 | 3.00×10⁸ m/s | 教学常用 |
| 光在空气中的速度 | 约 c / 1.0003 | 空气折射率约 1.0003 |
| 光在水中的速度 | 约 c / 1.33 ≈ 2.25×10⁸ m/s | 水的折射率 1.333 |
| 光在玻璃中的速度 | 约 c / 1.5 ≈ 2.0×10⁸ m/s | 普通玻璃折射率约 1.5 |

**重要提醒**：1983 年以前，米是实物基准；1983 年起，**米被定义为光在真空中 1/299 792 458 秒内传播的距离**——也就是说，光速从「被测的量」变成了「定义单位的量」。2019 年新 SI 沿用此定义（来源：BIPM 第 26 届国际计量大会决议 1）。

### 1.3 波的基本量

| 量 | 符号 | 关系 | 单位 |
| --- | --- | --- | --- |
| 波长 | λ | 一个完整波形的长度 | 米（m），光常用纳米 nm |
| 频率 | f 或 ν | 每秒振动次数 | 赫兹（Hz） |
| 周期 | T | T = 1/f | 秒（s） |
| 波速 | v | **v = λf** | m/s，真空中 v = c |
| 波数 | k | k = 2π/λ | rad/m |
| 角频率 | ω | ω = 2πf | rad/s |

**关键推论**：光从空气进入水，频率**不变**（由光源决定），速度变小，因此**波长变短**（λ = v/f）。这解释了为什么水中光的颜色不变，但折射率与波长有关。

### 1.4 横波与偏振的伏笔

光是**横波**：电场与磁场都垂直于传播方向振动。声波在空气中是**纵波**（振动方向与传播方向平行）。这个差别决定了「偏振」只对光（横波）成立，对声波不成立——这是 19 世纪波动说击败微粒说的关键证据之一。

## 二、几何光学：把光当作光线

几何光学（射线光学）的前提是：**当障碍物、孔径的尺度远大于波长时**，光近似沿直线传播，可以把光抽象为「光线」。

### 2.1 四条基本规律

| 规律 | 内容 |
| --- | --- |
| 光的直线传播 | 均匀介质中光沿直线传播（影子、小孔成像、日食） |
| 光的独立传播 | 两束光相交后各自继续传播，互不干扰 |
| 光的反射定律 | 反射光线、入射光线、法线共面；反射角 = 入射角 |
| 光的折射定律 | n₁sinθ₁ = n₂sinθ₂（斯涅尔定律） |

### 2.2 光线模型的适用边界

| 现象 | 光线模型能否解释 | 说明 |
| --- | --- | --- |
| 镜子成像 | 能 | 反射定律 |
| 凸透镜成像 | 能 | 折射定律 + 逐次折射 |
| 彩虹 | 部分能 | 需要折射 + 色散 |
| 肥皂泡彩色 | 不能 | 需薄膜干涉（波动光学） |
| 光盘彩色反光 | 不能 | 需光栅衍射（波动光学） |
| 分辨率极限 | 不能 | 需衍射极限（瑞利判据） |

**一句话记法**：几何光学管「光线往哪走」，波动光学管「光能不能看见、有多亮」。

## 三、光的反射

### 3.1 反射定律

> 入射光线、反射光线与法线在同一平面内；反射光线与入射光线分居法线两侧；反射角等于入射角。（来源：人教版高中物理选修）

### 3.2 两种反射

| 类型 | 条件 | 结果 | 例子 |
| --- | --- | --- | --- |
| 镜面反射 | 表面粗糙度 ≪ 波长 | 平行光反射后仍平行 | 平面镜、抛光金属、静水面 |
| 漫反射 | 表面粗糙度 ≳ 波长 | 平行光反射后射向各方向 | 白纸、墙壁、布料、月球表面 |

**常见误区**：「漫反射看起来没有反射」——错。漫反射同样遵守反射定律，只是每个微面朝向不同，所以整束光被打散。我们能从任何角度看见非发光物体，靠的正是漫反射。

### 3.3 平面镜成像

| 特征 | 说明 |
| --- | --- |
| 像的性质 | 正立、等大、虚像 |
| 像的位置 | 与物到镜面距离相等，在镜后对称处 |
| 左右关系 | 前后对称造成的「左右互换」错觉 |
| 像的大小 | 与物始终相等，与距离无关 |

**应用与现象**：镜子不改变物体大小，所以「走近镜子像变大」是错觉（视角变大）；潜望镜、自行车反光片、后视镜（凸面镜扩大视野）、牙医额镜（凹面镜聚光）都是用反射。

### 3.4 球面镜

| 类型 | 形状 | 对光的作用 | 焦点 | 典型用途 |
| --- | --- | --- | --- | --- |
| 凹面镜 | 内表面反射 | 会聚 | 实焦点，f = R/2 | 手电筒、望远镜、太阳灶 |
| 凸面镜 | 外表面反射 | 发散 | 虚焦点，在镜后 | 汽车后视镜、路口广角镜 |

**球面镜成像公式**（近轴条件）：1/f = 1/u + 1/v，其中 u 为物距、v 为像距（国内教材常用「1/u + 1/v = 1/f」符号约定，使用时须统一符号规则）。

### 3.5 反射的日常现象

| 现象 | 原理 |
| --- | --- |
| 水中倒影 | 水面镜面反射，伴随微弱折射 |
| 黑板「反光」看不清 | 镜面反射把光集中射向某一角度 |
| 月亮会发光吗 | 不发光，反射太阳光（漫反射） |
| 逆光看手机屏刺眼 | 屏幕与外界光的镜面反射叠加 |
| 夜间的路标很亮 | 逆反射材料把光沿原路返回 |
| 湖面比路面更远看清水底 | 平静水面反射强，且折射使底变浅 |

## 四、光的折射与斯涅尔定律

### 4.1 折射定律

> **n₁ sinθ₁ = n₂ sinθ₂**（来源：维基百科「斯涅尔定律」，亦称 Snell–Descartes 定律）

| 符号 | 含义 |
| --- | --- |
| n₁, n₂ | 两介质的折射率 |
| θ₁ | 入射角（相对法线） |
| θ₂ | 折射角（相对法线） |

### 4.2 折射率

折射率 n = c / v，表示光在介质中「变慢」的倍数。

| 介质 | 折射率 n（约，589 nm） |
| --- | --- |
| 真空 | 1（精确定义） |
| 空气（标准状态） | 1.000 293 |
| 水 | 1.333 |
| 乙醇 | 1.361 |
| 石英/熔融石英 | 1.458 |
| 普通玻璃（冕牌） | 约 1.5 |
| 聚碳酸酯 | 约 1.585 |
| 蓝宝石 | 约 1.77 |
| 金刚石 | 2.417 |
| 硅（红外） | 约 3.5 |

（来源：维基百科「折射率」；数值随波长与温度略有变化，故严格值须注明波长。）

### 4.3 折射的方向规则

| 情形 | 光线偏折 |
| --- | --- |
| 光疏 → 光密（空气→水） | 折射角 < 入射角，靠近法线 |
| 光密 → 光疏（水→空气） | 折射角 > 入射角，远离法线 |
| 垂直入射（θ₁ = 0） | 不偏折，但速度仍改变 |
| 折射率越大 | 偏折越厉害 |

### 4.4 折射的日常现象

| 现象 | 原理 |
| --- | --- |
| 筷子在水中「折断」 | 水面两侧折射率不同，视线方向被改变 |
| 水中的鱼看起来更浅 | 折射使物体的视深约为实深的 1/n |
| 游泳池看起来更浅 | 同上，安全隐患来源 |
| 海市蜃楼 | 空气温度梯度形成连续折射，光被弯曲 |
| 沙漠公路「水面」 | 下方热空气折射率低，形成全反射假象 |
| 星星闪烁 | 大气湍流使折射率随机起伏 |
| 眼镜矫正视力 | 用透镜的折射把像重新聚焦到视网膜 |

### 4.5 视深的定量关系

从正上方观察，物体在水中的视深 h′ 与实深 h 近似满足 **h′ ≈ h / n**。对 n = 1.33 的水，1.5 米深的池底看起来只有约 1.13 米深——这正是「水看起来比实际浅」的量化表达，也是池边警示牌反复提醒的原因。

## 五、全反射与临界角

### 5.1 临界角

当光从光密介质射向光疏介质，入射角增大到某值时折射角达到 90°，此后不再有折射光，全部被反射回原介质——这就是**全反射**。

临界角公式：**sinθ_c = n₂ / n₁**（n₁ > n₂）

| 界面 | 临界角（约） |
| --- | --- |
| 水 → 空气 | 48.8° |
| 普通玻璃 → 空气 | 41.8° |
| 金刚石 → 空气 | 24.4° |

（来源：维基百科「全反射」；数值由 sinθ_c = 1/n 计算，n_水=1.333、n_玻璃≈1.5、n_金刚石=2.417。）

### 5.2 全反射的应用

| 应用 | 原理 |
| --- | --- |
| 光纤通信 | 纤芯折射率高于包层，光在界面全反射「之」字形前进 |
| 内窥镜 | 光纤束传像与传光，弯曲也不漏光 |
| 直角棱镜 | 反射面无需镀膜即可 100% 反射，比镀银更耐久 |
| 潜望镜 | 棱镜全反射改变光路 |
| 双筒望远镜 | 棱镜折叠光路，缩短镜身 |
| 钻石的「火彩」 | 临界角小，光线多次全反射后从顶面射出 |
| 水中看水面像镜子 | 掠射角超过临界角，水面成银镜 |
| 指纹识别（光学式） | 脊线接触玻璃破坏全反射，谷线仍全反射 |

**常见误区**：「光纤是靠内壁镀反光膜导光」——错。光纤靠**折射率差 + 全反射**导光，这是它几乎无损耗、可绕弯、可拉数万公里的原因。

## 六、透镜与成像

### 6.1 两类透镜

| 类型 | 外形 | 对光 | 焦点 | 成像特点 |
| --- | --- | --- | --- | --- |
| 凸透镜（会聚） | 中间厚边缘薄 | 会聚 | 实焦点，f > 0 | 可成实像或虚像 |
| 凹透镜（发散） | 中间薄边缘厚 | 发散 | 虚焦点，f < 0 | 只成缩小的虚像 |

### 6.2 三条特殊光线（作图法）

| 光线 | 出射方向 |
| --- | --- |
| 平行于主光轴 | 过焦点（凸）／反向延长过虚焦点（凹） |
| 过光心 | 方向不变，沿直线传播 |
| 过焦点入射（凸） | 出射后平行于主光轴 |

### 6.3 凸透镜成像规律

| 物距 u | 像距 v | 像的性质 | 应用 |
| --- | --- | --- | --- |
| u > 2f | f < v < 2f | 倒立、缩小、实像 | 照相机、人眼 |
| u = 2f | v = 2f | 倒立、等大、实像 | 测焦距的基准位 |
| f < u < 2f | v > 2f | 倒立、放大、实像 | 投影仪、幻灯机 |
| u = f | 不成像 | 折射光平行射出 | 探照灯（逆用） |
| u < f | |v| > u，同侧 | 正立、放大、虚像 | 放大镜 |

### 6.4 成像公式与放大率

**薄透镜成像公式**：1/f = 1/u + 1/v　（国内教材约定，符号规则以教材为准）

**放大率**：m = v / u　（|m| > 1 放大，|m| < 1 缩小，负号表示倒立）

| 量 | 含义 |
| --- | --- |
| f | 焦距（凸正凹负） |
| u | 物距（物到光心） |
| v | 像距（像到光心） |
| m | 横向放大率 |

### 6.5 实像与虚像

| 比较 | 实像 | 虚像 |
| --- | --- | --- |
| 形成 | 光线实际会聚 | 光线反向延长线会聚 |
| 能否用屏承接 | 能 | 不能 |
| 正倒 | 通常倒立（凸透镜） | 正立 |
| 眼睛能否看见 | 能 | 能（因为进入眼睛的光线看起来来自像点） |
| 例子 | 照相机底片、投影幕 | 平面镜、放大镜、近视镜 |

### 6.6 眼睛与视力矫正

| 结构 | 相当于 | 作用 |
| --- | --- | --- |
| 角膜 + 晶状体 | 凸透镜组合 | 会聚光线 |
| 瞳孔 | 可变光阑 | 控制进光量（约 f/2 至 f/8 级） |
| 视网膜 | 感光屏 | 成像并转成神经信号 |
| 睫状肌 | 自动对焦马达 | 改变晶状体曲率实现调节 |

| 视力问题 | 成因 | 矫正 |
| --- | --- | --- |
| 近视 | 眼球过长或晶状体过强，像成在视网膜前 | 凹透镜（发散） |
| 远视 | 眼球过短或晶状体过弱，像成在视网膜后 | 凸透镜（会聚） |
| 老花 | 晶状体弹性下降，调节能力弱 | 凸透镜（阅读镜） |
| 散光 | 角膜曲率不对称 | 柱面镜（环曲面镜片） |

**健康提示**：本节仅为物理学原理说明，不构成任何医疗建议；视力问题请就医验光配镜。

## 七、光学仪器

### 7.1 成像类仪器

| 仪器 | 核心光学元件 | 特点 |
| --- | --- | --- |
| 放大镜 | 单凸透镜 | 物在焦距内，成正立放大虚像 |
| 显微镜 | 物镜 + 目镜（两次放大） | 放大倍数 = 物镜倍数 × 目镜倍数 |
| 开普勒望远镜 | 两凸透镜 | 成倒立像，视场大 |
| 伽利略望远镜 | 凸 + 凹 | 成正立像，视场小 |
| 牛顿反射望远镜 | 凹面镜 + 平面镜 | 无色差，口径可做得很大 |
| 照相机 | 镜头组 + 光圈 + 快门 | 实像落在传感器上 |
| 投影仪 | 凸透镜 | 物在 f 与 2f 之间，成放大实像 |

### 7.2 望远镜的关键指标

| 指标 | 含义 | 与什么有关 |
| --- | --- | --- |
| 口径 D | 主镜/物镜直径 | 决定集光能力与理论分辨率 |
| 焦距 f | 主镜焦距 | 与目镜配合决定放大率 |
| 放大率 | f_物 / f_目 | 越大像越大但视场越小 |
| 理论分辨率 | θ ≈ 1.22 λ/D | 口径越大分辨率越高（瑞利判据） |
| 集光面积 | ∝ D² | 口径翻倍，集光增强 4 倍 |

**为什么望远镜越做越大？** 因为角分辨率 θ ≈ 1.22λ/D，口径 D 越大，能分辨的细节越细，同时集光能力按 D² 增长。这就是大型天文望远镜口径竞赛的物理原因。

### 7.3 分辨率的极限

光学显微镜的分辨极限约为 λ/(2NA)，对可见光（约 550 nm）约为 200 nm 量级——比波长更小的细节无法直接成像。突破这一限制需要：

| 技术 | 思路 |
| --- | --- |
| 电子显微镜 | 用电子德布罗意波，波长可短至皮米 |
| 超分辨荧光显微 | 用荧光开关与算法突破衍射极限（2014 年诺贝尔化学奖相关） |
| 近场光学 | 在近场（小于波长距离）探测倏逝波 |
| X 射线晶体学 | 用更短波长的 X 射线衍射重建原子位置 |

## 八、光的干涉

干涉是**波动性最直接的证据**：两列波叠加，波峰遇波峰则加强（相长），遇波谷则抵消（相消）。

### 8.1 相干条件

| 条件 | 说明 |
| --- | --- |
| 频率相同 | 否则拍频、条纹移动 |
| 相位差恒定 | 否则条纹随机 |
| 振动方向相近 | 偏振方向差异会降低对比度 |

普通灯泡、太阳光各点相位随机，是**非相干光**；激光的相干性极好，因此干涉实验多用激光。

### 8.2 杨氏双缝干涉

1801 年，托马斯·杨用双缝实验证明光的波动性（来源：维基百科「双缝实验」）。单色光经两条细缝后成为两个相干光源，在屏上形成**等间距明暗条纹**。

| 量 | 关系式 |
| --- | --- |
| 光程差 | Δ = d sinθ |
| 相长（亮纹） | d sinθ = mλ（m = 0, ±1, ±2, …） |
| 相消（暗纹） | d sinθ = (m + ½)λ |
| 条纹间距（小角近似） | **Δy = λL / d** |

其中 d 为缝距、L 为缝到屏距离。

| 变量变化 | 条纹间距变化 |
| --- | --- |
| 波长 λ 变大（红移） | 变宽 |
| 屏距 L 变大 | 变宽 |
| 缝距 d 变大 | 变窄 |
| 白光入射 | 中央为白，两侧彩纹（紫在内、红在外） |

### 8.3 薄膜干涉

| 现象 | 原理 |
| --- | --- |
| 肥皂泡彩色 | 薄膜上下表面反射光干涉，厚度决定颜色 |
| 油膜彩色 | 同上，油与水折射率不同 |
| 增透膜（镜头镀膜） | 膜厚取 λ/4，使反射光相消，提高透光率 |
| 高反膜（激光腔镜） | 多层膜叠加，反射率可达 99.99% |
| 检验光学平面 | 干涉条纹弯曲暴露表面起伏 |
| 牛顿环 | 球面与平面间的空气膜干涉成同心环 |
| 手机屏幕「彩虹纹」 | 保护膜与玻璃间的薄空气层干涉 |

**易错点**：薄膜干涉中，若反射发生在「光疏→光密」界面，会有半波损失（附加 λ/2 相位差），这解释了为什么极薄薄膜中心看起来是暗的。

### 8.4 迈克尔逊干涉仪

用半透半反镜把一束光分成两路，各自反射后重新合并干涉。它既能测微小长度变化（精度到波长量级），也能测光的相干长度，更是 1887 年迈克尔逊－莫雷实验的核心仪器——那次「零结果」为狭义相对论埋下伏笔（详见《相对论与时空》）。

## 九、光的衍射

衍射是波遇到障碍物或小孔时**偏离直线传播、绕到几何阴影区**的现象。缝越窄（与波长可比），衍射越明显。

### 9.1 单缝衍射

| 特征 | 说明 |
| --- | --- |
| 中央亮纹 | 最宽最亮，约为两侧亮纹长度之和 |
| 暗纹条件 | a sinθ = mλ（m = ±1, ±2, …，a 为缝宽） |
| 缝宽 a 变小 | 中央亮纹变宽 |
| 缝宽 a ≫ λ | 退化为几何光学（光沿直线走） |

**与双缝的区别**：单缝干涉的中央是**亮**纹（m 从 1 起有暗纹），双缝的中央也是亮纹——但单缝条纹中间宽两边窄，双缝条纹等间距。这是考试与实验中最常见的混淆点。

### 9.2 圆孔衍射与瑞利判据

望远镜、显微镜、眼睛的孔径都是圆孔，其衍射图是一组同心圆环（艾里斑）。两物点刚能分辨的角距离为：

**θ_min ≈ 1.22 λ / D**

| 系统 | 孔径 D | 极限分辨率（λ = 550 nm） |
| --- | --- | --- |
| 人眼 | 约 2–8 mm | 约 1 角分（60″） |
| 业余望远镜 | 100 mm | 约 1.4″ |
| 大型望远镜 | 10 m | 约 0.014″ |
| 射电 VLBI（地球口径） | 约 10⁷ m | 微角秒级 |

**结论**：分辨率不是「做得更精细」就能提高的，它受波长与口径的双重约束。这也是「苍蝇复眼」能看更宽视野但看不清细节的物理原因。

### 9.3 光栅衍射

多缝（光栅）衍射的亮纹极窄极亮，位置为 d sinθ = mλ，因此能把白光精确展开成光谱。

| 应用 | 原理 |
| --- | --- |
| 光谱仪 | 光栅分光，测元素特征谱线 |
| CD/DVD 彩色反光 | 表面沟槽构成反射光栅 |
| 防伪全息标 | 微结构光栅产生特定角度色彩 |
| 单色仪 | 光栅旋转选出特定波长 |
| 天文光谱 | 分析恒星成分与红移 |

### 9.4 X 射线衍射与晶体结构

晶体中原子间距与 X 射线波长同量级（约 0.1 nm），晶体天然是三维光栅。**布拉格定律 2d sinθ = nλ** 使人们能「看见」DNA 双螺旋、蛋白质结构与金属晶格——DNA 双螺旋的发现正是基于 X 射线衍射照片。

## 十、光的偏振

偏振是横波特有的现象，证明光是横波，并支撑了大量现代技术。

### 10.1 偏振的基本概念

| 概念 | 含义 |
| --- | --- |
| 自然光（非偏振光） | 各方向振动机会均等 |
| 线偏振光 | 电场只在一个平面内振动 |
| 部分偏振光 | 某一方向占优（如散射天光） |
| 圆/椭圆偏振 | 电场矢量端点画圆或椭圆 |

### 10.2 偏振的产生

| 方式 | 说明 |
| --- | --- |
| 偏振片（二向色性） | 只透过平行于透振方向的电场分量 |
| 反射 | 在一定角度下反射光偏振（布儒斯特角） |
| 双折射 | 晶体（如方解石）把光分成两束偏振光 |
| 散射 | 天空散射光部分偏振 |
| 液晶调制 | 电压改变液晶分子取向，旋转偏振态（LCD 原理） |

### 10.3 马吕斯定律

**I = I₀ cos²θ**

| 情形 | 透射强度 |
| --- | --- |
| 自然光过单个偏振片 | I₀/2 |
| 两偏振片夹角 θ | I₀/2 × cos²θ（后者为偏振光时 I₀cos²θ） |
| 两偏振片正交（90°） | 0（全暗） |
| 0°、45°、90° 三片 | I₀/8（意外透光） |

**经典悖论**：两片正交的偏振片之间插入一片 45° 偏振片，光反而能透过来。这不是「违反常识」，而是偏振态被逐级投影的必然结果——也是量子力学中「测量改变状态」的经典类比。

### 10.4 布儒斯特角

反射光在特定入射角下**完全偏振**（振动方向平行于反射面），该角满足 **tanθ_B = n₂/n₁**。对空气－水界面，θ_B ≈ 53.1°。

这正是偏振太阳镜的设计依据：水面、路面、雪面的反光在接近布儒斯特角时偏振最强，镜片的透振方向与之垂直，即可大幅削减眩光。

### 10.5 偏振的应用

| 应用 | 原理 |
| --- | --- |
| 偏振太阳镜 | 滤除水面/路面反射的偏振眩光 |
| LCD 显示屏 | 液晶旋转偏振态 + 前后偏振片调制亮度 |
| 3D 电影 | 左右眼用不同偏振方向区分画面 |
| 摄影偏振镜 | 压暗天空、消除玻璃反光 |
| 应力分析 | 透明模型在偏振光下显出彩色应力条纹 |
| 卫星遥感 | 偏振信息区分云、气溶胶、水面 |
| 量子密钥分发 | 用偏振态编码比特（BB84 协议） |

**常见误区**：「偏振片能滤掉一半光，所以是灰色的」——错。偏振片滤掉的是强度而非颜色，透过的光颜色不变；两片叠加转动时亮度变化而色调不变。

## 十一、色散与颜色

### 11.1 色散

白光被分解成彩色光带的现象叫**色散**。根本原因是**折射率随波长变化**：短波（紫）折射率大、偏折多；长波（红）折射率小、偏折少。

| 演示 | 结果 |
| --- | --- |
| 三棱镜 | 白光→红橙黄绿蓝靛紫（紫偏折最大） |
| 雨滴（彩虹） | 折射 + 内部反射 + 再折射 |
| 钻石 | 强色散形成「火彩」 |
| 透镜 | 色差——不同波长焦点不同（需消色差镜组） |

牛顿 1666 年前后用棱镜证明白光是复合光，并在 1704 年《光学》中系统阐述（来源：维基百科「可见光谱」）。

### 11.2 可见光谱

| 颜色 | 波长范围（nm） | 频率（THz） | 光子能量（eV，约） |
| --- | --- | --- | --- |
| 紫 | 380–450 | 668–789 | 2.75–3.26 |
| 蓝 | 450–495 | 606–668 | 2.50–2.75 |
| 青 | 495–500 | 600–620 | 2.48–2.50 |
| 绿 | 500–565 | 530–600 | 2.19–2.48 |
| 黄 | 565–590 | 508–530 | 2.10–2.19 |
| 橙 | 590–620 | 484–508 | 2.00–2.10 |
| 红 | 620–750 | 400–484 | 1.65–2.00 |

（来源：维基百科「可见光谱」；边界为约定而非物理分界，个体差异可达数十纳米。）

### 11.3 颜色是怎么来的

| 机制 | 原理 | 例子 |
| --- | --- | --- |
| 吸收（选择性吸收） | 物体吸收部分波长，反射其余 | 红苹果反射红光 |
| 发射 | 原子/分子受激发光 | 霓虹灯、LED、焰色反应 |
| 干涉 | 薄膜厚度决定反射波长 | 肥皂泡、蝴蝶翅膀、孔雀羽毛 |
| 衍射 | 微结构光栅分光 | 光盘、某些甲虫外壳 |
| 散射 | 尺度决定散射波长依赖 | 天空蓝、晚霞红、牛奶白 |
| 色心/能带 | 晶体缺陷或能带吸收 | 红宝石、蓝宝石、玻璃着色 |

**关键区分**：
- **减法混色**（颜料）：红 + 绿 = 黑/深棕（吸收叠加）。
- **加法混色**（光）：红 + 绿 = 黄（能量叠加）。
- 屏幕用 RGB 加法混色，印刷用 CMYK 减法混色——理解这一点就不会困惑「为什么红绿颜料混出棕色，红绿光混出黄色」。

### 11.4 三原色与色觉

人眼视网膜有三种视锥细胞，峰值分别约在短波（蓝，约 420 nm）、中波（绿，约 530 nm）、长波（红，约 560 nm）波段（来源：维基百科「视锥细胞」，数值为常用近似）。任何颜色感都是这三路信号的组合——因此用三种基色光就能配出大部分颜色，这是显示技术的生理学基础。

**色盲/色弱**：某一类视锥缺失或敏感度异常，最常见为红绿型。设计图表与标识时避免仅靠红绿区分，是必要的无障碍考量。

### 11.5 色温

黑体辐射的谱峰位置随温度移动（详见《热学与热力学》维恩位移定律）。用黑体温度描述光源「冷暖」感觉，即**色温**。

| 光源 | 色温（K，约） | 视觉感受 |
| --- | --- | --- |
| 烛光 | 1800 | 暖 |
| 白炽灯 | 2700 | 暖白 |
| 卤素灯 | 3000 | 暖白 |
| 日光（正午） | 5500–6500 | 中性白 |
| 阴天 | 6500–7500 | 偏冷 |
| 冷白 LED | 5000–6500 | 冷白 |

注意：色温高≠亮度高，也不等于「质量更好」，只描述光谱分布造成的色调。

## 十二、散射与大气光学

### 12.1 瑞利散射

当散射粒子远小于波长时，散射强度 ∝ **1/λ⁴**（瑞利散射）。蓝光（约 450 nm）比红光（约 650 nm）波长短，散射强度约强 (650/450)⁴ ≈ 4.4 倍——这就是**天空呈蓝色**的原因。

| 现象 | 解释 |
| --- | --- |
| 白天天空蓝 | 蓝光被大气分子强散射，从各方向进入眼睛 |
| 日出日落红 | 阳光斜穿更厚大气，蓝光被散射殆尽，剩红橙 |
| 云是白的 | 水滴远大于波长，属米氏散射，各色均散射 |
| 火星日落偏蓝 | 大气稀薄且尘埃主导散射，机制不同 |
| 太空漆黑 | 无大气散射，只有直线光源可见 |
| 海水蓝色 | 水对红光的吸收 + 少量散射共同作用 |

### 12.2 彩虹的几何

彩虹由**折射 → 一次内反射 → 再折射**形成，主虹的视半径约 42°，副虹（二次内反射）约 51° 且色序相反。因此彩虹总是背对太阳、仰角约 42° 的圆弧——地面上看不到完整的圆，飞机上则可能看到整圈。

### 12.3 其他大气光学现象

| 现象 | 原理 |
| --- | --- |
| 日晕/月晕 | 高空冰晶折射形成 22° 环 |
| 幻日 | 冰晶折射形成的太阳虚像 |
| 佛光（宝光） | 观察者影子方向的背向散射衍射 |
| 绿闪 | 日落最后瞬间大气色散造成 |
| 极光 | 太阳带电粒子激发高层大气原子发光（非光学散射） |

## 十三、光谱与光谱分析

### 13.1 三类光谱

| 类型 | 特征 | 来源 |
| --- | --- | --- |
| 连续谱 | 各波长连续分布 | 炽热固体/液体/高压气体（黑体） |
| 发射（明线）谱 | 暗背景上若干亮线 | 低压稀薄气体放电 |
| 吸收（暗线）谱 | 连续谱上若干暗线 | 连续光源穿过冷气体 |

**基尔霍夫定律**：同一元素能发射哪些波长，就能吸收哪些波长——这是「光谱指纹」的物理基础。

### 13.2 光谱分析的威力

| 应用 | 说明 |
| --- | --- |
| 元素发现 | 铷、铯、氦（先在太阳光谱发现，后在地球找到） |
| 恒星成分 | 分析太阳与遥远恒星元素丰度 |
| 宇宙膨胀 | 星系光谱红移 → 哈勃定律 |
| 化学分析 | 原子吸收光谱、ICP 发射光谱 |
| 食品安全 | 光谱快速检测掺假 |
| 医学诊断 | 血氧仪用红光/红外吸收比测血氧 |
| 天文测速 | 多普勒频移测天体视向速度 |

**氦的发现**：1868 年日全食观测中，太阳色球光谱出现一条未知黄线，后被确认为新元素「氦」（helium，源自太阳 helios）——这是人类**先在天上发现、后在地上证实**的元素，光谱分析力量的经典案例。

## 十四、激光

激光（LASER）是「受激辐射光放大」（Light Amplification by Stimulated Emission of Radiation）的缩写。它的原理是爱因斯坦 1917 年提出的**受激辐射**。

### 14.1 三个关键要素

| 要素 | 作用 |
| --- | --- |
| 增益介质 | 提供可被激发的原子/分子（红宝石、半导体、光纤掺铒等） |
| 泵浦源 | 用光、电或化学能被激发介质到高能态（粒子数反转） |
| 光学谐振腔 | 两面反射镜让光来回振荡、雪崩式放大 |

### 14.2 激光的四大特性

| 特性 | 含义 | 用途 |
| --- | --- | --- |
| 单色性好 | 谱线极窄 | 光谱、原子钟、干涉 |
| 方向性强 | 发散角极小 | 测距、雷达、准直 |
| 亮度高 | 能量高度集中 | 切割、焊接、核聚变点火 |
| 相干性好 | 相位一致，可长距离干涉 | 全息、干涉测量、引力波探测 |

### 14.3 激光发展里程碑

| 年份 | 事件 | 人物 |
| --- | --- | --- |
| 1917 | 提出受激辐射概念 | 爱因斯坦 |
| 1954 | 微波激射器（maser） | 汤斯等 |
| 1958 | 提出激光原理（光频激射器） | 汤斯、肖洛 |
| 1960 | 首台红宝石激光器（694.3 nm 脉冲） | **梅曼**（休斯实验室） |
| 1961 | 氦氖连续激光器 | 贝尔实验室等 |

## 十五、光纤与光通信

### 15.1 光的「管道」

光纤由**纤芯**（高折射率）与**包层**（低折射率）构成，光在界面全反射前进。典型通信光纤外径 125 μm（约为一根头发直径的数十倍分之一量级），纤芯仅数微米。

| 类型 | 纤芯直径 | 特点 |
| --- | --- | --- |
| 多模光纤 | 约 50 或 62.5 μm | 允许多种模式，色散大，适合短距 |
| 单模光纤 | 约 8–10 μm | 只传基模，色散小，适合长距干线 |

### 15.2 为什么用 1.55 μm

石英玻璃在近红外吸收与散射损耗最低，通信窗口主要在：

| 窗口 | 波长 | 特点 |
| --- | --- | --- |
| 第一窗口 | 约 850 nm | 早期多模短距 |
| 第二窗口 | 约 1310 nm | 零色散区 |
| 第三窗口 | 约 1550 nm | **损耗最低**（约 0.2 dB/km），现代长距主流 |

（来源：光纤通信技术资料；掺铒光纤放大器的工作波段正好覆盖 1550 nm，是长距传输的关键。）

### 15.3 光纤发展里程碑

| 年份 | 事件 |
| --- | --- |
| 1966 | 高锟与霍克汉姆发表论文，指出光纤损耗源于杂质，理论上可降至 20 dB/km 以下（高锟获 2009 年诺贝尔物理学奖） |
| 1970 | 康宁公司制出 20 dB/km 低损耗石英光纤，同年室温连续半导体激光器问世 |
| 1974 | 损耗降至约 2 dB/km |
| 1976 | 首个光纤系统现场试验（美国亚特兰大） |
| 1979 | 中国拉出第一根实用化光纤（赵梓森团队，约 4 dB/km） |
| 1988 | 第一条跨大西洋海底光缆 |
| 1990s 起 | 光纤网络全球规模化部署 |

（来源：中国光学光电子行业协会、科技日报等公开资料。）

### 15.4 光纤的容量与优势

| 指标 | 量级 |
| --- | --- |
| 单根光纤承载语音 | 数十万路量级（取决调制与波分） |
| 波分复用（WDM） | 一根光纤中并行数十至上百个波长 |
| 衰减（1550 nm） | 约 0.2 dB/km |
| 带宽 | 远超铜缆，是互联网骨干 |

| 优势 | 说明 |
| --- | --- |
| 带宽大 | 光频约 10¹⁴ Hz，可调制空间巨大 |
| 损耗低 | 中继距离可达数十至上百公里 |
| 抗电磁干扰 | 介质导光，不受电磁噪声影响 |
| 无串扰 | 光纤间几乎不互相干扰 |
| 轻便耐腐 | 玻璃纤维，重量轻、抗腐蚀 |
| 安全性 | 难以无损窃听（弯曲会泄漏，可被检测） |

### 15.5 光纤的其他用途

光纤不只是通信管道，它同样是**传感器**与**光源**：分布式温度/应变传感（桥梁、管道、地震监测）、内窥镜成像、光纤激光器（工业加工主力）、光纤陀螺（导航）等。

## 十六、光的量子性：光子的引入

到这里，波动说已经解释了干涉、衍射、偏振、折射——但有些现象它**无法解释**。

### 16.1 光电效应

紫外光照射金属表面会打出电子。实验事实与波动说矛盾：

| 实验事实 | 波动说的预言 | 实际结果 |
| --- | --- | --- |
| 存在截止频率 | 只要足够强总能打出来 | 低于某频率，再强也没电子 |
| 光电子动能与频率有关 | 与光强有关 | 只与频率成正比 |
| 光电子与光强关系 | 动能随光强增大 | 只增加电子**数量** |
| 瞬时性（约 10⁻⁹ s 内） | 需时间累积能量 | 几乎瞬时 |

爱因斯坦 1905 年提出光量子（光子）假说，每个光子能量 **E = hν**，光电效应方程为：

**hν = W + E_k(max)**　（W 为逸出功）

| 符号 | 含义 |
| --- | --- |
| h | 普朗克常数 6.626 070 15×10⁻³⁴ J·s（SI 精确值） |
| ν | 光频率 |
| W | 逸出功（材料属性） |
| E_k(max) | 光电子最大初动能 |

在光子图像下，一切变得自然：一个电子只能**整份**吸收一个光子的能量；频率不够（单光子能量不足）就打不出电子。这为爱因斯坦赢得 1921 年诺贝尔物理学奖，也为密立根 1916 年的精密验证所证实（密立根获 1923 年诺贝尔奖）。

### 16.2 光子的性质

| 属性 | 表达 |
| --- | --- |
| 能量 | E = hν = hc/λ |
| 动量 | p = h/λ |
| 静质量 | 0（光子无静质量，「光子质量」通常指等效能量质量） |
| 传播速度 | 真空中恒为 c |

**实用换算**：**E(eV) ≈ 1240 / λ(nm)**。绿光 532 nm 的光子能量约 2.33 eV；红光 650 nm 约 1.91 eV；紫外 250 nm 约 4.96 eV——这解释了为什么紫外线能引发许多光化学反应，而红光不能。

### 16.3 康普顿散射

1923 年康普顿发现 X 射线被电子散射后波长变长，且偏移量随散射角变化。只有把光子当作有动量的粒子、与电子做弹性碰撞，才能定量解释——这是光子实在性的又一铁证（1927 年诺贝尔物理学奖）。

### 16.4 波粒二象性与互补原理

光既有波动性（干涉衍射）又有粒子性（光电效应、康普顿散射），但**不能在同一实验中同时显现**。玻尔 1928 年提出**互补原理**：波动性与粒子性是同一客体的两个互补侧面，实验装置决定我们看到哪一面。这一思想是量子力学的哲学支柱之一（详见《量子力学入门》）。

## 十九、常见误区汇总

| 误区 | 正解 |
| --- | --- |
| 漫反射不遵守反射定律 | 同样遵守，只是微面朝向不同 |
| 镜子离得近像就变大 | 像大小不变，是视角变化的错觉 |
| 光纤靠内壁镀反光膜导光 | 靠纤芯/包层折射率差与全反射 |
| 光在水中颜色变了 | 频率不变，颜色不变，只是速度与波长变了 |
| 水面看起来浅是错觉 | 是折射造成的真实视深变化（约 1/n） |
| 偏振片会把光变灰 | 只减少强度，不改变颜色 |
| 干涉和衍射是两回事 | 本质都是波的叠加，只是装置不同 |
| 放大率越高望远镜越好 | 放大率受口径与大气限制，过高反而更模糊 |
| 激光「会拐弯」所以能进光纤 | 直的光被界面全反射「折返」，不是主动拐弯 |
| 色温高就是更亮 | 色温只描述光谱色调，与亮度无关 |
| 紫外线看不见所以无害 | 紫外破坏性强于可见光，须防护 |
| 光子有静质量 | 光子静质量为零，有能量与动量 |

**一个有趣的交汇点**：VLT（甚大望远镜）与 EHT 用「干涉」把多台望远镜连成一体，等效口径可达地球直径；而 LIGO 用 4 公里臂长 + 法布里－珀罗腔把光路折成上千公里等效长度，靠干涉测出 10⁻²¹ 量级的时空应变——光学测量精度的极限被反复推高，如今已成为探测引力波的手段（详见《相对论与时空》）。

## 小结

- **光有三张面孔**：光线（几何光学）、波（波动光学）、粒子（光子）。三者互补，适用场景不同，不要用一张面孔解释所有现象。
- **几何光学四规律**：直线传播、独立传播、反射定律、折射定律（n₁sinθ₁ = n₂sinθ₂）。成像问题都由此推出。
- **全反射是光纤的命门**：光密到光疏且超过临界角时 100% 反射，靠折射率差而非镀膜，这是长距离光通信可行性的根基。
- **透镜成像记住三条特殊光线与一张表**：u > 2f 缩小实像、f < u < 2f 放大实像、u < f 放大虚像。
- **干涉、衍射、偏振是波动性的三重证据**：双缝条纹 Δy = λL/d；衍射极限 θ ≈ 1.22λ/D；马吕斯定律 I = I₀cos²θ。
- **颜色来自六种机制**：吸收、发射、干涉、衍射、散射、能带/色心。屏幕是加法混色，颜料是减法混色。
- **瑞利散射 ∝ 1/λ⁴** 解释了蓝天与红霞；米氏散射解释了白云。
- **激光靠受激辐射 + 粒子数反转 + 谐振腔**，具备单色、方向、亮度、相干四大优势，1960 年梅曼首台红宝石激光器。
- **光纤靠全反射导光**，1550 nm 窗口损耗约 0.2 dB/km，是现代信息社会的物理底座。
- **光子能量 E = hν ≈ 1240/λ(nm) eV**，光电效应把光推向量子世界，是量子力学的第一道门。
