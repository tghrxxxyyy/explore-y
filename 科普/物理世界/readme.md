# 科普 · 物理世界

> 用通俗语言讲清「看得见摸得着」的物理学：力如何改变运动、热量如何流动、电与磁如何统一。面向成人通识，重思想与实例，轻繁琐推导，配套大量生活现象解读与常见误区澄清。

## 阅读建议

1. **零基础**：按 力学 → 热学 → 电磁 顺序阅读，正好对应经典物理学的三大支柱（运动、能量、场）。
2. **按需查阅**：想看懂刹车/球赛物理读《经典力学与运动》；想懂冰箱/空调/恒星发光读《热学与热力学》；想懂手机/电网/变压器读《电磁学》。
3. **交叉关联**：
   - 变压器：电磁感应（《电磁学》）+ 能量守恒（《经典力学与运动》）。
   - 发动机：热机效率（《热学与热力学》）+ 力与运动（《经典力学与运动》）。
   - 超导输电：超导（《电磁学》）+ 第三定律与低温（《热学与热力学》）。
