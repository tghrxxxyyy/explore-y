# 科普 · 物理世界

> 用通俗语言讲清物理学的三条主线：力如何改变运动、热量如何流动、电与磁如何统一，并延伸到光学与波动、量子力学、相对论三大现代支柱。面向成人通识，重思想与实例，轻繁琐推导，配套大量生活现象解读与常见误区澄清。

## 阅读建议

1. **零基础**：按 力学 → 热学 → 电磁 顺序阅读，正好对应经典物理学的三大支柱（运动、能量、场）。
2. **进阶**：读完经典三篇后，按 光学与波动 → 量子力学入门 → 相对论与时空 顺序进入现代物理。光学是「经典与量子的交界」，量子力学与相对论是「现代物理的两大支柱」。
3. **按需查阅**：想看懂刹车/球赛物理读《经典力学与运动》；想懂冰箱/空调/恒星发光读《热学与热力学》；想懂手机/电网/变压器读《电磁学》；想懂眼镜/相机/激光/光纤读《光学与波动》；想懂芯片/LED/MRI/量子计算读《量子力学入门》；想懂 GPS/黑洞/引力波/宇宙膨胀读《相对论与时空》。
4. **交叉关联**：
   - 变压器：电磁感应（《电磁学》）+ 能量守恒（《经典力学与运动》）。
   - 发动机：热机效率（《热学与热力学》）+ 力与运动（《经典力学与运动》）。
   - 超导输电：超导（《电磁学》）+ 第三定律与低温（《热学与热力学》）。
   - 黑体辐射：维恩位移定律与斯特藩－玻尔兹曼定律（《热学与热力学》）+ 能量量子化（《量子力学入门》）。
   - 光子与光电效应：光的波动性与光子能量（《光学与波动》）+ 光量子假设与波粒二象性（《量子力学入门》）。
   - 光纤通信与 GPS 授时：全反射（《光学与波动》/《电磁学》）+ 光速精确定义与相对论时间修正（《相对论与时空》）。
   - 引力波探测：迈克尔逊干涉仪（《光学与波动》）+ 广义相对论与时空弯曲（《相对论与时空》）。
   - 粒子加速器：洛伦兹力（《电磁学》）+ 相对论动力学（《相对论与时空》）。
   - 激光冷却与原子钟：受激辐射（《光学与波动》）+ 量子跃迁（《量子力学入门》）+ 相对论频移（《相对论与时空》）。

## 本板块说明

- 六篇均为「成人通识」体例：导语 + 分章节（概念→原理→生活实例→常见误区）+ 小结，关键数据与常数标注来源（NIST CODATA、BIPM、人教版高中物理、NobelPrize.org 等）。
- 前四篇以经典物理为主（力学、热学、电磁、光学），后两篇进入现代物理（量子力学、相对论）。相对论与量子力学中「实验事实」与「诠释争论」严格区分：前者精度极高、已成工程基础，后者仍是开放研究问题。
- 关键常数（真空光速 299 792 458 m/s、普朗克常数 6.626 070 15×10⁻³⁴ J·s 等）均为 2019 年 SI 重定义后的精确定义值，标注 BIPM / NIST 来源。
- 本板块**不构成任何工程、医疗或安全操作建议**；电气作业请以持证专业人员与现行规范为准，激光使用与视力问题请遵循产品说明与医嘱。
