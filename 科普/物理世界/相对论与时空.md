# 相对论与时空

> 相对论是爱因斯坦在 1905 年（狭义）与 1915 年（广义）建立的两套时空理论。它把时间与空间统一为「时空」，把引力解释为时空弯曲，并给出质能等价 E = mc²。它并非纯思辨——每天都在你的手机导航、卫星授时与粒子加速器里被验证。本文面向成人通识，重思想与实验证据，轻张量推导。

## 导语

在相对论之前，牛顿给世界画了一张「绝对」的舞台：空间是固定不变的容器，时间均匀流逝，与任何事物无关。这套图景极其成功，能算出行星轨道、预测潮汐、把人类送上月球。

但有两个实验事实，牛顿的框架无法容纳：

- **光速不服从速度叠加**：无论光源如何运动，测到的光速都一样。
- **引力与加速度在局部无法区分**：自由下落时「失重」，而加速上升时「变重」。

爱因斯坦从这两点出发，分别建立了狭义相对论（处理匀速运动与光）与广义相对论（处理加速与引力）。本文的脉络是：

1. 先讲「以太危机」，即相对论诞生的实验背景。
2. 再讲狭义相对论的两条公设与四大推论（同时性、时间、长度、质能）。
3. 然后讲广义相对论的等效原理与弯曲时空。
4. 接着讲四大验证：水星近日点进动、光线偏折、引力红移、GPS 修正。
5. 最后讲黑洞、引力波与宇宙学。

一个重要提醒：相对论**不是**「一切都是相对的」。它有两个绝对：**光速在真空中对所有惯性观察者相同**，以及**时空间隔（四维长度）对所有观察者相同**。相对的是同时性、时间间隔、空间长度与质量，而非物理规律。

## 一、相对论之前的时空观

### 1.1 牛顿的绝对时空

| 概念 | 牛顿的表述 |
| --- | --- |
| 绝对时间 | 「自在地、均匀地流逝，与外界事物无关」 |
| 绝对空间 | 「与外界事物无关而永远相同且不动」 |
| 绝对运动 | 相对绝对空间的运动，原则上可测 |

### 1.2 伽利略相对性原理

> 在所有惯性参考系中，力学规律相同。（来源：维基百科「伽利略变换」）

这意味着：在密闭匀速行驶的船舱里做力学实验，无法判断船是静止还是匀速前进。牛顿力学本身满足这一原理。

### 1.3 以太：一个「必要」的假设

19 世纪，光被确认为电磁波（麦克斯韦 1865 年理论，赫兹 1887 年实验证实）。波动需要一个介质——于是科学家假设空间充满一种叫**以太**的物质，光在其中传播。

| 推论 | 内容 |
| --- | --- |
| 光速相对以太恒定 | 麦克斯韦方程给出 c，是相对以太的速度 |
| 地球在以太中运动 | 应有「以太风」，使不同方向的光速略有差异 |
| 可测量性 | 用干涉仪可测出这一差异 |

### 1.4 麦克斯韦方程组的「叛变」

麦克斯韦方程组给出的电磁波速为 c = 1/√(ε₀μ₀)，与光源、观察者的运动无关。

| 常数 | 数值（NIST CODATA） |
| --- | --- |
| 真空光速 c | 299 792 458 m/s（SI 精确定义） |
| 真空电容率 ε₀ | 8.854 187 8128×10⁻¹² F/m |
| 真空磁导率 μ₀ | 1.256 637 062 12×10⁻⁶ N/A² |

这与「速度可叠加」的直觉冲突，是相对论的核心导火索。

## 二、迈克尔逊－莫雷实验

### 2.1 实验设计

1887 年，迈克尔逊与莫雷用分束－反射－合并的干涉仪，测量沿地球运动方向与垂直方向的光速差异。若存在以太风，两路光返回时间应有差别，干涉条纹会移动。

| 项目 | 内容 |
| --- | --- |
| 目的 | 测出地球相对以太的运动（「以太风」） |
| 方法 | 干涉仪两臂互相垂直，旋转 90° 观察条纹移动 |
| 预期 | 条纹移动对应约 0.4 个条纹（当时灵敏度足够） |
| 实测 | **几乎为零**，远小于预期 |

### 2.2 为什么这个「零结果」如此重要

| 应对方案 | 代价 |
| --- | --- |
| 以太被地球「拖曳」 | 与天文观测（光行差）矛盾 |
| 洛伦兹－菲茨杰拉德收缩 | 引入「凑答案」的假设，缺乏机制 |
| 放弃以太 | 需要重构时间与空间概念 |

**爱因斯坦的选择**：直接接受实验结果——光速不依赖观察者运动，也不需要以太。1905 年他论文标题是《论动体的电动力学》，全文没有引用迈克尔逊－莫雷实验，说明他是从麦克斯韦理论与同时性问题出发的。但无论路径如何，狭义相对论正是这个零结果的理论归宿。

### 2.3 历史细节的分寸

| 说法 | 严谨表述 |
| --- | --- |
| 「爱因斯坦因迈克尔逊实验而创立相对论」 | 无直接证据，他的出发点是光速不变与同时性问题 |
| 「莫雷实验终结了以太」 | 是决定性一步，但以太概念此后一段时间仍有残余使用 |
| 「洛伦兹和庞加莱没有贡献」 | 他们提出了变换与相对性原理雏形，爱因斯坦整合并给出全新物理诠释 |

## 三、狭义相对论的两条公设

### 3.1 公设

| 序 | 内容 |
| --- | --- |
| 一：相对性原理 | 一切物理定律在所有惯性参考系中形式相同 |
| 二：光速不变原理 | 真空中光速 c 对所有惯性观察者相同，与光源、观察者运动无关 |

### 3.2 公设的激进之处

第二条公设直接颠覆了「速度叠加」。若火车以 0.5c 前进，向前发一束光，经典预言速度为 1.5c，相对论则仍为 c。

| 情形 | 经典预言 | 相对论 |
| --- | --- | --- |
| 光速加运动 | > c | 恒为 c |
| 速度叠加 | 直接相加 | 用相对论速度合成公式（结果不超过 c） |
| 极限速度 | 无上限 | c 为上限 |

### 3.3 惯性参考系

狭义相对论只适用于**惯性系**（无加速度）。非惯性系与引力需广义相对论处理。

## 四、同时性的相对性

### 4.1 核心思想

「两件事同时发生」这一判断依赖参考系。若两事件在一参考系中同时但地点不同，则在相对运动的另一参考系中不同时。

### 4.2 爱因斯坦的火车思想实验

一列匀速行驶的火车中，中间有一光源向两端发射光。

| 观察者 | 判断 |
| --- | --- |
| 车上观察者 | 两端同时收到光（两端等距） |
| 地面观察者 | 后端先收到光（后端在向光「迎上来」，前端在「逃开」） |

结论：**同时性不是绝对的**。这是所有相对论效应（时间膨胀、长度收缩）的共同源头。

### 4.3 为什么日常感受不到

效应量级约为 v²/c²。以高铁 300 km/h（约 83 m/s）为例，v²/c² ≈ 7.7×10⁻¹⁴——比任何可感知阈值小十几个数量级，因此日常完全无法察觉。相对论不是「日常经验错了」，而是「日常精度不够」。

## 五、时间膨胀

### 5.1 公式

**Δt = γ Δt₀**，其中 **γ = 1/√(1 − v²/c²)**

| 符号 | 含义 |
| --- | --- |
| Δt₀ | 固有时（随手表一起运动的时钟测得） |
| Δt | 实验室系测得的时长 |
| γ | 洛伦兹因子，v 越接近 c，γ 越大 |

### 5.2 数值感受

| 速度 | γ | 时间膨胀（每 1 秒固有时） |
| --- | --- | --- |
| 0.001c（约 300 km/s） | 1.000 000 5 | 慢约 0.5 μs/s |
| 0.1c | 1.005 | 慢约 0.5% |
| 0.5c | 1.155 | 慢约 15.5% |
| 0.9c | 2.294 | 慢约 56% |
| 0.99c | 7.089 | 慢约 86% |
| 0.999c | 22.37 | 慢约 95.5% |
| → c | → ∞ | 趋于「停住」 |

### 5.3 实验证据

| 实验 | 内容 | 结果 |
| --- | --- | --- |
| μ 子寿命 | 宇宙线 μ 子高速飞向地面，寿命本应极短 | 因时间膨胀可到达地面，与预言一致 |
| 飞行原子钟（Hafele–Keating，1971） | 环球飞行的铯钟与地面钟比对 | 与相对论预言吻合 |
| 粒子加速器 | 高速粒子寿命显著延长 | 每天都在验证 |
| GPS 卫星钟 | 综合狭义与广义效应 | 净快约 38 μs/天 |

**μ 子实验的直觉**：μ 子固有寿命约 2.2 μs，即使以 c 飞行也只能走约 660 m，而大气层厚约 10 km 以上。但在地面大量测到 μ 子，正是因为 γ 使其「主观寿命」被拉长，或者换个参考系看是「大气层变薄了」——两种描述都对，因为它们描述同一四维时空的不同切片。

## 六、长度收缩

### 6.1 公式

**L = L₀ / γ = L₀ √(1 − v²/c²)**

| 符号 | 含义 |
| --- | --- |
| L₀ | 固有长度（与物体相对静止时测得） |
| L | 运动方向上测得的长度 |
| 注意 | 只收缩**运动方向**，垂直方向不变 |

### 6.2 数值感受

| 速度 | γ | 长度比例为 |
| --- | --- | --- |
| 0.1c | 1.005 | 99.5% |
| 0.5c | 1.155 | 86.6% |
| 0.9c | 2.294 | 43.6% |
| 0.99c | 7.089 | 14.1% |
| 0.999c | 22.37 | 4.5% |

### 6.3 关键澄清

| 误区 | 正解 |
| --- | --- |
| 物体「真的被压扁了」 | 是测量结果依参考系不同，不是材质形变或受力 |
| 横着走就不收缩 | 垂直运动方向的尺寸不收缩 |
| 与时间膨胀是两回事 | 本质同一：两者由同一 γ 因子联系，是四维时空的几何关系 |
| 收缩说明绝对空间存在 | 恰恰相反，长度无绝对值，只有相对值 |

## 七、洛伦兹变换与速度合成

### 7.1 洛伦兹变换

若 S′ 以速度 v 沿 x 轴相对 S 运动，则：

| 变换关系 | 表达式 |
| --- | --- |
| 位置 | x′ = γ(x − vt) |
| 时间 | t′ = γ(t − vx/c²) |
| 垂直方向 | y′ = y，z′ = z |

**注意时间变换中含位置项**：这是「时空混合」的数学表达——不同参考系不仅空间坐标混合，时间与空间也互相混合。闵可夫斯基 1908 年据此提出「四维时空」，把相对论几何化。

### 7.2 相对论速度合成

以 u 和 v 沿同方向叠加时：

**u′ = (u + v) / (1 + uv/c²)**

| 情形 | 经典结果 | 相对论结果 |
| --- | --- | --- |
| 0.5c + 0.5c | 1.0c | 0.8c |
| 0.9c + 0.9c | 1.8c | 约 0.994c |
| c + 0.5c | 1.5c | 仍为 c |
| 0.01c + 0.01c | 0.02c | 约 0.019 998c（几乎相同） |

**结论**：低速时相对论退化为经典（对应原理），高速时速度叠加永远不超过 c。

### 7.3 时空间隔的不变性

**s² = c²Δt² − Δx² − Δy² − Δz²**

不同惯性观察者测到的 Δt、Δx 各不相同，但 s² 相同。这类似于二维旋转中「长度不变」——相对论就是时空中的「旋转」（洛伦兹变换），所以又叫「伪欧几里得几何」。

| 间隔类型 | 含义 | 是否可能有因果联系 |
| --- | --- | --- |
| 类时（s² > 0） | 可有物体从一事件到另一事件 | 可以 |
| 类光（s² = 0） | 光能连接 | 可以（光信号） |
| 类空（s² < 0） | 需超光速 | 不可以 |

这解释了「为什么超光速会破坏因果」：类空间隔的两事件在不同参考系中先后顺序可以颠倒，若允许超光速信号，就会出现「果先于因」。

## 八、相对论动量与质量

### 8.1 相对论动量

**p = γ m₀ v**

| 符号 | 含义 |
| --- | --- |
| m₀ | 静质量（不变量） |
| γ | 洛伦兹因子 |

当 v → c，p → ∞，需要无限大的冲量才能继续加速——这就是**物体无法达到光速**的动力学原因。

### 8.2 关于「相对论质量」

历史上常用「相对论质量」m = γm₀ 来表达「越快的物体越重」，这在科普中直观但有争议：

| 表述 | 优点 | 问题 |
| --- | --- | --- |
| 相对论质量 m = γm₀ | 保留 F = ma 形式，直观 | 引入依参考系变化的质量，易误解 |
| 只用静质量 m₀ | 质量是不变量，概念干净 | 动量与能量公式含 γ |

现代物理界主流倾向**只用静质量**（不变量），把 γ 归入动量与能量的表达式。本文以下采用此约定。

### 8.3 相对论能量

**E = γ m₀ c²**

| 情形 | 能量 |
| --- | --- |
| 静止（v = 0） | E₀ = m₀c²（静能） |
| 运动 | E = γm₀c² = 静能 + 动能 |
| 动能 | E_k = (γ − 1)m₀c² |
| 低速近似 | E_k ≈ ½m₀v²（回到经典公式） |

**能量－动量关系**：E² = (pc)² + (m₀c²)²。对光子（m₀ = 0）则 E = pc，与光子的能量动量关系一致。

## 九、质能方程

### 9.1 方程与含义

**E = mc²**（更严格写作 E₀ = m₀c²）

| c² 的数量级 | 含义 |
| --- | --- |
| c ≈ 3×10⁸ m/s | c² ≈ 9×10¹⁶ m²/s² |
| 1 g 物质完全转化 | 约 9×10¹³ J（相当于约 2 万吨 TNT 量级） |

### 9.2 常见误解

| 误解 | 正解 |
| --- | --- |
| 任何物质都能「变成能量」 | 只有通过具体物理过程（湮灭、核反应等）才转换 |
| 质量守恒与质能方程矛盾 | 质量守恒是低速近似；严格的守恒是「质能总量」 |
| 核电站把质量「烧掉」 | 质量亏损约 0.1% 量级（铀裂变），差额转为能量 |
| E = mc² 只适用于核能 | 适用于一切能量变化，包括放热、发光、化学键 |

### 9.3 实验验证与后果

| 事件 | 说明 |
| --- | --- |
| 1932 | 科克罗夫特－沃尔顿用质子轰击锂，质量亏损对应动能释放，直接验证 |
| 1933 | 约里奥－居里夫妇观测到能量转化为物质（正负电子对） |
| 1938 起 | 核裂变发现，质能转换进入工程 |
| 恒星发光 | 太阳每秒把约 400 万吨质量转为能量（氢核聚变） |
| 正负电子湮灭 | 两个电子质量完全转为光子能量 |
| PET 医学成像 | 正电子湮灭产生两个 511 keV 光子，成对探测 |
| 对撞机 | 用能量「造出」新粒子 |

**太阳的数字**：太阳光度约 3.828×10²⁶ W，由 E = mc² 得每秒质量亏损约 4.3×10⁹ kg（约 430 万吨）。以这个速率，太阳的氢燃料仍可维持约百亿年量级——这正是太阳能稳定发光的原因。

## 十、双生子佯谬

### 10.1 佯谬的提出

姐姐乘飞船高速往返，妹妹留在地球。由时间膨胀，双方都「看对方钟慢」，那么谁更年轻？

### 10.2 解答：参考系不对称

| 阶段 | 姐姐 | 妹妹 |
| --- | --- | --- |
| 出发 | 惯性系 A | 惯性系 |
| 转向 | **经历加速（换参考系）** | 始终惯性 |
| 返航 | 惯性系 B | 惯性系 |
| 结论 | 姐姐更年轻 | 妹妹更老 |

关键在于**姐姐必须转向（加速）**，因此两兄弟地位不对称，妹妹的判断（姐姐更年轻）才是唯一自洽答案。

### 10.3 直观版本与实验

| 版本 | 内容 |
| --- | --- |
| 经典版 | 高速往返飞船，姐姐年轻 |
| 引力版 | 住在山顶（引力势高）比住海平面老得快（引力时间膨胀） |
| 实验版 | μ 子、飞行原子钟、加速器粒子都验证了「运动时钟慢」 |
| 双生子「通讯版」 | 姐姐全程发信号，妹妹收到的信号频率全程偏低（多普勒 + 时间膨胀），累计也算出姐姐更年轻 |

**再强调一次**：这里没有「谁看谁」的主观性，因为姐姐的加速是绝对的（可用加速度计测出），所以答案唯一。

## 十一、等效原理

### 11.1 思想实验

爱因斯坦 1907 年设想：在远离一切引力的空间，一个密闭舱以 9.8 m/s² 加速上升。舱内的人无法区分这是「加速度」还是「站在地球表面」。

| 场景 | 舱内感受 |
| --- | --- |
| 静止在地球表面 | 脚被地板托住，有「重量」 |
| 无引力空间加速上升 | 感受完全相同 |
| 自由下落 | 「失重」，物体漂浮 |
| 远离引力匀速运动 | 同样失重 |

### 11.2 弱等效原理与强等效原理

| 版本 | 内容 |
| --- | --- |
| 弱等效原理 | 惯性质量与引力质量相等（自由落体加速度与质量无关） |
| 强等效原理 | 任何**局部**非引力实验都无法区分引力与加速度（含电磁、量子等一切物理） |

### 11.3 惯性质量 = 引力质量

| 概念 | 定义方式 |
| --- | --- |
| 惯性质量 | F = ma 中的 m（抗拒加速的程度） |
| 引力质量 | 万有引力中的「荷」（感受引力的强度） |

实验表明两者在极高精度下相等。现代检验包括扭秤实验、月球激光测距、以及 MICROSCOPE 卫星任务——精度已达 10⁻¹⁵ 量级（来源：等效原理检验相关文献）。这是广义相对论的基石。

### 11.4 光会「下落」

若在加速舱内水平射出一束光，光在舱内看起来向下弯曲（因为舱地板在加速向上「追上」光）。由等效原理，在引力场中光也会弯曲——这正是光线偏折的预言来源，也是「引力会弯折光」的思想起点。

## 十二、广义相对论与弯曲时空

### 12.1 核心思想

> 引力不是一种力，而是时空弯曲的几何效应。物体在弯曲时空中沿**测地线**（最接近直线的路径）运动。

**爱因斯坦场方程**（1915 年 11 月完成，1916 年正式发表）：

**G_μν + Λg_μν = (8πG/c⁴) T_μν**

| 符号 | 含义 |
| --- | --- |
| G_μν | 爱因斯坦张量（描述时空弯曲） |
| Λ | 宇宙学常数 |
| T_μν | 能量－动量张量（描述物质与能量分布） |
| G | 引力常数 6.674 30(15)×10⁻¹¹ m³·kg⁻¹·s⁻²（NIST CODATA 2022） |

**用一句话概括**：物质与能量告诉时空如何弯曲，时空弯曲告诉物质如何运动（惠勒的名言）。

### 12.2 与牛顿引力的关系

| 比较 | 牛顿引力 | 广义相对论 |
| --- | --- | --- |
| 引力的本质 | 超距的力 | 时空几何 |
| 适用 | 弱场、低速 | 任意场强 |
| 水星近日点 | 差 43″/世纪 | 精确吻合 |
| 强场 | 失效 | 预言黑洞等 |
| 弱场极限 | — | 退化为牛顿引力（对应原理） |

### 12.3 时空弯曲的证据直觉

| 现象 | 几何解释 |
| --- | --- |
| 行星绕日 | 沿弯曲时空的测地线运动 |
| 光线偏折 | 光沿测地线（零测地线） |
| 引力红移 | 弯曲时空中时钟速率不同 |
| 引力波 | 时空曲率的传播性扰动 |
| 黑洞 | 曲率极端到光无法逃逸 |

### 12.4 数学工具

| 工具 | 作用 |
| --- | --- |
| 黎曼几何 | 描述弯曲空间（1854 年黎曼提出基础） |
| 度规张量 g_μν | 定义长度与时间间隔 |
| 克里斯托费尔符号 | 描述坐标变化下的「弯曲」 |
| 里奇张量与曲率标量 | 进入场方程 |
| 测地线方程 | 自由粒子运动 |

历史细节：1912 年爱因斯坦在同学格罗斯曼帮助下学习黎曼几何与张量分析，又经三年摸索，于 1915 年 11 月完成场方程（来源：Britannica「100 Years of General Relativity」）。

## 十四、引力时间膨胀与引力红移

### 14.1 公式（弱场、球对称）

**Δt_∞ / Δt_r = 1/√(1 − 2GM/(rc²))**

| 符号 | 含义 |
| --- | --- |
| r | 距中心天体距离 |
| M | 中心天体质量 |
| Δt_r | 在 r 处测得的固有时间 |
| Δt_∞ | 无穷远处（弱引力）测得的对应时间 |

**结论**：引力越强（r 越小、M 越大），时钟走得越慢。

### 14.2 数值感受

| 场景 | 相对频移量级 |
| --- | --- |
| 地球表面 vs 无穷远 | 约 7×10⁻¹⁰ |
| 每升高 1 米（地表附近） | 约 1×10⁻¹⁶（现代光钟可测） |
| 太阳表面 vs 地球 | 约 2×10⁻⁶ |
| 中子星表面 | 可达 0.1 以上（极端情况） |
| 黑洞视界附近 | 趋于无穷（对外部观察者时钟「冻结」） |

### 14.3 与狭义相对论时间膨胀的联合

GPS 是两者的完美联合演示：

| 效应 | 来源 | 每天偏差 |
| --- | --- | --- |
| 狭义（速度） | 卫星约 3.87 km/s | 慢约 7 μs |
| 广义（引力势高） | 轨道高约 20 184 km | 快约 45 μs |
| **净效应** | 两者之差 | **快约 38 μs** |

## 十五、GPS 与相对论：日常生活中的验证

### 15.1 卫星参数

| 参数 | 数值 |

### 15.2 修正方式

| 步骤 | 做法 |
| --- | --- |
| 出厂预设 | 卫星钟频率预先调慢，设定为 10.229 999 995 43 MHz |
| 修正量 | 分数频偏约 −4.465×10⁻¹⁰ |
| 目的 | 上天后相对论效应把它「拉回」10.23 MHz |
| 接收机端 | 还需修正轨道偏心率引起的周期性变化（幅度几十纳秒）与萨格纳克效应（可达约 133 ns） |

## 十六、引力透镜

### 16.1 原理

大质量天体会弯曲周围时空，使经过的星光路径偏折，效果如同一个巨大的透镜。

| 类型 | 特征 |
| --- | --- |
| 强透镜 | 形成明显的多重像、爱因斯坦环或弧 |
| 弱透镜 | 轻微形变，需统计大量背景星系才能测出 |
| 微透镜 | 恒星量级天体造成的短时增亮 |

### 16.2 现象与观测

| 现象 | 说明 |
| --- | --- |
| 爱因斯坦环 | 光源、透镜、观察者三者近共线时成环 |
| 多重像 | 同一遥远天体出现多个像 |
| 引力弧 | 星系团把背景星系拉成弧 |
| 微引力透镜 | 用于搜寻系外行星与暗弱天体 |
| 时间延迟 | 不同像的光程不同，可用于测哈勃常数 |
| 爱因斯坦十字 | 四重像的著名案例 |

### 16.3 科学价值

| 应用 | 说明 |
| --- | --- |
| 探测暗物质 | 通过透镜效应间接「称量」不可见质量 |
| 测量哈勃常数 | 时间延迟距离法 |
| 研究遥远宇宙 | 透镜把更远天体「放大」，提高可见度 |
| 检验引力理论 | 偏折量是否与广义相对论一致 |
| 寻找系外行星 | 微透镜是独立于凌星法的手段 |

**爱因斯坦环的历史**：爱因斯坦本人 1936 年认为这种现象几乎不可能被观测到，但此后天体物理学家发现星系团尺度上非常普遍——如今引力透镜已成为观测宇宙学的标准工具。

## 十七、黑洞

### 17.1 从方程中「长出来」

1916 年，史瓦西在静态球对称条件下解出爱因斯坦场方程的第一个非平凡精确解，其结构中已包含后来被称为「黑洞」的时空。

| 概念 | 含义 |
| --- | --- |
| 事件视界 | 光无法逃逸的边界 |
| 史瓦西半径 | r_s = 2GM/c² |
| 奇点 | 理论中曲率发散处（需量子引力处理） |
| 无毛定理 | 黑洞只由质量、角动量、电荷三个参数描述 |
| 霍金辐射 | 黑洞因量子效应缓慢蒸发（尚未观测证实） |

### 17.2 史瓦西半径的数量级

| 天体 | 若压缩为黑洞，其史瓦西半径 |
| --- | --- |
| 太阳（约 2×10³⁰ kg） | 约 3.0 km |
| 地球（约 6×10²⁴ kg） | 约 8.9 mm |
| 10 倍太阳质量黑洞 | 约 30 km |
| 太阳系中心超大质量黑洞（Sgr A*，约 4×10⁶ M☉） | 约 1.2×10⁷ km（约 0.08 AU 量级） |

（由 r_s = 2GM/c² 计算，M☉ = 1.989×10³⁰ kg。）

### 17.3 观测证据

| 观测 | 内容 |
| --- | --- |
| 恒星轨道 | 银河系中心恒星绕不可见致密天体高速公转（S2 等），可推算质量 |
| X 射线双星 | 吸积盘高温辐射揭示致密天体 |
| 引力波 | 双黑洞并合波形直接证实黑洞 |
| 事件视界望远镜（EHT） | 2019 年公布 M87* 阴影图像，2022 年公布人马座 A* 图像 |
| 黑洞「阴影」尺寸 | M87* 阴影直径约 42 微角秒，与广义相对论对克尔黑洞的预言一致（约 5.2 倍引力半径量级） |

### 17.4 事件视界望远镜

| 技术 | 内容 |
| --- | --- |
| 原理 | 甚长基线干涉（VLBI），把全球射电望远镜连成「地球口径」望远镜 |
| 波段 | 1.3 mm 毫米波 |
| 时间 | 2017 年取数，2019 年发布 M87* 图像 |
| 质量 | M87* 约 6.5×10⁹ 太阳质量 |
| 挑战 | 需按广义相对论扣除信号传播中的弯曲与延迟，才能把各台望远镜相位对齐 |

### 17.5 黑洞的几个反直觉点

| 问题 | 解答 |
| --- | --- |
| 黑洞是「洞」吗 | 不是洞，是极度弯曲的时空区域 |
| 会被吸进去吗 | 只有在视界内才无法逃逸，远处绕行与普通引力类似 |
| 黑洞会永远存在吗 | 霍金辐射使其缓慢蒸发，但恒星质量黑洞的蒸发时间远超宇宙年龄 |
| 信息会丢失吗 | 黑洞信息佯谬，是量子引力研究的核心问题之一 |

## 二十一、常见误区汇总

| 误区 | 正解 |
| --- | --- |
| 相对论说「一切都是相对的」 | 光速与四维时空间隔是绝对的 |
| 时间膨胀是错觉 | 是真实的物理效应，实验可测 |
| 长度收缩是物体被挤压变形 | 是测量结果依参考系不同，不是材质形变 |
| 双生子佯谬说明相对论自相矛盾 | 加速方不对称，答案唯一 |
| 光速无法超越所以什么都不能快 | 相速度、群速度、宇宙膨胀等有细微区分；信息不能超光速 |
| 引力是「拉着」物体 | 广义相对论中是沿弯曲时空测地线运动 |
| 黑洞是宇宙吸尘器 | 远处轨道与普通引力无本质差别 |
| 引力波是「声音」 | 是时空应变，探测后用音频化播放便于感知 |
| E = mc² 只在核反应中成立 | 适用一切能量变化 |
| 爱因斯坦因相对论获诺贝尔奖 | 1921 年因光电效应获奖，相对论当时仍有争议 |
| 引力透镜是「折射」 | 是时空弯曲导致路径偏折，与介质折射机制不同 |
| GPS 若不修正只差几米 | 每天累积约 10 km 量级，量级差别巨大 |

## 二十四、动手感受相对论量级

不需要实验室，用计算器就能感受相对论为何「日常不可见」。

| 场景 | 速度 v | v²/c² | γ−1 量级 |
| --- | --- | --- | --- |
| 步行（1.4 m/s） | 1.4 m/s | 2×10⁻¹⁷ | 10⁻¹⁷ |
| 汽车（60 km/h） | 16.7 m/s | 3×10⁻¹⁵ | 10⁻¹⁵ |
| 客机（900 km/h） | 250 m/s | 7×10⁻¹³ | 10⁻¹³ |
| 高铁（300 km/h） | 83 m/s | 8×10⁻¹⁴ | 10⁻¹⁴ |
| 火箭入轨（7.9 km/s） | 7900 m/s | 7×10⁻¹⁰ | 10⁻¹⁰ |
| GPS 卫星 | 3874 m/s | 1.7×10⁻¹⁰ | 10⁻¹⁰ |
| 太阳绕银心 | 220 km/s | 5×10⁻⁷ | 10⁻⁷ |
| μ 子（近光速） | 0.999c | 0.998 | γ ≈ 22 |
| LHC 质子 | 0.999999991c | ≈ 1 | γ ≈ 7500 |

**结论**：只有当 v/c 达到百分之几以上，γ 才显著偏离 1。这就是相对论「日常不可见、极端显威力」的定量原因。

## 小结

- **两条公设撑起狭义相对论**：物理定律在所有惯性系相同；真空中光速对一切惯性观察者恒为 299 792 458 m/s（SI 精确定义值）。
- **同时性是相对的**，这是时间膨胀、长度收缩的共同源头；日常察觉不到是因为效应量级为 v²/c²。
- **时间膨胀 Δt = γΔt₀、长度收缩 L = L₀/γ**，同一 γ 因子、同一几何；已被 μ 子、飞行钟、加速器反复验证。
- **相对论动量与能量**：E = γm₀c²，低速退回 ½m₀v²；能量－动量关系 E² = (pc)² + (m₀c²)²，光子取 m₀ = 0。
- **E = mc² 严格说是 E₀ = m₀c²**，太阳每秒把约 430 万吨质量转为能量，PET 成像与核能都建基于此。
- **双生子佯谬的解在于加速不对称**，所以答案唯一，姐姐更年轻。
- **等效原理是广义相对论的基石**：引力与加速度局部不可区分，惯性质量与引力质量在 10⁻¹⁵ 精度下相等。
- **引力是时空弯曲的几何效应**，物体沿测地线运动；爱因斯坦场方程 1915 年 11 月完成。
- **四大经典验证**：水星近日点反常进动（约 43″/世纪）、1919 年日食光线偏折（约 1.75″）、引力红移（庞德－雷布卡 1959–1960）、雷达回波延迟。
- **GPS 是相对论的日常证明**：狭义使卫星钟慢约 7 μs/天，广义使其快约 45 μs/天，净快约 38 μs/天；不修正每天累积约 10 km 量级误差。卫星钟出厂预设频率 10.229 999 995 43 MHz。
- **引力透镜、黑洞、引力波**是广义相对论的强场预言：EHT 拍下 M87* 与 Sgr A*，LIGO 于 2015 年 9 月 14 日首次直接探测 GW150914（约 36 + 29 → 62 太阳质量，约 13 亿光年外）。
- **相对论不是「困难且无用」的理论**，而是精度极高、每天都在工程中兑现的理论；剩余的开放问题集中在黑洞信息、奇点与量子引力。
