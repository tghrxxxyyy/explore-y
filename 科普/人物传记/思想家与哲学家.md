# 思想家与哲学家

> 从古至今，这些思想巨匠用智慧照亮了人类文明的前行之路。

---

## 一、苏格拉底（Socrates，约前470—前399）

| 项目 | 内容 |
|------|------|
| 时代 | 古希腊雅典城邦 |
| 身份 | 哲学家、教育家 |
| 核心思想 | "认识你自己"、产婆术、美德即知识 |
| 代表著作 | 无（由弟子柏拉图记录） |
| 去世方式 | 饮鸩（毒芹汁）而死 |

### 1.1 生平时间线

- **约前470年**：出生于雅典一个石匠家庭，随父学习雕刻
- **前449年—前399年**：在雅典街头与人辩论，培养大批弟子
- **前399年**：被雅典法庭判处死刑，饮鸩而亡

### 1.2 核心思想

- **认识你自己**：哲学的起点是自我认知，人必须审视自己的灵魂
- **产婆术**：通过不断追问引导对方发现真理，而非直接灌输
- **美德即知识**：真正的知识是对善的认识，无知是恶的根源

### 1.3 人生故事

苏格拉底出身贫寒，父亲是石匠，母亲是助产士。他没有留下任何著作，却通过在雅典街头与人对话，成为西方哲学的奠基人。

公元前399年，他被指控"腐蚀青年"和"不敬神灵"。尽管有逃脱的机会，他选择坦然面对死亡，认为遵守城邦法律是公民的义务。临终前，他依然在与弟子讨论灵魂不朽的问题。

### 1.4 名言警句

- "未经审视的人生不值得过。"
- "我唯一知道的，就是我一无所知。"
- "认识你自己。"
- "教育不是灌输，而是点燃火焰。"

### 1.5 对后世思想的影响

苏格拉底被誉为"西方哲学之父"。他的反诘法深刻影响了逻辑学和辩证法的发展，他培养的弟子柏拉图和再传弟子亚里士多德共同奠定了西方哲学的基石。

## 二、孔子（Confucius，前551—前479）

| 项目 | 内容 |
|------|------|
| 时代 | 春秋时期鲁国 |
| 身份 | 思想家、教育家、政治家 |
| 核心思想 | 仁、义、礼、智、信 |
| 代表著作 | 《论语》（弟子记录） |
| 地位 | 儒家学派创始人、万世师表 |

### 2.1 生平时间线

- **前551年**：出生于鲁国陬邑（今山东曲阜）一个没落贵族家庭
- **前517年—前497年**：周游列国，寻求从政机会
- **前484年—前479年**：回到鲁国，专心教育与整理典籍
- **前479年**：病逝于鲁国，享年73岁

### 2.2 核心思想

- **仁**：核心道德理念，爱人、关怀他人
- **礼**：社会规范与秩序，仁的外在表现
- **中庸之道**：不偏不倚，恰到好处的处世智慧
- **有教无类**：教育不分贵贱，人人都有受教育的权利

### 2.3 人生故事

孔子幼年丧父，与母亲相依为命。成年后曾在鲁国担任官职，推行仁政，使鲁国大治。但因政治斗争被迫离开鲁国。

此后14年间，他带着弟子周游列国，希望找到一位能采纳其政治主张的君主。乱世之中，他的理想屡屡碰壁。晚年回到鲁国后，他整理《诗》《书》《礼》《乐》《易》《春秋》等典籍，开创私学，收徒三千人。

### 2.4 名言警句

- "己所不欲，勿施于人。"
- "学而时习之，不亦说乎？"
- "三人行，必有我师焉。"
- "知之为知之，不知为不知，是知也。"

### 2.5 对后世思想的影响

孔子被尊为"至圣先师"，其思想成为中国两千多年封建社会的正统意识形态。儒家学说不仅深刻影响了中国、日本、韩国、越南等东亚国家的文化与政治，也通过传教士传播到欧洲，影响了启蒙思想家。联合国教科文组织将其列为世界十大文化名人之首。

## 三、亚里士多德（Aristotle，前384—前322）

| 项目 | 内容 |
|------|------|
| 时代 | 古希腊马其顿王国 |
| 身份 | 哲学家、科学家、教育家 |
| 核心思想 | 逻辑学、形而上学、伦理学、政治学 |
| 代表著作 | 《形而上学》《尼各马可伦理学》《政治学》 |
| 名言 | "吾爱吾师，吾更爱真理" |

### 3.1 生平时间线

- **前384年**：出生于马其顿的斯塔基拉城，父亲是御医
- **前367年**：17岁前往雅典，进入柏拉图学园学习并任教20年
- **前343年**：受马其顿国王邀请，担任亚历山大的老师
- **前335年**：回到雅典，创立吕克昂学园
- **前322年**：在欧比亚岛病逝，享年62岁

### 3.2 核心思想

- **逻辑学**：创立形式逻辑（三段论），被称为"逻辑学之父"
- **形而上学**：探讨"存在之为存在"，提出"四因说"
- **伦理学**：追求幸福，美德是幸福的组成部分
- **政治学**：主张中产阶级统治的共和政体

### 3.3 人生故事

亚里士多德是一位百科全书式的学者。他17岁来到柏拉图学园，深受柏拉图哲学的影响，但并不盲从老师，最终在许多问题上与老师持不同见解。

柏拉图去世后，他受马其顿国王之邀，担任年仅13岁的亚历山大的老师。亚历山大即位后，他回到雅典创办吕克昂学园，进行广泛的教学和研究。据说他的著作达400卷，流传至今的只有约三分之一。

### 3.4 名言警句

- "吾爱吾师，吾更爱真理。"
- "人是理性的动物。"
- "幸福是灵魂合乎德性的活动。"
- "教育的根是苦的，但其果实是甜的。"

### 3.5 对后世思想的影响

亚里士多德的影响力几乎无人能及。他的逻辑学统治西方思想界近两千年；他的自然哲学在中世纪被奉为权威；他对伦理学、政治学的探讨至今仍是学术研究的基础。他被誉为"最后一个百科全书式的古代思想家"。

## 四、庄子（Zhuangzi，约前369—前286）

| 项目 | 内容 |
|------|------|
| 时代 | 战国时期宋国蒙地 |
| 身份 | 思想家、文学家 |
| 核心思想 | 道、逍遥、无为、齐物 |
| 代表著作 | 《庄子》 |
| 地位 | 道家学派代表人物 |

### 4.1 生平时间线

- **约前369年**：出生于宋国蒙地（今河南商丘一带）
- **前350年—前286年**：曾任漆园吏，后专心著述与哲学思考
- **约前286年**：病逝，享年约83岁

### 4.2 核心思想

- **逍遥游**：追求精神的绝对自由，超越世俗名利的束缚
- **齐物论**：万物平等，消除是非对立，达到"物我两忘"的境界
- **无为而治**：顺应自然，不以人为干预自然之道

### 4.3 人生故事

庄子一生贫困，却才华横溢，不愿做官，宁愿过着自由自在的平民生活。

楚王曾派人请他出任宰相，他却讲了一个故事：神龟死后被供奉在庙堂上，但它是愿意死后被供奉，还是愿意活着在泥里爬行？使者答：当然愿意活着在泥里爬行。庄子说：那就回去吧，我宁愿在泥里爬行。

他与惠施是好友，两人经常辩论。"子非鱼，安知鱼之乐"的著名对话就出自他们的辩论。

### 4.4 名言警句

- "子非鱼，安知鱼之乐？"
- "天地与我并生，万物与我为一。"
- "吾生也有涯，而知也无涯。"
- "至人无己，神人无功，圣人无名。"

### 4.5 对后世思想的影响

庄子的思想对中国文学、艺术、哲学产生了深远影响。他的散文汪洋恣肆，被誉为"文学的哲学，哲学的文学"。魏晋玄学、禅宗佛教都深受庄子思想的影响。他在西方也被誉为东方最具诗意的哲学家。

## 五、王阳明（Wang Yangming，1472—1529）

| 项目 | 内容 |
|------|------|
| 时代 | 明代 |
| 身份 | 思想家、哲学家、军事家、教育家 |
| 核心思想 | 心学、知行合一、致良知 |
| 代表著作 | 《传习录》《大学问》 |
| 地位 | "立德、立功、立言"三不朽的圣贤 |

### 5.1 生平时间线

- **1472年**：出生于浙江余姚一个书香门第
- **1506年**：因得罪宦官刘瑾被贬贵州龙场驿
- **1508年**：龙场悟道，悟出"心即理"的核心思想
- **1519年**：平定宁王朱宸濠叛乱
- **1521年**：正式提出"致良知"学说
- **1529年**：病逝于归乡途中，享年57岁

### 5.2 核心思想

- **心即理**：天理就在人心之中，不必外求
- **知行合一**：真正的知识必然包含行动，知而不行非真知
- **致良知**：人人皆有良知，通过修行可以达到圣人境界

### 5.3 人生故事

王阳明少年时立志做圣人，但人生道路充满坎坷。1506年，他因上疏得罪宦官刘瑾，被贬到贵州龙场驿。在极其艰苦的环境中，他日夜反省，终于在一个深夜悟道，史称"龙场悟道"。

此后，他一边从政，一边讲学。1519年，他以劣势兵力平定了宁王朱宸濠的叛乱，展现非凡的军事才能。他晚年提出"致良知"学说，强调每个人内心都有良知，只要遵循良知行事，就能成为圣人。

### 5.4 名言警句

- "你未看此花时，此花与汝心同归于寂。你来看此花时，则此花颜色一时明白起来。"
- "知行合一。"
- "破山中贼易，破心中贼难。"
- "此心光明，亦复何言。"

### 5.5 对后世思想的影响

王阳明的心学是中国哲学史上的重大突破。他打破了程朱理学"格物穷理"的僵化路径，强调人的主体性和道德自觉。他的思想深刻影响了日本、韩国等东亚国家，对近代东亚社会变革产生了重要作用。曾国藩、蒋介石、稻盛和夫等都深受阳明心学影响。

## 六、尼采（Friedrich Nietzsche，1844—1900）

| 项目 | 内容 |
|------|------|
| 时代 | 19世纪德国 |
| 身份 | 哲学家、语言学家、文化批评家 |
| 核心思想 | 权力意志、超人哲学、永恒轮回 |
| 代表著作 | 《查拉图斯特拉如是说》《善恶的彼岸》《道德的谱系》 |
| 名言 | "那些杀不死我的，使我更强大" |

### 6.1 生平时间线

- **1844年**：出生于普鲁士萨克森地区一个路德宗牧师家庭
- **1869年**：25岁成为巴塞尔大学古典语言学教授
- **1879年**：因健康原因辞去教职，开始自由写作
- **1883年—1885年**：完成代表作《查拉图斯特拉如是说》
- **1889年**：在都灵精神崩溃，陷入疯狂
- **1900年**：在魏玛病逝，享年55岁

### 6.2 核心思想

- **权力意志**：生命的本质是追求力量的扩张，而非单纯的求生
- **超人**：超越传统道德束缚，创造新价值的理想人格
- **上帝已死**：批判基督教和传统形而上学的衰落
- **永恒轮回**：宇宙是无限循环的，人应该热爱命运

### 6.3 人生故事

尼采生于一个牧师家庭，父亲在他5岁时去世。他自幼聪慧，25岁便成为巴塞尔大学教授。但他体弱多病，与同事关系紧张。1879年，他辞去教职，开始长达十年的漂泊写作生涯。

他的著作在当时几乎无人问津，但他坚持写作。1889年，他在都灵街头看到一匹马被车夫鞭打，冲上去抱住马的脖子痛哭，随后精神崩溃。此后十年，他在疯狂中度过，1900年病逝。

### 6.4 名言警句

- "那些杀不死我的，使我更强大。"
- "上帝已死。"
- "成为你自己。"
- "每一个不曾起舞的日子，都是对生命的辜负。"

### 6.5 对后世思想的影响

尼采被誉为"存在主义的先驱"。他对传统道德、宗教、哲学的批判深刻影响了20世纪的哲学思潮。萨特、加缪、海德格尔等人都深受其影响。他的"超人"思想被纳粹歪曲利用，但他的本意是追求个体的精神超越。他在文学、音乐、心理学等领域也有深远影响。

## 七、马克思（Karl Marx，1818—1883）

| 项目 | 内容 |
|------|------|
| 时代 | 19世纪德国/英国 |
| 身份 | 哲学家、经济学家、社会学家、革命理论家 |
| 核心思想 | 历史唯物主义、辩证唯物主义、共产主义 |
| 代表著作 | 《资本论》《共产党宣言》《德意志意识形态》 |
| 名言 | "哲学家们只是用不同的方式解释世界，问题在于改变世界" |

### 7.1 生平时间线

- **1818年**：出生于普鲁士莱茵省特里尔市一个律师家庭
- **1843年**：与燕妮结婚，移居巴黎
- **1844年**：与恩格斯在巴黎会面，开始终身合作
- **1848年**：发表《共产党宣言》
- **1849年**：流亡伦敦，在贫困中坚持研究和写作
- **1867年**：《资本论》第一卷出版
- **1883年**：在伦敦病逝，享年64岁

### 7.2 核心思想

- **历史唯物主义**：社会存在决定社会意识，生产力决定生产关系
- **剩余价值理论**：揭露资本主义剥削的秘密
- **阶级斗争**：阶级社会的历史是阶级斗争的历史
- **共产主义**：消灭私有制，实现人的全面解放

### 7.3 人生故事

马克思出生于一个富裕的律师家庭，年轻时曾是激进的青年黑格尔派成员。1843年，他与出身贵族的燕妮结婚，流亡巴黎。在巴黎，他与恩格斯结识，两人成为终身挚友和战友。

1849年后，马克思流亡伦敦。在大英博物馆里，他日夜研究经济学，写作《资本论》。他一家生活在极度贫困中，几个孩子因贫病夭折。但他从未放弃研究和革命事业。1883年，他在伦敦病逝。

### 7.4 名言警句

- "哲学家们只是用不同的方式解释世界，问题在于改变世界。"
- "全世界无产者，联合起来！"
- "宗教是人民的鸦片。"
- "人们自己创造自己的历史。"

### 7.5 对后世思想的影响

马克思是人类历史上最具影响力的思想家之一。他的理论深刻改变了20世纪的世界格局，影响了数十亿人的生活。他的经济学、社会学、哲学思想至今仍是学术研究的重要领域。无论赞同还是反对，没有人可以忽视他的影响。

## 八、伏尔泰（Voltaire，1694—1778）

| 项目 | 内容 |
|------|------|
| 时代 | 18世纪法国 |
| 身份 | 作家、哲学家、启蒙思想家 |
| 核心思想 | 言论自由、宗教宽容、理性主义 |
| 代表著作 | 《哲学通信》《老实人》《论宽容》 |
| 名言 | "我不同意你的观点，但我誓死捍卫你说话的权利" |

### 8.1 生平时间线

- **1694年**：出生于巴黎一个中产阶级家庭
- **1718年**：24岁因悲剧《俄狄浦斯王》一举成名
- **1726年—1729年**：流亡英国，深受洛克、牛顿思想影响
- **1755年—1778年**：隐居费尔奈庄园，笔耕不辍
- **1778年**：返回巴黎，同年病逝，享年83岁

### 8.2 核心思想

- **言论自由**：捍卫思想和言论的自由是社会进步的基础
- **宗教宽容**：批判宗教迫害，主张信仰自由
- **理性主义**：用理性而非迷信指导生活和社会

### 8.3 人生故事

伏尔泰原名弗朗索瓦-马利·阿鲁埃，出生于巴黎一个公证人家庭。他自幼聪慧，却因言辞犀利多次入狱。

1726年，他因得罪贵族被关进巴士底狱。出狱后，他流亡英国三年，深入了解洛克的哲学和牛顿的科学。回到法国后，他出版《哲学通信》，介绍英国的自由思想，引起巨大轰动，也招致政府打压。

此后20多年，他辗转于巴黎、普鲁士、瑞士之间。晚年隐居费尔奈庄园，仍笔耕不辍，写出大量哲学著作、戏剧和小说。1778年，83岁的伏尔泰重返巴黎，受到民众热烈欢迎，数周后病逝。

### 8.4 名言警句

- "我不同意你的观点，但我誓死捍卫你说话的权利。"
- "工作可以免除三大祸害：烦闷、恶习和贫穷。"
- "读书越多，越感到腹中空虚。"
- "完美是美好的敌人。"

### 8.5 对后世思想的影响

伏尔泰是法国启蒙运动的领袖，被誉为"法兰西思想之王"。他对封建专制和宗教迷信的批判，为法国大革命奠定了思想基础。他对言论自由、宗教宽容的倡导，深刻影响了现代民主社会的核心价值观。

## 九、弗洛伊德（Sigmund Freud，1856—1939）

| 项目 | 内容 |
|------|------|
| 时代 | 19世纪末—20世纪 |
| 身份 | 神经学家、心理学家、精神分析学创始人 |
| 核心思想 | 潜意识、本我自我超我、梦的解析 |
| 代表著作 | 《梦的解析》《精神分析引论》《文明及其缺憾》 |
| 名言 | "梦是通往潜意识的皇家大道" |

### 9.1 生平时间线

- **1856年**：出生于奥匈帝国摩拉维亚（今捷克）一个犹太商人家庭
- **1881年**：获得维也纳大学医学博士学位
- **1885年**：赴巴黎跟随夏尔科学习催眠术
- **1899年**：出版《梦的解析》
- **1938年**：纳粹吞并奥地利，流亡伦敦
- **1939年**：在伦敦病逝，享年83岁

### 9.2 核心思想

- **潜意识理论**：人的大部分心理活动发生在意识之外
- **人格结构**：本我（id）、自我（ego）、超我（superego）
- **梦的解析**：梦是愿望的伪装满足，是了解潜意识的途径

### 9.3 人生故事

弗洛伊德出生于一个犹太商人家庭，幼年随家人迁居维也纳。他在维也纳大学学医，最初研究神经解剖学。

1885年，他前往巴黎跟随夏尔科学习催眠术，接触到歇斯底里症的研究，这改变了他的人生方向。回到维也纳后，他开始从事心理治疗。

1899年，他出版《梦的解析》，提出梦是潜意识愿望的满足。这本书在当时几乎无人关注，但它开创了精神分析学派。他的"性心理发展理论"和"俄狄浦斯情结"等观点引起巨大争议，许多同事与他决裂。但他坚持自己的研究，创立了国际精神分析协会。

1938年，纳粹吞并奥地利，身为犹太人的弗洛伊德流亡伦敦。1939年，他因口腔癌在伦敦去世。

### 9.4 名言警句

- "梦是通往潜意识的皇家大道。"
- "未被表达的情绪永远不会消亡，它们只是被活埋，终有一天会以更丑陋的方式涌现。"
- "人类的本性是兽性与文化的矛盾统一。"
- "爱你的工作，和你的上司保持距离。"

### 9.5 对后世思想的影响

弗洛伊德被誉为"精神分析之父"。他对潜意识的发现深刻改变了人类对自身的认识，影响了心理学、精神病学、文学、艺术、哲学等多个领域。

## 十、萨特（Jean-Paul Sartre，1905—1980）

| 项目 | 内容 |
|------|------|
| 时代 | 20世纪法国 |
| 身份 | 哲学家、作家、剧作家、社会活动家 |
| 核心思想 | 存在主义、存在先于本质、自由与责任 |
| 代表著作 | 《存在与虚无》《恶心》《存在主义是一种人道主义》 |
| 名言 | "人是被判定为自由的" |

### 10.1 生平时间线

- **1905年**：出生于巴黎一个海军军官家庭
- **1924年**：进入巴黎高等师范学校攻读哲学
- **1933年—1934年**：在柏林研究胡塞尔现象学
- **1943年**：出版哲学巨著《存在与虚无》
- **1964年**：获得诺贝尔文学奖，拒绝领奖
- **1980年**：在巴黎病逝，享年74岁

### 10.2 核心思想

- **存在先于本质**：人首先存在，然后通过选择定义自己的本质
- **绝对自由**：人注定是自由的，无法逃避选择的责任
- **介入**：知识分子应该介入社会，承担政治责任

### 10.3 人生故事

萨特出生不久父亲即去世，由外祖父抚养长大。1924年，他进入巴黎高等师范学校，与西蒙娜·德·波伏瓦相遇，此后两人成为终身伴侣。1933年，他赴德国研究胡塞尔现象学，接触到存在主义哲学。

1943年，他的哲学巨著《存在与虚无》出版，奠定了存在主义哲学的基础。二战期间，他参加法国抵抗运动。1964年，他获得诺贝尔文学奖，但拒绝领奖，理由是不想被体制化。

1980年，他在巴黎病逝，数万人为他送葬。

### 10.4 名言警句

- "人是被判定为自由的。"
- "存在先于本质。"
- "他人即地狱。"
- "人除了自己塑造的自己以外，什么都不是。"

### 10.5 对后世思想的影响

萨特是20世纪最具影响力的哲学家之一。他与波伏瓦共同创立了存在主义哲学，深刻影响了战后一代人的思想。他对自由、责任、介入的探讨，对知识分子的社会角色有深远影响。

## 十一、结语

这十位思想家横跨两千五百余年，从古希腊的石匠之子到20世纪的巴黎咖啡馆，他们以不同的方式追问人类存在的根本问题。阅读他们的故事，不仅是为了了解过去，更是为了理解我们自己。正如苏格拉底所言："未经审视的人生不值得过。"
