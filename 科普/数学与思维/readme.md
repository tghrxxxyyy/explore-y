# 科普 · 数学与思维

> 数学不只是算数，更是一种思维方式。本板块帮你建立三块基石：俯瞰数学全貌的「地图」（分支概览）、推理的「语法」（逻辑与证明）、在不确定中做决定的「工具」（概率与统计）。面向成人通识，重思想与方法，少公式堆砌。

## 子模块导航

| 文件 | 主题 | 核心内容 |
|------|------|----------|
| [数学分支概览](数学分支概览.md) | 数学地图 | 算术/代数/几何/微积分/离散数学/概率统计/应用数学各研究什么、彼此如何相连 |
| [逻辑与证明](逻辑与证明.md) | 逻辑 | 命题与推理、归纳与演绎、常见逻辑谬误、构造证明的基本思想（反证法/数学归纳法等） |
| [概率与统计思维](概率与统计思维.md) | 概率统计 | 概率基础、贝叶斯、大数定律、赌徒谬误等常见概率错觉、均值方差与假设检验的真正含义 |

## 阅读建议

1. **零基础**：按 概览 → 逻辑 → 概率 顺序：先有全景，再学推理，最后学不确定性决策。
2. **按需查阅**：想看懂体检报告与新闻数据读《概率与统计思维》；想少被诡辩忽悠读《逻辑与证明》；想给孩子选数学学习路线读《数学分支概览》。
3. **交叉关联**：
   - 贝叶斯（《概率与统计思维》）依赖条件逻辑（《逻辑与证明》）。
   - 数学归纳法（《逻辑与证明》）是离散数学（《数学分支概览》）的核心工具。

## 本板块说明

- 三篇均为「成人通识」体例：导语 + 分章节（概念→原理→生活实例→常见误区）+ 小结。
- 案例均标注出处或可检验推导；涉及统计推断处会强调「统计 ≠ 证明」的边界。
- 本板块**不构成任何医疗、投资或决策建议**；个体决策请结合自身情况与专业人士意见。
