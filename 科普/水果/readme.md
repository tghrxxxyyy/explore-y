## 本板块说明

- 本板块按**水果类型 + 产地来源**双线组织：热带/温带/亚热带按气候带分类，进口水果单独成篇。
- 每种水果包含**基本信息卡**：产地、上市时间、价格区间、保存方法、选购技巧。
- 营养成分以**每100克可食部分**为基准，数据参考中国食物成分表与 USDA 数据库。
- 健康功效基于现代营养学研究，注明**证据等级**（充分/有限/传统说法），不夸大疗效。
- 所有水果均标注**食用禁忌**与**适宜人群**，特别关注糖尿病患者、过敏体质、孕妇等特殊人群。
