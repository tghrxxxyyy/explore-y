# 奇异水果图鉴
> 一文了解15种外形独特、口感奇特的奇异水果，涵盖热带、温带与沙漠品种
---
## 一、菠萝蜜
> 📷 [一个完整的菠萝蜜果实，表皮有密集的六边形凸起]（图片来源：维基百科）
### 1.1 基础信息卡
| 项目 | 说明 |
|------|------|
| **中文名** | 菠萝蜜 |
| **学名** | Artocarpus heterophyllus |
| **别名** | 树菠萝、木菠萝、苞萝 |
| **原产地** | 印度西高止山脉 |
| **上市时间** | 6-10月 |
| **价格参考** | 8-20元/斤 |
| **保存方法** | 未切开常温，切开后冷藏3-5天 |
| **选购技巧** | 按压微软、香气浓郁为佳 |
### 1.2 外观与口感
- **体型巨大**：世界最大树生水果，单果重5-50公斤
- **表皮特征**：外皮坚硬黄绿色，布满六边形凸起
- **内部结构**：切开后可见数百个黄色果包，每个含一颗种子
- **口感特点**：干包爽脆有嚼劲，湿包软糯香甜，甜度极高
### 1.3 营养成分（每100克）
| 营养素 | 含量 | 说明 |
|--------|------|------|
| **热量** | 105千卡 | 中等偏低 |
| **碳水化合物** | 25.7克 | 以果糖为主 |
| **膳食纤维** | 1.5克 | 促进肠道蠕动 |
| **钾** | 448毫克 | 维持电解质平衡 |
### 1.4 食用与购买
- **鲜食**：对半切开，去除白色粘液，取出黄色果包食用
- **煮食**：种子去壳后可煮、炒或烤食，口感似板栗
- **购买渠道**：水果店、超市、批发市场
- **价格参考**：国产海南广东产8-15元/斤，进口更贵
> 来源：中国热带农业科学院、维基百科

## 二、红毛丹
> 📷 [几颗红毛丹，外壳布满红色软毛]（图片来源：图虫创意）
### 2.1 基础信息卡
| 项目 | 说明 |
|------|------|
| **中文名** | 红毛丹 |
| **学名** | Nephelium lappaceum |
| **别名** | 毛荔枝、韶子、红毛果 |
| **原产地** | 马来半岛 |
| **上市时间** | 6-9月 |
| **价格参考** | 20-40元/斤 |
| **保存方法** | 常温1-2天，冷藏3-5天 |
| **选购技巧** | 果壳红色鲜艳、软毛挺立为佳 |
### 2.2 外观与口感
- **外壳特征**：果壳鲜红色或粉红色，布满柔软红色软毛
- **内部结构**：剥开后可见半透明白色果肉，包裹深褐色种子
- **口感特点**：果肉多汁爽滑，类似荔枝但略带脆感
- **香气**：独特清香，介于荔枝和龙眼之间
### 2.3 营养成分（每100克）
| 营养素 | 含量 | 说明 |
|--------|------|------|
| **热量** | 75千卡 | 较低 |
| **碳水化合物** | 15.9克 | 以蔗糖为主 |
| **膳食纤维** | 2.8克 | 促进消化 |
| **维生素C** | 8毫克 | 含量一般 |
### 2.4 食用与购买
- **鲜食**：用指甲或刀片划开果壳，剥出果肉食用
- **甜品**：可制作红毛丹沙拉、冰淇淋或糖水
- **购买渠道**：进口超市、水果店、网购
- **保存提示**：红毛丹保存困难，建议现买现吃
> 来源：东南亚水果贸易协会、中国热带作物学会

## 三、杨桃
> 📷 [切开的杨桃呈现完美的五角星形状]（图片来源：摄图网）
### 3.1 基础信息卡
| 项目 | 说明 |
|------|------|
| **中文名** | 杨桃 |
| **学名** | Averrhoa carambola |
| **别名** | 五敛子、阳桃、三廉子 |
| **原产地** | 印度尼西亚 |
| **上市时间** | 9月至次年3月 |
| **价格参考** | 8-20元/斤 |
| **保存方法** | 常温3-5天，冷藏可存1周 |
| **选购技巧** | 果皮金黄、棱角分明为佳 |
### 3.2 外观与口感
- **独特形状**：果实卵形，有5条棱，横切面呈五角星形
- **颜色变化**：未熟青绿色，成熟后金黄色或橙黄色
- **口感特点**：果肉脆嫩多汁，甜度较低，带明显酸味
- **食用提示**：未成熟酸涩味重，需选完全成熟的
### 3.3 营养成分（每100克）
| 营养素 | 含量 | 说明 |
|--------|------|------|
| **热量** | 31千卡 | 非常低 |
| **碳水化合物** | 6.7克 | 糖分含量低 |
| **膳食纤维** | 2.8克 | 促进肠道蠕动 |
| **草酸** | 0.6克 | 肾病患者忌食 |
### 3.4 食用与购买
- **鲜食**：洗净后直接食用，连皮吃口感更脆
- **装饰**：五角星切面常用于鸡尾酒装饰
- **购买渠道**：水果店、超市、网购
- **注意事项**：草酸含量高，肾病患者应避免食用
> 来源：中国营养学会、维基百科

## 四、百香果
> 📷 [切开的百香果露出橙黄色的果肉和黑色籽]（图片来源：维基百科）
### 4.1 基础信息卡
| 项目 | 说明 |
|------|------|
| **中文名** | 百香果 |
| **学名** | Passiflora edulis |
| **别名** | 鸡蛋果、热情果、西番莲 |
| **原产地** | 巴西 |
| **上市时间** | 6-10月 |
| **价格参考** | 5-15元/斤 |
| **保存方法** | 常温至表皮皱缩更甜，冷藏2周 |
| **选购技巧** | 果皮深紫、手感重、香气浓郁为佳 |
### 4.2 外观与口感
- **外形特征**：果实椭圆形或鸡蛋形，直径6-8厘米
- **表皮颜色**：成熟时深紫色或紫红色，光滑有光泽
- **口感特点**：风味复杂，集菠萝、芒果等多种香气于一体
- **甜酸比例**：酸度较高，甜度适中，香气浓郁
### 4.3 营养成分（每100克）
| 营养素 | 含量 | 说明 |
|--------|------|------|
| **热量** | 97千卡 | 中等 |
| **碳水化合物** | 23.4克 | 以果糖为主 |
| **膳食纤维** | 10.4克 | 含量极高 |
| **维生素C** | 30毫克 | 含量较高 |
### 4.4 食用与购买
- **泡水**：对半切开，挖出果肉加入温水或蜂蜜水
- **做酱**：果肉加糖熬煮成酱，可涂抹面包
- **购买渠道**：水果店、超市、网购
- **品种选择**：紫皮酸度高，黄金甜度更高
> 来源：广西农业科学院、中国营养学会

### 十五、水果选购技巧

**看外观**：
- 果形端正：发育良好
- 色泽均匀：成熟度适当
- 无机械损伤：新鲜度好
- 无病虫害：品质优良

**摸手感**：
- 弹性适中：成熟度好
- 硬度过大：未成熟
- 过软：过熟或腐烂

**闻香气**：
- 香气浓郁：成熟度好
- 无异味：新鲜度好
