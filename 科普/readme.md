## 本板块说明

- 本板块偏**科普**，力求通俗易懂、有据可查。
- 经济知识板块侧重「经济运行原理」，与「金融投资/宏观」（投资视角）互补。
- 中华历史板块侧重「历史认知与文化素养」，按时间线与专题双线组织。
- 世界史板块与中华历史互参：主线叙述世界文明，每篇附「同期中国对照」表格。
- 动物/植物板块按**生物学分类体系**组织，覆盖主要门纲目科属与代表物种。
- 所有内容引用权威来源，以官方或学术著作为准。
- 本板块**不构成任何投资建议或学术定论**，仅供学习参考。
