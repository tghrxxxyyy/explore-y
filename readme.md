- 🗺️ **生活 · 旅行**：全国 34 个省级行政区全覆盖，每城含「城市特色 / 著名景点 / 人文历史」（江苏已细化到景点级）。

- 🧒 **生活 · 教育与亲子**：学区择校、兴趣班选择、教育金规划、育儿方法与亲子沟通。
- ⚖️ **生活 · 法律维权**：消费维权、劳动权益与仲裁、合同审查、房产与邻里法律。
- 📈 **金融投资 · 炒股 / 基金**：从零基础到进阶，体系化概念 + 实操提醒。
- 🛡️ **金融投资 · 保险**：配置逻辑、重疾/医疗、寿险/意外、避坑（保障优先于理财）。
