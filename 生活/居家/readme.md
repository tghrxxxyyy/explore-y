> 房子是普通人最大的开支之一。本板块把"住"相关的高频决策梳理成可操作清单：装修怎么不踩坑、租房买房怎么选、交易流程与避坑。

## 通用原则

1. **先想清楚"自己住还是投资"**：自住重舒适与通勤，投资重租售比与流动性。
2. **合同大于口头**：任何承诺写进合同/补充协议；定金、尾款、违约责任明确。
3. **大头在隐蔽工程**：水电、防水、结构不能省；表面装饰后期可改。
4. **留证据**：合同、收据、聊天记录、现场照片视频，纠纷时都是依据。
