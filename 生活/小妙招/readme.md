## 通用原则

1. **安全第一，强酸碱物分开用**：本板块多数妙招用的小苏打、白醋、柠檬酸温和无害；但**漂白剂（含 84 消毒液）、洁厕剂、管道疏通剂属强腐蚀性化学品，不可与酸类/碱类混用**——漂白剂遇洁厕剂等酸性物质会产生**有毒氯气**，可致呼吸道灼伤甚至中毒；用管道疏通剂后通风并远离，皮肤接触立即冲水。儿童与宠物接触范围禁用。
2. **先在小面积试用，再全量操作**：清洁剂、去渍法对材质有差异（石材怕酸、真丝怕碱、不粘锅怕硬刷），先在隐蔽角落小范围试，确认无变色、无损伤再扩大。
3. **电器清洁先断电**：微波炉、冰箱、油烟机、洗衣机清洁前拔掉电源，避免进水短路与触电。
4. **妙招解决不了的标准问题，看《生活常识》板块**：涉及食品安全、保质期、解冻与食物中毒防护等安全相关内容，以 [食品安全与科学储存](../生活常识/食品安全与科学储存.md) 为准；本板块只讲保鲜与清洁技巧，不做安全判定。
5. **互补不重复**：与 [收纳整理](../居家/收纳整理.md)（柜内分区、断舍离、扩容）互补——收纳解决"东西放哪"，本板块解决"东西怎么保持干净好用"；食材存放更详细的温度与时限依据见 [食品安全与科学储存](../生活常识/食品安全与科学储存.md)。
