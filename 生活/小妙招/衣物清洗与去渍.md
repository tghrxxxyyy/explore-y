# 衣物清洗与去渍

> 看懂洗涤标签、分类洗涤，再用家用材料对付顽固污渍，洗衣晾晒一步到位。

## 一、洗涤标签怎么看

- **水洗符号**：盆形图标，盆内数字即最高水温（如 30 表示最高 30°C 水洗）；盆下一横为缓和洗涤，两横为非常缓和。
- **漂白符号**：三角图标，空白可漂白、带斜线不可漂白、带"氯"字样仅可用氯漂。
- **干洗符号**：圆圈图标，圈内有字母为干洗剂代号；圆圈打叉为不可干洗。
- **熨烫符号**：熨斗图标，圆点越多温度越高（一点低温、三点高温）；打叉不可熨烫。
- **烘干符号**：圆圈在方框内，圆圈有点为控温烘干，方框打叉为不可机器烘干。
- **记住要点**：**标签不准就按最保守方式洗**（冷水 + 缓和 + 自然晾干），多数衣服宁可洗不净也不洗坏。

## 二、分类洗涤原则

- **深浅分色**：深色、浅色、白色分三批，深色首次下水单独洗，防止串色。
- **按材质分**：棉麻正常洗；真丝、羊毛、蕾丝用冷水 + 专用洗衣液（真丝用中性洗涤剂），最好手洗或装洗衣袋缓和洗；牛仔首次冷水固色。
- **按脏净分**：内衣、袜子与外套分开；毛巾、床单每周一次高温洗涤（60°C 以上可杀螨虫）。
- **水温选择**：棉麻、内衣可 40°C 左右；含羊毛、真丝、氨纶弹性面料**一律冷水**；血渍、蛋白类污渍只能用冷水，热水会烫熟蛋白质固渍。
- **新衣先处理**：新买的深色衣物先泡盐水固色，或单独洗一次再混洗。

## 三、顽固污渍去渍法

| 污渍 | 家用去渍法 | 要点 |
|---|---|---|
| 血渍 | 冷水冲洗 + 肥皂搓洗；干固血渍可先泡冷水 30 分钟 | 忌热水；血渍未干时处理效果最好 |
| 油渍（食用油/机油） | 小苏打糊（小苏打+水调成稠糊）厚涂静置 15 分钟，再搓洗；或洗洁精干涂油渍处揉搓 | 先干处理再下水，不要先沾水 |
| 果汁/红酒渍 | 冷水冲 + 盐覆盖吸色，再涂牙膏搓洗；或用白醋与水 1:3 局部浸洗 | 尽快处理，干固后先用温水泡软 |
| 咖啡/茶渍 | 热水冲 + 小苏打糊搓洗；白领衬衫可在汗渍处先涂柠檬汁暴晒 | 白色衣物效果明显 |
| 笔渍（圆珠笔） | 酒精或白酒倒在污渍处浸透，用棉签拍打吸附 | 垫毛巾防止渗透到下层；避免用肥皂先洗 |
| 霉斑 | 白醋浸泡 20 分钟再正常洗；顽固霉斑涂柠檬汁+盐后日照，或稀释漂白液（仅限白色纯棉） | 漂白液用前先试色，戴手套通风 |
| 汗渍黄渍（领口腋下） | 小苏打+白醋调糊敷 30 分钟；或柠檬汁搓洗后正常洗涤 | 白衬衫发黄处可小苏打热水泡 1 小时 |
| 口红/粉底 | 洗洁精干涂揉搓后冷水洗；顽固者用卸妆油/婴儿油先乳化再洗 | 切忌先沾水 |

## 四、洗涤剂怎么选

- **洗衣粉**：去污强但碱性重，适合棉麻外衣；化纤、精细面料慎用，易残留发硬。
- **洗衣液**：中性温和、易漂洗，日常衣物通用首选，彩色衣物用"护色"型。
- **洗衣凝珠**：浓缩高效，一颗按桶量投放，**不要剪开用、不要放收纳盒里让儿童碰到**。
- **皂粉/透明皂**：婴幼儿衣物、内衣专用，无荧光剂更放心；先搓再洗效果最好。
- **柔顺剂**：只给外衣用，毛巾浴巾速干衣不用（见第六节）。
- **洗衣误区**：过期洗衣液效果变差但无害，**先倒液后放衣**防衣物染色；羽绒服用中性洗衣液，忌碱性洗涤剂伤绒。

## 五、洗衣机使用细节

- **洗衣液用量**：按瓶身刻度与衣物总量来，**用量宁少勿多**——泡沫过多反而洗不净，残留会发硬发黏；高浓缩洗衣液半盖即可。
- **滚筒自清洁**：每月用"筒自洁"程序空桶高温洗一次（可加适量柠檬酸除垢），洗后开门通风晾干。
- **定期清洗过滤网/排水口**：波轮洗衣机底部过滤网、滚筒洗衣机门封圈胶条，每月清一次毛发与杂物。
- **门封圈保养**：滚筒用完擦干门封圈胶条，防霉点产生；发现霉点用稀释白醋擦拭。
- **放平与减震**：洗衣机四脚调平，不平会噪音大、伤内桶。
- **不洗过重单件**：羽绒被、大毛毯脱水容易偏心，建议送洗或分两次。
- **洗衣袋使用**：文胸、蕾丝、毛衣、带拉链件的衣物套袋再洗，保护面料与纽扣。

## 六、晾晒技巧

- **阴干优先**：真丝、羊毛、深色衣物、印花衣物一律阴干，暴晒会褪色、变硬、缩水。
- **白色衣物反晒**：白 T 恤、白衬衫可反面朝外晾，减少正面泛黄；白衣服洗后滴几滴柠檬汁可增白。
- **贴身衣袜**：内衣晾时避开直射阳光，防止老化变脆。
- **羽绒服**：平铺阴干，干透后轻拍恢复蓬松，忌暴晒与熨烫。
- **晾晒时间**：潮湿梅雨季衣物阴干易有霉味，可用烘干机或空调房吹干，比挂着"阴到干"更卫生。
- **甩干后抖开再晾**：洗衣机甩干后把衣物展平抖顺再挂，褶皱少一半；针织衫平铺晾晒防整体拉长变形。
- **晾完及时收**：衣物干透即收，晾太久落灰、被蚊虫污染，收时顺手按人分叠。

## 七、洗衣禁忌

- **柔顺剂别乱用**：柔顺剂会附着纤维降低吸水性——毛巾、浴巾、运动速干衣、婴儿服**不要用**；羊毛真丝有专用护理剂，普通柔顺剂会破坏纤维。
- **干洗标签别自己水洗**：标"仅可干洗"的西服、皮草、带硬衬的大衣，水洗会变形缩水，送去干洗店。
- **不能混洗的组合**：真丝与牛仔裤、白色与深红、羊毛与其他毛料（起球互相粘）。
- **别用开水烫洗**：色素与蛋白污渍遇热更固；热水只用于毛巾、床单消毒。
- **洗衣机洗完别忘开门**：洗后闷着不通风，筒内滋生霉菌，下一桶衣服等于白洗。

## 八、常见问题速答

- **衣服洗后一股霉味**：洗衣机筒没自洁 + 晾晒不干所致；先空桶筒自洁，衣物重洗后务必彻底晾干。
- **白衣服越洗越黄**：氧化泛黄，柠檬汁浸泡或稀释漂白液（仅白色纯棉，先试色）。
- **毛衣洗后缩水**：温水手洗 + 平铺晾干；已缩水可用护发素水浸泡后轻轻拉伸回形。
- **不小心串色**：发现后立即取出，浅色衣物按漂白产品说明补救；混洗前先用湿布按衣角搓做掉色测试。
- **羽绒服洗后结块**：漂洗多一遍清水，干透后轻拍抖散，恢复蓬松。
