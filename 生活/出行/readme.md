## 通用原则

1. **早规划 > 临期抢**：国际/旺季机票、热门酒店越早越从容。
2. **比价用工具，下单看渠道**：比价平台看全，但最终下单比价官方 APP/官网/OTA 差价。
3. **退改规则先读**：特价票常不可退改，买前确认。
4. **证件有效期**：护照剩 6 个月以上再出行；签证材料留足提前量。
