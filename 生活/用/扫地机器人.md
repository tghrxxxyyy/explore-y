# 扫地机器人

> 扫拖一体已成主流，核心看导航（激光/LDS 优于随机）、避障（结构光/AI 识别）、自集尘/自清洗基站——选购心法：先定预算与户型，再按"吸力够用、能洗拖布、不缠毛、能越障"四要素选型号，别为用不上的参数买单。

## 一、原理与分类（小白必看）

### 1. 技术原理
扫地机器人 = 移动底盘 + 传感器 + 尘盒/水箱 + 基站。机器通过导航传感器扫描房间、绘制地图、规划清扫路径；拖地机型在回充时由基站自动洗拖布、热风烘干、自动集尘、补水，部分机型还能自动上下水，实现"彻底不脏手"。

### 2. 类型区分
**按导航方式**
- **LDS 激光雷达**：主流方案，建图快且准，机身需留凸起（或被做成可升降/嵌入）。
- **dToF 导航**：石头、云鲸部分机型采用，机身可做矮（约 95–98mm），易钻床底。
- **视觉/VSLAM 导航**：摄像头建图，机身矮，但涉及隐私（科沃斯做成可物理遮蔽模组）。
- **随机碰撞**：老式方案，已逐步淘汰，仅见于百元机。

**按避障方式**
- **红外/超声波**：仅防跌落、防碰撞，无法识别具体物体。
- **3D 结构光**：中高端主流，能识别鞋子、袜子、数据线等。
- **AI 视觉/双目**：旗舰方案，可识别并绕开宠物粪便、充电线（石头、追觅双线激光+AI）。
- **机械臂/外扩边刷**：解决墙角、踢脚线覆盖盲区（2025 主流下放）。

**按基站形态**
- **自集尘**：自动倒垃圾，尘袋 1–3 月换一次。
- **自洗拖布 + 烘干**：免去手洗拖布、防霉味。
- **自动上下水**：接水管，连加清水倒污水都省了（需预留位置）。
- **滚筒活水洗地**：2025 年由旗舰下放主流，喷淋+恒压刮条实时洗拖布，比旋转拖布更去污。

### 3. 关键参数名词解释

| 名词 | 含义 | 怎么选 |
| --- | --- | --- |
| 吸力（Pa） | 风机真空度，越大吸尘越强 | 15000Pa 已够日常；20000–30000Pa 为旗舰，边际效益递减 |
| 对地压强 | 拖布下压力（如 12N/3800Pa） | 重油污选带加压的，去污更彻底 |
| 越障高度 | 翻门槛/滑轨能力 | 普通家庭 2–3cm 够用；移门滑轨选 4–6cm |
| 热水洗拖布 | 基站用 60–100℃ 水冲洗拖布 | 厨房重油污/母婴除菌优先选 75℃ 以上 |
| 机械臂/外扩 | 边刷拖布伸出扫边角 | 户型多死角、家具贴墙必看 |
| 基站功能 | 集尘/洗布/烘干/上下水 | 想省心选"全能基站"，懒人上"自动上下水" |
| 续航/电池 | 5200mAh 约 140–180 分钟 | 100㎡ 选 60 分钟以上，大平层看"回充续扫" |
| 噪音 | 工作分贝 | 选 ≤65dB，夜间不打扰 |
| 尘袋/尘盒 | 集尘容量与更换周期 | 有宠物选大尘袋（60–75 天免倒） |

## 四、参数怎么看（选购看懂规格表）

- **吸力不是越大越好**：超过 15000Pa 后，日常瓷砖/木地板的清洁差异极小，重点看"对地压强"和"拖布清洁逻辑"。除非厚地毯/深缝隙，25000Pa 与 30000Pa 体感接近。
- **越障高度按需选**：普通家庭 2–3cm 足够；有阳台推拉门、门槛、滑轨选 4cm 以上，追觅 X50 的 6cm 为目前量产最高。
- **热水洗拖布看温度**：60℃ 可溶普通油污，75–100℃ 对干涸酱油、厨房重油更有效，配合"浸泡洗"效率提升 40%+。
- **防缠毛认结构**：双锥形滚刷（石头）、混合双滚刷+气旋（追觅）、梳齿+气旋结构优于单胶刷；长毛宠物家庭优先"0 缠绕"认证机型。
- **基站看"几自动"**：基础=自动洗拖布+烘干；进阶=加自动集尘+补水；终极=自动上下水+拖布自动拆装。家里有预留上下水位置直接上"上下水版"最省心。
- **导航优先 LDS/dToF**：建图快且准；纯视觉在暗处/反光环境易偏航。重视隐私可选物理遮蔽模组（科沃斯）。
- **噪音与续航**：选 ≤65dB；5200mAh 电池约覆盖 140–180㎡单充，大户型确认有"回充续扫"。

### 不同预算"闭眼入"
- **2000 元内**：小米米家扫拖机器人 5C（结构光避障越级）。
- **2500–3500 元**：云鲸 J6（拖地）或科沃斯 T80S（全能活水）；养宠加一点上石头 P20 Ultra。
- **3500–5000 元**：石头 P20 Ultra Plus（均衡标杆）或追觅 X50 Pro（性能怪兽）。
- **5000 元以上**：石头 G20S Ultra / 云鲸逍遥 003（体验封顶）；地毯党单独看戴森。

### 特殊需求
- **宠物掉毛**：认"双滚刷/双锥形+气旋防缠"，尘袋选 60–75 天容量，避开单胶刷老机型。
- **重油污厨房**：选带"加压湿拖+75℃ 以上热水洗布"的滚筒/履带机型。
- **水质/地材无关，但低矮家具多**：机身高度选 ≤98mm（科沃斯 T80S、石头 dToF 机型）。

## 六、避坑与常见误区

- **吸力数字游戏**：部分品牌标 25000–30000Pa，但日常 15000Pa 已够；别为纸面参数多花钱，看"对地压强"更实在。
- **"热水洗"温度虚标**：认准实测 60℃ 以上，低于 50℃ 的热水对重油几乎无效。
- **耗材隐性成本**：自集尘尘袋（约 1–3 月换，年成本 100–300 元）、滚刷/边刷（年 100–200 元）、清洁液。买前算 2 年耗材总账，别只看机器价。
- **"0 缠绕"宣传**：多为特定条件实验室数据，长丝状异物仍可能残留；养宠重点看真实评测而非标语。
- **自动上下水需预留**：无预留位置买上下水版用不了，水箱版也能用但需手动换水（半解放）。
- **国际品牌国行溢价**：iRobot、戴森国内定价远高于海外促销价，且拖地/基站功能常落后于同价国产旗舰；按需求而非品牌光环选。
- **二手/库存老款**：导航与避障换代快，一年前的旗舰可能已被新款在避障上反超，优先买当年新款。
- **隐私顾虑**：纯视觉导航机型摄像头可能被入侵，选可物理遮蔽模组或 LDS/dToF 机型更安心。

## 七、使用与维护

- **日常**：每次使用后倒净污水箱、冲洗拖布托盘；尘袋满了再换（别频繁开合浪费）。
- **周维护**：清理边刷/滚刷缠绕毛发；擦拭传感器与充电极片；检查轮子有无线绳。
- **月维护**：清洗基站清水箱与过滤棉；用附赠工具疏通出水孔；APP 查看滤网状态。
- **耗材更换周期与年成本（估算）**：
  - 尘袋：1–3 月/个，约 30–80 元/个 → 年约 120–300 元
  - 主滚刷：6–12 月，约 80–150 元 → 年约 100–200 元
  - 边刷：3–6 月，约 30–60 元 → 年约 60–120 元
  - 清洁液/除味：年约 50–100 元
  - 合计：主流机型年耗材约 300–700 元；高端全能基站略高。
- **延长寿命**：长期不用保持半电存放、每月至少充放一次；避免阳光直射基站；水质硬地区给清水箱用纯净水减少水垢；固件及时升级优化路径。
