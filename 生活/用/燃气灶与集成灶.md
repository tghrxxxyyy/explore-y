# 燃气灶与集成灶

> 燃气灶是厨房的火力引擎，集成灶是"灶+烟+蒸烤"的三合一方案；选购心法是"火力看热负荷与热效率、安全看熄火保护、安装看气源与开孔"，而燃气安全永远排在性能与颜值之前。

## 一、燃气灶原理与分类（小白必考）

### 1.1 火力：热负荷才是"猛"的关键

| 火力档位 | 热负荷 | 适用 |
| --- | --- | --- |
| 基础款 | 4.0-4.2kW | 煲汤煮饭、日常小炒够用 |
| 主流款 | 4.5kW 左右 | 中餐爆炒的及格线 |
| 猛火款 | 4.8-5.2kW | 猛火快炒、颠锅锁水，大厨向 |

- **看"有效火力"而非标称**：热负荷（kW）× 热效率 = 真正进锅的热量。一台 5.2kW 但效率 55% 的灶，火力未必比 4.5kW 效率 65% 的强。
- **中环小火**：多数家庭 80% 时间是小火慢炖，中环火能否"稳而不灭"比最大火更重要，别只盯着峰值参数。

### 1.2 热效率与能效等级

| 能效等级 | 嵌入式灶热效率 | 说明 |
| --- | --- | --- |
| 一级能效 | ≥63% | 省气明显，主流在售款多为一级 |
| 二级能效 | ≥59% | 及格线 |
| 三级能效 | ≥55% | 多为老款/低价款，不推荐 |

- 一级能效的差距在燃气费上不大（每月约省几元到十几元），但通常意味着燃烧器设计与炉头用料更好，火焰更蓝更均匀。

### 1.3 炉头材质：决定寿命与火力均匀度

| 材质 | 特点 | 常见区间 |
| --- | --- | --- |
| 纯铜/铜合金 | 导热快、不易生锈变形、火盖精密 | 中高端标配，贵的核心在铜含量 |
| 铸铁 | 厚重耐烧、蓄热好，但易生锈需养护 | 中端款 |
| 铝合金 | 轻、便宜，但高温易变形、氧化 | 入门款，不推荐长期使用 |

### 1.4 点火与安全功能

- **熄火保护**：国标强制（2009 年起），火焰意外熄灭自动切断气源，防止漏气。分**热电偶式**（熄火后数秒内关阀，可靠）与**离子感应式**（响应更快但耗电、需电池充足）。2026 年在售正品均有，买二手/杂牌务必当场验证。
- **点火方式**：脉冲电子点火为主，电池供电，留意电池仓是否好换；高端款带"零秒点火"与风门自动调节。
- **防爆玻璃面板**：钢化玻璃面板需带防爆膜/防爆工艺（自爆率极低但偶发），正规品牌均有保险。
- **童锁与防空烧**：儿童锁旋钮必备；部分高端款带"离锅熄火/防空烧自动关阀"。

### 1.5 面板材质

| 材质 | 优点 | 缺点 | 适合 |
| --- | --- | --- | --- |
| 不锈钢 | 耐用抗造、不怕热锅砸 | 易留指纹油污、划痕明显 | 中式爆炒重户 |
| 钢化玻璃 | 颜值高、好擦洗 | 相对脆，重物撞击/温差大时风险 | 主流首选 |
| 陶瓷/岩板 | 耐高温、质感好 | 贵、重、易碎 | 高端厨房 |

## 二、集成灶原理与分类

### 2.1 烟灶联动与下排烟

- **烟灶联动**：开火即自动开烟机，关火延时关机，这是集成灶的基本素养，多数款支持。
- **下排烟原理**：油烟从灶台两侧/后方的进风口直接向下吸入，风道在机身底部向后排出，烟机不占上方吊柜空间，厨房顶空更干净。
- **风量与风压**：主流 17-21m³/min 风量、静压 400-700Pa；高层住宅低楼层住户注意选大静压款，防公共烟道倒灌。
- **下排烟的代价**：排烟口在底部，需在烟道/外墙下方开孔走管；旧厨房改造要评估橱柜与烟道位置。

### 2.2 功能模块：消毒柜/蒸烤箱/蒸烤一体

| 模块类型 | 特点 | 适合 |
| --- | --- | --- |
| 消毒柜模块 | 便宜、实用，收纳碗筷 | 预算有限、传统家庭 |
| 蒸箱模块 | 蒸汽量大，蒸菜专业 | 注重健康蒸食 |
| 烤箱模块 | 容量偏小（下方空间受限） | 烘焙入门 |
| 蒸烤一体模块 | 蒸烤组合，一机多能 | 主流选择，2026 年最受欢迎 |

- 集成灶底部模块是核心溢价点，蒸烤一体款比消毒柜款贵 3000-6000 元；想清楚自己到底蒸多还是烤多。

### 2.3 安装条件与公共烟道

- **空间**：集成灶贴墙安装，两侧需留橱柜衔接尺寸（多为 750/900mm 宽），接缝处理依赖安装精度。
- **烟道**：下排烟需要从底部走管，公共烟道住宅需在烟道侧壁下方开孔，很多老小区烟道预留口在上方，需改管或确认物业许可。
- **橱柜**：基本要配合集成灶改橱柜或定制柜，整体成本要算进去。
- **燃气接入**：进气口位置低，需按规范用专用波纹管连接，不可与电源插座同侧贴地布置。

### 2.4 集成灶 vs 分体烟灶对比

| 维度 | 分体烟灶 | 集成灶 |
| --- | --- | --- |
| 价格 | 灶 300-3000 + 烟机 1000-5000 | 5000-20000+ |
| 吸油烟 | 顶吸/侧吸，常规够用 | 近吸下排，爆炒场合更强 |
| 空间 | 烟机占吊柜/上墙 | 省顶柜空间，底部集成模块 |
| 美观 | 分体独立 | 一体性强、整体感好 |
| 维护 | 烟机灶独立更换 | 整机维修，坏一处影响全部 |
| 适合 | 大多数家庭 | 开放式厨房、爆炒多、追求一体感 |

## 四、燃气灶选购避坑

1. **气源必须分清**：天然气（12T，管道气）与液化石油气（20Y，瓶装罐气）的喷嘴口径不同，**绝不能混用**。买错气源轻则火焰异常，重则一氧化碳超标。下单前确认小区/橱房气质，换气源需厂家专业改装喷嘴。
2. **安装资质**：燃气具安装必须由燃气公司或持证专业人员完成并验收，私自安装燃气公司有权拒绝通气；集成灶更是涉及烟道与燃气双路，务必走品牌官方安装。
3. **开孔尺寸核对**：标准嵌入式开孔约 650×350mm，换灶前先量旧孔；新灶常比旧孔小，需扩孔或加垫板，别只看面板尺寸。液化气换天然气还要清理旧管。
4. **熄火保护的"有"与"好"**：二手/杂牌灶可能拆掉热电偶，验货时开火用风吹灭测试；离子感应款电池亏电会偶发失灵，牢记换电池周期。
5. **钢化玻璃面板**：认准"防爆膜/防爆工艺"+产品责任险；台面极热时不要直接浇冷水，杜绝局部骤然降温。
6. **3C 认证**：燃气灶属强制认证产品，包装箱必须有 3C 标志与能效标识，查得到型号才买。
7. **换灶注意**：老灶换新先拆旧清洁台面，确认气源、管径（天然气 4 分管/液化气专用减压阀）、通风条件；集成灶则要先确认烟道开孔位置与橱柜改造预算。
8. **别迷信"5.2kW"**：配合一级能效看有效火力；猛火对小户型、开放式厨房反而是噪音与热浪负担。

## 五、燃气安全提醒（必读）

> 燃气安全高于一切性能参数。以下内容请记住并转告家人。

- **闻到燃气味时，第一动作是开窗通风**，让燃气尽快稀释排出，同时关闭入户燃气总阀。
- **不要开任何电器**：不要开灯、开抽油烟机、按门铃、打电话（尤其不要在室内），火花即火种。
- **撤离并报警**：人员撤到室外安全处，拨打燃气公司 24 小时报修电话或 119 说明情况，等待专业人员处理。不要自行维修或试压。
- **日常预防**：定期用肥皂水涂抹管接头查漏（冒泡即漏）；胶管/波纹管到期更换（胶管 18 个月、金属波纹管 8 年左右），不超长（不超过 2 米）、不穿墙。
- **灶具判废年限 8 年**：超期灶具密封圈老化、熄火保护失效风险大增，该换就换。
- **使用习惯**：做饭人不离灶，汤水溢出浇灭火焰是漏气高发场景；保持厨房通风，避免一氧化碳积聚。
