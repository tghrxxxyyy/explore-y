# 气象与自然灾害应对

> ## ⚠️ 重要免责声明
>
> **灾害来临时，一律以当地气象部门、应急管理部门发布的实时预警和官方指引为准。**
>
> - 本文为**科普整理**，内容依据中国气象局、应急管理部、自然资源部、中国地震局、国家卫生健康委等部门公开发布的规章、标准与新闻发布会资料，**不构成专业防灾指导或应急决策依据**。
> - 我国幅员辽阔，**各省、自治区、直辖市可以根据本行政区域内气象灾害的特点，选用或者增设预警信号种类、设置不同信号标准**〔中国气象局令第16号，第十六条〕。因此本文所列国家层面标准可能与您所在地的地方标准存在差异，**以当地气象台发布为准**。
> - 预警信号、防御指南会随法规修订而调整。若本文与官方**最新发布**不一致，**一律以官方最新发布为准**。
> - 紧急情况请拨打：**110**（公安）/ **119**（消防救援）/ **120**（医疗急救）/ **12379**（国家预警信息发布）。
> - 现场避险务必**先确保自身安全**，服从基层干部和专业救援人员的指挥。

## 一、气象灾害预警信号总则

### 1.1 四级颜色分级

根据 **《气象灾害预警信号发布与传播办法》（2007年6月12日中国气象局第16号令公布，自发布之日起施行）** 第三条：

> 预警信号的级别依据气象灾害可能造成的危害程度、紧急程度和发展态势**一般划分为四级：Ⅳ级（一般）、Ⅲ级（较重）、Ⅱ级（严重）、Ⅰ级（特别严重），依次用蓝色、黄色、橙色和红色表示**，同时以中英文标识。

| 颜色 | 级别 | 严重程度 | 公众行动导向 |
|---|---|---|---|
| 🔵 蓝色 | Ⅳ级 | 一般 | 关注天气变化，调整出行安排 |
| 🟡 黄色 | Ⅲ级 | 较重 | 做好防范准备，避免前往危险区域 |
| 🟠 橙色 | Ⅱ级 | 严重 | **明确的避险行动指令**，减少外出 |
| 🔴 红色 | Ⅰ级 | 特别严重 | **停止外出**，按官方要求撤离避险 |

> 国家预警信息发布中心副首席杨继国在新华访谈中提示：「蓝、黄、橙、红，由低到高排列……**不管是大风也好，暴雨也好，如果发到了橙色和红色的时候，就要特别要注意了**。」〔中国气象局转载新华访谈，2025-08-08〕

### 1.2 预警信号的种类

办法第二条明确，预警信号由**名称、图标、标准和防御指南**组成，分为**台风、暴雨、暴雪、寒潮、大风、沙尘暴、高温、干旱、雷电、冰雹、霜冻、大雾、霾、道路结冰**等〔中国气象局令第16号〕。

**注意：并非所有灾种都是四级。** 按办法附件《气象灾害预警信号及防御指南》：

| 灾种 | 级别数 | 具体颜色 |
|---|---|---|
| 台风、暴雨、暴雪、寒潮、大风 | 四级 | 蓝、黄、橙、红 |
| 沙尘暴、高温、雷电、大雾、道路结冰 | 三级 | 黄、橙、红 |
| 霜冻 | 三级 | 蓝、黄、橙 |
| 干旱、冰雹、霾 | 二级 | 干旱与冰雹为橙、红；霾为黄、橙 |

### 1.3 预警信息的属地性

- 气象灾害预警实行**属地化发布**。以北京为例，可能收到市级预警，也可能收到区级预警；**所在区、县的预警最为精确**〔中国气象局转载新华访谈，2025-08-08〕。
- 预警信号实行**统一发布制度**，只能由各级气象主管机构所属气象台站发布，**其他任何组织或者个人不得向社会发布预警信号**〔中国气象局令第16号，第七条〕。
- 媒体和通信网络**不得更改和删减预警信号内容，不得传播虚假、过时的气象灾害预警信号**〔同上，第十条〕。遇到来源不明的"预警"，请以中国气象局官网、中央气象台、中国天气网核实。

## 二、暴雨与城市内涝

### 2.1 暴雨预警信号标准

| 信号 | 标准（原文） |
|---|---|
| 🔵 蓝色 | 12小时内降雨量将达50毫米以上，或者已达50毫米以上且降雨可能持续 |
| 🟡 黄色 | 6小时内降雨量将达50毫米以上，或者已达50毫米以上且降雨可能持续 |
| 🟠 橙色 | 3小时内降雨量将达50毫米以上，或者已达50毫米以上且降雨可能持续 |
| 🔴 红色 | 3小时内降雨量将达100毫米以上，或者已达100毫米以上且降雨可能持续 |

〔中国气象局令第16号，附件《气象灾害预警信号及防御指南》二、暴雨预警信号〕

官方防御指南要点：黄色时应"切断低洼地带有危险的室外电源"；橙色时"处于危险地带的单位应当停课、停业"；**红色时"停止集会和停课、停业（除特殊行业外）"，并"做好山洪、滑坡、泥石流等灾害的防御和抢险工作"**〔同上〕。

### 2.2 城市内涝八条安全提示

在国家防灾减灾救灾委员会办公室、应急管理部 2025年8月5日汛期安全知识发布会上，中国水利水电科学研究院防洪抗旱减灾中心副主任杨昆给出八点提示〔应急管理部汛期安全知识发布会，2025-08-05〕：

1. **关注预警** —— 时刻关注应急、水利、气象、交通等部门发布的暴雨、洪水预警以及实时路况。
2. **避险为上** —— 暴雨期间坚持非必要不外出、不涉水；家中常备瓶装水、不易变质食物、收音机、常用药品、应急灯。**地下室、地下车库已经进水的，千万不要涉险进入。**
3. **注意断电** —— 室内有积水进入风险时，**立刻关闭家中电源总闸**，避免触电。
4. **远离带电物** —— 远离电线杆、路灯杆、变压器、配电箱等；**若电线掉落在水中，极其危险，必须远离**。
5. **注意漩涡** —— 路面出现漩涡或涌泉，往往意味着**下水道井盖已被冲开**，或存在深坑、激流，必须绕行。
6. **果断弃车** —— 不能准确判断水深时，**宁绕行不涉水**；被困深水要马上弃车逃生。
7. **及时求救** —— 被困立即拨打 110、119。
8. **卫生防疫** —— 不要让皮肤长时间接触积水，涉水后尽快彻底清洁；**皮肤有伤口更要避免进入积水**；只喝瓶装水或煮沸的水，不吃被洪水浸泡过的食物。

### 2.3 涉水行车的深度判断

| 积水深度 | 风险与处置（依据官方发布会口径） |
|---|---|
| < 30 厘米（不到半个轮胎） | 若判断准确，可**低速匀速**通过；中间**别换挡、别松油、别急加速** |
| 20–25 厘米 | 普通轿车已有**发动机进水风险** |
| 到保险杠或轮胎 2/3 | **应果断绕行** |
| 约 60 厘米 | 一般车辆大概率**熄火、漂浮**，水压会锁死车门 |
| 漫水桥被淹没 | 无法判断风险且水流冲击力极大，**果断掉头** |

〔应急管理部国家减灾中心灾害评估部主任吴玮、中国水利水电科学研究院杨昆，汛期安全知识发布会口径〕

**车辆涉水熄火或断电后：** 不要再启动车辆，不要在车内等待救援，立即弃车逃离；**车门被水压顶住打不开时，用破窗器等工具击打侧窗四个角**，天窗也可作为逃生出口〔同上〕。

### 2.4 触电风险专项

- 路面积水时，远离路灯、配电箱、充电桩、浸泡在水中的电力设施，**严禁蹚水靠近**。
- 发现电线垂入水中，**绕行并及时告知电力、交通等部门**。
- 家中进水，**及时关闭电源、燃气阀**；即便积水尚未没过家电、插座，也应先断电。
- 住低层的住户，积水往屋里灌时应立刻**关掉室内电源和燃气，向楼房高层或楼顶转移，绝对不要待在地下室**。

## 三、台风

### 3.1 台风预警信号标准

| 信号 | 标准（原文） |
|---|---|
| 🔵 蓝色 | 24小时内可能或者已经受热带气旋影响，沿海或者陆地平均风力达**6级**以上，或者阵风**8级**以上并可能持续 |
| 🟡 黄色 | 24小时内可能或者已经受热带气旋影响，沿海或者陆地平均风力达**8级**以上，或者阵风**10级**以上并可能持续 |
| 🟠 橙色 | 12小时内可能或者已经受热带气旋影响，沿海或者陆地平均风力达**10级**以上，或者阵风**12级**以上并可能持续 |
| 🔴 红色 | 6小时内可能或者已经受热带气旋影响，沿海或者陆地平均风力达**12级**以上，或者阵风达**14级**以上并可能持续 |

〔中国气象局令第16号，附件一、台风预警信号〕

### 3.2 防风加固与撤离

按官方防御指南分级行动：

- **蓝色**：停止露天集体活动和高空等户外危险作业；**加固门窗、围板、棚架、广告牌**等易被风吹动的搭建物，**切断危险的室外电源**。
- **黄色**：停止室内外大型集会和高空等户外危险作业；**人员切勿随意外出，确保老人小孩留在家中最安全的地方，危房人员及时转移**。
- **橙色**：停止室内外大型集会，停课、停业（除特殊行业外）；船舶回港避风；**注意防范强降水可能引发的山洪、地质灾害**。
- **红色**：停止集会、停课、停业（除特殊行业外）；**人员应当待在防风安全的地方**；危房人员及时转移。

〔中国气象局令第16号，附件一〕

### 3.3 「台风眼」绝不能外出

**这是官方防御指南中明确写入的警示条款**，台风橙色、红色预警的防御指南均载明：

> **当台风中心经过时风力会减小或者静止一段时间，切记强风将会突然吹袭，应当继续留在安全处避风**，危房人员及时转移。

〔中国气象局令第16号，附件一、（三）台风橙色预警信号 / （四）台风红色预警信号，防御指南第4条〕

即：台风眼过境时的"风平浪静"是**假象**，眼壁再次扫过时风向会骤然反转、风力瞬间恢复到最强，此时外出极易伤亡。

## 四、雷电

### 4.1 雷电预警信号标准

| 信号 | 标准（原文） |
|---|---|
| 🟡 黄色 | 6小时内可能发生雷电活动，可能会造成雷电灾害事故 |
| 🟠 橙色 | 2小时内发生雷电活动的可能性**很大**，或者已经受雷电活动影响且可能持续，出现雷电灾害事故的可能性比较大 |
| 🔴 红色 | 2小时内发生雷电活动的可能性**非常大**，或者已经有强烈的雷电活动发生且可能持续，出现雷电灾害事故的可能性非常大 |

〔中国气象局令第16号，附件九、雷电预警信号〕

### 4.2 官方防御指南要点

**室外（橙色预警防御指南原文）：**

- 户外人员应当**躲入有防雷设施的建筑物或者汽车内**；
- **不要在树下、电杆下、塔吊下避雨**；
- **在空旷场地不要打伞**，不要把农具、羽毛球拍、高尔夫球杆等**扛在肩上**。

**室内（红色预警防御指南原文）：**

- 尽量躲入有防雷设施的建筑物或者汽车内，**并关好门窗**；
- **切勿接触天线、水管、铁丝网、金属门窗、建筑物外墙**，远离电线等带电设备和其他类似金属装置；
- 尽量不要使用**无防雷装置或者防雷装置不完备**的电视、电话等电器。

〔中国气象局令第16号，附件九〕

中国气象学会专家在全国防灾减灾日补充提示：关闭电视等家用电器并**拔掉电源线插头**，防止雷电从电源线入侵；**打雷时不宜洗澡，特别是太阳能热水器用户**；立即停止游泳、划船、钓鱼等水上活动；不要在户外使用手机，不要使用有金属尖端的雨伞；远离孤立的大树、高塔、电线杆、广告牌〔中国气象局转载新华社，2013-05-13〕。

## 五、高温与中暑

### 5.1 高温预警信号标准（三级：黄、橙、红）

| 信号 | 标准（原文） |
|---|---|
| 🟡 黄色 | **连续3天**日最高气温将在 **35℃** 以上 |
| 🟠 橙色 | 24小时内最高气温将升至 **37℃** 以上 |
| 🔴 红色 | 24小时内最高气温将升至 **40℃** 以上 |

〔中国气象局令第16号，附件七、高温预警信号〕

**注意：高温预警没有蓝色级别。**

官方防御指南：黄色时"午后尽量减少户外活动"；橙色时"高温条件下作业的人员应当**缩短连续工作时间**"，并**注意防范因用电量过高、电线变压器等电力负载过大而引发的火灾**；**红色时"停止户外露天作业（除特殊行业外）"**，对老、弱、病、幼人群采取保护措施〔同上〕。

### 5.2 中暑的分类（GBZ 41—2019）

根据国家职业卫生标准 **GBZ 41—2019《职业性中暑的诊断》**（国家卫生健康委发布，2019-01-30 发布、2019-07-01 实施，代替 GBZ 41-2002）：

| 类型 | 主要表现（标准原文要点） |
|---|---|
| **中暑先兆** | 头晕、头痛、乏力、口渴、多汗、心悸、注意力不集中、动作不协调等，**体温正常或略有升高但低于 38.0℃**，可伴面色潮红、皮肤灼热，**短时间休息后症状即可消失** |
| **热痉挛** | 大量出汗后出现短暂、间歇发作的**肌痉挛，伴有收缩痛**，多见于四肢肌肉、咀嚼肌及腹肌，尤以腓肠肌为著，呈对称性；**体温一般正常** |
| **热衰竭** | 以**血容量不足**为特征：多汗、皮肤湿冷、面色苍白、恶心、头晕、心率明显增加、低血压、少尿，**体温常升高但不超过 40℃**，可伴眩晕、晕厥 |
| **热射病**（含日射病） | 以**体温明显增高及意识障碍**为主：皮肤干热、无汗、**体温高达 40℃ 及以上**，谵妄、昏迷等；可伴全身性癫痫样发作、横纹肌溶解、多器官功能障碍综合征 |

> **说明：** GBZ 41—2019 相比 2002 年版**删除了诊断分级**，改为按中暑先兆、热痉挛、热衰竭、热射病描述。日常科普中常见的"先兆中暑／轻症中暑／重症中暑"三分法源自更早的 GB 11508-1989，**现行职业卫生标准已不再采用**。

### 5.3 处理原则（GBZ 41—2019 第6章）

| 情形 | 标准载明的处理原则 |
|---|---|
| 中暑先兆 | **立即脱离高温环境**，到通风阴凉处休息、平卧；予含盐清凉饮料及对症处理，并**密切观察** |
| 热痉挛 | 纠正水与电解质紊乱及对症治疗 |
| 热衰竭 | 物理降温和（或）药物降温，注意监测体温，纠正水电解质紊乱，扩充血容量、防止休克 |
| 热射病 | **快速降温**，持续监测体温，保护重要脏器功能，呼吸循环支持等——**属致命性急症，须立即拨打 120** |

### 5.4 老幼与重点人群

各级高温预警防御指南均要求"对老、弱、病、幼人群提供防暑降温指导"并"采取必要的防护措施"〔中国气象局令第16号〕。日常提示：

- **绝不将儿童、老人或宠物单独留在停放的汽车内**——密闭车厢升温极快。
- 高温时段（一般为 11:00–16:00）避免强体力活动；老年人、孕妇、有慢性病特别是心血管疾病者尽可能减少外出。
- 少量多次补水，出汗多时补充盐分和电解质；避免含酒精或大量糖分的饮料。
- 空调温度不宜过低，避免室内外温差过大。

### 6.4 保暖、防滑与防冻

- **保暖**：寒潮黄色及以上预警防御指南明确要求"注意添衣保暖，**照顾好老、弱、病人**"〔中国气象局令第16号〕。
- **防滑**：暴雪、道路结冰预警防御指南均要求"**行人注意防寒防滑**，驾驶人员小心驾驶，车辆应当采取防滑措施"；道路结冰橙色时"驾驶人员**必须采取防滑措施**，听从指挥，慢速行驶"。
- **防雪压**：暴雪各级均要求"**加固棚架等易被雪压的临时搭建物**"。
- **水管防冻**：室外及未采暖区域的水管、水表可采用保温材料包裹；长时间无人时可关闭进水总阀并放空管内存水。**以当地供水部门发布的防冻指引为准。**

### 6.5 取暖防火与一氧化碳中毒

冬季取暖是火灾和一氧化碳中毒的高发诱因，需重点防范：

- **不使用明火炭盆、燃气灶取暖**，不在密闭房间内使用无烟道的燃烧式取暖设备。
- 燃气热水器、燃煤炉具应安装在通风良好处，**烟道畅通且定期检查**；建议加装**一氧化碳报警器**。
- 电暖器远离窗帘、被褥等可燃物，**不覆盖、不烘烤衣物**，人走断电。
- 一氧化碳中毒早期表现为头痛、头晕、恶心、乏力，**一旦怀疑应立即开窗通风、转移至户外并拨打 120**。

> 具体消防与燃气安全要点，参见同目录《消防安全常识.md》《居家安全常识.md》。

## 八、地震

### 8.1 核心避险要领：「伏地、遮挡、手抓牢」

中国地震局 2025年5月12日（第17个全国防灾减灾日）发布 **《防震减灾基本知识与技能大纲》（俗称"防震减灾18条"）**，明确：

> **遭遇地震时，伏地、遮挡、手抓牢，强烈震动结束后迅速移动到安全位置，是地震应急避险的主要原则性措施。**

〔中国地震局《防震减灾基本知识与技能大纲》，2025-05-12 发布〕

中国地震局《地震预警信息公众使用指引（试行）》对四个要领的释义：

| 要领 | 释义（原文） | 目的 |
|---|---|---|
| **伏地** | 迅速就近采取**蹲伏或跪伏**等姿势 | 降低身体重心、保持身体稳定，**防止摔倒** |
| **遮挡** | 就近寻求牢固物的遮挡或护住头部，如躲避在**桌子下（旁）、床下（旁）** | 防止被**坠落物或倒塌物击砸、埋压** |
| **手抓牢** | **双手抓住身边的固定物** | 防止身体滑动或**被甩离安全位置** |
| **震动结束后迅速移动到安全位置** | 迅速移动到**户外空旷区域**，远离可能的倒塌物和坠落物 | 避免余震与次生灾害 |

〔中国地震局《地震预警信息公众使用指引（试行）》8.2 避险方法〕

### 8.2 地震预警等级（注意：与气象预警的颜色顺序不同）

按**本地预估烈度**大小，地震预警分为四个等级〔中国地震局《地震预警信息公众使用指引（试行）》第7、8.1条〕：

| 等级 | 颜色 | 总体避险原则（原文） |
|---|---|---|
| Ⅰ级 | 🔴 红色 | **震时紧急避险，震后迅速撤离** |
| Ⅱ级 | 🟠 橙色 | **震时避险，震后撤离** |
| Ⅲ级 | 🟡 黄色 | **观察防范，注意避险** |
| Ⅳ级 | 🔵 蓝色 | **无需惊慌，保持正常** |

**发布策略：** 一般情况下，预估震级达到 **4级**或预估震中烈度达到 **5度**时才对外发布；公众所在位置本地预估烈度达到设定下限（一般为 **2度**）才会收到〔同上，5.2、6.2条〕。

**技术局限：** 震中附近一般破坏最严重，却往往是**地震预警盲区**；系统也存在误报、漏报的可能〔同上，4.2条〕。

### 8.3 分场景避险（依据《地震预警信息公众使用指引（试行）》8.3）

| 场景 | 红色/橙色预警下的措施要点 |
|---|---|
| **居家、办公** | 在**内承重墙的墙根、墙角**或结实家具下（旁）避险，远离玻璃门窗，避开易坠物；**不要在阳台避险，不要跳楼逃生**；尽量关闭电源、燃气。震动结束后迅速撤离到户外空旷区域，**撤离时不要乘坐电梯** |
| **中小学校** | 教室内在**课桌下（旁）**避险，远离窗户，避开顶灯、吊扇、实验器具；震后**分楼层、分班级，前排走前门、后排走后门**，就近逐次疏散；**不狂奔、不拥挤、不推搡、不弯腰拾物、不逆流而行** |
| **车站、影院、商场** | 在**承重立柱旁、内承重墙墙根墙角**或稳固柜台、展台、排椅下方（旁边）避险；远离吊灯、广告牌、玻璃门窗；震后听从指挥有序撤离，**防止拥挤踩踏** |
| **交通工具** | 自驾应**尽快减速到安全地带停车**，在空旷区域避险；乘坐公交、地铁、火车时**降低身体重心并抓紧扶手或座椅**，待车辆停稳后有序撤离 |
| **户外** | 就近选择**空旷区域**避险；远离楼房、围墙、立交桥；远离玻璃幕墙、广告牌、电线杆；远离高压电柜、加油站、危险品工厂；**远离山脚、陡坡**以防崩塌滑坡 |

**关于阳台与柜箱：** 防灾科技学院教授孟晓春指出，"**不能到阳台上，因为阳台是楼房建筑中拉力最弱的部位；也不要钻进柜子或箱子里**，防止视野受阻、丧失机动性，从而错过逃生机会"；**切记不能跳窗和乘坐电梯**。若地震发生时正在乘坐电梯，可迅速将各楼层按钮全部按下，一旦平层停靠立即离开电梯〔中国地震局网站转载人民日报报道〕。

### 8.4 被困废墟时的自救

北京市消防救援总队特勤支队高米店站站长潘照虎在应急管理部、中国地震局新闻发布会上提示〔应急管理部、中国地震局新闻发布会，2025-05-12〕：

1. 利用废弃的建筑构件、坚固的家具等**搭建一个安全空间**，紧急处理伤情。
2. 收集食物和水，包括**高湿度的空气以及金属管道的冷凝水**来延长生存时间。
3. 保持积极的求生心态，给自己积极的心理暗示。
4. **不要盲目大声呼救**，要合理分配体力；利用砖块、钢筋等**有节奏地敲击墙壁、金属管道**，以便救援人员识别和发现。

### 8.5 不信谣、不传谣

- **地震预测仍是世界性科学难题**，目前尚处于研究探索阶段；**国家对地震预报意见实行统一发布制度**〔中国地震局《防震减灾基本知识与技能大纲》〕。
- 中国灾害防御协会理事邹文卫明确指出：**动物异常行为并不代表地震前兆的规律**，"放射云""排骨云""鱼鳞云"等所谓"**地震云**"，**实际上也无法预测地震**〔应急管理部、中国地震局新闻发布会，2025-05-12〕。
- 任何非官方渠道发布的"某日某地将发生 X 级地震"均为谣言，请勿传播。

## 九、地质灾害：滑坡、泥石流、山洪

### 九.1 前兆识别

| 灾种 | 前兆（官方专家表述） |
|---|---|
| **滑坡** | 断流多年的**泉水突然复流**、泉水突然干涸；**岩石开裂或发出被剪切挤压的声音**；动植物出现异常；后缘出现**呈圈椅状的明显裂缝**，前缘出现**鼓包**（甚至把公路顶起）；**树木倾斜**、房屋墙壁开裂、地基下沉 |
| **泥石流** | 河（沟）床中**正常流水突然断流**，或**洪水突然增大并夹带柴草树木**；听到类似**火车轰鸣、闷雷声**；沟谷深处变得**昏暗**并伴有轰鸣声及**轻微的地面震动**（说明上游已发生泥石流）；水流**变浑浊** |
| **山洪** | 河水上涨、**颜色变浑**，夹带树枝、浮石等漂浮物；上游传来**持续轰鸣声** |

〔自然资源部官网转载人民日报《遇上山洪、滑坡、泥石流，要往哪个方向跑》2024-08-09；自然资源部地质灾害技术指导中心陈红旗；应急管理部国家自然灾害防治研究院许冲、刘传正〕

### 九.2 逃生方向：垂直于灾害运动方向的两侧高处

**共性原则** —— 应急管理部国家自然灾害防治研究院科技委员会主任刘传正：

> 无论是滑坡还是泥石流，逃生的时候都要沿着它流动或者运动方向**两侧，即垂直泥石流的方向，向两侧跑，跑得越快、爬得越高越好**。

〔应急管理部汛期安全知识发布会，2025-08-05〕

| 灾种 | 正确做法 | 错误做法 |
|---|---|---|
| **滑坡** | 向**垂直于滑坡方向的两侧**迅速逃离；无法逃离时找坡度较缓的开阔地停留，或**抱住大树等固定物** | 顺着滑坡方向向上游或下游跑；停留在**凹坡处**；靠近房屋、围墙、电线杆等可能倒塌或带电的物体；**滑坡停止后立即返回原处**（有二次滑坡风险） |
| **泥石流** | 向泥石流前行方向的**两侧山坡**上爬，越高越好；就近选择**树木生长密集**的地带 | 顺着行进方向跑；往地势空旷、**树木稀疏**处逃生；**爬到树上躲避**；停留在**河道弯曲的凹岸** |
| **山洪** | 向**沟道两侧高地**移动 | **顺着沟道方向逃生** |

**在汽车或火车中遇到泥石流，应果断弃车逃生**；遇险时立即丢弃沉重行李，但**要带好通信工具**以便求助〔自然资源部转载人民日报，2024-08-09〕。

### 九.3 山区、沟谷活动安全

应急管理部国家自然灾害防治研究院地质灾害研究中心主任许冲提示，山区露营遭遇强降雨等极端天气时牢记：**"看预警，不冒险，离河谷，往高走"**——不去发布灾害风险的地区，**不在河滩、沟口等扎营**，学会识别危险信号〔应急管理部汛期安全知识发布会〕。

- 一旦收到橙色或红色预警，**涉山涉水景区和高风险项目必须坚决关停**。
- 强降雨之后地质活动相对活跃，应**减少进入山谷、沟谷**，尽量不在较陡的山坡停留。
- **灾害发生后不要立即返回搜寻财物**〔自然资源部地质灾害技术指导中心陈红旗〕。

## 十、家庭防灾准备

应急管理部在 2025年5月12日新闻发布会上给出四条家庭准备建议〔应急管理部新闻发言人申展利〕：

1. **排查安全隐患** —— 家电线路、燃气管道是否老化，柜子、空调等易倒家具家电是否稳固，发现隐患及时消除。
2. **准备家庭应急包** —— 储备必要的食品、饮用水、急救药品、救生哨、保温毯等物品。
3. **学习急救知识** —— 掌握心肺复苏、止血包扎、灭火器使用等应急技能。
4. **熟悉逃生路线** —— 让家人了解周边**应急避难场所的分布和疏散路线**，并积极参加社区和单位组织的应急避难演练。

**建议补充的应急物资清单：**

| 类别 | 物品 |
|---|---|
| 饮食 | 瓶装水（3 天量）、压缩饼干等不易变质食品 |
| 照明通信 | 手电筒、备用电池、充电宝、**收音机**（断网时接收应急广播）、哨子 |
| 医疗 | 急救包、常用药、慢性病处方药、口罩 |
| 防护 | 保温毯、厚手套、结实的鞋、雨具 |
| 证件 | 身份证件复印件、少量现金（**断电断网时移动支付可能不可用**） |
| 车载 | **破窗器/安全锤**（务必放在触手可及处，而非后备箱） |

**预警接收渠道：** 中国气象局官网、中央气象台、中国天气网；国家预警信息发布中心；应急广播预警小程序；手机内置地震预警功能（详见中国地震局《地震预警信息公众使用指引（试行）》附录 A）。

## 十一、常见误区一览

| ❌ 误区 | ✅ 正解与依据 |
|---|---|
| 暴雨中蹚不明积水没关系 | **有漩涡或向外溢水的地方，很可能井盖已缺失**，还可能有深坑、激流；积水中的路灯杆、配电箱、掉落电线均有触电风险。非必要莫涉水〔应急管理部汛期安全知识发布会〕 |
| 车能开过去，水应该不深 | 20–25 厘米即有发动机进水风险；**约 60 厘米车辆大概率熄火漂浮，水压锁死车门**。不能准确判断水深时**宁绕行不涉水**〔同上〕 |
| 车辆涉水熄火后在车里等救援 | **不要再启动车辆，不要在车内等待**，应立即弃车逃离；车门打不开就用破窗器击打**侧窗四个角**〔同上〕 |
| 台风眼来了风停了，可以出门看看 | 官方防御指南明确：**"当台风中心经过时风力会减小或者静止一段时间，切记强风将会突然吹袭，应当继续留在安全处避风"**〔中国气象局令第16号，台风橙色/红色预警防御指南〕 |
| 打雷时在大树下躲雨 | 橙色预警防御指南明确**"不要在树下、电杆下、塔吊下避雨"**；空旷场地不要打伞，不要把农具、球杆等扛在肩上〔同上，附件九〕 |
| 雷雨天在室内绝对安全 | 应**关好门窗**，切勿接触天线、水管、铁丝网、金属门窗、建筑物外墙；**打雷时不宜洗澡**，特别是太阳能热水器用户〔同上；中国气象局转载新华社〕 |
| 中暑只是"热一下"，喝点水就行 | **热射病体温可达 40℃ 及以上，伴谵妄、昏迷、多器官功能障碍，属致命性急症**〔GBZ 41—2019〕，须立即降温并拨打 120 |
| 地震了赶紧往楼下跑 | "**地震中较为危险的行为，是在晃动最为强烈时试图逃出房屋或从室外返回房屋拿取财物**"；避震首要原则是**震时就近躲避、震后快速撤离**〔中国地震局网站转载人民日报〕 |
| 地震时坐电梯下楼快 | **切记不能跳窗和乘坐电梯**；撤离时不要乘坐电梯。若正在乘梯，迅速将各楼层按钮全部按下，平层停靠立即离开〔同上；《地震预警信息公众使用指引（试行）》8.3.1〕 |
| 躲到阳台上视野好、方便呼救 | **阳台是楼房建筑中拉力最弱的部位**，指引明确"不要在阳台避险，不要跳楼逃生"〔同上〕 |
| 钻进柜子或箱子里最安全 | **会导致视野受阻、丧失机动性，从而错过逃生机会**〔中国地震局网站转载人民日报〕 |
| 看到"地震云"、动物异常就是要地震了 | **动物异常行为并不代表地震前兆的规律**；所谓"地震云"**无法预测地震**〔应急管理部、中国地震局新闻发布会〕 |
| 遇泥石流顺着沟往下游跑 | 必须**垂直于泥石流方向向两侧山坡跑，越高越好**；顺沟跑跑不过泥石流〔自然资源部转载人民日报；应急管理部发布会〕 |
| 遇泥石流爬到树上躲避 | 明确**"不要爬到树上躲避"**；应就近选择树木生长密集的地带向高处逃离〔自然资源部转载人民日报〕 |
| 滑坡停了就可以回去拿东西 | **滑坡停止后不要立即返回原处，避免二次滑坡**；灾害发生后不要立即返回搜寻财物〔同上〕 |
| 各地预警标准都一样 | 各省、自治区、直辖市**可根据本地气象灾害特点选用或增设预警信号种类、设置不同信号标准**；同一类别有的是三级"黄橙红"，有的是四级"蓝黄橙红"〔中国气象局令第16号第十六条；中国气象局科普文章〕 |
| 高温预警也有蓝色 | **高温预警信号只有黄、橙、红三级**〔中国气象局令第16号，附件七〕 |
| 家里进水了先抢救家电财物 | **不要贪恋家中财物**，应立刻切断电源总开关并向高层转移；绝对不要待在地下室 |
