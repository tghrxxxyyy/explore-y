# 生活 · 生活常识

> 跨领域的**通用安全、权益、应急、防灾**常识库。所有内容均基于政府机关与官方机构（红十字会、卫健委、消防救援局、气象局、市场监管总局、全国人大等）公开发布的信息整理，**正文标注来源、文末附权威信息来源清单**，关键事实均经联网核实。

> ⚠️ 紧急电话：急救 120 / 火警 119 / 报警 110 / 政务服务 12345 / 反诈劝阻 96110。本文为科普，**不构成专业医疗、法律或救援建议**，紧急情况以现场专业人员与官方最新指引为准。
