## 一、用电安全

### 1.1 "五要五不要"

应急管理部新闻宣传司与光明网联合出品的消防安全科普，给出了家庭用火用电的"五要五不要"〔应急管理部新闻宣传司、光明网，2025 年全国消防宣传月〕：

**五要**

| 要点 | 具体做法 |
|---|---|
| 要定期检查 | 老旧线路、插座**每季度至少检查一次** |
| 要人走电断 | 电热毯、电暖气等取暖设备使用后及时关闭 |
| 要保持距离 | 取暖设备与可燃物保持 **1 米以上**安全距离 |
| 要选用正品 | 购买电器认准国家 **3C 认证** |
| 要装保护装置 | 建议加装**漏电保护器**和**烟雾报警器** |

**五不要**

| 要点 | 原因 |
|---|---|
| 不要超负荷 | 避免多个大功率电器共用一个插座，防止电流过载引发短路 |
| 不要拉拽电线 | 插拔插头应握插头部分，减少线路损坏 |
| 不要覆盖电器 | 衣物搭在电暖气上、远离窗帘沙发等易燃物 |
| 不要长时间使用大功率电器 | 做到"人走电断" |
| **不要用湿手触碰电器开关** | 易引发触电；**浴室等潮湿区域需用防水插座** |

> 真实案例：2025 年 2 月，江西吉安一户主使用"小太阳"取暖并盖了一张毛毯，因临时走开未关电源，覆盖的毛毯被点燃引发火灾〔应急管理部素材整理组，宁夏消防转发〕。

### 1.2 选购取暖电器的三个"硬标准"

〔应急管理部沈阳消防研究所副研究员 吴莹，应急管理部冬季安全知识发布会，2025-12-17〕

1. **认准 3C 标志**——电取暖产品的"安全身份证"，属国家强制性认证。
2. **紧盯核心安全功能**：
   - 电暖器需带"**过热保护**""**倾倒断电**"；
   - 电热毯要带"**自动断电**"功能；
   - 电热暖水袋要有"**防爆阀**"。
   这些都是国标要求。
3. **选对购买渠道**：不去路边摊、无资质网店买"三无"产品；产品上要有厂家的厂名、地址和售后电话。

### 1.3 使用时的三个"安全点"

〔应急管理部沈阳消防研究所 吴莹，2025-12-17〕

- **远离可燃物**：电暖器周围 1 米内不堆窗帘、衣物，不靠着沙发和床铺。
- **控制使用时间**：电热毯"**睡前开启，入睡关闭**"，拒绝整宿通电；电暖器连续使用不宜过长。
- **拒绝操作隐患**：电热暖水袋**不要边充边用**；电暖器不要覆盖衣物；电热毯充电时不要折叠。

### 1.4 其他关键点

〔北京市消防救援总队原副总队长 李进，人民网专访，2025-10-15；策划：人民网社会·法治频道、应急管理部宣教中心科普部〕

- **小家电散热孔必须畅通**：电饭煲、电磁炉、空气炸锅等周围和底部的散热孔切勿用毛巾、塑料袋覆盖；使用后及时关闭电源。
- **抽油烟机油垢是易燃物**：定期清洗内部叶轮、面板，**不能忽略排气管道**——油垢一旦被引燃，火势会沿管道迅速蔓延。
- **杜绝"三无"插线板**：这类产品缺乏安全保护装置，易因过热引发火灾。
- **电气总闸每半年检查一次**：确保空气开关的**短路、过载保护功能正常**。
- **每月检查**：灭火器指针是否在绿色正常区域；按下烟雾报警器测试键确认功能正常。

### 1.5 触电应急基本原则

1. **先断电**：立即拉闸断电，或用**干燥的木棍、塑料等绝缘物**挑开电线。
2. **切勿徒手拉扯触电者**——施救者会同时触电。
3. 断电后评估意识与呼吸，无反应无呼吸立即拨打 **120** 并开始心肺复苏。
4. 电气火灾**必须先断电**，再用干粉或二氧化碳灭火器；带电用水灭火会导致触电。

> 具体急救操作请参见本目录下《急救常识.md》，并以经过正规培训的技能为准。

## 二、燃气安全日常

### 2.1 法规与标准依据

| 依据 | 关键要求 |
|---|---|
| 《城镇燃气管理条例》**第二十七条** | 燃气用户应当遵守安全用气规则，使用合格的燃气燃烧器具和气瓶，**及时更换国家明令淘汰或者使用年限已届满的燃气燃烧器具、连接管等** |
| 《城镇燃气管理条例》**第四十九条** | 擅自安装、改装、拆除户内燃气设施和燃气计量装置的，责令限期改正；逾期不改，对单位可处 10 万元以下罚款，对个人可处 1000 元以下罚款；造成损失依法赔偿，构成犯罪依法追究刑责 |
| **GB 55009-2021**《燃气工程项目规范》5.3.3 | 用户燃气管道及附件**不得设置在卧室、客房等人员居住和休息的房间** |
| **GB 55009-2021** 6.1.2、6.1.6 | 家庭及商业燃具应设置**熄火保护装置**；家庭用户**不得使用燃气燃烧直接取暖的设备** |
| **GB 55009-2021** 6.1.7 | 软管连接应采用**专用燃具连接软管**，使用年限**不应低于燃具判废年限**，长度**不应大于 2 米**，**禁止私接三通** |
| **GB 55009-2021** 6.1.9 | 家庭用户管道应设置压力过低或流量过高时能切断供气的安全装置（**自闭阀**） |
| **GB 17905-2008**《家用燃气燃烧器具安全管理规则》 | 自售出当日起，液化石油气和天然气**热水器、采暖炉判废年限 8 年**；**燃气灶具判废年限 8 年** |
| **GB 50028-2006（2020 年版）**《城镇燃气设计规范》10.4.3 | 住宅厨房内**宜设置排气装置和燃气浓度检测报警器** |
| 《中华人民共和国安全生产法》**第三十六条** | **餐饮等行业**的生产经营单位使用燃气的，应当安装**可燃气体报警装置**，并保障其正常使用 |

> 需要区分：**餐饮等经营单位**安装可燃气体报警装置是**法定强制要求**（未安装可处 5 万至 20 万元罚款）；**居民用户**目前多为"鼓励加装、应装尽装"，各地要求不同，**以当地住建/城管部门与燃气企业最新通告为准**〔《安全生产法》第三十六条、第九十九条；深圳市住房和建设局指导发布的《深圳市燃气安全使用温馨提示》；多地住建局通告〕。

### 2.2 燃气安全"三件套"

指**自闭阀、燃气专用金属软管、燃气报警器**〔咸丰县城市管理领域政策问答，2025-11；依据 GB 55009-2021 6.1.7/6.1.9、GB 50028-2006（2020 年版）10.4.3〕。

**关于软管**：普通橡胶软管使用年限一般仅为 **18 个月**，不符合"软管使用年限不应低于燃具判废年限（8 年）"的规范要求，应更换为符合规定的**不锈钢金属波纹软管**〔北京市消防救援总队原副总队长 李进，人民网，2025-10-15；嘉峪关市住建局等六部门通告〕。金属波纹管虽耐用性更强，但仍需**每年检查一次**，确保无破损、无老化〔李进，人民网〕。

### 2.3 日常五个动作

1. **用后关阀**：每次用完关闭灶前阀；长时间外出或睡前关闭**入户总阀**。
2. **用气不离人**：煲汤、炖煮时不离开，汤水溢出熄火会导致燃气泄漏；优先选用带**防干烧自动断气**功能的灶具〔深圳市住房和建设局指导发布〕。
3. **保持通风**：烹饪、使用燃气热水器时**必须开窗通风**，厨房保持空气对流，不要完全依赖排气扇〔李进，人民网；深圳市住建局〕。
4. **定期查漏**：**每周**用**肥皂水**涂抹燃气接口、阀门处，若出现气泡说明存在泄漏，立即关阀并检修〔李进，人民网，2025-10-15〕。**严禁用明火试漏。**
5. **注意燃气表异常**：未使用燃气时燃气表仍在走字，可能存在泄漏，应立即报修。

### 2.4 十条禁止事项

〔综合《城镇燃气管理条例》、GB 55009-2021、各地住建部门燃气隐患排查通告〕

1. ❌ 私自改装、迁移、拆除燃气管道或设施、燃气计量装置（**违法**）。
2. ❌ 使用超过 **8 年**判废年限的燃气灶、热水器、采暖炉。
3. ❌ 使用**无熄火保护装置**的灶具。
4. ❌ 使用**直排式热水器**（已被国家明令禁止生产销售）〔李进，人民网〕。
5. ❌ 在**卫生间、卧室**等密闭空间安装燃气具。
6. ❌ 燃气管道穿越卧室、客房等人员居住休息房间。
7. ❌ 软管超过 2 米、私接三通、穿越墙体门窗、缠绕灶具。
8. ❌ 把裸露燃气管线当置物架、悬吊重物、包裹遮挡燃气管道。
9. ❌ 同一房间内使用两种及以上燃气，或在用气房间同时使用和存放其他燃料（醇基、煤、柴等）。
10. ❌ 液化气钢瓶阳光直射、靠近灶具暖气等热源；燃气表房、管道井内堆放杂物或住人。

### 2.5 泄漏应急处置

燃气有特殊臭味（类似臭鸡蛋），这是人为添加的硫化物警示剂。一旦闻到：

| 步骤 | 动作 | 禁止 |
|---|---|---|
| 1 | **保持镇静**，切勿惊慌奔跑 | — |
| 2 | **立即关闭**燃气入户总阀门（通常在燃气表前） | — |
| 3 | **轻轻打开**所有门窗，自然通风降低浓度 | 不要用力开关产生火花 |
| 4 | **迅速撤离**至室外安全区域 | — |
| 5 | 到**室外**拨打燃气公司 24 小时抢险电话 | **室内不得**打电话 |
| ⛔ | 全程严禁 | 明火、手机、电灯开关、排风扇、抽油烟机等**任何可能产生火花的设备** |

〔深圳市住房和建设局指导发布的《深圳市燃气安全使用温馨提示》；多地燃气企业公开安全提示〕

> **各地抢险电话不同**，请提前查询并存入手机、张贴在厨房显眼处。

## 三、一氧化碳中毒防范

### 3.1 风险来源

〔北京市消防救援总队原副总队长 李进，人民网，2025-10-15〕

燃气热水器一氧化碳泄漏的常见原因：

- 安装位置错误（装在浴室、卧室等密闭空间）；
- **排烟管道脱落、破损、接口不严，或安装角度不当**，导致废气倒灌；
- 大风天气下，即使有排风扇，烟气也可能被吹回室内；
- 热水器超期使用、内部积碳或部件老化，燃烧不充分产生过量一氧化碳；
- 违规加装防风圈、聚能环。

农村地区常用的"土暖气""烧火盆"、室内围炉煮茶、炭火锅等，同样是每年一氧化碳中毒事件的高发场景〔应急管理部冬季安全知识发布会，2025-12-17〕。

### 3.2 核心防范：通风良好 + 设备正常

〔李进，人民网，2025-10-15〕

1. 热水器需由**专业人员安装**，严禁私自改装或延长烟道。
2. 老旧房屋若仍在使用直排式热水器，**必须更换为强排式或平衡式**。
3. **安装一氧化碳报警器**：装在**靠近卧室、起居室**的位置，**勿装在热水器旁**（避免报警不及时）；日常定期检查电池和功能。
4. 使用热水器时**务必打开窗户形成空气对流**，不要完全依赖排气扇。
5. **每年请专业人员检查一次**热水器的气密性、热交换器、燃烧器和排烟管道。

### 3.3 中毒识别与处置

- **早期症状**：头晕、恶心、乏力、心悸〔李进，人民网〕。一氧化碳无色无味，中毒者往往察觉不到。
- **一旦出现不适**：立即关闭燃气设备、开窗通风，到室外呼吸新鲜空气；**严重时及时就医**并拨打 120。
- 施救他人时先确保自身安全（开窗、屏息进入、迅速转移到通风处），避免多人中毒。

## 四、防跌倒（老年人与全家）

### 4.1 标准与指南

- **WS/T 887—2026《社区老年人跌倒预防控制技术标准》**，2026-02-28 发布，**2026-09-01 实施**（推荐性卫生行业标准）。起草单位包括中国疾病预防控制中心慢性非传染性疾病预防控制中心、北京医院（国家老年医学中心）等〔国家卫生健康委员会 nhc.gov.cn〕。
- 卫生部疾病预防控制局《**老年人跌倒干预技术指南**》（早期跌倒干预权威文件，广东省疾控中心等有公开版本）。
- WHO《跌伤（Falls）》实况报道。
- 中国疾病预防控制中心《**预防儿童跌倒技术指南**》。

### 4.2 跌倒风险的自我筛查

WS/T 887—2026 给出的**一般性评估**提问法（回答"是"即判定为阳性）〔WS/T 887—2026, 5.1.1〕：

| 维度 | 提问 |
|---|---|
| 过去 12 个月跌倒情况 | "在过去 12 个月内，你是否跌倒过？"（无论是否受伤或就诊） |
| 自感平衡状态 | "你是否在站立或行走时感到不稳？" |
| 害怕跌倒心理状态 | "你是否担心跌倒？" |

**严重程度评估**〔WS/T 887—2026, 5.1.2〕：过去 12 个月跌倒次数是否 ≥2 次、是否因跌倒就诊、跌倒后是否需他人帮助才能起身、跌倒时是否伴有晕厥或失去意识。

> 出现阳性项，建议到社区卫生服务机构或医院接受进一步的跌倒风险评估与分级管理。

### 4.3 环境改造清单

| 区域 | 措施 |
|---|---|
| **浴室** | 铺防滑垫或贴防滑砖、安装扶手；地面保持干燥；淋浴区可放置防滑凳 |
| **地面通道** | 及时清除易绊倒杂物（玩具、起褶地毯、地板上的电线网线）；**地毯必须固定或使用防滑衬垫** |
| **照明** | 儿童玩耍区、走廊、卫生间保持足够亮度；**夜间下床应开启床头灯**，可加装感应夜灯 |
| **家具** | **家具摆放要固定**（《老年人跌倒干预技术指南》预防口诀）；沙发、床附近铺柔软缓冲防护垫 |
| **楼梯** | 上下楼梯抓扶手；扶手稳固、台阶照明良好、边缘可加贴防滑条 |
| **宠物** | 小猫小狗挂铃铛，避免被绊倒（《老年人跌倒干预技术指南》口诀） |

### 4.4 老年人个人层面

〔《老年人跌倒干预技术指南》预防口诀；地方疾控慢病防控科普〕

- **衣着**：衣服宽松又合身、不过大；穿**防滑、合脚、不硌脚**的鞋。
- **起床三个"30 秒"**：睡醒后在床上平躺 30 秒 → 慢慢坐起静坐 30 秒 → 双腿自然下垂静坐 30 秒（或床边站立 30 秒），站稳后方可活动。
- **拐杖**：长度要适中、手柄简单握得牢；必要时在专业人员指导下选择适老辅助器具。
- **运动**：太极拳、防跌倒操、快走、小强度力量练习，提升肌力与平衡协调能力；量力而行，太累就歇。
- **营养**：饮食均衡，补充钙质（牛奶、大豆、深海鱼），减少肌肉流失。
- **用药**：服用**镇静药、催眠药、肌肉松弛药、抗精神病药或降压药**等或感到头晕时，应暂时卧床休息，避免下床活动；了解药物副作用，听取医嘱，不随意增减。
- **出行**：关注天气预报，减少雨雪大风天外出；人多路滑请绕道；小心路上瓜果皮。
- **心态**："年纪大了得服老"，避免大意和急躁。

## 五、儿童居家安全：坠落、家具倾倒与其他

### 5.1 家是儿童伤害高发地

- **超过 40% 的儿童非故意伤害发生在家中**，且孩子年龄越小，在家中发生此类伤害的比例越高〔浙江省疾病预防控制中心慢病所伤害防制科副主任医师 赵鸣，2026-07 国家卫生健康委相关发布会〕。
- 在我国，**跌倒/坠落是引发儿童伤害的主要原因**，每年有**超过 3600 名 0-17 岁儿童死于跌倒**〔中国疾病预防控制中心《预防儿童跌倒技术指南》〕。
- 跌倒也是造成儿童**严重脑损伤、永久性残疾**的重要原因〔健康中国科普，全国中小学生安全教育日〕。

### 5.2 有效看护是第一原则

〔浙江省疾控中心 赵鸣，2026-07；健康中国科普〕

- 家长是儿童安全的**第一责任人**，看护要做到 **专心、近距离、不间断**。
- **不能把低龄儿童单独留在家中**。
- 因故无法看护，需委托**其他成年人**看护，**不可将低龄儿童交给未成年人看护**。
- 定期**从儿童视角**排查家庭环境隐患。

### 5.3 防坠落（最严重的一类）

〔中国疾病预防控制中心《预防儿童跌倒技术指南》；浙江省疾控中心 赵鸣〕

| 措施 | 具体参数/做法 |
|---|---|
| 窗户防护 | 家中儿童可触及的**所有窗户、阳台**都应安装防护装置：**窗户限位器**（限制打开宽度）、**护栏** |
| 护栏规格 | 阳台、窗户安装**竖向护栏**，高 **110 厘米以上**，护栏间隔 **10 厘米以下**〔中国疾控中心《预防儿童跌倒技术指南》〕 |
| ⚠️ 避免横向栏杆 | 横向栏杆会让孩子**借力攀爬翻越** |
| ⚠️ 保留逃生可能 | 安装护栏时**必须确保紧急情况下能够逃生**〔赵鸣；健康中国〕 |
| 清空攀爬物 | 阳台、窗台附近**杜绝一切可攀爬的杂物、椅凳**；不在窗边堆放物品 |
| 纱窗不算防护 | 纱网**无法阻止**孩子倚靠或撞击导致的坠落 |
| 外出时 | 抱孩子逛商场时远离商场护栏 |

### 5.4 家具防倾倒

高柜、斗柜、书架的多层抽屉会被孩子一层层拉开当"台阶"攀爬，极易因重心过高而倾倒。

| 措施 | 做法 |
|---|---|
| 固定到墙 | **高度超过 60 厘米的家具**应安装固定至墙面的装置，如 **L 型防倾倒支架** |
| 电视固定 | **电视也应固定至墙面**（电视柜上的电视尤其危险） |
| 抽屉上锁 | 为抽屉安装锁扣，防止孩子拉开攀爬 |
| 钝化边角 | 选择圆角或边缘圆润的家具；桌角、柜角、窗角加装**防撞角、防撞条**；所有低于儿童身高的边角贴好防撞条 |

〔浙江大学医学院附属儿童医院创伤科主任医师 赵国强，环球时报健康客户端，2025-08；中国疾控中心《预防儿童跌倒技术指南》；长沙市妇幼保健院专家建议〕

> 参考数据：美国消费品安全委员会（CPSC）统计显示，平均每两周就会有一名幼儿因家具或电视机倾倒被砸身亡；每年有超过 3.8 万人因家具等重物倾倒事故受伤，其中 **2/3 是 5 岁以下幼儿**〔美国消费品安全委员会数据，赵国强引述，环球时报健康客户端 2025-08〕。**我国相关统计以官方最新发布为准。**

### 5.5 防烧烫伤

〔浙江省疾控中心 赵鸣，2026-07〕

- 热水壶、电饭煲、热汤碗等盛热物容器放在**平稳的地方，把手朝内，远离桌沿**。
- **桌布应固定不易扯动**（孩子拉桌布会带下滚烫的汤锅）。
- 给孩子洗澡**先放冷水再放热水，入水前先试温**；用完水龙头调至冷水一侧。
- 万一烫伤牢记 **"冲、脱、泡、盖、送"** 五字诀；**不可涂酱油、牙膏**，以免加重伤情、影响判断。

### 5.6 防触电与防锐器伤

〔浙江省疾控中心 赵鸣，2026-07；健康中国科普〕

**防触电**：购买合格电器；不私拉乱接电线；**插座装上保护盖**；教育孩子不用手指、铅笔、铁丝捅插座口；湿手不碰电器；手机、平板充电时不玩；教会孩子拨打 **119**，记住逃生路线。

**防锐器伤**：刀具、针、牙签妥善放置在儿童不易拿取处，为儿童配备专用剪刀；低龄儿童使用儿童专用餐具，就餐时禁止拿着餐具跑动；豆浆机、榨汁机等不让孩子独自操作。

### 5.7 其他细节

- 不要将婴幼儿单独放在沙发或床上；换尿布、洗澡时切勿离开。
- 收拾好地面上的电器电线（手机充电器、电风扇线等）。
- 水池边安装浴室防滑垫和合适的儿童扶手。
- 为孩子选择**尺码合适、裤脚不过长**的衣裤，以及**鞋底有纹路、合脚**的鞋子。
- 楼梯处安装儿童不易翻越的防护门。
- 用游戏、绘本教育孩子："上下楼梯扶好慢慢走""窗台阳台很高，不能爬""不可以把椅子当梯子用"。

## 六、化学品与药品安全存放

### 6.1 ⛔ 清洁剂"混搭"雷区

| 组合 | 后果 | 说明 |
|---|---|---|
| **洁厕灵 + 84 消毒液** | **产生剧毒氯气** | 洁厕灵主要成分是**盐酸**（强酸），84 消毒液主要成分是**次氯酸钠**（强氧化剂），混合后迅速发生氧化还原反应生成氯气 |
| 84 消毒液 + 洗衣液 | 可能产生有毒物质 | 发生中和反应，既破坏消毒效果又降低去污能力；84 腐蚀性强还会使衣物掉色串色 |
| 漂白剂 + 含氨清洁剂 | 生成**氯胺气体** | 刺激鼻、喉、眼，严重时头痛、恶心 |
| 洗洁精 + 洁厕灵 | 清洁效果减弱 | 碱性遇酸性中和成盐和水，白费力气 |

〔深圳市卫生健康委员会（广东卫生信息），2026-02-14；央广网/央视网，2025-10-23；淄博市疾病预防控制中心，2026-02-05；西藏自治区应急管理厅〕

**氯气的危害**：吸入后呼吸道黏膜受强烈刺激，引起咳嗽、呼吸困难、胸闷、胸痛；严重时可致**肺水肿、窒息甚至死亡**；即使较低浓度也会灼伤眼、鼻、喉。氯气**密度比空气大**，会在卫生间等密闭空间的**地面附近聚集**，进一步加剧风险。美国职业安全卫生研究所（NIOSH）规定氯气的立即危及生命或健康浓度（IDLH）为 **29 毫克/立方米**〔淄博市疾控中心，2026-02-05 引 NIOSH〕。

### 6.2 混用后的紧急处置

〔淄博市疾病预防控制中心，2026-02-05；央广网，2025-10-23〕

1. **立即撤离**：离开污染空间，转移到空气新鲜、通风良好处，解开衣领腰带保持呼吸通畅。
2. **开窗通风**：迅速打开污染区域门窗加速扩散；期间**严禁点火、开关电器**。
3. **对症冲洗**：眼睛受刺激用大量流动清水或生理盐水从眼角内侧向外侧冲洗 **10-15 分钟**，避免揉眼；皮肤接触混合液用清水反复冲洗至少 **15 分钟**；更换被污染的衣物。
4. **及时就医**：只要出现咳嗽、胸闷、头晕等情况都需就医，务必**告知医生"因混用 84 消毒液和洁厕灵接触氯气"**。

### 6.3 安全使用与存放

| 要点 | 做法 |
|---|---|
| **严格分开使用** | 两种用品单独操作，间隔**至少半小时以上**（有疾控机构建议间隔 1 小时），用后用清水彻底冲洗清洁表面，避免成分残留〔西藏应急厅；淄博市疾控中心〕 |
| **个人防护三件套** | 专用**手套**、**口罩**、**护目镜**〔深圳市卫健委；西藏应急厅〕 |
| **保持通风** | 打扫时务必保持室内良好通风；日常每日开窗通风 2-3 次，每次不少于 30 分钟 |
| **不暴晒不近热源** | 清洁剂切勿阳光暴晒或靠近电暖器、灶台；**喷雾罐体膨胀应立即停止使用** |
| **不大面积喷酒精** | 不在室内大量喷洒 75% 酒精：遇热源火星易引发火灾爆炸，悬浮液滴吸入也会引起呼吸道不适〔深圳市卫健委〕 |
| **正规渠道采购** | 选择正规商场，查看生产日期，避免"三无"产品；使用前仔细阅读说明书 |
| **原包装保存** | **绝不用饮料瓶分装**清洁剂、农药、燃料——误饮事故的头号成因 |

> 关联案例：2022 年 3 月四川泸州流水席，因醇基燃料放在厨房无人看管，被误认为食用白酒装入塑料酒壶提供给客人饮用，造成 **4 人死亡**、十几人送医〔国家食品安全风险评估中心 韩海红，人民网在线访谈，2023-10〕。**燃料、工业酒精必须单独标识、专人看管、远离食用品。**

### 6.4 儿童防误服

- 清洁剂、消毒剂、杀虫剂、农药、药品一律**放在儿童无法看到、无法够到的地方**，最好上锁。
- 药品保留**原包装与说明书**；不要在孩子面前把吃药说成"吃糖"。
- 定期清理过期药品，按当地要求投放至**药品回收点**，不随意丢弃。
- 一旦怀疑误服：**立即拨打 120**，带上误服物品的原包装或标签就医；**不要盲目催吐**（强酸强碱、石油类产品催吐会造成二次灼伤）。具体处置**请遵医嘱与中毒控制中心指引**。

## 七、防盗与入户安全

> 说明：本节为通用防范建议，**具体防范要求与报警方式请以当地公安机关最新提示为准**；本节不涉及任何未经核实的统计数据。

### 7.1 门窗与锁具

- 入户门宜选用符合国家标准的**防盗安全门**，锁芯等级越高防技术开启能力越强；搬入新居、丢失钥匙、房屋出租后**及时更换锁芯**。
- 一层、顶层、靠近管道井/雨篷/空调外机的窗户是重点部位，可加装护栏——但**必须预留紧急逃生口**，避免火灾时被困（这与消防要求存在冲突，需权衡设计）。
- 门镜（猫眼）、门链、可视门铃可提升识别能力。

### 7.2 日常习惯

- **随手关门**，不要因"就下楼一趟"而虚掩房门。
- 不在门上、鞋柜下、消防栓内**藏备用钥匙**。
- 不向陌生来电、陌生上门者透露家庭人员构成、外出计划。
- **社交媒体不要实时晒**出行程、机票、房号、门牌与钥匙照片。
- 长期外出前：关闭燃气总阀、水阀，拔掉不必要的电器插头，请邻居代收快递、代取报箱物品，避免"家中长期无人"的信号外露。
- 快递面单**销毁个人信息**后再丢弃。

### 7.3 陌生人上门

- 自称维修、抄表、消杀、推销人员上门时，**先通过猫眼/可视门铃确认**，要求出示工作证件，必要时**致电物业或相关单位官方电话核实**——不要拨打对方提供的电话。
- 家中只有老人或儿童时，**不要开门**，可回应"大人在休息，请稍后再来"。
- 发现楼道内有可疑人员踩点、门锁有撬动痕迹、门上出现不明标记，**及时报警 110** 并告知物业。

### 7.4 遇到入室盗窃

- **回家发现门锁被撬、门虚掩**：不要进入，退到安全位置**立即拨打 110**。
- **夜间发现家中有人**：优先保证人身安全，不要正面冲突；条件允许时反锁房门、大声呼救或报警。
- 案发后**保护现场**，不要触碰、清理物品，等待民警勘查。

## 八、家庭安全自查清单

建议**每月对照检查一次**，节假日前额外加强一次〔北京市消防救援总队原副总队长 李进，人民网，2025-10-15〕。

### 8.1 厨房（每月）

- [ ] 燃气管道、阀门及软管是否老化开裂或漏气（**肥皂水涂抹接口看气泡**）
- [ ] 软管是否为**专用金属波纹管**、长度是否 ≤2 米、有无私接三通
- [ ] 灶具/热水器/采暖炉铭牌生产日期，是否**超过 8 年**判废年限
- [ ] 灶具是否带**熄火保护装置**
- [ ] 抽油烟机内部及油网油垢是否过厚；**排气管道**是否清洁
- [ ] 电器线路是否完好、插座是否因插满电饭煲/电磁炉而过载
- [ ] 用完是否关闭**灶前阀与总阀**；厨房是否通风良好

### 8.2 客厅与卧室（每月）

- [ ] 插座是否过载；多个高功率设备是否共用一个插线板
- [ ] 电线有无破损、老化；有无使用"三无"插线板
- [ ] 取暖器/电暖毯与可燃物是否保持 1 米以上距离
- [ ] 烟灰缸内烟头是否完全熄灭
- [ ] 高度超过 60 厘米的家具、电视是否**已固定到墙面**

### 8.3 全屋（每月 / 每半年）

- [ ] 灭火器指针是否在**绿色正常区域**（每月）
- [ ] 按下**烟雾报警器**测试键确认功能正常（每月）
- [ ] **燃气报警器**是否通电、指示灯正常（每月）
- [ ] **一氧化碳报警器**电池与功能（每月）
- [ ] **电气总闸**空气开关的短路、过载保护功能（**每半年**）
- [ ] **漏电保护器**试跳测试（按当地供电部门建议周期）

### 8.4 阳台与楼道（每周）

- [ ] 避免堆放纸箱、塑料瓶等易燃杂物
- [ ] 杜绝电动自行车违规停放或入户充电
- [ ] 阳台、窗台附近无可攀爬的椅凳杂物（有儿童家庭）

### 8.5 每年一次

- [ ] 请专业人员检查燃气热水器的**气密性、热交换器、燃烧器和排烟管道**
- [ ] 检查金属波纹软管有无破损老化
- [ ] 清理过期药品与失效消防器材

## 九、常见误区一览

| 误区 | 正确做法 | 依据 |
|---|---|---|
| 用湿布擦带电插座 / 湿手碰开关 | **先断电**再清洁；潮湿区域用防水插座 | 应急管理部新闻宣传司"五要五不要" |
| 燃气软管长年不换 | 橡胶软管年限仅约 18 个月；应换**金属波纹管**，且每年检查 | GB 55009-2021 6.1.7；李进，人民网 |

| **消毒液与洁厕灵混用** | 产生剧毒**氯气**；必须分开使用，间隔至少半小时以上 | 深圳市卫健委；央广网/央视网；淄博市疾控中心 |
| "84 消毒液加洗衣液效果加倍" | 中和反应破坏效果，还可能产生有毒物质 | 深圳市卫健委 |

| 电热毯整宿通电 | "**睡前开启，入睡关闭**" | 应急管理部沈阳消防研究所 |
| 电热暖水袋边充边用 | 严禁边充边用 | 应急管理部沈阳消防研究所 |
| 装了纱窗孩子就掉不下去 | 纱网无法阻止倚靠或撞击导致的坠落，须装**限位器/竖向护栏** | 中国疾控中心《预防儿童跌倒技术指南》；赵国强 |

| 电视柜上的电视不用固定 | 家具/电视倾倒是幼儿致死致伤的重要原因，**高于 60 厘米的家具与电视都应固定到墙** | 赵国强，环球时报健康客户端 |
