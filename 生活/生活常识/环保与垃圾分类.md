## 一、生活垃圾分类国家标准

### 1.1 四分类框架

根据 **《生活垃圾分类标志》（GB/T 19095-2019，国家市场监督管理总局、中国国家标准化管理委员会发布，住房和城乡建设部提出）**，生活垃圾分类标志由**4 个大类标志和 11 个小类标志**构成〔GB/T 19095-2019〕。四大类分别为：

| 大类 | 定义（节选自标准） | 通俗叫法示例 |
|------|------------------|--------------|
| **可回收物** | 适宜回收利用的生活废弃物 | 蓝桶 |
| **有害垃圾** | 对人体健康或自然环境造成直接或者潜在危害的生活废弃物 | 红桶 |
| **厨余垃圾** | 易腐烂的、含有机质的生活废弃物（家庭厨余、餐厨、其他厨余） | 绿桶（湿垃圾） |
| **其他垃圾** | 除可回收物、有害垃圾、厨余垃圾以外的其他生活废弃物 | 灰/黑桶（干垃圾） |

> 注：GB/T 19095-2019 为**推荐性国家标准**，对分类标志、图形符号、颜色作出统一规定；具体投放要求由地方条例细化。

### 1.2 四类的核心判定逻辑

- **可回收物**：看是否"能卖钱、可回炉"——纸张、塑料、玻璃、金属、织物五大材质的洁净废弃物。
- **有害垃圾**：看是否"含毒、含重金属、易燃易爆或需特殊处理"——电池类、灯管类、家用化学品、药类。
- **厨余垃圾**：看是否"易腐烂、来自吃或做饭"——剩菜剩饭、果皮、菜叶、茶渣、骨骼内脏（小软骨）。
- **其他垃圾**：前三类都装不下的"干、脏、难处理"废弃物。

## 二、四类垃圾详细清单与易错项

### 2.1 可回收物

依据标准小类〔GB/T 19095-2019〕，可回收物包括：**纸类、塑料、金属、玻璃、织物**五大类。

| 类别 | 典型物品 | 投放要求 |
|------|----------|----------|
| 纸类 | 报刊、书本、纸箱、干净包装纸 | 尽量压平、拆开；**不被油污、水严重污染的**才可回收 |
| 塑料 | 饮料瓶、洗发水瓶、塑料盆桶、干净塑料袋 | 倒净残留、简单冲洗；瓶盖可连带 |
| 金属 | 易拉罐、罐头盒、旧锅、金属文具 | 尽量清空内容物 |
| 玻璃 | 酒瓶、酱油瓶、玻璃杯 | 轻放防碎；碎玻璃建议裹好防割伤（部分城市归其他垃圾，以当地为准） |
| 织物 | 旧衣物、床单、背包、鞋帽 | 干净干燥；破损严重可回收再生纤维 |

**易错项**：
- 沾满油污的 Pizza 盒、用过的一次性纸杯 → 油污使其**失去回收价值**，通常归**其他垃圾**。
- 保鲜膜、塑料袋轻薄，部分地区**不进可回收物桶**（易缠绕机器），请按当地指引或投入其他垃圾。
- 一次性塑料餐具（已被限塑令管控）一般归**其他垃圾**。

### 2.2 有害垃圾

依据标准，有害垃圾小类含：**灯管类、家用化学品、电池类、药类**〔GB/T 19095-2019〕。

| 类别 | 典型物品 |
|------|----------|
| 电池类 | 纽扣电池、充电电池（镍镉/镍氢/锂离子）、铅酸蓄电池 |
| 灯管类 | 荧光灯管、节能灯（含汞） |
| 家用化学品 | 废油漆桶、杀虫剂罐、清洁剂、染发剂、指甲油、水银温度计、过期化妆品 |
| 药类 | 过期药品及其包装 |

**关键提示（易错）**：
- **普通无汞干电池（1/5/7 号等一次性碱性干电池）**：我国自 2008 年起推行干电池"无汞化"，目前市售普通干电池基本达到低汞/无汞标准，**多地已将其归入其他垃圾**（不再作为有害垃圾）。但**充电电池、纽扣电池、蓄电池仍属有害垃圾**。具体以当地分类目录为准。
- **水银温度计、血压计**：含汞，属有害垃圾，**破碎后勿扫吸尘，应开窗通风、用硫磺粉或胶带粘取后密封交投**。
- 生态环境部曾明确答复，**家庭过期药品属于有害垃圾**〔生态环境部，2023-01-官方答复〕，应交专门回收点或投放有害垃圾。

### 2.3 厨余垃圾（湿垃圾）

| 类别 | 典型物品 |
|------|----------|
| 家庭厨余 | 剩饭剩菜、菜叶菜根、果皮、果核、蛋壳、茶渣咖啡渣、过期面包糕点 |
| 餐厨垃圾 | 餐饮单位产生的泔脚、废弃油脂 |
| 其他厨余 | 农贸市场瓜果皮、腐肉、碎骨、畜禽内脏 |

**投放要求**：**沥干水分、去除塑料袋**；鼓励"破袋"投放（将垃圾倒入厨余桶、塑料袋另投其他垃圾），多地已推行或要求。

### 2.4 其他垃圾（干垃圾）

上述三类之外的废弃物，常见如：

- 餐巾纸、卫生纸、尿不湿、卫生巾、烟蒂、一次性餐具、大骨头、贝壳、榴莲壳、椰子壳、污染严重的纸塑、陶瓷碎片、灰土、一次性口罩。

> 说明：大骨头、榴莲壳、椰子壳等**质地坚硬、难腐烂、易损伤处理设备**，在上海等地明确归**干垃圾/其他垃圾**（而非厨余）〔《上海市生活垃圾管理条例》及配套目录〕。各地表述可能不同。

## 三、常见易混淆物品归属速查

| 物品 | 正确归属 | 理由 / 备注 |
|------|----------|-------------|
| 大棒骨、排骨大骨 | **其他垃圾** | 坚硬难腐，易损设备 |
| 榴莲壳、椰子壳、坚果硬壳 | **其他垃圾** | 同上 |
| 鱼刺、鸡骨、小软骨 | **厨余垃圾** | 易腐烂 |
| 一次性干电池（1/5/7号无汞） | **其他垃圾**（多数城市） | 已无汞化；以当地目录为准 |
| 充电电池、纽扣电池 | **有害垃圾** | 含重金属 |
| 节能灯、荧光灯管 | **有害垃圾** | 含汞 |
| 水银温度计 | **有害垃圾** | 含汞 |
| 过期药品 | **有害垃圾** | 生态环境部明确 |
| 外卖餐盒（油污） | **其他垃圾** | 油污难清洗回收 |
| 奶茶杯（带盖吸管） | 杯身/盖/吸管洗净可**可回收物**，残液归**其他/厨余** | 先清干净 |
| 旧衣物 | **可回收物** | 干净织物 |
| 尿不湿、卫生巾 | **其他垃圾** | 不回收、不腐烂 |
| 烟蒂 | **其他垃圾** | — |
| 花盆（陶瓷） | **其他垃圾** | 陶瓷非玻璃回收类 |
| 打火机 | **其他垃圾**（部分要求安全处理） | 含易燃物，勿投有害 |

### 3.1 投放通用原则

- **能卖钱的归可回收，有毒有害归有害，能烂的归厨余，都不沾的边角归其他**。拿不准时，优先查当地城管发布的"分类目录"或小程序。
- **清干净再投**：瓶罐倒空、餐盒去残食、纸类去污，回收价值才高。
- **按需破袋**：厨余去塑料袋投放，塑料袋另投其他垃圾（以当地要求为准）。
- **有害垃圾单独密封**：废电池、灯管、药品、化学品勿混装、勿破损泄漏。
- **不确定不硬塞**：疑似有害或特殊废弃物，交专门回收点最稳妥。

## 四、限塑令：塑料污染治理

### 4.1 政策文件

依据 **《关于进一步加强塑料污染治理的意见》（发改环资〔2020〕80号，国家发展改革委、生态环境部 2020-01 发布）**，我国按"**禁限一批、替代循环一批、规范一批**"思路，分阶段治理塑料污染〔发改环资〔2020〕80号〕。

### 4.2 主要时间节点与目标

| 时间节点 | 重点管控内容（节选） |
|----------|----------------------|
| **2020 年底** | 直辖市、省会等率先**禁用不可降解塑料袋**；全国餐饮行业**禁用不可降解一次性塑料吸管**；地级以上城市建成区餐饮堂食**禁用不可降解一次性塑料餐具** |
| **2022 年底** | 扩大不可降解塑料袋、一次性塑料餐具禁用范围至县城建成区；**禁用含塑料微珠的日化产品** |
| **2025 年** | 塑料污染得到有效控制，重点品类替代与回收体系基本建立；电商、快递、外卖领域减塑取得明显成效 |

> 具体禁用范围、豁免情形（如医用、保鲜确需）以发改环资〔2020〕80号及后续地方实施细则为准。

### 4.3 公众可做的替代

- 自带购物布袋、菜篮；拒绝不必要的外卖餐具（下单勾选"无需餐具"）。
- 使用可重复使用水杯，少取塑料吸管。
- 优先选择纸基、可降解（认准可堆肥认证）等替代包装，但注意"可降解"≠随意丢弃，仍需按当地要求投放。

## 五、日常生活中的节能减排

以下为通用低碳生活建议，**数据以官方最新发布为准**，不作具体减排量编造：

| 场景 | 可行行动 |
|------|----------|
| 用电 | 优先选购能效等级高的家电；空调夏季设 26℃ 以上、冬季 20℃ 以下；随手关灯、拔掉待机插头 |
| 用水 | 一水多用（淘米水浇花、洗衣水冲厕）；随手关紧水龙头；选用节水型器具 |
| 出行 | 优先步行、骑行、公交地铁；短途尽量不开车 |
| 消费 | 理性购物、减少过度包装；旧物捐赠或二手流转；自带餐具水杯 |
| 光盘 | 按需点餐做饭，减少厨余与食物浪费 |
| 纸类 | 双面打印；电子账单替代纸质 |

> 国家层面的碳达峰碳中和目标、能耗双控政策等以国家发展改革委、生态环境部公开发布为准。

## 六、特殊废弃物规范处理渠道

| 废弃物 | 规范处理方式 / 渠道 |
|--------|---------------------|
| **废电池（充电/纽扣/蓄电）** | 投放小区有害垃圾收集点；或交超市、便利店、电池销售点的回收箱；铅酸蓄电池交具备资质的回收点 |
| **废灯管、水银温度计** | 有害垃圾投放点；破损汞物品按前述通风、密封处理 |
| **过期药品** | 投放**药店"过期药品回收箱"**或社区有害垃圾点；勿冲入下水道或随生活垃圾丢弃〔生态环境部答复，2023〕 |
| **废弃电器电子产品** | 交售具备资质的回收处理企业、家电以旧换新、品牌/电商回收渠道。依据《废弃电器电子产品回收处理管理条例》（国务院令第 551 号，2009）规范处理〔国务院令第551号〕 |
| **废旧手机/电脑** | 品牌官翻回收、正规二手平台、生产商回收计划；注意**清除个人数据** |
| **大件垃圾（家具家电）** | 预约环卫或正规回收，不可随意堆放路边 |
| **装修垃圾** | 单独装袋、预约专项清运，不得混入生活垃圾 |

> 《国家危险废物名录》（2021 版，生态环境部令第 15 号；2025 版，生态环境部令第 36 号）对"家庭源危险废物"实行**豁免管理**——即家庭日常生活中产生的少量废电池、废灯管、废药品等在分类投放环节可按生活垃圾管理，但仍建议投入有害垃圾点规范处置〔《国家危险废物名录》〕。

## 七、常见误区一览

| 误区 | 正解 |
|------|------|
| "所有电池都是有害垃圾" | 普通无汞干电池（1/5/7号）多数城市归**其他垃圾**；仅充电、纽扣、蓄电池为有害垃圾 |
| "大骨头是厨余" | 坚硬大骨、榴莲壳、椰子壳归**其他垃圾**（易损设备） |
| "外卖盒都能回收" | 油污严重的餐盒难回收，归**其他垃圾** |
| "厨余=所有湿的垃圾" | 湿纸巾、尿不湿虽湿，仍属**其他垃圾**；厨余专指易腐有机质 |
| "过期药扔马桶/冲走" | 污染水体，应投有害垃圾或药店回收点 |
| "可降解塑料袋=可随便丢" | 仍需按当地要求投放，多数不在自然中速降 |
| "碎玻璃直接扔可回收" | 应包裹防割伤，部分城市归其他垃圾，以当地为准 |
| "节能灯当普通垃圾" | 含汞，属**有害垃圾** |
| "限塑令只禁塑料袋" | 还涉及一次性餐具、吸管、塑料微珠日化等〔发改环资〔2020〕80号〕 |

## 八、垃圾分类详解（四分类实操）

### 8.1 可回收物细分

| 材质 | 可回收物品 | 不可回收物品 | 处理要点 |
|------|-----------|-------------|---------|
| 纸类 | 报纸、书本、纸箱、办公纸 | 油污纸巾、一次性纸杯（油污） | 压平打包，去除胶带 |
| 塑料 | 饮料瓶、洗发水瓶、塑料盆 | 保鲜膜、塑料袋（部分城市）、一次性餐具 | 清空残留，瓶盖可连带 |
| 金属 | 易拉罐、罐头盒、旧锅、钥匙 | 混合材质物品 | 清空内容物 |
| 玻璃 | 酒瓶、酱油瓶、玻璃杯 | 碎玻璃（需包裹）、镜面玻璃 | 轻放防碎，碎玻璃裹好 |
| 织物 | 旧衣物、床单、背包、鞋帽 | 严重污损织物 | 干净干燥，打包整齐 |

### 8.2 有害垃圾细分

| 类别 | 特征 | 投放要点 |
|------|------|---------|
| 电池类 | 含重金属（汞、镉、铅） | 充电电池/纽扣电池/蓄电池单独密封投放 |
| 灯管类 | 含汞蒸气 | 荧光灯管轻放防碎，破碎后通风处理 |
| 药品类 | 化学成分复杂 | 过期药品连带包装一起投放有害垃圾 |
| 化学品类 | 腐蚀性/毒性 | 废油漆桶、杀虫剂罐密封投放 |

### 8.3 厨余垃圾细分

| 类别 | 典型物品 | 投放要点 |
|------|---------|---------|
| 食物残渣 | 剩饭剩菜、菜叶菜根 | 沥干水分，破袋投放 |
| 果皮果核 | 橘子皮、苹果核、蛋壳 | 可直接投放 |
| 茶渣咖啡渣 | 泡过的茶叶、咖啡渣 | 沥干水分 |
| 过期食品 | 面包糕点（未拆包装） | 拆掉包装，食物投厨余，包装投其他 |

### 8.4 其他垃圾细分

| 类别 | 典型物品 | 说明 |
|------|---------|------|
| 纸类 | 餐巾纸、卫生纸、尿不湿 | 虽是纸但无法回收 |
| 骨壳类 | 大骨头、榴莲壳、椰子壳 | 坚硬难腐，易损设备 |
| 陶瓷类 | 花盆、陶瓷碎片 | 非玻璃回收类 |
| 其他 | 烟蒂、一次性口罩、灰土 | 前三类都不属于的 |

### 跨城市投放注意事项

- **出差/旅游**：到新城市先看当地垃圾桶标识名称，避免投错。
- **名称差异**：上海"湿垃圾"=其他城市"厨余垃圾"，上海"干垃圾"=其他城市"其他垃圾"。
- **共同原则**：无论哪个城市，四分类的核心逻辑一致（能卖钱→可回收、有毒→有害、能烂→厨余、其他→其他）。

## 十、减少垃圾实用方法

### 10.1 减塑行动

| 行动 | 具体做法 | 减塑效果 |
|------|---------|---------|
| 自带购物袋 | 布袋/折叠袋常备包中 | 每次减少1-3个塑料袋 |
| 拒绝一次性餐具 | 外卖下单勾选"无需餐具" | 每餐减少1-2件塑料制品 |
| 使用可重复水杯 | 自带杯购买咖啡/奶茶 | 每杯减少1个塑料杯 |
| 选择无包装商品 | 散装区购买果蔬杂粮 | 减少塑料薄膜包装 |
| 替代保鲜膜 | 使用硅胶盖/保鲜盒 | 减少保鲜膜消耗 |

### 10.2 二手流转

- **衣物**：通过闲鱼、转转等平台出售或捐赠旧衣物，减少织物垃圾。
- **书籍**：二手书平台（多抓鱼、孔夫子）或社区漂流书架。
- **家具家电**：大件物品通过二手平台转让，或参加社区以物换物活动。
- **儿童用品**：玩具、童装、婴儿车等通过亲子社群流转。

### 10.3 维修与共享

- **家电维修**：小家电故障先尝试维修，而非直接丢弃更换。
- **共享工具**：偶尔使用的工具（如电钻、梯子）通过社区共享或租赁获取。
- **共享出行**：共享单车/电动车减少私家车使用，降低碳排放。

## 十一、低碳生活实践

### 11.1 家庭节能

| 领域 | 行动 | 节能效果 |
|------|------|---------|
| 用电 | 选购一级能效家电；空调夏季设26℃+；随手关灯拔插头 | 月节电10-20% |
| 用水 | 一水多用（淘米水浇花）；节水龙头；缩短淋浴时间 | 月节水15-30% |
| 用气 | 锅盖加盖减少热量散失；定期清洗燃气灶 | 月节气5-10% |
| 供暖 | 冬季暖气温度设定合理（18-20℃）；做好门窗密封 | 节能10-20% |

### 11.2 低碳出行

- **短途**：步行或骑行（3km以内）。
- **中途**：公交/地铁（3-10km）。
- **长途**：优先高铁，减少飞机出行。
- **自驾**：拼车出行、保持合理车速、定期保养。

### 11.3 低碳饮食

- **光盘行动**：按需点餐做饭，减少厨余垃圾。
- **减少食物浪费**：合理储存食物、先买先吃。
- **本地食材**：选择本地当季食材，减少运输碳排放。

## 十二、环保消费选择

### 12.1 绿色产品识别

- **中国环境标志（十环标志）**：产品通过环境认证，有害物质限量达标。
- **有机认证**：农产品通过有机认证，减少农药化肥使用。
- **FSC认证**：木质产品来自可持续管理的森林。
- **能效标识**：家电能效等级，一级能效最节能。

### 12.2 环保消费原则

- **按需购买**：避免冲动消费，买之前问"是否真的需要"。
- **选择耐用品**：质量好、耐用的产品比廉价易坏品更环保。
- **简约包装**：优先选择简约包装或无包装商品。
- **本地生产**：优先选择本地/本省生产的产品，减少运输碳排放。

### 12.3 环保生活方式

| 生活场景 | 环保选择 |
|---------|---------|
| 购物 | 自带购物袋、选择简装商品 |
| 餐饮 | 自带餐具、减少外卖、光盘行动 |
| 出行 | 公交地铁、骑行、拼车 |
| 居家 | 节能家电、随手关灯、一水多用 |
| 办公 | 双面打印、电子化办公 |
| 休闲 | 户外活动代替高耗能娱乐 |
