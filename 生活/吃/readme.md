# 生活 · 吃

![中华美食](/images/吃.png)

> 中华饮食文化历经数千年，因地理环境、物产资源、历史变迁与民俗差异，形成了以 **鲁、川、粤、闽、苏、浙、湘、徽** 八大菜系为基础，并纳入 **京菜、本帮菜（沪菜）** 两大都市菜系，构成 **"十大菜系"**，外加不分地域的国民**家常菜**。本板块按菜系逐一展开：每道菜含 **源流背景 / 精确食材 / 分步火候详解 / 关键要点 / 营养文化**，并附可引用的开源项目。

## 通用烹饪技法速查

中式烹饪按传热介质分三大类：

- **油传热（脆嫩焦香）**：炒（生炒/滑炒/熟炒/干炒）、爆（油爆/葱爆/酱爆）、熘（焦熘/软熘）、炸（清炸/软炸/酥炸）、烹。
- **水传热（入味软糯）**：烧（红烧/白烧/干烧）、焖、炖（隔水/不隔水）、煨、烩、汆、扒。
- **汽传热（保留本味）**：蒸（清蒸/粉蒸/干蒸）、烤。
- **辅助**：煎、拔丝、砂锅、卤。

**火候四档**：旺火（爆炒锁水）、中火（煎炸收汁）、小火（炖焖煨）、微火（焐烂结缔组织）。

> 权威参考：百度百科《烹调小常识》、中华美食技法 14 种、第九 feast 烹饪技法文档（见各菜系"代表家常菜做法"中火候标注）。

## 可引用的开源项目（GitHub）

做菜谱整理、检索、AI 问答时可参考以下真实开源项目：

1. **中式菜谱知识图谱 [xsdgithub/CookBook-KG](https://github.com/xsdgithub/CookBook-KG)**
   收录 8000+ 菜品及原料、步骤关系，提供可视化与 KBQA 问答（"水煮鱼类有哪些""可乐鸡翅要哪些食材"）。适合做"家里现有食材能做什么菜"的检索。

2. **中式菜谱数据集 [Eimo-Bai/Ta-da-recipe-dataset](https://github.com/Eimo-Bai/Ta-da-recipe-dataset)**
   爬取 1.2 万菜谱、3412 种食材、22 万条交互，含口味与菜系标注，适合菜谱推荐与聚类研究。

3. **食神 AI [usamimeri/TheGodOfCookery](https://github.com/usamimeri/TheGodOfCookery)**
   基于下厨房 152 万菜谱微调的对话模型（InternLM + LoRA + RAG），可问答式查菜谱、生成步骤。

4. **中国菜系地理相似度 [zhuyuxiao/Chinese-cuisine](https://github.com/zhuyuxiao/Chinese-cuisine)**
   PLoS ONE 论文《Geography and similarity of regional cuisines in China》配套数据集与代码，量化各菜系用料相似度。

5. **老乡鸡菜品开源 [Gar-bage/CookLikeHOC](https://github.com/Gar-bage/CookLikeHOC)**
   基于《老乡鸡菜品溯源报告》整理的家常菜谱，按炒菜/炖菜/蒸菜/凉拌等分类，结构清晰，网页版可浏览（https://cooklikehoc.soilzhu.su）。
