# 川菜

![川菜代表菜](images/川菜.png)

> 以"一菜一格，百菜百味"闻名天下，善用三椒（辣椒、花椒、胡椒）与豆瓣、豆豉，复合味型多达二十余种。巴蜀盆地湿气重，辛辣助发汗祛湿，遂成全民下饭之王。

---

## 一、菜系概览

### 源流与历史
川菜发源于四川、重庆（巴蜀）地区，秦末汉初已初具规模，唐宋时发展迅速，明清随辣椒传入正式定型。成都（上河帮/蓉派）尚精致典雅，重庆（下河帮/渝派）重辛辣豪放，自贡（小河帮/盐帮）以鲜辣重味、善用仔姜泡椒著称。川菜馆如今遍布全球，是海外认知度最高的中国菜系之一。

### 地理与物产基础
- 四川盆地气候湿润多雾，盛产辣椒、花椒（汉源花椒尤负盛名）、郫县豆瓣、泡菜（酸辣基底）。
- 江河湖塘水产丰富（草鱼、鲶鱼、江团），山地畜禽与笋、菇等山货兼备。
- 井盐（自贡）与保宁醋、潼川豆豉构成调味三件套。

### 味型体系（24 种常用复合味）
川菜的灵魂在"调味"。基础味为咸、甜、麻、辣、酸、鲜、香，相互组合成复合味型，常见的有：

| 味型 | 代表调料 | 代表菜 |
| --- | --- | --- |
| 麻辣 | 豆瓣、花椒、辣椒 | 麻婆豆腐、水煮肉片 |
| 鱼香 | 泡椒、姜蒜葱、糖醋 | 鱼香肉丝、鱼香茄子 |
| 家常 | 豆瓣、甜面酱 | 回锅肉、家常豆腐 |
| 宫保（糊辣荔枝） | 干辣椒、花椒、糖醋 | 宫保鸡丁 |
| 怪味 | 麻辣咸甜酸鲜香 | 怪味鸡块 |
| 酸辣 | 醋、辣椒、胡椒 | 酸辣汤 |
| 红油 | 辣椒油、芝麻 | 红油抄手 |
| 姜汁 | 姜米、醋 | 姜汁热窝鸡 |

### 代表调料
- **郫县豆瓣酱**：川菜之魂，蚕豆与辣椒发酵，红油亮、酱香浓。
- **汉源花椒 / 茂汶花椒**：麻香清冽，颗粒油润。
- **保宁醋**：麸醋，酸香柔和，鱼香、糖醋必备。
- **潼川豆豉 / 永川豆豉**：增鲜提味。
- **泡椒、泡姜**：泡菜坛出品，酸辣开胃。
- **二荆条 / 朝天椒**：提色提辣。

### 经典技法
川菜擅长小炒、干煸、干烧、家常烧、水煮、爆炒。尤其"小炒"讲究急火短炒、一锅成菜；"干煸"以中小火煸干水汽至干香酥脆；"水煮"则是"油煮"——菜借红油与热油激香。

## 二、代表家常菜做法（详尽）

### 1. 麻婆豆腐
**简介**：清同治年间成都万福桥畔陈麻婆创制，因脸有麻点得名。麻、辣、烫、香、酥、嫩、鲜、活八字真言。

**食材（2 人份）**
- 嫩豆腐（石膏豆腐）400g
- 牛肉末 80g（传统用牛肉，也可用猪肉）
- 郫县豆瓣酱 1.5 汤匙
- 豆豉 半汤匙（剁碎）
- 辣椒面（二荆条）1 茶匙
- 汉源花椒粉 1 茶匙
- 蒜苗（青蒜）1 根切花
- 高汤或温水 150ml
- 生抽、盐、水淀粉、菜油 适量

**做法**
1. 豆腐切 2cm 见方块，入加盐的温水中浸泡 5 分钟（定型防碎、去豆腥），沥干。
2. 热锅冷油，下牛肉末中火煸炒至吐油、呈金黄酥粒，盛出一半备用。
3. 原锅下豆瓣酱小火炒出红油（约 1 分钟，切忌炒糊发苦），加豆豉、辣椒面炒香。
4. 注入高汤烧开，下豆腐轻推（勿铲碎），中火煮 2–3 分钟入味。
5. **分两次勾芡**：第一次勾入 2/3 水淀粉推匀，待稍稠再勾剩余，使芡汁裹住豆腐。
6. 撒蒜苗花、花椒粉，推匀出锅，表面再补少许花椒粉。

**关键要点**
- 豆瓣必炒出红油才香；花椒粉最后撒以保留麻香，久煮则麻味挥发。
- 嫩豆腐易碎，全程用锅铲"推"而非"翻"。
- 牛肉末煸酥是"酥"字的来源。

**营养与文化**：豆腐提供优质植物蛋白，麻辣促进食欲与排汗；是川菜走向世界的名片。

### 2. 回锅肉
**简介**：川菜之王，所谓"入蜀不吃回锅肉，等于没到四川"。肥而不腻、咸香微辣，灯盏窝是标志。

**食材**
- 二刀坐臀肉（带皮五花/后腿）300g
- 青蒜（蒜苗）2 根切马耳段
- 郫县豆瓣酱 1 汤匙
- 甜面酱 半汤匙
- 豆豉 少许
- 姜片、料酒、菜油 适量

**做法**
1. 整块肉冷水下锅，加姜、料酒，煮至筷子能扎入瘦肉（约七分熟，约 15 分钟），捞出晾凉。
2. 逆纹切薄片（约 2mm，越薄越易卷）。
3. 锅烧热少油，下肉片中火煸炒，逼出油脂至肉片卷曲呈"灯盏窝"、边缘金黄。
4. 将肉推至锅边，下豆瓣酱炒红油，加甜面酱、豆豉炒匀。
5. 下青蒜段大火翻炒断生（约 30 秒），出锅。

**关键要点**
- 肉要煮到七分熟再切，全熟则老、生则难切。
- 煸出油是"不腻"的关键，油多可倒出部分。
- 青蒜后放保翠绿与蒜香。

### 3. 宫保鸡丁
**简介**：糊辣荔枝味型代表作。相传清光绪年间四川总督丁宝桢（官衔"太子少保"，故称宫保）喜食辣子鸡丁，后人以其官衔命名。

**食材**
- 鸡腿肉 300g（比鸡胸更嫩）
- 油酥花生米 50g
- 干辣椒段 10 个、花椒 1 茶匙
- 葱白切丁 适量
- 腌料：料酒、生抽、淀粉、蛋清 少许
- 碗汁：醋 1、糖 1、生抽 1、料酒、淀粉、清水 各适量（糖醋 1:1 成荔枝口）

**做法**
1. 鸡肉切 1.5cm 丁，加腌料抓匀腌 10 分钟。
2. 调碗汁：醋、糖、生抽、淀粉、水拌匀备用。
3. 热油滑炒鸡丁至变白盛出；底油小火爆香干辣椒、花椒（辣椒呈棕红即可，勿焦）。
4. 下葱白丁炒香，回鸡丁，淋碗汁大火收浓至裹匀。
5. 下花生米翻匀出锅。

**关键要点**
- 糖醋 1:1 是荔枝味核心；最后放花生保脆。
- 干辣椒花椒用小火逼香，火大则苦。

### 4. 鱼香肉丝
**简介**：川菜"无鱼却有鱼香"的典范，源于民国时期川菜厨师用烧鱼调料烧肉丝，咸甜酸辣兼备。

**食材**
- 猪里脊 250g
- 水发木耳丝、胡萝卜丝、冬笋丝 各 50g
- 泡椒末 1 汤匙（鱼香灵魂）
- 姜末、蒜末、葱花 适量
- 碗汁：醋、糖、生抽、淀粉、盐、清水

**做法**
1. 肉切丝，加盐、料酒、淀粉、蛋清上浆腌 10 分钟。
2. 调碗汁（醋:糖≈1:1，加生抽、淀粉、水）。
3. 热油滑炒肉丝变色盛出；底油下泡椒末炒出红油，下姜蒜葱爆香。
4. 下三丝炒断生，回肉丝，淋碗汁大火收汁出锅。

**关键要点**
- 鱼香味 = 泡椒 + 姜蒜葱 + 糖醋，缺一不可；无鱼无豆瓣亦可成菜。
- 泡椒要炒出红油，否则生辣。

### 5. 水煮肉片
**简介**：经典"油煮"技法，麻辣嫩滑、汤红油亮，是川菜"水煮系列"的鼻祖之一。

**食材**
- 猪里脊/梅花肉 300g
- 黄豆芽、油麦菜（或生菜）200g
- 郫县豆瓣酱 2 汤匙、干辣椒、花椒
- 蒜末、葱、高汤
- 腌料：蛋清、淀粉、料酒、盐

**做法**
1. 肉切薄片，上浆腌 15 分钟。
2. 青菜焯熟垫碗底。
3. 热油炒豆瓣酱出红油，加高汤烧开，下肉片滑散（勿搅动，轻推），煮 1 分钟连汤倒菜上。
4. 表面铺干辣椒段、花椒、蒜末；另起锅烧热油至冒烟，泼其上激香。

**关键要点**
- 肉片嫩靠上浆 + 滑煮，久煮则老。
- 最后泼热油是"香"的点睛之笔。

### 6. 夫妻肺片
**简介**：成都小吃，郭朝华、张田政夫妇创制，以牛杂卤香、红油麻辣著称。

**食材**
- 牛肚、牛心、牛舌、牛肉 共 500g
- 卤料（八角、桂皮、草果、香叶、姜）
- 红油辣椒、花椒粉、酱油、糖、熟芝麻、香菜

**做法**
1. 牛杂焯水后入卤水小火卤 1 小时，捞出晾凉切薄片。
2. 调味汁：红油 + 卤水 + 酱油 + 糖 + 花椒粉 + 芝麻。
3. 料汁拌入肉片，撒香菜。

**关键要点**
- 卤香是底味，红油是灵魂；可买现成卤牛杂简化。

## 三、更多家常菜速览
- **鱼香茄子**：茄子炸软，鱼香汁烧入味，素菜荤做。
- **辣子鸡**：鸡丁与大量干辣椒同炒，麻辣酥香，在辣椒里找鸡。
- **水煮鱼**：草鱼片滑嫩，红油浇淋，麻辣鲜香。
- **毛血旺**：鸭血、毛肚、午餐肉同煮，麻辣浓烈。
- **钵钵鸡**：鸡肉煮熟晾凉，串签泡红油藤椒汁，乐山小吃。
- **酸菜鱼**：酸菜熬汤煮鱼片，酸辣开胃。
- **川北凉粉**：豌豆凉粉浇红油、保宁醋、蒜泥，爽滑开胃。
