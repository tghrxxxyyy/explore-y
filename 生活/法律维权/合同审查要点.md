# 合同审查要点

> 签字之前先看条款，能省下无数麻烦。个人签得最多的几类合同，各有关键词要盯死；格式条款和"定金/订金"这两件事，最容易吃哑巴亏。

## 一、各类合同必看条款

### 1. 租房合同

- 押金退还条件与期限、水电燃气费承担方式
- 维修责任划分：房屋自然损耗原则上由出租方负责维修
- 提前解约的违约金与通知期
- 房东卖房、拆迁时租客的权利（"买卖不破租赁"）
- 是否允许转租、养宠物、简单改造

### 2. 购房合同

- 产权是否清晰、有无抵押或查封（可查不动产登记信息）
- 付款节点与过户节点的对应关系
- 逾期过户、逾期交房的违约责任
- 户口迁出与学位承诺——**写进合同才算数**
- 税费承担约定、交付时房屋现状与设备清单

### 3. 装修合同

- 材料品牌型号清单作为附件，防止"同档次"偷换
- 工期与逾期违约金
- 增项规则：先报价后施工，未经书面确认的增项可拒付
- 保修期与质保范围（水电隐蔽工程保修应更长）

### 4. 健身卡 / 预付卡

- 有效期、转卡费、退卡规则
- "最终解释权归本店""概不退款"等条款要警惕，排除消费者主要权利的条款可能无效
- 明确签约主体是哪个门店（防止挂靠品牌跑路）

### 5. 贷款 / 借贷合同

- 真实年化利率（综合各项费用折算后的实际成本）
- 提前还款是否收费、违约金多少
- 逾期利息与罚息标准
- 有无担保物、担保人，担保责任范围多大

### 6. 购车合同

- 车架号、配置清单、交付时间
- 金融服务费、上牌费是否明码标价
- 重大质量问题的退换车条件与保修条款
- 提车验车发现问题，当场书面记录

## 二、合同无效的常见情形（常识）

- 违反法律、行政法规的强制性规定
- 违背公序良俗
- 欺诈、胁迫手段订立，损害对方利益
- 恶意串通损害他人利益
- 无民事行为能力人订立

- 提醒：合同无效不能自行认定，需通过诉讼或仲裁程序确认；无效不等于可以随便不履行，先咨询专业人士。

## 三、定金 vs 订金

| 名称 | 性质 | 违约后果 |
|---|---|---|
| 定金 | 担保性质 | 给付方违约不退；收受方违约**双倍返还** |
| 订金 / 预付款 | 预付性质 | 未履约时原则上应退还，按约定处理 |

- 定金数额一般不超过主合同标的额的 20%，超出部分不产生定金效力。
- 实操：拿不准就写"订金"或"预付款"；交钱前问清这笔钱在违约时怎么处理，并写入合同或聊天记录。

## 四、格式条款与霸王条款

- **格式条款**：商家预先拟定、不与你协商的条款（会员协议、APP 用户协议、合同背面的"补充条款"）。
- **效力**：免除自身责任、加重对方责任、排除对方主要权利的格式条款，可能被认定无效；对格式条款有两种以上解释的，按不利于提供方解释。
- **常见霸王条款**："离柜概不负责""最终解释权归本店""概不退款""损坏只赔成本价"。
- **对策**：遇到不合理条款，当场要求删改并书面确认；删改不了的，至少把口头承诺固定到合同或聊天记录里。

## 五、签合同前 checklist

- 合同主体与实际收款方一致（核对营业执照或身份证）
- 口头承诺全部落到书面
- 空白处全部填写或划线作废
- 关键日期、金额、违约责任逐项核对
- 自己保留一份原件或清晰扫描件
- 大额交易前查对方涉诉、失信记录（公开渠道可查）
- 拿不准的条款咨询 12348 或律师

## 六、合同基本要素审查

### 1. 主体审查

| 审查项目 | 具体内容 | 风险提示 |
|---|---|---|
| **身份核对** | 自然人核对身份证；法人核对营业执照 | 主体不符可能导致合同无效 |
| **行为能力** | 确认对方是否为完全民事行为能力人 | 限制行为能力人订立的合同效力待定 |
| **代理权限** | 签约人是否为法定代表人或有授权委托书 | 越权代理可能构成表见代理 |
| **资质审查** | 特殊行业需要相关资质（如建筑、医疗） | 无资质可能导致合同无效 |
| **信用查询** | 通过国家企业信用信息公示系统查询 | 失信企业风险较高 |

### 2. 标的审查

- **明确性**：标的物名称、规格、数量、质量标准应明确具体
- **合法性**：标的物必须是法律允许流通的物品或服务
- **可履行性**：标的物必须是现实可能给付的
- **验收标准**：约定明确的验收标准、验收期限、验收方式

### 3. 价款与支付

| 要素 | 审查要点 |
|---|---|
| **价格条款** | 总价款、单价、计价方式（含税/不含税） |
| **支付方式** | 现金、转账、分期、预付比例 |
| **支付时间** | 明确节点（如"收到发票后7日内"） |
| **发票条款** | 发票类型、开具时间、税费承担 |
| **定金/预付款** | 定金不超过主合同标的额的20% |

### 4. 履行条款

- **履行期限**：明确起止时间，避免"尽快""适时"等模糊表述
- **履行地点**：关系到管辖法院确定和履行成本
- **履行方式**：运输方式、交付地点、验收流程
- **附随义务**：通知、协助、保密等义务的约定

### 5. 违约责任

- **违约情形**：列举主要违约情形（逾期、质量不合格、擅自解除等）
- **违约金**：约定具体金额或计算方式（如"每日按合同金额的0.1%"）
- **损害赔偿**：违约金不足以弥补损失的，可主张实际损失赔偿
- **解除权**：约定法定解除和约定解除的情形

### 6. 争议解决

| 方式 | 特点 | 适用场景 |
|---|---|---|
| **协商** | 成本最低、效率最高 | 争议较小、双方关系良好 |
| **调解** | 第三方介入、非强制 | 需要居中协调 |
| **仲裁** | 一裁终局、保密性强 | 商事合同、涉外合同 |
| **诉讼** | 强制执行、程序规范 | 大额纠纷、需要强制执行 |

- **仲裁与诉讼不能并列约定**：约定仲裁则不能诉讼，约定诉讼则不能仲裁
- **仲裁条款要明确**：仲裁机构名称准确、仲裁事项明确
- **管辖约定**：可在被告住所地、合同履行地、合同签订地、原告住所地、标的物所在地中选择

> 📷 来源：《民法典》第四百七十条、第四百九十六条

## 七、常见合同陷阱深度解析

### 1. 阴阳合同

| 类型 | 表现 | 法律后果 |
|---|---|---|
| **买卖阴阳合同** | 阳合同用于备案/过户，阴合同约定真实价格 | 阳合同无效，阴合同效力需具体判断 |
| **租赁阴阳合同** | 阳合同报低租金避税，阴合同约定真实租金 | 以阴合同为准，但可能面临行政处罚 |
| **借贷阴阳合同** | 表面借款合同掩盖高利贷 | 超过法定利率部分无效 |

- **识别方法**：合同金额与实际支付金额不符、存在多份不同版本合同
- **风险**：可能构成虚假意思表示、逃税、骗贷
- **应对**：坚持签订一份与实际相符的合同

### 2. 霸王条款识别

| 条款类型 | 常见表述 | 法律效力 |
|---|---|---|
| **排除退费** | "售出概不退换" | 无效 |
| **免除责任** | "因不可抗力造成损失概不负责" | 部分有效（不可抗力范围需合理） |
| **加重消费者** | "逾期付款每日支付10%违约金" | 过高部分无效 |
| **限制权利** | "不得向有关部门投诉" | 无效 |
| **单方解释** | "最终解释权归本店所有" | 无效 |

### 3. 违约金过高

- **法定上限**：违约金超过造成损失的30%的，一般可认定为"过分高于造成的损失"
- **举证责任**：主张违约金过高的一方需举证证明实际损失
- **法院调减**：当事人可请求法院或仲裁机构适当减少违约金
- **约定优先**：如双方明确约定且金额合理，法院一般会尊重当事人意思自治

### 4. 管辖约定陷阱

- **常见问题**：
  - 约定"由原告住所地法院管辖"（可能被认为增加对方诉累）
  - 约定不存在的仲裁机构
  - 同时约定仲裁和诉讼（约定无效）
- **正确做法**：
  - 约定明确、具体的仲裁机构全称
  - 选择与争议有实际联系的地点
  - 避免约定对自己明显不利的管辖

> 📷 来源：《民法典》第四百九十七条、《最高人民法院关于适用〈中华人民共和国合同法〉若干问题的解释（二）》

## 八、房屋合同专题

### 1. 租赁合同审查清单

| 审查项目 | 必须明确的内容 |
|---|---|
| **租赁物** | 房屋地址、面积、用途、现状 |
| **租赁期限** | 起止日期、续租条件 |
| **租金** | 金额、支付方式、支付时间、涨租规则 |
| **押金** | 金额、退还条件、扣除情形 |
| **费用承担** | 水电气、物业费、网络费由谁承担 |
| **维修责任** | 自然损耗与人为损坏的划分 |
| **转租规则** | 是否允许转租、转租条件 |
| **解约条款** | 提前解约条件、违约金、通知期 |

- **特别提醒**：
  - 租赁期限超过20年的部分无效
  - 房屋权属证明应作为合同附件
  - 签约时应进行房屋交接验收并拍照

### 2. 购房合同核心条款

| 要素 | 审查要点 |
|---|---|
| **产权状况** | 是否有抵押、查封、共有人 |
| **价格条款** | 总价款、付款方式、付款节点 |
| **交付条件** | 交付时间、交付标准、验收流程 |
| **过户约定** | 过户时间、税费承担、户口迁出 |
| **违约责任** | 逾期过户、逾期付款的违约金 |
| **补充协议** | 口头承诺必须写入补充协议 |

### 3. 中介费与定金

- **中介费**：
  - 一般由买方或双方共同承担
  - 费率一般为成交价的1%-3%
  - 中介费应在交易完成后支付
  - 交易未成功的，中介费如何处理应明确约定
- **定金与订金**：
  - 定金具有担保性质，违约适用定金罚则
  - 订金为预付款性质，一般应退还
  - 定金不超过主合同标的额的20%
  - 建议在合同中明确是"定金"还是"订金"

> 📷 来源：《民法典》第七百零四条、《城市房地产管理法》

## 九、借贷合同专题

### 1. 借条 vs 欠条

| 类型 | 法律性质 | 诉讼时效起算 | 举证难度 |
|---|---|---|---|
| **借条** | 借贷合同的凭证 | 还款期限届满之日起算 | 较低 |
| **欠条** | 债务关系的确认 | 出具欠条之日起算 | 较高 |

- **借条必备要素**：借款人、出借人、借款金额（大小写）、借款日期、还款日期、利息约定、借款人签名捺印
- **欠条注意事项**：应注明欠款原因、还款期限、利息约定

### 2. 利息约定规范

| 类型 | 规定 |
|---|---|
| **未约定利息** | 视为无息借款 |
| **约定不明** | 自然人之间借款视为无息；其他按合同相关条款或交易习惯确定 |
| **约定利息** | 不超过合同成立时一年期贷款市场报价利率（LPR）的四倍 |
| **逾期利息** | 可以约定，但总计不超过LPR的四倍 |

- **砍头息禁止**：借款的利息不得预先在本金中扣除（预扣利息的，按实际借款数额返还借款并计算利息）
- **复利限制**：利息不得计入本金计算复利（民间借贷）

### 3. 担保方式

| 担保类型 | 特点 | 注意事项 |
|---|---|---|
| **保证** | 保证人承诺债务人不履行时由其履行 | 明确是一般保证还是连带保证 |
| **抵押** | 以特定财产作为债权担保 | 需办理抵押登记方生效 |
| **质押** | 将动产或权利凭证交付债权人占有 | 质押物需移交占有 |
| **定金** | 交付定金作为债权担保 | 不超过主合同标的额20% |

- **保证方式**：未约定或约定不明的，按照一般保证承担保证责任
- **保证期间**：未约定的，为主债务履行期限届满之日起六个月
- **担保范围**：明确约定担保范围（本金、利息、违约金、损害赔偿金等）

### 4. 诉讼时效

| 情形 | 时效期间 |
|---|---|
| **约定了还款日期** | 还款日期届满之日起3年 |
| **未约定还款日期** | 出借人可随时催告，从催告之日起3年 |
| **分期还款** | 从最后一期还款期限届满之日起3年 |
| **中断时效** | 催收函、短信、起诉等可中断时效 |

> 📷 来源：《民法典》第六百六十七条至第六百八十条、《最高人民法院关于审理民间借贷案件适用法律若干问题的规定》

## 十、电子合同专题

### 1. 电子合同法律效力

- **法律依据**：《电子签名法》《民法典》第四百六十九条
- **有效条件**：
  - 能够有效表现所载内容并可供随时调取查用
  - 数据电文的格式保持完整、内容不被篡改
  - 能够识别数据电文的发送人、接收人、发送与接收时间

### 2. 电子签名可靠性标准

| 要素 | 要求 |
|---|---|
| **专属性** | 电子签名制作数据用于电子签名时，属于电子签名人专有 |
| **控制性** | 签署时电子签名制作数据仅由电子签名人控制 |
| **可检测** | 签署后对电子签名和数据电文内容的任何改动能够被发现 |
| **完整性** | 签署后对数据电文内容的任何改动能够被发现 |

### 3. 区块链存证

- **技术原理**：利用区块链不可篡改、可追溯的特性，对合同签署过程和内容进行存证
- **司法认可**：最高人民法院已认可区块链存证的法律效力
- **应用场景**：电子合同签署、知识产权存证、证据固定
- **存证平台**：选择具有司法鉴定资质或与法院对接的存证平台

### 4. 电子合同风险防范

- **身份验证**：通过实名认证、人脸识别等方式确认签约方身份
- **签约环境**：确保网络环境安全，避免公共WiFi
- **合同保存**：下载保存电子合同原件，定期备份
- **证据保全**：重要合同可同时进行公证或区块链存证
- **争议解决**：明确约定电子合同的争议解决方式和管辖

> 📷 来源：《电子签名法》《最高人民法院关于互联网法院审理案件若干问题的规定》

## 十二、租房合同关键条款进阶

### 12.1 租房合同审查清单

| 条款 | 必须明确 | 风险提示 |
| --- | --- | --- |
| **租赁期限** | 起止日期、续租条件 | 未约定续租条件可能被无故不续 |
| **租金金额** | 月租金、支付方式、支付时间 | 口头约定租金无保障 |
| **押金** | 金额、退还条件、扣除标准 | 押金退还条件不明确易引发纠纷 |
| **维修责任** | 房屋设施维修责任方 | 未约定则房东负责结构性维修 |
| **转租条款** | 是否允许转租、转租条件 | 不约定转租可能导致违约 |
| **提前解约** | 解约条件、违约金 | 未约定提前解约可能全额扣押金 |
| **房屋用途** | 居住/商用 | 商用需房东同意并可能加租金 |

### 12.2 租房常见陷阱

| 陷阱 | 表现 | 防范措施 |
| --- | --- | --- |
| **二房东转租** | 房东不知情，租约无效 | 要求看房产证和房东身份证 |
| **口头承诺** | 房东口头承诺但不写入合同 | 所有承诺写入合同 |
| **隐性费用** | 物业费、水电费、网费未约定 | 明确各项费用承担方 |
| **提前解约** | 房东提前收房无补偿 | 合同约定违约金和补偿 |
| **房屋隐患** | 漏水、电路问题等 | 签约前检查房屋状况 |
| **霸王条款** | "房东可随时解约""押金不退" | 拒绝不合理条款 |

### 12.3 租房合同签约流程

1. **核实房东身份**：查看房产证原件、房东身份证；二房东需查看原租赁合同和房东同意转租证明。
2. **现场检查房屋**：检查门窗、水电、燃气、网络；记录现有问题并拍照留存。
3. **逐条阅读合同**：逐条阅读，不理解的条款要求解释；对不合理的条款要求修改。
4. **明确费用**：租金、押金、物业费、水电费、网费等各项费用明确约定。
5. **签字盖章**：双方签字、按手印、各执一份合同原件。
6. **留存证据**：房屋交接时拍照/视频留证，双方确认。

## 十三、劳动合同注意事项进阶

### 13.1 劳动合同签约前审查

| 审查项 | 关注点 | 风险等级 |
| --- | --- | --- |
| **公司资质** | 营业执照、经营状态 | 高 |
| **合同主体** | 是否与实际用工单位一致 | 高 |
| **岗位描述** | 岗位职责是否清晰具体 | 中 |
| **薪酬结构** | 基本工资/绩效/奖金/补贴 | 高 |
| **五险一金** | 缴纳基数、缴纳比例 | 高 |
| **试用期** | 时长、工资标准 | 中 |
| **竞业限制** | 范围、期限、补偿 | 高 |
| **服务期** | 培训费用、违约金 | 中 |

### 13.2 劳动合同常见霸王条款

| 条款 | 违法点 | 应对 |
| --- | --- | --- |
| "工资包含加班费" | 免除用人单位支付加班费义务 | 要求明确加班费另行计算 |
| "公司可随时调整岗位" | 变更劳动合同需协商一致 | 要求明确调岗条件 |
| "放弃年休假" | 年休假是法定权利，不可放弃 | 拒绝该条款 |
| "自愿放弃社保" | 社保是法定义务，不可放弃 | 坚持要求缴纳社保 |
| "违约金过高" | 违约金不得超过实际损失 | 要求降低违约金 |

### 13.3 劳动合同签约注意事项

- **签字前逐条阅读**：不要因为"大家都是这样签"就跳过。
- **保留合同原件**：自己必须持有一份合同原件，不要全部交给公司。
- **不要空白签字**：绝对不要在空白合同上签字。
- **签字日期**：确认签字日期，避免被倒签日期。
- **补充条款**：口头承诺的事项要求写入合同或补充协议。

## 十四、买卖合同常见陷阱

| **争议解决不明** | 管辖法院、仲裁机构 | 明确约定争议解决方式 |

## 十五、借款合同规范要点

### 15.1 借款合同必备条款

| 条款 | 内容 | 说明 |
| --- | --- | --- |
| **借款金额** | 大小写一致 | 避免金额篡改 |
| **借款用途** | 明确用途 | 超出用途可能影响追偿 |
| **借款利率** | 年利率/月利率 | 不超过LPR的4倍（民间借贷） |
| **还款方式** | 一次性还本付息/分期还款 | 明确还款计划 |
| **还款期限** | 明确日期 | 避免还款时间争议 |
| **违约责任** | 逾期利息、违约金 | 明确违约后果 |
| **担保条款** | 保证人、抵押物 | 增加还款保障 |

### 15.2 民间借贷利率规定

| 利率类型 | 法律规定 | 说明 |
| --- | --- | --- |
| **司法保护上限** | LPR的4倍 | 超过部分法院不予支持 |
| **2025年LPR** | 1年期LPR约3.1%，5年期约3.6% | 司法保护上限约12.4%-14.4% |
| **利息约定不明** | 视为没有利息 | 自然人之间借款利息约定不明视为无息 |
| **逾期利息** | 可以约定，但不超过司法保护上限 | 超出部分法院不予支持 |

### 15.3 借款合同签约注意事项

- **书面形式**：尽量签订书面合同，避免口头借款。
- **转账留证**：通过银行转账或支付宝/微信转账，保留转账记录。
- **大写金额**：金额同时写大写和小写，避免篡改。
- **担保人**：大额借款建议有担保人，担保人需签字确认。
- **保留证据**：借条、转账记录、聊天记录、还款记录全部保留。
- **诉讼时效**：借款合同诉讼时效3年，从约定还款日期届满起算。

### 15.4 借款合同模板要素

```
1. 借款人信息（姓名、身份证号、住址、联系方式）
2. 出借人信息（姓名、身份证号、住址、联系方式）
3. 借款金额（大写+小写）
4. 借款用途
5. 借款期限
6. 还款方式
7. 利率约定
8. 违约责任
9. 担保条款（如有）
10. 争议解决方式
11. 签字盖章、日期
```

## 十六、合同纠纷处理策略

### 16.1 合同纠纷解决途径

| 途径 | 优点 | 缺点 | 适合情形 |
| --- | --- | --- | --- |
| **协商** | 速度快、成本低、关系影响小 | 可能无法达成一致 | 争议不大、双方有协商意愿 |
| **调解** | 中立第三方介入、成本低 | 需双方同意、无强制力 | 有争议但愿协商 |
| **仲裁** | 专业性强、一裁终局 | 费用较高、需有仲裁条款 | 大额合同、有仲裁条款 |
| **诉讼** | 法律效力强、可上诉 | 时间长、成本高 | 重大争议、金额大 |

### 16.2 合同纠纷证据收集

| 证据类型 | 具体材料 |
| --- | --- |
| **合同文本** | 原件或复印件 |
| **履行证据** | 交付凭证、验收记录、付款凭证 |
| **沟通记录** | 微信聊天、邮件、电话录音 |
| **鉴定报告** | 质量检测报告、评估报告 |
| **证人证言** | 在场人员书面证词 |

### 16.3 诉讼时效提醒

| 合同类型 | 诉讼时效 | 起算时间 |
| --- | --- | --- |
| **买卖合同** | 3年 | 知道或应当知道权利被侵害时 |
| **借款合同** | 3年 | 约定还款日期届满 |
| **租赁合同** | 3年 | 知道或应当知道权利被侵害时 |
| **服务合同** | 3年 | 知道或应当知道权利被侵害时 |

> **重要提示**：诉讼时效期间可以因提起诉讼、当事人一方提出要求或者同意履行义务而中断。中断后诉讼时效重新计算。
