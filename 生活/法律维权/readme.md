# 法律维权

> 用常识性描述帮你理清"遇到纠纷第一步做什么"，不堆砌法条、不引用具体法条编号。维权三板斧：**留证据、找对门、趁早办**。涉及大额或复杂纠纷，务必咨询专业律师或拨打 12348 公共法律服务热线。

## 通用原则

1. **证据第一**：聊天记录、转账凭证、合同发票、录音录像、证人联系方式全程留痕；电子证据注意保存原始载体，关键内容截图并定期备份。
2. **时效观念**：民事纠纷一般诉讼时效为**三年**，从知道权利受损之日起算；劳动争议仲裁时效为**一年**。拖得越久，越被动。
3. **先协商后起诉**：大多数纠纷协商能解决，直接起诉耗时长、成本高；协商过程本身也是固定证据的过程。
4. **善用公共资源**：法律咨询拨打 12348；消费纠纷拨打 12315 或通过全国 12315 平台；政务服务 12345；劳动社保咨询 12333。
5. **大额找律师**：标的较大、案情复杂、对方有专业法务团队时，别省律师费；符合条件的困难群众可向法律援助机构申请免费法律服务。
6. **诉求要具体**：维权不是泄愤，写清"赔多少、怎么赔、凭什么"，证据与诉求一一对应，否则赢了道理也可能输在程序。
