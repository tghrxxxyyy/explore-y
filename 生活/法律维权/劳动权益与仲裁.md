# 劳动权益与仲裁

> 打工人遇到欠薪、违法辞退、不给加班费，先别慌。这套常识与流程，足够你走完维权的大半程：留证据、找对门、按步骤来。

## 一、劳动合同：入职必看

- **试用期**：试用期长短与合同期限挂钩，一般最长不超过六个月；同一单位只能约定一次试用期。
- **试用期工资**：不低于转正工资的一定比例（常见为 80%），且不得低于当地最低工资标准。
- **不签合同**：用工之日起超过一个月不满一年未签书面劳动合同的，可主张二倍工资差额。
- **必备条款**：岗位、薪酬构成（基本工资 + 绩效 + 提成的计算方式）、工作地点、工时制度、社保缴纳主体。口头承诺的福利，写进合同才算数。

## 二、加班费与欠薪

- **加班费标准**（常识口径）：工作日延长工作时间的，不低于工资的 1.5 倍；休息日工作且不能补休的，不低于 2 倍；法定节假日工作的，不低于 3 倍。
- **证据是命根子**：考勤记录、排班表、加班审批单、工作群消息、加班打车记录，统统保留。
- **欠薪处理**：
  1. 先书面催告，给单位改正机会；
  2. 向劳动保障监察部门投诉（可拨打 12333 咨询），监察部门责令限期支付；
  3. 仍不支付的，申请劳动仲裁。

## 三、辞退与补偿：N / N+1 / 2N

- **N（经济补偿）**：每工作满一年补一个月工资；满半年不满一年的按一年算；不满半年的补半个月。月工资按离职前十二个月平均工资计算。
- **N+1（代通知金）**：单位依据法定情形解除合同、且未提前三十日书面通知的，额外支付一个月工资作为代通知金。
- **2N（违法解除赔偿金）**：单位违法解除或终止合同的，按经济补偿标准的两倍赔偿。
- **常见情形对照**：

| 情形 | 常见结果 |
|---|---|
| 单位提出协商解除 | N |
| 劳动合同到期单位不续签 | N |
| 单位依法裁员 | N |
| 无故辞退、试用期理由站不住脚 | 可主张 2N |
| 自己主动辞职 | 一般无补偿；因欠薪、不缴社保等被迫辞职可主张 N |

- **口头辞退不算数**：要求单位出具书面解除通知并写明理由；口头赶人，你继续正常出勤留痕。

## 四、劳动仲裁流程

- **时效**：仲裁时效一般为**一年**，从知道或应当知道权利受侵害之日起算；欠薪争议在劳动关系存续期间不受此限，但离职后要尽快主张。
- **前置程序**：劳动争议一般先仲裁，对仲裁裁决不服再向法院起诉。
- **申请材料**：仲裁申请书（写明请求事项与事实理由）、身份证明、劳动关系证明（合同、工资流水、工牌、考勤记录等）、证据复印件。
- **费用**：劳动仲裁**不收费**；符合条件的还可拨打 12348 申请法律援助。
- **地点**：一般向用人单位所在地或劳动合同履行地的劳动争议仲裁委员会申请。
- **周期**：仲裁审限较短（一般 45 日内，可依法延长），比诉讼快。

## 五、工伤与社保常识

- **工伤认定**：工作时间和工作场所内因工作原因受伤，一般构成工伤；上下班途中受非本人主要责任的交通事故伤害，也属常见工伤情形。
- **时限**：单位应在事故发生后及时申报（一般 30 日内）；单位不申报的，个人或家属可在一年内自行申请。
- **待遇**：医疗费、停工留薪期工资、伤残待遇等，具体以劳动能力鉴定结论为准。
- **社保**：单位必须依法缴纳社保；以"自愿放弃社保换现金"的做法违法，出了工伤吃亏的是自己。

## 六、被违法对待时怎么留证据

- 打卡：每天截图或拍照，含日期时间。
- 沟通：重要事项用微信、邮件留文字，不只有口头。
- 工资：银行流水定期备份；工资结构被单方调整时，要求书面说明。
- 加班：保留审批记录与加班成果（注意邮件发出时间）。
- 谈话：与 HR、老板谈辞退时全程录音，注明时间、地点、在场人。
- 原则：**不签空白文件，不把证据原件交给单位。**

## 七、劳动合同签订详解

### 1. 合同签订时间要求

| 时间节点 | 法律后果 |
|---|---|
| 用工之日起1个月内 | 必须签订书面劳动合同 |
| 超过1个月不满1年未签 | 支付双倍工资（最多11个月） |
| 超过1年未签 | 视为已订立无固定期限劳动合同 |

### 2. 试用期法律规定

| 合同期限 | 最长试用期 | 试用期工资底线 |
|---|---|---|
| 3个月 ≤ 合同 < 1年 | 1个月 | 不低于约定工资的80%且不低于最低工资 |
| 1年 ≤ 合同 < 3年 | 2个月 | 不低于约定工资的80%且不低于最低工资 |
| 3年及以上或无固定期限 | 6个月 | 不低于约定工资的80%且不低于最低工资 |
| 以完成一定工作任务为期限 | 不得约定试用期 | - |

- **禁止重复约定**：同一用人单位与同一劳动者只能约定一次试用期
- **试用期包含在合同期限内**：仅约定试用期的，该期限视为劳动合同期限
- **违法约定后果**：试用期已履行的，由用人单位以试用期满月工资为标准支付赔偿金

### 3. 竞业限制协议

| 要素 | 规定 |
|---|---|
| **适用人员** | 高级管理人员、高级技术人员和其他负有保密义务的人员 |
| **期限** | 最长不超过2年（自离职之日起算） |
| **经济补偿** | 按月支付，一般不低于离职前12个月平均工资的30%，且不低于当地最低工资 |
| **违约金** | 由双方约定，但需合理；过高可请求法院调减 |
| **解除条件** | 用人单位超过3个月未支付补偿的，劳动者可请求解除竞业限制约定 |

### 4. 保密协议要点

- **形式**：可以单独签订保密协议，也可以在劳动合同中约定保密条款
- **内容**：明确保密信息范围、保密期限、保密义务、违约责任
- **补偿**：在职期间的保密义务一般无额外补偿；离职后的竞业限制需支付经济补偿
- **期限**：保密义务不以劳动关系存续为前提，但保密期应合理

### 5. 无固定期限劳动合同

- **应当订立的情形**：
  - 连续订立两次固定期限劳动合同后续签的
  - 在该用人单位连续工作满十年的
  - 用人单位初次实行劳动合同制度或国企改制重新订立合同时，劳动者在该单位连续工作满十年且距法定退休年龄不足十年的
- **视为订立**：超过一年未签书面劳动合同的，视为已订立无固定期限劳动合同
- **法律保护**：无固定期限合同不是"铁饭碗"，但用人单位解除合同的限制更严格

> 📷 来源：《劳动合同法》第十四条、第二十三条、第二十四条

## 八、加班与休假专题

### 1. 加班费计算公式

| 加班类型 | 计算基数 | 倍数 |
|---|---|---|
| 工作日延长工作时间 | 月工资 ÷ 21.75 ÷ 8 | 1.5倍 |
| 休息日加班（不能补休） | 月工资 ÷ 21.75 ÷ 8 | 2倍 |
| 法定节假日加班 | 月工资 ÷ 21.75 ÷ 8 | 3倍 |

- **基数确定**：一般按劳动合同约定的工资标准；未约定的按正常出勤月工资的70%
- **注意**：用人单位不能以调休替代法定节假日加班费；休息日加班可以先安排补休

### 2. 年休假规定

| 工龄 | 年休假天数 |
|---|---|
| 1年 ≤ 工龄 < 10年 | 5天 |
| 10年 ≤ 工龄 < 20年 | 10天 |
| 20年以上 | 15天 |

- **年假工资**：单位确因工作需要不能安排年休假的，经职工本人同意，可以不安排年休假，但应按照该职工日工资收入的300%支付年休假工资报酬
- **未休年假**：单位不安排年休假又不支付报酬的，可向劳动保障监察部门投诉

### 3. 调休与法定假日

- **调休规则**：休息日加班可以安排调休替代加班费；工作日延长工作时间和法定节假日加班不能用调休替代
- **法定假日（11天）**：元旦1天、春节3天、清明1天、劳动节1天、端午1天、中秋1天、国庆3天
- **注意事项**：法定假日调休后的工作日上班属于休息日加班，按2倍计算

> 📷 来源：《职工带薪年休假条例》《劳动法》第四十四条

## 九、社保与公积金专题

### 1. 社保缴纳比例（参考值）

| 险种 | 单位比例 | 个人比例 |
|---|---|---|
| 养老保险 | 16% | 8% |
| 医疗保险 | 6-10% | 2% |
| 失业保险 | 0.5-1% | 0.2-0.5% |
| 工伤保险 | 0.2-1.9% | 0 |
| 生育保险 | 已并入医疗 | 0 |

- **缴纳基数**：一般为职工上年度月平均工资，有上下限（当地社平工资的60%-300%）
- **违法情形**：以"自愿放弃"为由不缴社保的约定无效；试用期也必须缴纳

### 2. 社保补缴

- **单位未缴**：劳动者可向社保经办机构投诉，要求单位补缴
- **补缴时限**：一般无明确时效限制，但建议尽早主张
- **个人无法补缴**：个人只能以灵活就业人员身份缴纳养老和医疗，不能补缴历史欠费
- **仲裁时效**：因社保缴纳问题产生的劳动争议，适用劳动仲裁时效

### 3. 社保转移

- **跨省转移**：在新参保地提出申请 → 原参保地办理转出 → 新参保地接收
- **转移内容**：养老保险个人账户全额转移，统筹基金按比例转移（约12%）
- **医疗保险转移**：个人账户余额可转移，缴费年限各地有累计计算和折算规定
- **办理渠道**：国家社会保险公共服务平台、各地社保经办窗口

### 4. 公积金提取

| 提取情形 | 所需材料 |
|---|---|
| 购买自住住房 | 购房合同、付款凭证、身份证明 |
| 偿还房贷 | 借款合同、还款凭证、身份证明 |
| 租房提取 | 租赁合同备案证明、无房证明 |
| 离职提取 | 解除劳动合同证明、公积金卡 |
| 退休提取 | 退休证、身份证明 |

- **公积金贷款**：连续缴存6-12个月可申请公积金贷款，利率低于商业贷款
- **提取额度**：各地规定不同，购房、还贷一般可全额提取；租房有年度限额

> 📷 来源：《社会保险法》《住房公积金管理条例》

## 十、离职补偿详解

### 1. 经济补偿金计算

- **计算公式**：经济补偿 = 工作年限 × 月工资
- **工作年限计算**：
  - 每满一年支付一个月工资
  - 六个月以上不满一年的，按一年计算
  - 不满六个月的，支付半个月工资
- **月工资标准**：劳动合同解除或终止前十二个月的平均工资
- **上限规定**：月工资高于当地职工月平均工资三倍的，按三倍计算，且补偿年限最高不超过十二年

### 2. N+1 代通知金

- **适用情形**：用人单位依据《劳动合同法》第四十条解除合同（医疗期满不能从事工作、不能胜任工作、客观情况重大变化），且未提前三十日书面通知的
- **计算标准**：一个月工资（按上月工资标准，非十二个月平均）
- **与N的关系**：N+1 = 经济补偿N + 代通知金1，两者叠加

### 3. 2N违法解除赔偿金

- **适用情形**：用人单位违反《劳动合同法》规定解除或终止劳动合同
- **常见违法情形**：
  - 在孕期、产期、哺乳期解除合同
  - 在医疗期内解除合同
  - 未提前通知且无合法理由
  - 程序违法（如未通知工会）
- **计算标准**：经济补偿标准的二倍
- **与N+1的关系**：2N是赔偿金，N+1是补偿金+代通知金，二者不能同时主张

### 4. 经济补偿对比表

| 情形 | 补偿标准 | 法律依据 |
|---|---|---|
| 协商解除 | N | 第三十六条 |
| 不能胜任工作解除 | N+1或提前30天通知 | 第四十条 |
| 经济性裁员 | N | 第四十一条 |
| 合同到期不续签 | N | 第四十六条 |
| 违法解除 | 2N | 第八十七条 |
| 员工主动辞职 | 一般无补偿 | 第三十七条 |

### 5. 特殊情形补偿

- **工伤员工**：五至十级伤残的，解除或终止合同时支付一次性工伤医疗补助金和一次性伤残就业补助金
- **医疗期满员工**：解除合同需支付N+1，且需额外支付不低于六个月工资的医疗补助费（重病、绝症更多）
- **临近退休员工**：距法定退休年龄不足五年的，一般不得依据第四十条、四十一条解除合同

> 📷 来源：《劳动合同法》第四十条、第四十六条、第四十七条、第八十七条

## 十一、劳动仲裁流程详解

### 1. 申请前准备

| 步骤 | 内容 |
|---|---|
| **确认管辖** | 向用人单位所在地或劳动合同履行地的劳动争议仲裁委员会申请 |
| **准备材料** | 仲裁申请书、身份证复印件、证据材料、送达地址确认书 |
| **确定请求** | 明确仲裁请求（金额、事项），请求需具体、可量化 |
| **时效检查** | 确认是否在一年仲裁时效内，欠薪争议在劳动关系存续期间不受限 |

### 2. 仲裁申请书要点

- **当事人信息**：申请人姓名、住址、联系方式；被申请人名称、住所地、法定代表人
- **仲裁请求**：逐项列明（如：支付拖欠工资XX元、支付经济补偿金XX元）
- **事实与理由**：按时间顺序描述入职、工作、争议发生过程
- **证据清单**：列明证据名称、证明目的

### 3. 仲裁流程时间线

| 阶段 | 时限 |
|---|---|
| 申请受理 | 收到申请之日起5日内决定是否受理 |
| 送达答辩 | 受理之日起5日内将申请书副本送达被申请人 |
| 被申请人答辩 | 收到副本之日起10日内提交答辩书 |
| 开庭审理 | 受理之日起45日内结案（可延长15日） |
| 裁决 | 开庭后择期裁决 |
| 起诉期限 | 收到裁决书之日起15日内可向法院起诉 |

### 4. 一裁终局情形

以下争议仲裁裁决为终局裁决，用人单位不能起诉（劳动者不服仍可起诉）：
- 追索劳动报酬、工伤医疗费、经济补偿或赔偿金，不超过当地月最低工资标准十二个月金额的争议
- 因执行国家劳动标准在工作时间、休息休假、社会保险等方面发生的争议

### 5. 裁决执行

- **自动履行**：裁决生效后，用人单位应在规定期限内履行
- **强制执行**：用人单位不履行的，可向法院申请强制执行
- **执行时效**：裁决生效后二年内申请强制执行
- **执行措施**：冻结银行账户、查封财产、限制高消费、纳入失信名单

### 6. 费用与法律援助

- **仲裁费用**：劳动仲裁不收取任何费用
- **法律援助**：经济困难的劳动者可拨打12348申请免费法律援助
- **律师费**：一般由当事人自行承担，但部分地方法规支持由败诉方承担

> 📷 来源：《劳动争议调解仲裁法》《劳动人事争议仲裁办案规则》

## 十二、证据收集实务

### 1. 劳动关系证明证据

| 证据类型 | 具体材料 |
|---|---|
| **书面合同** | 劳动合同、聘用协议、offer letter |
| **工资凭证** | 银行流水、工资条、个税缴纳记录 |
| **工作记录** | 考勤记录、工牌、工作证、名片 |
| **社保记录** | 社保缴纳记录、公积金缴存记录 |
| **电子证据** | 工作邮件、企业微信聊天记录、钉钉打卡记录 |

### 2. 证据保全技巧

- **原始保存**：电子证据保存原始设备，不要删除原始数据
- **多备份**：截图、录屏、导出，至少保留两份备份
- **公证保全**：重要证据可到公证处进行证据保全公证
- **时间戳**：重要沟通记录记录具体时间
- **完整性**：证据要形成完整链条，能够证明整个事实经过

> 📷 来源：《民事诉讼法》《最高人民法院关于民事诉讼证据的若干规定》

## 十七、劳动法核心条款详解

### 17.1 劳动合同必备条款

| 条款 | 法律依据 | 说明 |
| --- | --- | --- |
| **用人单位信息** | 第17条 | 名称、住所、法定代表人 |
| **劳动者信息** | 第17条 | 姓名、住址、身份证号 |
| **合同期限** | 第17条 | 固定期限/无固定期限/以完成一定工作为期限 |
| **工作内容和地点** | 第17条 | 明确岗位和工作地点 |
| **工作时间和休息** | 第17条 | 标准工时/综合计算工时/不定时 |
| **劳动报酬** | 第17条 | 工资标准、支付方式、支付日期 |
| **社会保险** | 第17条 | 五险一金 |
| **劳动保护和条件** | 第17条 | 职业危害防护、劳动条件 |

### 17.2 试用期规定详解

| 合同期限 | 试用期上限 | 试用期工资 | 说明 |
| --- | --- | --- | --- |
| **<3个月** | 不得约定试用期 | — | 临时性、短期用工 |
| **3个月-1年** | 不得超过1个月 | ≥约定工资80% | 且≥当地最低工资 |
| **1-3年** | 不得超过2个月 | ≥约定工资80% | 且≥当地最低工资 |
| **>3年/无固定** | 不得超过6个月 | ≥约定工资80% | 且≥当地最低工资 |
| **仅约定试用期** | 试用期不成立 | 按正式工资计算 | 试用期包含在合同期限内 |

### 17.3 工资支付规定

| 情形 | 支付标准 | 法律依据 |
| --- | --- | --- |
| **正常工作** | 按合同约定支付 | 第30条 |
| **加班** | 平日1.5倍/休息日2倍/法定3倍 | 第44条 |
| **事假** | 可不支付 | 规章制度规定 |
| **病假** | 不低于最低工资80% | 第30条 |
| **停工停产** | 首月正常工资，次月起不低于最低工资70% | 各地规定 |

## 十八、加班工资计算进阶

### 18.1 加班工资计算公式

| 加班类型 | 计算公式 | 举例（月薪10000元） |
| --- | --- | --- |
| **工作日加班** | 月薪÷21.75÷8×加班小时×1.5 | 10000÷21.75÷8×2×1.5≈172.4元 |
| **休息日加班** | 月薪÷21.75÷8×加班小时×2 | 10000÷21.75÷8×8×2≈919.5元 |
| **法定节假日** | 月薪÷21.75÷8×加班小时×3 | 10000÷21.75÷8×8×3≈1379.3元 |
| **年休假未休** | 日工资×未休天数×300% | 10000÷21.75×5≈2298.9元 |

### 18.2 加班举证责任

| 证据类型 | 举证责任方 | 说明 |
| --- | --- | --- |
| **加班事实** | 劳动者 | 提供考勤记录、加班审批单、工作记录 |
| **已支付加班费** | 用人单位 | 工资发放记录由用人单位保管 |
| **加班审批制度** | 用人单位 | 需证明有加班审批制度且已告知劳动者 |
| **自愿加班** | 用人单位 | 需证明是劳动者自愿而非单位安排 |

### 18.3 特殊工时制度

| 制度 | 适用条件 | 加班计算 |
| --- | --- | --- |
| **标准工时** | 一般劳动者 | 按加班规定计算 |
| **综合计算工时** | 适合季节性/连续性工作 | 周期综合计算，超出部分算加班 |
| **不定时工作制** | 外勤/高管/特殊岗位 | 一般无加班费（需审批） |

- **不定时工时制审批**：需向劳动行政部门申请，未经审批不得执行。
- **综合计算工时周期**：可按周、月、季、年计算，需报劳动行政部门批准。

## 十九、违法辞退赔偿深度分析

### 19.1 经济补偿金计算

| 情形 | 计算标准 | 举例（月薪10000元，工作3年） |
| --- | --- | --- |
| **协商解除** | N×月工资 | 3×10000=30000元 |
| **无过失性解除** | N×月工资（+代通知金1个月） | 3×10000+10000=40000元 |
| **经济性裁员** | N×月工资 | 3×10000=30000元 |
| **违法解除** | 2N×月工资（赔偿金） | 2×3×10000=60000元 |
| **合同期满不续签** | N×月工资 | 3×10000=30000元 |

> N = 工作年限（每满1年算1个月，6个月以上不满1年按1年算，不满6个月算0.5个月）

### 19.2 违法辞退常见情形

| 情形 | 是否违法 | 说明 |
| --- | --- | --- |
| **无理由辞退** | 是 | 用人单位需证明解除合法 |
| **试用期无理由辞退** | 是 | 需证明不符合录用条件 |
| **怀孕期间辞退** | 是 | 女职工"三期"受特殊保护 |
| **工伤期间辞退** | 是 | 工伤职工"停工留薪期"受保护 |
| **医疗期内辞退** | 是 | 不能解除劳动合同 |
| **未提前30天通知** | 需支付代通知金 | 否则需支付1个月工资作为代通知金 |

### 19.3 维权策略选择

| 策略 | 优点 | 缺点 | 适合情形 |
| --- | --- | --- | --- |
| **协商** | 速度快、成本低 | 金额可能低于法定 | 关系尚可、金额不大 |
| **调解** | 中立第三方介入 | 需双方同意 | 有争议但愿协商 |
| **仲裁** | 法律效力强、时间适中 | 1-2个月周期 | 协商不成 |
| **诉讼** | 最终法律救济 | 时间长、成本高 | 重大争议、金额大 |
| **监察投诉** | 行政执法、效率高 | 只处理明确违法 | 欠薪、超时加班等 |

### 仲裁流程

1. **提交申请**：向劳动仲裁委员会提交申请书
2. **受理通知**：仲裁委员会5日内决定是否受理
3. **开庭审理**：仲裁庭开庭审理案件
4. **裁决**：仲裁庭作出裁决
5. **执行**：裁决生效后申请执行

### 仲裁时效

- **普通争议**：1年（从知道或应当知道权利被侵害之日起）
- **劳动报酬**：劳动关系存续期间不受限制
- **工伤**：1年（从工伤认定之日起）
