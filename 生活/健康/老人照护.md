# 老人照护

> 照护老人，核心三件事：防跌倒、管好药、守住认知和营养。本文讲常见慢病家庭管理、安全改造、多重用药与照护者自救。

## 一、常见慢病的家庭管理

- **心血管病（高血压、冠心病）**：每天定时测血压并记录；低盐饮食、按时服药；胸痛胸闷立即就医，家中备硝酸甘油（按医嘱）。
- **糖尿病**：注意**低血糖信号**（心慌、出汗、手抖、头晕）——老人低血糖比高血糖更危险；随身带糖或饼干；鞋袜宽松干燥，每天检查脚底。
- **骨质疏松**：已确诊者防摔是头等大事（见下节）；钙+维 D 按医嘱补；骨折后尽快康复训练。

### 骨质疏松管理要点

| 管理方面 | 具体措施 |
| --- | --- |
| 营养 | 钙 1000–1200 mg/天 + 维 D 800–1000 IU/天 |
| 运动 | 负重运动（快走、太极拳）+ 抗阻训练（弹力带、轻哑铃） |
| 防跌倒 | 家居改造（见第二节）、穿防滑鞋、保持视力良好 |
| 药物 | 双膦酸盐（阿仑膦酸钠）、地舒单抗等（遵医嘱） |
| 监测 | 每 1–2 年查骨密度（DXA） |
- **关节炎（骨关节炎）**：保暖、适度活动（游泳、骑车）比"躺着养"好；疼痛影响睡眠或走路再考虑止痛药，老人用止痛药须谨慎（伤胃、伤肾）。

## 二、跌倒预防：老人第一大风险

- 老人跌倒后果不轻：髋部骨折、卧床、再难恢复。**每年约有三分之一 65 岁以上老人跌倒**，且多数在家发生。
- **跌倒后髋部骨折的严重性**：65 岁以上髋部骨折后 1 年内死亡率约 20%–30%（主要因卧床并发症：肺炎、血栓、压疮）；因此预防跌倒是老人照护中最重要的单项干预。
- **居家改造清单**：
  - 浴室：防滑垫、马桶旁/淋浴区装扶手；
  - 卧室到卫生间路线留夜灯、清走电线杂物；
  - 地面不打蜡、门槛做平、常用物品放伸手可及处。
- **药物致跌倒风险**：安眠药、降压药过快、降糖药低血糖、利尿剂（夜里频繁起夜）都会增加跌倒；换药初期或新加药 1–2 周内格外小心。
- 鞋穿防滑合脚的，裤子别太长；视力听力差先解决（老花镜、助听器）；头晕/脚软/走路不稳及时就医评估。

## 三、多重用药管理

- 老人常同时吃几种药（慢病药+止痛+保健品），**重复用药、相互作用是常见隐患**。
- 建一份**用药清单**：药名、剂量、时间、用途、开药医生；每次就诊都带上，让医生核对是否有重复和冲突。
- 同一成分的"复方感冒药"与单方药易重复（都含对乙酰氨基酚，叠加伤肝）；**中西药同服也要告诉医生**。
- 吃不完的药定期清理（过期、停药原因不明的不留）；"保健品当药吃""听邻居推荐加药"都不可取。
- 老人忘服/错服：用一周药盒分装 + 家属提醒；开药时请医生优先"一天一次"的剂型。

### 老人用药"五问"原则

每次就诊或拿到新药时，主动问医生/药师以下问题：
1. **这个药治什么？**（明确用途）
2. **怎么吃？饭前还是饭后？**（用法用量）
3. **和我现在吃的药有冲突吗？**（药物相互作用）
4. **有什么副作用？出现什么情况要停药？**（安全性）
5. **什么时候需要复查？**（监测指标）

### 常见药物相互作用速查

| 药物 A | 药物 B | 风险 |
| --- | --- | --- |
| 华法林 | 阿司匹林/布洛芬 | 出血风险增加 |
| 他汀类 | 红霉素/伊曲康唑 | 横纹肌溶解风险 |
| 降压药（ARB/ACEI） | NSAIDs（布洛芬） | 降压减弱、肾损害 |
| 地高辛 | 胺碘酮 | 地高辛中毒（心律失常） |
| 降糖药 | 酒精 | 低血糖风险增加 |
| 利尿剂 | 锂盐 | 锂中毒风险 |

## 四、认知退化：早期信号与就医

- 与"老糊涂"的界限：正常是忘事但事后能想起、生活自理不受影响；**病理性**是：
  - 重复问同一件事、近期记忆明显变差；
  - 找不到常去的地方、算不清账、不会用常用家电；
  - 性格大变（多疑、易怒）、语言表达困难、迷路。
- 出现上述信号，**尽早就诊**：挂神经内科或记忆门诊，做认知评估。阿尔茨海默早期干预可延缓进展；部分"痴呆样"表现（甲状腺问题、药物副作用、维生素缺乏、抑郁）是可逆的，查了才知道。
- 确诊后：建立规律生活、防走失（定位手表/卡片）、管好钱物、家属同步接受照护培训。

## 五、失能照护与照护者自我照顾

- 失能照护要点：翻身防压疮（每 2 小时）、口腔护理、防呛咳（进食半坐位、小口慢咽）、康复训练不中断（能走尽量下地）。
- **照护者最容易垮**：把 24 小时全扛在自己身上，身体和心理都透支。给自己排"轮换"（家人分工、请护工/日间照料中心），保留每周属于自己的时间。
- 照护者出现持续失眠、烦躁、抑郁——同样需要就医或找心理支持，这不是矫情。
- 可利用资源：社区养老服务、长护险（多城已试点）、护工中介、三甲医院照护咨询门诊。

### 照护者自我评估

如果你是照护者，问自己以下问题：
- 我是否有持续的疲惫感？
- 我是否经常感到烦躁或易怒？
- 我是否失去了原本的兴趣爱好？
- 我是否有睡眠问题（入睡困难/早醒）？
- 我是否觉得"没有人能帮我"？
- 如果有 3 项以上回答"是"，建议寻求照护者支持服务或心理咨询。

## 六、老人疫苗接种

- **流感疫苗**：每年秋季接种，老人是重点人群，可降低感染后重症风险。
- **23 价肺炎球菌疫苗**：65 岁以上或慢性病老人接种（1 剂，5 年以上按需复种，遵医嘱）。
- **带状疱疹疫苗**：50 岁以上接种，预防带状疱疹及后遗神经痛；曾患过带状疱疹也可接种。
- **新冠疫苗加强、百白破加强**（老人易漏）按当地建议接种；接种前如实告知慢病情况，稳定期一般可接种。

## 七、定期体检与随访

- 每年 1 次常规体检：血压血糖血脂、心电、肝肾功能、骨密度（绝经后女性/60+ 男性）、眼底、口腔。
- 慢病患者按医嘱随访（高血压 3–6 个月、糖尿病每 3–6 个月查糖化）；**换季节时留意血压血糖波动**。
- 关注"异常不等于生病"：老人体检的小箭头多，重点是看趋势和组合，由医生判断，别为指标焦虑。

## 八、跌倒预防详解

- **跌倒风险因素**：
  - 内在因素：肌力下降、平衡障碍、视力/听力下降、认知障碍、尿频/尿急、药物影响（安眠药、降压药、利尿剂）；
  - 外在因素：地面湿滑、光线不足、杂物绊倒、鞋子不合脚、家具摆放不当。
- **居家安全改造清单**：

| 区域 | 改造措施 |
| --- | --- |
| 浴室 | 防滑垫、马桶旁/淋浴区装扶手、坐式淋浴 |
| 卧室 | 床边留夜灯、床高适中（坐床边脚能着地）、常用物品放伸手可及处 |
| 客厅/走廊 | 清除电线杂物、地毯固定或移除、门槛做平 |
| 楼梯 | 两侧装扶手、踏步边缘贴防滑条、充足照明 |
| 厨房 | 常用物品放低处、用稳固的踏凳（非椅子）取高处物品 |

- **平衡训练**（每天练习）：
  - 单脚站立（扶椅背）：每侧 30 秒，重复 3 次；
  - 脚跟接脚尖走直线：来回走 10 步；
  - 坐站训练（从椅子上站起坐下）：10 次 × 3 组。
- **药物致跌倒高风险清单**：
  - 安眠药/镇静药（苯二氮䓬类）：影响平衡和反应速度；
  - 降压药（尤其α受体阻滞剂）：体位性低血压；
  - 降糖药：低血糖导致头晕；
  - 利尿剂：夜间频繁起夜；
  - 抗抑郁药/抗精神病药：嗜睡、头晕。
- **跌倒后的正确应对**：不要急于站起，先评估是否有疼痛/无法活动的部位；若无大碍，先翻身侧卧→手撑地→膝盖跪地→扶家具站起；若无法站起或疼痛剧烈，拨打 120。

## 九、多重用药管理详解

- **药物相互作用风险**：
  - 华法林 + 阿司匹林/布洛芬：出血风险增加；
  - 他汀类 + 大环内酯类抗生素（红霉素）：横纹肌溶解风险；
  - 降压药 + NSAIDs（布洛芬）：降压效果减弱、肾功能损害；
  - 降糖药 + 酒精：低血糖风险增加。
- **用药清单模板**：

| 药物名称 | 剂量 | 用法 | 用途 | 开药医生 | 副作用 |
| --- | --- | --- | --- | --- | --- |
| 氨氯地平 | 5 mg | 每日 1 次 | 高血压 | 心内科张医生 | 踝部水肿 |
| ... | ... | ... | ... | ... | ... |

- **定期用药评估**：每 3–6 个月让医生/药师审核一次用药清单，检查：
  - 是否有重复用药（不同药含相同成分）；
  - 是否有不必要的药物（症状已缓解可停的药）；
  - 剂量是否需要调整（肾功能下降时某些药需减量）。
- **中西药同服注意事项**：
  - 含甘草的中成药可能升高血压（与降压药拮抗）；
  - 含麻黄的中成药可能升高血压、加快心率；
  - 丹参、当归等活血中药可能增加华法林出血风险；
  - **所有中药/中成药/保健品都要告知医生**。

## 十、认知退化识别详解

- **正常老化 vs 轻度认知障碍（MCI）vs 痴呆**：

| 特征 | 正常老化 | MCI | 痴呆 |
| --- | --- | --- | --- |
| 记忆 | 偶尔忘名字，事后能想起 | 经常忘近期事件，影响日常 | 远期近期记忆均受损 |
| 日常生活 | 完全自理 | 基本自理，偶有困难 | 需要帮助 |
| 定向力 | 清楚时间地点 | 偶尔不确定 | 经常搞不清时间地点 |
| 语言 | 偶尔找不到词 | 经常找词困难 | 语言表达和理解明显下降 |
| 判断力 | 正常 | 可能有轻微变化 | 明显受损 |

- **阿尔茨海默病早期信号**：
  - 近期记忆减退（重复问同一个问题、忘记刚说过的话）；
  - 执行功能下降（不会用新家电、算不清账）；
  - 空间定向障碍（在熟悉的地方迷路）；
  - 语言变化（找词困难、叫不出物品名称）；
  - 人格改变（多疑、冷漠、易怒）。
- **早期干预的意义**：
  - MCI 阶段干预（认知训练、运动、控制三高）可延缓进展为痴呆；
  - 确诊后用药（多奈哌齐、美金刚、卡巴拉汀）可改善症状但不能治愈；
  - 可逆性"假性痴呆"：甲状腺功能减退、维生素 B12 缺乏、抑郁症、药物副作用——查了才知道，务必排查。

## 十一、失能照护详解

- **压疮（褥疮）预防**：
  - 核心：定时翻身（每 2 小时一次，夜間不超过 3 小时）；
  - 使用减压床垫/气垫床；
  - 保持皮肤清洁干燥，骨隆突处（骶尾、足跟、髋部）垫软枕；
  - 营养支持（蛋白质摄入不足是压疮危险因素）。
- **管道护理**（胃管、尿管、气管切开）：
  - 胃管：每次喂食前回抽确认位置，避免反流；口腔护理每日 2 次；
  - 尿管：保持尿袋低于膀胱水平，防止逆行感染；每日清洁尿道口；
  - 气管切开：内套管每日清洗消毒，保持切口周围皮肤干燥。
- **营养支持**：
  - 失能老人易营养不良（咀嚼/吞咽困难、食欲下降）；
  - 必要时调整食物质地（糊状、碎食）；吞咽困难者防止误吸（进食半坐位、小口慢咽）；
  - 必要时鼻饲/胃造瘘保证营养和水分。

## 十二、老年人心理与社会支持

- **孤独感**：
  - 老年人常见心理问题，与认知衰退、抑郁、死亡率增加相关；
  - 应对：社区活动、兴趣班、志愿者服务、宠物陪伴、视频通话（子女/亲友）。
- **丧偶/丧亲**：
  - 老年丧偶是最大生活应激事件之一，可能引发抑郁、免疫下降；
  - 允许悲伤，不强迫"赶紧走出来"；持续低落 ≥2 个月需专业干预；
  - 子女/亲友多陪伴，帮助处理日常事务。
- **退休适应**：
  - 常见问题：失落感、无价值感、角色缺失；
  - 应对：建立新的日常结构、发展兴趣爱好、参与社区/志愿活动、接受"从工作者到退休者"的身份转变。
- **老年人心理健康信号**：持续情绪低落、社交退缩、睡眠/食欲显著改变、对以前喜欢的事失去兴趣、反复表达无望感——出现这些信号应考虑抑郁可能，尽早就医。

## 十三、跌倒预防深度指南

### 家居改造详细清单

| 区域 | 改造措施 | 费用参考 |
| --- | --- | --- |
| 浴室 | 防滑垫（30–80 元）、马桶扶手（100–300 元）、淋浴区扶手、坐式淋浴凳 | 200–800 元 |
| 卧室 | 床边夜灯（20–50 元）、床高适中（坐床边脚能着地）、常用物品放伸手可及处 | 50–200 元 |
| 客厅/走廊 | 地毯固定胶带（20 元）、清除电线杂物、门槛做平 | 50–500 元 |
| 楼梯 | 两侧扶手（已有则检查牢固度）、踏步防滑条（50–100 元）、充足照明 | 100–500 元 |
| 厨房 | 常用物品放低处、稳固踏凳（非椅子）取高处物品、防滑地垫 | 50–200 元 |

### 平衡训练方案（每天 10 分钟）

| 训练项目 | 具体方法 | 组数×时间 |
| --- | --- | --- |
| 单脚站立（扶椅背） | 交替单脚站立，保持平衡 | 每侧 30 秒 × 3 次 |
| 脚跟接脚尖走直线 | 沿直线前后走 | 来回走 10 步 × 3 组 |
| 坐站训练 | 从椅子上站起坐下（不扶扶手） | 10 次 × 3 组 |
| 重心转移 | 双脚分开与肩同宽，左右转移重心 | 每侧 10 秒 × 5 次 |
| 踮脚站立 | 扶墙踮脚保持 | 10 秒 × 5 次 |

### 辅具选择

| 辅具类型 | 适用情况 | 选择要点 |
| --- | --- | --- |
| 拐杖（单拐） | 一侧下肢力量不足 | 高度：手柄与股骨大转子齐平 |
| 助行器（四脚拐） | 平衡功能较差 | 双手握持，高度与手腕齐平 |
| 轮椅 | 无法长时间行走 | 坐宽合适，脚踏可调 |
| 防滑鞋 | 日常行走 | 鞋底有深纹路、鞋面合脚、无鞋带（魔术贴） |
| 浴室扶手 | 洗澡/如厕 | 安装在马桶旁和淋浴区，承重 ≥100 kg |

### 跌倒后应对流程

1. **不要急于站起**：先评估是否有疼痛/无法活动的部位。
2. **若无大碍**：翻身侧卧 → 手撑地 → 膝盖跪地 → 扶家具站起。
3. **若无法站起或疼痛剧烈**：拨打 120，保持温暖，等待救援。
4. **跌倒后无论有无外伤**：建议 24 小时内就医检查（排除骨折、颅内出血）。

## 十四、认知症照护详解

### 阿尔茨海默病（AD）照护技巧

| 阶段 | 照护重点 |
| --- | --- |
| 轻度（早期） | 鼓励自理、建立规律生活、防走失（定位手表/卡片）、药物管理 |
| 中度（中期） | 简化环境（减少干扰物品）、使用图片提示、防止误食/误伤 |
| 重度（晚期） | 全面护理（翻身、口腔、营养）、管道护理、预防并发症 |

### 日常沟通技巧

- **使用简单短句**：一次说一件事，语速放慢。
- **用肯定句代替否定句**：说"请坐这里"而非"不要站着"。
- **给予充足时间**：不催促，等待回应。
- **保持眼神接触**：从正面接近，避免从背后突然出现。
- **用身体语言辅助**：指向物品、做示范动作。
- **避免争辩**：患者说出"错误"的话时不纠正，顺着话题引导。

### 环境安全改造

| 改造项目 | 原因 |
| --- | --- |
| 锁好刀具、清洁剂、药品 | 防误伤、误食 |
| 冰箱加锁或移除危险物品 | 防误食变质食物 |
| 安装GPS定位设备 | 防走失 |
| 移除门槛或做平 | 防绊倒 |
| 简化家具摆放 | 减少空间混乱感 |
| 厨房不使用时关闭燃气 | 防忘关火引发火灾 |

### 血管性痴呆照护

- **核心**：控制三高（高血压、高血糖、高血脂）是延缓进展的关键。
- **与 AD 的区别**：血管性痴呆常呈"阶梯式"恶化（每次脑血管事件后加重），AD 为渐进性。
- **康复训练**：语言训练、认知训练（拼图、记忆游戏）、肢体功能训练——越早开始效果越好。

> 来源：中国阿尔茨海默病协会（ADC）照护指南

## 十五、临终关怀

### 临终关怀的核心理念

- **不加速也不延缓死亡**：让患者在最后阶段尽可能舒适、有尊严。
- **控制症状为主**：疼痛、呼吸困难、恶心、焦虑——通过药物和护理缓解。
- **心理和精神支持**：倾听、陪伴、尊重患者意愿。

### 症状管理

| 症状 | 处理方法 |
| --- | --- |
| 疼痛 | WHO 三阶梯止痛（轻度→中度→重度逐级用药）；阿片类药物不会加速死亡 |
| 呼吸困难 | 半坐位、低流量吸氧、小剂量吗啡（缓解呼吸困难感） |
| 恶心呕吐 | 止吐药（甲氧氯普胺、昂丹司琼） |
| 焦虑烦躁 | 小剂量苯二氮䓬（劳拉西泮）、陪伴 |
| 谵妄 | 排除可逆原因（感染、便秘、药物）；小剂量抗精神病药 |

### 家属支持

- **提前沟通**：了解患者意愿（是否愿意插管、心肺复苏等），签署预立医疗指示。
- **哀伤辅导**：丧亲后持续悲伤 ≥6 个月需专业干预。
- **资源**：社区安宁疗护服务、医院临终关怀科、志愿者陪伴。

> 来源：中国抗癌协会癌症康复与姑息治疗专业委员会

## 十六、照护者心理健康

### 照护者压力评估

- **Zarit 照护者负担量表（ZBI）**：22 题，评估身体、情感、经济、社交四个维度的负担。
- **评分参考**：<21 分轻度负担，21–40 分中度负担，>40 分重度负担。

### 照护者自我关怀清单

| 方法 | 具体操作 |
| --- | --- |
| 轮换制度 | 与其他家人分工，每人负责固定时段；请护工/日间照料中心分担 |
| 保留个人时间 | 每周至少 2–3 小时完全属于自己（散步、读书、见朋友） |
| 支持团体 | 加入照护者互助群/社区支持小组（线上线下均可） |
| 心理咨询 | 出现持续失眠、烦躁、抑郁时就医或找心理咨询 |
| 接受帮助 | 接受亲友的帮助，不要觉得"必须自己扛" |
| 喘息服务 | 社区日间照料、短期托管，让照护者"喘口气" |

### 照护者身体健康管理

- **定期体检**：照护者自身健康同样重要，不要因照顾他人忽略自己。
- **睡眠保证**：尽量保证 6–7 小时睡眠；夜班照护可安排轮换。
- **运动**：每天 20–30 分钟散步或简单运动，缓解身体疲劳。
- **营养**：按时吃饭，不要用零食代替正餐。

> 来源：世界卫生组织（WHO）照护者支持指南

## 十八、老人营养管理

### 老人营养需求

| 营养素 | 每日需求 | 食物来源 |
|--------|---------|---------|
| 蛋白质 | 1.0-1.2g/kg体重 | 鸡蛋、鱼、瘦肉、豆腐 |
| 钙 | 1000-1200mg | 牛奶、酸奶、豆制品、绿叶菜 |
| 维生素D | 800-1000IU | 阳光、鱼肝油、蛋黄 |
| 膳食纤维 | 25-30g | 蔬菜、水果、全谷物 |
| 铁 | 男8mg/女10mg | 红肉、动物血、深色蔬菜 |

### 老人常见营养问题

| 问题 | 原因 | 对策 |
|------|------|------|
| 蛋白质不足 | 咀嚼/吞咽困难 | 调整食物质地（碎食、糊状） |
| 钙缺乏 | 吸收能力下降 | 补充钙剂+维生素D |
| 贫血 | 铁吸收减少 | 补充铁剂+维生素C |
| 营养不良 | 食欲下降、疾病消耗 | 少量多餐、营养补充 |
| 脱水 | 感觉迟钝、饮水不足 | 定时提醒饮水 |

### 老人饮食建议

| 建议 | 说明 |
|------|------|
| 少量多餐 | 每天5-6餐，每餐量少 |
| 食物质地 | 软烂、碎小、易咀嚼 |
| 营养均衡 | 蛋白质+碳水+脂肪+维生素+矿物质 |
| 定时进餐 | 养成规律进餐习惯 |
| 充足饮水 | 每天1500-2000ml |

### 老人饮食禁忌

| 禁忌 | 原因 |
|------|------|
| 过硬食物 | 咀嚼困难，易噎住 |
| 过咸食物 | 加重高血压、水肿 |
| 过甜食物 | 加重糖尿病、肥胖 |
| 油腻食物 | 消化不良、腹泻 |
| 生冷食物 | 胃肠功能弱，易腹泻 |

> 来源：中国营养学会《中国老年人膳食指南》

## 十九、老人用药安全

### 用药安全原则

| 原则 | 说明 |
|------|------|
| 遵医嘱 | 按医生开的药吃，不自行增减 |
| 定时定量 | 固定时间、固定剂量 |
| 不混用 | 不自行混用多种药物 |
| 定期复查 | 按医嘱复查，评估疗效和副作用 |
| 及时沟通 | 出现不适及时告诉医生 |

### 老人用药常见风险

| 风险 | 说明 | 防范 |
|------|------|------|
| 重复用药 | 不同药含相同成分 | 用药清单，让医生核对 |
| 药物相互作用 | 多种药同时吃可能冲突 | 告知医生所有在用药物 |
| 漏服/错服 | 老人记忆力差 | 药盒分装+手机提醒 |
| 副作用 | 老人代谢慢，副作用更明显 | 定期复查，及时调整 |
| 停药风险 | 血压血糖正常后停药会反弹 | 遵医嘱，不自行停药 |

### 用药管理工具

| 工具 | 用途 |
|------|------|
| 一周药盒 | 分装一周药物，避免漏服 |
| 手机提醒 | 设定服药时间提醒 |
| 用药清单 | 记录所有在用药物，就诊时带上 |
| 药物日志 | 记录服药情况和副作用 |

> 来源：中国老年医学学会用药安全指南

## 二十、老人心理健康

### 老人常见心理问题

| 问题 | 表现 | 应对 |
|------|------|------|
| 孤独感 | 情绪低落、社交退缩 | 社区活动、视频通话、宠物陪伴 |

| 焦虑 | 过度担心、坐立不安 | 放松训练、药物治疗 |
| 失落感 | 退休后角色缺失 | 发展兴趣爱好、参与社区活动 |
| 死亡焦虑 | 对死亡的恐惧和担忧 | 心理疏导、精神支持 |

### 心理健康干预

| 方法 | 说明 |
|------|------|
| 社交活动 | 鼓励参加社区活动、兴趣班 |
| 运动锻炼 | 适度运动改善情绪 |
| 兴趣爱好 | 培养新的兴趣爱好 |
| 家人陪伴 | 定期探望、视频通话 |
| 专业帮助 | 心理咨询、药物治疗 |

### 照护者心理健康

| 问题 | 表现 | 应对 |
|------|------|------|
| 照护者倦怠 | 疲惫、烦躁、抑郁 | 轮换制度、保留个人时间 |

| 身体透支 | 睡眠不足、饮食不规律 | 保证休息、规律饮食 |
