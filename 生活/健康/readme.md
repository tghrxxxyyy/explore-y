# 健康

> 个人健康知识库：体检怎么读、家里该备什么药、怎么科学运动与吃。目标是在去医院前能自查、能预防、能少踩坑。

## 核心原则

1. **预防大于治疗**：规律体检、疫苗、作息、饮食、运动，是最划算的健康投资。
2. **看懂指标比恐慌重要**：单项轻微异常很常见，看趋势、看组合、听医生。
3. **家里有药不等于能自诊**：抗生素、处方药不可滥用；症状重/持续/不明原因必须就医。
4. **急症认标志**：胸痛大汗、单侧肢体无力/口齿不清（中风）、剧烈头痛、呼吸困难、大出血——立即拨打 120。
