# 家庭药箱与常用药

> 家里备一点常用药，小毛病能从容应对；但"有药"不等于"能自诊"。本文按场景列常备清单、用法要点与最易踩的坑。

> ⚠️ 非医疗建议。处方药、抗生素、慢病药须遵医嘱；症状重/持续/高热/不明原因请就医。

## 一、退烧止痛

- **对乙酰氨基酚（扑热息痛）**：退烧、轻中度疼痛。相对温和，但**每日不超过 2 g**，肝不好者减量；很多复方感冒药已含此成分，叠加易过量中毒。
- **布洛芬（或萘普生）**：退烧、止痛、抗炎。胃肠刺激较大，**不要空腹吃**；有胃溃疡、肾功能不全、孕晚期慎用。
- 二者选一种即可，不要混吃；用药间隔遵医嘱/说明书。

## 二、感冒（大多是病毒，抗生素无效）

- 感冒多为自限性（5–7 天），对症即可：鼻塞用生理性盐水喷鼻；伪麻黄碱类可缓解鼻塞（高血压者慎用）；咳嗽用右美沙芬（干咳）。
- **关键误区**：普通感冒/流感是病毒，吃阿莫西林/头孢**没用**，反而破坏菌群、催生耐药。仅当明确细菌感染（如化脓性扁桃体炎、细菌性鼻窦炎）且医生判断后才用抗生素。

## 三、肠胃

- **口服补液盐（ORS）**：腹泻/呕吐第一要务是防脱水，比"止泻"更重要，尤其小孩老人。
- **蒙脱石散**：吸附止泻，急性腹泻可用；与其他药隔开 1–2 小时服。
- **益生菌**：辅助调节菌群，对抗生素相关腹泻、消化不良有帮助，非神药。
- **质子泵抑制剂（奥美拉唑等）**：反酸烧心短期用；长期用需医生评估。
- 剧烈腹痛、血便、高热、脱水——别硬扛，就医。

### 腹泻脱水判断与处理

| 脱水程度 | 表现 | 处理 |
| --- | --- | --- |
| 轻度 | 口渴、尿量略少 | 口服补液盐，继续饮食 |
| 中度 | 明显口渴、尿少、皮肤弹性差 | 口服补液盐，观察；不改善就医 |
| 重度 | 精神萎靡、眼窝凹陷、四肢冰凉 | 立即就医，可能需要静脉补液 |

- **ORS 冲调方法**：一包冲 500 ml 温水（不能用牛奶/果汁替代水）；少量多次饮用（每 5–10 分钟喝几口）。
- **儿童腹泻注意**：不用止泻药（洛哌丁胺不用于 2 岁以下）；继续喂养（不要禁食）；观察脱水体征。

## 四、过敏

- **氯雷他定 / 西替利嗪**：抗组胺，治荨麻疹、过敏性鼻炎、蚊虫过敏。嗜睡较轻（西替利嗪略困）。
- 严重过敏（喉头水肿、呼吸困难、全身风团伴头晕）——**立即急诊/肾上腺素笔（如有）**。

### 过敏分级与应对

| 过敏程度 | 表现 | 处理 |
| --- | --- | --- |
| 轻度 | 局部皮疹、轻微瘙痒、喷嚏 | 口服抗组胺药（氯雷他定） |
| 中度 | 大面积荨麻疹、轻度肿胀 | 抗组胺药 + 观察；加重就医 |
| 重度过敏反应 | 喉头水肿、呼吸困难、休克 | 立即打 120 + 肾上腺素笔 |

- **过敏原记录**：每次过敏后记录接触了什么食物/药物/物品、症状、持续时间——帮助识别过敏原。
- **常见交叉过敏**：对青霉素过敏者约 10% 对头孢也过敏；对某种花粉过敏者可能对某些水果也过敏（花粉-食物过敏综合征）。

## 五、中暑与晕车

- **中暑**：
  - 先兆中暑：头晕、口渴、多汗——移至阴凉处、补充含盐饮料、冷敷；
  - 轻度中暑：体温升高、恶心——上述措施 + 休息；不好转就医；
  - 重度中暑（热射病）：体温 >40℃、意识模糊——**立即打 120**，同时全身冷水降温。
- **晕车**：
  - 乘车前 30–60 分钟服用茶苯海明（乘晕宁）或东莨菪碱贴片；
  - 选择前排座位、看远方、开窗通风；
  - 避免空腹或过饱乘车。

## 六、外伤处理

- **碘伏**：消毒首选，比酒精温和、不蛰伤口；酒精用于完整皮肤。
- **创可贴 / 无菌纱布**：小伤口覆盖。
- **莫匹罗星（百多邦）等外用药**：预防/治小创面细菌感染。
- 深、脏、动物咬、锈铁扎伤——清创+评估是否打破伤风。

## 六、慢病与突发（按需备）

- 高血压/糖尿病/哮喘/心绞痛等：**按医嘱常备足量**，不可随意停。
- 冠心病者医生可能建议随身**硝酸甘油**（避光保存，舌下含服，5 分钟不缓解重复、仍不缓解打 120）。

## 七、药箱管理

- **分类+标签**：外用药、口服药分开；保留原包装与说明书。
- **定期清理**：过期药丢掉（别冲马桶，分类丢弃）；保健品不等于药。
- **存放**：阴凉干燥、儿童够不到；多数不需冰箱，需冷藏的按说明。
- **旅行小包**：退烧、止泻、创可贴、过敏药、个人常用药。

## 八、最该记住的坑

1. 抗生素 ≠ 消炎药 ≠ 感冒药，别乱吃。
2. 多种药可能含同种成分（如对乙酰氨基酚），叠加会过量。
3. 症状重/持续 3 天以上/高热/皮疹/呼吸困难——就医优先于自家药箱。

## 九、家庭药箱必备清单

| 类别 | 推荐药物 | 用途 | 备注 |
| --- | --- | --- | --- |
| 退烧止痛 | 对乙酰氨基酚、布洛芬 | 发烧、头痛、牙痛、肌肉痛 | 二选一，不混吃；注意复方感冒药含相同成分 |
| 感冒对症 | 生理性盐水鼻喷、右美沙芬（干咳）、伪麻黄碱 | 鼻塞、咳嗽 | 伪麻黄碱高血压者慎用 |
| 止泻 | 口服补液盐（ORS）、蒙脱石散 | 腹泻防脱水 | ORS 是腹泻第一要务 |
| 抗过敏 | 氯雷他定、西替利嗪 | 荨麻疹、鼻炎、蚊虫叮咬 | 氯雷他定嗜睡较轻 |
| 外伤 | 碘伏、创可贴、无菌纱布、莫匹罗星软膏 | 伤口消毒、覆盖、防感染 | 碘伏比酒精温和 |
| 止痒 | 炉甘石洗剂、氢化可的松乳膏（弱效） | 蚊虫叮咬、轻度皮炎 | 弱效激素乳膏短期局部用安全 |
| 胃肠 | 益生菌、多潘立酮（吗丁啉） | 消化不良、腹胀 | 吗丁啉饭前 15–30 分钟吃 |
| 眼部 | 含防腐剂的人工泪液 | 眼干、视疲劳 | 选不含防腐剂的单支装更好 |
| 个人常用药 | 按个人需求 | 慢性病用药、哮喘吸入剂等 | 足量备 1–2 周量 |

### 药品保存条件速查

| 保存条件 | 适用药品 | 注意事项 |
| --- | --- | --- |
| 阴凉干燥处（<20℃） | 大部分片剂、胶囊 | 避免阳光直射 |
| 常温保存（10–30℃） | 多数外用药、碘伏 | 不需冷藏 |
| 冷藏（2–8℃） | 部分眼药水、胰岛素、益生菌 | 不可冷冻 |
| 避光保存 | 硝酸甘油、某些滴眼液 | 原瓶保存或用棕色瓶 |

## 十、儿童用药注意事项

- **剂量计算**：儿童用药剂量必须按体重或体表面积计算，不能用成人剂量"减半"。常见计算方式：
  - 按体重：剂量 = 成人剂量 × (儿童体重 / 70 kg)
  - 按年龄：简化法（4–6 岁用成人 1/3，7–12 岁用成人 1/2）
  - **最准确的方式：看说明书或问药师**
- **儿童禁用/慎用药物**：

| 药物 | 年龄限制 | 风险 |
| --- | --- | --- |
| 阿司匹林 | <16 岁禁用（发热相关） | 瑞氏综合征（罕见但致命） |
| 含可待因/右美沙芬 | <12 岁慎用 | 呼吸抑制风险 |
| 喹诺酮类（如左氧氟沙星） | <18 岁慎用 | 影响软骨发育 |
| 四环素类 | <8 岁禁用 | 牙齿着色、釉质发育不全 |
| 氨基糖苷类（如庆大霉素） | 儿童慎用 | 耳毒性、肾毒性 |

- **对乙酰氨基酚 vs 布洛芬（儿童）**：
  - 对乙酰氨基酚：2 月龄以上可用，相对温和，但每日总量不超过 15 mg/kg（每剂间隔 4–6 小时）；
  - 布洛芬：6 月龄以上可用，退热效果稍强且持续更久（每剂间隔 6–8 小时），但胃肠刺激较大；
  - 两者可交替使用（间隔 2 小时以上），但单用一种通常足够。

## 十一、常见用药误区

| 误区 | 事实 |
| --- | --- |
| 抗生素 = 消炎药 | 抗生素杀细菌，对病毒无效；"消炎药"应指布洛芬等抗炎药 |
| 症状好转就停抗生素 | 疗程未完成易催生耐药；必须按医嘱用完全程 |
| 中药/中成药没有副作用 | 是药三分毒，中药也有肝肾毒性（如含马兜铃酸的中药）、药物相互作用 |
| 多种药一起吃效果更好 | 药物可能相互作用（增强或拮抗），必须告知医生所有在用药物 |
| 药量越大效果越好 | 超量使用增加毒副作用风险，严格按说明书/医嘱 |
| 输液比口服药好 | 输液有风险（过敏、感染、输液反应），能口服解决的不输液 |
| 维生素/保健品随便补 | 脂溶性维生素（A/D/E/K）过量蓄积会中毒；铁过量损伤肝脏 |

### 家庭药箱管理检查表

| 检查项目 | 频率 | 具体操作 |
| --- | --- | --- |
| 过期药清理 | 每 3–6 个月 | 检查所有药品有效期，过期丢弃 |

| 冷藏药品检查 | 每周 | 需冷藏药品是否在 2–8℃ 保存 |

## 十二、过期药处理

- **过期药不能吃**：过期后药效降低或产生有害分解物。
- **过期药不能随意丢弃**：不冲马桶、不扔厨余垃圾——污染环境。
- **正确处理方式**：
  - 连同包装一起放入密封袋；
  - 投入社区/药店的"过期药品回收箱"（部分城市已设点）；
  - 无回收点时，混入猫砂/咖啡渣后密封丢入"有害垃圾"桶。
- **定期清理**：每 3–6 个月检查一次药箱，过期药物及时清理，补足常用药。

## 十三、用药时间与方式

| 用药时间 | 含义 | 常见药物举例 |
| --- | --- | --- |
| 空腹 | 餐前 1 小时或餐后 2 小时 | 甲状腺药（左甲状腺素）、某些胃药 |
| 餐前（饭前 15–30 分钟） | 胃排空时吸收好 | 吗丁啉、部分降糖药 |
| 餐中/餐后 | 减少胃肠刺激 | 布洛芬、大多数中成药 |
| 睡前 | 助眠或减少夜间症状 | 他汀类（部分）、抗组胺药 |
| 定时 | 维持血药浓度 | 降压药、抗生素（按间隔时间） |

- **服药用水**：一般 200 ml 温开水送服；不建议用茶、牛奶、果汁送服（可能影响药物吸收）。
- **缓释片/控释片**：整片吞服，不可掰开、碾碎或嚼碎（破坏控释机制导致药物突释）。

## 十四、就医信号识别

以下情况不要犹豫，及时去医院：

| 症状 | 可能提示 |
| --- | --- |
| 高热持续 3 天以上不退 | 感染未控制、需排查病因 |
| 胸痛、胸闷、气短 | 心脏问题、肺栓塞 |
| 剧烈头痛伴呕吐、视物模糊 | 高血压急症、脑出血 |
| 呼吸困难、喉头水肿 | 严重过敏反应、哮喘急性发作 |
| 腹痛剧烈、血便 | 消化道出血、急腹症 |
| 外伤出血不止、疑似骨折 | 需清创/缝合/影像检查 |
| 皮疹伴发热、黏膜溃疡 | 严重药物过敏、感染性疾病 |
| 尿量明显减少、水肿 | 肾功能问题 |
| 意识模糊、抽搐 | 神经系统问题 |
| 儿童精神萎靡、持续哭闹 | 感染严重、脱水 |

## 十五、非处方药分类速查

### 感冒用药

| 药物 | 作用 | 用法要点 | 注意事项 |
| --- | --- | --- | --- |
| 对乙酰氨基酚（扑热息痛） | 退烧、止痛 | 每次 300–600 mg，每 4–6 小时一次 | 每日不超过 2 g，肝功能不全者慎用 |
| 布洛芬 | 退烧、止痛、抗炎 | 每次 200–400 mg，每 6–8 小时一次 | 餐后服用，胃溃疡者禁用 |
| 右美沙芬 | 干咳 | 每次 15–30 mg，每 6–8 小时一次 | 痰多者不宜单用（抑制咳嗽排痰） |
| 伪麻黄碱 | 缓解鼻塞 | 每次 30–60 mg，每 6–8 小时一次 | 高血压者慎用 |

### 止痛药

| 药物 | 适用疼痛类型 | 用法要点 |
| --- | --- | --- |
| 对乙酰氨基酚 | 头痛、牙痛、关节痛 | 按说明书剂量，不与含同成分感冒药叠加 |
| 布洛芬 | 头痛、牙痛、痛经、肌肉痛 | 餐后服用，连续使用不超过 5 天 |
| 萘普生 | 痛经、肌肉痛 | 布洛芬不耐受时的替代选择 |

### 止泻药

| 药物 | 作用 | 用法要点 |
| --- | --- | --- |
| 口服补液盐（ORS） | 防脱水（腹泻首要措施） | 一包冲 500 ml 温水，少量多次饮用 |
| 蒙脱石散 | 吸附止泻 | 急性腹泻可用，与其他药隔开 1–2 小时 |
| 洛哌丁胺（易蒙停） | 减少肠蠕动 | 2 岁以上可用；感染性腹泻不宜单独使用 |

### 抗过敏药

| 药物 | 特点 | 用法 |
| --- | --- | --- |
| 氯雷他定 | 嗜睡较轻，一天一次 | 每次 10 mg，每天 1 次 |
| 西替利嗪 | 嗜睡较重（部分人） | 每次 10 mg，每天 1 次 |
| 扑尔敏（氯苯那敏） | 嗜睡明显 | 每次 4 mg，每天 3 次（夜间使用较好） |

### 外用药

| 药物 | 用途 | 用法 |
| --- | --- | --- |
| 碘伏 | 伤口消毒 | 直接涂抹，比酒精温和 |
| 莫匹罗星（百多邦） | 小创面感染预防/治疗 | 薄涂患处，每日 2–3 次 |
| 炉甘石洗剂 | 蚊虫叮咬、轻度皮炎 | 摇匀后涂抹，每日多次 |
| 氢化可的松乳膏（弱效） | 轻度皮炎、湿疹 | 薄涂患处，每日 1–2 次，短期使用 |

> 来源：中国非处方药物协会用药指南

## 十六、药物存储条件详解

### 常见药品保存要求

| 保存条件 | 温度范围 | 适用药品 | 注意事项 |
| --- | --- | --- | --- |
| 阴凉干燥处 | <20℃ | 大部分片剂、胶囊 | 避免阳光直射、远离热源 |
| 常温保存 | 10–30℃ | 多数外用药、碘伏 | 不需冷藏 |
| 冷藏 | 2–8℃ | 部分眼药水、胰岛素、益生菌 | 不可冷冻，用冷藏室上层 |
| 避光保存 | — | 硝酸甘油、某些滴眼液 | 原瓶保存或用棕色瓶 |
| 阴暗处 | 避光+阴凉 | 某些栓剂、生物制剂 | 按说明书要求 |

### 特殊药品存储

| 药品 | 特殊要求 |

## 十九、过期药处理

### 过期药的危害

- **药效降低**：有效成分分解，达不到治疗效果。
- **产生有害物质**：某些药物过期后分解产物有毒（如四环素过期后产生肾毒性物质）。
- **延误治疗**：吃无效的药等于没治，反而可能延误病情。

### 正确处理方式

| 步骤 | 操作 |
| --- | --- |
| 第一步 | 连同包装一起放入密封袋 |
| 第二步 | 投入社区/药店的"过期药品回收箱"（部分城市已设点） |
| 第三步 | 无回收点时，混入猫砂/咖啡渣后密封丢入"有害垃圾"桶 |
| 第四步 | **不要**冲马桶、不扔厨余垃圾（污染环境） |

### 定期清理建议

- **频率**：每 3–6 个月检查一次药箱。
- **检查内容**：药品有效期、药品外观（变色、变味、潮解）、药品完整性。
- **清理后补充**：退烧、止泻、过敏药是家庭必备，及时补足。

> 来源：国家药品监督管理局过期药品处理指南

## 十九、非处方药分类详解

### 感冒用药

| 药物 | 作用 | 用法要点 | 注意事项 |
| --- | --- | --- | --- |
| 对乙酰氨基酚（扑热息痛） | 退烧、止痛 | 每次 300–600 mg，每 4–6 小时一次 | 每日不超过 2 g，肝功能不全者慎用 |
| 布洛芬 | 退烧、止痛、抗炎 | 每次 200–400 mg，每 6–8 小时一次 | 餐后服用，胃溃疡者禁用 |
| 右美沙芬 | 干咳 | 每次 15–30 mg，每 6–8 小时一次 | 痰多者不宜单用（抑制咳嗽排痰） |
| 伪麻黄碱 | 缓解鼻塞 | 每次 30–60 mg，每 6–8 小时一次 | 高血压者慎用 |

### 止痛药

| 药物 | 适用疼痛类型 | 用法要点 |
| --- | --- | --- |
| 对乙酰氨基酚 | 头痛、牙痛、关节痛 | 按说明书剂量，不与含同成分感冒药叠加 |
| 布洛芬 | 头痛、牙痛、痛经、肌肉痛 | 餐后服用，连续使用不超过 5 天 |
| 萘普生 | 痛经、肌肉痛 | 布洛芬不耐受时的替代选择 |

### 止泻药

| 药物 | 作用 | 用法要点 |
| --- | --- | --- |
| 口服补液盐（ORS） | 防脱水（腹泻首要措施） | 一包冲 500 ml 温水，少量多次饮用 |
| 蒙脱石散 | 吸附止泻 | 急性腹泻可用，与其他药隔开 1–2 小时 |
| 洛哌丁胺（易蒙停） | 减少肠蠕动 | 2 岁以上可用；感染性腹泻不宜单独使用 |

### 抗过敏药

| 药物 | 特点 | 用法 |
| --- | --- | --- |
| 氯雷他定 | 嗜睡较轻，一天一次 | 每次 10 mg，每天 1 次 |
| 西替利嗪 | 嗜睡较重（部分人） | 每次 10 mg，每天 1 次 |
| 扑尔敏（氯苯那敏） | 嗜睡明显 | 每次 4 mg，每天 3 次（夜间使用较好） |

### 外用药

| 药物 | 用途 | 用法 |
| --- | --- | --- |
| 碘伏 | 伤口消毒 | 直接涂抹，比酒精温和 |
| 莫匹罗星（百多邦） | 小创面感染预防/治疗 | 薄涂患处，每日 2–3 次 |
| 炉甘石洗剂 | 蚊虫叮咬、轻度皮炎 | 摇匀后涂抹，每日多次 |
| 氢化可的松乳膏（弱效） | 轻度皮炎、湿疹 | 薄涂患处，每日 1–2 次，短期使用 |
