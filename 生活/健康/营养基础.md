# 营养基础

> 吃是每天的事，搞懂基本逻辑比追某个"超级食物"有用。本文讲宏量营养素、热量缺口、膳食结构、常见误区。

## 一、三大宏量营养素

- **蛋白质**：构建肌肉/酶/免疫。成人约 0.8–1.2 g/kg/天；运动/增肌/老人可到 1.2–1.6 g/kg。来源：蛋奶肉鱼虾豆制品。
- **碳水**：主要能量来源。优选全谷、薯类、豆类（慢碳，升糖稳）；少喝含糖饮料、少吃精制糖。
- **脂肪**：激素合成、吸收脂溶性维生素所需。优选不饱和脂肪（橄榄油、坚果、鱼）；控反式脂肪（部分氢化油）、限过量饱和脂肪。

## 二、热量：减脂的核心是缺口

- **热量缺口** = 消耗 − 摄入。制造约每天 300–500 kcal 缺口，安全减重（每周 0.3–0.5 kg）。
- 估算消耗：基础代谢（BMR）× 活动系数；网上 Mifflin-St Jeor 公式可用。手算粗略：男性约 1500–1800 基础，女性约 1200–1500。
- **别极端节食**：低于基础代谢易掉肌肉、代谢下降、反弹；蛋白质吃够+力量训练能保肌肉。

## 三、膳食结构（参考"膳食宝塔"思路）

- 一半盘子是蔬菜（多样、深绿色为主），适量水果（别当饭吃，糖分不低）。
- 主食 1/3–1/2 换全谷杂豆薯类。
- 优质蛋白每餐有一点；鱼每周 1–2 次。
- 奶/豆制品 daily。
- 油盐控量：盐 < 5 g/天，油 25–30 g/天。

## 四、喝水与膳食纤维

- 水：约 1.5–2 L/天（运动/热天加量），看尿色（淡黄为好）。
- 纤维：蔬菜+全谷+豆类，助肠道、稳血糖；突然加量会胀气，循序渐进+多喝水。

## 五、外卖/外食怎么相对健康

- 少油少糖少精制：米线/麻辣烫多选菜少麻酱；盖饭配菜加倍、米饭减半；奶茶选无糖/三分糖。
- 蛋白质优先：鱼虾蛋瘦肉 > 加工肉（香肠培根）。
- 规律进食，避免长期熬夜吃宵夜。

## 六、常见误区

1. **戒碳水能瘦**：短期掉的是水；长期伤代谢、情绪、运动表现。控"质+量"而非全戒。
2. **生酮/断食人人适用**：特定人群（糖尿病用药、孕哺、进食障碍史、青少年）需谨慎，先问医生。
3. **蛋白粉伤肾**：健康人适量无碍；已有肾病才需限蛋白——看前提。
4. **"0 糖"= 健康**：代糖饮料热量低，但别当水喝，整体饮食才是关键。
5. **补剂替代食物**：维 D、B12、Omega-3 等在特定缺乏时有用，但不能替代均衡饮食。

## 七、该查的营养相关指标

- 贫血看血常规+铁蛋白；维 D 可查血 25-OH-D；血糖看空腹+糖化；血脂看 LDL/HDL/TG。缺了再补，别盲补。

## 九、中国居民膳食指南（2022）核心要点

- **食物多样，合理搭配**：每天摄入 12 种以上食物，每周 25 种以上。
- **谷类为主**：每天谷类 200–300 g，其中全谷物和杂豆 50–150 g；薯类 50–100 g。
- **多吃蔬果**：蔬菜每天 300–500 g（深色蔬菜占一半以上），水果 200–350 g。
- **适量鱼禽蛋瘦肉**：动物性食物每天 120–200 g；每周至少吃 2 次鱼（每次约 100–150 g）。
- **奶及豆类**：每天液态奶 300–500 g，大豆及坚果 25–35 g。
- **少盐少油**：盐 < 5 g/天，油 25–30 g/天；添加糖 < 50 g/天（最好 < 25 g）。
- **足量饮水**：成年男性约 1700 ml/天，女性约 1500 ml/天（不包括食物含水）。

### 膳食宝塔各层建议量

| 层级 | 食物类别 | 每日建议量 |
| --- | --- | --- |
| 第一层（底层） | 谷薯类 | 谷类 200–300 g，全谷物 50–150 g，薯类 50–100 g |
| 第二层 | 蔬菜水果 | 蔬菜 300–500 g，水果 200–350 g |
| 第三层 | 畜禽肉蛋 | 肉类 40–75 g，水产品 40–75 g，蛋类 40–50 g（约 1 个） |
| 第四层 | 奶豆坚果 | 液态奶 300–500 g，大豆 15–25 g，坚果 10 g |
| 第五层（顶层） | 油盐 | 盐 < 5 g，油 25–30 g |

### 实用餐盘法

- **蔬菜占 1/2 盘子**：深色和浅色各一半；
- **主食占 1/4 盘子**：尽量选全谷物和薯类；
- **蛋白质占 1/4 盘子**：鱼、禽、蛋、瘦肉、豆制品轮换；
- **每餐加一份奶制品**：牛奶、酸奶或奶酪。

## 十、热量计算与体重管理

- **基础代谢率（BMR）估算（Mifflin-St Jeor 公式）**：
  - 男性：BMR = 10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 + 5
  - 女性：BMR = 10 × 体重(kg) + 6.25 × 身高(cm) − 5 × 年龄 − 161
- **每日总消耗（TDEE）** = BMR × 活动系数：
  - 久坐：1.2；轻度活动：1.375；中等活动：1.55；重度活动：1.725
- **减脂**：TDEE − 300~500 kcal/天，每周减重 0.3–0.5 kg（安全且可持续）。
- **增肌**：TDEE + 200~300 kcal/天，配合力量训练，蛋白质摄入 1.6–2.2 g/kg。
- **体重指数（BMI）**：18.5–24.9 正常，25–27.9 超重，≥28 肥胖（中国标准）；但 BMI 不区分肌肉和脂肪，体脂率和腰围更有参考价值。

### 减脂饮食策略

- **蛋白质优先**：每餐先吃蛋白质（蛋/肉/鱼/豆），增加饱腹感、保护肌肉。
- **蔬菜打底**：每餐至少 1 拳蔬菜，体积大热量低，填饱肚子。
- **主食后吃**：最后吃碳水，可减缓血糖波动。
- **细嚼慢咽**：每口嚼 20 次以上，大脑接收饱腹信号需 15–20 分钟。
- **不饿不食**：区分"真饿"（胃空感）和"假饿"（嘴馋/情绪性进食）。

## 十一、常见饮食误区

| 误区 | 事实 |
| --- | --- |
| 节食/极低热量减肥 | 短期掉秤但掉的是肌肉和水，代谢下降，反弹更快 |
| 代餐可以完全替代正餐 | 代餐热量低、营养不全面，长期用会导致营养缺乏 |
| 生酮饮食适合所有人 | 生酮限制碳水严重，糖尿病用药者、孕妇、肾病患者、青少年需谨慎 |
| 间歇性断食人人适用 | 育龄女性可能影响月经，低血糖风险人群不宜 |
| "0 糖"饮料随便喝 | 代糖可能影响肠道菌群，且整体饮食结构才是关键 |
| 蛋白粉比食物好吸收 | 天然食物中的蛋白附带其他营养素，补剂只是补充而非替代 |
| 减肥不能吃主食 | 完全不吃碳水影响情绪、运动表现和激素水平 |

## 十二、特殊人群营养

- **孕妇**：
  - 孕中晚期能量增加约 300 kcal/天；蛋白质、铁、钙、叶酸需求增加；
  - 叶酸 400–800 μg/天（孕前 3 个月开始）；铁 24–29 mg/天（多吃红肉、动物血）；
  - 避免：生鱼片、未全熟肉蛋、高汞鱼类（鲨鱼、金枪鱼）、酒精。

| 孕期 | 额外能量需求 | 关键营养素 |
| --- | --- | --- |
| 孕早期（1–3 月） | 不增加 | 叶酸 600 μg/天 |
| 孕中期（4–6 月） | +300 kcal/天 | 铁 24 mg/天、钙 1000 mg/天 |
| 孕晚期（7–9 月） | +450 kcal/天 | 蛋白质增加 25 g/天、钙 1000 mg/天 |
| 哺乳期 | +500 kcal/天 | 钙 1000 mg/天、维 D 10 μg/天 |

- **儿童**：
  - 均衡饮食优先，不偏食；牛奶每天 300–500 ml；
  - 不喝含糖饮料；零食选水果、坚果、酸奶；
  - 2 岁以下避免蜂蜜（肉毒杆菌风险）。

| 年龄段 | 关键营养重点 |
| --- | --- |
| 0–6 月 | 纯母乳喂养（最佳营养来源） |
| 6–12 月 | 逐步添加辅食（先泥糊状后碎食），补铁（强化铁米粉） |
| 1–3 岁 | 蛋白质、钙（奶量保证）、铁（红肉每周 2–3 次） |
| 4–6 岁 | 均衡膳食、控制零食和含糖饮料 |
| 7–17 岁 | 蛋白质需求增加（生长发育期）、钙（骨骼生长） |

- **老年人**：
  - 蛋白质需求增加（1.0–1.2 g/kg），预防少肌症；
  - 钙 1000–1200 mg/天 + 维 D 800–1000 IU/天；
  - 食物煮软易消化，少量多餐。
- **运动人群**：
  - 运动前 1–2 小时：碳水为主（香蕉、全麦面包）；
  - 运动后 30–60 分钟：蛋白质 + 碳水（牛奶 + 水果、蛋白粉 + 香蕉）；
  - 大量出汗时补充含电解质的运动饮料。
- **素食者**：
  - 注意补充维生素 B12（几乎只存在于动物性食品中）；
  - 铁来源（植物铁吸收率低）：搭配维 C 食物（如菠菜+柠檬汁）提高吸收率；
  - 蛋白质互补：谷类 + 豆类搭配可获得完整氨基酸谱；
  - 必要时考虑补充剂（B12、铁、锌、Omega-3/DHA）。

## 十三、读懂食品标签

- **营养成分表必看三项**：能量（kJ）、蛋白质、钠；关注"每份"还是"每 100 g"的区别。
- **配料表顺序**：按含量从高到低排列，排在前面的含量越多；警惕"糖"的各种变体（蔗糖、果葡糖浆、麦芽糊精等）。
- **健康声称不等于健康食品**：标注"低脂"可能加了大量糖，"高钙"可能脂肪也很高。
- **NRV%（营养素参考值百分比）**：超过 20% 为"高"，低于 5% 为"低"；钠的 NRV% 越低越好。

### 食品标签阅读实战

| 看什么 | 怎么判断 | 常见陷阱 |
| --- | --- | --- |
| 配料表第一项 | 排在最前面 = 含量最多 | "全麦面包"第一项是小麦粉而非全麦粉 = 虚假宣传 |
| 每份 vs 每 100 g | 对比不同产品用"每 100 g"更公平 | 小包装写"每份"隐藏真实份量 |
| 糖的位置 | 配料表中糖排名越靠后越好 | 果葡糖浆、麦芽糖浆、蜂蜜都是糖的变体 |
| 钠含量 | 每 100 g 中钠 × 2.5 = 盐含量（mg） | "酱油味""烧烤味"等风味零食钠含量极高 |
| 蛋白质含量 | >12 g/100 g 为高蛋白食物 | 某些"高蛋白"产品靠添加蛋白粉而非天然蛋白 |
| 脂肪类型 | 关注反式脂肪（部分氢化植物油） | 标注 0 g 反式脂肪可能仍有 <0.3 g（法规允许） |

## 十五、营养标签解读

### 必看三项

| 项目 | 怎么看 | 常见陷阱 |
| --- | --- | --- |
| 能量（kJ） | 除以 4.18 换算为大卡（kcal） | 大包装写"每份"隐藏真实份量 |
| 蛋白质 | >12 g/100 g 为高蛋白食物 | 某些"高蛋白"产品靠添加蛋白粉 |
| 钠 | 每 100 g 中钠 × 2.5 = 盐含量（mg） | "低钠"不等于"无盐" |

### 配料表解读规则

- **按含量从高到低排列**：排在最前面的含量越多。
- **警惕"糖"的变体**：蔗糖、果葡糖浆、麦芽糊精、蜂蜜、浓缩果汁——都是糖。
- **"全麦面包"不一定全麦**：配料表第一项是"全麦粉"才是真正的全麦面包。
- **"0 反式脂肪"不等于无反式脂肪**：法规允许 <0.3 g/100 g 标注为 0。

### NRV%（营养素参考值百分比）

- **含义**：该食物一份提供的营养素占每日推荐摄入量的百分比。
- **判断标准**：>20% 为"高"，<5% 为"低"。
- **钠的 NRV% 越低越好**（钠高 = 盐高）。
- **蛋白质的 NRV% 越高越好**（蛋白质高 = 营养密度高）。

> 来源：中国营养学会《中国居民膳食指南（2022）》

## 十六、特殊人群营养

### 孕妇营养要点

| 营养素 | 需求增加 | 食物来源 |
| --- | --- | --- |
| 叶酸 | 600 μg/天（孕前 3 个月开始） | 深绿色蔬菜、动物肝脏、豆类 |
| 铁 | 24–29 mg/天（孕中晚期） | 红肉、动物血、菠菜 |
| 钙 | 1000 mg/天 | 奶制品、豆腐、绿叶菜 |
| DHA | 200 mg/天 | 深海鱼（三文鱼、沙丁鱼）、藻油 |
| 碘 | 230 μg/天 | 碘盐、海带、紫菜 |

### 老年人营养

| 营养素 | 需求变化 | 实操建议 |
| --- | --- | --- |
| 蛋白质 | 需求增加（1.0–1.2 g/kg） | 每餐有蛋白质（蛋/肉/鱼/豆） |
| 钙 | 1000–1200 mg/天 | 每天 300–500 ml 奶 + 补充剂 |
| 维生素 D | 800–1000 IU/天 | 日照 + 补充剂 |
| 膳食纤维 | 25–30 g/天 | 蔬菜 + 全谷 + 豆类（逐渐增加） |

### 素食者营养

| 容易缺乏的营养素 | 补充建议 |
| --- | --- |
| 维生素 B12 | 几乎只存在于动物性食品中，需补充剂 |
| 铁 | 植物铁吸收率低，搭配维 C 食物提高吸收率 |
| 锌 | 坚果、全谷、豆类；必要时用补充剂 |
| Omega-3/DHA | 亚麻籽、核桃；或藻油 DHA 补充剂 |
| 蛋白质互补 | 谷类 + 豆类搭配获得完整氨基酸谱 |

### 健身人群营养

| 训练目标 | 蛋白质需求 | 碳水策略 |
| --- | --- | --- |
| 增肌 | 1.6–2.2 g/kg/天 | 训练前 1–2 小时碳水为主；训练后蛋白质+碳水 |
| 减脂 | 1.2–1.6 g/kg/天 | 控制总热量，蛋白质优先 |
| 耐力运动 | 1.2–1.4 g/kg/天 | 运动中每小时补充 30–60 g 碳水 |

> 来源：中国营养学会特殊人群营养指南

## 十七、常见营养误区

| 误区 | 事实 |
| --- | --- |
| "维生素 C 能治感冒" | 无法治疗感冒，但可能轻微缩短病程；预防效果证据有限 |
| "蛋白粉比食物好吸收" | 天然食物中的蛋白附带其他营养素，补剂只是补充而非替代 |
| "喝骨头汤补钙" | 骨头汤钙含量极低（约 2–4 mg/100 ml），远不如牛奶（约 104 mg/100 ml） |
| "红皮鸡蛋比白皮鸡蛋营养好" | 蛋壳颜色与营养价值无关，取决于鸡的品种 |
| "土鸡蛋比洋鸡蛋营养好" | 营养成分差异很小，主要区别在口感和饲养方式 |
| "蜂蜜比白糖健康" | 蜂蜜主要成分是糖（果糖+葡萄糖），热量与白糖接近 |
| "膳食纤维越多越好" | 过量纤维导致腹胀、影响矿物质吸收；循序渐进增加 |
| "油不能吃，越少越好" | 必需脂肪酸需要适量油脂；优选不饱和脂肪（橄榄油、鱼油） |
| "食物相克导致中毒" | 无科学依据；但某些食物确实影响药物吸收（如西柚与他汀） |

> 来源：中国营养学会营养科普平台
