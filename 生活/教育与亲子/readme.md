# 教育与亲子

> 养孩子是家庭最大也最长的"项目"：从择校、兴趣班到教育金和日常沟通，每步都有信息差。本板块把高频决策整理成可操作的思路与清单。

## 通用原则

1. **尊重孩子的节奏**：发育有早有晚，横向比较是焦虑源头，多纵向看"比上次有进步"。
2. **教育金越早越省**：复利靠时间，0 岁开始每年存一点，远轻松过 12 岁一次性补。
3. **机构宣传要辨别**："保过""名师""冠军"话术打折看，试听、资质、退费条款比海报重要。
4. **家长先稳定自己**：父母的情绪是孩子情绪的定海神针，先处理好自己的焦虑再谈教育方法。
