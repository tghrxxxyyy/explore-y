## 通用原则

1. **领养代替购买**：领养渠道（城市救助站、线上领养平台）可救一条命，成本也常更低；购买请只考虑正规犬舍猫舍，拒绝无证繁殖。
2. **预算先行**：先算清每月固定开销与医疗储备金再决定养不养、养什么；养得起比养得起"品种"重要。
3. **定期体检**：疫苗、驱虫、年度体检不能省，早发现小病，省的是大钱。
4. **科学喂养，不人云亦云**：以兽医和可靠科普为准，警惕"网红喂法"和偏方。
