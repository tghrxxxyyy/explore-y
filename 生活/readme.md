# 生活

> 围绕日常生活的实用内容库，分十一大板块：**吃**（家常菜做法）、**用**（家电选购）、**健康**（体检/用药/运动/营养）、**居家**（装修/收纳/物业）、**出行**（机票酒店签证/海关行李/租车）、**旅行**（全国省市区指南）、**生活常识**（安全/权益/应急/防灾，权威来源可查）、**小妙招**（清洁去渍/保鲜/除味防潮/家务效率）、**养宠**、**教育与亲子**、**法律维权**。

## 子板块

- [吃](吃/readme.md) — 十大菜系（鲁川粤闽苏浙湘徽 + 京、本帮）+ 家常菜，每道菜含食材、步骤、小贴士，可配图文。
- [用](用/readme.md) — 常见家电的品牌、价格区间、评价与选购建议。
- [健康](健康/readme.md) — 体检报告解读、家庭药箱与常用药、运动健身、营养、睡眠、心理情绪、慢病管理、女性健康、老人照护、口腔视力、疫苗接种（含免责声明）。
- [居家](居家/readme.md) — 装修避坑、收纳整理、家电安装与保修、物业与邻里纠纷、租房与买房决策。
- [出行](出行/readme.md) — 机票酒店与签证、海关与行李、境外用卡与通信、租车自驾、行李打包、里程积分与省钱攻略。
- [旅行](旅行/readme.md) — 全国 34 个省级行政区全覆盖，分省分市，城市特色 / 景点 / 人文历史（江苏已细化到景点级）。
- [生活常识](生活常识/readme.md) — 急救 / 消防 / 食品安全 / 居家安全 / 防骗维权 / 法律权益 / 气象灾害 / 环保垃圾分类；全部基于政府机关与官方机构权威来源，正文标出处、文末附来源清单。
- [小妙招](小妙招/readme.md) — 衣物清洗去渍、厨房清洁去油、食材保鲜与冰箱管理、除味防潮防虫、一物多用与家务效率。
- [养宠](养宠/readme.md) — 养猫养狗入门、日常照顾、常见病与就医、花销预算与宠物保险。
- [教育与亲子](教育与亲子/readme.md) — 学区择校、兴趣班选择、教育金规划、育儿方法与亲子沟通。
- [法律维权](法律维权/readme.md) — 消费维权、劳动权益与仲裁、合同审查要点、房产与邻里法律。
