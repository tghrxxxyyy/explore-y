# 生活

> 围绕日常生活的实用内容库，分七大板块：**吃**（家常菜做法）、**用**（家电选购）、**健康**（体检/用药/运动/营养）、**居家**（装修/租房买房）、**出行**（机票酒店签证/里程）、**旅行**（全国省市区指南）、**生活常识**（安全/权益/应急/防灾，权威来源可查）。

## 子板块

- [吃](吃/readme.md) — 十大菜系（鲁川粤闽苏浙湘徽 + 京、本帮）+ 家常菜，每道菜含食材、步骤、小贴士，可配图文。
- [用](用/readme.md) — 常见家电的品牌、价格区间、评价与选购建议。
- [健康](健康/readme.md) — 体检报告解读、家庭药箱与常用药、运动健身基础、营养基础（含免责声明）。
- [居家](居家/readme.md) — 装修避坑、租房与买房决策。
- [出行](出行/readme.md) — 机票酒店与签证、里程积分与省钱攻略。
- [旅行](旅行/readme.md) — 全国 34 个省级行政区全覆盖，分省分市，城市特色 / 景点 / 人文历史（江苏已细化到景点级）。
- [生活常识](生活常识/readme.md) — 急救 / 消防 / 食品安全 / 居家安全 / 防骗维权 / 法律权益 / 气象灾害 / 环保垃圾分类；全部基于政府机关与官方机构权威来源，正文标出处、文末附来源清单。
