# 河北（省）

![河北代表风光](/images/河北.png)


> 环抱京津，燕赵大地，太行山与渤海之间。古迹众多，长城与大运河重要段落，钢铁建材重镇。

**省会/首府：** 石家庄

## 🍜 美食地图
驴肉火烧、保定铁球(小吃)、白洋淀全鱼

## 🗓️ 最佳旅游季节
夏避暑、秋登高，承德夏宜

## 🚆 交通概况
环京高铁密，石家庄正定机场
