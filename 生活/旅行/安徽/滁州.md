# 滁州（市）

> "醉翁之意不在酒"。皖东门户，欧阳修《醉翁亭记》故里，琅琊山人文与明中都皇城遗址交相辉映。

## 城市速览

- **别称 / 区位**：亭城、醉翁故里；安徽东部、苏皖交界，紧邻南京
- **最佳季节**：春（4–5 月）琅琊山新绿、醉翁亭雅集；秋（9–11 月）登高最爽；夏季山林清凉
- **交通概况**：高铁滁州站 / 全椒站（京沪高铁）、滁州北站（普铁）；南京地铁 S4（宁滁城际）已通；自驾经 G40 / G42
- **必吃**：琅琊酥糖、雷官板鸭、滁州鲫、管坝牛肉、凤阳酿豆腐、炉桥桥尾

## ⛰️ 名山古亭

### 琅琊山
- **位置**：滁州市南谯区（市区西南约 5 公里）
- **特色看点**：因欧阳修《醉翁亭记》名扬天下，"蓬莱之后无别山"。醉翁亭（四大名亭之首）、同乐园（欧阳修纪念馆）、琅琊寺、南天门、深秀湖；摩崖石刻与古木幽径
- **门票参考价**：山门免费入园；核心四景点联票（醉翁亭 + 同乐园 + 琅琊寺 + 南天门）成人 ¥65、优待 ¥35；醉翁亭单票 ¥40；景区交通车另计
- **开放时间**：7:30–17:30
- **建议时长**：半天
- **交通**：市区公交 / 打车约 20 分钟；南京自驾约 1 小时
- **贴士**：① 必到醉翁亭与琅琊寺；② 春来山花、秋来红叶最美；③ 联票比单买划算

## 🏯 明中都遗址

### 明中都皇故城 · 明皇陵（凤阳）
- **位置**：凤阳县（滁州西北约 1.5 小时）
- **特色看点**：朱元璋在家乡营建的中都皇城遗址，规模宏大的明初都城规制，城墙、午门、石刻保存；明皇陵为朱元璋父母陵寝，神道石像生精美
- **门票参考价**：遗址公园 / 明皇陵多为低价或免费（以官方公示为准，常 ¥10–30 区间）
- **开放时间**：8:00–17:30
- **建议时长**：2–3 小时
- **交通**：凤阳县城公交 / 自驾
- **贴士**：与"小岗村"（大包干发源地，红色研学）同处凤阳片区，可串成一日

### 吴敬梓纪念馆（全椒）
- **位置**：全椒县（滁州西南）
- **特色看点**：《儒林外史》作者吴敬梓故里，纪念馆展陈其生平与著作版本，园林雅致
- **门票参考价**：免费（以官方公示为准）
- **开放时间**：8:30–17:00；周一闭馆
- **建议时长**：1–1.5 小时
- **交通**：全椒站转公交 / 自驾
- **贴士**：文学爱好者必访；与滁州城区可组合

### 滁州市博物馆
- **位置**：南谯区（政务新区）
- **特色看点**：藏历代滁州文物、明中都城砖、滁州民俗，建立城市认知的好起点
- **门票参考价**：免费，需预约
- **开放时间**：9:00–17:00；周一闭馆
- **建议时长**：1.5 小时
- **交通**：公交 / 打车
- **贴士**：行程首日安排，了解"亭城"文脉
