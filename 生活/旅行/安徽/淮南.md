# 淮南（市）

> "中州咽喉、江南屏障"，中国能源之都，豆腐的发源地。八公山下一盘豆腐、一城楚汉风云，寿县古城静卧淮水。

## 城市速览

- **别称 / 区位**：煤城、能源之都；安徽中北部、淮河中游，八公山麓
- **最佳季节**：春（3–5 月）八公山新绿、豆腐文化节；秋（9–11 月）最舒适；夏偏热，冬有煤城暖意
- **交通概况**：高铁淮南南站 / 淮南东站（商合杭、合蚌）；淮河水运；自驾经 G3 / G36
- **必吃**：淮南牛肉汤、八公山豆腐（豆腐宴）、寿县大救驾、上窑馓子、潘集酥瓜

## ⛰️ 名山与古城

### 八公山风景区
- **位置**：八公山区丁山路（淮南市区西北）
- **特色看点**："风声鹤唳、草木皆兵"淝水之战古战场，淮南王刘安在此炼丹、发明豆腐；有汉淮南王宫、白塔寺、忘情谷、石林与地质公园景观
- **门票参考价**：成人 ¥40；儿童 / 老人优待 ¥20
- **开放时间**：8:00–17:30
- **建议时长**：2–3 小时
- **交通**：市区公交 / 打车约 30 分钟
- **贴士**：① 必尝八公山豆腐宴；② 与寿县古城可同日游；③ 春季山花、秋季红叶皆宜

### 寿县古城
- **位置**：淮南市寿县（八公山西南，淮河南岸）
- **特色看点**：国家级历史文化名城，保存完好的宋代砖石城墙（全国七大古城墙之一），宾阳门、通淝门、报恩禅寺、孔庙、清真寺；楚文化深厚
- **门票参考价**：古城街区免费（24 小时）；南门城楼 ¥5、东门城楼 ¥10；内部小景点另计
- **开放时间**：古城全天；城楼约 8:00–17:30
- **建议时长**：半天
- **交通**：淮南市区自驾 / 公交约 40 分钟
- **贴士**：① 登城墙看护城河环绕格局；② 报恩禅寺有 1300 年古银杏；③ 与八公山、安徽楚文化博物馆组合

### 安徽楚文化博物馆（寿县）
- **位置**：寿县明珠大道与宾阳大道交口
- **特色看点**：国家一级博物馆，侧重楚文化体系文物（青铜、漆木器、楚金币"郢爰"），建筑即楚风礼器造型
- **门票参考价**：免费，需预约
- **开放时间**：9:00–17:00（16:30 停止）；周一闭馆
- **建议时长**：2–3 小时
- **交通**：寿县县城内
- **贴士**：来寿县必访，建立楚文化认知；与古城步行可达

### 茅仙洞
- **位置**：凤台县（寿县西侧，淮河畔）
- **特色看点**：佛道两教圣地，三面环水，洞窟幽深，历史悠久
- **门票参考价**：低价 / 免费（以官方公示为准，约 ¥10–20）
- **开放时间**：8:30–17:00
- **建议时长**：1.5 小时
- **交通**：凤台方向自驾 / 公交
- **贴士**：淮畔清幽，可与寿县线组合

### 焦岗湖影视城
- **位置**：凤台县（焦岗湖畔）
- **特色看点**：复建的新中国初期街景（知青、文革场景），影视拍摄基地，怀旧打卡
- **门票参考价**：约 ¥58–128（套票）
- **开放时间**：8:30–17:30
- **建议时长**：2 小时
- **交通**：自驾 / 公交
- **贴士**：拍照怀旧向；夏季湖景 + 荷花
