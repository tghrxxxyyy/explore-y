# 芜湖（市）

> 长江之畔的"江城"，安徽经济重镇与主题乐园之都。方特欢乐世界、鸠兹古镇、半城山半城水的城市格局，宜游宜住。

## 城市速览

- **别称 / 区位**：江城、鸠兹；安徽东南部、长江南岸，青弋江入江口
- **最佳季节**：春（3–5 月）与秋（9–11 月）最舒适；夏季可玩水上乐园；梅雨期注意防潮
- **交通概况**：芜宣机场（宣城共建）；高铁芜湖站 / 芜湖北站（商合杭、宁安、合杭）；长江航运与轻轨（单轨）已通
- **必吃**：芜湖虾籽面、耿福兴蟹黄汤包、渣肉蒸饭、红皮鸭子、无为板鸭、芜湖小笼包

## 🎡 主题乐园

### 芜湖方特旅游区
- **位置**：鸠江区银湖北路（方特梦幻王国 / 东方神画 / 水上乐园等多个园区）
- **特色看点**：华强方特旗下大型主题乐园集群。梦幻王国（科幻 + 动漫）、东方神画（中华神话 + 4D 演艺）、水上乐园（夏季戏水）；"神画"的《孟姜女》《圆明园》演艺口碑极佳
- **门票参考价**：梦幻王国成人 ¥239（中高考生 ¥140、大学生 ¥180、儿童 ¥120、老人 ¥210、夜场 ¥129.9）；东方神画成人 ¥239–280；水上乐园 ¥129.9；两日两园联票 ¥399–430
- **开放时间**：平日 9:30–17:30，暑期 / 节假日延长；水上乐园夏季白天 + 夜场
- **建议时长**：每园 1 天
- **交通**：市区公交 / 打车直达；轻轨可达
- **贴士**：① 周末人多，热门项目先抢预约；② 带防晒与补水；③ 两日票分摊更划算；④ 身高 / 年龄优惠政策以官方为准

### 鸠兹古镇
- **位置**：鸠江区（方特旁，新华联文旅小镇）
- **特色看点**：徽派建筑风格的沉浸式古镇，演艺、非遗、民宿、夜景灯光，适合拍照与亲子
- **门票参考价**：街区免费入园；部分演艺 / 体验项目另计
- **开放时间**：街区 10:00–21:00（夜景更美）
- **建议时长**：2–3 小时
- **交通**：与方特相邻，公交 / 打车
- **贴士**：可与方特同日安排，晚上逛古镇看灯

## 🌳 城市山水

### 赭山公园 · 镜湖公园
- **位置**：镜湖区（市中心）
- **特色看点**：赭山为城市绿肺，有赭塔、动物园、眺江亭；镜湖为城中湖，"镜湖细柳"为芜湖古八景，环湖步道休闲
- **门票参考价**：免费（动物园等小景点另计）
- **开放时间**：6:00–22:00
- **建议时长**：1.5–2 小时
- **交通**：市中心，公交 / 轻轨可达
- **贴士**：清晨本地人晨练；镜湖边耿福兴老字号可吃早茶

### 雕塑公园 · 神山公园
- **位置**：鸠江区神山路
- **特色看点**：露天雕塑艺术公园，作品散布于山林草地，四季花海（春季樱花、秋季粉黛）出片
- **门票参考价**：免费
- **开放时间**：全天
- **建议时长**：1.5–2 小时
- **交通**：公交 / 打车
- **贴士**：春樱、秋粉黛是网红打卡期

### 马仁奇峰
- **位置**：繁昌区（芜湖西南约 1 小时）
- **特色看点**：森林奇峰、玻璃栈道、高空滑索、楠木林；有"天下第一福鼎"与红色文化（新四军）
- **门票参考价**：约 ¥80（含部分项目，玻璃桥 / 滑道另计）
- **开放时间**：8:00–17:00
- **建议时长**：半天
- **交通**：自驾或市区转繁昌班车
- **贴士**：玻璃栈道胆量挑战；夏季森林清凉

### 芜湖市博物馆
- **位置**：鸠江区（政务新区）
- **特色看点**：藏有芜湖铁画、繁昌窑青白瓷、渡江战役文物，通览江城历史
- **门票参考价**：免费，需预约
- **开放时间**：9:00–17:00（16:30 停止）；周一闭馆
- **建议时长**：1.5–2 小时
- **交通**：公交 / 打车
- **贴士**：与雕塑公园相邻，可一并游览
