# 铜陵（市）

> "中国古铜都"，长江之滨的工业名城。天井湖波光、大通千年古埠、永泉小镇徽韵，铜文化与江南水乡交织。

## 城市速览

- **别称 / 区位**：铜都；安徽中南部、长江南岸，皖江城市带
- **最佳季节**：春（3–5 月）凤凰山凤丹花开；秋（9–11 月）天井湖、大通江风宜人；夏可玩水，冬偏冷
- **交通概况**：高铁铜陵站 / 铜陵北站（宁安、京福）；长江黄金水道；自驾经 G50 / G3
- **必吃**：铜陵大肠面、顺安酥糖、大通茶干、太平街烧饼、江鲜（刀鱼 / 鲥鱼时令）、凤凰山土菜

## 🌊 湖与古埠

### 天井湖公园
- **位置**：铜官区长江西路（市中心）
- **特色看点**：城中湖，湖中有"天井"奇观（通江泉眼），堤桥分隔南北湖，垂柳环湖，夜景灯光秀；园内天井湖游乐园有摩天轮等设施
- **门票参考价**：公园免费（24 小时）；游乐园单项约 ¥20/项
- **开放时间**：全天（游乐园约 9:00–21:00）
- **建议时长**：1.5–2 小时
- **交通**：市区步行 / 公交 / 打车
- **贴士**：环湖慢走、看喷泉灯光最舒服；与铜文化园相邻

### 大通古镇
- **位置**：郊区大通镇（长江南岸，铜陵西南约 20 分钟）
- **特色看点**：长江千年古埠、中国历史文化名镇，澜溪老街、大士阁、天主堂钟楼、和悦洲（江中绿洲）；"大通—和悦"曾是长江重要商埠
- **门票参考价**：古镇免费
- **开放时间**：全天（老街商铺约 9:00–18:00）
- **建议时长**：2–3 小时
- **交通**：市区公交 / 自驾至大通镇
- **贴士**：和悦洲需摆渡，田园风光静谧；可与天井湖、永泉组合

### 犁桥水镇
- **位置**：义安区（铜陵北郊）
- **特色看点**：新建的江南水乡式文旅小镇，白墙黛瓦、水系园林、夜景灯光，适合拍照休闲
- **门票参考价**：政府主办景区常态免费（以官方公示为准；部分活动 / 演绎另计）
- **开放时间**：全天（夜景至 21:00）
- **建议时长**：2 小时
- **交通**：市区自驾 / 公交
- **贴士**：晚上灯光倒映水面最出片

## 🏞️ 山水休闲

### 永泉小镇（永泉农庄）
- **位置**：义安区叶山林场（沿江高速铜陵东出口旁）
- **特色看点**：徽派园林式的度假小镇，"忆江南 12 景"、山水园林、温泉、特色餐饮；可穿汉服、用"铜钱"在街区消费，沉浸感强
- **门票参考价**：小镇门票 ¥65；上山云梯 ¥55、下山玻璃滑道 ¥45、门票 + 云梯 + 滑道 ¥168；自助餐 ¥65、柴锅饭套票 ¥99
- **开放时间**：8:00–22:00
- **建议时长**：半天–1 天
- **交通**：自驾（铜陵东出口旁）最便；市区打车约 30 分钟
- **贴士**：① 园区大，穿舒适鞋；② 带娃 / 老人可坐云梯省体力；③ 春夏草木最盛

### 凤凰山
- **位置**：义安区凤凰镇（铜陵东南）
- **特色看点**：以"凤丹"（药用牡丹）闻名，4 月牡丹花海漫山；有金牛洞古采矿遗址（铜文化）、相思树等
- **门票参考价**：免费（金牛洞等小景点另计）
- **开放时间**：全天（花季 4 月最佳）
- **建议时长**：2–3 小时
- **交通**：自驾 / 公交至凤凰镇
- **贴士**：4 月中下旬牡丹节最热闹；与铜文化研学结合

### 铜陵市博物馆
- **位置**：铜官区（政务新区）
- **特色看点**：以"铜文化"为主题，展陈青铜冶铸史、本土历史，铜雕艺术品丰富
- **门票参考价**：免费，需预约
- **开放时间**：9:00–17:00；周一闭馆
- **建议时长**：1.5 小时
- **交通**：公交 / 打车
- **贴士**：来铜都必先看铜文化，建议行程首日

## 三、交通指南

### 一、高铁

- **铜陵站/铜陵北站**：宁安/京福高铁
- 至合肥约1小时、至南京约1.5小时

### 二、市内交通

- 公交覆盖市区至天井湖、大通
- 自驾最便捷

### 三、自驾

- G50沪渝高速、G3京台高速经过

> 来源：铜陵市交通运输局

## 七、2 日行程规划

### Day 1：铜都文化日

- 上午：铜陵市博物馆（1.5h）
- 中午：大肠面+酥糖
- 下午：天井湖公园（1.5h） → 犁桥水镇
- 晚上：犁桥水镇夜景

### Day 2：古埠休闲日

- 上午：大通古镇（2h） → 和悦洲
- 中午：江鲜午餐
- 下午：永泉小镇（半天） → 汉服体验
- 晚上：返程
