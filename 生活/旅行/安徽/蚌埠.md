# 蚌埠（市）

> "淮河明珠"，中国南北地理分界线穿城而过。龙子湖两山夹一湖，花鼓灯嘉年华热闹，双墩遗址诉说史前文明。

## 城市速览

- **别称 / 区位**：珠城；安徽北部、淮河中游，南北分界线上
- **最佳季节**：春（4–5 月）龙子湖畔花海；秋（9–11 月）最舒适；夏可玩水乐园，冬偏冷
- **交通概况**：高铁蚌埠南站（京沪高铁）；淮河航运；自驾经 G3 / G36
- **必吃**：蚌埠烧饼夹里脊、雪圆、蚂虾（小龙虾）、湖沟烧饼、怀远石榴、五河螃蟹

## 🌊 湖与公园

### 龙子湖风景区
- **位置**：龙子湖区东海大道与环湖西路交口
- **特色看点**："两山夹一湖"的城市湖泊，湖东公园、中国南北分界标志（红蓝球体地标）、栖岩寺、湖上升明月（古民居迁建文化园）点缀
- **门票参考价**：免费（8:00 开园）；湖上升明月等小景点另计
- **开放时间**：8:00–22:00（湖区全天可达）
- **建议时长**：2–3 小时
- **交通**：市区公交 / 打车
- **贴士**：① 必打卡"中国南北分界标志"地标；② 环湖骑行 / 散步最舒服；③ 日落湖景出片

### 张公山公园
- **位置**：禹会区张公山路 132 号
- **特色看点**：山水相映的城市公园，湖心岛、望淮塔可登临俯瞰全市，动物园受亲子家庭喜爱
- **门票参考价**：免费（动物园另计）
- **开放时间**：6:00–22:00
- **建议时长**：1.5–2 小时
- **交通**：市区公交 / 打车
- **贴士**：本地人晨练地；登塔看城市全景

### 蚌埠市博物馆
- **位置**：蚌山区龙腾路与行湖路交口（市政府对面）
- **特色看点**：皖北文化地标，藏双墩遗址出土陶塑人头像、元青花等，通览淮河文明
- **门票参考价**：免费，需预约
- **开放时间**：9:00–17:00
- **建议时长**：1.5–2 小时
- **交通**：市区公交 / 打车
- **贴士**：双墩刻划符号是"文字起源"重要物证，必看

## 🎡 亲子游乐

### 花鼓灯嘉年华（蚌埠嘉年华）
- **位置**：蚌山区燕山路 768 号
- **特色看点**：以国家级非遗"花鼓灯"为主题的游乐园，过山车、摩天轮等现代游艺 + 海贝海洋乐园，亲子首选
- **门票参考价**：水乐园成人 ¥69、儿童 ¥49；蚌埠海贝海洋乐园 ¥75；日场 11:00–21:00（部分项目另计）
- **开放时间**：日场 11:00–21:00
- **建议时长**：半天
- **交通**：市区公交 / 打车
- **贴士**：夏季水乐园最热闹；带娃可买套票

### 热浪岛室内水公园
- **位置**：蚌山区黄山大道 5599 号
- **特色看点**：室内恒温水上乐园，全年可玩，夏季戏水、冬季童玩
- **门票参考价**：全天票约 ¥75–85（成人）、儿童 ¥48、夜场 ¥50
- **开放时间**：以官方当日公示为准（通常 10:00–21:00）
- **建议时长**：半天
- **交通**：市区打车 / 自驾
- **贴士**：室内恒温，冬季也能玩

## 七、2 日行程规划

### Day 1：湖城+博物馆日

- 上午：龙子湖风景区（2h） → 南北分界标志
- 中午：烧饼夹里脊+雪圆
- 下午：蚌埠市博物馆（1.5h） → 张公山公园（1.5h）
- 晚上：夜市小吃

### Day 2：亲子游乐日

- 上午：花鼓灯嘉年华（半天）
- 中午：园内午餐
- 下午：热浪岛水公园（半天）
- 晚上：怀远石榴采购 → 返程

> *蚌埠各景区票价与开放时间以官方公示为准（数据参考 2026-07）。龙子湖、张公山、博物馆均免费。*
