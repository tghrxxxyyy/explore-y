# 宣城（市）

> "文房四宝之乡"，诗意山水之城。李白"相看两不厌，只有敬亭山"，桃花潭畔汪伦情深，徽杭古道徽商走出山门。

## 城市速览

- **别称 / 区位**：宣州、宛陵；安徽东南、苏浙皖交界，皖南山区与平原过渡
- **最佳季节**：春（3–5 月）敬亭山茶园新绿、查济 / 桃花潭烟雨；秋（9–11 月）徽杭古道徒步、红叶；夏可戏水（月亮湾、水墨汀溪）
- **交通概况**：高铁宣城站（商合杭）；宣绩高铁已通；自驾经 G50 / S05
- **必吃**：宣城麻辣粉丝、水阳鸭脚包、水阳干子、绩溪胡适一品锅、泾县发糕、琴鱼干、敬亭绿雪（茶）

## ⛰️ 诗山与古村

### 敬亭山
- **位置**：宣州区昭亭北路（市区北）
- **特色看点**：李白"相看两不厌，只有敬亭山"的吟咏地，竹林茶园、独坐亭、广教寺双塔；山不高、爬着不累，山顶俯瞰宣城
- **门票参考价**：成人 ¥30；双人 ¥59
- **开放时间**：8:00–17:30
- **建议时长**：2–3 小时
- **交通**：市区打车 / 公交至东大门
- **贴士**：① 山顶落日极佳；② 山脚有宣笔、宣纸体验（付费）；③ 与市区宛陵湖可组合

### 桃花潭
- **位置**：泾县桃花潭镇（宣城西南约 1.5 小时）
- **特色看点**：李白《赠汪伦》"桃花潭水深千尺"之地，青弋江上的诗意潭水，汪伦墓、踏歌岸阁、彩虹堤坝，晨雾泛舟如入仙境
- **门票参考价**：门票约 ¥62–65；含客船 + 往返景交约 ¥72–75；优待（儿童 / 老人）¥32
- **开放时间**：7:30–17:30
- **建议时长**：半天
- **交通**：泾县转 K603 公交 / 自驾
- **贴士**：① 清晨雾景必看，乘乌篷船最应景；② 与查济相邻，可同日游

### 查济
- **位置**：泾县桃花潭镇查济村（宣城西南）
- **特色看点**：现存规模最大的明清古村落之一，"查济画画"写生圣地；二甲祠、德公厅屋砖雕、岑溪穿村、拱桥流水，免费区域很大
- **门票参考价**：¥65（8:00 开园；村域免费区域可漫步，核心祠堂景点需票）
- **开放时间**：8:00–17:30
- **建议时长**：半天
- **交通**：泾县方向公交 / 自驾
- **贴士**：① 写生爱好者扎堆，建议住村中老宅民宿；② 与桃花潭接驳车相连

### 绩溪龙川
- **位置**：绩溪县瀛洲镇（宣城东南约 1 小时）
- **特色看点**：胡姓聚族而居的千年徽村，胡氏宗祠（"江南第一祠"，木雕极精）、奕世尚书坊、水街；胡锦涛故里所在
- **门票参考价**：成人 ¥75；学生 / 老人 ¥37.5
- **开放时间**：7:40–17:20
- **建议时长**：2–3 小时
- **交通**：绩溪县城转公交 / 自驾
- **贴士**：① 胡氏宗祠木雕必看；② 与徽杭古道同处绩溪，可组合一日

## 🥾 古道与亲水

### 徽杭古道
- **位置**：绩溪县伏岭镇（徽浙交界）
- **特色看点**：中国十大徒步线路之一，徽商走出山门的通道；经江南第一关、黄茅培、下雪堂至蓝天凹，古关、古桥、古茶亭连绵，春秋繁花
- **门票参考价**：成人 ¥58；亲子 1 大 1 小 ¥88、双人 ¥115
- **开放时间**：8:00–16:30（部分路段全天可走）
- **建议时长**：徒步 1 天（单程约半天，可原路或穿越至杭州临安）
- **交通**：绩溪汽车站乘中巴至鱼川村 / 浙基田入口
- **贴士**：① 初级难度，备登山鞋与饮水；② 蓝天凹可扎营；③ 春秋最佳，夏季防暑

### 中国宣纸文化园
- **位置**：泾县榔桥镇（宣城西南）
- **特色看点**："纸寿千年"的宣纸发源地，展示捞纸、晒纸、剪纸全流程，可体验亲手制作宣纸
- **门票参考价**：约 ¥58–60
- **开放时间**：7:40–17:00
- **建议时长**：1.5–2 小时
- **交通**：泾县方向自驾 / 公交
- **贴士**：文房四宝爱好者必访；与桃花潭、查济同处泾县片区

### 水墨汀溪 · 月亮湾 · 鄣山大峡谷
- **位置**：泾县（宣城西南）
- **特色看点**：水墨汀溪为原始森林探幽地；月亮湾是青弋江畔竹海漂流、戏水胜地（免费）；鄣山大峡谷瀑布奇石，夏季清凉
- **门票参考价**：水墨汀溪约 ¥50；鄣山大峡谷约 ¥52–54；月亮湾免费
- **开放时间**：8:00–17:00
- **建议时长**：各 2–3 小时
- **交通**：泾县方向自驾为主
- **贴士**：夏季亲水首选；与桃花潭片区组合两日游

### 中国扬子鳄景区
- **位置**：宣州区（市区周边）
- **特色看点**：国家级扬子鳄繁育研究基地，近距离观察"活化石"扬子鳄，亲子科普
- **门票参考价**：约 ¥30（优待 ¥25）
- **开放时间**：8:00–17:00
- **建议时长**：1.5 小时
- **交通**：市区自驾 / 公交
- **贴士**：夏季鳄鱼活跃、观感最佳；亲子家庭推荐
