# 池州（市）

> "千载诗人地"，皖南佛教圣地。九华山为地藏菩萨道场，中国佛教四大名山之一；秋浦河、平天湖、杏花村诗意流淌。

## 城市速览

- **别称 / 区位**：秋浦；安徽南部、长江南岸，皖南山区与沿江平原过渡带
- **最佳季节**：春（4–5 月）杏花村踏青、秋浦河漂流；夏（6–8 月）九华 / 牯牛降避暑；秋（9–11 月）登高礼佛、看红叶
- **交通概况**：高铁池州站（宁安城际 + 池黄高铁）通达；九华山机场（军民合用）；沿江高速 G50 经过
- **必吃**：九华素斋、石台富硒土菜、秋浦花鳜、池州小粑、东至麦鱼

## 🛕 佛教名山

### 九华山
- **位置**：青阳县九华镇（池州市西北约 30 公里）
- **特色看点**：中国佛教四大名山之一、地藏菩萨道场。核心景区：化城寺（开山祖寺）、肉身宝殿（地藏肉身塔）、百岁宫（天然睡佛、明代无瑕肉身）、天台峰（最高峰，天台寺）、花台（高山杜鹃与怪石）。朝圣 + 自然观景兼具
- **门票参考价**：旺季（1.16–11.14）¥160；淡季（11.15–1.15）¥140。景区交通车 ¥50（3 日内有效）。索道：百岁宫缆车单程 ¥85 / 往返 ¥100；天台索道单程 ¥85 / 往返 ¥160；花台索道单程 ¥55 / 往返 ¥110
- **开放时间**：6:30–21:30（旺季延长）；索道约 7:00–17:00
- **建议时长**：1–2 天
- **交通**：池州站乘景区巴士（约 1 小时）或自驾至柯村游客中心换乘
- **贴士**：① 肉身宝殿、百岁宫为必到；② 天台需乘索道 + 爬一段；③ 花台索道看高山风光，体力好可徒步；④ 遵守佛教礼仪，着素净衣物

### 大愿文化园
- **位置**：九华山东麓柯村（景区北大门）
- **特色看点**：以 99 米地藏菩萨露天铜像为核心的佛教文化园，宏像庄严，夜景灯光秀
- **门票参考价**：免费开放（部分演绎项目另计）
- **开放时间**：8:00–17:00（夜景至 21:00 左右）
- **建议时长**：1–2 小时
- **交通**：九华山柯村游客中心旁
- **贴士**：可与九华山主景区同游，作为朝圣起点

## 🌿 湖村与生态

### 平天湖
- **位置**：池州市贵池区城区
- **特色看点**：城市绿心，"水如一匹练"的天然湖泊，有莲花台、平天湖湿地公园，可骑行、观鸟、看落日
- **门票参考价**：免费
- **开放时间**：全天（景点设施 8:00–17:30）
- **建议时长**：1–2 小时
- **交通**：市区打车 / 公交可达
- **贴士**：环湖绿道适合骑行；与杏花村可串成市区半日

### 杏花村
- **位置**：池州市城西
- **特色看点**：因杜牧"牧童遥指杏花村"闻名，复建的村落有酒坊、古井、诗文化园，春季杏花如雪
- **门票参考价**：街区免费；部分文化园 / 体验项目另计
- **开放时间**：8:00–17:30
- **建议时长**：1–2 小时
- **交通**：市区公交可达
- **贴士**：可尝杏花村酒、本地米酒；春来杏花最应景

### 石台牯牛降
- **位置**：石台县大演乡（池州西南，距市区约 2 小时）
- **特色看点**："皖南小九寨"，原始森林、峡谷溪流、龙门潭碧水，负氧离子极高，避暑与亲水胜地
- **门票参考价**：门票 + 园内接驳车约 ¥100–110；儿童 / 学生约 ¥65
- **开放时间**：7:30–17:00
- **建议时长**：半天–1 天
- **交通**：自驾或石台县城转景区专线
- **贴士**：夏季玩水、溯溪最佳；与仙寓山富硒村可组合
