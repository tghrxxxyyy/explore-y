# 安徽（省）

![安徽代表风光](/images/安徽.png)

> 江淮大地，徽文化发祥地。黄山奇绝、九华佛国、皖南古村水墨如画，江淮之间科教新兴、淮北平原面食飘香——一省兼容"徽风皖韵"与"钢铁江淮"两种气质。

**省会：** 合肥　**特点：** 皖南徽派山水 + 皖江名城 + 皖北平原，南北差异鲜明，徽菜为中国八大菜系之一

## 🗓️ 最佳旅游季节

- **秋季最佳（9–11 月）**：天高云淡，登黄山、赏宏村秋色与晒秋、看九华红叶，体感最舒适
- **春季（3–5 月）**：黄山杜鹃、皖南油菜花（呈坎 / 婺源外围）、敬亭山茶园新绿，踏青正当时
- **夏季避暑（6–8 月）**：黄山 / 九华 / 天柱山 / 大别山（天堂寨、牯牛降）均清凉，是天然空调
- **冬季限定（12–2 月）**：黄山冬雪云海绝美且为淡季票价（¥150）；九华、徽村雪景静谧；泡半汤 / 汤王温泉
- **避坑**：梅雨季（6–7 月）皖南多雨路滑，山区注意安全；暑期（7–8 月）黄山山顶住宿紧张需提前订

## 🚆 交通概况

- **航空**：合肥新桥国际机场（全省枢纽）、黄山屯溪、安庆天柱山、芜宣等支线机场；省内多市可经南京 / 杭州禄口中转
- **高铁**：合肥为米字枢纽（合福、合宁、合武、商合杭、合安九）；京沪高铁过蚌埠南；宁安城际串起马鞍山 / 芜湖 / 铜陵 / 池州 / 安庆；杭黄高铁连通黄山—杭州；昌景黄高铁已通；16 市全部通动车
- **市内 / 县域**：黄山、九华等山岳景区需换乘景区大巴 / 索道；徽州古村多需汽车或旅游专线接驳；皖北平原城市公交 + 打车便利
