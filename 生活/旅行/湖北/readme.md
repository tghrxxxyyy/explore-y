# 湖北（省）

![湖北代表风光](/images/湖北.png)

> 千湖之省，荆楚文化的发源地。长江与汉江在此交汇，三峡雄峙、武当道教名山、黄鹤楼俯瞰江城，神农架藏着原始森林与野人传说——一文一武、一江一山，是湖北最厚重的名片。

**省会：** 武汉　**特点：** 九省通衢、高铁枢纽；荆楚文化与三国文化交汇；山水（长江 / 汉江 / 千湖）与武当道教、三峡工程、神农架生态兼具；热干面、小龙虾、排骨藕汤香飘全国

## 🍜 美食地图（按片区）

- **武汉片区（武汉）**：热干面（蔡林记等）、豆皮、面窝、糊汤粉、排骨藕汤、武昌鱼、鸭脖（周黑鸭 / 精武）、油饼包烧麦、鲜鱼糊汤粉、重油烧麦。户部巷、吉庆街、粮道街是宵夜集中地
- **鄂西片区（十堰 / 宜昌 / 襄阳 / 恩施 / 神农架）**：襄阳牛肉面、宜城大虾、宜昌凉虾、萝卜饺子、红油小面；恩施合渣（张关合渣）、土家腊肉、炕土豆、油茶汤、柏杨豆干；十堰郧阳三合汤、竹溪蒸盆、丹江口翘嘴鲌、武当斋菜；神农架腊肉、懒豆腐、摔碗酒。恩施女儿城、宜昌 CBD、十堰六堰美食街是集聚区
- **江汉平原片区（荆州 / 荆门 / 孝感 / 黄冈 / 咸宁 / 仙桃 / 潜江 / 天门 / 鄂州）**：荆州鱼糕、公安锅盔、洪湖莲藕；潜江油焖小龙虾、焌米茶、二回头；仙桃沔阳三蒸、毛嘴卤鸡；天门蒸菜、黄潭米粉、米茶；孝感米酒、麻糖、云梦鱼面；黄陂三鲜、黄冈东坡肉、英山茶叶；咸宁贺胜桥鸡汤、通山包坨；鄂州梁子湖大闸蟹。潜江龙虾城、荆州大赛巷、孝感文化路是必访食街

## 🗓️ 最佳旅游季节

- **春季（3–5 月）**：武汉樱花（武大 / 东湖磨山，3 月中下旬盛花期）、荆州荆楚文化节、宜昌油菜花、黄冈杜鹃（龟峰山万亩古杜鹃 4–5 月）、神农架高山杜鹃；气候宜人，适合城市与山水游
- **夏季（6–8 月）**：鄂西避暑正当时——神农架（20℃左右）、恩施大峡谷/利川腾龙洞（洞内 14–18℃）、九宫山、大洪山、武当山均是避暑胜地；长江三峡游船旺季；武汉"火炉"可安排夜游江城、东湖绿道
- **秋季（9–11 月）**：最舒适季节，武当山红叶、神农架层林尽染、荆门莫愁村丰收、咸宁桂花（"香城"）、潜江/仙桃湖鲜肥美；国庆后游客明显回落
- **冬季（12–2 月）**：神农架国际滑雪场、武当山雪景银装；温泉季（咸宁、孝感汤池、随州西游记公园女儿国温泉）；武汉园博园/东湖梅花（2 月），新年庙会氛围浓

## 🚄 交通概况

- **航空**：武汉天河国际机场（全省最大枢纽，通达全国及国际）、宜昌三峡机场、襄阳刘集机场、恩施许家坪机场、十堰武当山机场、荆州沙市机场等，多数地级市通航
- **高铁/动车**：武汉"九省通衢"高铁枢纽——京广（北京—武汉—广州）、沪汉蓉（上海—武汉—成都）、汉十（武汉—十堰—西安，西十高铁已通）、郑渝（郑州—襄阳—重庆）等，武汉至省内各市基本 2 小时内直达；宜昌、襄阳为区域性高铁节点
- **城际/普铁**：武石、武冈、武咸、武孝等城际铁路连通武汉城市圈；汉宜铁路串起武汉—荆州—宜昌
- **公路**：高速路网密集（沪蓉、沪渝、福银、二广等），自驾串联武当山、神农架、恩施喀斯特景区十分便利；武汉城市圈环线完善
- **城市内**：武汉地铁成网（多条线路+空轨）；宜昌、襄阳等公交+旅游专线接驳景区间；恩施、神农架山区建议包车/景区直通车
