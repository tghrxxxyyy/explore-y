# 新疆（维吾尔自治区）

![新疆](/images/新疆.png)

> 三山夹两盆，丝路贯千年。从阿尔泰的雪林到帕米尔的冰峰，从吐鲁番的火洲到伊犁的草原，新疆用最辽阔的尺度收藏了雪山、沙漠、湖泊、胡杨与多民族的歌声。这里是瓜果与歌舞的故乡，也是一生必去一次的远方。

**首府：** 乌鲁木齐　**特点：** 中国陆地面积最大的省级行政区（约 166 万平方公里）；"三山夹两盆"地貌（阿尔泰山、天山、昆仑山夹准噶尔盆地、塔里木盆地）；古丝绸之路枢纽；维吾尔、哈萨克、柯尔克孜、蒙古等 13 个世居民族共居；日照强、昼夜温差大，瓜果特别甜。

## 🍜 美食地图（按片区）

- **北疆（乌鲁木齐 / 昌吉 / 克拉玛依 / 博州 / 塔城 / 阿勒泰）**：大盘鸡（柴窝堡辣子鸡为乌鲁木齐招牌）、烤肉（羊肉串）、拌面（拉条子）、抓饭、馕、奶茶、酸奶；阿勒泰产冷水鱼（狗鱼、五道黑）与瓜子仁酥糖；塔城有俄罗斯列巴、风干肉、玛洛什冰激凌；克拉玛依凉皮爽口。夜市烤包子、馕坑肉、椒麻鸡是标配。
- **东疆（吐鲁番 / 哈密）**：吐鲁番无核白葡萄、葡萄沟现摘瓜果、哈密瓜、哈密大枣；烤包子、馕坑肉、豆豆面、曲曲（馄饨）、盆盆肉；火焰山下的葡萄干、哈密瓜干是手信首选。
- **伊犁（塞外江南）**：手抓饭、纳仁（哈萨克手抓肉片）、熏马肠、马奶酒（库木孜）、烤羊肉、奶茶、凉皮、玛拉奇冰激凌；霍城薰衣草蜜、伊犁特曲；六星街的俄罗斯风味与手工冰淇淋不可错过。
- **南疆（巴州 / 阿克苏 / 克州 / 喀什 / 和田）**：烤包子、缸子肉、鸽子汤（喀什一绝）、烤全羊、薄皮包子、拉条子、烤鸽子、胡辣羊蹄；巴州博斯腾湖鱼宴（五道黑、池沼公鱼）、尉犁烤全羊（非遗）；阿克苏冰糖心苹果、库车大馕；和田烤蛋、酸奶粽子、玫瑰花酱、大枣、薄皮核桃；喀什石榴、无花果、巴旦木；全疆通用的干果：杏干、无花果干、核桃、巴旦木、红枣。

## 🗓️ 最佳旅游季节

- **春季（4–5 月）**：伊犁杏花沟（新源、吐尔根）粉雪相间，帕米尔杏花村（塔县）惊艳；吐鲁番杏花、库尔勒香梨花开；风沙渐起但人流少。
- **夏季（6–8 月）**：全疆黄金季。北疆草原碧绿（那拉提、巴音布鲁克、喀拉峻），赛里木湖野花环湖，独库公路 6 月通车串联天山；吐鲁番葡萄成熟（无核白 7–9 月）；南疆瓜果飘香。昼夜温差大，山区清凉避暑。
- **秋季（9–10 月）**：公认"颜值巅峰"。喀纳斯、禾木层林尽染（9 月中下旬最佳）；塔里木胡杨林金黄（10 月中下旬）；葡萄、哈密瓜、红枣丰收尾期。国庆后游客明显回落。
- **冬季（11–3 月）**：阿勒泰冰雪游（可可托海滑雪、禾木雪乡、喀纳斯水墨秘境）是顶流；赛里木湖蓝冰冰泡、天鹅泉野天鹅；南疆相对温暖，古城年味浓。部分山区景区冬季封闭或半价。

## 🚄 交通概况

- **航空**：乌鲁木齐地窝堡国际机场为全疆最大枢纽，直飞国内主要城市及中亚、西亚多地；喀什、伊宁、阿克苏、库尔勒、克拉玛依、吐鲁番、阿勒泰、喀纳斯、莎车、和田等均有机场，多数地级行政区通航。
- **铁路**：兰新高铁（兰州—西宁—乌鲁木齐）已通车，乌鲁木齐至哈密、吐鲁番、鄯善、柳园方向动车便捷；南疆铁路（乌鲁木齐—吐鲁番—库尔勒—阿克苏—喀什）、北疆铁路（乌鲁木齐—石河子—伊宁）成网；格库铁路（青海格尔木—库尔勒）打通进出疆新通道。
- **公路 / 自驾**：连霍高速（G30）、京新高速（G7）横贯；独库公路（G217，独山子—库车）2026 年 6 月 1 日通车，实行"昼保通行、夜保施工"，每日 8:00–19:00（部分路段弹性至 21:00）限 7 座及以下客车通行，主线免费（盐水沟站点收 ¥20）；伊昭公路、塔莎古道、S101 天山地理画廊等为网红景观道。自驾是深度玩新疆的最优方式，但需提前规划限速与安检。
- **城市内**：乌鲁木齐地铁 1 号线已运营，公交 + 出租车方便；其余城市以公交、出租车、包车为主，景区间多需包车或参加一日游。

> 票价与开放时间以景区官方公示为准（数据参考 2026-07）。60 周岁以上老人、6 周岁（或 1.3 米）以下儿童、现役军人、残疾人等多享免票或半价，出行请带好证件；进入边境县（塔什库尔干、白哈巴等）需提前办理边防证。
