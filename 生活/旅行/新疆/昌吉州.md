# 昌吉州（昌吉回族自治州）

> 天山北坡的回民之乡，天池倒映博格达。从雪山天池到江布拉克的金色麦浪，从北庭故城的唐风到五彩湾的侏罗纪火岩——昌吉把田园与秘境都铺在了天山脚下。

## 🎯 城市速览

- **定位**：新疆中部、天山北麓，环抱乌鲁木齐的回族自治州，首府昌吉市
- **核心看点**：天山天池（阜康）、江布拉克（奇台）、北庭故城（吉木萨尔）、五彩湾/古海温泉、硫磺沟、努尔加大峡谷
- **最佳季节**：6–10 月；江布拉克 7–9 月麦浪与秋色佳；冬季天池雪景、温泉宜人
- **建议游玩**：2–3 天（含天池）

## 🏞️ 景点卡片

### 天山天池

- **位置**：昌吉州阜康市，距乌鲁木齐约 70 公里
- **特色看点**：国家 5A 级高山湖泊，博格达峰雪峰倒映，云杉环拥；定海神针古榆、西王母祖庙、飞龙潭；马牙山索道登顶看全景（详见[乌鲁木齐](乌鲁木齐.md)页交通参考，天池属本州核心景区）
- **门票参考价**：旺季（4.16–10.31）门票 ¥95 + 区间车 ¥60 = **¥155（参考）**；淡季门票 ¥45 + 车 ¥60 = ¥105
- **开放时间**：旺季 8:00–19:00；淡季 9:30–17:00
- **建议时长**：半天–1 天
- **交通**：阜康市区转天池专线；乌鲁木齐直通车约 1.5 小时；自驾导航"天山天池景区"
- **贴士**：早到避人流；山区温差大备薄外套；马牙山索道晴天最佳

### 江布拉克

- **位置**：昌吉州奇台县半截沟镇，距乌鲁木齐约 200 公里
- **特色看点**：国家 5A 级，"圣水之源"之意，雪山、森林、草原与金色麦浪交织；怪坡、万亩旱田、疏勒城遗址；7–9 月麦浪翻滚，秋季白桦金黄
- **门票参考价**：**约 ¥55 起（参考）**
- **开放时间**：约 9:00–19:00
- **建议时长**：半天–1 天
- **交通**：奇台县包车/自驾；乌鲁木齐—奇台高速转景区
- **贴士**：7–8 月绿色麦浪、9 月金黄最出片；自驾景区公路风景连绵

### 北庭故城

- **位置**：昌吉州吉木萨尔县北庭镇
- **特色看点**：唐代北庭大都护府治所，世界文化遗产；保存完整的夯土城垣与西大寺佛教遗址，丝路北道重镇见证
- **门票参考价**：**免费 / 低价（参考，博物馆部分需预约）**
- **开放时间**：约 10:00–18:00（周一闭馆）
- **建议时长**：1.5 小时
- **交通**：吉木萨尔县城包车/公交
- **贴士**：与北庭西大寺遗址博物馆同游；了解唐—回鹘历史

### 五彩湾 / 古海温泉

- **位置**：昌吉州吉木萨尔县北部卡拉麦里山一带
- **特色看点**：侏罗纪煤田燃烧形成的五彩雅丹丘陵，红黄褐绿如调色盘；古海温泉（古地层温泉）可泡汤解乏
- **门票参考价**：五彩湾 **约 ¥30（参考）**；古海温泉另计（套票含住宿更划算）
- **开放时间**：约 9:30–19:30
- **建议时长**：2–3 小时（含温泉）
- **交通**：乌鲁木齐/奇台自驾经 G216 准东方向
- **贴士**：日落拍五彩丘陵最佳；温泉冬季人气高，需提前订房

### 硫磺沟 / 努尔加大峡谷

- **位置**：昌吉市南郊（硫磺沟镇、努尔加水库一带）
- **特色看点**：火烧般的红色峡谷与丹霞，雅丹与峡谷同框；努尔加大峡谷险峻深邃，是摄影与自驾小众线
- **门票参考价**：**免费 / 低价（参考，部分路段未开发）**
- **开放时间**：全天（户外）
- **建议时长**：2 小时
- **交通**：昌吉市自驾南行
- **贴士**：未开发路段需越野车与向导；注意落石与信号弱

## 🍜 昌吉味道

回民风味突出：粉汤、丸子汤、油塔子、黄面、烤肉、拌面、抓饭、馕、九碗三行子（回族宴席）；奇台过油肉拌面、黄面凉皮知名；奶制品与酸奶常见。
