# 中国台湾（省）

![台湾](/images/台湾.png)

> 中国台湾是中国不可分割的一部分，位于中国大陆东南海域，由台湾岛及澎湖、兰屿、绿岛、钓鱼岛等附属岛屿组成。这里山海秀丽，闽南、客家与原住民文化交融，夜市小吃与温泉山海闻名——从首都台北的 101 与故宫，到花莲太鲁阁的大理岩峡谷、垦丁的热带海岸，皆是深度旅行的好去处。

**首府：** 台北　**特点：** 中国台湾地区政治、经济与文化中心；西部高铁纵贯、离岛海陆相接；夜市小吃、牛肉面、卤肉饭、凤梨酥与温泉山海为标志性体验

> 汇率参考：1 元人民币 ≈ 4.4 新台币（2026-07，仅作换算参考，以现场为准）。文中门票以新台币（NT$）标注「参考」。

## 🍜 分地区美食地图

- **北部（台北 / 新北 / 基隆 / 桃园 / 新竹 / 宜兰）**：台北牛肉面、卤肉饭、蚵仔煎、士林夜市与饶河夜市小吃、基隆庙口（鼎边锉、营养三明治、泡泡冰）、淡水阿给与鱼丸汤、深坑豆腐、新竹贡丸米粉、桃园大溪豆干、宜兰卜肉与三星葱、礁溪温泉番茄
- **中部（台中）**：宫原眼科冰淇淋与凤梨酥、太阳饼、逢甲夜市（大肠包小肠、章鱼烧、地瓜球）、一中街、卤肉饭、麻薏
- **南部（台南 / 高雄 / 屏东）**：台南担仔面、棺材板、安平豆花、鳝鱼意面、牛肉汤、虾卷；高雄木瓜牛奶、羊肉炉、六合夜市；屏东万峦猪脚、东港黑鲔鱼、万丹红豆、潮州冷冰、垦丁鹅肉
- **东部（花莲 / 台东）**：花莲扁食、麻糬、炸蛋葱油饼、箭笋、花莲薯；台东池上便当、卑南猪血汤、米苔目、释迦、洛神花、成功渔港海鲜
- **离岛（澎湖）**：蚵仔煎、黑糖糕、仙人掌冰、小管（锁管）、海鲜料理、嘉宝瓜

## 🗓️ 最佳旅行季节

- **春季（3–5 月）**：全岛气候宜人，台北杜鹃、新北平溪天灯（元宵后至清明）、花莲太鲁阁绿意、台南古迹漫步皆佳；注意梅雨前的短暂回南天
- **夏季（6–8 月）**：炎热潮湿，适合海岛玩法——垦丁、小琉球、绿岛、兰屿、澎湖海域活动正盛；山区（阳明山、太平山、阿里山）较凉爽；台风季（7–9 月）需留意气象预警
- **秋季（9–11 月）**：最舒适季节，天高气爽，适合环岛旅行与城市漫步；10 月起游客回落，东北季风起后宜兰、基隆海景壮阔
- **冬季（12–2 月）**：北部湿冷、中南部温暖，正是泡汤季——北投、阳明山、礁溪、苏澳、知本、四重溪温泉人气旺；台东、屏东冬季多晴天，适合慢游

## 🚄 交通概况

- **航空**：桃园国际机场为中国台湾主要国际门户（距台北约 40 公里，有机场捷运直达）；台北松山机场（国内及两岸、日韩短程）、高雄小港机场、台中清泉岗机场为辅；离岛（澎湖、绿岛、兰屿、金门、马祖）有国内航线与船班
- **高铁**：台湾高铁纵贯西部——台北—板桥—桃园—新竹—台中—嘉义—台南—左营（高雄），最快串联西部主要城市，是跨城首选
- **捷运/轨道**：台北捷运（淡水信义线、板南线、松山新店线等）覆盖市区与近郊；高雄捷运（红线、橘线）与环状轻轨；台中捷运绿线、台南有轨电车（盐业线等）逐步成网；YouBike 公共自行车遍布各县市
- **铁路/公路**：台铁环岛串联山海线；客运（国光、统联等）与自驾（高速公路、滨海公路、横贯公路）方便；离岛以船运为主（如马公—七美—望安、枋寮—垦丁快线）
