# 北京（直辖市）

![北京代表风光](/images/北京.png)

> 中华人民共和国首都，政治、文化、国际交往、科技创新中心。三千年建城史、八百年建都史，是世界上世界文化遗产最密集的城市之一——故宫、长城、颐和园、天坛、周口店遗址皆在此间。皇城格局与胡同烟火并存，古典与摩登在此相遇。

**行政中心：** 北京（首都；城市副中心位于通州）　**特点：** 中轴线申遗核心、皇家园林荟萃、胡同四合院文化、京味儿小吃与宫廷菜同源，既是历史教科书也是现代国门

## 🍜 美食地图（按片区）

- **核心城区（东城/西城）**：京味儿源头——北京烤鸭（全聚德挂炉、便宜坊焖炉）、铜锅涮羊肉（东来顺、南门涮肉）、炸酱面（海碗居、方砖厂69号）、卤煮火烧（门框胡同）、炒肝（姚记）、豆汁焦圈驴打滚艾窝窝（护国寺小吃、尹三豆汁）、宫廷点心；牛街一条街是清真美食天堂（聚宝源涮肉、白记年糕、驴打滚、爆肚满）。前门大栅栏、王府井小吃街是老字号聚集地。
- **朝阳**：最国际化的胃——三里屯/工体酒吧与各国料理、望京韩餐（烤肉、部队锅）、簋街麻辣小龙虾（胡大饭馆）、CBD高端餐厅、亮马河国际风情水岸夜经济。
- **海淀**：高校与中关村周边的烟火——京味家常菜、大学食堂对外开放窗口、中关村创业咖啡馆，京西宾馆风格的清淡官府菜。
- **丰台/石景山**：园博园与南宫一带亲子餐饮、首钢园工业风网红餐厅、老丰台炖菜；石景山模式口驼铃古道小吃。
- **昌平**：阳坊涮肉（昌平阳坊镇招牌铜锅）、十三陵周边农家宴、小汤山温泉度假区药膳与农家菜。
- **通州（副中心）**：通州"三宝"——小楼饭店烧鲇鱼、大顺斋糖火烧、万通酱园腐乳；运河岸边的大运河船宴、张家湾设计小镇咖啡馆。
- **门头沟/房山（西山）**：京西农家饭——门头沟黄芩茶、京白梨、爨底下民俗宴、清水豆腐；房山上方山香椿、周口店周边农家院、十渡虹鳟鱼（实为怀柔名产，房山亦多流水鱼宴）。
- **怀柔/密云/延庆（北部山水）**：怀柔虹鳟鱼（生鱼片+烧烤一鱼两吃）、板栗炖肉；密云水库鱼（胖头鱼剁椒/酱炖）、杂粮宴；延庆火勺、柳沟豆腐宴（一锅鲜）、永宁豆腐、八达岭脚下虹鳟与农家炕桌。
- **顺义/大兴/平谷（东部）**：顺义牛栏山二锅头原产地、河东农家；大兴庞各庄西瓜（5–7月）、采育葡萄（9月）、魏善庄月季宴；平谷大桃（7–9月闻名全国）、雕窝村农家饭、北寨红杏。

## 🗓️ 最佳旅游季节

- **春季（3–5 月）**：玉渊潭樱花、元大都城垣海棠、北京植物园桃花、明城墙梅花次第开放；慕田峪长城两侧山花烂漫；平谷桃花节（4 月，大华山—峪口一带万亩桃林）；气候宜人，是逛胡同、游园林的好时节。
- **夏季（6–8 月）**：炎热多雨，建议把主场搬到北部山区与水域——龙庆峡、云蒙山、喇叭沟门原始森林避暑；金海湖、十渡、青龙峡玩水漂流；水立方嬉水乐园、欢乐谷玛雅水世界亲子放电；室内场馆（国博、中国科技馆、首博）是暑期避暑首选。注意：故宫、国博等热门景区暑期预约极难。
- **秋季（9–11 月）**：北京最舒适的季节，也是颜值巅峰——香山红叶（10 月下旬–11 月上旬）、钓鱼台银杏大道、坡峰岭/北宫国家森林公园红叶、八达岭与慕田峪长城秋色苍茫；秋高气爽适合长城登高与胡同漫步，国庆后游客明显回落。
- **冬季（12–2 月）**：银装素裹别有韵味——故宫雪景、颐和园昆明湖冰场、什刹海天然冰场滑冰；龙庆峡冰灯艺术节（1 月中旬–3 月初）；古北水镇、小汤山、南宫泡温泉；春节地坛/龙潭湖庙会年味最浓。

## 🚄 交通概况

- **航空**：首都国际机场（顺义，市区东北）与大兴国际机场（大兴，市区南）双枢纽，均通地铁/机场线/城际；首都机场快轨直抵东直门，大兴机场线接驳草桥并换乘地铁 19 号线，亦可乘京雄城际进西站。
- **高铁/动车**：北京站、北京西站、北京南站、北京北站、清河站、北京朝阳站六大站成网——京沪（南站）、京广（西站）、京张（北站/清河）、京哈（朝阳/星火）高铁通达全国；去八达岭长城可从清河站乘高铁约 20 分钟直达，也可坐市郊铁路 S2 线（"开往春天的列车"）看居庸关花海。
- **地铁**：27 条线路（含首都机场线、大兴机场线）基本成网，覆盖核心区及多数景点；支付宝/北京一卡通/亿通行 APP 扫码即乘，外地车进京需办"进京证"且工作日早晚高峰五环内限行。
- **城市内**：公交发达且多数景区有旅游专线/接驳；核心区胡同最适合骑车或步行；长城、古北水镇等有东直门等发出的正规旅游专线大巴，切勿轻信路边低价一日游。

> ⚠️ 票价与开放时间以景区官方公示为准（数据参考 2026-07）。60 周岁以上老人、6 周岁（或 1.4 米）以下儿童、现役军人、残疾人等多享免票或半价，出行请带好证件。
