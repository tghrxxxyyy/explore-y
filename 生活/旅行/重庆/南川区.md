# 南川区

> 金佛山，"天下第一桌山"，世界自然遗产。云瀑、杜鹃、雪原、佛光四时各异；神龙峡激流、山王坪林海，是重庆主城近郊的避暑与滑雪天堂。

## 🎯 城市速览

- **定位**：渝南生态旅游区，以世界自然遗产金佛山为龙头
- **核心看点**：金佛山、神龙峡、山王坪喀斯特森林公园、天星温泉、黎香湖、永隆山
- **最佳季节**：夏（6–8 月）避暑、冬（12–2 月）滑雪、春（4–5 月）杜鹃花海
- **建议游玩**：1–2 天

## 🏞️ 景点卡片

### 金佛山

- **位置**：南川区南部（三泉镇 / 头渡镇一带）
- **特色看点**：世界自然遗产、国家 AAAAA 级，"天下第一桌山"；原始森林、高山杜鹃（4–5 月）、云海佛光、冬季滑雪；北坡西坡各有索道与栈道
- **门票参考价**：门票约 ¥70–80；北门套票（门票 + 索道往返）约 ¥70–120，西门套票（门票 + 巴士 + 索道）约 ¥180（以官方公示为准）
- **开放时间**：8:00–17:30（冬季滑雪期延长）
- **建议时长**：大半天–1 天
- **交通**：重庆主城自驾约 1.5h / 坐大巴至南川转景区车；导航"金佛山北门 / 西门"
- **贴士**：北门近城区、西门景更野；看云海选晴日清晨；滑雪季提前订套票

### 神龙峡

- **位置**：南川区南平镇（金佛山西侧）
- **特色看点**：峡谷漂流 + 瀑布群，夏季漂流刺激、水质清冽；飞龙瀑布、绝壁栈道，避暑亲水两相宜
- **门票参考价**：门票约 ¥50，漂流套票约 ¥120–160（以官方公示为准）
- **开放时间**：8:00–17:00（漂流季节性开放）
- **建议时长**：半天
- **交通**：南川转景区车 / 自驾导航"神龙峡"
- **贴士**：漂流备防水袋与拖鞋；与金佛山同日安排（上午山、下午峡）

### 山王坪喀斯特森林公园

- **位置**：南川区山王坪镇
- **特色看点**：中国首个喀斯特生态公园，水杉林与喀斯特石林交织；秋季"一半碧绿一半金黄"的奇景刷屏，露营、骑行胜地
- **门票参考价**：约 ¥20–40（官方公示；露营另计）
- **开放时间**：8:00–18:00
- **建议时长**：2–3 小时
- **交通**：南川自驾 / 包车（山路弯多）
- **贴士**：秋天色彩最惊艳；林场露营需预约

### 天星温泉

- **位置**：南川区三泉镇（金佛山北坡下）
- **特色看点**：依金佛山而建的碳酸温泉，山林泡池、冬季雪景温泉，滑雪后解乏绝佳
- **门票参考价**：约 ¥80–150（按池型 / 时段，以官方公示为准）
- **开放时间**：约 10:00–22:00
- **建议时长**：2–3 小时
- **交通**：同金佛山北坡方向
- **贴士**：滑雪日安排温泉最舒服；夜泡配星空

### 黎香湖

- **位置**：南川区黎香湖镇
- **特色看点**：高山湿地湖泊，湖光潋滟、民宿成群，可皮划艇、环湖骑行、亲子露营，慢生活休闲地
- **门票参考价**：免费 / 水上项目另计
- **开放时间**：全天
- **建议时长**：2 小时
- **交通**：南川自驾 / 包车
- **贴士**：适合周末微度假；民宿提前订

### 永隆山森林公园

- **位置**：南川区西城街道（近城区）
- **特色看点**：城郊森林步道、林海观景台，登顶可远眺金佛山轮廓，晨练与轻徒步友好
- **门票参考价**：免费
- **开放时间**：全天
- **建议时长**：1.5 小时
- **交通**：城区打车 / 公交
- **贴士**：与城区游览半日串联；清晨空气最佳

## 🍜 南川味道

南川大树茶（高山绿茶）、金佛山方竹笋（珍稀鲜笋）、南川米粉、小河米粉、土鸡炖方竹笋；城区与金佛山脚下农家乐人均 40–70 元，春笋与腊味最地道。

> ⚠️ 票价与开放时间以景区官方公示为准（数据参考 2026-07）。60 周岁以上老人、6 周岁（或 1.2 米）以下儿童、现役军人、残疾人等多享免票或半价，出行请带好证件。
