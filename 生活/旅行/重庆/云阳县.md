# 云阳县

> 长江边的"梯城"，龙缸如巨盆嵌于群山，张飞庙诉说着三国旧事；一城山水、一江文脉，是三峡库区里最宜慢游的县城。

## 🎯 城市速览

- **定位**：渝东北三峡旅游节点，以龙缸地缝奇观 + 张飞庙 + 梯城夜景为特色
- **核心看点**：云阳龙缸、张飞庙、三峡梯城（磐石城）、歧山草原、普安恐龙化石、栖霞宫
- **最佳季节**：春（4–5 月）草原新绿、秋（10–11 月）登缸看红叶
- **建议游玩**：1–2 天

## 🏞️ 景点卡片

### 云阳龙缸

- **位置**：云阳县清水土家族乡（歧曜山）
- **特色看点**：国家 AAAAA 级，被称为"天下第一缸"，喀斯特漏斗深约 335 米，绝壁环抱；云端廊桥（天空悬廊）伸出峭壁、全透明玻璃底，惊险刺激
- **门票参考价**：约 ¥95–100（官方公示；含部分设施）；优待 / 免票按政策
- **开放时间**：8:00–17:30
- **建议时长**：3–4 小时
- **交通**：云阳站乘景区直通车 / 自驾至清水乡；导航"云阳龙缸景区"
- **贴士**：云端廊桥恐高慎入；晴天俯瞰最壮观；与歧山草原同日

### 张飞庙

- **位置**：云阳县盘龙街道长江南岸（距老县城对岸）
- **特色看点**：国家 AAAA 级，为纪念张飞而建的千年庙宇，依山临江、建筑精美，藏有大量三国与书画碑刻；"结义楼""望云轩"俯江怀古
- **门票参考价**：约 ¥32–35（官方公示）
- **开放时间**：8:00–17:30
- **建议时长**：1.5 小时
- **交通**：云阳县城渡船 / 自驾导航"张飞庙"
- **贴士**：与刘备、关羽故事串联更有味；渡江观庙角度最佳

### 三峡梯城（磐石城）

- **位置**：云阳县城内（登城步道）
- **特色看点**：云阳新城依山建为"阶梯之城"，登城步道连接滨江与制高点磐石城（古寨），俯瞰长江大拐弯与县城灯火，夜景迷人
- **门票参考价**：免费（登城步道开放）
- **开放时间**：全天（夜景建议 19:00 后）
- **建议时长**：1–2 小时
- **交通**：县城内步行 / 公交
- **贴士**：傍晚登梯看平湖落日与灯火；台阶多穿舒适鞋

### 歧山草原

- **位置**：云阳县清水乡（龙缸旁，海拔约 1000–1500 米）
- **特色看点**：高山草甸 + 松林，夏季清凉、星空璀璨，可露营、骑马；与龙缸同日串联的高山休闲地
- **门票参考价**：约 ¥30–50（官方公示；露营 / 骑马另计）
- **开放时间**：全天
- **建议时长**：2–3 小时
- **交通**：同龙缸方向
- **贴士**：高原温差大带外套；夏季避暑露营极佳

### 普安恐龙化石遗址

- **位置**：云阳县普安乡
- **特色看点**：世界级"恐龙化石墙"遗址，埋藏密度惊人，被誉为"恐龙化石长城"；地质科普与研学热地（展示馆开放）
- **门票参考价**：约 ¥30–50（展示馆门票，以官方公示为准）
- **开放时间**：9:00–17:00
- **建议时长**：1.5 小时
- **交通**：云阳站转车 / 自驾至普安乡
- **贴士**：亲子与地质爱好者友好；配合县内其他景点安排

### 栖霞宫

- **位置**：云阳县城附近（栖霞山）
- **特色看点**：三峡库区著名的道教宫观，依山而建、古树环绕，清静修身，可俯瞰江景
- **门票参考价**：免费 / 小额香花券（以公示为准）
- **开放时间**：8:00–17:00
- **建议时长**：1 小时
- **交通**：县城内打车
- **贴士**：与梯城、张飞庙可半日人文游

## 🍜 云阳味道

云阳桃片糕（非遗糕点，香甜软糯）、云阳面（重庆小面重要源头）、张飞红烧鱼、长江鱼鲜、羊脚脚；县城滨江路小吃集中，人均 35–55 元。
