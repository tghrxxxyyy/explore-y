# 巫山县

> "曾经沧海难为水，除却巫山不是云"。巫峡的秀、神女的风、小三峡的幽，与满山红叶，让巫山成为三峡画廊中最诗意的段落。

## 🎯 城市速览

- **定位**：渝东北三峡画廊核心，以巫峡·神女景区 + 小三峡为名片
- **核心看点**：小三峡·小小三峡、神女峰、巫峡·神女景区（南环 / 神女溪）、大昌古镇、文峰景区、当阳大峡谷
- **最佳季节**：秋（11 月）红叶节最盛、春（3–4 月）峡江新绿
- **建议游玩**：2 天

## 🏞️ 景点卡片

### 小三峡·小小三峡

- **位置**：巫山县大宁河（长江支流）
- **特色看点**：国家 AAAAA 级，由龙门峡、巴雾峡、滴翠峡组成，峡谷幽深、碧水如玉；换乘小小三峡橡皮艇更刺激；悬棺、古栈道点缀其间
- **门票参考价**：约 ¥120（含游船；小小三峡漂流另计，以官方公示为准）
- **开放时间**：8:00–17:00（以当日船班为准）
- **建议时长**：3–4 小时
- **交通**：巫山站 / 县城转游船码头；自驾导航"巫山小三峡游客中心"
- **贴士**：乘船看峡谷最省力；红叶季（11 月）一票难求，提前订

### 神女峰

- **位置**：巫山县长江北岸巫峡中（神女景区）
- **特色看点**：巫峡标志性景观，"神女应无恙"的巫山神女；登望霞峰远眺神女石柱，云雨巫山意境十足；可徒步或乘索道
- **门票参考价**：约 ¥50（神女景区门票；索道另计）
- **开放时间**：8:00–17:00
- **建议时长**：2 小时
- **交通**：县城转神女景区专线 / 游船至神女溪
- **贴士**：云雨天气更具"巫山云雨"神韵；与神女溪同日游

### 巫峡·神女景区（南环线）

- **位置**：巫山县长江南岸（神女溪—柳坪—黄岩）
- **特色看点**：新晋精华线，含神女溪泛舟、黄岩索道、九龙索道、观景台俯瞰巫峡与神女峰，全景视野震撼
- **门票参考价**：约 ¥80–120（含索道套票，以官方公示为准）
- **开放时间**：8:00–17:00
- **建议时长**：半天
- **交通**：县城转景区专线
- **贴士**：索道观峡最佳；与神女峰北线组合看全景

### 大昌古镇

- **位置**：巫山县大昌镇（小三峡上游）
- **特色看点**：三峡库区保存较完整的明清古镇，温润江畔、青石板巷，复建后原味依旧，可顺游船线抵达
- **门票参考价**：免费（古镇开放）
- **开放时间**：全天
- **建议时长**：1.5 小时
- **交通**：小三峡游船线途经 / 自驾导航"大昌古镇"
- **贴士**：配合小三峡游船半日逛古镇最顺；晨雾时分极美

### 文峰景区

- **位置**：巫山县城东南文峰山
- **特色看点**：登文峰塔俯瞰巫山县城与长江大拐弯，"宁河晚渡"观景地；森林步道、玻璃眺台，适合看城景与日落
- **门票参考价**：免费 / 部分设施另计（以官方公示为准）
- **开放时间**：8:00–18:00
- **建议时长**：1.5 小时
- **交通**：县城打车 / 公交
- **贴士**：黄昏登高看江城灯火最佳；与神女湖串联

### 当阳大峡谷（当阳廊道）

- **位置**：巫山县当阳乡（偏远山区）
- **特色看点**：原生态高山峡谷，瀑布群、绝壁栈道、清凉溪谷，避暑与户外徒步秘境，人少景野
- **门票参考价**：约 ¥50–80（官方公示）
- **开放时间**：8:00–17:00
- **建议时长**：半天
- **交通**：县城包车 / 自驾（山路弯多）
- **贴士**：自驾注意山路安全；夏季玩水备拖鞋

## 🍜 巫山味道

巫山烤鱼（与万州同源，麻辣鲜香）、巫山纸包鱼、翡翠凉粉（特色甜品）、巫山神茶、脐橙；县城广东路一带烤鱼馆密集，人均 50–80 元。

> ⚠️ 票价与开放时间以景区官方公示为准（数据参考 2026-07）。60 周岁以上老人、6 周岁（或 1.2 米）以下儿童、现役军人、残疾人等多享免票或半价，出行请带好证件。
