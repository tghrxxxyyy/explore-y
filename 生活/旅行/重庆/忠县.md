# 忠县

> 长江畔的"三峡库心"，石宝寨孤峰插壁的江中盆景，白公祠文脉悠长；一座把忠义文化与江湖胜景融为一体的滨江古城。

## 🎯 城市速览

- **定位**：渝东北三峡库区旅游节点，以"江中盆景"石宝寨 + 忠义文化为名片
- **核心看点**：石宝寨、白公祠、烽烟三国实景演出、忠州博物馆、独珠江村、三峡港湾
- **最佳季节**：春（3–5 月）登寨踏青、秋（9–11 月）平湖碧水最宜人
- **建议游玩**：1 天（半日石宝寨 + 半日人文）

## 🏞️ 景点卡片

### 石宝寨

- **位置**：忠县石宝镇长江北岸
- **特色看点**：国家 AAAAA 级，被誉为"江中盆景""世界八大奇异建筑"之一；12 层木结构宝塔依玉印山而建，倚山取值、四角三方，登顶俯瞰长江与平湖，是三峡标志性奇观
- **门票参考价**：约 ¥45（官方公示；优待 / 免票按政策）
- **开放时间**：8:30–17:30
- **建议时长**：1.5–2 小时
- **交通**：重庆北站乘动车至忠县（约 1.5h）或至万州转车；自驾导航"石宝寨"
- **贴士**：库区蓄水后寨身如浮江上，晨雾或黄昏光影最佳；登塔台阶陡，注意脚下

### 白公祠

- **位置**：忠县忠州街道城西
- **特色看点**：为纪念白居易（曾任忠州刺史）而建的祠堂园林，含龙昌寺、醉吟阁、白居易生平陈列；亭台临江，文气与江景兼具
- **门票参考价**：约 ¥20–30（官方公示；平台常有优惠）
- **开放时间**：8:30–17:30
- **建议时长**：1–1.5 小时
- **交通**：县城内打车 / 公交可达
- **贴士**：与石宝寨同属忠县人文主线；祠内碑刻书法值得细看

### 《烽烟三国》实景演出

- **位置**：忠县三峡港湾（天子山脚）
- **特色看点**：以关羽故事为蓝本的大型山水实景演出，烽火、水战、马术实景呈现，场面宏大
- **门票参考价**：普通席约 ¥120–180，VIP 席更高（以官方公示为准）
- **开放时间**：夜场约 20:00（以当日场次为准，建议提前订）
- **建议时长**：约 70 分钟
- **交通**：县城打车 / 景区专线至三峡港湾
- **贴士**：旺季票紧提前订；看演出前可先游白公祠、石宝寨

### 忠州博物馆

- **位置**：忠县忠州街道（县城内）
- **特色看点**：系统展示忠县从巴文化到三峡库区移民的历史，馆藏青铜器、汉阙、庖厨俑等，免费了解本地文脉的好去处
- **门票参考价**：免费（需预约）
- **开放时间**：9:00–17:00（周一闭馆，以公示为准）
- **建议时长**：1.5 小时
- **交通**：县城内公交 / 打车
- **贴士**：馆内汉阙与"丁房双阙"复制件值得看；与白公祠可同日安排

### 独珠江村

- **位置**：忠县独珠村（长江中的江中岛村）
- **特色看点**：长江回水形成的"独珠"半岛，田园江水相依，是近年走红的休闲乡村，可露营、骑行、观江
- **门票参考价**：免费（部分体验项目另计）
- **开放时间**：全天
- **建议时长**：2–3 小时
- **交通**：县城打车 / 自驾至渡口或环岛路
- **贴士**：适合慢游与摄影；傍晚江风宜人

### 三峡港湾（天子山）

- **位置**：忠县县城长江南岸
- **特色看点**：俯瞰长江与石宝寨方向的观景高地，与《烽烟三国》剧场相邻，黄昏平湖落日极美
- **门票参考价**：免费 / 含演出套票（以官方公示为准）
- **开放时间**：全天（演出夜场另计）
- **建议时长**：1 小时
- **交通**：同《烽烟三国》方向
- **贴士**：黄昏前来拍平湖与远山层次最佳

## 🍜 忠县味道

忠县豆腐乳（中华老字号，下饭一绝）、忠州霉皮子、石宝蒸豆腐、长江鱼鲜、拨鱼儿；县城与石宝镇沿街多有本地小馆，人均 35–55 元。

> ⚠️ 票价与开放时间以景区官方公示为准（数据参考 2026-07）。60 周岁以上老人、6 周岁（或 1.2 米）以下儿童、现役军人、残疾人等多享免票或半价，出行请带好证件。
