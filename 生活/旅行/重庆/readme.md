# 重庆（直辖市）

![重庆代表风光](/images/重庆.png)

> 山城、江城、雾都，巴渝文化发祥地。一座建在山水之间的"8D 魔幻立体城市"——轻轨穿楼、索道过江、火锅飘香，长江与嘉陵江在此交汇，向东则是雄奇的长江三峡。

**首府/行政中心：** 重庆　**特点：** 山（武隆喀斯特 / 金佛山）· 水（长江三峡 / 乌江画廊）· 城（8D 立体交通 / 洪崖洞夜景）· 辣（火锅与江湖菜之源），下辖 38 个区县，集世界自然遗产、大足石刻世界文化遗产与三峡人文于一身

## 🍜 美食地图（按片区）

- **中心城区（渝中 / 江北 / 南岸 / 九龙坡 / 沙坪坝）**：重庆火锅（牛油九宫格，佩姐、周师兄、珮姐等为代表）为灵魂；重庆小面、酸辣粉、红油抄手、山城小汤圆、冰粉、凉糕是街头主角；江湖菜有毛血旺、辣子鸡、来凤鱼、水煮肉片；磁器口陈麻花、江北熊鸭子、夜市烧烤必尝
- **渝东南（武隆 / 酉阳 / 黔江 / 彭水 / 石柱）**：武隆碗碗羊肉、蕨粑炒腊肉、土坎晶丝苕粉；酉阳绿豆粉、土家腊肉、酿豆腐、油粑粑；黔江鸡杂（鸡杂火锅原产地）；彭水米粉、苗家酸鲊肉、郁山擀酥饼；石柱莼菜、黄水红烧肉、倒流水豆腐干
- **渝东北三峡（丰都 / 忠县 / 万州 / 奉节 / 巫山 / 云阳）**：丰都麻辣鸡块、鬼城麻辣鱼；忠县忠州豆腐乳、东坡肉；万州烤鱼（万州烤鱼发源地）、万州格格（粉蒸羊肉/排骨）；奉节盬子鸡、奉节脐橙；巫山纸包鱼、腊蹄子炖洋芋果果；云阳桃片糕、羊脚脚
- **渝西（大足 / 南川 等）**：大足冬菜尖、邮亭鲫鱼、三驱田凉粉；南川方竹笋（笋宴）、南川鸡、金佛山蜂蜜；江津米花糖、合川桃片、涪陵榨菜（世界三大名腌菜之一）

## 🗓️ 最佳旅游季节

- **春季（3–5 月）**：气温宜人，金佛山 / 武隆高山杜鹃初绽，酉阳桃花源桃花盛开，潼南崇龛镇万亩油菜花海（3 月盛放）；主城踏青正当时
- **夏季（6–8 月）**：主城炎热，正是"上山下乡"避暑季——武隆仙女山、石柱黄水、南川金佛山、彭水摩围山、江津四面山均成天然空调房（日均 20℃ 出头）；乌江画廊、阿依河漂流亲水玩法火爆
- **秋季（9–11 月）**：最舒适的季节。巫山长江三峡国际红叶节（11 月–12 月，120 万亩红叶）、奉节白帝城秋色、酉阳叠石花谷粉黛乱子草（9–11 月）、南川山王坪秋色公路；国庆后游客回落
- **冬季（12–2 月）**：火锅与温泉季——统景温泉、南温泉、金佛山天星温泉泡汤正暖；金佛山、武隆仙女山可滑雪赏雾凇；主城雾岚中的洪崖洞夜景别有一番意境

## 🚄 交通概况

- **航空**：重庆江北国际机场（西部重要航空枢纽，通达全国主要城市及国际航线）；武隆仙女山机场等支线机场；多数区县有高速或铁路接驳
- **高铁/动车**：成渝高铁（重庆—成都，1 小时左右）；郑渝高铁纵贯（重庆北—万州—奉节—巫山—襄阳—郑州—北京，三峡沿线县区设站）；渝贵铁路（重庆—贵阳）、渝利铁路（重庆—利川—武汉）、成渝中线高铁在建。主要枢纽：重庆北站、重庆西站、沙坪坝站
- **公路**：高速路网密集，G65 包茂、G50 沪渝、G42 沪蓉、G75 兰海等贯通；自驾串联武隆、酉阳、黔江、彭水、石柱等渝东南秘境十分便利
- **城市内**：轨道交通（轻轨）成网——2 号线李子坝"轻轨穿楼"、1/6 号线过江，是城市名片；长江索道、两江小渡轮渡提供独特过江体验；公交 + 黄色出租车。地形 8D 魔幻，建议使用高德地图"重庆模式"导航，多问本地人（"往上走 / 往下走"）

> ⚠️ 票价与开放时间以景区官方公示为准（数据参考 2026-07）。60 周岁以上老人、6 周岁（或 1.2 米）以下儿童、现役军人、残疾人等多享免票或半价，出行请带好证件。
