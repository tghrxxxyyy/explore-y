# 丰都县

> 长江边的"鬼城"名山，千年惩恶扬善的民俗信仰圣地；南天湖与雪玉洞一冷一暖，是渝东北三峡黄金线上的清凉秘境。

## 🎯 城市速览

- **定位**：渝东北三峡库区旅游节点，以"鬼城"民俗文化 + 高山避暑为特色
- **核心看点**：丰都名山（鬼城）、双桂山、雪玉洞、南天湖、九重天连廊、夜游鬼城
- **最佳季节**：春（3–5 月）踏青、夏（6–8 月）南天湖避暑、秋（9–11 月）登名山
- **建议游玩**：1–2 天

## 🏞️ 景点卡片

### 丰都名山（鬼城）

- **位置**：丰都县名山街道长江北岸名山
- **特色看点**：国家 AAAAA 级，"鬼国京都"；奈何桥、鬼门关、天子殿、玉皇大帝像等，承载千年惩恶扬善民俗信仰；可看《阴司街》实景演出
- **门票参考价**：约 ¥88–90（淡季略低；夜游套票另计）；优待 / 免票按政策
- **开放时间**：7:40–17:20
- **建议时长**：2–3 小时
- **交通**：重庆北站乘动车至丰都站（约 1h），转公交 / 打车至名山；自驾导航"丰都名山景区"
- **贴士**：登顶可俯瞰长江与县城；建议跟讲解了解"鬼文化"典故；夜游项目更具氛围感

### 双桂山

- **位置**：丰都县名山街道，与名山隔隙相望
- **特色看点**：国家森林公园，苏轼题"双桂山"、陆游碑刻、护国亭；林木葱郁，可俯瞰长江，是名山游览的自然延伸
- **门票参考价**：免费 / 或含于名山联票（以官方公示为准）
- **开放时间**：8:00–17:30
- **建议时长**：1–1.5 小时
- **交通**：与名山同方向，步行或摆渡可达
- **贴士**：与名山同日串联，登顶看江景最佳；林荫步道清凉舒适

### 雪玉洞

- **位置**：丰都县仙女湖镇（原都督乡）雪玉洞景区
- **特色看点**：世界罕见的"洁白如玉"碳酸盐溶洞，被誉为"天下第一洞"；地盾、塔珊瑚、雪玉企鹅等奇观，洞内常年约 16℃
- **门票参考价**：约 ¥70–80（官方公示；平台常有优惠，以购票页为准）
- **开放时间**：8:30–17:00
- **建议时长**：1.5–2 小时
- **交通**：丰都站转景区直通车 / 包车；自驾导航"雪玉洞"
- **贴士**：洞内湿冷，带薄外套；地面湿滑穿防滑鞋；与南天湖可同日安排

### 南天湖

- **位置**：丰都县仙女湖镇（海拔约 1700 米）
- **特色看点**：高山湖泊 + 原始森林，夏季均温约 20℃，避暑天堂；滑雪场（冬季）、环湖步道、房车营地，可观云海日出
- **门票参考价**：约 ¥60（含景区交通另计）；旺季 / 滑雪季套票另计
- **开放时间**：8:30–17:30（旺季延长）
- **建议时长**：半天–1 天
- **交通**：丰都站转景区直通车（约 1.5h）；自驾导航"南天湖景区"
- **贴士**：高原紫外线强防晒；冬季滑雪需提前订票；山区温差大带外套

### 九重天连廊

- **位置**：丰都县仙女湖镇（南天湖片区内）
- **特色看点**：悬崖玻璃观景连廊 + 高空秋千，号称"天空之城"，俯瞰峡谷云海，适合喜欢刺激项目的游客
- **门票参考价**：约 ¥60–80（含于南天湖片区套票较划算）
- **开放时间**：8:30–17:00
- **建议时长**：1.5–2 小时
- **交通**：同南天湖方向
- **贴士**：恐高者慎入；晴天能见度好时拍照最出片

### 丰都夜游鬼城（夜间演艺）

- **位置**：丰都名山景区及周边
- **特色看点**：以《阴司街》等实景 / 行进式演出活化"鬼城"民俗，灯光、NPC 互动营造沉浸氛围
- **门票参考价**：夜游套票约 ¥80–120（以官方公示为准）
- **开放时间**：夜场约 19:30 起（以当日场次为准）
- **建议时长**：约 1.5 小时
- **交通**：县城内打车至名山景区
- **贴士**：适合亲子与年轻人；建议提前订票，配合白天名山游览更佳

## 🍜 丰都味道

丰都麻辣鸡（非遗名菜，皮脆肉嫩、麻辣鲜香）、仙家豆腐乳、丰都榨菜、长江肥坨鱼、油茶汤；县城名山周边与平都大道一带有多家老字号，人均 40–60 元。

## 七、详细景点攻略

### 丰都名山鬼城体验

- **推荐路线**：奈何桥→鬼门关→天子殿
- **讲解服务**：跟讲解了解"鬼文化"典故
- **夜游项目**：《阴司街》实景演出，氛围感更强
- **最佳时间**：下午 3 点后光影更佳

### 南天湖避暑攻略

- **最佳月份**：6–8 月，日均温约 20℃
- **滑雪**：冬季有滑雪场
- **高原紫外线强**：防晒

### 雪玉洞探秘

- **核心看点**：洁白如玉碳酸盐溶洞
- **恒温提示**：洞内约 16℃，带薄外套
- **地面湿滑**：穿防滑鞋

> 来源：重庆市丰都县文化和旅游发展委员会
