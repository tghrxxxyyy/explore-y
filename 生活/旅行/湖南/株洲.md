# 株洲

> 动力之都，火车拖来的城市。炎帝陵安眠于此，醴陵釉下五彩惊艳世界，湘江与渌水在此交汇。

## 🎯 城市速览

- **定位**：湘东工业重镇、"中国动力谷"（轨道交通/航空/新能源汽车）、炎帝神农文化发源地
- **核心看点**：炎帝陵、神农谷、株洲方特、醴陵釉下五彩博物馆、酒埠江、神农城
- **最佳季节**：4–5 月（神农谷杜鹃）、9–11 月；夏季山间避暑
- **建议游玩**：2 天

## 🏞️ 景点卡片

### 炎帝陵

- **位置**：株洲市炎陵县鹿原镇
- **特色看点**：中华民族始祖炎帝神农氏安息地，国家级祭典圣地；阙门、大殿、陵寝，古柏森森，是寻根祭祖的朝圣之处
- **门票参考价**：¥60 左右
- **开放时间**：8:00–17:30
- **建议时长**：2 小时
- **交通**：株洲/炎陵乘班车至鹿原镇；自驾导航"炎帝陵"
- **贴士**：农历节气与清明前后公祭最隆重；与神农谷串联一日游

### 神农谷国家森林公园

- **位置**：株洲市炎陵县（原桃源洞）
- **特色看点**：原始次生林、珠帘瀑布、神农飞瀑（湖南最高瀑布之一）、高山湿地；负氧离子极高，夏季清凉避暑秘境
- **门票参考价**：¥75 左右
- **开放时间**：8:00–17:30
- **建议时长**：半天–1 天
- **交通**：炎陵县城转景区车；自驾导航"神农谷"
- **贴士**：山区多雨带雨衣；瀑布步道湿滑穿防滑鞋；夏季比市区低 5–8℃

### 株洲方特欢乐世界 / 东方神画

- **位置**：株洲市石峰区云龙示范区
- **特色看点**：大型主题乐园，方特欢乐世界（机动游乐）+东方神画（中华文化 IP 项目）；亲子与年轻人首选
- **门票参考价**：¥220 起（单园；双园联票更高）
- **开放时间**：9:30–17:30（节假日延长、夜场另算）
- **建议时长**：1 天
- **交通**：株洲市区乘公交/磁悬浮至云龙；自驾导航
- **贴士**：工作日人少；APP 查排队；带娃家庭首选

### 醴陵釉下五彩博物馆 & 瓷谷

- **位置**：株洲市醴陵市
- **特色看点**：中国陶瓷名城，釉下五彩瓷发源地；博物馆展示瓷艺珍品，瓷谷为现代陶瓷文化建筑群，可体验拉坯绘制
- **门票参考价**：免费（部分体验项目收费）
- **开放时间**：9:00–17:00（周一闭馆）
- **建议时长**：2 小时
- **交通**：醴陵高铁站/市区乘车
- **贴士**：可购伴手礼瓷器；顺游渌江书院、李立三故居

### 酒埠江风景区

- **位置**：株洲市攸县酒埠江镇
- **特色看点**：水库湖泊+溶洞（禹王洞）+温泉，水上休闲与地质奇观结合；可乘船游湖、探地下河
- **门票参考价**：¥80 起（含船/洞，套票另计）
- **开放时间**：8:00–17:30
- **建议时长**：半天
- **交通**：攸县转景区车；自驾导航
- **贴士**：夏季可玩水、泡温泉；溶洞清凉

### 神农城 & 湘江风光带

- **位置**：株洲市天元区（神农城）、湘江两岸
- **特色看点**：城市地标炎帝广场、神农塔、神农湖音乐喷泉；湘江风光带夜景、智轨穿城，是市民休闲客厅
- **门票参考价**：免费（登塔¥30 左右）
- **开放时间**：广场全天；音乐喷泉夜间特定时段
- **建议时长**：1–2 小时
- **交通**：株洲西站/市区公交、智轨可达
- **贴士**：夜间喷泉+灯光秀适合散步；城市夜景出片

## 🍜 株洲味道

醴陵炒粉、攸县香干、攸县血鸭、醴陵小炒肉、株洲麻辣烫（口味较重）、什锦菜、酱板鸭。钟鼓岭夜市、醴陵瓷谷周边是美食集中地。

## 🔍 景点详细攻略

### 炎帝陵深度游

- **最佳时段**：上午 9:00 前入园，避开旅游团高峰；清明/重阳公祭仪式庄严，可提前关注官方公告
- **游览动线**：阙门 → 神农大殿 → 炎帝墓冢 → 陵前祭祀广场 → 神农碑林，全程约 2 小时
- **摄影点**：大殿前广场对称构图最佳，秋季古柏金黄时出片率极高
- **特别体验**：清明前后可参与公祭大典，场面庄重震撼；每年农历四月廿六炎帝诞辰有民间祭拜活动

### 神农谷玩转指南

- **核心步道**：珠帘瀑布步道（往返约 2 小时）→ 神农飞瀑（往返约 3 小时）→ 高山湿地（往返约 1.5 小时）
- **避暑数据**：夏季谷内气温 18–22℃，比市区低 6–10℃，是天然空调
- **露营推荐**：谷内有营地（需预约），夜晚可观星，清晨听鸟鸣
- **安全提醒**：瀑布步道湿滑必须穿防滑鞋；雨季水量大时部分步道可能封闭

### 醴陵陶瓷体验

- **拉坯体验**：瓷谷多家工坊提供手拉坯体验（约 ¥50–80/人），可制作纪念品带走
- **釉下五彩观赏**：博物馆二楼精品展厅可近距离观赏大师作品
- **购物建议**：醴陵瓷器性价比高于景德镇，日用瓷与礼品瓷均可选购

## 🗓️ 2日行程规划

### Day 1：炎帝文化 + 醴陵瓷艺

- **上午**：高铁至株洲 → 炎帝陵（2 小时）→ 公祭广场拍照
- **中午**：炎陵县城午餐（血鸭/腊肉）
- **下午**：高铁至醴陵 → 醴陵釉下五彩博物馆（1.5 小时）→ 瓷谷体验拉坯（1.5 小时）
- **晚上**：返回株洲市区 → 钟鼓岭夜市（麻辣烫/炒粉）

### Day 2：山水避暑或主题乐园

**方案 A（山水线）**：
- **全天**：神农谷（珠帘瀑布 + 神农飞瀑 + 高山湿地），住炎陵县城

**方案 B（乐园线）**：
- **全天**：株洲方特欢乐世界/东方神画 → 神农城夜景灯光秀
