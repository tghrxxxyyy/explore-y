# 益阳

> 银城，洞庭南岸。安化黑茶香飘千里，茶马古道马铃悠远，"山乡巨变"的清溪村记录着乡土中国的变迁——益阳是湘北水乡的温厚一角。

## 🎯 城市速览

- **定位**：环洞庭湖生态城市、安化黑茶原产地、竹乡与水乡交融的"银城"
- **核心看点**：安化茶马古道、清溪村（山乡巨变）、洞庭湖（沅江/南县）、奥林匹克公园、千山红/大通湖
- **最佳季节**：3–5 月、9–11 月（湖区候鸟、茶园新绿）；夏季可亲水观湖
- **建议游玩**：2 天

## 🏞️ 景点卡片

### 安化茶马古道

- **位置**：益阳市安化县（雪峰山深处）
- **特色看点**：南方"茶马古道"遗存，马帮驿道、永锡桥（风雨廊桥）、洞市老街、川岩江峡谷；安化黑茶（千两茶）制作可体验，茶马文化活态博物馆
- **门票参考价**：¥80 起（含部分体验；套票另计）
- **开放时间**：8:00–17:30
- **建议时长**：半天–1 天
- **交通**：安化县城转景区车；自驾导航"安化茶马古道"
- **贴士**：可品黑茶、看千两茶踩制；山区多雨带雨具；与茶乡花海串联

### 清溪村（山乡巨变第一村）

- **位置**：益阳市赫山区谢林港镇
- **特色看点**：作家周立波《山乡巨变》原型地，乡村振兴样板；清溪书屋群、立波故居、荷塘稻田，文学与田园融合的文旅村
- **门票参考价**：免费（部分体验收费）
- **开放时间**：9:00–17:30
- **建议时长**：2 小时
- **交通**：益阳市区乘车/自驾
- **贴士**：文学爱好者与亲子研学友好；荷季（夏秋）最美

### 洞庭湖（沅江 / 南县段）

- **位置**：益阳市沅江市、南县城（南洞庭湖）
- **特色看点**：南洞庭湖湿地，万子湖、芦苇荡、麋鹿苑（麋鹿野生种群）、观鸟；赤山岛、胭脂湖，水乡渔船与湖鲜
- **门票参考价**：湿地观鸟/湖区免费或低价（游船另计）
- **开放时间**：全天（游船约 8:00–17:00）
- **建议时长**：半天
- **交通**：沅江/南县乘车至湖边；自驾导航
- **贴士**：冬季（11–3 月）观候鸟与麋鹿最佳；夏秋可采莲尝湖鲜

### 益阳奥林匹克公园

- **位置**：益阳市赫山区
- **特色看点**：城市体育公园，体育场/馆建筑现代，常用于赛事与演唱会；周边绿地广场是市民休闲地
- **门票参考价**：公园免费（赛事/演出另购票）
- **开放时间**：全天（场馆按活动）
- **建议时长**：1 小时
- **交通**：市区公交
- **贴士**：适合散步、看演出；与梓山湖串联

### 碧云峰 / 梓山湖

- **位置**：益阳市赫山区
- **特色看点**：城郊低山（碧云峰）与城市湖泊（梓山湖），登高望远、环湖骑行，近郊踏青地
- **门票参考价**：免费
- **开放时间**：全天
- **建议时长**：1–2 小时
- **交通**：市区公交/自驾
- **贴士**：市民周末遛娃、骑行首选；轻松不累

### 安化茶乡花海

- **位置**：益阳市安化县
- **特色看点**：万亩茶山与花海梯田，春季油菜花、夏季采茶，高山云海茶园景观；可体验采茶制茶
- **门票参考价**：¥60 左右
- **开放时间**：8:00–17:30
- **建议时长**：2 小时
- **交通**：安化县城转车；自驾导航
- **贴士**：春季花海最盛；与茶马古道同游安化

## 🍜 益阳味道

安化擂茶（配黑茶与小吃）、南县麻辣肉、沅江银鱼、松花皮蛋、益阳擂辣椒、大通湖大闸蟹、稻虾米。沅江鱼宴、安化黑茶宴是特色。
