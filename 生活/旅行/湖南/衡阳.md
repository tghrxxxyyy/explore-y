# 衡阳

> 雁城，南岳衡山所在地。五岳独秀的衡山雄峙城北，蔡伦造纸、王夫之著书皆出于此——衡阳是湖湘文化的山水门户。

## 🎯 城市速览

- **定位**：湘南中心城市、南岳衡山所在地、蔡伦故里与抗战名城（衡阳保卫战）
- **核心看点**：南岳衡山（中心景区/祝融峰）、南岳大庙、石鼓书院、东洲岛、蔡伦竹海、罗荣桓故居
- **最佳季节**：4–5 月（衡山杜鹃）、9–11 月（秋高登顶）；冬季可看南岳雾凇
- **建议游玩**：2–3 天（衡山至少留 1 天）

## 🏞️ 景点卡片

### 南岳衡山（中心景区）

- **位置**：衡阳市南岳区
- **特色看点**：五岳之南岳，"五岳独秀"；祝融峰（海拔 1300 米，衡山最高）、南天门、藏经殿、磨镜台、忠烈祠（全国最大抗战烈士纪念祠）；佛教道教名山，可夜爬看日出云海
- **门票参考价**：¥100（中心景区，旺季 5–10 月可能上浮至¥110，以官方公示为准）；学生/60–64 岁老人半价，65 岁以上及 1.4 米以下儿童免票
- **开放时间**：中心景区 24 小时开放（夜爬可行）；环保车 7:00–17:30（旺季延至 18:00）
- **建议时长**：1 天（登山+祝融峰）或夜爬看日出
- **交通**：高铁"衡山西站"→ 官方旅游专线巴士（约¥6）15 分钟达南岳游客中心；自驾导航"南岳衡山游客中心"，换乘环保车
- **贴士**：环保车往返约¥78 必买，省 4 小时盘山路；祝融峰望月台是云海最佳机位；山顶温差大带外套；红墙黄瓦的南岳大庙祈福必去

### 南岳大庙

- **位置**：衡阳市南岳区北支街 2 号（衡山脚下）
- **特色看点**：江南最大的古建筑群之一，"佛道共存"的稀有庙宇格局（东侧八寺、西侧八观）；红墙黄瓦、九进院落，香火极盛的祈福圣地
- **门票参考价**：¥58
- **开放时间**：8:00–17:30（冬季 17:00）
- **建议时长**：1–1.5 小时
- **交通**：南岳游客中心步行/公交可达
- **贴士**：与中心景区可串联一日游；红墙拍照出片；农历八月香期人潮极旺

### 石鼓书院

- **位置**：衡阳市石鼓区潇湘街（蒸水、湘江、耒水三江汇流处）
- **特色看点**：北宋四大书院之一，湖湘文脉源头；临江而建，亭台楼阁与摩崖石刻并存，是衡阳老城文化地标
- **门票参考价**：免费（凭身份证）
- **开放时间**：8:30–17:30
- **建议时长**：1 小时
- **交通**：市区公交"石鼓书院"站
- **贴士**：顺游湘江风光带、明清老街；与东洲岛隔江相望

### 东洲岛

- **位置**：衡阳市雁峰区湘江中
- **特色看点**：湘江三大洲之一，岛上园林、船山书院（王夫之讲学地）、亲水栈道，是市民休闲与夜游湘江的精华段
- **门票参考价**：免费
- **开放时间**：全天（园内景点约 8:30–17:30）
- **建议时长**：1–2 小时
- **交通**：市区公交至"东洲岛"或步行桥上岛
- **贴士**：傍晚看湘江落日、夜景灯光；岛上桃柳成荫，适合散步

### 蔡伦竹海

- **位置**：衡阳市耒阳市黄市镇
- **特色看点**：万亩竹林连绵成海，纪念造纸术发明家蔡伦；可游竹海栈道、观海楼、上堡晶矿大溶洞，夏日清凉避暑
- **门票参考价**：¥50 左右（以官方为准）
- **开放时间**：8:00–17:30
- **建议时长**：半天
- **交通**：耒阳乘公交/打车前往；自驾导航"蔡伦竹海"
- **贴士**：竹林避暑佳；可与蔡伦纪念园串联；夏季带防蚊

### 罗荣桓故居

- **位置**：衡阳市衡东县荣桓镇南湾村
- **特色看点**：开国元帅罗荣桓诞生地，清代湘南民居院落，陈列生平史料，红色旅游经典
- **门票参考价**：免费
- **开放时间**：8:30–17:00（周一可能闭馆）
- **建议时长**：1 小时
- **交通**：衡东县城转公交/打车
- **贴士**：顺游衡东土菜美食、洣水风光；红色研学线串联

## 🍜 衡阳味道

衡阳鱼粉（鲜辣汤底配草鱼）、衡山豆腐煲、土头碗（乡宴头牌）、渣江假羊肉、脆皮乳鸽、常宁凉粉、祁东黄花菜。解放路夜市、衡山脚下南岳里街区可一站式品尝。

## 🔍 景点详细攻略

### 南岳衡山登顶攻略

- **经典路线**：南岳大庙（祈福）→ 忠烈祠（抗战纪念）→ 磨镜台 → 南天门 → 祝融峰（登顶），全程步行约 5–6 小时
- **省力路线**：环保车至半山亭 → 索道/步行至南天门 → 祝融峰，约 2–3 小时
- **夜爬指南**：下午出发，凌晨登顶祝融峰看日出（需带厚外套与手电）
- **摄影点**：祝融峰望月台看云海、藏经殿前古松

### 南岳大庙祈福须知

- **参拜顺序**：先主殿后偏殿，东侧八寺（佛教）、西侧八观（道教），佛道共存格局独特
- **香火选择**：景区外购买更实惠，寺内有免费香领取
- **最佳时间**：农历八月香期最盛，平日清晨香火氛围最静

### 石鼓书院+东洲岛串联

- **半日路线**：石鼓书院（1 小时）→ 湘江风光带步行 → 东洲岛（2 小时）→ 船山书院
- **傍晚体验**：东洲岛看湘江落日，夜景灯光秀

## 🗓️ 2日行程规划

### Day 1：南岳衡山朝圣

- **上午**：衡阳出发 → 南岳大庙（1.5 小时）→ 忠烈祠（1 小时）
- **中午**：南岳里街区午餐（豆腐煲/鱼粉）
- **下午**：环保车至半山亭 → 步行/索道至祝融峰（3 小时）
- **晚上**：住南岳区或山顶（次日看日出可选山顶）

### Day 2：书院文化 + 东洲岛

- **上午**：石鼓书院（1 小时）→ 湘江风光带漫步
- **中午**：衡阳市区午餐（鱼粉/乳鸽）
- **下午**：东洲岛（2 小时）→ 船山书院 → 蔡伦竹海（如时间充裕）
- **晚上**：衡阳市区夜市
