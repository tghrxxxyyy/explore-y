# 江苏（省）

![江苏代表风光](/images/江苏.png)

> 鱼米之乡，吴文化与江淮文化交汇，经济强省，园林水乡冠绝天下；13 个地级市各有招牌。

**省会：** 南京　**特点：** 苏南园林水乡 + 苏中淮扬风味 + 苏北汉风湿地，南北差异鲜明

## 🍜 美食地图（按片区）

- **苏南（宁镇苏锡常）**：盐水鸭（南京）、鸭血粉丝、苏式糕团/松鼠鳜鱼（苏州）、无锡酱排骨/小笼/太湖三白、镇江锅盖面/水晶肴肉/香醋、常州天目湖砂锅鱼头/大麻糕
- **苏中（扬泰南通）**：扬州早茶（蟹黄汤包/大煮干丝/狮子头）、泰州干丝/靖江汤包/黄桥烧饼、南通文蛤（天下第一鲜）/跳面/如皋火腿
- **苏北（徐淮盐连宿）**：徐州地锅鸡/饣它汤/烙馍、淮安软兜长鱼/平桥豆腐/文楼汤包、盐城生炝鱼虾/东台鱼汤面/阜宁大糕、连云港海鲜/豆丹/凤鹅、宿迁黄狗猪头肉/车轮饼/洋河酒

## 🗓️ 最佳旅游季节

- **春秋最佳**（3–5 月赏樱/琼花/菜花，9–11 月品蟹、秋高气爽）
- **春季限定**：泰州兴化千垛油菜花（3–4 月）、无锡鼋头渚樱花（3 月底–4 月初）、扬州烟花三月
- **冬季限定**：盐城丹顶鹤越冬（11–2 月）、各地温泉
- **夏季**：海滨（连云港连岛、盐城湿地）、山水乐园（常州恐龙园、天目湖）

## 🚆 交通概况

- **航空**：南京禄口、无锡硕放、常州奔牛、徐州观音、盐城南洋、南通兴东等有机场；苏南硕放服务苏锡常
- **高铁**：京沪高铁、沪宁城际、宁杭、徐兰、连镇、盐通等密布，13 市全部通动车，跨市多 1 小时内可达
- **市内**：地铁覆盖南京/苏州/无锡/常州/徐州/南通等；水乡古镇多需汽车/旅游专线接驳
