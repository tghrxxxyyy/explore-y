# 广西（自治区）

![广西](/images/广西.png)

> 八桂大地，喀斯特山水甲天下。桂林漓江的烟雨、阳朔的田园、北海的银沙碧海、德天瀑布的一瀑跨两国，与壮乡歌圩、侗寨鼓楼、瑶山长鼓舞交织成一幅南国画卷。广西背靠大西南、面朝北部湾，是中国—东盟开放合作的门户，也是山水与海鲜兼得的旅行天堂。

**首府：** 南宁　**特点：** 面向东盟的枢纽门户、喀斯特山水与滨海度假兼具、壮族及多民族文化交汇；老友粉与螺蛳粉飘香，滨海、边关、山水、民族风情四张名片俱全

## 🍜 美食地图（按片区）

- **桂北（桂林 / 柳州 / 贺州）**：桂林米粉（卤菜粉干拌是灵魂）、阳朔啤酒鱼、荔浦芋扣肉、恭城油茶、平乐十八酿；柳州螺蛳粉、柳州云片糕、融水滤粉、侗族百家宴、酸鱼酸肉；贺州黄姚豆豉排骨、豆腐酿、信都三黄鸡、油茶、艾叶粑。山水之间，"鲜辣酸香"四味俱全。
- **桂南（南宁 / 北海 / 钦州 / 防城港 / 玉林 / 贵港）**：南宁老友粉、柠檬鸭、生榨米粉、卷筒粉、酸嘢；北海虾饼、侨港越南卷粉、蟹仔粉、海鲜加工；钦州猪脚粉、大蚝、坭兴陶宴；防城港京族风吹饼、鱼露、海鲜粥；玉林牛巴、玉林牛杂、生料粉、陆川烤乳猪；贵港罗秀米粉、桂平香辣糟、西山茶。
- **桂西（百色 / 河池 / 崇左 / 来宾）**：百色西林麻鸭、靖西酸嘢、德保猪血肠、凌云白毫茶；河池巴马香猪、火麻汤、宜州牛肉条、刘三姐豆腐瑶；崇左酸粥、壮家五色糯米饭、明仕珍珠鸭、凭祥越南风味；来宾金秀瑶家腊肉、圣堂山野菜、忻城糯玉米。民族风味浓烈，酸辣与糯米是底色。
- **桂东（梧州）**：梧州龟苓膏、纸包鸡、冰泉豆浆、梧州肠粉、岭南早茶、岑溪古典鸡、藤县濛江烧腊——粤味浓郁，是广西最"广府"的舌尖。

## 🗓️ 最佳旅游季节

- **春季（3–5 月）**：桂林烟雨漓江如泼墨山水，柳州紫荆花海（三月的洋紫荆满城粉霞），梧州/贺州气候宜人；山野新绿、客流未起，是摄影与踏青黄金期
- **夏季（6–8 月）**：滨海正当时——北海银滩、涠洲岛戏水，防城港/钦州赶海；德天瀑布进入丰水期最为壮观；山区（猫儿山、大瑶山、姑婆山）避暑。注意台风与酷暑，海边留意天气预报
- **秋季（9–11 月）**：最舒适季节，龙脊梯田金浪翻滚（9 月末–10 月最佳），桂林秋高气爽倒影绝美，红叶与桂花齐放；国庆后游客回落，性价比高
- **冬季（12–2 月）**：北方避寒优选，北海/防城港温暖干爽；涠洲岛 12–4 月为布氏鲸观测黄金期（国内近海稳定观鲸海域）；温泉（贺州、象州、巴马）养生；春节逛侗寨百家宴、壮族歌圩年味浓

## 🚄 交通概况

- **航空**：南宁吴圩国际机场（广西最大枢纽，通达全国及东盟多国）、桂林两江国际机场（第二大枢纽）、北海福成机场，另有柳州、梧州、百色、河池（金城江）、玉林等支线机场，多数地级市可航空直达
- **高铁/动车**：南宁为中心——衡柳高铁（衡阳—桂林—柳州—南宁）、柳南客专、南广高铁（南宁—梧州—广州）、南昆客专（南宁—百色—昆明）、邕北高铁（南宁—钦州—北海）、钦防支线（钦州—防城港）；南凭高铁（南宁—崇左—凭祥）已通至崇左，贵南高铁（贵阳—南宁）贯通；区内"2 小时高铁圈"基本成形
- **公路**：高速路网密集，合那高速（钦州—崇左—百色）被誉为"中国最美高速"之一，自驾串联边关与喀斯特景区极方便；滨海公路风景佳
- **城市内**：南宁地铁成网（多条线路）、桂林地铁建设推进中；桂林/阳朔/北海等热门地有旅游专线、观光车与共享电单车接驳；涠洲岛靠租电动车环岛

> ⚠️ 票价与开放时间以景区官方公示为准（数据参考 2026-07）。60 周岁以上老人、6 周岁（或 1.4 米）以下儿童、现役军人、残疾人等多享免票或半价，出行请带好证件。
