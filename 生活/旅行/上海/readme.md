# 上海（直辖市）

![上海代表风光](/images/上海.png)

> 长江入海口，中国经济、金融、贸易、航运中心。开埠百余年，海派文化兼容并蓄，摩登天际线与石库门烟火交织——"魔都"之名，一半在陆家嘴的塔尖，一半在弄堂的葱油香里。

**行政级别：** 直辖市（省级）　**下辖：** 16 个市辖区，本页按中心城区 + 近郊古镇组织

## 🍜 美食地图（按品类）

- **本帮菜（浓油赤酱）**：红烧肉、响油鳝糊、八宝鸭、腌笃鲜、油爆虾、草头圈子——老字号如老正兴、上海老饭店、功德林（素菜）
- **市井小吃**：生煎（小杨生煎 / 大壶春）、南翔小笼、锅贴、葱油饼、排骨年糕、油墩子、柴爿馄饨
- **四大金刚（早点）**：大饼、油条、粢饭、豆浆；衍生粢饭团、羌饼、粢饭糕
- **糕团甜点**：条头糕、海棠糕、擂沙圆、青团（清明）、桂花条头糕、凯司令栗子蛋糕
- **海派西餐 / 咖啡**：红房子西菜馆、德大西菜社；武康路 / 安福路 / 永康路咖啡馆集群
- **美食街区**：云南南路（老字号）、黄河路、乍浦路、昌里路（夜市）、城隍庙小吃广场

## 🗓️ 最佳旅游季节

- **春秋最佳**（3–5 月、10–11 月）：春赏樱（顾村公园、上海植物园）、秋看银杏桂花（世纪公园、桂林公园）；气温舒适、活动多
- **夏季**（6–9 月）：梅雨季闷热、台风偶有；室内场馆（博物馆 / 迪士尼 / 海洋公园）友好，但户外景区体感差
- **冬季**（12–2 月）：湿冷少雪，圣诞–春节商圈灯光与跨年（外滩 / 陆家嘴）氛围浓
- **节庆**：10 月国庆灯光秀、跨年外滩倒计时、2 月元宵豫园灯会

## 🚆 交通概况

- **航空**：浦东国际机场（国际主枢纽，磁悬浮连接市区）、虹桥国际机场（国内 + 部分国际，与高铁一体）
- **高铁 / 火车**：虹桥站（最大综合枢纽）、上海站、上海南站；长三角"1–2 小时通勤圈"（至杭州约 1h、南京约 1.5h、苏州约 25min）
- **市内**：地铁 20+ 条线覆盖全域（Metro 大都会 APP 扫码）；磁悬浮（龙阳路–浦东机场）；公交 + 轮渡（浦江轮渡 ¥2，体验老上海）；出租车 / 网约车普及
- **跨江**：隧道 + 桥梁 + 地铁，过江便捷；外滩 ↔ 陆家嘴可乘轮渡或观光隧道
