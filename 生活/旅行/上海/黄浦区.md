# 黄浦区

> 上海的城市原点。外滩的万国建筑、南京路的霓虹、豫园的飞檐、人民广场的文化场馆，都在这一方寸土里——"不到外滩，不算到上海"。

> ⚠️ 票价说明：黄浦区大部分为开放式街区与免费场馆，仅豫园等少数景点收费；下列为 2026-07 参考价，出行前以景区官方公众号或现场为准。

---

## 一、城市速览

- **城市特色**：上海"零公里"所在地，近代城市与中西文明交汇的舞台；万国建筑博览群、中华商业第一街、老城厢厢味三者并存。
- **怎么去**：地铁 1/2/8 号线"人民广场"、2/10 号线"南京东路"、10/14 号线"豫园"等密集覆盖；外滩紧邻陆家嘴（轮渡 ¥2 即达）。
- **最佳季节**：春秋最佳，四季皆宜；春节豫园灯会、国庆外滩灯光秀为高峰。
- **本地特色美食**：南翔小笼（豫园）、大壶春生煎、老正兴本帮菜、功德林素菜、城隍庙小吃（蟹壳黄、梨膏糖）。
- **住宿建议**：外滩 / 南京东路一带方便看江景与夜景；豫园周边体验老城厢；人民广场交通枢纽换乘最便捷。

---

## 二、地标与街区

### 外滩 · 万国建筑博览群
- **位置**：黄浦区中山东一路（北起外白渡桥，南至十六铺）。
- **特色看点**：52 栋风格各异的近代建筑（哥特、巴洛克、新古典等），对岸即陆家嘴"三件套"；夜景灯光是上海封面；外白渡桥、情人墙、观景平台皆经典。
- **门票**：**免费**（全天开放，灯光约 19:00–23:00）。
- **建议时长**：1–2 小时（夜景更值）。
- **交通**：地铁 2/10 号线"南京东路"步行 10 分钟；或轮渡（金陵东路 / 东门路渡口）。
- **贴士**：想避开人潮可清晨来；想拍"三件套"全景去对岸陆家嘴或北外滩；外滩观光隧道体验一般、性价比低。

### 南京东路步行街 · 中华商业第一街
- **位置**：黄浦区南京东路（河南中路—西藏中路）。
- **特色看点**：百年商业街，老字号（沈大成、泰康、邵万生）+ 现代商场；街头"叮叮车"、霓虹与年货橱窗；连接外滩与人民广场。
- **门票**：**免费**。
- **建议时长**：1–2 小时（购物 / 逛吃）。
- **交通**：地铁 2/10 号线"南京东路"。
- **贴士**：年货季与跨年最热闹；往西接南京西路（高端商圈），往东直通外滩。

### 豫园 / 城隍庙 · 老城厢核心
- **位置**：黄浦区福佑路 168 号（安仁街）。
- **特色看点**：明代私家园林（潘允端所建），九曲桥、湖心亭、玉玲珑（江南名石）；周边城隍庙商圈小吃云集、年味最浓；豫园灯会（元宵）闻名。
- **门票（参考）**：豫园 ¥30（学生 / 老人 ¥15）；城隍庙街区免费。
- **开放时间**：约 9:00–16:30（冬季略短）。
- **建议时长**：2 小时（园林 + 小吃）。
- **交通**：地铁 10/14 号线"豫园"站。
- **贴士**：节假日人极多；九曲桥拍照经典；小吃认准老字号、比价防宰。

### 人民广场 · 城市文化心脏
- **位置**：黄浦区人民大道（南京西路 / 武胜路一带）。
- **特色看点**：上海博物馆（东馆在浦东）、上海大剧院、上海城市规划展示馆、美术馆；地下"香港名店街 / 迪美"；鸽群广场是城市名片。
- **门票**：广场与多数场馆**免费**（上博需预约）；演出另购票。
- **建议时长**：半日（含逛馆）。
- **交通**：地铁 1/2/8 号线"人民广场"枢纽。
- **贴士**：上海博物馆（人民广场馆）青铜器、书画顶级，务必提前预约。

### 新天地 · 石库门时尚地标
- **位置**：黄浦区太仓路（马当路—黄陂南路）。
- **特色看点**：以中共一大会址为核心的石库门建筑群改造，中西餐厅、酒吧、潮牌聚集；"怀里抱历史、面上很摩登"。
- **门票**：街区**免费**（一大会址纪念馆免费需预约）。
- **建议时长**：2 小时（晚餐 / 小酌）。
- **交通**：地铁 10/13 号线"一大会址 · 新天地"站。
- **贴士**：白天逛会址与石库门，夜晚泡吧；比田子坊更整洁精致。

### 田子坊 · 弄堂里的创意集市
- **位置**：黄浦区泰康路 210 弄（打浦桥）。
- **特色看点**：老弄堂改造的文创集市，画廊、手作、咖啡、旗袍小店密布；"最上海的弄堂烟火与文艺"。
- **门票**：**免费**（小店消费另计）。
- **建议时长**：1–2 小时。
- **交通**：地铁 9 号线"打浦桥"站。
- **贴士**：周末拥挤嘈杂；喜欢安静可选工作日上午；网红店同质化，挑特色手作。

### 思南公馆 / 复兴公园 · 法租界优雅样本
- **位置**：黄浦区思南路（复兴中路—淮海中路）。
- **特色看点**：成片花园洋房（思南公馆），梧桐掩映；复兴公园是上海唯一法式园林；思南读书会、露天市集常有。
- **门票**：街区**免费**（部分展览 / 公馆参观收费）。
- **建议时长**：1.5 小时。
- **交通**：地铁 10/13 号线"新天地"或 1 号线"黄陂南路"步行。
- **贴士**：与淮海路商圈串联，喝杯咖啡看洋房最惬意。

## 三、文化与艺术场馆（多为免费，需预约）

### 上海博物馆（人民广场馆）· 顶级文博
- **位置**：黄浦区人民大道 201 号。
- **特色看点**：中国四大博物馆之一，青铜器（大克鼎、晋侯稣钟）、书画、陶瓷、钱币馆藏顶级；常设 + 特展。
- **门票**：**免费，须提前预约**（官方公众号，旺季秒空）。
- **开放时间**：周二–周日 9:00–17:00（16:00 停止入馆），周一闭馆。
- **建议时长**：3 小时+。
- **交通**：地铁 1/2/8 号线"人民广场"。
- **贴士**：与东馆（浦东）二选一或都看；青铜馆、书画馆必看。

### 上海当代艺术博物馆（PSA）
- **位置**：黄浦区苗江路 678 号（原南市发电厂，世博园区）。
- **特色看点**：上海双年展主场地，巨型烟囱地标；当代艺术大展不断；馆内咖啡与江景平台出片。
- **门票**：常设展免费，特展多收费（约 ¥60–150）。
- **开放时间**：周二–周日 11:00–19:00（18:00 停止入馆），周一闭馆。
- **建议时长**：2 小时。
- **交通**：地铁 4/8 号线"西藏南路"转公交 / 打车；或南浦大桥旁步行。
- **贴士**：建筑本身即展品，江边散步顺路。

### 上海大剧院 / 上海文化广场
- **位置**：人民广场西侧（黄陂北路 / 复兴中路）。
- **特色看点**：歌剧、芭蕾、音乐剧顶级舞台；建筑造型如"水晶宫殿"（大剧院）。
- **门票**：演出票 ¥80–1280 不等。
- **贴士**：看一场演出是体验海派文化的另一种方式；官网提前购票。

## 四、浦江游览（十六铺码头）

### 黄浦江游览 · 母亲河夜景
- **位置**：黄浦区中山东二路 / 十六铺码头。
- **特色看点**：乘船看外滩万国建筑 + 陆家嘴天际线，日航看城市轮廓、夜航看灯光璀璨；经典"上海初体验"。
- **门票（参考）**：十六铺日航约 ¥79、夜航约 ¥102–130（不同船型 / 含餐差异大）。
- **开放时间**：日航约 13:00 起、夜航约 19:00 起（班次随季节）。
- **建议时长**：45 分钟–1.5 小时。
- **交通**：地铁 9/10 号线"豫园"步行至十六铺。
- **贴士**：夜航比日航值；想省钱可坐 ¥2 轮渡（东金线）感受过江，不讲解但景一样。

## 五、实用信息

- **经典 1 日路线**：外滩（清晨）→ 南京东路 → 人民广场（上博）→ 豫园 / 城隍庙（午餐小吃）→ 新天地 / 田子坊（傍晚）→ 外滩夜景。
- **交通贴士**：黄浦景点极集中，地铁 + 步行最方便；外滩 ↔ 陆家嘴轮渡 ¥2 最划算。
- **避坑**：节假日外滩 / 豫园人挤人，看管好财物；景区周边"黑车"与高价拍照谨慎；小吃认老字号。
- **联游**：隔江即浦东（东方明珠 / 迪士尼），地铁 2 号线直达；苏州河南岸步道（外白渡桥—邮政博物馆）适合散步拍照。
