# 徐汇区

> 法租界的花园住宅区，海派生活美学的优雅样本。武康路的梧桐、衡复的洋房、龙华的钟声、西岸的美术馆——"最上海"的慢与潮，都在这片梧桐区里。

> ⚠️ 票价说明：多数街区 / 公园免费，龙华寺等少量收费；下列为 2026-07 参考价，以官方为准。

---

## 一、城市速览

- **城市特色**：衡复历史文化风貌区核心，梧桐区 + 花园洋房 + 美术馆集群；中西文化交融的高雅生活样本。
- **怎么去**：地铁 1/9/11 号线"徐家汇"、10/11 号线"交通大学"、7 号线"龙华中路"等；武康路一带多步行。
- **最佳季节**：春秋最佳，梧桐新绿 / 银杏金黄时街区最美。
- **本地特色美食**：乔家栅糕团、老洋房西餐、武康路咖啡馆、永康路网红小食、龙华寺素面。
- **住宿建议**：衡复风貌区精品酒店 / 民宿体验洋房；徐家汇商圈交通购物便利。

## 二、风貌街区与名人足迹

### 武康路 / 衡复风貌区 · 梧桐区精华
- **位置**：徐汇区武康路（淮海中路—安福路—五原路一带）。
- **特色看点**："中国历史文化名街"，武康大楼（诺曼底公寓，一艘"一艘船"形老公寓）是顶流打卡；百年梧桐、西班牙式 / 法国式花园洋房、罗密宋故居、巴金故居；安福路话剧、五原路小店、湖南路静谧。
- **门票**：街区**免费**。
- **建议时长**：2–3 小时（散步 + 咖啡）。
- **交通**：地铁 10/11 号线"交通大学"或 1 号线"衡山路"步行。
- **贴士**：清晨 / 工作日人少出片；武康大楼在路口拍全景；安福路、五原路适合逛小店喝咖啡。

### 衡山路 / 复兴西路
- **位置**：徐汇区衡山路沿线。
- **特色看点**：老上海酒吧街与梧桐大道，衡山公园、复兴西路洋房群；夜晚梧桐灯下最有情调。
- **门票**：**免费**。
- **建议时长**：1–2 小时。
- **交通**：地铁 1 号线"衡山路"。
- **贴士**：与衡复风貌区串联步行即可。

### 宋庆龄故居
- **位置**：徐汇区淮海中路 1843 号。
- **特色看点**：宋庆龄长期居住寓所，主楼、车库、花园保留原貌；了解其生平与近代史。
- **门票（参考）**：约 ¥20。
- **开放时间**：约 9:00–16:30（周一可能闭馆，以官方为准）。
- **建议时长**：1 小时。
- **交通**：地铁 10/11 号线"交通大学"步行。
- **贴士**：与武康路顺路，历史爱好者必看。

## 三、古刹与园林

### 龙华寺 / 龙华塔 · 千年古刹
- **位置**：徐汇区龙华路 2853 号。
- **特色看点**：上海地区历史最久、规模最老的寺院（三国吴赤乌年间传说）；七层龙华塔（北宋重建）、龙华钟声；3 月龙华庙会 + 桃花最盛。
- **门票（参考）**：约 ¥10（香花券）；塔另计。
- **开放时间**：约 7:00–16:30。
- **建议时长**：1.5 小时。
- **交通**：地铁 11/12 号线"龙华"站。
- **贴士**：新春撞钟、桃花节是两大高峰；寺外龙华烈士陵园免费瞻仰。

### 桂林公园 / 康健园
- **位置**：徐汇区桂林路（近上海植物园）。
- **特色看点**：桂花主题园林（"桂林公园"因桂得名），秋季金桂飘香；原上海大亨黄金荣私园，四教厅、九曲长廊。
- **门票**：约 ¥2（低价 / 免费，以现场为准）。
- **建议时长**：1 小时。
- **交通**：地铁 12 号线"桂林公园"。
- **贴士**：9–10 月桂花季最香；与上海植物园串联。

## 四、西岸艺术走廊（美术馆集群）

### 西岸 · 龙美术馆 / 余德耀 / 西岸美术馆 / 油罐
- **位置**：徐汇区龙腾大道（滨江，原龙华机场 / 北票码头一带）。
- **特色看点**：黄浦江畔美术馆集群——龙美术馆（西岸馆，清水混凝土"伞拱"）、余德耀美术馆、西岸美术馆（与蓬皮杜合作）、油罐艺术中心、星美术馆；江边跑道 + 塔吊保留，工业风 + 艺术范。
- **门票**：公园 / 跑道**免费**；各馆特展多收费（¥80–150 不等，部分免费日）。
- **开放时间**：展馆多为周二–周日 10:00–18:00，周一闭馆。
- **建议时长**：半日（逛 1–2 馆 + 江边）。
- **交通**：地铁 11 号线"云锦路"或 7 号线"龙华中路"转步行。
- **贴士**：江边散步 + 看展是徐汇最潮玩法；关注各馆特展档期。

## 五、徐家汇商圈与体育

### 徐家汇 · 天主堂 / 港汇 / 徐家汇书院
- **位置**：徐汇区徐家汇（地铁 1/9/11 号线枢纽）。
- **特色看点**：徐家汇源（天主教文化：徐家汇天主堂、光启公园、徐家汇观象台）；港汇恒隆、太平洋、美罗城购物；徐家汇书院（网红图书馆，穹顶书海）。
- **门票**：天主堂免费（礼拜 / 参观以公告）；书院免费需预约；购物自由。
- **建议时长**：2 小时（含书院 + 教堂）。
- **交通**：地铁 1/9/11 号线"徐家汇"。
- **贴士**：徐家汇书院顶楼景观位要早到；天主堂哥特式双塔很出片。

### 上海体育场（八万人体育场）/ 上海体育馆
- **位置**：徐汇区天钥桥路 / 中山南二路。
- **特色看点**：大型演唱会、体育赛事主场地；周边为体育文化商圈。
- **门票**：赛事 / 演出票另购。
- **贴士**：看演出 / 球赛目的地；地铁 4 号线"上海体育场"直达。

## 六、实用信息

- **经典 1 日**：武康路（上午光影）→ 安福路咖啡 → 徐家汇天主堂 / 书院（午餐）→ 龙华寺 → 西岸江边看展散步（傍晚）。
- **交通贴士**：梧桐区以步行为主，地铁到边缘再走；共享单车穿梭巷子很方便。
- **避坑**：网红咖啡馆排队久；武康路周末人挤人，想拍空镜赶早。
- **联游**：向西接静安（南京西路），向南接闵行（七宝），向东越江到浦东。
