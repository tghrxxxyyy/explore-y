# 陕西（省）

![陕西](/images/陕西.png)

> 三秦大地，十三朝古都所在。黄河奔涌于东，秦岭横亘于南，黄土高原铺展于北——关中的厚重、陕南的温润、陕北的苍茫在此交汇。周秦汉唐的文明中心、丝绸之路的东方起点、中国革命圣地，都在这片土地上层叠生长。

**省会：** 西安　**特点：** 关中平原为核心，陕北黄土高原与陕南秦巴山地为两翼；华夏文明重要发祥地，秦汉唐帝陵与古城墙星罗棋布；面食与小吃天下闻名（肉夹馍、羊肉泡馍、凉皮、油泼面、Biangbiang 面、葫芦头）；西安"米"字形高铁枢纽 + 咸阳国际机场双门户

## 🍜 美食地图（按片区）

- **关中（西安 / 咸阳 / 宝鸡 / 铜川 / 渭南）**：陕西小吃灵魂所在。**肉夹馍**（腊汁肉夹白吉馍，樊记/秦豫为代表；回坊"老潼关"肉夹馍酥皮有别）、**羊肉泡馍**（煮馍掰碎、牛羊肉汤浇头，同盛祥/老孙家）、**凉皮**（麻酱凉皮、秦镇米皮、擀面皮三种流派）、**油泼面**（滚油泼辣子浇宽面）、**Biangbiang 面**（裤带面、油泼辣子biangbiang香）、**葫芦头**（猪肠泡馍，春发生老字号）、**臊子面**（宝鸡岐山酸辣红油）、**荞面饸饹**、**锅盔牙子**、**水盆羊肉**（渭南大荔/蒲城）。咸阳袁家村、西安回民街、永兴坊是集中打卡地。
- **陕南（汉中 / 安康 / 商洛）**：山水间的温润风味，偏川渝麻辣又不失清爽。**汉中热米皮 + 菜豆腐 + 花生稀饭**（早餐标配）、**核桃馍**、**麻辣鸡**（王建强）、**浆水面**；安康**蒸面**、**炕炕馍**、**富硒茶**、**紫阳蒸盆子**；商洛**商州糍粑**、**柞水洋芋糍粑**、**商南茶**、**漫川八大件**。整体口味比关中清淡，米饭为主。
- **陕北（榆林 / 延安）**：黄土高原的粗犷豪爽。**羊肉面**、**剁荞面**、**陕北油糕**、**黄馍馍**、**洋芋擦擦**（子长）、**碗托**、**羊杂碎**（李老二）、**抿节**、**拼三鲜**（榆林）、**钱钱饭**、**陕北烩菜**。红枣、小米、羊肉是当家食材，冬季暖身首选。

## 🗓️ 最佳旅行季节

- **春季（3–5 月）**：关中牡丹（西安牡丹苑）、汉中油菜花海（南郑陈村、洋县，3 月盛放）、宝鸡岐山踏青、延安宝塔山新绿；气候温和宜人
- **夏季（6–8 月）**：秦岭避暑正当时——太白山、牛背梁、金丝峡、黎坪、南宫山均凉爽；陕北（榆林/延安）昼夜温差大、夜间舒适；西安等平原城市偏热，建议安排山区与博物馆
- **秋季（9–11 月）**：最舒适季节，秦岭红叶（太白山、黎坪、牛背梁）、华山登高、延安枣园秋色、关中平原丰收景；国庆后游客明显回落
- **冬季（12–2 月）**：华山雪景雾凇壮观但需装备；陕北窑洞年味、延安红色研学淡季优惠；西安城墙灯会、大唐不夜城年俗热闹；温泉（太白山、华清池）正当时

## 🚄 交通概况

- **航空**：西安咸阳国际机场（西北最大航空枢纽，位于咸阳市，距西安市区约 30 公里，地铁 14 号线/机场城际直达），通航全国及亚洲主要城市；另有榆林榆阳机场、延安南泥湾机场、汉中城固机场、安康富强机场、宝鸡（经西安/咸阳）、渭南（经西安/华山）等支线机场
- **高铁/动车**：西安"米"字形高铁枢纽——徐兰（兰州—西安—郑州—洛阳）、京昆（北京—石家庄—太原—西安—成都—昆明）、西成（西安—汉中—成都）、西渝/西十（在建/部分通车，西安—十堰—武汉）等交汇；西安北站为全国最繁忙高铁站之一。地市覆盖：宝鸡/咸阳/渭南/汉中均已通高铁，延安/榆林/安康/商洛经动车或在建线路接入
- **普铁**：陇海、包西、宁西、阳安等干线贯通；宝鸡、西安为传统铁路枢纽
- **公路**：连霍、京昆、包茂、福银、沪陕等高速路网密集，自驾串联秦岭、黄土高原景区便利；沿黄观光路串联渭南洽川、韩城、延安黄河壶口等
- **城市内**：西安地铁成网（多条线路 + 14 号线机场线）；宝鸡、咸阳接驳西安轨道；各景区多配套旅游专线/公交
