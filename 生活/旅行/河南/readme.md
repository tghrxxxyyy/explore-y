# 河南（省）

![河南代表风光](/images/河南.png)

> 中原腹地，华夏文明核心。八大古都河南独占其四（郑州、洛阳、开封、安阳），少林太极、殷墟甲骨、龙门石窟、《清明上河图》皆出于此。地跨黄河中下游，是中华文明最重要的发源地之一，也是全国人口与粮食大省。

**省会：** 郑州　**特点：** 中原综合交通枢纽、"米"字形高铁核心；华夏历史文明核心区；少林武术与陈氏太极发源地；面食与汤文化浓郁，胡辣汤、烩面、水席闻名全国

## 🗓️ 最佳旅游季节

- **春季（3–5 月）**：洛阳牡丹文化节（4 月盛花期，王城公园/国家牡丹园/中国国花园）、开封清明文化节、新乡宝泉郁金香、信阳采茶（清明前后毛尖）、驻马店嵖岈山杜鹃；气候宜人
- **夏季（6–8 月）**：太行山避暑（云台山/八里沟/宝泉/万仙山/老界岭/白云山）、南阳宝天曼、信阳鸡公山（中国四大避暑胜地之一）、南阳西峡恐龙园亲子游正当时
- **秋季（9–11 月）**：最舒适季节，太行红叶（焦作青天河/云台山红叶节）、嵩山登高、开封菊花文化节（10–11 月）、南阳内乡赏秋；国庆后游客明显回落
- **冬季（12–2 月）**：三门峡天鹅湖（11 月–次年 3 月，数千只大天鹅越冬）是绝对主角；济源/焦作滑雪、嵩山雪景、洛阳温泉；春节逛庙会（浚县古城正月古庙会极盛）

## 🚄 交通概况

- **航空**：郑州新郑国际机场（河南最大枢纽，与"米"字形高铁共构双枢纽）、洛阳北郊机场、南阳姜营机场、信阳明港机场，及商丘/安阳等支线机场
- **高铁/动车**：郑州"米"字形高铁枢纽——京广（北京—石家庄—郑州—武汉—广州）、徐兰（徐州—郑州—洛阳—西安）、郑渝（郑州—南阳—重庆）、郑阜/商合杭（郑州—周口—阜阳—杭州）、郑太（郑州—焦作—太原）等，多数地市已入高铁网；郑州东站为全国最繁忙高铁站之一
- **普铁**：陇海、京广两大干线交汇郑州；焦柳、宁西等线贯通南北
- **公路**：高速路网密集（连霍、京港澳、大广、二广等），自驾串联太行、伏牛山景区十分便利
- **城市内**：郑州地铁成网（多条线路）；洛阳地铁 1/2 号线；开封/安阳等公交+旅游专线接驳景区间
