# 商丘

> "三商之源"，商人、商业、商文化的发祥地。归德府城的八卦城格局、芒砀山的汉梁王陵，串起从商周到汉唐的厚重。

## 🎯 城市速览

- **定位**：豫东门户、三商文化之源、国家历史文化名城
- **核心看点**：商丘古城、芒砀山、夫子山、应天书院、火神台、商丘博物馆
- **最佳季节**：4–5 月、9–10 月；春秋最宜
- **建议游玩**：2 天

## 🏞️ 景点卡片

### 商丘古城（归德府城）

- **位置**：商丘市睢阳区
- **特色看点**：明代归德府城，保存完整的八卦城格局与砖城墙；南城门、张巡祠、应天书院、状元巷、穆氏四合院散布城内
- **门票参考价**：古城免费（联票含南城门+张巡祠+应天书院约¥35；火神台¥30）
- **开放时间**：8:00–17:30
- **建议时长**：半日
- **交通**：市区公交"商丘古城"站
- **贴士**：登城墙俯瞰八卦格局；城湖环抱很特别

### 芒砀山

- **位置**：商丘市永城市
- **特色看点**：汉梁王陵墓群，西汉梁国诸侯王陵（梁孝王王后陵、梁孝王陵）、兵马俑、刘邦斩蛇处；联票含汉宫演出
- **门票参考价**：¥88（联票含汉宫演出）
- **开放时间**：8:00–17:30
- **建议时长**：1 天
- **交通**：永城公交/自驾导航"芒砀山旅游区"
- **贴士**：地下宫殿规模震撼；与夫子山同区

### 夫子山

- **位置**：商丘市永城市芒砀山片区
- **特色看点**：相传孔夫子周游列国避雨处，文圣园、孔夫子石像、玻璃栈道
- **门票参考价**：¥60
- **开放时间**：8:00–17:30
- **建议时长**：半天
- **交通**：与芒砀山同区
- **贴士**：与芒砀山同日游；亲子研学友好

### 应天书院

- **位置**：商丘古城内
- **特色看点**：北宋四大书院之首，范仲淹曾讲学；书院复原与展览
- **门票参考价**：含于古城联票
- **开放时间**：8:00–17:30
- **建议时长**：1 小时
- **交通**：古城内步行
- **贴士**：与古城同游；书院文化爱好者必到

### 火神台（阏伯台）

- **位置**：商丘古城旁
- **特色看点**：传说阏伯（商祖）观星授时处，火文化圣地；台上有庙，春节庙会热闹
- **门票参考价**：¥30
- **开放时间**：8:00–17:30
- **建议时长**：1 小时
- **交通**：古城旁公交/步行
- **贴士**：与古城串联；火文化节期间有活动

### 商丘博物馆

- **位置**：商丘市睢阳区
- **特色看点**："商"文化专题馆，金缕玉衣、汉画像石、商代文物；建筑如"鹿角"造型
- **门票参考价**：免费
- **开放时间**：9:00–17:00（周一闭馆）
- **建议时长**：1.5 小时
- **交通**：市区公交可达
- **贴士**：出行前先建认知；与古城呼应

## 🍜 商丘味道

商丘水煎包（底部焦脆）、sha汤（饣它汤，咸鲜醒神）、垛子羊肉、永城sa汤、夏邑糟鱼、柘城酥制培乳。古城与夜市小吃集中。
