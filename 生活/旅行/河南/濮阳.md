# 濮阳

> "中华龙乡"，西水坡出土了 6400 年前的蚌塑龙；也是杂技之乡与造字圣人仓颉的故里，低调却文脉深厚。

## 🎯 城市速览

- **定位**：豫东北边境城市、龙文化/杂技之乡、平原生态城
- **核心看点**：戚城文物景区、东北庄杂技、中原绿色庄园、濮上园、仓颉陵、濮阳博物馆
- **最佳季节**：4–5 月、9–10 月；春秋最宜
- **建议游玩**：1–2 天

## 🏞️ 景点卡片

### 戚城文物景区

- **位置**：濮阳市华龙区京开大道
- **特色看点**：颛顼遗都、春秋卫国都城遗址，古城墙、会盟台；西水坡出土"中华第一龙"蚌壳龙陈列于此（龙乡之源）
- **门票参考价**：免费
- **开放时间**：8:00–18:00
- **建议时长**：1.5 小时
- **交通**：市区公交"戚城公园"站
- **贴士**：濮阳"龙文化"核心地；与濮阳博物馆串联认知

### 东北庄杂技

- **位置**：濮阳市华龙区岳村乡东北庄村
- **特色看点**：与河北吴桥并称的"中国杂技之乡"；杂技博物馆+实景演出，可看高难度杂技
- **门票参考价**：¥40（演出票）
- **开放时间**：8:00–17:30
- **建议时长**：2 小时
- **交通**：市区乘乡村公交/自驾导航"东北庄杂技文化园"
- **贴士**：带娃必看；常有互动体验

### 中原绿色庄园

- **位置**：濮阳市濮上园片区
- **特色看点**：大型生态园林，森林、湖泊、亲子游乐设施；城市"绿肺"
- **门票参考价**：¥20
- **开放时间**：8:00–18:00
- **建议时长**：2 小时
- **交通**：市区公交可达
- **贴士**：亲子休闲首选；与濮上园相邻

### 濮上园

- **位置**：濮阳市城区西部
- **特色看点**：黄河湿地生态园，草地、水面、骑行道；休闲露营好去处
- **门票参考价**：免费
- **开放时间**：至 18:00
- **建议时长**：2 小时
- **交通**：市区公交/自驾
- **贴士**：周末野餐、骑行、放风筝；与绿色庄园连游

### 仓颉陵

- **位置**：濮阳市南乐县
- **特色看点**：造字圣人仓颉的陵墓与祠庙，碑刻、古柏；汉字文化寻根地
- **门票参考价**：免费
- **开放时间**：8:00–17:30
- **建议时长**：1 小时
- **交通**：南乐公交/自驾
- **贴士**：文字文化爱好者朝圣；顺游南乐民俗

### 濮阳博物馆

- **位置**：濮阳市华龙区
- **特色看点**：展示濮阳历史、龙文化、杂技与黄河文明；西水坡龙文物复制品
- **门票参考价**：免费（需预约）
- **开放时间**：9:00–17:00（周一闭馆）
- **建议时长**：1.5 小时
- **交通**：市区公交可达
- **贴士**：出发前先来建立认知；与戚城呼应

## 🍜 濮阳味道

濮阳壮馍（大肉饼，外酥里嫩）、滑脊汤（酸辣肉片汤）、范县大包子、渠村鱼汤、牛肉耗辣椒、清丰烧饼。

## 🔍 景点详细攻略

### 戚城+龙文化之旅

- **核心线路**：戚城遗址（古城墙/会盟台）→ 濮阳博物馆（西水坡龙文物）→ 仓颉陵
- **龙文化打卡**：濮阳"中华第一龙"出土地，6400 年前蚌塑龙
- **最佳时间**：春秋季节最宜

### 东北庄杂技体验

- **核心体验**：杂技博物馆 → 实景演出 → 互动体验
- **适合人群**：亲子首选，带娃必看
- **演出时间**：提前查询当日演出安排

### 濮上园+绿色庄园

- **核心体验**：骑行道 → 湖泊 → 亲子游乐 → 野餐
- **最佳时间**：周末家庭出游

## 🗓️ 2日行程规划

### Day 1：龙文化+杂技

- **上午**：濮阳博物馆（龙文化，1.5 小时）→ 戚城遗址（1.5 小时）
- **中午**：濮阳市区午餐（壮馍/滑脊汤）
- **下午**：东北庄杂技（演出+体验，2 小时）
- **晚上**：濮阳市区晚餐

### Day 2：仓颉陵或绿色庄园

**方案 A（文字线）**：
- **上午**：仓颉陵（1 小时）→ 南乐民俗
- **下午**：濮上园/绿色庄园 → 返程

**方案 B（休闲线）**：
- **全天**：中原绿色庄园+濮上园（亲子游乐，半天）→ 返程
