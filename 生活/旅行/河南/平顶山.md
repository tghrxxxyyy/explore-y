# 平顶山

> 因煤而兴的"鹰城"，却藏着中原最震撼的山水与佛像。尧山云海、中原大佛、二郎山平湖，让这座工业城有了水墨般的灵气。

## 🎯 城市速览

- **定位**：中原能源与重工业城市、尧山—大佛旅游核心
- **核心看点**：尧山、中原大佛、二郎山、画眉谷、香山寺、风穴寺、三苏园
- **最佳季节**：4–5 月、9–11 月（登山避暑/赏秋）；夏季尧山避暑
- **建议游玩**：2 天

## 🏞️ 景点卡片

### 尧山（石人山）

- **位置**：平顶山市鲁山县尧山风景区
- **特色看点**：伏牛山东段主峰，奇峰、云海、瀑布、温泉俱佳；"中原独秀"；可乘索道省体力；与旁的尧山温泉小镇配套
- **门票参考价**：¥60（学生¥35）；索道上行¥60/下行¥50 另计
- **开放时间**：8:00–17:30
- **建议时长**：1 天
- **交通**：平顶山/鲁山乘旅游专线或自驾导航"尧山景区"；郑尧高速直达
- **贴士**：雨后云海概率高；冬季冰雪节亦景；与中原大佛顺路

### 中原大佛

- **位置**：平顶山市鲁山县佛泉寺
- **特色看点**：世界最高青铜立佛（总高 108 米）；佛泉寺、礼佛坛、朝圣大道；景区以"佛、山、汤"为主题
- **门票参考价**：¥35（学生¥15）
- **开放时间**：8:00–17:30
- **建议时长**：2–3 小时
- **交通**：鲁山乘公交/自驾导航"中原大佛"；与尧山相邻
- **贴士**：可与尧山、温泉串成 1–2 日朝圣休闲线

### 二郎山

- **位置**：平顶山市舞钢市
- **特色看点**：石漫滩水库旁的山水景区，湖光山色、平湖峡谷、吊桥与栈道；可乘船游湖
- **门票参考价**：¥52.9（约¥55）
- **开放时间**：8:00–17:30
- **建议时长**：半天
- **交通**：舞钢市内公交/自驾导航"二郎山景区"
- **贴士**：夏季亲水凉爽；与石漫滩大坝、灯台架可串联

### 画眉谷

- **位置**：平顶山市鲁山县
- **特色看点**：尧山脚下的溪谷景区，瀑布、潭池、奇石遍布，夏季清凉；有漂流
- **门票参考价**：¥50 起
- **开放时间**：8:00–17:30
- **建议时长**：半天
- **交通**：鲁山—尧山沿线公交/自驾
- **贴士**：亲子亲水好去处；与尧山同日游

### 香山寺

- **位置**：平顶山市新城区北香山
- **特色看点**：传说为观音菩萨证道之地（大悲观音菩萨"香山"说之源），千年古刹；寺塔可俯瞰新城
- **门票参考价**：免费/低价
- **开放时间**：8:00–17:30
- **建议时长**：1 小时
- **交通**：市区公交/自驾导航"平顶山香山寺"
- **贴士**：市区近，可顺游；香山与白龟湖湿地公园相连

### 风穴寺

- **位置**：平顶山市汝州市
- **特色看点**：中原四大名刹之一，依山而建、无中轴线布局独特；七祖塔、毗卢殿、悬钟阁；银杏古树
- **门票参考价**：¥30
- **开放时间**：8:00–17:30
- **建议时长**：1.5 小时
- **交通**：汝州市区公交/自驾
- **贴士**：清幽少人，摄影与古建爱好者友好

## 🍜 平顶山味道

郏县饸饹面（荞麦面配羊肉臊子，非遗）、鲁山揽锅菜（杂烩炖菜）、舞钢热豆腐、叶县烩面、宝丰酒、汝州粉皮。郏县三绝：饸饹面、茶水、牛肉。

## 🔍 景点详细攻略

### 尧山+中原大佛一日游

- **上午**：尧山（索道上山 → 奇峰云海 → 天下第一滑道 → 索道下山，4 小时）
- **下午**：中原大佛（108 米青铜立佛 → 佛泉寺 → 朝圣大道，2 小时）
- **住宿推荐**：尧山温泉小镇，泡温泉解乏

### 二郎山亲水攻略

- **核心体验**：石漫滩水库游湖 → 吊桥 → 栈道 → 灯台架（可选）
- **最佳时间**：夏季亲水清凉

### 风穴寺古建探秘

- **核心看点**：七祖塔 → 毗卢殿 → 悬钟阁 → 银杏古树
- **特色**：中原四大名刹之一，无中轴线布局独特，清幽少人

## 🗓️ 2日行程规划

### Day 1：尧山+中原大佛

- **上午**：平顶山出发 → 尧山（索道+奇峰+云海，4 小时）
- **中午**：尧山镇午餐
- **下午**：中原大佛（2 小时）→ 佛泉寺
- **晚上**：尧山温泉小镇泡温泉

### Day 2：风穴寺或二郎山

**方案 A（古建线）**：
- **上午**：风穴寺（1.5 小时）→ 汝州汝瓷体验
- **下午**：白龟湖湿地公园 → 返程

**方案 B（亲水线）**：
- **全天**：二郎山（游湖+栈道+灯台架）
