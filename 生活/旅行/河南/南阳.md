# 南阳

> "宛"城，诸葛亮躬耕之地，张仲景、张衡的故乡。卧龙岗的草庐、内乡县衙的官文化、西峡的恐龙与老界岭的云海，让南阳文武兼备。

## 🎯 城市速览

- **定位**：豫西南中心城市、医圣/科圣故里、南水北调中线渠首
- **核心看点**：卧龙岗武侯祠、医圣祠、内乡县衙、西峡恐龙园、老界岭、宝天曼、南阳府衙、汉画馆
- **最佳季节**：4–5 月、9–11 月（老界岭避暑/赏秋）；夏季山区凉爽
- **建议游玩**：3 天

## 🏞️ 景点卡片

### 卧龙岗武侯祠

- **位置**：南阳市卧龙区
- **特色看点**：诸葛亮"躬耕南阳"、刘备"三顾茅庐"处；诸葛草庐、武侯祠、三顾堂、抱膝石；"臣本布衣"的出典地
- **门票参考价**：¥46（学生¥25，夜场¥26.9）
- **开放时间**：8:00–18:00
- **建议时长**：2 小时
- **交通**：市区公交"卧龙岗"站
- **贴士**：三国迷必到；夜场沉浸式演出有新意

### 医圣祠（张仲景博物院）

- **位置**：南阳市宛城区
- **特色看点**：医圣张仲景墓祠，《伤寒杂病论》文化；中医文化展陈、仲景像
- **门票参考价**：¥23.8
- **开放时间**：8:00–17:30
- **建议时长**：1.5 小时
- **交通**：市区公交可达
- **贴士**：中医文化寻根；与南阳府衙同城

### 内乡县衙

- **位置**：南阳市内乡县
- **特色看点**：保存最完整的清代县级官署，"一座内乡衙，半部官文化"；大堂、二堂、三堂、刑钱夫子院
- **门票参考价**：¥75（学生¥37）
- **开放时间**：8:00–17:30
- **建议时长**：2 小时
- **交通**：内乡公交/自驾导航"内乡县衙"
- **贴士**：古建+官制文化；与南阳府衙对比有趣

### 西峡恐龙园

- **位置**：南阳市西峡县
- **特色看点**：恐龙蛋化石宝库，恐龙馆、仿真恐龙、亲子乐园；"恐龙之乡"科普游
- **门票参考价**：¥70（学生¥34）
- **开放时间**：8:00–17:30
- **建议时长**：半天
- **交通**：西峡公交/自驾导航"西峡恐龙园"
- **贴士**：亲子首选；与老界岭同日游

### 老界岭

- **位置**：南阳市西峡县
- **特色看点**：伏牛山主峰，海拔 2212 米，原始森林、云海、避暑；索道上下省力
- **门票参考价**：¥39.9（含交通）+索道另计
- **开放时间**：8:00–17:30
- **建议时长**：1 天
- **交通**：西峡景区直通车/自驾导航"老界岭"
- **贴士**：夏季避暑、秋季彩林；索道看云海

### 宝天曼

- **位置**：南阳市内乡县
- **特色看点**：世界生物圈保护区，原始森林、瀑布、珍稀动植物；徒步与生态研学
- **门票参考价**：¥39.9
- **开放时间**：8:00–17:30
- **建议时长**：1 天
- **交通**：内乡公交/自驾
- **贴士**：与内乡县衙组合；生态爱好者友好

### 南阳府衙

- **位置**：南阳市宛城区
- **特色看点**：保存较好的清代知府衙门，与内乡县衙"府—县"呼应
- **门票参考价**：免费
- **开放时间**：8:00–17:30
- **建议时长**：1 小时
- **交通**：市区公交可达
- **贴士**：与医圣祠、卧龙岗同城半日游

### 南阳汉画馆

- **位置**：南阳市卧龙区
- **特色看点**：汉画像石专题馆，天文图、车马出行、乐舞百戏等；汉文化瑰宝
- **门票参考价**：免费
- **开放时间**：9:00–17:00（周一闭馆）
- **建议时长**：1.5 小时
- **交通**：市区公交可达
- **贴士**：与卧龙岗相邻；汉文化爱好者必看

## 🍜 南阳味道

南阳黄牛肉（酱卤/牛肉汤）、镇平烧鸡、新野板面、博望锅盔、淅川粉蒸肉、方城烩面、唐河肘子。
