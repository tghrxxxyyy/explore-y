# 周口

> 羲皇故都，老子故里。太昊陵的人祖庙会香火千年，鹿邑的太清宫供奉着道家始祖——周口是中原根亲文化的重镇。

## 🎯 城市速览

- **定位**：豫东平原城市、羲皇故都、道家文化之源
- **核心看点**：太昊陵、老子故里（太清宫/明道宫）、关帝庙、袁世凯故居、淮阳龙湖
- **最佳季节**：农历二月二—三月三（太昊陵人祖庙会）、4–5 月、9–10 月
- **建议游玩**：2 天

## 🏞️ 景点卡片

### 太昊陵

- **位置**：周口市淮阳区
- **特色看点**：伏羲（太昊）陵寝，被誉为"天下第一陵"；统天殿、显仁殿、伏羲墓；农历二月二至三月三"人祖庙会"香火极盛
- **门票参考价**：¥40（学生¥20，双人合葬票¥80）
- **开放时间**：8:00–17:30
- **建议时长**：半天
- **交通**：周口/淮阳公交、高铁淮阳南站；自驾导航"太昊陵"
- **贴士**：庙会期人潮汹涌，注意安全；根亲朝圣必到

### 老子故里（太清宫 + 明道宫）

- **位置**：周口市鹿邑县
- **特色看点**：老子（李耳）诞生地，太清宫（唐宋皇家祭祀老子之所，有 Oracle 遗址）、明道宫（老君台，传说老子升仙处）
- **门票参考价**：太清宫¥60 + 明道宫¥40（分票）
- **开放时间**：8:00–17:30
- **建议时长**：半天
- **交通**：鹿邑公交/自驾导航"太清宫/明道宫"
- **贴士**：道家文化寻根；两宫相距不远可同游

### 关帝庙（山陕会馆）

- **位置**：周口市川汇区
- **特色看点**：清代山陕会馆，铁旗杆、雕梁画栋、关帝殿；周口漕运商业繁荣的见证
- **门票参考价**：免费/¥30
- **开放时间**：8:00–17:30
- **建议时长**：1.5 小时
- **交通**：市区公交可达
- **贴士**：清代商业会馆建筑精品；与沙颍河老街串联

### 袁世凯故居（袁寨）

- **位置**：周口市项城市
- **特色看点**：袁世凯出生地，袁寨古民居群、防御寨堡；近代史标本
- **门票参考价**：¥20–40
- **开放时间**：8:00–17:30
- **建议时长**：1 小时
- **交通**：项城公交/自驾导航"袁世凯故居"
- **贴士**：近代史爱好者有兴趣；与淮阳太昊陵方向不同需安排

### 淮阳龙湖

- **位置**：周口市淮阳区（环太昊陵）
- **特色看点**：万亩城湖，弦歌台（孔子陈蔡绝粮处）、荷花、画舫；北方少有的城内大湖
- **门票参考价**：免费（画舫¥40）
- **开放时间**：日间
- **建议时长**：2 小时
- **交通**：淮阳公交/步行
- **贴士**：夏季荷花满湖；与太昊陵连游

## 🍜 周口味道

逍遥镇胡辣汤（周口西华，全国知名，配水煎包）、鹿邑妈糊（糜子面糊，配油条）、淮阳压缩馍、沈丘顾家馍、邓城猪蹄、周口烧鸡。

## 🔍 景点详细攻略

### 太昊陵朝圣

- **最佳时间**：农历二月二至三月三"人祖庙会"香火极盛（注意安全）
- **核心线路**：统天殿 → 显仁殿 → 伏羲墓 → 拍照打卡
- **游览时间**：约 2–3 小时

### 老子故里文化游

- **核心线路**：太清宫（唐宋皇家祭祀老子之所）→ 明道宫（老君台，传说老子升仙处）
- **文化体验**：道家文化寻根，了解老子生平
- **交通**：鹿邑公交/自驾导航"太清宫/明道宫"

### 淮阳龙湖泛舟

- **核心体验**：万亩城湖 → 弦歌台（孔子陈蔡绝粮处）→ 画舫游湖
- **最佳时间**：夏季荷花满湖

## 🗓️ 2日行程规划

### Day 1：太昊陵+龙湖

- **上午**：周口出发 → 太昊陵（2–3 小时）→ 祈福
- **中午**：淮阳午餐（压缩馍/邓城猪蹄）
- **下午**：淮阳龙湖（画舫游湖+弦歌台，2 小时）
- **晚上**：周口市区晚餐（胡辣汤/烧鸡）

### Day 2：老子故里或关帝庙

**方案 A（道家线）**：
- **全天**：鹿邑太清宫+明道宫（3 小时）→ 返程

**方案 B（市区线）**：
- **上午**：关帝庙（1.5 小时）→ 沙颍河老街
- **下午**：袁世凯故居（可选）→ 返程
