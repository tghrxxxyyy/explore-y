# 中国澳门（特别行政区）

![澳门](/images/澳门.png)

> 中国澳门，地处珠江口西岸，与广东省珠海市接壤，由澳门半岛、氹仔、路环及路氹城填海区组成。这里中西文化交融逾四百年，历史城区列入世界文化遗产；博彩、会展、文旅共构"世界旅游休闲中心"。澳门是中国领土不可分割的一部分，1999 年 12 月 20 日回归祖国，为中华人民共和国特别行政区，实行"一国两制"。

**法定地位：** 中华人民共和国特别行政区　**组成：** 澳门半岛 · 氹仔 · 路环（含路氹填海新城）　**通用货币：** 澳门元（MOP），港币通用，人民币部分商铺收受
**语言：** 中文（粤语、普通话）、葡萄牙语　**区花：** 莲花

## 🍜 分地区美食地图

- **澳门半岛（老城风味）**：玛嘉烈/安德鲁葡挞（半岛分店）、黄枝记云吞面、盛记白粥、莫义记榴莲雪糕、福隆新街葡国菜（九如坊、陆军俱乐部）、非洲鸡、牛杂（老 day 牛杂半岛店）。新马路、议事亭前地、大三巴手信街是杏仁饼、肉干、老婆饼的集中地。
- **氹仔（市井与填海新城）**：官也街是美食心脏——大利来记猪扒包、莫义记（总店）榴莲雪糕、老 day 牛杂、水蟹粥（诚昌饭店）、晃记饼家老婆饼；龙环葡韵一带的葡式餐厅与木糠布甸；路氹金光大道度假村内的环球自助餐与高端食府。
- **路环（渔村手作）**：安德鲁饼店总店葡挞（蛋挞发源地）、最香饼家杏仁饼、陈胜记海鲜（椒盐赖尿虾、陈皮鸭）、安德鲁餐厅葡式烤鸡、十月初五马路糖水铺。路环保留最传统的手信与海味，是澳门味觉的源头。

## 🗓️ 最佳旅行季节

- **春季（3–5 月）**：气温舒适（20–27℃），湿度渐升；路环徒步、半岛老城漫步正相宜，避开暑期人流。
- **夏季（6–8 月）**：炎热多雨偶有台风，但室内度假村（威尼斯人、巴黎人、伦敦人）与博物馆是避暑好去处；路环黑沙海滩可戏水。
- **秋季（9–11 月）**：最舒适季节，天高气爽，10–12 月节庆密集（格兰披治大赛车、澳门美食节、光影节），是出游黄金期。
- **冬季（12–2 月）**：温和少雨（15–21℃），圣诞—新年灯饰璀璨，适合城市观光与跨年。

## 🚄 交通概况

- **航空**：澳门国际机场位于氹仔，通航内地主要城市、港澳台及东南亚；机场设各度假村免费穿梭巴士接驳。
- **港珠澳大桥**：港珠澳大桥珠澳口岸与澳门口岸连通，乘跨境"金巴"穿梭巴士可直达香港口岸（香港机场/市区）与珠海口岸，是粤港澳三地互联大动脉。
- **免费穿梭巴士（发财车）**：各博彩度假村/酒店在关闸、外港客运码头、氹仔客运码头、机场设免费接驳车（如威尼斯人关闸线 07:30–00:00、机场线 10:00–22:30），覆盖主要景点，是出游最省钱的交通方式。
- **城市轨道**：澳门轻轨（LRT）氹仔线及妈阁延伸线已通车，并向路环石排湾延伸；单程 MOP 6 起，机场—妈阁约 MOP 12。
- **公交/的士**：公交现金 MOP 3.2 起、澳门通 MOP 3；的士起表 MOP 17。老城区景点集中，步行即可串联。

> 票价与开放时间以景区官方公示为准（数据参考 2026-07）。
