# 海南（省）

![海南](/images/海南.png)

> 热带海岛，自贸港，阳光沙滩与椰林。北纬 18° 的碧海蓝天，黎苗风情与南洋记忆在此交织——东线的椰风海韵、南线的度假天堂、西线的原始海岸、中部的热带雨林，构成了中国唯一全省皆景的度假胜地。

**省会：** 海口　**特点：** 全域热带海岛、自贸港核心；东线滨海度假（三亚/万宁/陵水）、西线原生态海岸（儋州/昌江/东方）、中部雨林山地（五指山/保亭/琼中）、南端航天与宗教地标（文昌/南山）；椰子鸡、清补凉、文昌鸡、海鲜四季不断

## 🍜 美食地图（按片区）

- **琼北（海口 / 澄迈 / 定安 / 临高）**：海口老爸茶（糕点、咖啡、鹧鸪茶）、海南粉、文昌鸡（海口也常吃）、澄迈白莲鹅、定安骨头汤/定安粽子、临高烤乳猪、临高渔歌调声伴海鲜；骑楼水巷口的小吃（辣汤饭、炸排骨、清补凉）是早餐天堂
- **琼东（琼海 / 文昌 / 万宁 / 屯昌）**：文昌鸡（白切蘸蒜泥）、文昌抱罗粉、东郊椰林椰子宴、琼海杂粮甜品（清补凉、芒果肠粉）、万宁和乐蟹、万宁东山羊、后安粉、兴隆南洋风味（咖喱鸡、沙爹、印尼糕）、屯昌黑猪
- **琼南（三亚 / 陵水 / 保亭 / 五指山 / 乐东）**：三亚海鲜加工（和乐蟹、基围虾、芒果螺）、陵水酸粉、陵水圣女果、保亭五脚猪、三色饭（黎苗特色）、五指山野菜/蚂蚁鸡、乐东腰果；椰子鸡火锅、清补凉是全岛标配
- **琼西（儋州 / 东方 / 昌江 / 白沙 / 琼中）**：儋州米烂、东坡肉、光村沙虫、千年古盐田盐焗海鲜、东方四更烤乳猪、昌江乌烈乳羊、白沙绿茶、黎家竹筒饭、琼中绿橙；西线海鲜便宜新鲜，椰香与黎味交织

## 🗓️ 最佳旅游季节

- **春季（3–5 月）**：气温宜人（25–30℃），西沙风浪渐小适合邮轮；中部雨林（呀诺达/五指山）新绿盎然；避开清明后渐热的暑期前奏，性价比高
- **夏季（6–8 月）**：全岛炎热（30℃+）且多台风，但万宁日月湾、三亚后海进入冲浪黄金浪季；室内项目（航天科普、博物馆、海花岛水上王国夜场）友好；暑期亲子客流大，价格偏高
- **秋季（9–11 月）**：暑热消退、台风减少，是最佳过渡季；文昌常迎来火箭发射观礼、琼海博鳌论坛年会季，海滩重新舒适
- **冬季（12–2 月）**：海南旅游绝对旺季，海口/三亚/万宁避寒正当时，北方"候鸟"云集；气温 20–27℃，下海游泳、潜水、骑行皆宜，建议提前订房

## 🚄 交通概况

- **航空**：海口美兰国际机场（全省枢纽，连接内陆与东南亚）、三亚凤凰国际机场（南部枢纽，西沙邮轮母港所在地）；博鳌机场（琼海，支线）；三沙永兴机场仅限公务/探亲包机
- **高铁/动车**：海南环岛高铁闭环成网——东线（海口—文昌—琼海—万宁—陵水—三亚，约 2 小时）、西线（海口—儋州—东方—崖州—三亚），"3 小时环岛"轻松达成；三亚还有绕城与通往育才的支线
- **公路**：环岛旅游公路（G98 高速+滨海旅游公路）贯通东、西、南、北海岸，自驾/环岛骑行极受欢迎；中线高速（海口—屯昌—五指山—三亚）穿越热带雨林，风景壮丽
- **海运**：海口秀英港/新海港通往广东徐闻（粤海铁路轮渡）；三亚凤凰岛国际邮轮港为西沙邮轮（南海之梦号、长乐公主号）母港；清澜港有补给船（需审批）
- **城市内**：海口/三亚有公交与旅游专线；三亚、万宁、陵水等地租电动车/汽车方便；三沙仅邮轮与补给船可达，无普通公共交通
