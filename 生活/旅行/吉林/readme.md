## 🍜 美食地图

吉林菜（吉菜）粗犷鲜香，东部延边朝鲜族风味独树一帜：

- **中部（长春、吉林、四平、辽源）**：锅包肉、杀猪菜、满族八大碗、李连贵熏肉大饼（四平）、朝鲜冷面、雪衣豆沙、拔丝地瓜、人参鸡、鹿茸滋补锅（辽源）。
- **东部（通化、白山、延边）**：朝鲜冷面、石锅拌饭、辣白菜、打糕、高丽火盆（集安）、参鸡汤、明太鱼、延吉烧烤、米肠、紫菜包饭。
- **西部（松原、白城）**：查干湖胖头鱼（全鱼宴）、蒙古手把肉、烤全羊、奶食品、荞麦面、碱蓬草野菜。

## 🗓️ 最佳旅游季节

- **雾凇（吉林市）**：12 月下旬–2 月，零下 20℃ 左右、晴日清晨最佳。
- **避暑（长白山、延边、通化）**：6–8 月，均温 20℃ 左右，是东北"天然空调"。
- **滑雪（吉林市北大湖/万科松花湖、长白山）**：11 月下旬–3 月。
- **观鸟（向海、莫莫格）**：4–5 月（繁殖）、9–10 月（迁徙）。
- **红叶彩林**：9 月底–10 月中，长白山、蛟河红叶谷层林尽染。

## 🚆 交通概况

- **航空**：长春龙嘉国际机场（CZ 主基地，联通全国+日韩）、延吉朝阳川机场（东北亚航线）。
- **高铁/铁路**：京哈高铁贯穿长春、四平；长珲城际（长春—吉林—延吉—珲春）串起东部；沈佳高铁（部分通车）覆盖东部山地。
- **公路**：G1 京哈、G12 珲乌、G1112 集双、G302 等交织；G331 沿鸭绿江/图们江边境线（"吉线 331"）是自驾热门。
- **省内串联**：长春为中心枢纽，向东 2–4 小时可达延边/长白山；向西 2 小时到松原查干湖、3 小时到白城。
