## 🍜 美食地图

**辽中（沈阳 / 鞍山 / 辽阳 / 铁岭）**
老边饺子、锅包肉、李连贵熏肉大饼、沈阳鸡架、西塔朝鲜冷面、辽阳塔糖、铁岭火勺、铁锅炖、白肉血肠。鞍山南果梨、辽阳千山酒亦是一绝。

**辽南·大连 / 营口**
海胆、虾夷扇贝、鲍鱼、海肠、焖子、咸鱼饼子、鲅鱼饺子、海菜包子；营口烧烤、营口大酱、海鸭蛋、熊岳葡萄。大连的"海味+欧风"组合最出片。

**辽东（丹东 / 本溪 / 抚顺）**
丹东黄蚬子、朝鲜冷面、高丽火盆、草莓；本溪小市羊汤、铁锅炖鱼、烤豆皮；抚顺麻辣拌（全国起源地）、满族八大碗。东部山区山野菜、林蛙不可错过。

**辽西（锦州 / 葫芦岛 / 朝阳 / 阜新）**
锦州烧烤（万物皆可烤）、沟帮子熏鸡、锦州干豆腐；葫芦岛虹螺岘干豆腐、绥中白梨、海鲜饺子；朝阳烤鸽子、凌源豆腐脑、喀左羊汤；阜新荞面饸饹、喇嘛炖肉、蒙古馅饼、清河门烧鸡。

## 🗓️ 最佳旅游季节

- **夏季（6–8 月）**：大连/营口/葫芦岛海滨避暑，本溪水洞恒温 12℃ 消夏，朝阳凤凰山、抚顺筐子沟纳凉。
- **秋季（9–10 月）**：本溪关门山、桓仁枫林谷、医巫闾山红叶封神；盘锦红海滩碱蓬草转为炽红（9 月下旬–10 月中旬最佳）；丹东鸭绿江两岸层林尽染。
- **春季（4–5 月）**：丹东樱花/草莓、鞍山千山梨花、阜新海棠山杜鹃。
- **冬季（12–2 月）**：沈阳冰雪、温泉季（汤岗子、弓长岭、熊岳、兴城），葫芦岛海滨观冰排。

## 🚆 交通概况

- **航空**：沈阳桃仙国际机场（东北枢纽）、大连周水子国际机场，朝阳/锦州/丹东/营口/鞍山等有机场或近邻。
- **高铁**：哈大高铁纵贯（哈尔滨—长春—沈阳—大连），京沈高铁连通北京；沈丹、丹大、盘营等支线密集，沈阳到大连约 2 小时，到丹东约 1.5 小时。
- **公路**：沈海、京哈、丹锡、长深等高速成网，自驾串联辽东半岛与辽西走廊十分方便。
- **市内**：沈阳/大连地铁发达；其余城市公交+打车起步价 5–8 元，去郊县景区建议包车或拼车。
