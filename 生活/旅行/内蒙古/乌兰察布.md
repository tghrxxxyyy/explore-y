# 乌兰察布

> "中国草原避暑之都"，北京人周末的"后花园"。乌兰哈达的火山像外星地表，辉腾锡勒的风车矩阵转过花海——距离首都最近的草原与火山，夏天只有 20℃ 出头。

## 🎯 城市速览

- **定位**：内蒙古中部、京津冀夏避暑门户；草原火山、风电矩阵、高山草甸
- **核心看点**：乌兰哈达火山、辉腾锡勒草原（黄花沟）、格根塔拉草原、岱海、红石崖
- **最佳季节**：6–9 月避暑（7–8 月草原花海、风车）；9–10 月白桦与草原金黄
- **建议游玩**：2–3 天

## 🏞️ 景点卡片

### 乌兰哈达火山地质公园

- **位置**：察右后旗二广高速西侧
- **特色看点**：天然"火山博物馆"，典型的火山锥群（三号"北炼丹炉"、五号、六号"南炼丹炉"），黑色熔岩与草原同框，登火山口如抵外星；是 2026 内蒙古必打卡景点之一
- **门票参考价**：免费入园（景交/定制自驾游票 ¥60 起；部分平台显示门票 ¥60，以景区公示为准）
- **开放时间**：约 8:00–20:30
- **交通**：自驾/包车最佳（呼和浩特—火山直通车约 ¥98/人）；乌兰察布市区约 1 小时
- **贴士**：穿防滑鞋登火山；傍晚光线拍熔岩最出片；风大带外套；与辉腾锡勒可同线

### 辉腾锡勒草原（黄花沟草原旅游度假区）

- **位置**：察右中旗南部（辉腾锡勒意为"寒冷的高原"）
- **特色看点**：海拔约 2000 米的高山草甸，天然湖泊与风车矩阵遍布；黄花沟峡谷、缆车、小火车、骑马、诈马宴与《相会敖包》演出，是距北京最近的知名草原
- **门票参考价**：辉腾锡勒草原免费开放；黄花沟度假区 ¥90 起（含交通的畅游票 ¥294.9 双人/¥264.9 单人；骑马 ¥98 起）
- **开放时间**：草原全天；黄花沟 7:30–18:00
- **建议时长**：1 天
- **交通**：自驾/包车；呼和浩特—辉腾锡勒直通车；乌兰察布市区转乘
- **贴士**：海拔高、气温低，即使夏天也带薄外套；风车矩阵拍照绝美；想免费看草原可在非景区段停车

### 格根塔拉草原

- **位置**：四子王旗（距呼市/乌兰察布约 1.5–2 小时）
- **特色看点**：内蒙古最早开发的草原旅游点之一，"格根塔拉"意为"夏营盘"；骑马、乘驼、草原小火车、访牧户、那达慕与篝火，体验成熟
- **门票参考价**：观光车 ¥25–38（门市价约 ¥198 含多项；骑马/乘驼/卡丁车 3 选 1 约 ¥98）
- **开放时间**：8:30–17:30
- **建议时长**：半天–1 天
- **交通**：自驾/包车；部分旅行社直通车
- **贴士**：那达慕期间最热闹；与四子王旗大红山（免费）可同线

### 岱海

- **位置**：凉城县（距乌兰察布市区约 1 小时）
- **特色看点**：内蒙古闻名的内陆湖泊，湖光山色、候鸟栖息，可环湖休闲、水上活动，周边温泉资源
- **门票参考价**：¥28 起
- **开放时间**：约 8:00–18:00
- **建议时长**：2 小时
- **交通**：凉城县自驾/转乘
- **贴士**：与周边温泉、长城（明长城遗址）可组合；夏秋宜人

### 红石崖国家生态公园

- **位置**：卓资县（距市区约 1 小时）
- **特色看点**：红色砂岩崖壁与森林草甸相映，宗教（红石崖寺）特色浓郁，亲子友好、步道亲民
- **门票参考价**：¥60（约 ¥58 起）
- **开放时间**：约 8:00–18:00
- **建议时长**：2–3 小时
- **交通**：自驾/包车
- **贴士**：与辉腾锡勒、林胡古塞同属卓资—中旗一线，可组草原山水一日游

### 察尔湖 / 涝利海

- **位置**：兴和县（察尔湖）、商都/乌兰察布沿线（涝利海）
- **特色看点**：水库型生态湖，水鸟栖息、环湖步道，是京郊自驾游憩地；涝利海近火山线，常作为火山游补给点
- **门票参考价**：免费（部分游乐项目另计）
- **开放时间**：全天
- **建议时长**：1–2 小时
- **交通**：自驾导航"察尔湖"/"涝利海"
- **贴士**：与火山、草原串联成 2 日环线最舒服

## 🍜 城市味道

手把肉、羊肉烧麦、莜面窝窝、羊杂碎、冰煮羊、锅茶、奶豆腐、卓资山熏鸡、丰镇月饼。集宁（市区）老街、察右中旗/后旗草原上的牧家乐是吃蒙餐去处。

## 🔍 景点详细攻略

### 乌兰哈达火山地质公园

- **核心体验**：登火山口如抵外星；黑色熔岩与草原同框
- **最佳时间**：傍晚光线拍熔岩最出片；风大带外套
- **门票参考**：免费入园（景交/定制自驾游票 ¥60 起）
- **摄影建议**：穿防滑鞋登火山；广角拍火山锥群震撼
- **串联建议**：与辉腾锡勒草原可同线游览

### 辉腾锡勒草原（黄花沟）

- **核心体验**：海拔约 2000 米高山草甸 → 风车矩阵拍照 → 缆车/小火车 → 诈马宴/篝火
- **门票参考**：草原免费；黄花沟度假区 ¥90 起（畅游票 ¥294.9 双人）
- **最佳时间**：7–8 月草原花海最美
- **注意事项**：海拔高、气温低，即使夏天也带薄外套
- **免费方案**：想免费看草原可在非景区段停车

### 格根塔拉草原+那达慕

- **核心体验**：骑马/乘驼 → 草原小火车 → 访牧户 → 那达慕演艺 → 篝火晚会
- **那达慕大会**：夏季那达慕期间最热闹，可看赛马、摔跤、射箭
- **门票参考**：观光车 ¥25–38（门市约 ¥198 含多项）
- **串联建议**：与四子王旗大红山（免费）可同线

### 岱海温泉休闲

- **核心体验**：环湖步道 → 水上活动 → 周边温泉泡汤
- **门票参考**：¥28 起
- **串联建议**：与长城（明长城遗址）、红石崖可组合
- **最佳时间**：夏秋宜人

## 🗓️ 2日行程规划

### Day 1：火山+草原

- **上午**：乌兰哈达火山地质公园（登火山口+熔岩摄影，2.5 小时）
- **中午**：集宁市区午餐（手把肉/烧麦）
- **下午**：辉腾锡勒草原（风车矩阵+骑马+小火车，3 小时）
- **晚上**：草原蒙古包住宿 → 篝火晚会

### Day 2：草原深度体验

- **上午**：格根塔拉草原（骑马/乘驼/那达慕，半天）
- **中午**：草原午餐（烤全羊/锅茶）
- **下午**：岱海（环湖+温泉，2 小时）
- **晚上**：返回集宁 → 返程
