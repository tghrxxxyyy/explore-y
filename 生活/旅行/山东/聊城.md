# 聊城

> "江北水城、运河古都"。城中有湖、湖中有城，光岳楼守望六百年的东昌府，运河漕运记忆在博物馆与古会馆间流淌。

## 🎯 城市速览

- **定位**：鲁西运河名城、"中国北方的威尼斯"
- **核心看点**：光岳楼、东昌湖、山陕会馆、水城之眼摩天轮、中国运河文化博物馆、聊城水上古城
- **最佳季节**：4–5 月、9–10 月湖光宜人；夏季可夜游东昌湖
- **建议游玩**：1–2 天

## 🏞️ 景点卡片

### 光岳楼

- **位置**：东昌府区楼北大街 28 号（古城中央）
- **特色看点**：明代木构楼阁，"虽黄鹤、岳阳亦当望拜"，中国现存最古木构楼之一；登楼俯瞰古城与东昌湖
- **门票参考价**：¥30（学生¥15）；与山陕会馆/县署等联票¥79–129
- **开放时间**：8:30–17:30
- **建议时长**：1 小时
- **交通**：聊城古城内步行；公交"光岳楼"站
- **贴士**：聊城象征，登楼看"城湖一体"格局最佳；可与古城慢游结合

### 东昌湖

- **位置**：东昌府区湖滨路 2 号（环抱聊城古城）
- **特色看点**：中国北方最大城市内湖，"城中有湖、湖中有城"；可环湖骑行、乘船夜游+水舞光影秀
- **门票参考价**：湖滨免费；游船环湖¥50；夜游船+光影秀¥49.9 起
- **开放时间**：全天（游船日间+夜场）
- **建议时长**：1–2 小时（夜游更佳）
- **交通**：古城周边步行/公交
- **贴士**：傍晚—夜间乘船看灯光秀最出片；环湖绿道骑行舒服

### 山陕会馆

- **位置**：东昌府区双街 55 号
- **特色看点**：清代晋陕商人会馆，雕梁画栋、戏楼精美，运河商业繁荣的实物见证
- **门票参考价**：含在光岳楼联票内（单馆约¥20–30，以公示为准）
- **开放时间**：8:30–17:30
- **建议时长**：1 小时
- **交通**：古城内步行
- **贴士**：木石砖雕工艺极致，拍照细节多；与光岳楼 5 分钟步行

### 水城之眼摩天轮

- **位置**：东昌府区湖南路中段与南关街交叉口
- **特色看点**：全球首座"楼体结合"摩天轮，建在聊城地标建筑顶端，俯瞰全城湖光
- **门票参考价**：¥50（儿童¥29–40、老人¥25）；+360 极限飞球套票¥79
- **开放时间**：日间+夜场
- **建议时长**：0.5–1 小时
- **交通**：东昌湖东南岸；公交可达
- **贴士**：夜景俯瞰东昌湖灯火很美；恐高慎入

### 中国运河文化博物馆

- **位置**：东昌府区东昌西路 88 号
- **特色看点**：系统展示京杭大运河历史、漕运与聊城运河文化，展陈现代
- **门票参考价**：免费（需预约）
- **开放时间**：9:00–17:00（周一闭馆）
- **建议时长**：1.5–2 小时
- **交通**：聊城市区公交"运河博物馆"站
- **贴士**：逛古城前先来，更好理解"运河古都"；免费且质量高

## 🍜 聊城味道

聊城呱嗒（油炸馅饼）、临清烧麦、魏氏熏鸡、八批果子、高唐老豆腐、东昌府酱菜。呱嗒是聊城早餐代表，外酥里嫩、肉蛋馅香。
