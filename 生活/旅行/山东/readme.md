# 山东（省）

![山东代表风光](/images/山东.png)

> 齐鲁大地，孔孟之乡，黄河入海处。泰山雄峙、三孔庄严、泉城灵动、青岛浪漫、胶东海岸线绵延千里——一山一水一圣人，是山东最响亮的名片。

**省会：** 济南　**特点：** 山（泰山）· 水（泉城 / 黄河 / 大海）· 圣人（孔子），鲁菜为中国八大菜系之首，海滨与内陆风光兼具

## 🍜 美食地图（按片区）

- **鲁中（济南 / 淄博 / 泰安）**：济南菜（历下菜）为鲁菜源头——糖醋鲤鱼、九转大肠、把子肉、奶汤蒲菜、甜沫、油旋；泰安豆腐宴（泰山三美：白菜/豆腐/水）、泰山煎饼；淄博烧烤（小饼烤炉蘸料三件套）、周村烧饼、博山酥锅、博山豆腐箱
- **胶东半岛（青岛 / 烟台 / 威海 / 潍坊 / 日照 / 东营）**：海鲜主导——葱烧海参、油焖大虾、鲅鱼水饺、辣炒蛤蜊、海菜凉粉、威海清蒸海鲜；青岛啤酒、袋装散啤、烤鱿鱼；烟台苹果、莱阳梨、张裕葡萄酒；日照海鲜豆腐、文蛤；潍坊朝天锅、鸡鸭和乐
- **鲁南（济宁 / 枣庄 / 临沂 / 菏泽）**：孔府菜（诗礼银杏、带子上朝、一品豆腐）、曲阜熏豆腐、临沂炒鸡、糁汤（sa汤）、沂蒙煎饼、临沂塌煎饼、枣庄辣子鸡、菜煎饼、菏泽羊肉汤、水煎包、单县羊肉汤、郓城壮馍
- **鲁西北（德州 / 聊城 / 滨州）**：德州扒鸡、武城旋饼、聊城呱嗒、临清烧麦、魏氏熏鸡、滨州锅子饼、沾化冬枣、博兴麻大湖水产

## 🗓️ 最佳旅游季节

- **春季（4–5 月）**：泰山杜鹃、青岛樱花（中山公园）、菏泽牡丹（4 月上旬–5 月中旬盛花期）、潍坊国际风筝会（4 月），气候宜人
- **夏季（6–8 月）**：青岛 / 烟台 / 威海 / 日照海滨避暑正当时，海水浴场开放；内陆偏热，建议安排山区（泰山夜爬看日出、沂蒙山）
- **秋季（9–11 月）**：最舒适季节，泰山登高、红叶（红叶柿岩、黄河口芦花）、海鲜肥美，国庆后游客回落
- **冬季（12–2 月）**：青岛栈桥喂海鸥、曲阜雪中三孔别有韵味；泰山雪景雾凇壮观但路滑需装备

## 🚄 交通概况

- **航空**：济南遥墙、青岛胶东（山东最大枢纽）、烟台蓬莱、威海、临沂、济宁曲阜等主要机场；多数地级市通航
- **高铁/动车**：京沪高铁纵贯（天津—济南—泰安—曲阜—枣庄—徐州），胶济客专（济南—淄博—潍坊—青岛），青荣城际（青岛—烟台—威海），日兰高铁（日照—临沂—曲阜—菏泽）等，省内"2 小时交通圈"基本成型
- **公路**：高速路网密集，自驾友好；海滨城市（青烟威日）环海公路风景佳
- **城市内**：济南/青岛地铁成网；泰山、三孔、台儿庄等均有旅游专线/公交接驳
