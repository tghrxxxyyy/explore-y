# 双鸭山

> 完达山下的森林煤城，七星峰的险峻与雁窝岛湿地的辽阔在此交汇。作为北大荒核心腹地，这里既有原始林海，也有一望无垠的垦区沃野。

## 🎯 城市速览

- **定位**：黑龙江省东部资源型城市、重要的煤炭与粮食基地、森林湿地富集区
- **核心看点**：七星峰、青山国家森林公园、雁窝岛湿地、安邦河湿地、北大荒农机博览
- **最佳季节**：6–9 月（森林避暑、湿地观鸟）；9–10 月五花山色
- **建议游玩**：2 天

## 🏞️ 景点卡片

### 七星峰

- **位置**：双鸭山市集贤县（完达山脉中段）
- **特色看点**：完达山主峰之一，七座山峰如北斗排列，森林密布、怪石嶙峋；东北抗联重要根据地，含抗联遗址与纪念碑，登顶可俯瞰林海
- **门票参考价**：约 ¥30–40
- **开放时间**：8:00–17:00
- **建议时长**：大半天（登山 3–4 小时）
- **交通**：双鸭山/集贤包车前往；自驾导航"七星峰森林公园"
- **贴士**：登山穿防滑鞋；雨季路滑，体力一般者走缓坡栈道

### 青山国家森林公园

- **位置**：双鸭山市岭东区（市区东南）
- **特色看点**：完达山余脉的城市森林公园，原始红松与阔叶混交林、溪流瀑布、抗联密营遗址；负氧离子高，避暑与徒步佳
- **门票参考价**：约 ¥20–30
- **开放时间**：8:00–17:00
- **建议时长**：2–3 小时
- **交通**：市区公交/打车可达
- **贴士**：近郊一日氧吧；夏季清凉，自带饮水

### 雁窝岛湿地

- **位置**：双鸭山市宝清县（挠力河国家级自然保护区）
- **特色看点**：北大荒腹地的处女湿地，芦苇连天、水鸟翔集，可见丹顶鹤、白鹳等珍稀鸟类；"棒打狍子瓢舀鱼"的垦区原生态写照
- **门票参考价**：约 ¥20–40
- **开放时间**：8:00–17:00（季节性）
- **建议时长**：2–3 小时
- **交通**：宝清县包车；自驾导航"雁窝岛"
- **贴士**：最佳观鸟在清晨黄昏；蚊虫多，备驱蚊与长袖

### 安邦河湿地

- **位置**：双鸭山市集贤县（市区西北）
- **特色看点**：城市近郊的河流型湿地，木栈道穿行芦荡，科普馆展示湿地生态；亲子观鸟与休闲步道友好
- **门票参考价**：约 ¥20（低价/免费时段以公示为准）
- **开放时间**：8:00–17:00
- **建议时长**：1.5–2 小时
- **交通**：市区包车/公交
- **贴士**：亲子半日游；夏季荷花与候鸟看点足

## 🍜 双鸭山味道

东北铁锅炖、杀猪菜、黑龙江江鱼、山野菜、黏豆包、垦区大米饭包。北大荒菜系分量足、原生态，农场周边最地道。

## 一、景点详细攻略

### 1. 七星峰
- **最佳路线**：入口→登山步道→抗联遗址→山顶观景台（俯瞰林海）
- **最佳时间**：夏季6-8月避暑，秋季9-10月红叶
- **拍照机位**：山顶（林海全景）、抗联遗址（红色印记）、怪石嶙峋
- **贴士**：完达山主峰之一，七座山峰如北斗排列

### 2. 青山国家森林公园
- **最佳时间**：夏季6-8月避暑
- **拍照机位**：原始红松林（森林氧吧）、溪流瀑布、抗联密营遗址
- **贴士**：近郊一日氧吧，负氧离子高

### 3. 雁窝岛湿地
- **最佳时间**：清晨/黄昏观鸟
- **拍照机位**：芦苇荡（生态大片）、水鸟（长焦特写）
- **贴士**：北大荒腹地的处女湿地，蚊虫多备驱蚊

### 4. 安邦河湿地
- **最佳时间**：夏季荷花与候鸟
- **拍照机位**：木栈道（芦荡风光）、科普馆
- **贴士**：亲子半日游首选

## 三、交通指南

### 1. 航空
- 双鸭山友谊机场，距市区约40公里
- 机场大巴/打车

### 2. 高铁/火车
- 双鸭山站：佳双铁路，佳木斯出发约1小时
- 双鸭山西站：高铁停靠

### 3. 市内交通
- 公交：¥1-2，覆盖市区
- 打车：起步价¥6

### 4. 周边交通
- 七星峰：双鸭山/集贤包车
- 雁窝岛：宝清县包车

## 七、2日行程规划

### Day 1
- **上午**：七星峰（半天，登山+抗联遗址）
- **午餐**：集贤农家菜
- **下午**：青山国家森林公园（2小时）
- **晚餐**：东北铁锅炖
- **晚上**：市区散步

### Day 2
- **上午**：雁窝岛湿地（半天，观鸟+芦苇荡）
- **午餐**：宝清县
- **下午**：安邦河湿地（2小时）→科普馆
- **晚餐**：杀猪菜+大米饭包
- **晚上**：返回
