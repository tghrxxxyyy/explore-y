# 云南（省）

![云南](/images/云南.png)

> 彩云之南，动植物王国，多民族大观园。从昆明的四季春城到香格里拉的雪山草甸，从大理的风花雪月到西双版纳的热带雨林，从元阳的千年梯田到腾冲的火山热海——26 个民族在此共生，立体气候孕育出"一山分四季、十里不同天"的奇景，是中国最富体验层次的旅行目的地之一。

**省会：** 昆明　**特点：** 高原山地省份、低纬气候宜人（"春城"为代表）；少数民族种类全国最多；动植物资源极丰富（"植物王国""动物王国"）；滇菜兼收川黔粤味又自成"鲜、酸、辣、香"体系，过桥米线、野生菌、汽锅鸡、傣味、宣威火腿闻名天下

## 🗓️ 最佳旅行季节

- **春季（3–5 月）**：罗平油菜花海（2–3 月盛花）、大理樱花/苍山杜鹃、昆明蓝花楹（4–5 月）、西双版纳泼水节（4 月 13–15 日）；气候舒爽
- **夏季（6–8 月）**：云南多数地区凉爽宜人，是天然避暑地；普者黑荷花、香格里拉草原碧绿、抚仙湖戏水正当时；雨季（6–9 月）山区多阵雨，虎跳峡/怒江峡谷水势最壮但需注意地质灾害
- **秋季（9–11 月）**：最舒适季节，腾冲银杏村（11 月金黄）、香格里拉秋色、元阳梯田开始灌水（11 月起）、腾冲界头秋收；国庆后游客回落
- **冬季（12–2 月）**：西双版纳、元江等地避寒正旺；昆明翠湖/滇池红嘴鸥（11 月–次年 3 月）是经典画面；梅里雪山、玉龙雪山观景概率高，香格里拉大雪但游客少

## 🚄 交通概况

- **航空**：昆明长水国际机场为全省枢纽（通达全国及东南亚）；支线机场覆盖丽江、大理、西双版纳、香格里拉（迪庆）、腾冲、保山、普洱、临沧、昭通、文山、芒市（德宏）等地，地州通飞便捷
- **高铁/动车**：昆明为中心——成昆客专（昆明—楚雄—大理—丽江）、沪昆高铁（昆明—曲靖—贵阳—长沙）、云桂高铁（昆明—弥勒—普者黑—文山—南宁）、中老铁路（昆明—玉溪—普洱—西双版纳—磨憨）；大理—丽江、大理—保山—腾冲方向铁路已贯通
- **公路**：高速路网"能通全通"，自驾串联滇西北、滇西、滇南景区便利；怒江、迪庆部分山区仍为盘山路，雨季谨慎
- **城市内**：昆明地铁成网（已通 1–6 号线等）；丽江、大理、西双版纳有公交+旅游专线+景区直通车；多数古城/古镇步行可达，环洱海、环滇池有观光巴士与骑行道

> 票价与开放时间以景区官方公示为准（数据参考 2026-07）。60 周岁以上老人、6 周岁（或 1.2 米）以下儿童、现役军人、残疾人等多享免票或半价，出行请带好证件。
