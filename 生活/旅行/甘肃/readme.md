# 甘肃（省）

![甘肃](/images/甘肃.png)

> 丝路黄金段，河西走廊的咽喉。黄土高原、青藏高原与内蒙古高原在此交汇，黄河穿城而过，祁连雪峰映照沙漠绿洲。敦煌壁画、麦积山石窟、嘉峪关雄城，丝路文明与多元民族风情交织，是一部可阅读的"露天历史长卷"。

**省会：** 兰州　**特点：** 黄河唯一穿城而过的省会；丝路枢纽与西北铁路/航空要冲；丹霞、大漠、石窟、草原地貌齐备；牛肉面香飘万里，多民族（回、藏、裕固、东乡等）文化交融

## 🍜 美食地图（按片区）

- **兰州及临夏（省会圈·回族风味）**：兰州牛肉面（一清二白三红四绿五黄，推荐磨沟沿/马子禄/陈香斋等老字号）、酿皮、灰豆子、牛奶鸡蛋醪糟（正宁路夜市）、甜醅子、手抓羊肉（临夏做法最负盛名）、河州包子、发子面肠
- **河西走廊（武威 / 金昌 / 张掖 / 酒泉 / 嘉峪关）**：肉食天下——手抓羊肉、烤全羊、羊肉垫卷子、嘉峪关烤肉、酒泉糊锅、张掖搓鱼面/炒炮仗、牛肉小饭、敦煌驴肉黄面、杏皮水；武威凉州熏醋、金昌羊肉垫卷子
- **天水及陇东南（天水 / 陇南 / 庆阳 / 平凉 / 定西）**：天水呱呱、酿皮、捞捞、浆水面、天水暖锅、陇南罐罐茶、武都橄榄油、庆阳饸饹面/土暖锅、平凉羊肉泡馍、静宁烧鸡、定西宽粉/马铃薯宴
- **甘南（藏餐）**：糌粑、酥油茶、手抓牦牛肉、藏包、酸奶、蕨麻猪肉；夏河、碌曲一带的藏式茶馆是体验高原生活的入口

## 🗓️ 最佳旅游季节

- **春季（4–5 月）**：天水麦积山烟雨、兰州桃花；河西走廊风沙渐弱，气候宜人；甘南草原初绿
- **夏季（6–8 月）**：最舒适出行期——甘南（拉卜楞寺/扎尕那/桑科草原）、陇南官鹅沟、平凉崆峒山、定西贵清山皆避暑胜地；河西走廊白天气温高但干燥，建议早晚游玩。7–8 月敦煌正午暴晒，需避开 12:00–16:00 户外
- **秋季（9–11 月）**：甘肃颜值巅峰——张掖丹霞色彩最艳、金塔胡杨金黄、甘南扎尕那秋色、陇南官鹅沟红叶；国庆后游客明显回落
- **冬季（12–2 月）**：敦煌（11 月–次年 4 月）游客极少、门票半价、酒店机票优惠，适合慢游丝路；嘉峪关雪落雄关、祁连山雪景壮美；甘南部分高海拔景区封山

## 🚄 交通概况

- **航空**：兰州中川国际机场（全省枢纽，通达全国主要城市，并衔接地铁/城际直达市区）、敦煌莫高窟机场、嘉峪关酒泉机场、张掖甘州机场、天水麦积山机场、庆阳机场、金昌金川机场等，多数地级市通航
- **高铁/动车**：兰新高铁纵贯河西走廊（兰州西—西宁—张掖西—嘉峪关南—敦煌—哈密—乌鲁木齐），宝兰高铁（兰州西—宝鸡南—西安北）东联中原，银兰高铁（银川—中卫—兰州）北通宁夏；兰州中川机场城际铁路"空铁联运"；兰州西站为西北核心枢纽之一
- **普铁**：陇海（兰州—天水—西安）、兰新、包兰、干武等干线交汇兰州；敦煌铁路通动车
- **公路**：连霍高速（G30）横贯全境串联河西四郡，自驾友好；甘南、陇南山区道路多弯道，雨雪天谨慎
- **城市内**：兰州地铁 1/2 号线成网；敦煌、嘉峪关等景点分散，多依赖包车/拼车（西线尤为必要）

> 票价与开放时间以景区官方公示为准（数据参考 2026-07）。
