# 贵州（省）

![贵州](/images/贵州.png)

> 山地公园省，喀斯特王国。瀑布、溶洞、峡谷与少数民族村寨在此交织，夏季均温 23℃ 的"爽爽贵阳"闻名全国，苗侗布依风情、红色长征印记与"中国天眼"同处一省——一步一景，一餐一味。

**省会：** 贵阳　**特点：** 喀斯特地貌典型、少数民族（苗/侗/布依/彝等）荟萃、夏季避暑胜地、大数据枢纽；酸汤鱼、肠旺面、折耳根、丝娃娃等黔味鲜明，县县通高速、市市通高铁

## 🍜 美食地图（按片区）

- **黔中（贵阳 / 安顺 / 遵义）**：肠旺面（血旺+肥肠+红油）、牛肉粉、羊肉粉、恋爱豆腐果（折耳根蘸水）、丝娃娃（素春卷）、豆腐圆子、青岩卤猪脚、安顺裹卷、夺夺粉；遵义羊肉粉（虾子羊肉粉）、豆花面、鸡蛋糕、茅台镇酱酒。折耳根（鱼腥草）是黔味灵魂，几乎无处不在
- **黔东南（凯里 / 雷山 / 镇远 / 黎平）**：酸汤鱼（红酸汤以毛辣果发酵、白酸汤以米汤发酵）为招牌，另有牛瘪/羊瘪（"百草汤"）、侗族百家宴、腌鱼、糍粑、米豆腐、从江香猪。凯里酸汤鱼名扬全国，镇远道菜、黎平油茶亦不可错过
- **黔南（都匀 / 荔波 / 平塘）**：虾酸牛肉（独山三酸之一）、盐酸菜烧鱼、荔波酸肉、鱼包韭菜（水族名菜）、螺蛳肉、平塘坛子鱼；茶饮以都匀毛尖（绿茶上品）为代表，荔波野生杨梅汤清润消暑
- **黔西（毕节 / 六盘水 / 铜仁 / 黔西南）**：毕节汤圆、织金荞凉粉、威宁火腿、水城羊肉粉、盘县火腿、烙锅（贵州夜宵顶流）；铜仁米豆腐、锅巴粉、江口牛干巴、社饭；兴义羊肉粉、刷把头（形似烧麦）、鸡肉汤圆（咸口）、贞丰糯米饭。黔西重"辣、酸、香"，下饭下酒皆宜

## 🗓️ 最佳旅游季节

- **春季（3–5 月）**：百里杜鹃（3 月底–4 月底盛花期，全球最大原生杜鹃林）、贵安樱花园（3 月）、兴义万峰林油菜花海（2–3 月）、平坝农场樱花开，气候宜人，是贵州最"出片"的季节
- **夏季（6–8 月）**："爽爽贵阳"避暑正当时，全省均温多在 23–28℃，黄果树、荔波小七孔玩水，梵净山、乌蒙大草原、玉舍避暑，马岭河/杉木河/赤水漂流清凉刺激；也是苗族姊妹节、侗族大歌节密集期
- **秋季（9–11 月）**：最舒适季节，韭菜坪（8–9 月野韭菜花海）、梵净山层林尽染、万峰林稻浪翻金；国庆后游客明显回落，酸汤鱼最肥美
- **冬季（12–2 月）**：六盘水玉舍、乌蒙大草原滑雪场开放，是南方少有的冰雪度假地；西江千户苗寨、镇远古城年味浓（苗年、侗年、长桌宴）；温泉（剑河、石阡）驱寒，登山需防滑保暖

## 🚄 交通概况

- **航空**：贵阳龙洞堡国际机场（全省最大枢纽，通达全国主要城市及东南亚）；遵义茅台、安顺黄果树、铜仁凤凰、兴义万峰林、毕节飞雄、凯里黄平、荔波等支线机场，多数地级市可直飞或中转
- **高铁/动车**：贵阳是全国高铁枢纽之一——沪昆高铁（贵阳—安顺—盘州—昆明）、贵广高铁（贵阳—都匀—桂林—广州）、渝贵铁路（重庆—遵义—贵阳）、成贵高铁（成都—毕节—贵阳）、贵南高铁（贵阳—荔波—南宁）、铜玉城际等贯通，"市市通高铁"基本成型，省内主要景区多可"高铁+直通车"直达
- **公路**：县县通高速，是世界知名的"桥梁博物馆"（北盘江大桥、花江峡谷大桥等）；自驾串联瀑布、峰林、苗寨十分便利，山路多弯需谨慎
- **城市内**：贵阳地铁 1/2/3 号线成网；其余各市以公交+旅游直通车/景区专线接驳，西江、荔波、梵净山等设游客集散中心往返直通车

> 票价与开放时间以景区官方公示为准（数据参考 2026-07）。
