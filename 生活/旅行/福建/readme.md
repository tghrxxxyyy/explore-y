# 福建（省）

![福建代表风光](/images/福建.png)

> 东南沿海的"山海画廊"，海上丝绸之路起点与著名侨乡。武夷丹霞、福建土楼两大世界遗产在此辉映，闽菜清淡鲜醇、乌龙茶香飘万里，闽南红砖古厝、客家土楼与妈祖信俗交织出独特多元的地域文化。

**省会：** 福州　**特点：** 依山傍海、侨乡与海丝核心；世界遗产"武夷山+福建土楼"；闽菜（佛跳墙为首席）、乌龙茶（铁观音/大红袍/正山小种）与红砖古厝、客家土楼、妈祖文化多元并存

## 🍜 美食地图（按片区）

- **闽东（福州 / 宁德 / 莆田）**：福州鱼丸、肉燕、佛跳墙、荔枝肉、光饼、鼎边糊、芋泥、茉莉花茶；宁德大黄鱼、福鼎肉片、槟榔芋、继光饼、福安穆阳烤肉、古田银耳；莆田卤面、荔枝肉、海蛎煎、妈祖面、兴化米粉、焖豆腐（莆仙之别具一味）
- **闽南（厦门 / 漳州 / 泉州）**：沙茶面、海蛎煎、土笋冻、面线糊、花生汤、姜母鸭、烧肉粽；漳州卤面、手抓面、四果汤、东山小管、猫仔粥；泉州面线糊、牛肉羹、润饼、石花膏、深沪鱼丸、安海土笋冻、永春咯摊
- **闽西（龙岩 / 三明）**：龙岩簸箕粄、芋子包、永定牛肉丸、长汀豆腐干、连城地瓜干、涮九品、客家米酒；三明沙县小吃（拌面/扁肉/蒸饺/炖罐）、泰宁大金湖鱼、将乐擂茶、宁化客家八大碗、明溪肉脯干
- **闽北（南平）**：武夷山岚谷熏鹅、文公菜、朱子孝母饼、建瓯板鸭、建阳水吉扁肉、顺昌灌蛋、政和桂花茶，以及大红袍岩茶、正山小种等乌龙/红茶名品

## 🗓️ 最佳旅游季节

- **春季（3–5 月）**：武夷山茶香与杜鹃初绽、福州森林公园樱花、闽南滨海宜人、龙岩/三明山区春色正好，气温舒适少酷暑
- **夏季（6–8 月）**：沿海避暑首选（厦门、宁德海滨、平潭蓝眼泪 4–8 月）、山区清凉（武夷山、泰宁、白水洋戏水）、太姥山洞窟恒温如天然凉房；注意 7–9 月台风可能影响航班船班
- **秋季（9–11 月）**：全年最舒适，武夷山秋色层林、土楼周边稻田金黄、泉州开元寺银杏、闽西山区红叶，国庆后游客明显回落
- **冬季（12–2 月）**：厦门/漳州温暖如春；福州/厦门/连城等地温泉宜人；泉州民俗庙会、闽北山景清幽，适合慢游与品茶

## 🚄 交通概况

- **航空**：厦门高崎（全省最大枢纽）、福州长乐为双核心，另有泉州晋江、武夷山、龙岩冠豸山、三明沙县等支线机场，多数地级市可直飞或中转
- **高铁/动车**：合福高铁（合肥—武夷山—南平—福州）、福厦高铁（福州—莆田—泉州—厦门—漳州，最快约 1 小时直达）、杭深/厦深线、赣龙厦线、南三龙线等，省内基本形成"2 小时交通圈"
- **公路**：沈海、福银、厦蓉、泉南、长深等高速纵横，自驾串联山海与土楼景区便利
- **城市内**：福州/厦门地铁成网；其余城市以公交+旅游专线接驳景区间
- **轮渡**：厦门—鼓浪屿（邮轮中心厦鼓码头）、莆田—湄洲岛（文甲码头）、宁德—嵛山岛（渔井/三沙码头）为经典水上通道

> ⚠️ 票价与开放时间以景区官方公示为准（数据参考 2026-07）。60 周岁以上老人、6 周岁（或 1.4 米）以下儿童、现役军人、残疾人等多享免票或半价，出行请带好证件。
