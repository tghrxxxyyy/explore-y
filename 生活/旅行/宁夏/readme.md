# 宁夏回族自治区

![宁夏](/images/宁夏.png)

> 塞上江南，黄河滋养的绿洲。贺兰山屏蔽风沙，黄河水穿境而过，孕育出"天下黄河富宁夏"的奇观；西夏王朝在此留下苍凉王陵，回族风情与枸杞飘香交织，沙湖、沙坡头、六盘山串起大漠、黄河与绿洲的极致画卷。

**首府：** 银川　**特点：** 沿黄城市群核心、贺兰山东麓葡萄酒产区；西夏文明故地、回族之乡；手抓羊肉与枸杞闻名，大漠与黄河风光兼具

## 🍜 分地区美食地图

- **银川（首府风味）**：羊肉臊子面、手抓羊肉、烩羊杂（羊杂碎）、羊肉搓面、辣糊糊、糊饽、馓子、油香、八宝盖碗茶、凉拌沙葱；鼓楼/怀远夜市是宵夜聚集地
- **石嘴山（贺兰山麓）**：沙湖大鱼头、生氽面、黄渠桥羊羔肉、糖麻丫、冷串、凉粉；大武口凉皮与烤串也颇具口碑
- **吴忠（回族早茶城）**：吴忠早茶（羊杂碎配油香）、国强手抓、白水鸡、炒糊饽、馓子、八宝盖碗茶、辣糊糊；利通街夜市与光耀美食街最热闹
- **固原（南部山区）**：羊肉泡馍、烩羊杂、固原酿皮、荞麦饸饹面、燕面揉揉、蒸鸡、暖锅、土豆宴、蒿籽面；山区杂粮与羊肉最对味
- **中卫（黄河漠畔）**：蒿子面、清汤羊肉、酸菜羊肉粘饭、炒拉条、滚粉泡芋头、黄河鲤鱼、硒砂瓜、沙坡头苹果；"大漠味集·向阳街"可一网打尽

## 🗓️ 最佳旅行季节

- **春季（4–5 月）**：银川/石嘴山黄河岸桃花杏花次第开，中卫/吴忠风沙渐歇，气候宜人；固原六盘山新绿初染
- **夏季（6–8 月）**：北方最舒适季节，沙坡头、沙湖戏水避暑正当时；贺兰山、六盘山、火石寨山区凉爽，是亲子与户外旺季
- **秋季（9–11 月）**：最推荐季节，天高云淡、枸杞与硒砂瓜丰收，胡杨与腾格里沙漠金黄；国庆后游客明显回落
- **冬季（12–2 月）**：沙湖候鸟、黄河凌汛别有韵味；沙坡头可体验沙漠冰雪，中卫"星星的故乡"冬夜观星极佳，但风大需保暖

## 🚄 交通概况

- **航空**：银川河东国际机场（宁夏最大枢纽，通达全国主要城市），中卫沙坡头机场（支线），银川—西安等航线密集
- **高铁/动车**：银西高铁（银川—吴忠—西安，2020 通车）串起引黄灌区；包银高铁（在建/分段开通）连通阿拉善与包头方向；宝中铁路、太中银铁路过境，多数地市已入高铁/动车网
- **公路**：京藏、福银、青银、定武等高速路网密集，自驾串联沙湖—沙坡头—六盘山十分便利；滨河大道沿黄河风景佳
- **城市内**：银川地铁（1/2 号线）成网；各地公交+旅游专线接驳景区间，银川至镇北堡/沙湖有直通车

> 票价与开放时间以景区官方公示为准（数据参考 2026-07）。60 周岁以上老人、6 周岁（或 1.4 米）以下儿童、现役军人、残疾人等多享免票或半价，出行请带好证件。
