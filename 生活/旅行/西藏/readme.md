# 西藏（自治区）

![西藏](/images/西藏.png)

> 世界屋脊，雪域高原。这里有世界海拔最高的宫殿布达拉宫、最深的峡谷雅鲁藏布大峡谷、地球之巅珠穆朗玛，也有三大圣湖（纳木错、羊卓雍错、玛旁雍错）与神山冈仁波齐。从藏源雅砻到天上阿里，西藏是中国最辽阔、最神圣、也最令人心生敬畏的旅行目的地。

**首府：** 拉萨　**特点：** 平均海拔 4000 米以上；藏传佛教中心；雪山、圣湖、草原、林海、土林与冰川并存；川藏/青藏/新藏/滇藏多条进藏线交汇，进藏需关注高原反应与边防证

## 🍜 美食地图（按片区）

- **卫藏（拉萨 / 日喀则 / 山南）**：藏餐核心区——糌粑（青稞炒面捏团）、酥油茶、甜茶、藏面、牦牛肉包子、藏式酸奶、风干牦牛肉、蒸牛舌、藏式血肠；日喀则特色"朋必"（豌豆凉粉）、岗巴羊；拉萨甜茶馆文化是市井灵魂，推荐光明港琼、仓姑寺甜茶馆
- **藏北羌塘（那曲）**：游牧风味——风干牦牛肉（按斤售卖）、手抓羊肉、高原酸奶、奶渣、藏北血肠、酥油茶；夏季牧场可尝高原野菌汤；措那湖鱼极少入席，以肉乳为主
- **藏东康区（昌都）**：川藏交融——盐井"加加面"（一口一碗越吃越多）、芒康葡萄酒、昌都醉梨、牦牛肉干、藏式紫铜火锅、盐井天主教堂边的葡萄架；加查木碗盛食是工布—康区特色
- **林芝（工布）**：高原江南——鲁朗石锅鸡（墨脱石锅+手掌参+松茸，必吃）、雅鲁藏布江鱼、藏香猪、林芝松茸、荞麦饼、工布响箭配餐；近川味，辣子鸡、水煮鱼也常见
- **阿里**：简便高原食——风干肉、糌粑、酥油茶、噶尔苹果、普兰牦牛肉；物资相对稀缺，沿途建议自备高热量干粮与饮水

## 🗓️ 最佳旅游季节

- **春季（3–4 月）**：林芝桃花节（3 月下旬–4 月上旬盛放，嘎拉村、波密桃花沟最盛），雅江两岸桃林与雪山同框；拉萨/山南气候渐暖，游客较少
- **夏季（5–8 月）**：西藏旅游黄金期开端，草原碧绿、湖水最蓝；阿里/那曲进入最佳（6–9 月）；7–8 月为雨季，部分山路（如珠峰、萨普）易遇塌方，自驾需关注路况
- **秋季（9–10 月）**：**全年最舒适、最推荐**——天高云淡、雨水少、能见度高，珠峰/南迦巴瓦"日照金山"概率最高，胡杨与色林错候鸟登场；国庆后游客明显回落
- **冬季（11–4 月）**：阳光充足、门票优惠、人少，但高海拔景区（纳木错、珠峰部分时段、萨普）易受大雪封山；阿里/那曲严寒，仅适合有经验的旅人；拉萨冬日晒太阳别有韵味

> 综合建议：**5–10 月为西藏旅行的黄金窗口**，尤其 9–10 月兼顾天气与景色；进藏前建议预留 1–2 天适应海拔，避免剧烈运动与饮酒。

## 🚄 交通概况

- **航空**：拉萨贡嘎国际机场（位于山南贡嘎县，西藏最大枢纽，直飞国内主要城市）；另有日喀则和平机场、林芝米林机场、昌都邦达机场、阿里昆莎机场，多数地市已通航；那曲机场在建/规划中
- **铁路**：青藏铁路（西宁—格尔木—那曲—拉萨）是世界海拔最高的铁路，那曲、拉萨为主要站；拉日铁路（拉萨—日喀则）、拉林铁路（拉萨—山南—林芝，川藏铁路一段）已通车；进藏列车建议选白天班次赏可可西里风光
- **公路**：G318 川藏线、G109 青藏线、G219 新藏线（边境大通道）、G214 滇藏线等构成进藏网络；景区之间多以包车/拼车/旅游专线衔接；前往珠峰、阿里、山南洛扎等边境地带**需提前办理边防证**
- **城市内**：拉萨公交+打车便捷，老城区（八廓街一带）禁机动车需步行；其余地市景点分散，普遍依赖包车或自驾

> ⚠️ 票价与开放时间以景区官方公示为准（数据参考 2026-07）。60 周岁以上老人、儿童、现役军人、残疾人等多享免票或半价，出行请带好证件；高原地区注意防晒、保暖与防高反。
