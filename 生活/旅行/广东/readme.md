# 广东（省）

![广东代表风光](/images/广东.png)

> 岭南门户，改革开放前沿。这里是广府文化、潮汕文化与客家文化交汇之地，早茶烟火、海岸栈道与侨乡碉楼并存；粤港澳大湾区核心，四季常青、饮食精致，是中国最"好吃"也最宜居的省份之一。

**省会：** 广州　**特点：** 粤港澳大湾区核心、岭南文化中心；广府/潮汕/客家三大民系并存；早茶与粤菜发源地；海岸线绵长、海岛众多；华侨之乡，气候常年温暖湿润

## 🍜 美食地图（按片区）

- **广府片区（广州 / 佛山 / 深圳 / 珠海 / 东莞 / 中山 / 江门 / 肇庆 / 惠州 / 韶关 / 清远 / 阳江 / 茂名 / 湛江 / 云浮 等沿海及珠三角）**：粤菜本源——早茶点心（虾饺、烧卖、凤爪、叉烧包、肠粉）、白切鸡、烧鹅、脆皮乳鸽、老火靓汤、清蒸海鲜；广州"食在广州"、佛山顺德"世界美食之都"（双皮奶、均安蒸猪、鱼生）、潮汕以外最讲究食材本味
- **潮汕片区（汕头 / 潮州 / 揭阳 / 汕尾）**：牛肉火锅（现切吊龙、匙柄、五花趾）、潮汕卤水、蚝烙、粿条、肠粉、鸭母捻、工夫茶、砂锅粥、生腌（血蛤、虾蛄）；潮汕菜以"鲜、淡、巧"著称，小吃极丰，是粤菜重要分支
- **客家片区（梅州 / 河源 / 惠州部分 / 韶关客家县）**：盐焗鸡、酿豆腐、客家酿三宝、梅菜扣肉、盆菜、饺俚糍、黄酒（娘酒）、擂茶；口味偏咸香浓重，讲求实惠，与中原饮食一脉相承

## 🗓️ 最佳旅游季节

- **春季（3–5 月）**：气温回暖，回南天（"回南"潮湿）逐渐消退；适合逛古城、品早茶、踏青（肇庆七星岩、惠州西湖、韶关丹霞山）
- **夏季（6–8 月）**：炎热多雨，海滨（南澳岛、海陵岛、巽寮湾、东海岛、上下川岛）进入旺季；注意防台风（7–9 月为台风高发期，海岛航线易停航）
- **秋季（10–11 月）**：最舒适季节，秋高气爽、湿度下降，最适合全域旅行；国庆后游客回落，丹霞山、鼎湖山、罗浮山登高正宜
- **冬季（12–2 月）**：温暖少雨，是"避寒"热门；广府地区年均温高，粤北（韶关、清远）偶有低温，可泡温泉（清远、中山、云浮、江门）；避"回南天"首选此时

> 💡 避坑提示：广东"回南天"多在 2–4 月，墙壁出水、衣物难干；台风季 7–9 月，海岛游请密切关注气象与航线公告，预留改期余地。

## 🚄 交通概况

- **航空**：广州白云（全省最大枢纽，通达全球）、深圳宝安两大国际枢纽；珠海金湾、揭阳潮汕、湛江吴川、惠州平潭、韶关丹霞等支线机场；多数地级市 1 小时航程可达
- **高铁/动车**："市市通高铁"基本成型——京广高铁（北入湖南）、广深港高铁（连通香港西九龙）、广汕汕高铁（广州—汕尾—汕头—潮汕）、赣深高铁（江西—河源—深圳）、贵广/南广高铁（通广西、贵州）、梅汕高铁、广湛高铁（在建/分段通车）等，大湾区"1 小时生活圈"成熟
- **城际/地铁**：广佛、广清、穗莞深、广珠城际成网；广州、深圳地铁发达，佛山/东莞/珠海等接入城际
- **公路**：高速路网极密（沈海、京港澳、广昆、长深等），自驾串联海岸线与山区景区便利；跨珠江口有港珠澳大桥、南沙大桥等
- **水运**：珠江夜游（广州）、珠海—深圳—香港客轮、各海岛客滚轮渡（南澳、海陵、上下川、硇洲等）

> ⚠️ 票价与开放时间以景区官方公示为准（数据参考 2026-07）。60 周岁以上老人、6 周岁（或 1.4 米）以下儿童、现役军人、残疾人等多享免票或半价，出行请带好证件。
