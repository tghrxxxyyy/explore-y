# 宁波

> "书藏古今，港通天下。"天一阁的墨香、三江口的潮声、老外滩的霓虹，还有雪窦山的弥勒——宁波把千年藏书文化与东方大港的喧嚣，调成了一杯温润的甬城茶。

> ⚠️ 票价说明：天一阁、溪口等收费，老外滩 / 东钱湖 / 宁波博物馆免费；下列为 2026-07 参考价，以景区官方为准。

---

## 一、城市速览

- **城市特色**：港口名城（北仑港，全球货物吞吐量领先）、藏书文化（天一阁）、佛教（弥勒道场雪窦山）、甬商故里。
- **行政区划（景点分布）**：**海曙区**（天一阁、月湖、鼓楼）；**江北区**（老外滩、慈城）；**鄞州区**（东钱湖、博物馆）；**奉化区**（溪口、雪窦山）；**北仑**（港口）。
- **怎么去**：
  - 高铁：宁波站（市区），杭州约 1h、上海经杭州约 2h（或经沪甬跨海）。
  - 飞机：宁波栎社国际机场，地铁 2 号线直达市区。
- **最佳季节**：**春秋最佳**；春季奉化樱花、秋季桂花；夏季沿海可玩，台风留意。
- **本地特色美食**：宁波汤圆（缸鸭狗）、红膏呛蟹、糟货、雪菜黄鱼、油赞子、慈城年糕、溪口千层饼。
- **住宿建议**：住**海曙 / 三江口**（老城 + 商圈），逛老外滩方便；东钱湖周边有度假民宿。

## 二、城区的古与潮

### 天一阁 · 亚洲最古私家藏书楼
- **位置**：海曙区天一街 10 号（月湖畔）。
- **特色看点**：明兵部右侍郎范钦始建于 1561 年，中国现存最古私家藏书楼，世界最早三大家族图书馆之一；宝书楼、范氏故居、麻将起源地陈列馆、园林；书香 + 江南园林。
- **门票（参考）**：约 ¥27（老人 / 儿童优惠）。
- **开放时间**：约 8:30–17:30（冬季略短）。
- **建议时长**：2 小时。
- **交通**：地铁 2 号线"城隍庙"或公交"天一阁"站。
- **贴士**：爱书人圣地；与月湖公园、鼓楼串联成海曙半日游。

### 月湖 / 鼓楼 / 天宁寺塔
- **位置**：海曙区（市中心）。
- **特色看点**："浙东邹鲁"，月湖十洲烟水、贺秘监祠、银台第；鼓楼（唐代子城南门，现存城楼）与永丰库遗址；天宁寺唐宋塔。
- **门票**：免费 / 低价（以现场为准）。
- **建议时长**：1.5 小时。
- **交通**：地铁 2 号线"鼓楼"。
- **贴士**：月湖散步 + 鼓楼逛吃，老宁波慢生活。

### 老外滩（江北）
- **位置**：江北区三江口北岸（甬江 / 余姚江 / 奉化江交汇）。
- **特色看点**：1844 年开埠，比上海外滩还早；欧式老建筑改造成酒吧、餐厅、美术馆；天主教堂（哥特式）夜景；比上海外滩更安静有情调。
- **门票**：街区**免费**。
- **建议时长**：2 小时（傍晚–夜）。
- **交通**：地铁 2 号线"外滩大桥"站。
- **贴士**：入夜灯光 + 教堂最出片；酒吧聚餐氛围好；与"新外滩"三江口夜景相连。

### 宁波博物馆
- **位置**：鄞州区首南中路 1000 号。
- **特色看点**：王澍设计，"新乡土主义"代表作，瓦爿墙震撼；宁波历史 / 民俗 / 海上丝路展陈（免费，需预约）。
- **门票**：**免费，需预约**。
- **开放时间**：周二–周日 9:00–17:00（16:00 停止入馆），周一闭馆。
- **建议时长**：2 小时。
- **交通**：地铁 3 号线"鄞州区政府"步行。
- **贴士**：建筑本身就是展品；拍照出片；与南部商务区顺路。

## 三、东钱湖（城市绿心）

### 东钱湖 · 浙东明珠
- **位置**：鄞州区东钱湖镇（市区东南约 15 km）。
- **特色看点**：浙江最大淡水湖，小普陀、陶公岛、韩岭老街（文艺）、福泉山（茶山 + 海景）；骑行 / 游船 / 茶旅。
- **门票**：湖区**免费**；福泉山约 ¥46；部分小景点另计。
- **建议时长**：半日–1 日。
- **交通**：地铁 4 号线"东钱湖"站转公交 / 骑行。
- **贴士**：韩岭老街改造文艺、适合咖啡拍照；环湖骑行很舒服。

## 四、奉化 · 溪口—雪窦山（弥勒道场）

### 溪口—滕头旅游景区（联票）
- **位置**：奉化区溪口镇（市区西南约 40 km）。
- **特色看点**：蒋氏故里（丰镐房、玉泰盐铺、武岭门、文昌阁）+ 雪窦山（弥勒道场，雪窦寺、千丈岩瀑布、妙高台、三隐潭）；滕头村（生态村）；民国史 + 佛教名山。
- **门票（参考）**：溪口—滕头联票约 ¥205；雪窦山单独约 ¥150、蒋氏故居单独约 ¥120（以官方为准）。
- **开放时间**：约 8:00–17:00。
- **建议时长**：1 日（溪口 + 雪窦）。
- **交通**：宁波站 / 奉化站转公交 / 旅游专线；自驾约 1 小时。
- **贴士**：联票划算；雪窦山缆车 + 观光车省体力；蒋氏故居讲解值得听。

### 弥勒圣坛（雪窦山）
- **位置**：奉化区溪口雪窦山（雪窦寺旁）。
- **特色看点**：露天弥勒大佛（全球最高坐姿铜制弥勒之一）、弥勒圣坛；雪窦寺为弥勒道场（佛教五大名山之一）。
- **门票（参考）**：约 ¥60（含雪窦寺 / 圣坛，以官方为准）。
- **建议时长**：1.5 小时。
- **交通**：溪口景区内接驳。
- **贴士**：与雪窦山联游；香会日人多。

## 五、慈城与近郊

### 慈城古县城
- **位置**：江北区慈城镇（市区北约 15 km）。
- **特色看点**：江南唯一保存完整的古县城，孔庙、县衙、校士馆、慈城年糕馆；明清街巷格局完好。
- **门票**：古县城街区免费；小景点联票约 ¥50–75（以现场为准）。
- **建议时长**：半日。
- **交通**：地铁 4 号线"慈城"站。
- **贴士**：年糕是招牌，尝现做年糕；比市区安静。

### 象山 / 松兰山（滨海）
- **位置**：宁波市象山县（市区东南约 1.5h 车程）。
- **特色看点**：东海海滨，松兰山度假区、石浦渔港古城、中国渔村；开渔节（9 月）最热闹；海鲜盛宴。
- **门票**：石浦渔港古城约 ¥50；松兰山等另计（以现场为准）。
- **建议时长**：1–2 日（滨海游）。
- **交通**：自驾 / 大巴至象山。
- **贴士**：开渔节吃最鲜的海；与舟山隔海相望，可组合海岛游。

## 六、实用信息

- **经典 1 日（城区 + 溪口）**：上午天一阁 + 月湖 → 老外滩午餐 → 下午溪口（蒋氏故居）→ 夜回老外滩。
- **经典 2 日**：Day1 城区（天一阁 / 博物馆 / 老外滩）；Day2 雪窦山 + 弥勒圣坛。或换东钱湖 / 慈城。
- **交通贴士**：市区地铁 + 公交方便；溪口 / 象山建议自驾或旅游专线。
- **避坑**：海鲜按市价、问清单价再点；老外滩酒吧消费偏高；台风季（7–9 月）关注船期与景区开放。
- **联游**：舟山（轮渡 / 跨海大桥，普陀山朝圣）、绍兴（高铁 1h）、杭州（1h）。
