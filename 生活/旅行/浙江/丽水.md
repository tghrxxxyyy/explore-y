# 丽水

> "中国生态第一市，最后的江南秘境。"仙都的鼎湖峰刺破晨雾、云和梯田的镜面映着银河、古堰画乡的帆影、松阳老村的夯土墙——丽水是被《国家地理》偏爱的"浙江绿谷"，畲乡的歌声藏在山坳里。

> ⚠️ 票价说明：仙都、云和梯田、古堰画乡等收费，松阳古村多免费；下列为 2026-07 参考价，以景区官方为准。

---

## 一、城市速览

- **城市特色**：浙江面积最大、山地最多的市，"九山半水半分田"；生态环境顶级（负氧离子爆表）、梯田与古村云集；畲族自治（景宁）；"江南秘境"。
- **行政区划（景点分布）**：**莲都区**（古堰画乡、市区）；**缙云县**（仙都）；**青田县**（石门洞、侨乡）；**云和县**（梯田）；**龙泉市**（剑瓷、龙泉山）；**遂昌县**（金矿、千佛山）；**松阳县**（百余古村）；**景宁畲族自治县**（畲乡之窗）；**庆元县**（廊桥）。
- **怎么去**：
  - 高铁：丽水站（金丽温高铁），杭州约 1.5h、温州约 30min、上海约 2.5h；缙云西（近仙都）、青田、松阳等站。
  - 飞机：最近温州龙湾 / 义乌。
- **最佳季节**：**春秋最佳**；春季云和梯田灌水如镜（4–5 月）、仙都晨雾；秋季松阳晒秋、银杏；夏季山区避暑。
- **本地特色美食**：缙云烧饼、遂昌长粽、青田糖糕、畲族乌米饭、龙泉安仁鱼头、处州白莲、卷饼、炸土豆饼。
- **住宿建议**：仙居住**缙云 / 仙都**民宿、梯田住**云和**（看日出云海）、古村住**松阳**（夯土民宿闻名）、畲乡住**景宁**。

## 二、缙云 · 仙都

### 仙都 · 鼎湖峰
- **位置**：缙云县仙都街道（丽水北，高铁"缙云西"转，约 20 min）。
- **特色看点**："仙人荟萃之都"，鼎湖峰（170m 石柱拔地，号称"天下第一峰"）、朱潭山（老农牵牛过石板桥，经典晨雾大片）、倪翁洞、小赤壁、芙蓉峡；《仙剑》《花千骨》取景；黄帝祭典（缙云为黄帝文化中心）。
- **门票（参考）**：约 ¥70–85（含景交约 ¥90；学生 ¥40–60 / 儿童 ¥40–50 / 老人 ¥40–60；以官方为准）。
- **建议时长**：1 日（建议住一晚拍晨雾）。
- **交通**：缙云西站转公交 / 自驾。
- **贴士**：**清晨朱潭山牵牛雾景必拍**（很多摄影团守点）；黄帝祠宇祭典日人多；景交车串各点省力。

## 三、云和 · 梯田

### 云和梯田
- **位置**：云和县崇头镇（丽水西南，高铁"云和"转 / 自驾）。
- **特色看点**："中国最美梯田"之一，千米落差梯田，灌水期（4–5 月）如明镜、秋收（9–10 月）金黄；日出云海、七星墩、白银谷古村；"云和梯田"夜观星河。
- **门票（参考）**：约 ¥70（含索道套票约 ¥195；优待 ¥40；以官方为准）。
- **建议时长**：半日–1 日（建议住梯田民宿看日出）。
- **交通**：云和站转公交 / 自驾（盘山）。
- **贴士**：**日出 + 云海**是精华，住一晚值；灌水期镜面最出片；索道省爬山。

## 四、莲都 · 古堰画乡

### 古堰画乡
- **位置**：莲都区大港头镇（市区郊，瓯江畔）。
- **特色看点**："古堰"（通济堰，1500 年水利奇观，世界灌溉工程遗产）+ "画乡"（大港头，油画创作基地、江畔帆影、写生学生）；瓯江帆影、千年樟树群、古街。
- **门票（参考）**：约 ¥45（含双程船，单票约 ¥20；以官方为准）。
- **建议时长**：半日。
- **交通**：丽水站转公交 / 自驾。
- **贴士**：乘船过江连接古堰与画乡；江边写生、喝咖啡很惬意；通济堰看古代水利智慧。

## 五、龙泉 · 剑瓷与高山

### 龙泉山（凤阳山）
- **位置**：龙泉市（丽水西南，浙闽交界）。
- **特色看点**：浙江第二高峰（黄茅尖，海拔 1929m，长三角之巅），原始森林、绝壁奇松、云海日出、高山草甸；龙泉宝剑 / 青瓷文化（龙泉青瓷博物馆、宝剑厂）。
- **门票（参考）**：龙泉山约 ¥158（含索道 + 景交；单门票约 ¥80；以官方为准）。
- **建议时长**：1 日（登顶看云海）。
- **交通**：龙泉站 / 自驾。
- **贴士**：夏季避暑、登顶看日出；剑瓷爱好者访青瓷小镇（披云青瓷文化园）。

## 六、遂昌与松阳（古村秘境）

### 遂昌 · 千佛山 / 金矿
- **位置**：遂昌县（丽水西南）。
- **特色看点**：千佛山（天然释迦牟尼峰、未来寺石窟，山林禅意）；遂昌金矿国家矿山公园（明代采金遗址、黄金隧道、坐矿车）；南尖岩（云海梯田、竹海，摄影地）。
- **门票（参考）**：千佛山约 ¥65–68（优待 ¥40）；金矿约 ¥80；南尖岩约 ¥70（以官方为准）。
- **建议时长**：1 日（千佛 / 金矿二选一 + 南尖岩）。
- **交通**：遂昌站 / 自驾。
- **贴士**：金矿体验挖金 / 坐矿车有趣（亲子）；南尖岩云海摄影经典。

### 松阳 · 百余传统村落
- **位置**：松阳县（丽水中部，瓯江支流）。
- **特色看点**："最后的江南秘境"，100+ 保存完好的传统村落——杨家堂（"金色布达拉宫"，黄土夯墙梯田间）、陈家铺（平民书局，悬崖上的书店）、西坑、松庄村（石拱桥 + 溪流）；山间夯土民居 + 茶田。
- **门票**：古村多**免费**（个别体验收费）。
- **建议时长**：1–2 日（建议住陈家铺 / 杨家堂民宿）。
- **交通**：松阳站 / 自驾（山路）。
- **贴士**：**陈家铺平民书局**必去（悬崖书店出片）；杨家堂黄昏金色墙最绝；松阳是民宿 + 古村慢游天花板。

### 景宁 · 畲乡之窗
- **位置**：景宁畲族自治县（丽水南，浙江唯一畲族自治县）。
- **特色看点**：畲族文化，畲乡之窗（大均乡，畲族婚俗、歌舞、彩带编织）、畲族博物馆；山水 + 民族风情。
- **门票（参考）**：畲乡之窗约 ¥40（以官方为准，部分表演另计）。
- **建议时长**：半日。
- **交通**：景宁站 / 自驾。
- **贴士**：看畲族歌舞、尝乌米饭；与云和梯田顺路。

### 庆元 · 廊桥
- **位置**：庆元县（丽水西南，浙闽交界）。
- **特色看点**："中国廊桥之乡"，如龙桥、咏归桥等编木拱廊桥（与泰顺并列）；百山祖（冷杉、原始林、避暑）。
- **门票**：廊桥**免费**；百山祖约 ¥50（以官方为准）。
- **建议时长**：半日–1 日。
- **交通**：庆元站 / 自驾。
- **贴士**：廊桥爱好者与泰顺串成"浙闽廊桥线"；百山祖避暑 + 看珍稀冷杉。

### 青田 · 石门洞 / 侨乡
- **位置**：青田县（丽水东南，近温州，侨乡）。
- **特色看点**：石门洞（刘基读书处，瀑布 + 摩崖石刻）、千丝岩石文化公园（石雕）；"华侨之乡"，欧式建筑 + 咖啡文化浓厚。
- **门票（参考）**：石门洞约 ¥60（以官方为准）。
- **建议时长**：半日。
- **交通**：青田站 / 自驾。
- **贴士**：侨乡咖啡 + 石雕淘宝；与温州顺路。

## 七、实用信息

- **经典 2 日（仙都 + 古堰）**：Day1 仙都（鼎湖峰 + 朱潭山晨雾）；Day2 古堰画乡（莲都），宿市区。
- **经典 3 日（梯田 + 古村）**：Day1 云和梯田（日出）；Day2 松阳古村（陈家铺 + 杨家堂）；Day3 遂昌千佛 / 南尖岩。
- **交通贴士**：金丽温高铁通杭州 / 温州；仙都近缙云西最方便；古村 / 梯田 / 山区分散，自驾高效；山路弯多、慢开。
- **避坑**：梯田看季节（灌水 4–5 月、金黄 9–10 月），错峰更美；松阳古村民宿抢手、早订；山区天气多变，带雨具。
- **联游**：温州（30min）、金华（1.5h）、衢州（经江山）、福建武夷山（经庆元 / 松溪）。
