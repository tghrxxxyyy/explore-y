# 杭州

> "上有天堂，下有苏杭。"西湖的烟柳、灵隐的钟声、运河的桨声、数字经济的脉动——杭州把千年的江南诗意与最潮的互联网基因揉在了一起。

> ⚠️ 票价说明：西湖免费，灵隐等寺庙收香花券，西溪 / 雷峰塔 / 宋城等收费；下列为 2026-07 参考价，出行前以"杭州西湖风景名胜区" / 景区官方公众号或现场为准。

---

## 一、城市速览

- **城市特色**：西湖文化景观（世界遗产）、京杭大运河（世界遗产）、良渚古城（世界遗产）——杭州独拥 3 处世界遗产；数字经济（阿里、直播电商）高地。
- **行政区划（景点分布）**：核心在**西湖区 / 上城区**（西湖、灵隐、清河坊）；**拱墅区**（运河、桥西）；**滨江 / 萧山**（湘湖、杭州乐园）；代管**建德 / 富阳 / 临安 / 桐庐 / 淳安**（千岛湖在淳安）。
- **怎么去**：
  - 高铁：杭州东站（最大枢纽）、杭州站、杭州西站；上海约 1h、南京约 1.5h、宁波约 1h。
  - 飞机：杭州萧山国际机场，地铁 1/7 号线、机场大巴通达。
- **最佳季节**：**春秋最佳**——3–5 月桃柳新绿、太子湾郁金香；9–10 月满城桂花、秋高气爽；夏季西湖荷花开但炎热，冬季断桥残雪难得。
- **本地特色美食**：西湖醋鱼、龙井虾仁、东坡肉、叫花鸡、宋嫂鱼羹、片儿川、虾爆鳝面、猫耳朵、定胜糕；楼外楼、知味观、外婆家。
- **住宿建议**：想逛西湖住**湖滨 / 龙翔桥**（地铁 1 号线，步行到湖）；爱文艺住**青芝坞 / 四眼井**（西湖边民宿）；商务住**钱江新城**。

## 二、西湖（免费，世界遗产）

### 西湖 · 三面云山一面城
- **位置**：杭州西湖区（环湖，湖滨 / 断桥 / 苏堤 / 雷峰塔皆可达）。
- **特色看点**："淡妆浓抹总相宜"，十景（苏堤春晓、断桥残雪、平湖秋月、花港观鱼、曲院风荷、雷峰夕照等）；可步行 / 骑行 / 游船；断桥、白堤、苏堤、杨公堤串联；三潭印月需乘船登岛。
- **门票**：湖区**免费**（开放式）；三潭印月船票 + 岛约 ¥70（含往返船，以现场为准）。
- **开放时间**：全天（夜景灯光约 18:00–22:00）。
- **建议时长**：半日–1 日（环湖慢跑 / 骑行 1 圈约 10 km）。
- **交通**：地铁 1 号线"龙翔桥"步行至湖滨；环湖公交 / 自行车。
- **贴士**：早 7 点前断桥人少出片；骑行环湖最舒服；想避开人流去杨公堤 / 茅家埠更清幽。

### 雷峰塔
- **位置**：西湖风景区南山路（夕照山上，长桥旁）。
- **特色看点**："雷峰夕照"，《白蛇传》传说地；塔内可见旧塔遗址、壁画；登塔俯瞰西湖与净慈寺。
- **门票（参考）**：¥40。
- **开放时间**：约 8:00–17:30（冬季略短）。
- **建议时长**：1 小时。
- **交通**：公交 / 打车至"净寺"站。
- **贴士**：与净慈寺（南屏晚钟）挨着；傍晚看夕照最美。

### 灵隐寺 / 飞来峰
- **位置**：西湖区法云弄 1 号（西湖西北，飞来峰景区内）。
- **特色看点**："东南佛国"，始建于东晋，济公传说地；大雄宝殿、飞来峰石窟造像（五代–宋，国宝）、永福寺、韬光寺；山林幽深。
- **门票（参考）**：灵隐寺免费预约（需先购飞来峰景区门票约 ¥45 香花券 / 进山券，进寺另请香）；具体以官方为准。
- **开放时间**：约 7:00–18:00（夏季延长）。
- **建议时长**：2–3 小时。
- **交通**：公交 7/278 路"灵隐"站；地铁 + 接驳。
- **贴士**：先买飞来峰票再进寺；永福寺素斋有名；周末人极多，赶早。

### 西溪湿地
- **位置**：西湖区天目山路（蒋村，市区西）。
- **特色看点**："城市之肾"，《非诚勿扰》取景地；芦苇荡、摇橹船、秋雪庵、湿地植物；春季花朝、秋季芦花。
- **门票（参考）**：¥70（儿童 / 老人 ¥40）；摇橹船另计。
- **开放时间**：约 8:00–17:30。
- **建议时长**：半日。
- **交通**：地铁 3 号线"西溪湿地南"或公交。
- **贴士**：坐摇橹船进芦苇深处最惬意；洪园（西溪洪氏）在另一侧可联游。

## 三、运河与老街

### 京杭大运河（拱宸桥 / 桥西历史街区）
- **位置**：拱墅区拱宸桥—桥西（运河东岸）。
- **特色看点**：世界遗产活态运河；拱宸桥（杭州最高石拱桥）、桥西历史街区（手工艺活态馆、刀剪剑 / 伞 / 扇博物馆，多免费）、大运河博物馆（免费）；乘水上巴士（¥3）游河。
- **门票**：街区与多数博物馆**免费**；水上巴士 ¥3。
- **建议时长**：半日。
- **交通**：地铁 5 号线"拱宸桥东"步行。
- **贴士**：水上巴士比游船便宜太多；桥西喝杯茶看运河慢生活。

### 清河坊 / 河坊街 / 南宋御街
- **位置**：上城区河坊街（吴山脚下，近西湖）。
- **特色看点**：南宋皇城根下的老街，胡庆余堂（中药博物馆）、王星记扇、张小泉；小吃（定胜糕、葱包桧、臭豆腐）；清河坊与南宋御街相连。
- **门票**：街区**免费**。
- **建议时长**：2 小时（逛吃）。
- **交通**：地铁 1 号线"定安路"步行。
- **贴士**：胡庆余堂可免费参观中药文化；小吃比景区价亲民但仍比街边略贵。

### 湘湖
- **位置**：萧山区湘湖路（杭州南，近杭州乐园）。
- **特色看点**："西湖的姊妹湖"，更小众清幽，越王城遗址、跨湖桥遗址（独木舟，8000 年）；环湖骑行、游船。
- **门票**：湖区**免费**（部分场馆收费）。
- **建议时长**：半日。
- **交通**：地铁 1 号线"湘湖"站。
- **贴士**：避开西湖人潮的好替代；与杭州乐园 / 极地海洋公园顺路。

## 四、主题与演艺

### 宋城 · 宋韵演艺
- **位置**：西湖区之江路 148 号（之江片区）。
- **特色看点**：大型宋文化主题公园，《宋城千古情》演出（杭州旅游名片，金海岸级）；市井街、怪街、穿越快闪。
- **门票（参考）**：含演出席约 ¥249（大学生票约 ¥129；不同档位差异大）。
- **开放时间**：约 9:30–21:00（演出夜场为主）。
- **建议时长**：半日（含演出）。
- **交通**：公交 / 自驾。
- **贴士**：《千古情》必看；网购选含演出席位；暑期 / 节假日加场。

### 千岛湖（淳安）
- **位置**：杭州市淳安县（杭州西约 150 km，高铁 / 大巴可达）。
- **特色看点**：人工湖、千座翠岛，中心湖区（梅峰岛、龙山岛、月光岛）、东南湖区；游船 / 骑行 / 温泉；水质极佳。
- **门票（参考）**：中心湖区门票 + 船约 ¥45.5 起（按线路 / 游船档位，以官方为准）；景区套票更高。
- **建议时长**：1–2 日。
- **交通**：杭州西站 / 东站高铁至千岛湖站，转公交；或自驾。
- **贴士**：梅峰岛"一览众岛小"最佳观景；想静可住湖景民宿骑行。

## 五、良渚与近郊

### 良渚古城遗址（世界遗产）
- **位置**：余杭区瓶窑镇 / 良渚街道（杭州北）。
- **特色看点**：5300 年中华文明实证，"中华第一城"；古城遗址、莫角山、水利系统、反山王陵；良渚博物院（免费，顶级展陈）。
- **门票（参考）**：遗址公园约 ¥55（含观光车 ¥70）；良渚博物院免费需预约。
- **开放时间**：约 9:00–17:00。
- **建议时长**：半日。
- **交通**：地铁 2 号线"良渚"站转公交 / 打车。
- **贴士**：先去良渚博物院理解背景再看遗址；本地市民常免费政策以官方为准。

### 富阳 / 桐庐（富春江山水）
- **位置**：杭州西南部（富阳、桐庐，高铁可达）。
- **特色看点**："富春山居图"实景地，富春江、瑶琳仙境（溶洞）、严子陵钓台、桐君山；自驾 / 高铁沿线皆景。
- **门票**：瑶琳仙境约 ¥100；钓台等另计（以现场为准）。
- **建议时长**：1 日（县域游）。
- **交通**：杭州东高铁至富阳 / 桐庐约 20–40 分钟。
- **贴士**：与千岛湖组成杭州西线山水游。

## 六、实用信息

- **经典 1 日（西湖精华）**：断桥 → 白堤 → 平湖秋月 → 孤山（文澜阁 / 西泠印社）→ 苏堤骑行 → 花港观鱼 → 雷峰塔 → 湖滨音乐喷泉夜景。
- **经典 2 日**：Day1 西湖 + 灵隐；Day2 运河（拱宸桥）+ 清河坊 + 宋城（夜）。
- **交通贴士**：西湖边停车难，**地铁 + 共享单车 + 公交**最方便；景区"杭州通"文旅卡可省部分门票。
- **避坑**：西湖边的"免费茶""算命"多为套路；龙井村买茶比价；节假日西湖隧道 / 景区极堵，地铁优先。
- **联游**：上海（高铁 1h）、乌镇 / 西塘（嘉兴，1h 内）、千岛湖（2h）、黄山（经杭州西—黄山北）。
