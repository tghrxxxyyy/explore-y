# 舟山

> "海天佛国，渔都港城。"普陀山的钟磬、朱家尖的沙、东极岛的蓝、嵊泗的礁——舟山是中国唯一以群岛建市的地方，1000 多座岛屿散在东海，是中国人的"海上桃源"。

> ⚠️ 票价说明：普陀山为"门票 + 船票 + 香"组合，离岛船票另计；下列为 2026-07 参考价，出行前以"舟山普陀山" / 船运官方为准，台风季船期多变务必查当日。

---

## 一、城市速览

- **城市特色**：群岛地级市，佛教四大名山之一普陀山、沙雕故乡朱家尖、最东极东极岛、贻贝之乡嵊泗；海鲜天堂。
- **行政区划（景点分布）**：**定海区 / 临城**（本岛市区）；**普陀区**（普陀山、朱家尖、沈家门）；**岱山县**；**嵊泗县**（列岛，最北）；代管**群岛诸岛**。
- **怎么去**：
  - 飞机：普陀山机场（朱家尖），通航多地。
  - 轮渡：本岛（定海 / 沈家门）有连接宁波（白峰 / 鸭蛋山）、上海（吴淞 / 小洋山）的车客渡；普陀山 / 东极 / 嵊泗均需从沈家门 / 朱家尖 / 岱山乘船。
  - 高铁：最近宁波站，转大巴 / 船。
- **最佳季节**：**5–10 月最佳**（海水暖、适合玩海）；7–9 月台风多；冬季海风大但海鲜肥；观音香会（农历二月十九 / 六月十九 / 九月十九）人多。
- **本地特色美食**：海鲜面、带鱼、大黄鱼、梭子蟹、嵊泗贻贝、普陀山观音饼、沈家门夜排档。
- **住宿建议**：普陀山住岛上（方便朝圣、看晨景）；朱家尖住南沙旁（玩沙看海）；沈家门住夜排档旁（吃海鲜）；东极 / 嵊泗住渔家民宿。

## 二、普陀山（海天佛国）

### 普陀山 · 观音道场
- **位置**：舟山市普陀区普陀山岛（朱家尖对岸，船约 15–20 分钟）。
- **特色看点**：佛教四大名山之一、观音菩萨道场；普济寺（前寺）、法雨寺（后寺）、慧济寺（佛顶山）、南海观音立像（33m 铜像）、紫竹林、不肯去观音院；三步一拜、海天一色。
- **门票（参考）**：普陀山门票 + 船票 + 香组合约 ¥250（旺季门票约 ¥160 + 往返船约 ¥60；淡季门票约 ¥140；以官方为准）；寺庙香花券各 ¥5–10。
- **开放时间**：船班约 6:30–21:30（随季）；景区全天。
- **建议时长**：1–2 日（建议住一晚）。
- **交通**：朱家尖蜈蚣峙码头 / 沈家门半升洞码头乘船；上海 / 宁波有直达快艇（依季节）。
- **贴士**：**香会日与节假日人爆满、船票紧张，提前订**；岛内禁私家车，靠步行 / 景区公交 / 索道；心诚则灵、文明进香。

## 三、朱家尖（沙雕与海岛玩乐）

### 朱家尖 · 大青山 / 南沙 / 东沙
- **位置**：普陀区朱家尖岛（与普陀山隔海，机场所在）。
- **特色看点**："沙雕故乡"，南沙（国际沙雕节、海滨浴场）、东沙（日出 / 露营）、大青山（环岛公路、里沙生态、制高点看海）；乌石塘（乌石砾滩）。
- **门票（参考）**：大青山约 ¥100；南沙约 ¥70（优待 ¥35）；东沙约 ¥35（以官方为准）。
- **建议时长**：1 日。
- **交通**：朱家尖岛内公交 / 打车；与普陀山船程近。
- **贴士**：夏季玩沙戏水最佳；大青山环岛自驾 / 观光车出片；南沙沙雕节（7–10 月）最盛。

### 朱家尖 ↔ 普陀山 船
- **位置**：蜈蚣峙码头 ↔ 普陀山码头。
- **门票（参考）**：单程船约 ¥30（以官方为准）。
- **贴士**：去普陀山主通道；旺季排队久，早班船人少。

### 观音法界（朱家尖）
- **位置**：普陀区朱家尖（观音文化园）。
- **特色看点**：现代佛教艺术建筑群，观音圣坛（莲花穹顶）金碧辉煌；建筑震撼、拍照出片。
- **门票（参考）**：约 ¥90（以官方为准）。
- **建议时长**：1.5 小时。
- **交通**：朱家尖岛内。
- **贴士**：与普陀山互补，建筑党必看。

## 四、东极岛（中国大陆最东）

### 东极岛 · 东海极地
- **位置**：舟山市普陀区东极镇（普陀山 / 沈家门东南，船约 2–3 小时）。
- **特色看点**：中国大陆最东端住人岛，《后会无期》取景地；庙子湖（主岛、灯塔、网红灯塔）、东福山（新世纪第一缕曙光、环岛徒步）、青浜岛（"海上布达拉宫"石屋群）；蓝海、礁石、银河。
- **门票（参考）**：东极岛**免费**进岛；岛内公交 / 电瓶车约 ¥88；沈家门—东极船下舱约 ¥100 / 中舱 ¥130 / 上舱 ¥150（以官方为准，旺季上浮且难买）。
- **建议时长**：2–3 日（建议住 1–2 晚）。
- **交通**：沈家门半升洞 / 墩头码头乘船（每日班次少，旺季一票难求，务必提前购）。
- **贴士**：**船票是难点**，提前在"舟山星海"等官方渠道抢；晕船备药；东福山徒步看日出绝美但耗时，体力评估。

## 五、嵊泗列岛（最北的蓝）

### 嵊泗 · 基湖沙滩 / 枸杞岛 / 花鸟岛
- **位置**：舟山市嵊泗县（长江口外，上海东南，船约 1–2 小时）。
- **特色看点**："东方小希腊"，基湖沙滩（海滨浴场）、南长途沙滩、枸杞岛（贻贝养殖、大王沙滩、海上牧场）、花鸟岛（荧光海、百年灯塔、蓝白小镇）；离上海近。
- **门票（参考）**：基湖沙滩约 ¥60；枸杞 / 花鸟部分免费、部分小景点收费（以官方为准）。
- **建议时长**：2–3 日。
- **交通**：上海吴淞 / 小洋山、宁波 / 沈家门有船至嵊泗（菜园 / 枸杞）；船期随季。
- **贴士**：花鸟岛网红（灯塔 + 荧光海，夏季夜）；枸杞岛更原生态；船程看天气。

## 六、实用信息

- **经典 2 日（普陀 + 朱家尖）**：Day1 朱家尖（大青山 / 南沙）→ 晚宿朱家尖；Day2 普陀山朝圣（宿岛或返）。
- **经典 3 日（东极）**：沈家门船 → 庙子湖 → 东福山徒步看日出 → 返。
- **交通贴士**：群岛靠船，**台风季（7–9 月）船期多变、可能停航**，出行前必查当日船期与预警；岛上多步行，轻装。
- **避坑**：海边海鲜问清单价再点；普陀山香会 / 节假日船票住宿暴涨，早订；东极 / 嵊泗船票难抢，规划好回程。
- **联游**：宁波（船 / 跨海大桥）、上海（嵊泗快船直达）、杭州（经宁波）。
