# 台州

> "佛宗道源，山海台州。"天台山的国清寺钟声、神仙居的云海栈道、台州府城的古城墙、大陈岛的渔火——台州是被山与海共同偏爱的地方，也是"和合文化"的发源地。

> ⚠️ 票价说明：神仙居、天台山各景点、台州府城墙收费，国清寺免费预约；下列为 2026-07 参考价，以景区官方为准（暑期师生常有优惠，留意官方公告）。

---

## 一、城市速览

- **城市特色**："佛宗道源"（天台山，佛教天台宗 / 道教南宗祖庭）、"和合文化"（寒山拾得）、山海之城（台州湾）、民营经济（民营汽车 / 制造）；神仙居、台州府城、大陈岛。
- **行政区划（景点分布）**：**椒江区**（市区、椒江）；**黄岩区**；**路桥区**；**临海市**（台州府城 / 江南长城）；**天台县**（天台山）；**仙居县**（神仙居）；**温岭市**（方山 / 长屿硐天）；**玉环市**；**三门县**。
- **怎么去**：
  - 高铁：台州站（椒江）/ 临海站 / 天台山站 / 仙居站等，杭州约 1.5–2h、宁波约 1h、上海约 2.5h（杭台高铁）。
  - 飞机：台州路桥机场（支线）。
- **最佳季节**：**春秋最佳**；夏季山区（神仙居 / 天台）避暑、海岛（大陈岛）玩海；台风（7–9 月）留意。
- **本地特色美食**：蛋清羊尾、麦虾、食饼筒、糟羹、沙蒜豆面、涌泉蜜橘、三门青蟹、温岭嵌糕。
- **住宿建议**：游天台住**天台县城**、神仙居住**白塔 / 淡竹**民宿、访古城住**临海**（紫阳古街旁）、海岛住**大陈岛**渔家。

## 二、仙居 · 神仙居

### 神仙居 · 云端仙境
- **位置**：仙居县白塔镇（台州西，高铁"仙居"站 / 诸永高速）。
- **特色看点**："神仙居所"，火山流纹岩地貌，云雾缭绕的峰林、悬空栈道、如意桥（网红打卡）、南天顶（玻璃观景）、观音峰；《天龙八部》取景地；缆车 + 栈道轻松游。
- **门票（参考）**：约 ¥99（老人 / 学生 / 儿童 ¥55；加南天顶约 ¥168；暑期师生常免费 / 优惠，以官方为准）。
- **开放时间**：约 7:30–17:00。
- **建议时长**：半日–1 日（建议缆车上下省体力）。
- **交通**：仙居站转公交 / 自驾。
- **贴士**：**雨后云海最佳**；如意桥 + 南天顶必拍；缆车 + 南天索道环线不累；暑假师生优惠力度大。

## 三、天台山（佛宗道源）

### 国清寺 · 天台宗祖庭
- **位置**：天台县国清路（天台县城北）。
- **特色看点**：隋代古刹，佛教天台宗祖庭（智者大师创宗），"寺若成，国即清"；隋塔、隋梅、丰干桥、一行禅师墓；**免费开放、不收门票、香火从容**，被誉"最清贫也最从容"的寺庙。
- **门票**：**免费，需预约**（以官方为准）。
- **建议时长**：1.5–2 小时。
- **交通**：天台站转公交 / 打车。
- **贴士**：与商业化寺院反差大，氛围极好；旁有赤城山（梁妃塔）；国清寺外农田禾苗四季景不同。

### 天台山 · 大瀑布 / 石梁 / 琼台仙谷
- **位置**：天台县（国清寺周边群山）。
- **特色看点**：
  - **天台山大瀑布**（琼台仙谷出口）：落差 325m 的九级瀑布，气势磅礴，可沿栈道上行。
  - **石梁飞瀑**：天然石桥（梁）横跨，瀑布穿梁而下，王安石、徐霞客题咏；"瀑布穿梁"奇观。
  - **琼台仙谷**：峡谷、栈道、仙湖，道教南宗祖庭（桐柏宫）在旁。
  - **华顶**：天台山主峰，云锦杜鹃（5 月）、茶园、看日出云海。
  - **赤城山**：丹霞孤峰，梁妃塔、紫云洞。
- **门票（参考）**：大瀑布约 ¥100；石梁约 ¥60；琼台仙谷约 ¥65；华顶约 ¥50；赤城山约 ¥15；济公故居约 ¥30（以官方为准，有联票）。
- **建议时长**：1–2 日（多景点分散）。
- **交通**：天台县城转景区公交 / 自驾。
- **贴士**：大瀑布 + 石梁最经典；5 月华顶杜鹃节；道教爱好者访桐柏宫。

### 济公故居
- **位置**：天台县城（赤城路）。
- **特色看点**："活佛"济公（李修缘）出生地，故居、济公庙；了解济公传说。
- **门票（参考）**：约 ¥30（以官方为准）。
- **建议时长**：1 小时。
- **交通**：县城内。
- **贴士**：与国清寺 / 赤城山串联。

## 四、临海 · 台州府城（江南长城）

### 台州府城墙（江南长城）
- **位置**：临海市（台州府城，紫阳古街旁）。
- **特色看点**："江南八达岭"，明代抗倭城墙，依山临江，揽胜门—望江门段最壮观；敌台、瓮城、城墙漫步；与紫阳古街相连；中国文化遗产（申遗预备）。
- **门票（参考）**：约 ¥55–60（学生 ¥30；以官方为准）。
- **建议时长**：2–3 小时（登城 + 古街）。
- **交通**：高铁临海站转公交 / 打车。
- **贴士**：登城看灵江与古城；与紫阳古街（吃食饼筒、蛋清羊尾）串联；东湖（古园）在侧。

### 紫阳古街 / 东湖
- **位置**：临海市台州府城内。
- **特色看点**：浙江保存最完整的古街之一，宋代格局，百年老店、非遗（剪纸、泥塑）、小吃；东湖为宋代园林（"小西湖"）。
- **门票**：古街免费；东湖约 ¥15（以官方为准）。
- **建议时长**：2 小时。
- **交通**：府城内步行。
- **贴士**：吃蛋清羊尾、麦虾、食饼筒；古街慢逛最有味。

## 五、温岭与海岛

### 温岭 · 方山 / 长屿硐天
- **位置**：温岭市（台州东南，沿海）。
- **特色看点**：方山（火山台地、崖壁、山顶平川，"台岳"，石峰如屏）；长屿硐天（人工采石硐窟群，硐穴音乐厅、观夕硐，世界地质奇观）；石塘（彩色渔村、千年曙光碑，中国大陆新千年第一缕曙光）。
- **门票（参考）**：方山约 ¥40（优待 ¥20）；长屿硐天约 ¥70–90（以官方为准）。
- **建议时长**：1 日（方山 + 硐天 / 石塘）。
- **交通**：温岭站 / 自驾。
- **贴士**：石塘七彩小箬村（网红彩虹村）拍照；千年曙光碑看海上日出。

### 大陈岛（椒江外海）
- **位置**：台州市椒江区外海（台州湾，船约 2 小时）。
- **特色看点**："东海明珠"，甲午岩（海蚀崖）、浪通门、垦荒纪念碑（1956 年青年志愿垦荒）、渔港、灯塔；蓝海 + 悬崖 + 灯塔，小众海岛。
- **门票**：岛上**免费**（船票 + 部分项目收费）。
- **建议时长**：1–2 日（住渔家）。
- **交通**：椒江七号码头乘船（每日班次，留意海况）。
- **贴士**：船程看天气、台风季可能停航；海岛慢生活、看星海；甲午岩出片。

### 桃渚古城 / 三门青蟹
- **位置**：临海市桃渚镇（台州沿海）；三门县（青蟹之乡）。
- **特色看点**：桃渚古城（明代抗倭所城，保存完好，桃渚武坑石林）；三门青蟹肥美（9–10 月最盛），海鲜之旅。
- **门票（参考）**：桃渚古城约 ¥15（以官方为准）。
- **建议时长**：半日（古城）+ 海鲜餐。
- **交通**：临海 / 三门自驾。
- **贴士**：爱历史去桃渚；爱吃蟹去三门（青蟹节秋季）。

## 六、实用信息

- **经典 2 日（仙居 + 临海）**：Day1 神仙居（云海栈道）；Day2 台州府城（长城 + 紫阳街），宿临海。
- **经典 2 日（天台）**：Day1 国清寺 + 赤城山 + 济公故居；Day2 天台山大瀑布 + 石梁 / 琼台仙谷。
- **交通贴士**：杭台高铁通车后杭州约 1.5h 直达天台 / 临海 / 仙居；山区景点分散，自驾高效；海岛看船期。
- **避坑**：神仙居雨后云海最佳、晴天也美但少雾；暑期师生票优惠大、带证件；台风季（7–9 月）关注船 / 景区开放。
- **联游**：宁波（1h）、绍兴（1.5h）、温州（神仙居—雁荡高铁约 1h）、舟山（经宁波）。
