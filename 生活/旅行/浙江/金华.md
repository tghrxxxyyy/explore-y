# 金华

> "小商品之都，影视名城。"义乌的万国商品、横店的王者片场、双龙洞的地下长河、诸葛八卦村的阵图——金华是浙江最"会做生意"也最"藏古"的地方。

> ⚠️ 票价说明：横店按园区 / 联票收费，双龙洞 / 诸葛村等收费，义乌商贸城免费逛；下列为 2026-07 参考价，以景区官方为准。

---

## 一、城市速览

- **城市特色**：义乌国际商贸城（全球小商品集散）、横店影视城（中国好莱坞）、金华火腿之乡、婺州文化；代管义乌、东阳、永康、兰溪等。
- **行政区划（景点分布）**：**婺城区**（双龙洞、婺州古城）；**东阳市**（横店、卢宅）；**兰溪市**（诸葛八卦村、地下长河）；**义乌市**（国际商贸城）；**武义县**（温泉、牛头山）；**永康**（方岩）。
- **怎么去**：
  - 高铁：金华站 / 金华南站，杭州约 1h、义乌约 15min、上海约 2h。
  - 飞机：义乌机场（近）；横店有通航机场（旅游包机）。
- **最佳季节**：**春秋最佳**；武义温泉冬季佳；横店夜戏（梦幻谷）夏季最旺。
- **本地特色美食**：金华火腿、东阳沃面、兰溪牛肉面、金华酥饼、婺州桶饼、永康肉麦饼、义乌红糖。
- **住宿建议**：逛横店住**横店镇**（景区旁）；购物住**义乌**；市区住婺城（双龙洞旁）。

## 二、横店影视城（中国好莱坞）

### 横店 · 影视拍摄基地群
- **位置**：东阳市横店镇（金华东约 1h 车程，高铁"横店"站 / 义乌转）。
- **特色看点**：全球最大影视拍摄基地，秦王宫、明清宫苑（1:1 故宫）、清明上河图、广州街·香港街、梦幻谷（戏水 + 演艺）、明清民居博览城等；常遇剧组 / 明星，穿戏服拍"大片"。
- **门票（参考）**：一日票（5 园区）约 ¥239、二日票约 ¥369；单园如秦王宫约 ¥185 起、明清宫苑约 ¥170、清明上河图约 ¥185 起、梦幻谷约 ¥199–220（以官方为准，网购优惠）。
- **开放时间**：约 8:00–17:00（梦幻谷夜场至 21:00 左右）。
- **建议时长**：1–2 日。
- **交通**：义乌 / 东阳转横店专线；自驾约 1h；高铁横店站。
- **贴士**：**二日票更划算**；想看拍摄可打听剧组；穿古装拍照很出片；梦幻谷夏季夜游戏水。

### 秦王宫 / 明清宫苑 / 清明上河图
- **位置**：横店影视城内（独立园区）。
- **特色看点**：秦王宫（咸阳宫、四海归一殿，气势恢宏，多影视取景）；明清宫苑（1:1 复刻故宫，太和殿等）；清明上河图（宋代市井，《知否》等取景）。
- **门票（参考）**：见上联票；单园约 ¥170–185（以官方为准）。
- **建议时长**：每园 2–3 小时。
- **交通**：横店影视城专用公交串联各园。
- **贴士**：带娃 / 影视迷首选；园区内表演（如《梦回秦汉》《汴梁一梦》）别错过。

## 三、溶洞与古村

### 双龙洞（金华山）
- **位置**：婺城区罗店镇金华山（市区北约 15 km）。
- **特色看点**：叶圣陶《记金华的双龙洞》原型；坐船平卧进洞（"卧舟"穿越孔隙）是独特体验；溶洞钟乳、冰壶洞瀑布、黄大仙祖宫；金华山避暑。
- **门票（参考）**：约 ¥80（含景交；以官方为准）。
- **建议时长**：半日。
- **交通**：市区公交 / 打车至双龙景区。
- **贴士**：卧舟进洞为名场面；与黄大仙祖宫 / 鹿田书院串联。

### 诸葛八卦村（兰溪）
- **位置**：兰溪市诸葛镇（金华西北约 40 km）。
- **特色看点**：诸葛亮后裔聚居地，按八卦阵图布局（钟池为心、八巷向外）；明清古民居、丞相祠堂、大公堂；"八卦"格局迷阵有趣。
- **门票（参考）**：约 ¥85（学生 / 儿童 ¥45；以官方为准）。
- **建议时长**：半日。
- **交通**：兰溪转公交 / 自驾。
- **贴士**：看阵图布局、找"生门"；与兰溪地下长河（溶洞）顺路。

### 卢宅（东阳）
- **位置**：东阳市卢宅街（横店旁）。
- **特色看点**："北有故宫、南有肃雍"，明清东阳木雕古民居建筑群，肃雍堂轴线完整；木雕艺术巅峰。
- **门票（参考）**：约 ¥65（以官方为准）。
- **建议时长**：1.5 小时。
- **交通**：东阳 / 横店旁。
- **贴士**：木雕爱好者必看；与横店串联。

## 四、义乌与武义

### 义乌国际商贸城
- **位置**：义乌市（金华东，高铁义乌站）。
- **特色看点**：全球最大小商品批发市场（多个区，超百万种商品）；"买全球、卖全球"；可零售淘货、看"世界超市"运转。
- **门票**：商贸城**免费**逛（进货 / 零售均可）。
- **建议时长**：半日–1 日。
- **交通**：高铁义乌站转公交 / 打车。
- **贴士**：分区巨大，先定目标再去；支持快递代发；配套"鸡毛换糖"精神陈列馆。

### 武义 · 牛头山 / 温泉
- **位置**：武义县（金华南约 1h）。
- **特色看点**：牛头山（浙中最高峰之一，原始森林、飞瀑、玻璃栈道）；武义温泉（唐风温泉、清水湾，江浙温泉名地）；郭洞 / 俞源古村（太极星象村）。
- **门票（参考）**：牛头山约 ¥100–110；温泉约 ¥100–200（以官方为准）。
- **建议时长**：1–2 日。
- **交通**：武义站 / 自驾。
- **贴士**：冬季泡温泉 + 夏季避牛头山，组合最佳；俞源古村看"太极布局"。

### 熊猫猪猪 · 两头乌猪主题乐园
- **位置**：金华市（近市区 / 开发区）。
- **特色看点**：金华"两头乌"（熊猫猪，火腿原料名种）主题乐园，萌猪展示、科普、城堡建筑；亲子热门。
- **门票（参考）**：约 ¥89 起（以官方为准）。
- **建议时长**：2 小时。
- **交通**：市区自驾 / 公交。
- **贴士**：亲子必去；与火腿文化结合。

## 五、实用信息

- **经典 2 日（横店）**：Day1 秦王宫 + 清明上河图；Day2 明清宫苑 + 梦幻谷夜游，住横店。
- **经典 2 日（山水古村）**：Day1 双龙洞 + 婺州古城；Day2 诸葛八卦村 + 兰溪 / 义乌商贸城。
- **交通贴士**：横店 / 义乌有高铁最方便；古村溶洞靠自驾 / 县域公交；义乌机场近。
- **避坑**：横店单园票不划算、优先联票；商贸城很大、防迷路；温泉选正规场所。
- **联游**：杭州（1h）、衢州（高铁约 1h）、丽水（约 1.5h）。
