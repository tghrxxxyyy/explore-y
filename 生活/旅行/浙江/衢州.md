# 衢州

> "钱江源头，南孔圣地。"一座被低估的山水古城——江郎的丹霞、廿八都的冷兵器关隘、根宫的佛像、龙游的地下石窟，还有那一碗辣到灵魂的"三头一掌"。衢州，是浙江最"江湖"的地方。

> ⚠️ 票价说明：江郎山、根宫佛国、龙游石窟等收费，衢州古城免费；下列为 2026-07 参考价，以景区官方为准。

---

## 一、城市速览

- **城市特色**：浙江西大门、钱江源（钱塘江发源）、南孔圣地（孔氏南宗家庙）、浙闽赣皖四省通衢；丹霞（江郎山，世界自然遗产）、石窟（龙游）、根雕（根宫佛国）。
- **行政区划（景点分布）**：**柯城区**（衢州古城、水亭门）；**江山市**（江郎山、廿八都、仙霞关）；**开化县**（钱江源、根宫佛国）；**龙游县**（龙游石窟、民居苑）；**常山县**。
- **怎么去**：
  - 高铁：衢州站（杭长高铁），杭州约 1h、上海约 2.5h、南昌约 2h；江山站近江郎山。
  - 飞机：最近衢州机场（支线） / 杭州。
- **最佳季节**：**春秋最佳**；夏季山区避暑（钱江源）、秋季根雕 / 丹霞宜人；衢州菜偏辣，冬吃暖身。
- **本地特色美食**："三头一掌"（兔头 / 鸭头 / 鱼头 / 鸭掌，麻辣鲜香）、衢州烤饼、常山贡面、开化清水鱼、龙游发糕、葱花馒头、搁袋饼。
- **住宿建议**：市区住**水亭门 / 古城**周边（夜景 + 美食）；游江郎山住**江山**，游根宫住**开化**。

## 二、衢州古城（南孔圣地）

### 孔氏南宗家庙 / 水亭门
- **位置**：柯城区新桥街（孔庙）、水亭门历史文化街区（古城西）。
- **特色看点**：孔氏南宗家庙（宋建炎年间孔端友南渡衢州，史称"东南阙里"，全国仅曲阜与衢州两座孔氏家庙）；水亭门是衢州古城核心，城墙、钟楼、天王塔、老街；城墙夜景 + 灯光秀。
- **门票（参考）**：孔氏南宗家庙约 ¥10（老人 ¥5）；水亭门街区免费。
- **建议时长**：半日（家庙 + 水亭门夜景）。
- **交通**：市区步行 / 公交。
- **贴士**：每年 9 月祭孔大典；水亭门入夜灯光 + 城墙最出片；吃"三头一掌"就在街区。

### 信安湖夜游
- **位置**：柯城区信安湖（古城旁）。
- **特色看点**：沿江灯光夜游船，看水亭门、城墙、江景灯光；衢州夜经济名片。
- **门票（参考）**：约 ¥138（以官方为准）。
- **建议时长**：1 小时。
- **交通**：水亭门码头。
- **贴士**：夏季夜游最舒服；与古城晚餐串联。

## 三、江山 · 江郎山与古道

### 江郎山 · 三爿石（世界自然遗产）
- **位置**：江山市石门镇（衢州西南约 1h，高铁"江山"转）。
- **特色看点**："中国丹霞"世界自然遗产组成部分，三块巨石（三爿石）拔地而起、高逾 300m，形似石峰插天；郎峰、亚峰、灵峰；一线天、伟人峰；徐霞客三游。
- **门票（参考）**：约 ¥105（含景交；儿童 ¥15，老人 60–69 约 ¥60；以官方为准）。
- **建议时长**：半日（登郎峰约 3–4 小时，体力评估）。
- **交通**：江山站转旅游专线 / 自驾。
- **贴士**：**一线天**狭窄震撼；登顶俯瞰三省；恐高 / 体力弱者走低线看三爿石也值。

### 廿八都古镇 · 军事要隘
- **位置**：江山市廿八都镇（浙闽赣交界，江郎山旁约 40 km）。
- **特色看点**："一个遗落在大山里的梦"，自古兵家必争（仙霞古道节点）；139 种姓氏、13 种方言的"百姓古镇"；文昌宫、姜遇鸿旧宅、枫溪老街、水安凉风；闽浙赣皖建筑交融。
- **门票（参考）**：约 ¥80（优待 ¥40；以官方为准）。
- **建议时长**：半日–1 日（建议住一晚）。
- **交通**：江山转公交 / 自驾（仙霞古道旁）。
- **贴士**：比江南水乡更"硬核"、边关味；与仙霞关、江郎山串成江山一日 / 二日。

### 仙霞关 · 雄关古道
- **位置**：江山市保安乡（廿八都旁）。
- **特色看点**：仙霞岭上的千年雄关（黄巢起义军开道），四道关门、枫岭、古道；"东南锁钥"；秋日枫叶。
- **门票（参考）**：约 ¥55（以官方为准）。
- **建议时长**：2–3 小时（徒步关道）。
- **交通**：江山自驾 / 公交。
- **贴士**：爱徒步 / 历史者必走；与廿八都、江郎山组合。

### 浮盖山
- **位置**：江山市（闽浙交界，浮盖山）。
- **特色看点**：怪石垒叠的丹霞 / 花岗岩山，乱石迷宫、石洞、云海；徐霞客称"怪石拿云"。
- **门票（参考）**：约 ¥45（以官方为准）。
- **建议时长**：半日。
- **交通**：江山自驾。
- **贴士**：攀石趣、强度适中；与廿八都顺路。

## 四、开化 · 根宫与钱江源

### 根宫佛国（根博园）
- **位置**：开化县根博路（衢州西，近安徽）。
- **特色看点**：以树根雕刻的佛教文化主题园林，巨型根雕佛像群、根雕佛塔、醉根宝塔；"根雕圣地"，震撼且独特。
- **门票（参考）**：约 ¥117.8–118（优待 ¥78；以官方为准）。
- **建议时长**：半日。
- **交通**：开化站 / 自驾。
- **贴士**：根雕艺术奇观，拍照出片；与钱江源串联。

### 钱江源 · 钱塘江源头
- **位置**：开化县齐溪镇（浙皖赣交界，钱江源国家森林公园）。
- **特色看点**：钱塘江正源，原始森林、瀑布（莲花塘、瀑布群）、钱江源大峡谷；生态极佳、避暑。
- **门票（参考）**：约 ¥60–80（以官方为准）。
- **建议时长**：半日–1 日。
- **交通**：开化自驾。
- **贴士**：溯溪 / 徒步爱好者；与根宫佛国组合开化一日。

## 五、龙游 · 地下石窟

### 龙游石窟
- **位置**：龙游县小南海镇（衢州东约 30 km）。
- **特色看点**："世界第九大奇迹"，千年地下石窟群（人工开凿的巨型石室，鱼尾状凿痕、斜柱支撑），用途成谜（采石 / 屯兵 / 陵寝？）；水下石窟神秘。
- **门票（参考）**：约 ¥80（以官方为准）。
- **建议时长**：2–3 小时。
- **交通**：龙游站转公交 / 自驾。
- **贴士**：石窟恒温阴凉、夏季舒适；讲解帮助理解未解之谜；旁有民居苑（迁建古宅）。

### 龙游民居苑
- **位置**：龙游县（石窟旁）。
- **特色看点**：集中迁建的明清古民居（高岗起凤、巫氏厅等），了解浙西民居木雕。
- **门票（参考）**：约 ¥30（与石窟联票更划算；以官方为准）。
- **建议时长**：1 小时。
- **交通**：与石窟同片区。
- **贴士**：与石窟联游，看木雕与石室对比。

## 六、实用信息

- **经典 2 日（江山）**：Day1 江郎山 + 浮盖山；Day2 廿八都 + 仙霞关，宿廿八都。
- **经典 2 日（开化 + 龙游）**：Day1 根宫佛国 + 钱江源；Day2 龙游石窟 + 民居苑，返市区水亭门夜游。
- **交通贴士**：江山站近江郎山最方便；开化 / 龙游通高铁；山区景点分散，自驾效率高。
- **避坑**：衢州菜偏辣（辣度高于一般浙菜），不能吃辣提前说；江郎山登顶耗体力，评估后再上。
- **联游**：杭州（1h）、黄山（经开化—黄山约 2h）、武夷山（经南平）、江西上饶（三清山）。
