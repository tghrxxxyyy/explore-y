# 绍兴

> "鉴湖越台名士乡。"鲁迅笔下的乌篷船、沈园墙上的钗头凤、兰亭流觞的墨香、黄酒坛里的岁月——绍兴是"没有围墙的博物馆"，也是中国师爷与名士的故乡。

> ⚠️ 票价说明：鲁迅故里 / 安昌免费预约，沈园 / 柯岩 / 东湖 / 兰亭等收费；下列为 2026-07 参考价，以景区官方为准。

---

## 一、城市速览

- **城市特色**：越国故都、东晋书法圣地（兰亭）、鲁迅故里、黄酒之乡、师爷故里；"东方威尼斯"（水巷、乌篷船、石桥）。
- **行政区划（景点分布）**：**越城区**（鲁迅故里、沈园、东湖、府山）；**柯桥区**（柯岩、安昌、兰亭）；**诸暨市**（西施故里、五泄）；**新昌县**（大佛寺、穿岩十九峰）。
- **怎么去**：
  - 高铁：绍兴北站（市区），杭州约 20min、宁波约 40min、上海经杭州约 1.5h。
  - 飞机：最近杭州萧山（约 1h 车程）。
- **最佳季节**：**春秋最佳**；3–4 月油菜花、10–11 月桂花 + 黄酒节；夏季可玩水（东湖 / 柯岩），冬季黄酒温饮。
- **本地特色美食**：绍兴黄酒、霉干菜扣肉、茴香豆、臭豆腐、花雕鸡、糟鸡、酱鸭、奶油小攀、绍兴香糕。
- **住宿建议**：住**越城区**（鲁迅故里周边，水巷民宿）；安昌古镇可住一晚体验蜡染与水乡。

## 二、越城核心（鲁迅与沈园）

### 鲁迅故里（免费，需预约）
- **位置**：越城区鲁迅中路（都昌坊口）。
- **特色看点**：鲁迅祖居（周家老台门）、故居（新台门）、三味书屋（寿镜吾私塾、早字课桌）、百草园、鲁迅纪念馆、咸亨酒店（孔乙己吃的茴香豆）；"从百草园到三味书屋"实景。
- **门票**：**免费，须提前预约**（官方公众号，实名）。
- **开放时间**：约 8:30–17:00（周一可能闭馆部分馆，以公告）。
- **建议时长**：2–3 小时。
- **交通**：公交 / 打车至"鲁迅故里"；地铁 1 号线"鲁迅故里"站。
- **贴士**：免费但旺季限流，务必早约；咸亨酒店吃茴香豆、温一碗黄酒最应景。

### 沈园 · 钗头凤
- **位置**：越城区鲁迅中路 318 号（鲁迅故里旁）。
- **特色看点**：南宋园林，陆游与唐婉《钗头凤》题壁处（"红酥手，黄縢酒"）；孤鹤轩、葫芦池；夜游《沈园情》越剧实景。
- **门票（参考）**：约 ¥40（优待 ¥20）；夜游另购票。
- **开放时间**：日约 8:00–17:00；夜场约 19:00 起。
- **建议时长**：1–1.5 小时。
- **交通**：与鲁迅故里步行可达。
- **贴士**：爱情主题，夜游越剧很催泪；与鲁迅故里串联。

### 东湖 · 崖壁盆景
- **位置**：越城区皋埠镇（市区东约 6 km）。
- **特色看点**：汉代采石遗存的悬崖峭壁 + 清潭，"天下第一水石盆景"；乘乌篷船穿陶公洞、仙桃洞，崖壁夹道、狭小如门。
- **门票（参考）**：约 ¥50。
- **开放时间**：约 8:00–17:00。
- **建议时长**：1.5–2 小时。
- **交通**：公交 / 打车至"东湖"；地铁 1 号线"东湖"站。
- **贴士**：乌篷船是精华（另付费）；悬崖倒影出片；夏季清凉。

### 府山 / 越王台
- **位置**：越城区府山公园（市区中心）。
- **特色看点**：越国宫台留存地，越王台、飞翼楼、文种墓；城市中的小山，俯瞰古城；秋瑾纪念馆（免费）在山脚。
- **门票**：免费 / 低价（以现场为准）。
- **建议时长**：1 小时。
- **交通**：市区步行 / 公交。
- **贴士**：与鲁迅故里、沈园顺路；秋瑾遗迹可一并缅怀。

## 三、柯桥 · 兰亭与柯岩

### 兰亭 · 书法圣地
- **位置**：柯桥区兰亭镇（市区西南约 13 km）。
- **特色看点**："书法圣地"，王羲之《兰亭集序》诞生地；鹅池、兰亭碑、曲水流觞、御碑亭、书法博物馆；3 月"兰亭书法节"雅集。
- **门票（参考）**：约 ¥70。
- **开放时间**：约 8:30–17:00。
- **建议时长**：1.5–2 小时。
- **交通**：公交 3 路 / 旅游专线；自驾。
- **贴士**：书法爱好者必到；曲水流觞处可想象当年雅集。

### 柯岩风景区 · 采石奇观
- **位置**：柯桥区柯岩大道（市区西南约 12 km）。
- **特色看点**：古采石遗景，云骨（孤立奇石）、天工大佛（隋代弥勒）、鉴湖（黄酒之源，柯桥段）、鲁镇（鲁迅笔下小镇，阿 Q / 祥林嫂情景）；山水 + 石景 + 鲁镇文化。
- **门票（参考）**：联票约 ¥90（单柯岩约 ¥75；以官方为准）。
- **开放时间**：约 8:00–16:30。
- **建议时长**：半日。
- **交通**：公交 / 自驾。
- **贴士**：柯岩 + 鉴湖 + 鲁镇联游最值；鲁镇有表演（社戏等）。

### 安昌古镇 · 腊月最浓的年味
- **位置**：柯桥区安昌镇（市区西北约 18 km）。
- **特色看点**：原生态水乡，临水老街、廊棚、石桥；腊肠、酱鸭、安昌扯白糖挂满街，"腊月风情节"（农历腊月）最盛；绍兴师爷博物馆。
- **门票**：古镇街区**免费**（部分展馆 / 乌篷船收费）。
- **建议时长**：半日–1 日。
- **交通**：公交 118/806 路；自驾。
- **贴士**：腊月（约 12 月–次年 1 月）来最有味道；酱油 / 腊味可买手信。

### 黄酒博物馆
- **位置**：越城区下大路（市区）。
- **特色看点**：中国黄酒专题馆，黄酒历史、酿造工艺、酒俗；可品鉴；配套黄酒小镇。
- **门票（参考）**：约 ¥25。
- **建议时长**：1 小时。
- **交通**：市区公交 / 打车。
- **贴士**：爱酒人必看；配茴香豆最对味。

## 四、诸暨与新昌

### 西施故里（诸暨）
- **位置**：诸暨市苎萝东路（绍兴西南约 60 km）。
- **特色看点**：西施传说地，浣纱江、西施殿、中国历代名媛馆；苎萝村古韵。
- **门票（参考）**：约 ¥45（以官方为准，部分免费）。
- **建议时长**：半日。
- **交通**：高铁诸暨站转公交 / 自驾。
- **贴士**：与五泄（瀑布群，夏季玩水）组合。

### 大佛寺（新昌）
- **位置**：新昌县南明街道（绍兴东南约 70 km）。
- **特色看点**：南朝石窟大佛（"江南第一大佛"，弥勒石窟），石弥勒像高逾 16m；千佛岩、般若谷、射雕村（《射雕英雄传》城寨）；"佛宗道源"名山。
- **门票（参考）**：约 ¥66.7 起（以官方为准）。
- **建议时长**：半日。
- **交通**：高铁新昌站 / 自驾。
- **贴士**：礼佛 + 石窟艺术；与穿岩十九峰（丹霞）顺路。

## 五、实用信息

- **经典 1 日（越城精华）**：鲁迅故里（上午）→ 沈园 → 午餐咸亨酒店 → 东湖（乌篷船）→ 府山 / 仓桥直街（傍晚）。
- **经典 2 日**：Day1 越城（鲁迅 / 沈园 / 东湖）；Day2 兰亭 + 柯岩 + 安昌（或换诸暨 / 新昌）。
- **交通贴士**：越城景点集中，公交 + 骑行 + 乌篷船；柯桥 / 诸暨 / 新昌靠高铁 + 公交 / 自驾。
- **避坑**：乌篷船按趟计价、先问价；黄酒虽好莫贪杯；安昌免费但展馆另票。
- **联游**：杭州（20min）、宁波（40min）、嘉兴乌镇（1h）、台州（高铁约 2h）。
