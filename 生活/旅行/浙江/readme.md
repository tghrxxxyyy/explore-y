# 浙江（省）

![浙江代表风光](/images/浙江.png)

> 江南水乡，民营经济与互联网高地，"七山一水两分田"。从西湖的烟柳到雁荡的奇峰，从普陀的梵音到丽水的梯田——绿水青山间，是越文化与江南美学的最高范式。

**省会：** 杭州　**特点：** 11 个地级市，浙北水乡 + 浙东佛国 + 浙南山水 + 浙西钱江源，山海兼备

## 🍜 美食地图（按片区）

- **杭嘉湖（浙北）**：西湖醋鱼、龙井虾仁、东坡肉、虾爆鳝面、杭帮酱鸭；嘉兴粽子、南湖菱；湖州丁莲芳千张包子、百鱼宴、太湖三白
- **宁绍（浙东）**：宁波汤圆、糟货、红膏呛蟹、雪菜黄鱼；绍兴黄酒、霉干菜扣肉、茴香豆、臭豆腐、花雕鸡
- **温台（东南沿海）**：温州鱼丸、糯米饭、江蟹生、炒粉干；台州麦虾、蛋清羊尾、涌泉蜜橘、沙蒜豆面
- **金衢（浙中西南）**：金华火腿、东阳沃面、兰溪牛肉面；衢州"三头一掌"（兔头/鸭头/鱼头/鸭掌）、常山贡面、开化清水鱼
- **舟山海鲜**：带鱼、大黄鱼、梭子蟹、海鲜面、观音饼
- **丽水深山**：缙云烧饼、遂昌长粽、青田糖糕、畲族乌米饭、龙泉安仁鱼头

## 🗓️ 最佳旅游季节

- **春秋最佳**（3–5 月、9–11 月）：春踏青（西湖桃柳、婺源级花海）、秋桂雨（杭州满城桂花、9–10 月）
- **夏季**：沿海（舟山 / 温州）避暑玩海，山区（莫干山 / 天台 / 仙都）清凉；但 7–9 月多台风，关注预警
- **冬季**：温泉（武义 / 泰顺）、滑雪（临安 / 安吉）；江南古镇冬雨别有韵
- **节庆**：农历八月十八钱塘江大潮（海宁盐官）、舟山观音香会（农历二月十九等）、绍兴黄酒节

## 🚆 交通概况

- **航空**：杭州萧山（主枢纽）、宁波栎社、温州龙湾、义乌（国际商贸）、舟山普陀山等机场；11 市中 9 市有客运机场
- **高铁**：沪昆、宁杭、杭黄、杭温、金温、杭台、甬台温等密布；杭州东为核心枢纽，11 市全部通动车，杭州至各市多 1–2 小时内
- **市内 / 县域**：地铁仅杭州 / 宁波 / 温州（部分）成网；多数景区靠自驾 / 旅游专线 / 公交接驳；海岛（舟山 / 东极 / 嵊泗）需轮渡
