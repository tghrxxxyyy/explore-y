# 温州

> "东南山水甲天下。"雁荡的奇峰、楠溪的清流、江心的孤屿、泰顺的廊桥——温州既有"温州模式"的商业锋芒，也有永嘉学派"经世致用"的务实与山水间的隐逸。

> ⚠️ 票价说明：雁荡山各峰单独 / 联票收费，江心屿轮渡收费，楠溪江街区免费；下列为 2026-07 参考价，以景区官方为准。

---

## 一、城市速览

- **城市特色**：民营经济标杆（"温州模式"）、永嘉学派发源、山水诗发祥地（谢灵运）；雁荡山（世界地质公园）、楠溪江、江心屿、泰顺廊桥。
- **行政区划（景点分布）**：**鹿城区**（江心屿、五马街）；**乐清市**（北雁荡山）；**永嘉县**（楠溪江、茗岙梯田）；**泰顺县**（廊桥）；**文成县**（百丈漈）；**洞头区**（海岛）。
- **怎么去**：
  - 高铁：温州南站（市区），杭州约 2h、宁波约 1.5h、上海约 3h。
  - 飞机：温州龙湾国际机场，地铁 S1 / 公交通达。
- **最佳季节**：**春秋最佳**；夏季山水清凉可玩（楠溪江漂流、百丈漈），但台风（7–9 月）多；冬季山景清冷。
- **本地特色美食**：温州鱼丸、糯米饭、江蟹生、炒粉干、灯盏糕、猪脏粉、马蹄松、永嘉麦饼、泰顺婆饼。
- **住宿建议**：市区住**鹿城**（江心屿 / 五马街旁）；游雁荡住**响岭头**（景区内）；楠溪江住**岩头 / 枫林**民宿。

## 二、雁荡山（世界地质公园）

### 北雁荡山 · 东南第一山
- **位置**：乐清市雁荡镇（温州市区北约 1h 车程，高铁"雁荡山"站）。
- **特色看点**："海上名山、寰中绝胜"，火山流纹岩地貌奇观；**灵峰**（日看合掌峰、夜看夫妻峰，昼夜两景）、**灵岩**（小龙湫、灵岩飞渡表演）、**大龙湫**（197m 大瀑布，雨季最壮观）、**方洞**（悬空栈道、铁索桥）；雁荡三绝。
- **门票（参考）**：灵峰约 ¥45（日 / 夜各一票）、灵岩约 ¥50、大龙湫约 ¥50、方洞约 ¥40；联票 A 约 ¥170、联票 B 约 ¥200（以官方为准）。
- **开放时间**：约 6:30–17:30（夜游灵峰另时段）。
- **建议时长**：1–2 日（三绝至少 1 日）。
- **交通**：高铁雁荡山站转公交 / 打车；自驾约 1h。
- **贴士**：**灵峰夜景必看**（白天晚上形状不同）；灵岩"飞渡"表演定时；雨季大龙湫最震撼、枯水期较弱。

### 灵峰夜景 / 灵岩飞渡
- **位置**：雁荡山景区内。
- **特色看点**：灵峰白天如合掌、入夜如情侣相依；灵岩高空"飞渡"杂技（采药人传统，现为表演）。
- **门票**：含于各峰票；飞渡免费看（表演时段）。
- **建议时长**：各 1 小时。
- **贴士**：夜游灵峰需另购夜票；飞渡表演留意当日时刻。

## 三、楠溪江与江心屿

### 楠溪江 · 中国山水诗的摇篮
- **位置**：永嘉县（温州市区北，楠溪江流域）。
- **特色看点**："永远的山水诗、最美的桃花源"，清澈溪水、滩林、古村（岩头、苍坡、芙蓉、丽水街）、狮子岩、龙瀑仙洞；竹筏漂流、古村慢游。
- **门票**：楠溪江景区街区**免费**；龙瀑仙洞约 ¥54；漂流 / 部分古村联票另计（以官方为准）。
- **建议时长**：1–2 日。
- **交通**：温州市区自驾 / 公交至永嘉；高铁楠溪江站（新开通）更方便。
- **贴士**：竹筏漂流夏季最爽；古村（苍坡八卦村、芙蓉村）适合拍照；与茗岙梯田（油菜花，3 月）组合。

### 江心屿
- **位置**：鹿城区瓯江中（市区北侧）。
- **特色看点**："中国诗之岛"，江心双塔（东塔 / 西塔，英国领事馆旧址）、江心寺（"云朝朝朝朝朝朝朝朝散"奇联）、谢公亭、革命烈士纪念馆；孤屿枕江。
- **门票（参考）**：轮渡约 ¥30（优待 ¥15，含往返；以官方为准）。
- **开放时间**：约 8:00–17:00（船班）。
- **建议时长**：2–3 小时。
- **交通**：江心屿码头（望江路）乘船。
- **贴士**：屿上绿树成荫、江景开阔；与五马街顺路。

### 五马街 / 禅街（鹿城）
- **位置**：鹿城区五马街（市中心）。
- **特色看点**：温州最老牌商业街，骑楼老建筑、老字号；旁"禅街"文艺更新；小吃（鱼丸、灯盏糕）密集。
- **门票**：**免费**。
- **建议时长**：1–2 小时。
- **交通**：市区步行 / 公交。
- **贴士**：吃糯米饭、鱼丸汤；与江心屿串联。

## 四、泰顺廊桥与瀑布

### 泰顺廊桥 · 编木拱桥活化石
- **位置**：泰顺县（温州市区西南约 2h 车程，浙闽交界）。
- **特色看点**："中国廊桥之乡"，编木拱廊桥（非遗）代表——泗溪姐妹桥（北涧桥、溪东桥）、仙居桥、文兴桥；廊屋遮雨、桥堡信仰；泗溪周边茶园与溪水。
- **门票**：廊桥**免费**（部分古村 / 博物馆收费）。
- **建议时长**：半日–1 日（多桥分散，建议自驾）。
- **交通**：自驾 / 大巴至泰顺（泰顺有高铁站更便捷）。
- **贴士**：北涧桥与溪东桥相距近、最经典；雨后溪水丰美；廊桥文化园可深读。

### 文成百丈漈
- **位置**：文成县（温州市区西南约 1.5h）。
- **特色看点**："中华第一高瀑"，三级瀑布（一漈 207m），落差巨大、气势磅礴；刘基（刘伯温）故里在文成。
- **门票（参考）**：约 ¥65（以官方为准）。
- **建议时长**：半日。
- **交通**：自驾 / 大巴至文成。
- **贴士**：丰水期（尤其雨后）最壮观；台阶多、穿好鞋。

### 洞头海岛
- **位置**：洞头区（温州东南海上，跨海大桥连陆）。
- **特色看点**："百岛洞头"，半屏山（海上断崖）、仙叠岩、望海楼、妈祖文化；海鲜与灯塔。
- **门票**：部分景点收费（以现场为准）；跨海大桥免费通行。
- **建议时长**：1 日。
- **交通**：自驾 / 公交经跨海大桥。
- **贴士**：与市区近，半日海岛游可行。

## 五、户外探险

### 飞拉达（岩壁探险）
- **位置**：乐清 / 永嘉等岩壁基地（如雁荡周边）。
- **特色看点**："飞拉达"（Via Ferrata）铁索攀岩，沿崖壁钢索攀爬，俯瞰峡谷；A 线入门、B 线进阶。
- **门票（参考）**：A 线约 ¥188（以运营方为准）。
- **建议时长**：2–3 小时。
- **交通**：景区内 / 自驾。
- **贴士**：需安全装备与教练；恐高慎选；与雁荡串联。

## 六、实用信息

- **经典 1 日（雁荡）**：灵峰（日 + 夜）→ 灵岩（飞渡）→ 大龙湫，宿响岭头。
- **经典 2 日**：Day1 雁荡；Day2 楠溪江古村 + 漂流，或江心屿 + 五马街（市区）。
- **交通贴士**：雁荡山有高铁站最方便；楠溪江新通高铁；泰顺 / 文成建议自驾；台风季（7–9 月）关注船 / 桥 / 景区开放。
- **避坑**：雁荡"野导"与高价香谨慎；漂流注意安全与天气；廊桥分散，规划路线。
- **联游**：台州（神仙居，高铁约 1h）、宁波（1.5h）、福州（经高铁南下的福建山水）。
