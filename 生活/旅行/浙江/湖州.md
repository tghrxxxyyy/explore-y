# 湖州

> "太湖之滨，丝绸之府，竹茶之地。"莫干山的清凉、南浔的百间楼、太湖边的龙之梦——湖州是上海人的避暑后花园，也是"绿水青山就是金山银山"理念的发源地。

> ⚠️ 票价说明：莫干山、南浔、龙之梦各项目收费，太湖度假区免费；下列为 2026-07 参考价，以景区官方为准。

---

## 一、城市速览

- **城市特色**：太湖南岸唯一地级市、丝绸之府、湖笔之乡、"两山"理念发源地（安吉余村）；莫干山避暑、南浔古镇、太湖旅游。
- **行政区划（景点分布）**：**吴兴区**（市中心、太湖度假区）；**南浔区**（南浔古镇）；**德清县**（莫干山、下渚湖）；**长兴县**（太湖龙之梦、金钉子）；**安吉县**（竹海、余村、Hello Kitty 乐园）。
- **怎么去**：
  - 高铁：湖州站（高铁枢纽），杭州约 30min、上海约 1.5h（经沪苏湖高铁更近）、南京约 1h。
  - 飞机：最近杭州萧山 / 上海。
- **最佳季节**：**春秋最佳**；夏季莫干山 / 安吉竹海避暑；冬季温泉（长兴 / 安吉）。
- **本地特色美食**：丁莲芳千张包子、周生记馄饨、太湖三白、百鱼宴、诸老大粽子、安吉白茶、新市酱羊肉。
- **住宿建议**：避暑住**莫干山 / 安吉**民宿（洋家乐闻名）；逛古镇住**南浔**；玩乐园住**太湖龙之梦**酒店群。

## 二、莫干山（清凉世界）

### 莫干山 · 江南第一山
- **位置**：德清县莫干山镇（湖州市区西北约 1h 车程，高铁"德清"转）。
- **特色看点**："江南第一山"，以竹、云、泉、别墅"四胜"闻名；毛泽东下榻处（皇后饭店）、蒋介石官邸（松月庐）、武陵村、剑池（莫干 / 干将铸剑传说）、庾村（民国风情小镇）；避暑胜地，民宿"洋家乐"发源。
- **门票（参考）**：莫干山门票 + 景交约 ¥150（单门票约 ¥85，学生 / 老人 ¥47.5；以官方为准）。
- **开放时间**：约 8:00–17:00。
- **建议时长**：1–2 日（建议住山上民宿）。
- **交通**：德清站转公交 / 自驾上山（盘山公路）。
- **贴士**：夏季避暑最佳；民宿体验是核心（裸心谷等高端洋家乐）；庾村文艺咖啡 + 民国风。

## 三、南浔古镇（中西合璧）

### 南浔 · 百间楼
- **位置**：南浔区南浔镇（湖州市区东南约 40 km，高铁"南浔"站）。
- **特色看点**："江南古镇的巨富之镇"，中西合璧（丝商宅第）：小莲庄（刘镛园 + 嘉业堂藏书楼）、张石铭旧宅（江南第一民宅，巴洛克风）、刘氏梯号（红砖洋楼"小红楼"）、百间楼（临河百间民居，最出片）、辑里湖丝馆。
- **门票（参考）**：联票约 ¥85（小莲庄 ¥25 / 刘氏梯号 ¥20 / 张石铭 ¥19 等，游船 ¥40；以官方为准）。
- **建议时长**：半日–1 日（建议住一晚看夜景）。
- **交通**：高铁南浔站 / 自驾 / 湖州转公交。
- **贴士**：百间楼清晨无人最出片；中西合璧宅第是南浔独特处；比起乌镇更安静大气。

## 四、太湖龙之梦（乐园集群）

### 太湖龙之梦乐园（长兴）
- **位置**：长兴县图影旅游度假区（太湖南岸，湖州市区东南）。
- **特色看点**：超大型旅游综合体，动物世界、古镇（太湖古镇，免费夜景 + 演艺）、冰雪世界、嬉水世界、大马戏、湿地；"一票玩一天"的亲子度假地。
- **门票（参考）**：动物世界约 ¥100（3 日有效）；古镇免费；冰雪世界约 ¥80；嬉水世界约 ¥120；大马戏约 ¥180（以官方为准，套票更划算）。
- **建议时长**：1–2 日。
- **交通**：湖州 / 长兴自驾 / 公交；龙之梦有酒店群可住。
- **贴士**：太湖古镇夜景免费、灯火 + 水秀值得；动物世界 + 大马戏亲子首选；套票省心。

### 太湖度假区（吴兴 / 滨湖）
- **位置**：吴兴区太湖南岸（湖州太湖旅游度假区）。
- **特色看点**：太湖岸线、渔人码头、黄金湖岸、喜来登"指环"酒店；太湖风光 + 骑行 + 湖鲜；月亮广场音乐喷泉。
- **门票**：度假区**免费**（部分项目收费）。
- **建议时长**：半日（傍晚看湖）。
- **交通**：湖州公交 / 自驾。
- **贴士**：傍晚太湖落日 + 喷泉；吃太湖三白（白鱼 / 白虾 / 银鱼）。

## 五、安吉与长兴

### 安吉 · 竹海 / 余村 / Hello Kitty
- **位置**：安吉县（湖州市区西南约 1h）。
- **特色看点**："中国竹乡"，大竹海（《卧虎藏龙》取景）、竹博园（熊猫）、余村（"两山"理念发源地，美丽乡村样板）、Hello Kitty 乐园（亲子）、江南天池（抽水蓄能电站 + 滑雪）；
- **门票（参考）**：大竹海约 ¥58；Hello Kitty 约 ¥210；竹博园约 ¥80（以官方为准）。
- **建议时长**：1–2 日。
- **交通**：安吉站（高铁）/ 自驾。
- **贴士**：亲子去 Hello Kitty、竹博园看熊猫；避暑去竹海；滑雪去江南天池（冬季）。

### 长兴 · 金钉子 / 古生态
- **位置**：长兴县（湖州北，太湖畔）。
- **特色看点**：金钉子远古世界（二叠纪–三叠纪界线层型，地质奇观）、扬子鳄保护区、江南红村（新四军苏浙军区旧址）；与龙之梦相邻。
- **门票（参考）**：金钉子约 ¥80（以官方为准）。
- **建议时长**：半日。
- **交通**：长兴站 / 自驾。
- **贴士**：地质爱好者必看；与龙之梦串联。

### 下渚湖（德清）
- **位置**：德清县（莫干山旁）。
- **特色看点**：江南最大湿地之一，芦苇、水禽、朱鹮（人工繁育放归）；泛舟湿地。
- **门票（参考）**：约 ¥80（含船；以官方为准）。
- **建议时长**：半日。
- **交通**：德清站转。
- **贴士**：观鸟、湿地慢游；与莫干山组合。

## 六、实用信息

- **经典 2 日（南浔 + 太湖）**：Day1 南浔古镇（住一晚）；Day2 太湖龙之梦（动物 + 古镇夜景）。
- **经典 2 日（莫干山避暑）**：Day1 莫干山（剑池 + 庾村）；Day2 下渚湖 / 民宿泡汤。
- **交通贴士**：沪苏湖高铁通后上海约 1.5h 内；莫干山 / 安吉自驾最方便；南浔通高铁。
- **避坑**：莫干山民宿旺季贵、早订；太湖边湖鲜按市价；龙之梦套票算清天数。
- **联游**：杭州（30min）、苏州（经太湖）、嘉兴（南浔近）、无锡（太湖对岸）。
