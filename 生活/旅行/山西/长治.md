# 长治

> "上党从来天下脊。"太行山在长治隆起最壮美的褶皱——八泉峡的碧水悬瀑、通天峡的峡湖倒影，加上八路军总部的红色记忆，让这座"太行明珠"刚柔并济。

## 🎯 城市速览

- **定位**：晋东南中心、太行山大峡谷门户、红色抗战圣地
- **核心看点**：太行山大峡谷（八泉峡）、通天峡、八路军太行纪念馆、上党门、神农温泉、天脊山
- **最佳季节**：6–8 月（太行避暑，均温 20℃出头）、9–10 月（红叶）；四季皆宜山水
- **建议游玩**：2–3 天

## 🏞️ 景点卡片

### 太行山大峡谷·八泉峡

- **位置**：长治市壶关县大峡谷镇
- **特色看点**：太行山水的精华，"世界级极品峡谷"；高峡平湖、峡谷索道、观光电梯"天空之城"、游船穿洞，山水与工程奇观结合；红豆峡、青龙峡可联游
- **门票参考价**：门票¥100；含游船+索道+电梯+景交套票约¥180 起（以官方为准）
- **开放时间**：7:30–16:30（景交收班较早）
- **建议时长**：1 天
- **交通**：壶关县/长治乘景区直通车；自驾导航"八泉峡景区"
- **贴士**：套票最值、省体力；夏季水景最佳；山区天气多变带雨具

### 通天峡

- **位置**：长治市平顺县梯后村
- **特色看点**："北方小九寨"，峡湖碧绿、飞瀑流泉、红岩赤壁；乘索道俯瞰、游船入画，亲水与登高皆宜
- **门票参考价**：¥90（含索道+游船+景交套票约¥180）
- **开放时间**：8:00–17:00
- **建议时长**：半日
- **交通**：平顺县转景区车/自驾；距长治约 1.5h
- **贴士**：与八泉峡可二选一或两日联游；游船段最出片

### 八路军太行纪念馆

- **位置**：长治市武乡县太行街
- **特色看点**：全国唯一全面反映八路军抗战史的大型专题馆；进驻武乡的总部旧址群（王家峪、砖壁）可一并参观，红色研学首选
- **门票参考价**：免费（需预约/证件）
- **开放时间**：8:30–17:00（周一可能闭馆）
- **建议时长**：2 小时
- **交通**：武乡县公交/自驾；郑太高铁"武乡东"站
- **贴士**：配合实景演出《太行山上》体验更完整；适合亲子红色教育

### 上党门

- **位置**：长治市潞州区（市区）
- **特色看点**：隋代上党郡署大门遗存，鼓楼、钟楼对峙，"风驰""云动"二匾沧桑；长治城市原点与历史地标
- **门票参考价**：免费
- **开放时间**：全天（外观）；院内约 8:00–18:00
- **建议时长**：0.5–1 小时
- **交通**：市区公交/步行
- **贴士**：顺游潞安府城隍庙；了解"上党"地名由来

### 神农温泉 / 太行水乡

- **位置**：长治市（屯留/壶关一带）
- **特色看点**：太行山间温泉度假，神农温泉可泡汤缓解徒步疲劳；太行水乡（浊漳河段）有漂流、亲水与乡村体验
- **门票参考价**：温泉约¥80–150（以官方为准）；水乡低价或免费段
- **开放时间**：多为 9:00–22:00（温泉）
- **建议时长**：半日–1 天
- **交通**：自驾/市区转车
- **贴士**：徒步大峡谷后泡汤最佳；亲子亲水选水乡

### 天脊山 / 灵空山

- **位置**：长治市平顺县/沁源县
- **特色看点**：天脊山绝壁飞瀑、栈道悬空；灵空山以圣寿寺与"油松之王"九杆旗闻名，是太行深处的清幽秘境
- **门票参考价**：约¥50–80（以官方为准）
- **开放时间**：8:00–17:30
- **建议时长**：半日
- **交通**：县域转车/自驾
- **贴士**：小众原生态，适合深度自驾；灵空山秋季色彩绚烂

长子炒饼、长治腊驴肉、上党烩面、壶关羊汤、潞城甩饼、沁县元宵、武乡枣糕、荤汤素饺。山野食材丰富，党参炖鸡、小河鱼是地方特色。

## 一、景点详细攻略

### 太行山大峡谷·八泉峡

- **套票最值**：门票+游船+索道+电梯+景交约¥180起，省体力
- **精华路线**：游船穿洞→观光电梯"天空之城"→索道俯瞰→峡谷栈道
- **夏季最佳**：水景最美，山区天气多变带雨具

### 通天峡

- **与八泉峡**：可二选一或两日联游
- **游船段最出片**：峡湖碧绿、飞瀑流泉

### 八路军太行纪念馆

- **红色研学**：配合实景演出《太行山上》体验更完整
- **武乡东站**：郑太高铁可达，交通便利

## 三、交通指南

### 外部交通

- **高铁**：长治东站（郑太高铁），郑州至长治约1.5小时
- **自驾**：二广高速长治出口

### 市内交通

- **公交**：市区覆盖较全，票价¥1–2
- **出租车**：起步价¥8，打车软件可用

### 前往各县

- **壶关（八泉峡）**：长治乘景区直通车约1小时
- **平顺（通天峡）**：长治自驾约1.5小时
- **武乡（八路军纪念馆）**：长治乘高铁至武乡东站约20分钟

> 来源：长治市交通运输局

## 七、2日行程规划

### Day 1：太行山大峡谷·八泉峡

- **早上**：长治乘景区直通车至八泉峡（约1小时）
- **上午**：游船穿洞→观光电梯"天空之城"→索道俯瞰（约4小时）
- **中午**：景区附近午餐
- **下午**：峡谷栈道、瀑布群（约3小时）
- **傍晚**：返回长治
- **住宿**：长治市区

### Day 2：八路军太行纪念馆 + 通天峡

- **上午**：长治乘高铁至武乡东站（约20分钟），八路军太行纪念馆（约2小时）
- **中午**：武乡午餐
- **下午**：返回长治，前往通天峡（约1.5小时车程），游船入画、飞瀑流泉（约3小时）
- **傍晚**：返回长治，结束行程

> 来源：长治市文旅局推荐路线
