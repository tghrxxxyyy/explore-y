# 山西（省）

![山西代表风光](/images/山西.png)

> 表里山河，古建之乡。山西是全国现存古建筑数量最多的省份，元代以前的木构建筑占全国的七成以上。云冈石窟的北魏佛韵、平遥古城的明清市井、五台山的梵音钟磬、壶口瀑布的黄河咆哮、晋商大院的砖雕门楼，串起一部"地上文物看山西"的立体史书。

**省会：** 太原　**特点：** 古建第一大省、晋商文化发源地、黄河与长城交汇的表里山河；面食与老陈醋之乡，煤铁之地的硬核与温情并存

## 🍜 美食地图（按片区：晋北 / 晋中 / 晋南 / 晋东南）

- **晋北（大同 / 朔州 / 忻州）**：刀削面（大同东方削面为代表）、浑源凉粉、莜面栲栳栳、羊杂割、大同兔头、朔州油糕、忻州瓦酥、定襄蒸肉、五台台蘑炖豆腐；口味偏咸鲜、喜羊肉与杂粮
- **晋中（太原 / 晋中 / 阳泉 / 吕梁）**：太原头脑（傅山女考，配黄酒）、过油肉、灌肠、莜面鱼鱼、晋阳红烧丸子；晋商口味——平遥牛肉、太谷饼、祁县油茶、寿阳豆腐干；阳泉漂抿曲、吕梁汾阳核桃、孝义火烧；老陈醋是全域灵魂蘸料
- **晋南（临汾 / 运城）**：运城羊肉泡馍、解州羊肉泡、闻喜煮饼、稷山麻花、临汾牛肉丸子面、翼城霸王鞭（小吃）、黄河鲤鱼焙面；晋南面食与陕西风味相近，油酥火烧、凉粉系列丰富
- **晋东南（长治 / 晋城）**：长子炒饼、长治腊驴肉、上党烩面、壶关羊汤、晋城饸饹面、高平烧豆腐、阳城烧肝、沁水柿饼；潞城甩饼、陵川党参炖土鸡，山野风味浓

## 🗓️ 最佳旅游季节

- **春季（4–5 月）**：五台山杜鹃、大同华严寺春日古建、平遥古城清明文化节、运城永乐宫梨花；气温回暖，古建踏青正宜；悬空寺、恒山 4 月初常恢复开放
- **夏季（6–8 月）**：太行山大峡谷（八泉峡）、通天峡、芦芽山、庞泉沟避暑正当时，均温 20℃出头；五台山、绵山、云丘山凉爽宜人；壶口瀑布夏季水量最盛、气势最足
- **秋季（9–11 月）**：最舒适季节，太行红叶（王莽岭、八泉峡）、五台山秋色、平遥金秋、碛口古镇黄河落日；国庆后游客明显回落，摄影黄金期
- **冬季（12–2 月）**：云冈石窟雪景、平遥古城雪中明清街巷、壶口瀑布"冰瀑玉带"奇观、五台山银装素裹；春节逛平遥年味社火、忻州古城庙会氛围浓；部分山区景区开放时间缩短

## 🚄 交通概况

- **航空**：太原武宿国际机场（全省最大枢纽，通达全国主要城市）、大同云冈机场、运城张孝机场、长治王村机场、临汾尧都机场，及吕梁大武机场等支线机场，多数地级市通航
- **高铁/动车**：大西高铁纵贯（大同—忻州—太原—晋中—临汾—运城，直连西安）、石太客专（石家庄—太原）、郑太高铁（郑州—晋城—长治—太原）、张大高铁（张家口—大同）；太原南站为全省高铁核心，省内"3 小时交通圈"基本成型
- **普铁/公路**：同蒲铁路南北纵贯；高速路网密集（二广、京昆、青银、荣乌等），自驾串联古建、太行、黄河景区便利，但县域景点间距较远，山区建议自驾/包车
- **城市内**：太原地铁 2 号线运营，各大古城（平遥、忻州、大同、祁县）步行+电瓶车接驳；五台山、壶口等景区内有旅游专线/摆渡车

> ⚠️ 票价与开放时间以景区官方公示为准（数据参考 2026-07）。60 周岁以上老人、6 周岁（或 1.4 米）以下儿童、现役军人、残疾人等多享免票或半价，出行请带好证件。
