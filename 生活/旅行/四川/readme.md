# 四川（省）

![四川](/images/四川.png)

> 天府之国，巴蜀腹地，熊猫故乡。从成都平原的烟火茶馆到川西高原的雪山海子，从麻辣鲜香的火锅到世界遗产云集的山水——四川，是中国地理与人文最富层次的省份之一。

**省会：** 成都　**特点：** 西部经济与科技重镇、熊猫故乡、古蜀文明（三星堆/金沙）发源地；川菜与火锅甲天下；高山峡谷、高原草甸、竹海温泉兼备，宜居宜游

## 🍜 分地区美食地图

- **成都平原（成都 / 德阳 / 绵阳 / 眉山 / 资阳 / 雅安）**：川菜正宗本味——麻婆豆腐、回锅肉、夫妻肺片、宫保鸡丁、水煮鱼；成都火锅与串串香、担担面、钟水饺、龙抄手、甜水面；绵阳米粉、江油肥肠；德阳连山回锅肉、孝泉果汁牛肉；眉山东坡肘子、彭山甜皮鸭；雅安砂锅雅鱼、荥经棒棒鸡；资阳安岳柠檬宴
- **川南（宜宾 / 泸州 / 自贡 / 内江 / 乐山）**：盐帮菜与河鲜为主——自贡冷吃兔、富顺豆花、火边子牛肉；内江牛肉面、大千干烧鱼；泸州古蔺麻辣鸡、合江荔枝、泸州白糕；宜宾燃面、李庄白肉、芽菜扣肉、竹海全竹宴；乐山甜皮鸭、跷脚牛肉、钵钵鸡、豆腐脑、夹江豆腐乳
- **川北·川东北（广元 / 巴中 / 达州 / 南充 / 广安 / 遂宁）**：家常川味与小吃——广元蒸凉面、剑门豆腐；巴中腊肉、通江银耳；达州灯影牛肉、宣汉黄油饼；南充锅盔凉粉、川北凉粉、张飞牛肉、保宁醋；广安岳池米粉、武胜猪肝面；遂宁豆腐干、卓筒井盐
- **攀西（攀枝花 / 凉山州）**：阳光食材与民族风味——攀枝花芒果、盐边油底肉、浑浆豆花；凉山坨坨肉、苦荞粑粑、邛海烤鱼、会理黑山羊、彝家酸菜汤、建昌板鸭
- **川西高原（阿坝州 / 甘孜州）**：藏羌风味——酥油茶、糌粑、牦牛肉、青稞酒、雅江松茸、丹巴香猪腿、九寨沟藏式火锅、甘孜酸奶、道孚牛羊肉

## 🗓️ 最佳旅行季节

- **春季（3–5 月）**：成都平原菜花金黄、眉山樱花、乐山犍为嘉阳小火车油菜花海；川西高原冰雪初融、杜鹃待放；气候宜人，是多数地区的舒适季
- **夏季（6–8 月）**：成都平原偏热，建议转战高原避暑——九寨沟（均温 18℃）、黄龙、稻城亚丁、四姑娘山、若尔盖草原、色达、牛背山皆是避暑天堂；宜宾蜀南竹海、雅安碧峰峡也清凉宜人
- **秋季（9–11 月）**：四川最惊艳的季节。九寨沟彩林、稻城亚丁金黄草甸与蓝湖、巴中光雾山亚洲最大红叶（10 月下旬–11 月上旬）、米亚罗红叶；成都平原秋高气爽，国庆后游客明显回落
- **冬季（12–2 月）**：攀枝花、凉山州西昌避寒正当时；川西高原雪景壮美（峨眉山金顶、西岭雪山、达古冰川）；温泉季——峨眉山、海螺沟、青城山道温泉；春节逛阆中古城年味最浓

## 🚄 交通概况

- **航空**：成都双流、成都天府（四川最大枢纽，双机场格局）两大机场， plus 九黄（九寨黄龙）、绵阳、泸州、宜宾、南充、达州、西昌、康定、稻城亚丁、广元、巴中等支线机场，多数地级市通航
- **高铁/动车**：成都为中心——成渝（成都—重庆）、西成（成都—西安，经广元/绵阳/德阳）、成贵（成都—贵阳，经乐山/宜宾/泸州）、成昆（成都—昆明，经眉山/乐山/西昌）、川青铁路（成都—黄龙九寨站，2024 通车）、成达万（在建）等，成都平原与川南已基本成网；川西高原以公路为主
- **公路**：高速路网密集，自驾串联大熊猫走廊、大九寨、大香格里拉环线十分便利；川西高原（阿坝/甘孜）多山路，冬季需防滑链
- **城市内**：成都地铁成网（多条线路+天府机场线）；乐山、绵阳、宜宾、泸州等公交+旅游专线接驳景区间；九寨沟/稻城等远端景区以观光车+官方直通车为主
