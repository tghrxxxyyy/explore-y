# 江西（省）

![江西代表风光](/images/江西.png)

> 赣鄱大地，红色摇篮。庐山雄奇、井冈巍峨、三清秀绝、龙虎仙逸，瓷都景德镇千年窑火不熄，婺源徽派村落春染金黄——一山一水一圣人，红绿古三色交融，是江西最鲜明的底色。

**省会：** 南昌　**特点：** 红色革命圣地（井冈山/瑞金/八一南昌）、山水奇观（庐山/三清山/龙虎山/武功山）、千年瓷都（景德镇）与最美乡村（婺源）；赣菜鲜辣鲜香，米粉瓦罐汤遍布街巷

## 🍜 美食地图（按片区）

- **赣北（南昌 / 九江 / 景德镇 / 鹰潭 / 上饶）**：南昌拌粉、瓦罐汤、藜蒿炒腊肉、鄱阳湖胖鱼头；庐山石鸡/石鱼/石耳"三石"、浔阳鱼片；景德镇冷粉、饺子粑、碱水粑、瓷泥煨鸡；鹰潭天师板栗、上清豆腐；上饶铅山烫粉、婺源荷包红鲤鱼、糊豆腐、汽糕、清明果
- **赣中（萍乡 / 宜春 / 新余 / 吉安 / 抚州）**：萍乡辣（萍乡炒粉、莲花血鸭、烟熏肉、小炒肉）；宜春慈化鸡、包圆、富硒温汤发糕；新余麻辣鸭三件、仙女湖鱼；吉安安福火腿、永和豆腐、遂川板鸭、吉州薄酥饼；抚州临川牛杂、南丰蜜桔、资溪面包、黎川芋糍
- **赣南（赣州）**：赣南小炒鱼、宁都三杯鸡、瑞金牛肉汤、兴国米粉鱼（四星望月）、客家酿豆腐、信丰萝卜饺、赣州鲜笋、脐橙（秋季时令）

## 🗓️ 最佳旅游季节

- **春季（3–5 月）**：婺源江岭、篁岭油菜花海（3 月上旬–4 月上旬盛花期）铺满梯田，是江西最负盛名的春景；井冈山、明月山杜鹃次第绽放；气候温和宜人
- **夏季（6–8 月）**：庐山（山顶均温约 22℃）、井冈山、三清山、武功山高山草甸是避暑胜地；丰水期瀑布磅礴（三叠泉、庐山、明月山云谷飞瀑）；武功山露营观银河正当时
- **秋季（9–11 月）**：最舒适季节，三清山云海、龙虎山丹霞秋色、庐山西海层林尽染；赣南脐橙、南丰蜜桔成熟；国庆后游客回落
- **冬季（12–2 月）**：鄱阳湖（吴城/南矶山）越冬候鸟（11 月–次年 3 月，白鹤等珍禽）是绝对主角；庐山、三清山雾凇雪景壮美；宜春温汤镇泡富硒温泉驱寒

## 🚄 交通概况

- **航空**：南昌昌北国际机场（全省枢纽，通达全国及东南亚）、景德镇罗家机场、九江庐山机场、赣州黄金机场、井冈山机场、宜春明月山机场、上饶三清山机场等，多数地级市通航
- **高铁/动车**：沪昆高铁（上海—杭州—南昌—长沙—昆明）横贯东西，合福高铁（合肥—上饶—福州）与京九（昌赣）高铁纵贯南北，赣深高铁（赣州—深圳）打通南下通道；南昌"十字"高铁枢纽基本成型，省内"2 小时交通圈"覆盖主要景区
- **普铁**：京九、沪昆两大干线交汇南昌，向莆、皖赣等线联通周边
- **公路**：高速路网密集（杭瑞、福银、大广、济广等），环庐山、环鄱阳湖、武功山—明月山等景区自驾友好；庐山西海、婺源、三清山等山区道路弯多，建议预留时间
- **城市内**：南昌地铁（1–4 号线）成网；景德镇、九江、赣州等公交+旅游专线接驳景区间；庐山、三清山、武功山景区内须乘观光车/索道

> ⚠️ 票价与开放时间以景区官方公示为准（数据参考 2026-07）。60 周岁以上老人、6 周岁（或 1.4 米）以下儿童、现役军人、残疾人等多享免票或半价，出行请带好证件。
