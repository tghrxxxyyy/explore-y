# 副业 · 合规与税务（国内必看）

> 中国做能盈利的小产品，**第一步就是获取经营主体**。个人身份几乎「走不通」商业闭环。本文讲清个体户 vs 公司、ICP 备案与许可证、等保、微信支付、税务，帮你少踩坑。

## 一、为什么必须「先有主体」

你不可能用自己身份证商业化运营一个产品。没有营业执照，以下全部做不了：
- 申请 **微信支付 / 支付宝商户接口**
- 上架 **微信小程序**（个人主体限制极多）
- 做 **ICP 备案**（个人备案不允许任何商业行为）
- 给 **企业客户开发票**
- 签正式商业合同

> ⚠️ 用个人微信悄悄收款短期可行，但一旦被举报/被查，微信支付会直接**封停收款、冻结资金、申诉无门**；个人备案网站挂「购买按钮/微信收款码」被查到，备案直接注销、域名停止解析。

**结论**：在中国做能盈利的小产品，要么注册 **个体工商户**，要么注册 **公司**。

## 二、个体工商户 vs 有限责任公司

| 维度 | 个体工商户 | 有限责任公司 |
| --- | --- | --- |
| 注册速度 | 快，几天（线上/工商局） | 慢，需地址、章程、刻章 |
| 记账要求 | 简单，可核定征收 | 须建账，需代账 |
| 维护成本 | 极低 | 年代账 + 地址 + 银行账户 |
| 债务责任 | **无限连带**（个人/家庭财产） | 有限（仅出资额为限） |
| 合伙/融资 | 不可 | 可以 |
| ICP 备案 | 可（单位主体） | 可 |
| H5 支付 | **不支持**（官方限制） | 支持 |
| 商家转账/返佣 | 开通难、审核严 | 相对容易、额度高 |

**建议**：绝大多数个人副业/轻量数字产品，**起步首选个体工商户**；若涉及合伙、融资、B2B 大额、高频分销返现，直接注册公司。

> 注：部分省份对个体户申请 ICP 许可证较严格，且个体户通常无法做用户注册/支付等交互功能、无法申请算法备案与等保定级——若产品要这些，需升级为公司。

## 三、ICP 备案 vs ICP 许可证（最容易混的两个）

- **ICP 备案**：所有境内服务器网站**强制**要做（通过阿里云/腾讯云等服务商提交），免费。仅证明「谁建的站」。
- **ICP 许可证（增值电信业务经营许可证）**：**经营性网站**才需要（在线销售、付费会员、广告盈利、会员收费）。
  - 办理条件：营业执照经营范围含「增值电信业务/互联网信息服务」、境内服务器、部分省份需社保证明。
  - 周期：20–60 个工作日，官方免费（代办约 3000–8000 元）。
  - 若涉及 **第三方商家入驻（淘宝模式）**，还需额外办 **EDI 许可证**。
- 判断：只展示商品/资讯 → 只需备案；在线交易收费 → 需许可证。

## 四、微信支付 / 支付宝商户

- 必须 **营业执照 + 对公/经营者账户**。
- 个体户：可开通基础商户（**H5 支付受限**）；公司：全功能（含 H5 支付、商家转账、更高额度）。
- 微信小程序：企业主体才能开通支付、用户体系等完整能力；个人主体只能做工具类展示。

## 五、等保与数据安全（产品上线后）

- **等保 2.0**：系统按重要度分五级，涉及用户信息的系统通常需**定级、测评、备案**。
- **个人信息保护法 / 数据安全法**：采集须告知同意、最小必要、境内存储优先；跨境传输有严格审批。
- 若做 AI 产品处理用户数据：注意训练数据合规、用户隐私、内容安全（生成内容需有审核机制）。

## 六、税务（个体户如何缴税）

- **核定征收**：多数副业个体户可申请「定期定额征收」，按行业核定税额，简单低成本。
- **双免个体户**（部分园区政策）：季度销售额不超 30 万（小微免征增值税），个税核定后实际税负很低——适合小型软件外包/技术服务。
- **发票**：个体户可开普通发票；若客户要 **增值税专票**，往往需升级为小规模/一般纳税人公司（国企/大厂客户常强制要求专票）。
- 建议：用**园区集群地址 + 代账**降低合规成本；保留合同、发票、银行流水三件套。

## 七、跨境收款（出海副业）

- 海外收款：Stripe / Paddle（Paddle 更适合数字商品、代扣税）、PayPal、Wise。
- 合规：通过个体户/公司签约，外汇入账按「服务贸易」申报；注意反洗钱与年度额度。
- 国内提现：绑定主体银行账户，保留交易凭证应对外汇核查。

## 八、副业「合规自检清单」

- [ ] 产品要收费 → 先注册个体户/公司（别用个人微信收款）。
- [ ] 网站要交易 → 办 ICP 许可证（纯展示只需备案）。
- [ ] 做平台（商家入驻）→ 额外办 EDI 许可证。
- [ ] 接用户数据 → 做等保定级 + 隐私合规。
- [ ] 用开源二开 → 守许可证（MIT/Apache 随意，AGPL/GPL 注意开源义务，dify/FastGPT 看商业授权）。
- [ ] 开发票 → 客户要专票就升公司；个体户用核定/双免降负。
- [ ] 出海 → Stripe/Paddle + 主体签约 + 外汇申报。
- [ ] 不影响主业 → 看劳动合同竞业/兼职条款。

> 一句话：**副业可以小，但主体不能省。** 先合规，再放大，别等被封号/补税才后悔。
