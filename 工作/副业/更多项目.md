# 副业 · 更多开源项目与变现思路

> 在上一份「github项目推荐」基础上，补充更多可直接借鉴或二次开发的项目。

## 可直接二开做产品的开源
| 项目 | 用途 / 变现思路 |
| --- | --- |
| `calcom/cal.com` | 开源日程预约系统，可做付费 SaaS 或行业定制。 |
| `logseq/logseq` | 开源笔记/知识管理，可做成私有部署服务。 |
| `AppFlowy-IO/AppFlowy` | Notion 开源替代，企业私有化需求大。 |
| `maybe-finance/maybe` | 个人理财开源，可做订阅制。 |
| `PostHog/posthog` | 产品分析开源，替代 Mixpanel 做部署服务。 |

## 练手与素材
| 项目 | 用途 |
| --- | --- |
| `public-apis/public-apis` | 免费 API 大全，做产品的数据源。 |
| `EbookFoundation/free-programming-books` | 技术学习资料。 |
| `awesome-selfhosted/awesome-selfhosted` | 找可部署的自托管软件。 |
| `n8n-io/n8n` | 自动化工作流，接企业单。 |

## 变现路径小结
1. **SaaS**：用 `cal.com`/`PostHog` 类二开，做垂直行业版本订阅收费。
2. **部署服务**：帮中小企业私有化部署 `Logseq`/`AppFlowy`，收年费。
3. **自动化外包**：用 `n8n` 帮商家打通电商/客服/表单，按项目收费。
4. **模板/课程**：把部署与二开经验写成教程/视频变现。
5. **开源赞助**：维护受欢迎项目，开通 GitHub Sponsors。

> 合规提醒：二开须遵守原项目许可证（多为 MIT/AGPL），AGPL 项目修改后提供网络服务需开源衍生代码。
