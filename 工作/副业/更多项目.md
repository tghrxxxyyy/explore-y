## 可直接二开做产品的开源

### [`calcom/cal.diy`](https://github.com/calcom/cal.diy) ⭐ ~46.8k（原 `cal.com`，已更名为 cal.diy）
- **简介**：面向所有人的「预约调度基础设施」，支持时区、团队、支付、集成。
- **语言 / 许可证**：TypeScript / **MIT**（商用友好）。
- **官网**：https://cal.diy
- **二开思路**：做付费 SaaS 或行业定制版（医生/教练/咨询师预约），MIT 可闭源商用。
- **注意**：若用其托管品牌/商标需另看商标条款，代码本身 MIT 自由。

### [`logseq/logseq`](https://github.com/logseq/logseq) ⭐ ~44.1k
- **简介**：隐私优先的开源知识管理与协作平台（本地优先 + Git 图谱）。
- **语言 / 许可证**：Clojure / **AGPL-3.0**。
- **官网**：https://logseq.com
- **二开思路**：做企业/个人私有部署的「第二大脑」服务，收年费。
- **注意**：AGPL——修改后提供网络服务须开源衍生代码。

### [`AppFlowy-IO/AppFlowy`](https://github.com/AppFlowy-IO/AppFlowy) ⭐ ~74.3k
- **简介**：AI 协同工作区（项目/维基/团队），开源版 Notion 替代品，强调数据自主。
- **语言 / 许可证**：Dart / **AGPL-3.0**。
- **官网**：https://appflowy.com
- **二开思路**：面向「不想把数据放 Notion 云端」的企业做私有化部署。
- **注意**：AGPL 红线同上；可走其商业授权绕开。

### [`maybe-finance/maybe`](https://github.com/maybe-finance/maybe) ⭐ ~54.4k
- **简介**：人人可用的个人理财应用（资产、负债、投资追踪）。
- **语言 / 许可证**：Ruby / **AGPL-3.0**。
- **二开思路**：做订阅制个人/家庭记账 SaaS，或加「理财顾问」增值服务。
- **注意**：AGPL；其商业版有单独授权。

### [`PostHog/posthog`](https://github.com/PostHog/posthog) ⭐ ~37.3k
- **简介**：产品分析平台（分析、会话回放、特性开关、实验、错误追踪等），自称「自动驾驶产品」工具。
- **语言 / 许可证**：Python（仓库未声明标准 SPDX，以仓库 LICENSE 为准）。
- **官网**：https://posthog.com
- **二开思路**：替代 Mixpanel，给中小企业做私有化分析部署服务。
- **注意**：商用请核对官方许可与托管条款。

## 变现路径小结
1. **SaaS**：用 `cal.diy` / `PostHog` 类二开，做垂直行业版本订阅收费（cal.diy 为 MIT，最省心）。
2. **部署服务**：帮中小企业私有化部署 `Logseq` / `AppFlowy` / `maybe`，收年费（注意 AGPL 开源义务）。
3. **自动化外包**：用 `n8n` 帮商家打通电商/客服/表单，按项目收费。
4. **模板/课程**：把部署与二开经验写成教程/视频变现。
5. **开源赞助**：维护受欢迎项目，开通 GitHub Sponsors。

> ⚠️ 合规提醒：二开须遵守原项目许可证。MIT 类（`cal.diy`）可闭源商用；**AGPL 类（`logseq`/`AppFlowy`/`maybe`）修改后提供网络服务需开源衍生代码**；`n8n` 为 fair-code，商用需看其许可条款。迁移仓库（cal.com→cal.diy）以当前地址为准。
