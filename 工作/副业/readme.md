## 二、为什么程序员适合搞副业（国内更明显）

- **边际成本低**：写一次可卖多次（模板、SaaS、课程、API）。
- **全球市场**：英语 + 代码即可触达海外用户（出海 SaaS）。
- **自动化强**：能用脚本代替重复劳动，AI 工具（Cursor/通义灵码）让 1 人顶 5 人。
- **起步轻**：一台电脑 + 云服务商即可开工。
- **国内平台成熟**：掘金、CSDN、公众号、小红书、B站、知乎、知识星球、小报童，变现链路短。

## 三、六大副业方向（国内版，配文档索引）

1. **独立开发 / SaaS / 小程序**：解决小痛点做工具，订阅/买断变现。→ 灵感见 [`awesome-indie-cn`](https://github.com/kuaijierun/awesome-indie-cn)；二开见 [`cal.diy`](https://github.com/calcom/cal.diy)。
2. **AI 应用 / 智能体**：用 RAG/Agent 做企业知识库、垂直助手，私有化部署收费。→ 练手 [`dify`](https://github.com/langgenius/dify)、[`FastGPT`](https://github.com/labring/FastGPT)。
3. **技术内容创作**：博客、公众号、视频、电子书、付费专栏。→ 素材 [`build-your-own-x`](https://github.com/codecrafters-io/build-your-own-x)、[`free-programming-books`](https://github.com/EbookFoundation/free-programming-books)。
4. **开源赞助 / GitHub Sponsors**：维护受欢迎项目获赞助（2025 累计支付超 5 亿美元）。→ 入口 [`awesome`](https://github.com/sindresorhus/awesome)、[`awesome-selfhosted`](https://github.com/awesome-selfhosted/awesome-selfhosted)。
5. **自托管部署变现**：帮中小企业私有化部署监控/相册/BI/AI，收月费。→ [`1Panel`](https://github.com/1Panel-dev/1Panel)、[`coolify`](https://github.com/coollabsio/coolify)、[`immich`](https://github.com/immich-app/immich)。
6. **技术外包 / 咨询 / 培训**：程序员客栈、电鸭社区、BOSS 直聘 接单，或做企业内训。→ 工具 [`n8n`](https://github.com/n8n-io/n8n)、[`uptime-kuma`](https://github.com/louislam/uptime-kuma)。

## 四、国内接单 / 引流平台速查

| 类型 | 平台 | 特点 |
| --- | --- | --- |
| 小单（500–3000） | 闲鱼、小红书 | 个人网站/小程序，需养号 |
| 专业外包 | 程序员客栈（抽成 20%）、码市、电鸭社区（远程，报价可达 1.5 倍） | 有客户经理/远程项目 |
| 企业单 | BOSS 直聘（搜小公司）、人脉转介 | 老客户转介客单价高 30% |
| 国际单 | Upwork、Toptal、Arc | 需英语，单价高 |
| 品牌引流 | 掘金、CSDN、知乎、B站、公众号、V2EX | 「吸引工作」而非「申请工作」 |

> ⚠️ 合规红线（详见《合规与税务》）：国内做能盈利的产品**第一步就是获取经营主体**（个体户或公司），个人身份无法申请微信支付商户、无法 ICP 备案做商业行为、无法开发票。

## 五、避坑总览

- 别一开始 All in，用业余时间验证（工作日 2h + 周末 6h 是常见节奏）。
- 先有 10 个真实用户，再谈扩张。
- 注意合规：个体户/公司、ICP、等保、税务、海外收款资质。
- 副业不影响主业与竞业协议为前提。
- **许可证红线**：`immich`/`logseq`/`AppFlowy`/`maybe` 等为 **AGPL-3.0**，修改后作网络服务须开源衍生代码；`n8n` 为 fair-code，商用需看条款；`cal.diy` 为 MIT 可闭源商用。
