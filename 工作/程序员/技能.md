# 程序员 · 核心技能（含国产技术栈与 AI 应用）

> 从「会写代码」到「能交付系统，并在中国市场有竞争力」。本文给出技能地图与学习建议，分基础、语言、工程、国产栈、AI 应用、软技能六块，附开源学习资源。

## 一、计算机基础（越往后越值钱）

- **数据结构与算法**：数组/链表/树/图/排序/动态规划——面试与性能优化根基。刷题用 LeetCode / 牛客网。
- **计算机网络**：TCP/IP、HTTP/HTTPS、DNS、WebSocket、TLS。国内常考 HTTPS 握手、HTTP/2/3、CDN。
- **操作系统**：进程/线程、内存、IO、并发、锁。理解 Linux 进程模型对服务端至关重要。
- **数据库**：SQL、索引（B+树）、事务（ACID、隔离级别）、范式；NoSQL（Redis/MongoDB）适用场景。**国产库**：达梦 DM、GaussDB、人大金仓、TiDB（见第四节）。
- **设计模式与架构**：SOLID、分层、微服务、事件驱动、CQRS。国内企业最爱 Spring Boot + 微服务。

> 📘 中文神级笔记：[`CyC2018/CS-Notes`](https://github.com/CyC2018/CS-Notes)、[`doocs/advanced-java`](https://github.com/doocs/advanced-java)（doocs 进阶 Java，覆盖高并发/分布式/JVM）。

## 二、编程语言（国内偏好 + 选型建议）

| 语言 | 国内地位 | 主战场 | 备注 |
| --- | --- | --- | --- |
| **Java** | 企业级绝对主力 | 互联网后端、银行/国企核心系统、信创迁移 | 生态庞大，Spring Boot/Cloud 是标配 |
| **Go** | 云原生首选、上升快 | 微服务、中间件、K8s 生态、高并发 | 并发模型（goroutine）友好，字节重度使用 |
| **Python** | AI/脚本/后端通吃 | 大模型应用、数据、自动化、爬虫 | AI 时代「最该会」的第二语言 |
| **JavaScript / TypeScript** | 前端+全栈必备 | Web、小程序、Node 后端、鸿蒙 ArkTS | TS 已成大型项目事实标准 |
| **C / C++** | 底层/游戏/高性能 | 引擎、交易系统、嵌入式、信创内核 | 性能与可控性强 |
| **Rust** | 系统级新宠、安全 | 信创安全模块、区块链、高性能组件 | 内存安全，学习曲线陡但前景好 |
| **ArkTS** | 鸿蒙原生开发语言 | 鸿蒙应用（手机/车机/ IoT） | 想蹭鸿蒙红利必学，语法近 TS |

**建议**：选 1–2 门深耕（后端 Java/Go，AI Python，系统 C/C++/Rust），前端 TS 人人要会点。

## 三、工程能力（决定你能不能「交付」）

- **版本控制**：Git 工作流（分支、PR、rebase、cherry-pick）。参考 [`tiimgreen/github-cheat-sheet`](https://github.com/tiimgreen/github-cheat-sheet)。国内团队多用 GitLab / Gitee / 工蜂。
- **测试**：单元/集成/端到端，TDD 思维；框架 pytest / Jest / JUnit。AI 在「测试与文档」上增值最大。
- **CI/CD**：GitHub Actions、GitLab CI、Jenkins、Gitea Actions；自动化构建与发布。
- **容器化与云原生**：Docker、Kubernetes、Helm；服务网格 Istio。云厂商：阿里云/腾讯云/华为云。
- **调试与性能**：会看日志、会 profiling（perf、Arthas、Py-Spy）、会排查内存泄漏与慢查询。
- **可观测性**：Prometheus + Grafana + Loki + Jaeger（链路追踪）——国内中大型团队标配。

## 四、国产技术栈（信创能力，国内差异化竞争力）

> 信创（信息技术应用创新）是「2+8+N」国家战略：党政 + 金融/电信/能源 + 全行业国产化。掌握国产栈能吃到政策红利，也是银行/政务岗硬要求。

### 4.1 国产操作系统
- **统信 UOS / 麒麟 OS**（桌面/服务器）：类 Linux，熟悉 UKUI/DDE 桌面、包管理、适配。
- **OpenEuler**（云原生服务器 OS，华为开源）：K8s 友好，国内政企云主流。
- **OpenHarmony / HarmonyOS**（物联网/移动）：用 **ArkTS + ArkUI** 开发，一次开发多端部署。

### 4.2 国产数据库
- **达梦 DM（DMSQL）**：金融/政务迁移 Oracle 首选，熟悉 DMETL 迁移工具。
- **GaussDB（PL/pgSQL 系）**：华为分布式库，适配 PostgreSQL 生态。
- **人大金仓 KingBase、南大通用 GBase**：兼容性迁移场景。
- **TiDB**：国产分布式 NewSQL，兼容 MySQL，互联网使用广。

### 4.3 国产芯片与架构
- **鲲鹏（ARM64）**、**飞腾**、**龙芯（LoongArch）**、**RISC-V**：编译与部署需注意架构差异。

### 4.4 国产中间件与框架
- 东方通、宝兰德（国产中间件）；Spring Boot / gRPC / Qt（跨平台）；MindSpore / PaddlePaddle（国产 AI 框架）。

### 4.5 信创迁移典型路径
- C#/.NET 开发者 → 转 **Java（Spring Boot）+ 达梦/高斯**（语法相近）。
- C++ 开发者 → 续用 C/C++，补 **Rust + OpenEuler 内核/驱动**。
- Python 开发者 → 续用 Python，切 **MindSpore + 昇腾 NPU** 做 AI。
- JS 开发者 → 转 **ArkTS/ArkUI** 做鸿蒙应用。

### 4.6 安全合规（国内必懂）
- **等保 2.0**：《信息安全技术 网络安全等级保护基本要求》，系统按重要度分五级定级、测评、备案。
- **国密算法**：SM2（非对称）/ SM3（哈希）/ SM4（对称），金融与政务系统强制或推荐使用。
- **个人信息保护法 / 数据安全法**：涉及用户数据的系统必须满足合规采集、存储、跨境要求。

## 五、AI 应用开发（当下最被争抢的技能）

> 不要只「会调 API」，要做「能把 AI 嵌入业务流、用大模型重构流程」的人。

| 能力 | 学什么 | 价值 |
| --- | --- | --- |
| **Prompt Engineering** | 结构化提示、少样本/思维链、系统提示设计 | 入门快，所有 AI 应用的起点 |
| **RAG（检索增强生成）** | 向量库（Milvus/Chroma/Qdrant）、Embedding、切片、重排 | 企业知识库标配，解决幻觉 |
| **Agent 编排** | 工具调用、规划-执行、多智能体、MCP 协议 | 2026 「Agent 大年」核心岗 |
| **微调 / 蒸馏** | LoRA/QLoRA、SFT、模型蒸馏、数据集构建 | 模型优化专家年薪 90–150 万 |
| **模型服务化** | vLLM / TGI 推理部署、量化、GPU 资源调度 | 把模型跑起来、跑得便宜 |
| **评测** | 准确率/幻觉率/安全护栏、自动评测集 | 保证 AI 产品可控可上线 |

**国内大模型生态**：DeepSeek、通义千问 Qwen、智谱 GLM、文心一言、豆包、Kimi——多为主流 OpenAI 风格 API，迁移成本低。

> 🛠 练手开源：[`langgenius/dify`](https://github.com/langgenius/dify)（LLMOps 可视化平台，可私有化部署做 AI 副业）、[`labring/FastGPT`](https://github.com/labring/FastGPT)（基于 LLM 的知识库问答，国内团队，私有化友好）、[`OpenBMB/ChatDev`](https://github.com/OpenBMB/ChatDev)（清华多智能体软件开发）、[`vllm-project/vllm`](https://github.com/vllm-project/vllm)（高性能推理）。

## 六、软技能（AI 时代更值钱）

- 把技术问题讲给非技术人听；需求拆解与优先级判断。
- 产品感与业务理解——**AI 替代不了「在约束下做权衡、理解真实需求」**。
- 文档与代码可读性；跨团队协作与责任心。
- 技术影响力（写博客、做分享、维护开源）——副业与求职双加分。
