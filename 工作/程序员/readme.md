## 二、三句话看懂 2026 国内行情（速览）

1. **「冰火两重天」**：传统 CRUD / 前端 / 测试 / 运维岗招聘量相比 2021 年高峰跌去 75%–85%，薪资回落约 30%；而 AI 应用（RAG / Agent / 大模型微调）、信创（国产软硬件适配）、鸿蒙开发岗逆势扩招、薪资大涨。
2. **「35 岁危机」被重新定义**：本质是「技能危机」而非「年龄危机」。只会 CRUD 的 35+ 简历通过率不足 10%；但懂业务、能把 AI 嵌入工作流的 35+ 资深者正迎来「价值重估」，大厂 AI 负责人平均月薪约 13.3 万元（脉脉 2026 数据）。
3. **「程序员平民化」**：AI 编程工具（Copilot / Cursor / 通义灵码 / 豆包）让写代码门槛趋近于零，编程从「昂贵工种」下沉为「平价通用工种」，超级个体（一人公司）崛起，但也意味着纯「搬砖」价值归零。

## 三、本板块怎么用

- **小白**：先读《学习路线》选一条路径，再按《核心技能》补地图，最后用《面试题》自查。
- **在职想转型**：重点读《行业情况》看清机会洼地 + 《职业发展与转型》找岔路 + 《核心技能》的「AI 应用开发」「信创国产栈」两节。
- **求职者**：《面试题》按方向刷，配合 LeetCode / 牛客网；系统设计看 *Designing Data-Intensive Applications*。
