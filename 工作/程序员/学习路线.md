# 程序员 · 学习路线（国内五条路径）

> 一条可落地的「能上手 → 能交付 → 能深入」路线。下文给出 **校招 / 社招转岗 / 信创 / AI 应用 / 35+ 转型** 五条贴合中国市场的路径，可结合自身裁剪。

---

## 路径 A：校招就业路线（学生 / 应届）

**目标**：拿大厂或中厂开发岗 Offer。

### 阶段一：打基础（1–3 个月）
- 一门语言吃透（Java 或 Python 或 JS 任选其一）。
- 数据结构与算法：数组、链表、树、图、排序、二分、动态规划入门（每天 1–2 道 LeetCode/牛客）。
- 计算机基础：HTTP、TCP/IP、操作系统进程线程、SQL 基础。
- 做一个小项目并写 README。

### 阶段二：学工程（3–6 个月）
- Git（分支、PR、rebase）；一门框架（前端 React/Vue，后端 Spring/Express/Django，全栈 Next.js）。
- 数据库：MySQL + Redis，会写索引友好的 SQL。
- 测试：单元测试（pytest/Jest），了解 CI。
- 容器化：Docker 基础，能跑起一个服务。

### 阶段三：冲实习 + 刷题（持续）
- 至少一段实习（大厂/中厂/实验室均可），简历才有「硬通货」。
- 算法题刷到 300+，覆盖剑指 Offer / 热题 HOT 100。
- 做 1–2 个可上线项目，写技术博客沉淀作品集。

### 阶段四：深入方向
- 后端：高并发、分布式、消息队列、微服务。
- 算法/AI：Python、PyTorch、数据处理（走路径 D）。
- 前端：性能优化、工程化、可视化。

> 校招真理：**学历 + 实习 + 算法 + 项目**，四者缺一都可能被刷。

## 路径 B：社招转岗 / 进阶路线（在职 1–5 年）

**目标**：从「能写功能」到「能设计系统」，避免被 AI 平替。

1. 补系统设计：短链、限流、秒杀、Feed 流、缓存架构；读 *Designing Data-Intensive Applications*。
2. 深入一个方向：分布式事务、JVM 调优、前端性能、云原生。
3. 主动吃透一个**业务域**（电商/支付/风控/出行），成为「懂业务的工程师」。
4. 学 AI 应用（路径 D 前两步），把 AI 工具嵌入日常工作流。
5. 输出技术影响力：内部分享、外部博客、开源 PR。

## 路径 C：信创 / 国产替代路线（求稳 + 吃政策红利）

**目标**：进银行/政务/国企 IT 或信创企业，做国产栈迁移与适配。

### 阶段一：夯实通用栈（0–6 个月）
- Java（Spring Boot）或 Go 或 Python 任选一，打好基础。
- Linux 运维基础：Shell、权限、服务管理。

### 阶段二：切入国产栈（6–18 个月）
- **操作系统**：统信 UOS / 麒麟 OS / OpenEuler 上开发、部署、调优。
- **数据库**：达梦 DM（DMSQL）/ GaussDB（PL/pgSQL），学 DMETL 迁移工具。
- **芯片架构**：鲲鹏（ARM64）/ 飞腾 / 龙芯，注意编译差异。
- **鸿蒙**：ArkTS + ArkUI 开发（可选，蹭鸿蒙红利）。

### 阶段三：合规与安全（18 个月+）
- 等保 2.0 基本要求；国密 SM2/SM3/SM4 集成。
- 《网络安全法》《个人信息保护法》基础。
- 考 **工信部「信创工程师」认证** 或 华为 HCIA/HCIP（鲲鹏、GaussDB、鸿蒙）。

> 信创系统开发工程师在 2025 被评为最紧缺技术岗，年薪 50 万+；2027 信创市场预计达 3 万亿。

## 路径 D：AI 应用开发路线（当下最被争抢）

**目标**：成为 AI Application Engineer（RAG / Agent / 微调）。

### 阶段一：大模型基础（小白入门）
- 搞懂 Transformer、预训练/推理、RLHF；了解 DeepSeek / Qwen / GLM 等国产模型。
- Prompt 工程：精准引导、系统提示、思维链。
- API 与 Token：调用成本（输入约 0.5 元/百万 tokens 起），学会控本。

### 阶段二：RAG 工程（核心）
- 向量库：Milvus / Chroma / Qdrant；Embedding 模型选型与微调。
- 切片、检索、重排、引用溯源；企业知识库落地。
- 练手：[`langgenius/dify`](https://github.com/langgenius/dify)、[`labring/FastGPT`](https://github.com/labring/FastGPT) 私有化部署。

### 阶段三：Agent 编排
- 工具调用、规划-执行循环、多智能体协作、**MCP 协议**（连接模型与数据库/API 的事实标准）。
- 用 Cursor / 通义灵码 / 豆包 提升自身开发效率。

### 阶段四：微调与模型服务化（进阶）
- LoRA / QLoRA 微调、SFT 数据构建、模型蒸馏。
- vLLM 推理部署、量化、GPU 资源调度。

> 掌握 RAG + Agent 的程序员薪资溢价约 56%；AI 人才供需比仅 0.5（两个岗抢一人）。

## 路径 E：35+ 转型 / 抗风险路线（在职 8 年+）

**目标**：把「行业经验」变成「驾驭 AI 的核心资产」，避开纯 CRUD 被裁。

1. **盘点资产**：你最懂哪个行业/业务？把它和 AI 结合，做「行业 + AI」方案。
2. **三岔路选择**：
   - **专家/架构**：深耕分布式/性能/安全，成「别人解决不了的问题你来解决」。
   - **管理**：TL → 技术经理 → CTO，带人比写码多。
   - **独立/出海**：用 AI 做 SaaS/小工具，见《副业》板块。
3. **备选兜底**：考公考编（政府/事业单位信息化岗）、国企银行 IT（稳定）、培训/咨询。
4. **持续杠杆**：把 AI 工具用到极致，用「1 人 = 过去 3 人」的效率证明价值。

> 关键认知：35 岁危机 = 技能危机。**懂业务 + 会用 AI + 有经验** 的 35+，正被大厂「价值重估」。

## 通用建议（所有路径）

- 先打基础（一门语言 + 数据结构 + 一个项目），再学工程化，后选方向深入。
- 做 2–3 个能上线的小产品，比背 100 道八股更有用。
- 持续跟进行业（AI、云原生、信创、出海），动手做副业练手。
- 路线图见 [`nilbuild/developer-roadmap`](https://github.com/nilbuild/developer-roadmap)；中文路线图见 [`rd2coding/RoadMaps`](https://github.com/rd2coding/RoadMaps)。

## 专题一：前端学习路线图

### 阶段一：基础（1–2 个月）
- **HTML/CSS**：语义化标签、Flex/Grid 布局、响应式设计、BEM 命名规范。
- **JavaScript**：ES6+（解构、Promise、async/await、模块化）、DOM 操作、事件循环机制。
- **开发工具**：VS Code 插件配置、Chrome DevTools 调试、Git 基础操作。

### 阶段二：框架（2–4 个月）
- **React**：Hooks、状态管理（Zustand/Redux Toolkit）、路由（React Router）、Next.js SSR/SSG。
- **Vue**：Composition API、Pinia、Nuxt.js。
- **TypeScript**：类型系统、泛型、装饰器、与框架集成。

### 阶段三：工程化（3–5 个月）
- **构建工具**：Vite 原理与配置、Webpack 优化、Rollup 打包。
- **测试**：Vitest/Jest 单元测试、Playwright E2E 测试。
- **CI/CD**：GitHub Actions 自动化部署、Docker 容器化前端应用。
- **性能优化**：Lighthouse 指标、懒加载、代码分割、图片压缩、CDN 加速。

### 阶段四：进阶方向（6 个月+）
- **可视化**：Canvas/SVG、ECharts/D3.js、Three.js 3D 渲染。
- **跨端**：React Native / Flutter / 鸿蒙 ArkTS。
- **微前端**：qiankun、Module Federation、微前端架构设计。
- **AI 前端**：AI 组件集成、Prompt 可视化编辑器、AI 辅助开发工具链。

> 来源：前端学习路线综合 React/Vue 官方文档、前端早读课、掘金小册

## 专题二：后端学习路线图

### 阶段一：语言与基础（1–3 个月）
- **Java**：JUC 并发包、JVM 内存模型、Spring Boot 自动装配原理。
- **Go**：goroutine 调度、channel 原理、gin 框架、gRPC 通信。
- **Python**：FastAPI/Flask、ORM（SQLAlchemy）、异步编程（asyncio）。

### 阶段二：中间件（3–6 个月）
- **数据库**：MySQL 索引优化、事务隔离级别、分库分表（ShardingSphere）；Redis 数据结构与缓存策略。
- **消息队列**：Kafka（高吞吐场景）、RocketMQ（事务消息）、RabbitMQ（复杂路由）。
- **微服务**：Spring Cloud Alibaba / Go Micro、服务注册发现（Nacos）、网关（Gateway）。

### 阶段三：分布式与云原生（6–12 个月）
- **分布式系统**：CAP/BASE 理论、分布式事务（Seata/TCC）、分布式锁、一致性哈希。
- **云原生**：Kubernetes 编排、Service Mesh（Istio）、可观测性（Prometheus + Grafana）。
- **高并发实战**：秒杀系统设计、限流熔断、缓存一致性、读写分离。

### 阶段四：架构进阶（12 个月+）
- **DDD 领域驱动设计**：限界上下文、聚合根、CQRS 事件溯源。
- **架构评审能力**：画架构图、写技术方案、做架构决策（ADR）。
- **行业深耕**：电商（交易/支付/仓储）、金融（风控/清算/合规）、物流（调度/轨迹/结算）。

> 来源：后端学习路线综合 Java/Go 社区、微服务实践指南、云原生技术白皮书

## 专题四：AI 学习路线图（2026 热门方向）

### 阶段一：AI 基础（1–3 个月）
- **数学基础**：线性代数（矩阵运算）、概率统计（贝叶斯）、微积分（梯度下降）。
- **Python 数据科**：NumPy、Pandas、Matplotlib、Jupyter Notebook。
- **机器学习入门**：Scikit-learn、监督/无监督学习、模型评估指标。

### 阶段二：深度学习（3–6 个月）
- **核心框架**：PyTorch（主流）、TensorFlow（边缘部署）。
- **网络架构**：CNN（图像）、RNN/LSTM（序列）、Transformer（NLP/CV 通用）。
- **实战项目**：图像分类、文本分类、目标检测、语音识别。

### 阶段三：大模型应用（6–9 个月）
- **Prompt Engineering**：系统提示、思维链（CoT）、Few-shot、工具调用。
- **RAG 工程**：文档解析、切片策略、Embedding 选型、向量库（Milvus/Chroma）、重排与溯源。
- **Agent 开发**：LangChain/LlamaIndex 框架、工具调用、规划-执行循环、MCP 协议。

### 阶段四：模型训练与优化（9–12 个月+）
- **微调技术**：SFT 数据构建、LoRA/QLoRA、RLHF/DPO、评测集设计。
- **推理部署**：vLLM/TGI 推理引擎、模型量化（INT4/INT8/FP8）、GPU 调度。
- **AI  Infra**：训练集群管理、数据管道、MLOps、模型版本管理。

> 来源：AI 学习路线参考 fast.ai 课程、李宏毅机器学习、Hugging Face 官方教程

## 专题五：大数据学习路线图

### 阶段一：基础（1–2 个月）
- **Linux**：Shell 脚本、文件系统、进程管理、网络基础。
- **SQL 进阶**：窗口函数、CTE、执行计划分析、Hive SQL。
- **Java/Scala**：面向对象、集合框架、并发编程、Scala 基础语法。

### 阶段二：Hadoop 生态（3–5 个月）
- **HDFS**：架构原理、读写流程、副本策略、数据均衡。
- **MapReduce**：编程模型、Shuffle 机制、性能调优。
- **Hive**：数据仓库建模、分区分桶、性能优化、与 Presto 对比。
- **HBase**：列族存储、读写流程、与 MySQL 选型对比。

### 阶段三：实时计算（5–8 个月）
- **Spark**：Spark SQL、Spark Streaming、DataFrame/Dataset API、调优。
- **Flink**：流批一体、窗口函数、状态管理、Exactly-Once 语义。
- **Kafka**：生产者消费者模型、分区与副本、监控与调优。

### 阶段四：数据平台与治理（8–12 个月+）
- **数据湖仓**：Delta Lake / Apache Iceberg、湖仓一体架构。
- **数据治理**：数据质量（Great Expectations）、元数据管理（Apache Atlas）、数据血缘。
- **BI 与可视化**：Superset、DataEase、数据看板设计、指标体系建设。
- **大数据 + AI**：特征工程、特征平台（Feast）、实时特征计算、数据标注管理。

> 来源：大数据路线参考 Cloudera 官方课程、Apache 基金会项目文档、DataFun 社区分享

## 七、项目实战建议

### 选题原则
- **解决真实问题**：自己遇到的痛点（记账、日程管理、知识整理）比「仿微博/仿微信」更有说服力。
- **技术栈匹配**：项目技术栈与目标岗位 JD 关键词对齐（投 Java 后端就别写纯前端项目）。
- **可量化成果**：有上线地址、有用户量、有性能指标（响应时间 < 200ms、支持 1000 并发）。

### 推荐项目类型
| 类型 | 示例项目 | 技术亮点 | 适合方向 |
| --- | --- | --- | --- |
| AI 应用 | 企业知识库问答系统 | RAG 全链路、向量检索、成本优化 | AI 应用工程师 |
| 全栈产品 | 个人 SaaS 工具（记账/习惯追踪） | 前后端部署、支付集成、CI/CD | 全栈/独立开发 |
| 系统仿真 | 短链生成器 + 限流系统 | 分布式 ID、缓存、高并发 | 后端/架构 |
| 数据平台 | 实时数据看板 | Flink + Kafka + ClickHouse | 大数据工程师 |
| 移动应用 | 跨端记账 App | Flutter/RN + 本地存储 + 推送 | 移动端开发 |

### 项目展示
- **README 是门面**：项目截图/演示 GIF、技术架构图、部署指南、设计决策说明。
- **写技术博客**：把项目难点、踩坑经历写成系列文章，面试时直接甩链接。
- **GitHub 活跃度**：持续提交、有 Issues 互动、有 Contributing 指南——面试官会看绿格子。

## 八、面试准备时间线

### 校招时间线（以秋招为例）
| 时间节点 | 动作 | 产出 |
| --- | --- | --- |
| 3–5 月 | 打基础 + 算法每日 1 题 | 数据结构与算法基础扎实 |
| 5–7 月 | 实习 + 项目实战 | 实习证明 + 1–2 个项目 |
| 7–8 月 | 简历打磨 + 系统设计 | 完整简历 + 2 个设计题准备 |
| 8–10 月 | 秋招投递 + 面试 | 拿到 Offer |
| 10–11 月 | 查漏补缺 + 补招 | 备选 Offer |

### 社招时间线（跳槽准备）
| 时间节点 | 动作 | 产出 |
| --- | --- | --- |
| 第 1 个月 | 算法复习 + 项目复盘 | HOT 100 过半 + 3 个 STAR 故事 |
| 第 2 个月 | 系统设计 + 行业八股 | 2 个完整设计题 + 基础脱稿 |
| 第 3 个月 | 模拟面试 + 投递 | 面试模拟记录 + 简历投递 |
| 持续 | 复盘 + 调整 | 每次面试后写复盘笔记 |

### 面试前一周清单
- [ ] 算法：每天 2 题保持手感，重点复习高频题。
- [ ] 项目：对着镜子讲一遍项目（3 分钟版本 + 10 分钟深挖版本）。
