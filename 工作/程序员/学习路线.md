# 程序员 · 学习路线（国内五条路径）

> 一条可落地的「能上手 → 能交付 → 能深入」路线。下文给出 **校招 / 社招转岗 / 信创 / AI 应用 / 35+ 转型** 五条贴合中国市场的路径，可结合自身裁剪。

---

## 路径 A：校招就业路线（学生 / 应届）

**目标**：拿大厂或中厂开发岗 Offer。

### 阶段一：打基础（1–3 个月）
- 一门语言吃透（Java 或 Python 或 JS 任选其一）。
- 数据结构与算法：数组、链表、树、图、排序、二分、动态规划入门（每天 1–2 道 LeetCode/牛客）。
- 计算机基础：HTTP、TCP/IP、操作系统进程线程、SQL 基础。
- 做一个小项目并写 README。

### 阶段二：学工程（3–6 个月）
- Git（分支、PR、rebase）；一门框架（前端 React/Vue，后端 Spring/Express/Django，全栈 Next.js）。
- 数据库：MySQL + Redis，会写索引友好的 SQL。
- 测试：单元测试（pytest/Jest），了解 CI。
- 容器化：Docker 基础，能跑起一个服务。

### 阶段三：冲实习 + 刷题（持续）
- 至少一段实习（大厂/中厂/实验室均可），简历才有「硬通货」。
- 算法题刷到 300+，覆盖剑指 Offer / 热题 HOT 100。
- 做 1–2 个可上线项目，写技术博客沉淀作品集。

### 阶段四：深入方向
- 后端：高并发、分布式、消息队列、微服务。
- 算法/AI：Python、PyTorch、数据处理（走路径 D）。
- 前端：性能优化、工程化、可视化。

> 校招真理：**学历 + 实习 + 算法 + 项目**，四者缺一都可能被刷。

---

## 路径 B：社招转岗 / 进阶路线（在职 1–5 年）

**目标**：从「能写功能」到「能设计系统」，避免被 AI 平替。

1. 补系统设计：短链、限流、秒杀、Feed 流、缓存架构；读 *Designing Data-Intensive Applications*。
2. 深入一个方向：分布式事务、JVM 调优、前端性能、云原生。
3. 主动吃透一个**业务域**（电商/支付/风控/出行），成为「懂业务的工程师」。
4. 学 AI 应用（路径 D 前两步），把 AI 工具嵌入日常工作流。
5. 输出技术影响力：内部分享、外部博客、开源 PR。

---

## 路径 C：信创 / 国产替代路线（求稳 + 吃政策红利）

**目标**：进银行/政务/国企 IT 或信创企业，做国产栈迁移与适配。

### 阶段一：夯实通用栈（0–6 个月）
- Java（Spring Boot）或 Go 或 Python 任选一，打好基础。
- Linux 运维基础：Shell、权限、服务管理。

### 阶段二：切入国产栈（6–18 个月）
- **操作系统**：统信 UOS / 麒麟 OS / OpenEuler 上开发、部署、调优。
- **数据库**：达梦 DM（DMSQL）/ GaussDB（PL/pgSQL），学 DMETL 迁移工具。
- **芯片架构**：鲲鹏（ARM64）/ 飞腾 / 龙芯，注意编译差异。
- **鸿蒙**：ArkTS + ArkUI 开发（可选，蹭鸿蒙红利）。

### 阶段三：合规与安全（18 个月+）
- 等保 2.0 基本要求；国密 SM2/SM3/SM4 集成。
- 《网络安全法》《个人信息保护法》基础。
- 考 **工信部「信创工程师」认证** 或 华为 HCIA/HCIP（鲲鹏、GaussDB、鸿蒙）。

> 信创系统开发工程师在 2025 被评为最紧缺技术岗，年薪 50 万+；2027 信创市场预计达 3 万亿。

## 路径 D：AI 应用开发路线（当下最被争抢）

**目标**：成为 AI Application Engineer（RAG / Agent / 微调）。

### 阶段一：大模型基础（小白入门）
- 搞懂 Transformer、预训练/推理、RLHF；了解 DeepSeek / Qwen / GLM 等国产模型。
- Prompt 工程：精准引导、系统提示、思维链。
- API 与 Token：调用成本（输入约 0.5 元/百万 tokens 起），学会控本。

### 阶段二：RAG 工程（核心）
- 向量库：Milvus / Chroma / Qdrant；Embedding 模型选型与微调。
- 切片、检索、重排、引用溯源；企业知识库落地。
- 练手：[`langgenius/dify`](https://github.com/langgenius/dify)、[`labring/FastGPT`](https://github.com/labring/FastGPT) 私有化部署。

### 阶段三：Agent 编排
- 工具调用、规划-执行循环、多智能体协作、**MCP 协议**（连接模型与数据库/API 的事实标准）。
- 用 Cursor / 通义灵码 / 豆包 提升自身开发效率。

### 阶段四：微调与模型服务化（进阶）
- LoRA / QLoRA 微调、SFT 数据构建、模型蒸馏。
- vLLM 推理部署、量化、GPU 资源调度。

> 掌握 RAG + Agent 的程序员薪资溢价约 56%；AI 人才供需比仅 0.5（两个岗抢一人）。

## 路径 E：35+ 转型 / 抗风险路线（在职 8 年+）

**目标**：把「行业经验」变成「驾驭 AI 的核心资产」，避开纯 CRUD 被裁。

1. **盘点资产**：你最懂哪个行业/业务？把它和 AI 结合，做「行业 + AI」方案。
2. **三岔路选择**：
   - **专家/架构**：深耕分布式/性能/安全，成「别人解决不了的问题你来解决」。
   - **管理**：TL → 技术经理 → CTO，带人比写码多。
   - **独立/出海**：用 AI 做 SaaS/小工具，见《副业》板块。
3. **备选兜底**：考公考编（政府/事业单位信息化岗）、国企银行 IT（稳定）、培训/咨询。
4. **持续杠杆**：把 AI 工具用到极致，用「1 人 = 过去 3 人」的效率证明价值。

> 关键认知：35 岁危机 = 技能危机。**懂业务 + 会用 AI + 有经验** 的 35+，正被大厂「价值重估」。

---

## 通用建议（所有路径）

- 先打基础（一门语言 + 数据结构 + 一个项目），再学工程化，后选方向深入。
- 做 2–3 个能上线的小产品，比背 100 道八股更有用。
- 持续跟进行业（AI、云原生、信创、出海），动手做副业练手。
