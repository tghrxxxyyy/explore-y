# 程序员 · 学习路线

> 一条可落地的「能上手 → 能交付 → 能深入」路线，可按自身方向裁剪。

## 阶段一：打基础（1-3 个月）
- 一门语言吃透（Python / Java / JavaScript 任选）。
- 数据结构与算法：数组、链表、树、图、排序、二分、动态规划入门。
- 计算机基础：HTTP、TCP/IP、操作系统进程线程、SQL 基础。
- 做一个小项目并写 README。

## 阶段二：学工程（3-6 个月）
- 版本控制 Git（分支、PR、rebase）。
- 一门框架（前端 React/Vue；后端 Spring/Express/Django；全栈 Next.js）。
- 数据库：MySQL + Redis，会写索引友好的 SQL。
- 测试：单元测试（pytest/Jest），了解 CI。
- 容器化：Docker 基础，能跑起一个服务。

## 阶段三：做项目（持续）
- 独立完成 2-3 个可上线项目（含部署到云）。
- 读 1-2 个优秀开源项目源码。
- 参与开源或写技术博客，沉淀作品集。

## 阶段四：选方向深入
- 前端：性能优化、工程化、可视化。
- 后端：高并发、分布式、消息队列、微服务。
- 算法/AI：Python、PyTorch、数据处理。
- 数据：数仓、Spark/Flink、BI。
- 运维/SRE：K8s、监控、稳定性。

## 阶段五：软技能与视野
- 需求拆解、技术沟通、写文档。
- 关注行业趋势（AI、云原生、出海）。
- 持续学习：路线图见 `kamranahmedse/developer-roadmap`。
