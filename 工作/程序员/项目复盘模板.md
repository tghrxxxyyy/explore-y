# 程序员 · 项目复盘模板（STAR / 技术选型 / 踩坑 / 指标）

> 把「做过」变成「能讲、能写、能加分」的项目资产。本文给完整模板 + 可抄改的示例，既用于简历，也用于面试深挖和团队复盘。

## 一、STAR 结构模板（项目描述的骨架）

```
- **S（背景 Situation）**：项目服务谁、解决什么问题、规模多大。
- **T（任务 Task）**：你的角色、职责边界、独立负责的部分。
- **A（行动 Action）**：具体方案、技术选型、关键决策及理由。
- **R（结果 Result）**：量化指标、影响、你的独特贡献。
```

- 四段缺一不可；面试讲项目按 S→T→A→R 顺序，每段 30–60 秒。
- 常见错误：S、T 过长（面试官想听的是 A 和 R）；A 报菜名（只列中间件）不给理由；R 没有数字。

## 二、技术选型复盘（面试官最爱追问的「为什么」）

| 决策点 | 复盘问题 | 示例回答框架 |
| --- | --- | --- |
| 为什么用这个中间件 | 当时的备选有哪些？对比过什么指标？ | 备选 Redis vs Memcached，因需要持久化 + 数据结构丰富选了 Redis |
| 为什么用这个框架/语言 | 团队基础、生态、学习成本怎么权衡 | 团队 Java 基础好、Spring 生态全，选 Spring Boot 而非 Go |
| 数据量/QPS 依据 | 预估基于什么？上线后验证了吗 | 按订单峰值预估约 2 万 QPS，压测验证后留了 30% 余量 |
| 如果重来 | 现在知道什么？哪里会改 | 会用 Kafka 替代自研队列，因为积压排查成本高 |

- 复盘句式：**「当初为什么选 X → 遇到过什么坑 → 如果重来怎么选」**，一段话讲清，比背框架强。

## 三、踩坑记录（复盘的精华区）

- 按「现象 → 定位 → 根因 → 修复 → 预防」五步写：
  - 现象：什么时间、什么表现（报错、告警、用户反馈）。
  - 定位：怎么排查的（看日志、加监控、复现路径）。
  - 根因：最底层的原因（代码、配置、依赖、容量）。
  - 修复：改动是什么、怎么验证的。
  - 预防：加了什么监控/测试/规范，避免再犯。
- 高频踩坑类型自查：
  - 缓存穿透/击穿/雪崩、分布式锁过期、消息重复消费、慢 SQL、内存泄漏、时区/编码问题。
- 面试讲踩坑 = 高光时刻：选一个「你主导定位 + 你主导修复」的，讲出排查路径，比讲成功项目更能证明水平。

## 四、指标复盘（让结果可量化）

- 通用技术指标：QPS/并发量、延迟（P50/P95/P99）、可用性（SLA）、资源成本（CPU/内存/带宽）、发布效率。
- 业务指标：转化率、留存、客诉量、GMV 占比、人效。
- 没有线上指标时：压测数据（标注压测条件）、代码规模（模块数/接口数）、流程提升（发布从 2 小时到 10 分钟）。
- 数字来源标注：真实数据 / 压测数据 / 估算——避免面试被追问时露馅。

## 五、完整模板 + 示例（可直接抄改）

### 5.1 简历版（2–3 行，配数字）
```
会员积分系统（S：平台约 50 万注册用户）
独立完成积分计算、发放与防刷（T）
采用 Redis 预扣 + 幂等表防重复发放，本地消息表保证最终一致（A）
上线后月活渗透率 60%，客服积分类工单降约 70%（R）
```

### 5.2 面试深挖版（1–2 分钟讲述结构）
- S（10 秒）：一句话背景 + 你在哪一环。
- T（15 秒）：你的职责与难点。
- A（60 秒）：方案 + 为什么 + 权衡，重点讲「当时的取舍」。
- R（15 秒）：数字结果 + 你的独特贡献 + 「如果重来会改哪里」。

### 5.3 团队复盘会版（事故/迭代后用）
```
1. 目标与结果：本次迭代的目标是什么、达成率多少。
2. 做得好的：值得固化的 2–3 点（流程/技术/协作）。
3. 问题与踩坑：现象/根因/修复/预防（用第三节五步法）。
4. 数据对比：关键指标 vs 上一周期。
5. 下一步行动：具体责任人 + 截止时间 + 验证方式。
```

### 5.4 面试讲述示例（完整话术骨架）
```
「这个项目是 XX 系统的核心模块，我负责 XXX（S/T）。
当时难点是 XX 场景下的 XX 问题（如并发扣减不重不漏），
我对比了 A/B 两种方案，选了 X，因为……（A 的取舍）。
上线后 XX 指标从 X 降到 Y，用户反馈 XX（R）。
如果重做，我会提前把 XX 的监控加上——这是当时踩过的坑。」
```

- 持续积累：每个项目维护一份「项目档案」（背景/决策/踩坑/指标各一页），面试季直接提取，不用临时回忆。

> 一句话：**没有复盘的项目等于没做；有复盘模板的人，面试就是讲故事。**
