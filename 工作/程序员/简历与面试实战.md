# 程序员 · 简历与面试实战（2025–2026 国内行情版）

> 从简历怎么写、投到哪儿，到面试怎么答、怎么谈薪、怎么复盘。结合 2025–2026 国内「简历海量、AI 筛人、面试深度化」的现实，给可直接套用的模板。

## 一、简历写法：四件事做对了就赢一半

### 1.1 量化成果（数字是简历的命脉）
- 用「动词 + 做了什么 + 量化结果 + 影响」句式，每个项目至少 2–3 个数字。
- 数字来源性质：线上真实数据（PV、QPS、转化率）> 压测数据 > 估算（标注「约」）。
- 差的写法：负责订单系统开发，修复若干 bug。
- 好的写法：重构订单模块，接口 P95 延迟从 800ms 降到 200ms，峰值支撑约 2 万 QPS，故障率降约 60%。
- 没有现成数字？主动埋点、压测、看监控——写简历前先「制造」可汇报的指标。

### 1.2 项目描述用 STAR
- **S（背景）**：一句话说清项目是什么、服务谁、多大规模。
- **T（任务）**：你的职责边界、独立负责的部分。
- **A（行动）**：技术方案与关键决策，以及为什么不用别的方案。
- **R（结果）**：量化指标 + 你的独特贡献。
- 反面示例：参与 XX 平台开发，使用 Spring Boot + Redis。
- 正面示例：从 0 搭建会员积分系统（背景），独立完成积分计算与防刷（任务），选 Redis 预扣 + 幂等表保证扣减不重不漏（行动），上线后月活渗透率 60%，客服积分类工单降约 70%（结果）。

### 1.3 技术栈关键词：给筛人系统看
- 2025–2026 简历普遍先过 ATS/AI 初筛，按 JD 关键词逐项核对：Spring Boot、Redis、Kafka、MySQL、微服务、Docker、K8s、RAG、Agent、LangChain（真实用过才写）。
- 关键词要对得上项目：写了 Kafka，就准备「怎么保证消息不丢/不重」。
- 用「熟悉 / 掌握 / 了解」分级，避免「精通」字样；每项都要能自圆其说。

### 1.4 一页原则与排版
- 应届 / 1–3 年严格一页，3–8 年最多两页；按「项目经验」密度排序，学历、技能精简。
- 结构：基本信息（姓名/电话/邮箱/城市/求职意向）→ 一句话个人优势 → 技能清单 → 项目经验（占一半篇幅）→ 工作/教育经历。
- 投递细节：用 PDF；文件名「姓名_目标岗_年限」；邮件正文附 2–3 句自荐 + 作品链接。

## 二、投递渠道：2025–2026 谁的简历能活下来

| 渠道 | 特点 | 用法 |
| --- | --- | --- |
| **BOSS 直聘** | 直接聊、反馈快，国内投递主渠道 | 主动打招呼带一句「做过 XX，匹配你哪条 JD」，别只发简历 |
| **内推** | 简历直达、免初筛，性价比最高 | 找前同事/脉脉/牛客校友，附「为什么推荐你」的一句话 |
| **猎聘** | 猎头多，中高端岗位集中 | 3–5 年+ 更新简历后猎头会主动找；警惕「先交钱」的假猎头 |
| **牛客** | 校招主阵地 + 面经/题库 | 应届必刷真题；社招可看内推帖 |
| 官网/官方公众号 | 大厂校招/社招直投 | 关注各厂「招聘」官方账号，别错过提前批 |
| 脉脉/小红书 | 看行情、找人内推、验证风评 | 别只刷焦虑帖，重点是找「在职的人」聊 |

- 2025–2026 现实：投递量是 2021 年的数倍，回复率普遍下降；**内推 + 主动沟通 + 简历针对 JD 微调**是提高回复率的三板斧。
- 警惕：外包岗包装成自研、薪资虚标、入职前收费培训——投递前用企查查/脉脉查公司底细。

## 三、面试流程：四轮各有剧本

### 3.1 HR 面（15–30 分钟）
- 目的：筛动机、稳定性、薪资预期。常问离职原因、期望薪资、到岗时间、学历背景。
- 应对：薪资预期报「底线 + 期望」区间；离职原因不吐槽前东家；gap 期准备合理叙事（学习、家庭、个人项目）。

### 3.2 技术面（1–3 轮，决定生死）
- 内容：八股（网络/OS/DB/语言）+ 手撕算法 + 项目深挖 + 至少一轮系统设计。
- 2026 新变化：部分岗位现场让你用 Cursor/Copilot 完成小需求，考察「AI 辅助开发」熟练度；RAG/Agent 岗有场景题。
- 不会就承认不会并给出思路；会 60% 就按「原理 + 方案 + 取舍」讲完，比硬答错强得多。

### 3.3 主管面（终面常见）
- 考察业务理解、协作、抗压、价值观（「最有成就感的项目」「怎么处理需求冲突」）。
- 加分项：主动说清「你进来后能带来什么」，对齐团队现状而非画饼。

### 3.4 HRBP 谈薪（offer 前最后一道坎）
- 报区间而非单点：如「期望 28K–32K，看整体 package」；让 HR 先出价，再谈涨幅。
- 2025–2026 现实：跳槽涨幅从过去的 20%–30% 回落到约 5%–15% 甚至平薪；比 package 组成：基本工资 + 绩效 + 年终 + 期权/股票 + 五险一金基数。
- 问清：年终奖发放条件、绩效分布、试用期折扣、公积金比例、股票归属期——**没写进 offer 的一律不算数**。

## 四、面试技巧

### 4.1 自我介绍（1–2 分钟模板）
- 公式：我是谁（年限 + 方向）→ 最拿得出手的 1–2 个成果（带数字）→ 与岗位的匹配点 → 今天想重点展示什么。
- 忌背简历；结尾留钩子，如「订单系统这块我可以展开讲」。

### 4.2 项目深挖：把「做过」讲成「设计过」
- 每个项目准备三层：**表层**（功能）、**中层**（架构与关键决策）、**深层**（瓶颈、权衡、如果重来怎么改）。
- 高频追问提前想好：为什么用这个中间件？数据量多大、QPS 多少？出过什么线上故障？怎么排查的？
- 真不会就明说「这块当时是同事负责/后来才接手」，补一句「如果让我做，我会……」。

### 4.3 反问环节：别问「我能不能过」
- 加分问题：团队现在最大的技术挑战？这个岗位 6 个月内的核心目标？绩效怎么评？
- 减分问题：加班多吗（可侧面问「团队节奏」）、我能过吗。

## 五、面试后复盘（决定下次能不能过）

- 每次面完当天记录：被问了什么、哪里卡壳、答错的题；24 小时内补掉知识盲区。
- 复盘模板：题目清单 / 我的回答 vs 标准思路 / 卡壳点与原因 / 下次改进动作（复习哪一章、补哪个项目）。
- 面挂了不是白挂：把追问过的项目细节补进简历；把没答出的系统设计题做一遍练手。
- 被拒后礼貌要一句原因，多数能得到「技术深度不足 / 不匹配」的线索，作为下一家的校准。

> 一句话：**简历决定有没有面试，项目深挖决定过不过，谈薪决定值不值。三关都要练。**
