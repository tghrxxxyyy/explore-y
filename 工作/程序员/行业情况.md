# 程序员 · 行业整体情况

> 客观梳理程序员行业的现状、方向、薪资与趋势，帮你看清「这个行业现在到底什么样」。

## 一、行业概况
程序员（软件开发工程师）是把需求变成可运行软件的劳动者。行业覆盖：
- **互联网/大厂**：电商、社交、内容、本地生活、云计算。
- **软件与 SaaS**：企业服务、工具、行业软件。
- **硬件/嵌入式**：手机、汽车、IoT、芯片配套软件。
- **传统行业 IT 化**：金融、制造、医疗、政务的数字化部门。
- **自由职业/独立开发**：接外包、做 SaaS、开源变现。

## 二、主要岗位方向
| 方向 | 做什么 | 典型技术栈 |
| --- | --- | --- |
| 前端 | 网页/App 界面与交互 | HTML/CSS/JS、React、Vue、移动端 |
| 后端 | 服务端逻辑、数据库、接口 | Java/Go/Python、MySQL、Redis、微服务 |
| 客户端 | 桌面/移动原生应用 | Swift、Kotlin、Flutter、Electron |
| 算法/AI | 模型、推荐、CV/NLP | Python、PyTorch、TensorFlow |
| 数据 | 数仓、ETL、BI | SQL、Spark、Flink、Hadoop |
| 测试/质量 | 自动化测试、性能 | Selenium、pytest、JMeter |
| 运维/SRE | 部署、监控、稳定性 | Linux、K8s、Docker、Prometheus |
| 安全 | 渗透、防护、合规 | 逆向、密码学、防护体系 |

## 三、就业与薪资（参考）
- 薪资呈「金字塔」：初级饱和、资深稀缺；一线 > 新一线 > 其他。
- 大厂校招与社招门槛高但待遇好；中小厂更看重即战力。
- 35 岁焦虑真实存在，但「持续学习 + 走向架构/管理/专家/独立」可破局。
- 远程/出海岗位增多，独立开发（indie hacker）成为新路径。

## 四、当前趋势
1. **AI 提效**：Copilot、Cursor、大模型显著改变coding方式，重复代码成本下降。
2. **云原生**：K8s、Serverless、微服务成标配。
3. **全栈化**：小团队更需要「能端到端交付」的人。
4. **出海与独立开发**：利用全球市场做 SaaS/插件，见「副业」板块。
5. **软技能升值**：沟通、产品感、业务理解比纯语法更重要。

## 五、职业路径
- 初级 → 中级 → 高级 → 技术专家 / 技术管理（TL、架构师）。
- 或横向转产品、创业、独立开发、技术布道。
- 关键：**T 型能力**——一专（深度）+ 多能（广度）。
