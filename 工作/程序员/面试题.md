# 程序员 · 常见面试题

> 按方向分类的常考知识点清单，用于自查与复习。

## 计算机基础
- TCP 三次握手/四次挥手；HTTP 与 HTTPS 区别；状态码含义。
- 进程 vs 线程；死锁四个条件；虚拟内存。
- 索引为什么快（B+树）；事务 ACID；脏读/幻读。

## 数据结构与算法
- 数组/链表/栈/队列/哈希表特性与复杂度。
- 二叉树遍历、二叉搜索树、堆。
- 排序算法（快排、归并、堆排）复杂度与稳定性。
- 动态规划、回溯、贪心典型题。

## 语言（以 Java/Python 为例）
- 内存模型与垃圾回收；异常处理；多态与继承。
- GIL 是什么；装饰器；生成器与迭代器。

## 框架与工程
- 前端：事件循环、虚拟 DOM、闭包、防抖节流。
- 后端：RESTful 设计、鉴权（JWT/Session）、幂等。
- 数据库：慢查询优化、分库分表、缓存穿透/雪崩。
- 系统设计：短链、限流、秒杀、Feed 流初步。

## 行为/软技能
- 介绍一个你解决的最难问题。
- 需求变更如何沟通？
- 如何排查一个线上故障？

> 刷题用 LeetCode；系统设计看《designing data-intensive applications》。
