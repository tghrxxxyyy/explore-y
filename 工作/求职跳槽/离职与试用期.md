# 求职跳槽 · 离职与试用期

> 好聚好散是跳槽的最后一课，试用期是新旅程的生死线，被裁员则是每个打工人早晚要面对的现实题。本文覆盖离职全流程、离职谈话、社保公积金衔接、试用期生存指南与被裁应对。

## 一、离职流程：时机 / 交接 / 竞业

- **提离职的时机**：
  - 新 offer 到手、且关键条款（薪资、入职日期）书面确认后，再向现公司提——别先裸提再找工作。
  - 避开项目关键节点和试用期前两周，留出体面交接的空间。
  - 法律上提前通知的期限有法定要求（正式员工一般需提前 30 天书面通知，试用期内提前 3 天），具体以劳动合同与最新劳动法规为准，留出足够交接时间。
- **交接清单**：
  - 工作文档：代码、文档、账号密码、对接人清单全部整理归档。
  - 交接说明书：手头任务状态、下一步动作、风险点，交给接手人并带他过一遍。
  - 报销与欠账：报销单、借款、考勤确认完，别留尾巴。
  - 私人物品与账号：个人微信/网盘里的公司资料清理边界，离职前导出自己的作品集（不涉密的）。
- **竞业限制注意**：离职时确认是否签过竞业协议；若签了，关注公司是否支付竞业补偿金——**未支付补偿的竞业协议通常难以主张执行**；入职竞品前评估风险，别赌。
- **拿到离职证明**：离职证明是下家入职的必需材料，公司出具离职证明是法定义务，索要合理范围内的离职证明内容不被刁难是你的权利。

## 二、离职谈话怎么说

- **原则**：感谢 + 理由（笼统）+ 交接承诺，不留口实，不掀桌子——圈子很小，口碑会跟着你走。
- **话术参考**：
  - 开场：「感谢您和团队这一年多的栽培，我认真考虑后决定离职。」
  - 理由：「主要是个人的职业规划调整（/家庭原因/想换个方向），与公司无关。」
  - 封堵挽留：「很感谢挽留，但我已经确定了，想趁这个机会去挑战一下，就不占公司资源了。」
- **谈判空间**：如果公司开价挽留（涨薪、升职），先想清楚：你要走的原因如果是「钱」，可谈；如果是「团队/业务/成长」问题，加钱通常治标不治本。
- **别做的三件事**：别在情绪上头时提离职、别在谈话中抱怨同事领导、别在离职前摆烂——最后一个月的工作表现是背调里最常被问到的一段。

## 三、离职证明与社保公积金衔接（断缴影响）

- **社保断缴的影响**：
  - 医保：断缴次月通常无法享受医保报销，断缴超 3 个月补缴后有等待期（各地不同）。
  - 养老：断缴影响累计年限，影响退休待遇测算。
  - 生育、工伤、失业险：与连续缴费挂钩，断缴可能导致无法享受。
  - **买房/摇号/落户**：多地对社保连续缴纳有要求（尤其北上广深），断缴可能清空连续记录，影响购房资格。
- **衔接方案**：离职前问清新公司社保起缴月份（次月缴 vs 当月补缴）；两段之间有空窗期的，可自行以灵活就业身份缴纳，或咨询当地政策，尽量别断。
- **公积金**：断缴影响公积金贷款资格（多要求连续缴存），有购房计划的人尤其注意；公积金账户余额可提取或转移，不会清零。
- **离职证明内容**：一般含姓名、身份证号、入职/离职时间、岗位、离职原因（写「个人原因」居多）；若公司写的离职原因对你不利，有权要求更正。

## 四、试用期考核要点：新公司前 3 个月怎么过

- **第 1 个月：活下来**——确认任务边界、摸清关键人（决策者、配合者、把关者）、立「靠谱」人设：守时、留痕、不懂就问、答应必达。
- **第 2 个月：出小成果**——找一个看得见、能量化的小项目做到位，让转正考核有据可依；主动约直属上级 1v1，对齐「转正标准是什么、我现在差在哪」。
- **第 3 个月：亮证据**——整理试用期成果清单（做了什么、带来什么结果），主动请求转正评估；如果转正被拖延或标准模糊，书面问清原因并留痕。
- **踩雷清单**：
  - 上来就推翻现有方案（先理解再提建议，前 3 个月的新人没资格否定存量）。
  - 站队、八卦、卷入办公室政治。
  - 对业务只问「为什么」不给「我建议」。
  - 试用期频繁请假（有风险，但合法合规的假不用怕）。
- **试用期被劝退**：先问清「不符合录用条件」的具体依据（必须有明确的录用标准与事实）；认为不成立的，可协商补偿或主张权利，别默默走人。

## 五、被裁员 / 被劝退的应对与补偿（N+1 常识）

- **先稳住局面**：被谈话时保持冷静，不签任何文件、不口头承诺、不冲动交接；说「我需要时间理解，回复你」，然后回去查资料、咨询、留证据。
- **了解基本补偿常识**：
  - 经济补偿按「每满一年补一个月工资」计算（即常说的 N），工资按离职前 12 个月平均工资算（有上限，且高于当地平均工资 3 倍的按 3 倍封顶）。
  - **协商一致离职（公司提出的）**、裁员、合同到期公司不续签等情形，通常涉及 N；「N+1」是常见协商口径，其中 +1 为代通知金（未提前 30 天通知时）。
  - 违法解除（无正当理由、程序违法）可主张赔偿（即 2N 口径），但需劳动仲裁认定，别把 2N 当默认答案。
- **谈判策略**：协商时守住「法定底线（N），争取 N+1 或更高（+年终奖折算）」，一次谈不拢就约下次；谈到口头答应不算数，**落成书面协议再签**。
- **被劝退（没签书面辞退）**：公司让你「自己提离职」通常是想省补偿——是否接受取决于你：想快拿离职证明就谈补偿条件（「可以自己提，但请按 N+1 赔偿」），不想妥协就拒绝签字、正常上班、等公司走法定流程。
- **离职后**：拿到书面解除通知/协议（写清补偿金额与支付时间）、离职证明、社保衔接；补偿未按期到账的，向劳动监察或仲裁机构求助。
- **心理建设**：裁员是周期与业务问题，不是你个人价值的判决书；2025–2026 年大量「被动离职」的人都在 3–6 个月内重新出发，先保现金流，再谈心态。

## 六、离职流程完整清单

### 提前准备（离职前 1 个月）
- **确认新 Offer**：关键条款（薪资、入职日期、岗位）书面确认后再提离职。
- **了解法律义务**：正式员工提前 30 天书面通知，试用期提前 3 天——这是法定最低要求。
- **整理交接材料**：
  - 代码仓库权限移交清单
  - 文档与知识库（Confluence/飞书文档/语雀）
  - 账号密码（服务器/第三方服务/云平台）
  - 对接人清单（产品/测试/运维/客户）
  - 进行中项目的下一步计划与风险点

### 正式提离职
- **书面通知**：向直属上级提交书面离职申请（邮件/纸质），保留发送记录。
- **离职谈话**：保持感谢 + 理由（笼统）+ 交接承诺——不掀桌子、不留口实。
- **交接期工作**：正常工作、配合交接、不摆烂——最后一个月的表现是背调高频问到的内容。

### 离职手续办理
| 事项 | 说明 | 注意点 |
| --- | --- | --- |
| 离职证明 | 公司法定义务，必须出具 | 核对内容（岗位/时间/原因），有误可要求更正 |
| 工作交接 | 文档/代码/账号/对接人全部移交 | 有交接清单最好，双方签字确认 |
| 报销结算 | 报销单、借款、出差补贴全部结清 | 别留尾巴，离职后报销可能拖很久 |
| 年假折算 | 未休年假按日工资 300% 折算 | 确认折算金额写在离职结算单里 |
| 考勤确认 | 最后一个月考勤核对 | 避免被扣旷工/迟到 |
| 归还物品 | 笔记本电脑/工牌/门禁卡/公司资料 | 清单逐项归还，拿到回执 |
| 社保公积金 | 确认最后缴纳月份 | 问清新公司起缴时间，避免断缴 |

## 七、竞业限制详解

### 竞业协议核心要素
- **适用对象**：高级管理人员、高级技术人员、其他负有保密义务的人员——不是所有岗位都能签。
- **限制范围**：与公司生产同类产品或经营同类业务的有竞争关系的单位。
- **限制期限**：最长不超过 2 年（《劳动合同法》第 24 条）。
- **竞业补偿**：公司必须按月支付竞业限制补偿金（通常为离职前 12 个月平均工资的 30%，各地有差异）。
- **违约金**：违反竞业协议需支付违约金（金额由协议约定，通常较高）。

### 竞业协议执行现状（2025–2026）
- **大厂查竞业增多**：字节、阿里、美团等大厂竞业诉讼案例增加，别心存侥幸。
- **未支付补偿的协议**：公司连续 3 个月未支付竞业补偿金，你可请求解除竞业协议（司法实践支持率高）。
- **竞业范围争议**：公司以「泛竞业」限制你去所有互联网公司，可主张范围过宽——司法实践中会审查合理性。
- **竞业 vs 保密**：竞业限制需要单独签协议 + 支付补偿；保密义务是法定义务，不需要额外协议。

### 应对建议
- 离职时确认是否签过竞业协议，仔细看限制范围和补偿条款。
- 如签了竞业，评估新公司是否在竞业范围内——不确定就咨询律师。
- 入职竞品前确认：竞业补偿是否按时支付、协议是否仍有效。
- 保留竞业协议原件、补偿金支付记录作为证据。

## 八、试用期权益保障（法律保护）

### 试用期法定权益

| 权益 | 法律规定 | 实操注意 |
| --- | --- | --- |
| 试用期时长 | 合同 1–3 年 → 试用期 ≤ 2 个月；3 年以上 → ≤ 6 个月 | 只能约定一次，不得延长 |
| 试用期工资 | ≥ 约定工资的 80%，且 ≥ 当地最低工资标准 | 低于 80% 可主张补差 |
| 社保公积金 | 试用期必须缴纳 | 不缴社保违法，可投诉 |
| 解除条件 | 公司需证明「不符合录用条件」 | 录用条件须入职时书面告知 |
| 提前通知 | 试用期内解除需提前 3 天通知 | 无需支付经济补偿（公司有过错除外） |
| 劳动合同 | 入职 1 个月内必须签订 | 超过 1 个月未签，可主张双倍工资 |

### 试用期被解除的法律保护
- **公司举证责任**：公司必须证明你「不符合录用条件」，且录用条件必须在入职时书面告知。
- **无理由解除**：试用期内无理由解除劳动合同，公司需支付经济补偿（N）。
- **违法解除**：公司以「不符合录用条件」为由解除但无法举证的，属于违法解除，可主张赔偿金（2N）。
- **维权途径**：劳动监察投诉 → 劳动仲裁 → 法院诉讼（劳动仲裁不收费）。

### 常见试用期陷阱
| 陷阱 | 实质 | 应对 |
| --- | --- | --- |
| 「试用期不交社保」 | 违法 | 要求缴纳，拒绝可投诉 |
| 「试用期工资打折」 | 违法（低于 80%） | 要求补差，保留工资条 |
| 「试用期无限延长」 | 违法（只能约定一次） | 拒绝签字，保留证据 |
| 「试用期批量开人」 | 稳定性风险 | 入职前了解公司口碑 |
| 「口头录用条件」 | 无法举证 | 要求书面录用条件 |

## 九、社保断缴影响与衔接方案

### 断缴影响（按险种）

| 险种 | 断缴影响 | 恢复时间 | 严重程度 |
| --- | --- | --- | --- |
| 医保 | 断缴次月无法报销 | 补缴后有等待期（各地 1–6 个月） | 高 |
| 养老 | 影响累计年限 | 补缴后累计计算 | 中 |
| 生育 | 无法享受生育津贴 | 连续缴满 12 个月后恢复 | 高（计划生育者） |
| 失业 | 影响失业金领取 | 累计缴满 1 年可领 | 中 |
| 工伤 | 断缴期间无保障 | 补缴后恢复 | 中 |

### 特别影响：买房/落户/摇号
- **北京**：购房需连续缴满 5 年社保/个税，断缴 1 个月重新计算。
- **上海**：购房需连续缴满 5 年社保，断缴清零重算。
- **深圳**：购房需连续缴满 3 年社保。
- **杭州**：购房需连续缴满 2 年社保。
- **落户**：多数城市积分落户要求连续缴纳社保，断缴影响积分。

### 衔接方案
- **最优方案**：新公司入职当月缴纳社保——问清 HR「当月还是次月起缴」。
- **有空窗期**：以灵活就业身份自行缴纳（部分城市支持），或咨询社保代缴机构（注意合规性）。
- **跨城市**：社保转移接续（养老保险可跨省转移，医保各地政策不同）。
- **公积金**：断缴影响公积金贷款资格（通常要求连续缴存 6–12 个月），有购房计划尤其注意。

### 公积金处理
- **账户余额**：不会清零，可提取或转移。
- **离职提取**：部分城市支持离职后提取公积金余额（需提供离职证明）。
- **转移**：跨城市转移通过全国住房公积金小程序办理。

## 十、被裁员 / 被劝退应对全指南

### 第一步：稳住局面
- 被谈话时保持冷静，**不签任何文件、不口头承诺**。
- 说「我需要时间理解，回去考虑一下」，争取缓冲时间。
- 立即做：录音/截图保留证据（合法范围内）。

### 第二步：了解补偿标准

| 情形 | 补偿标准 | 说明 |
| --- | --- | --- |
| 协商一致（公司提出） | N（法定）→ N+1（常见） | +1 为代通知金（未提前 30 天通知） |
| 经济性裁员 | N | 需提前 30 天通知或支付代通知金 |
| 合同到期公司不续签 | N | 公司维持或提高条件你拒签则无补偿 |
| 违法解除 | 2N | 无正当理由/程序违法，需劳动仲裁认定 |
| 员工主动辞职 | 无补偿 | 所以不要「自己提离职」来帮公司省补偿 |

### 第三步：谈判策略
- **守住底线**：法定补偿 N 是底线，争取 N+1 或更高。
- **可谈项**：年终奖折算、股票加速归属、推荐信、离职时间弹性。
- **一次谈不拢就约下次**：不急于当场签字。
- **落成书面**：口头答应不算数，补偿金额和支付时间必须写进协议。

### 第四步：被劝退（没签书面辞退）的应对
- 公司让你「自己提离职」= 想省补偿。
- **应对选择**：
  - 想快走：「可以自己提，但请按 N+1 赔偿，写进协议」。
  - 不想妥协：拒绝签字、正常上班、等公司走法定流程。
- **不要**：在压力下签「自愿离职申请」——这会让你失去补偿资格。

### 第五步：离职后事项
- [ ] 拿到书面解除通知/协议（写清补偿金额与支付时间）。
- [ ] 拿到离职证明。
- [ ] 确认社保缴纳到最后月份。
- [ ] 补偿未按期到账 → 劳动监察投诉或劳动仲裁。
- [ ] 失业保险：非自愿离职可申领失业金（缴满 1 年可领，各地标准不同）。

### 心理建设
- 裁员是周期与业务问题，不是你个人价值的判决书。
- 2025–2026 年大量「被动离职」的人都在 3–6 个月内重新出发。
- 先保现金流（3–6 个月紧急储备），再谈心态和方向。

> 来源：劳动法相关条款参考《劳动合同法》《劳动争议调解仲裁法》；社保政策参考各地人社局公开信息

## 十一、离职流程详解

### 11.1 交接清单（完整版）

| **账号密码** | 服务器/第三方服务/云平台账号移交 | [ ] |

| **社保公积金** | 确认最后缴纳月份 | [ ] |

### 11.2 离职证明

| 维度 | 说明 |
| --- | --- |
| **法律义务** | 公司必须出具离职证明，这是法定义务 |
| **内容** | 姓名、身份证号、入职/离职时间、岗位、离职原因 |
| **离职原因** | 一般写「个人原因」居多；若不利可要求更正 |
| **用途** | 下家入职必需材料、社保转移、公积金提取 |
| **注意事项** | 核对内容准确性，有误可要求更正 |

### 11.3 社保转移

| 步骤 | 内容 | 时间 |
| --- | --- | --- |
| **确认缴纳月份** | 问现公司最后缴纳到几月 | 离职前 |
| **问新公司起缴** | 当月还是次月起缴 | 入职前 |
| **有空窗期** | 灵活就业身份自行缴纳 | 空窗期 |
| **跨城市转移** | 养老保险可跨省转移（国家社保公共服务平台） | 入职新城市后 |
| **医保转移** | 各地政策不同，需咨询当地医保局 | 入职新城市后 |

## 十二、竞业限制深度分析

### 12.1 竞业协议核心要素

| 要素 | 法律规定 | 实操注意 |
| --- | --- | --- |
| **适用对象** | 高级管理人员、高级技术人员、其他负有保密义务的人员 | 不是所有岗位都能签 |
| **限制范围** | 与公司生产同类产品或经营同类业务的有竞争关系的单位 | 范围过宽可主张不合理 |
| **限制期限** | 最长不超过 2 年 | 超过 2 年的部分无效 |
| **竞业补偿** | 公司必须按月支付（通常为离职前 12 个月平均工资的 30%） | 各地有差异 |
| **违约金** | 由协议约定，通常较高 | 仔细看违约金条款 |

### 12.2 2025–2026 竞业执行现状

| 现状 | 说明 | 应对 |
| --- | --- | --- |
| **大厂查竞业增多** | 字节、阿里、美团等竞业诉讼案例增加 | 别心存侥幸 |
| **未支付补偿** | 连续 3 个月未支付可请求解除 | 保留支付记录 |
| **泛竞业争议** | 公司限制你去所有互联网公司 | 可主张范围过宽 |
| **竞业 vs 保密** | 竞业需单独签协议 + 支付补偿 | 仔细看协议条款 |

> 来源：竞业限制参考《劳动合同法》第二十三条、第二十四条；司法实践参考各地劳动仲裁案例

## 十三、试用期权益保障

### 13.1 试用期法定权益

| 权益 | 法律规定 | 实操注意 |
| --- | --- | --- |
| **试用期时长** | 合同 1–3 年 → ≤ 2 个月；3 年以上 → ≤ 6 个月 | 只能约定一次，不得延长 |
| **试用期工资** | ≥ 约定工资的 80%，且 ≥ 当地最低工资标准 | 低于 80% 可主张补差 |
| **社保公积金** | 试用期必须缴纳 | 不缴社保违法，可投诉 |
| **解除条件** | 公司需证明「不符合录用条件」 | 录用条件须入职时书面告知 |
| **提前通知** | 试用期内解除需提前 3 天通知 | 无需支付经济补偿（公司有过错除外） |
| **劳动合同** | 入职 1 个月内必须签订 | 超过 1 个月未签，可主张双倍工资 |

### 13.2 试用期解除的举证责任

| 维度 | 说明 |
| --- | --- |
| **公司举证** | 公司必须证明你「不符合录用条件」 |
| **录用条件** | 必须在入职时书面告知，口头不算 |
| **无理由解除** | 试用期内无理由解除需支付经济补偿（N） |
| **违法解除** | 无法举证「不符合录用条件」= 违法解除，可主张 2N |

> 来源：试用期权益参考《劳动合同法》第十九条、第二十一条、第三十九条

## 十四、劳动仲裁流程

### 14.1 仲裁适用范围

| 纠纷类型 | 是否可仲裁 | 说明 |
| --- | --- | --- |
| **工资拖欠** | 是 | 最常见 |
| **加班费** | 是 | 需有加班证据 |
| **违法解除** | 是 | 主张赔偿金 2N |
| **社保补缴** | 否 | 需投诉劳动监察 |
| **公积金** | 否 | 需投诉住房公积金管理中心 |
| **竞业补偿** | 是 | 公司未支付竞业补偿 |

### 14.2 仲裁流程

| 步骤 | 内容 | 时间 |
| --- | --- | --- |
| **收集证据** | 劳动合同、工资条、考勤记录、邮件/IM 记录 | 1–2 周 |
| **提交申请** | 到当地劳动仲裁委员会提交仲裁申请书 | 1 天 |
| **受理** | 仲裁委 5 个工作日内决定是否受理 | 5 天 |
| **开庭** | 双方举证、质证、辩论 | 受理后 45 天内 |
| **裁决** | 仲裁委出具裁决书 | 开庭后 15 天内 |
| **执行** | 公司不执行可申请法院强制执行 | 裁决生效后 |

## 十五、劳动仲裁流程进阶

### 15.1 仲裁前准备

| 步骤 | 内容 | 时间 |
| --- | --- | --- |
| **收集证据** | 劳动合同、工资条、考勤记录、邮件/IM记录 | 1-2周 |
| **确认管辖** | 向用人单位所在地或劳动合同履行地的仲裁委申请 | 1天 |
| **确定请求** | 明确仲裁请求（金额、事项），请求需具体、可量化 | 1天 |
| **时效检查** | 确认是否在一年仲裁时效内 | 1天 |

### 15.2 仲裁申请书要点

- **当事人信息**：申请人姓名、住址、联系方式；被申请人名称、住所地、法定代表人
- **仲裁请求**：逐项列明（如：支付拖欠工资XX元、支付经济补偿金XX元）
- **事实与理由**：按时间顺序描述入职、工作、争议发生过程
- **证据清单**：列明证据名称、证明目的

### 15.3 一裁终局情形

以下争议仲裁裁决为终局裁决，用人单位不能起诉（劳动者不服仍可起诉）：
- 追索劳动报酬、工伤医疗费、经济补偿或赔偿金，不超过当地月最低工资标准十二个月金额的争议
- 因执行国家劳动标准在工作时间、休息休假、社会保险等方面发生的争议

### 15.4 裁决执行

- **自动履行**：裁决生效后，用人单位应在规定期限内履行
- **强制执行**：用人单位不履行的，可向法院申请强制执行
- **执行时效**：裁决生效后二年内申请强制执行
- **执行措施**：冻结银行账户、查封财产、限制高消费、纳入失信名单

## 十六、工伤认定流程详解

### 16.1 工伤认定条件

| 情形 | 是否构成工伤 | 说明 |
| --- | --- | --- |
| **工作时间+工作场所+工作原因** | 是 | 最典型的工伤情形 |
| **上下班途中非本人主要责任交通事故** | 是 | 需交警部门出具事故认定书 |
| **突发疾病死亡或48小时内抢救无效死亡** | 视同工伤 | 在工作时间和工作岗位 |
| **因工外出期间受伤** | 是 | 因工作原因受到伤害或下落不明 |
| **上下班途中自己摔倒** | 否 | 非交通事故或本人主要责任 |

### 16.2 工伤认定流程

| 步骤 | 时间 | 内容 |
| --- | --- | --- |
| **单位申报** | 事故发生后30日内 | 向统筹地区社会保险行政部门提出工伤认定申请 |
| **个人申报** | 事故发生后1年内 | 单位不申报的，个人或近亲属可自行申报 |
| **调查核实** | 受理后60日内 | 社会保险行政部门调查核实 |
| **作出决定** | 受理后60日内 | 作出工伤认定决定 |
| **送达** | 作出决定后20日内 | 送达申请人和用人单位 |

### 16.3 工伤待遇

| 待遇项目 | 内容 |
| --- | --- |
| **医疗费** | 工伤保险基金支付（符合工伤保险诊疗项目目录） |
| **停工留薪期工资** | 原工资福利待遇不变，由用人单位支付 |
| **伤残待遇** | 根据劳动能力鉴定等级，享受一次性伤残补助金、伤残津贴等 |
| **工亡待遇** | 丧葬补助金、供养亲属抚恤金、一次性工亡补助金 |

## 十八、离职流程详解

### 18.1 正式离职流程

| 步骤 | 操作 | 时间要求 | 注意事项 |
|------|------|---------|---------|
| 1. 提交辞职信 | 书面提交辞职申请 | 提前30天（试用期3天） | 保留送达证据 |
| 2. 工作交接 | 完成交接清单 | 离职前 | 确保交接完整 |
| 3. 归还物品 | 归还公司设备、资料 | 离职前 | 获取归还确认 |
| 4. 离职证明 | 获取离职证明 | 离职当日 | 必须获取 |
| 5. 社保转移 | 办理社保转移手续 | 离职后15天内 | 避免断缴 |
| 6. 档案转移 | 人事档案转移 | 离职后 | 新单位接收 |

- **辞职信提交**：正式员工需提前30天书面提交辞职信，试用期员工提前3天，可通过邮件、纸质信件等方式提交，保留送达证据。
- **工作交接**：确保工作交接完整，制作交接清单，双方签字确认，避免后续纠纷，交接内容包括工作文件、客户资料、项目进度等。
- **离职证明**：必须获取离职证明，这是入职新单位的必备材料，离职证明应包含工作时间、职位、离职原因等信息。

### 18.2 离职证明重要性

| 用途 | 说明 | 必要性 |
|------|------|--------|
| 入职新单位 | 新单位要求提供离职证明 | 必须 |
| 社保转移 | 办理社保转移需要 | 必须 |
| 公积金提取 | 部分地区提取需要 | 部分需要 |
| 失业保险 | 申领失业保险金需要 | 必须 |
| 工龄证明 | 证明工作经历 | 重要 |

- **入职新单位**：绝大多数新单位要求提供离职证明，确认已与前单位解除劳动关系，避免双重劳动关系纠纷。
- **社保转移**：离职证明是办理社保转移的必要材料，没有离职证明无法办理社保转移手续。
- **失业保险**：申领失业保险金需要提供离职证明，证明非自愿离职，离职原因需为"非本人意愿中断就业"。

### 18.3 离职交接清单

| 交接项目 | 具体内容 | 确认方式 |
|---------|---------|---------|
| 工作文件 | 项目文档、客户资料、工作总结 | 清单签字 |
| 电子资料 | 电脑文件、邮箱数据、云盘资料 | 备份确认 |
| 公司物品 | 电脑、手机、门禁卡、工牌 | 归还签字 |
| 账号权限 | 系统账号、VPN权限、邮箱 | 注销确认 |
| 客户交接 | 客户联系方式、沟通记录 | 移交签字 |
| 财务结清 | 借款、报销、奖金 | 结算确认 |

- **工作文件**：整理所有工作文件，制作详细交接清单，与接替人员逐项确认，确保工作连续性。
- **电子资料**：备份电脑文件、邮箱数据、云盘资料，确保公司数据安全，同时删除个人隐私信息。
- **账号权限**：注销公司系统账号、VPN权限、邮箱，确保信息安全，避免离职后仍有权限访问公司系统。

## 十九、竞业限制详解

### 19.1 竞业限制基本规定

| 规定 | 内容 | 说明 |
|------|------|------|
| 适用人员 | 高级管理人员、高级技术人员、其他负有保密义务的人员 | 非全员适用 |
| 限制期限 | 最长不超过2年 | 超过2年部分无效 |
| 竞业范围 | 与原单位生产或经营同类产品、从事同类业务 | 不得过于宽泛 |
| 经济补偿 | 按月支付，不低于离职前12个月平均工资的30% | 必须支付 |
| 违约金 | 按合同约定，一般为补偿金的2-3倍 | 不得过高 |

- **适用人员**：竞业限制仅适用于高级管理人员、高级技术人员、其他负有保密义务的人员，普通员工一般不受竞业限制约束。
- **经济补偿**：用人单位必须按月支付竞业限制补偿金，补偿标准不低于离职前12个月平均工资的30%，且不低于当地最低工资标准。
- **违约金**：劳动者违反竞业限制约定的，需支付违约金，违约金一般为补偿金的2-3倍，但不得过高，否则可请求法院调整。

### 19.2 竞业限制补偿金计算

| 计算项目 | 计算方法 | 说明 |
|---------|---------|------|
| 月补偿金 | 离职前12个月平均工资×30% | 不低于当地最低工资标准 |
| 补偿期限 | 最长24个月 | 按月支付 |
| 总补偿金 | 月补偿金×补偿月数 | 税前金额 |
| 税费 | 按照"工资薪金所得"缴税 | 个人所得税 |

- **月补偿金**：以劳动者离职前12个月的平均工资为基数，乘以30%计算月补偿金，但不得低于当地最低工资标准。
- **补偿期限**：竞业限制期限最长不超过24个月，用人单位可在24个月内提前通知解除竞业限制。
- **税费处理**：竞业限制补偿金按照"工资薪金所得"缴纳个人所得税，由支付方代扣代缴。

### 19.3 竞业限制注意事项

| 事项 | 说明 | 建议 |
|------|------|------|
| 协议签订 | 竞业限制协议需书面签订 | 仔细阅读条款 |
| 补偿金领取 | 按月领取，保留凭证 | 及时领取 |
| 就业限制 | 不得在竞争单位就业 | 避免违约 |
| 自由职业 | 自由职业可能受限 | 确认范围 |
| 解除协议 | 可协商解除或单方解除 | 了解解除条件 |

- **协议签订**：竞业限制协议需书面签订，劳动者应仔细阅读条款，了解竞业范围、补偿标准、违约金等关键内容。
- **补偿金领取**：竞业限制补偿金按月支付，劳动者应按时领取，保留领取凭证，若用人单位连续3个月未支付，可请求解除竞业限制。
- **就业限制**：在竞业限制期限内，劳动者不得在与原单位生产或经营同类产品、从事同类业务的有竞争关系的其他用人单位就业。

## 二十、试用期权益详解

### 20.1 试用期基本规定

| 规定 | 内容 | 说明 |
|------|------|------|
| 试用期时长 | 劳动合同期限3个月-1年：不超过1个月；1-3年：不超过2个月；3年以上：不超过6个月 | 以合同期限为准 |
| 试用期次数 | 同一用人单位与同一劳动者只能约定一次试用期 | 不得重复约定 |
| 试用期工资 | 不低于本单位相同岗位最低档工资或者劳动合同约定工资的80%，并不得低于当地最低工资标准 | 双重标准 |
| 试用期社保 | 必须缴纳社会保险 | 从入职第一天起 |

- **试用期时长**：试用期时长与劳动合同期限挂钩，合同期限越长试用期越长，但最长不超过6个月，超过部分无效。
- **试用期工资**：试用期工资不得低于本单位相同岗位最低档工资或劳动合同约定工资的80%，且不得低于当地最低工资标准。
- **试用期社保**：用人单位必须从劳动者入职第一天起缴纳社会保险，不得以试用期为由不缴纳社保。

### 20.2 试用期解除劳动合同

| 情形 | 用人单位解除条件 | 劳动者解除条件 |
|------|----------------|--------------|
| 试用期内解除 | 证明不符合录用条件 | 提前3天通知 |
| 试用期后解除 | 需符合法定条件 | 提前30天通知 |
| 违法解除 | 需支付赔偿金 | 可要求恢复劳动关系 |

- **用人单位解除**：用人单位在试用期内解除劳动合同，需证明劳动者不符合录用条件，且需在试用期满前作出解除决定，否则视为试用期已通过。
- **劳动者解除**：劳动者在试用期内解除劳动合同，需提前3天通知用人单位，无需说明理由，3天后可离职。
- **违法解除**：用人单位违法解除劳动合同（如无正当理由解除），需支付赔偿金（经济补偿金的2倍），劳动者可要求恢复劳动关系。

### 20.3 试用期权益保障

| 权益 | 具体内容 | 维权方式 |
|------|---------|---------|
| 工资权益 | 试用期工资不低于约定工资80% | 劳动仲裁 |
| 社保权益 | 试用期必须缴纳社保 | 社保投诉 |
| 工伤权益 | 试用期工伤与正式员工同等 | 工伤认定 |
| 解除权益 | 用人单位需证明不符合录用条件 | 劳动仲裁 |

- **工资权益**：试用期工资不得低于约定工资的80%，若用人单位未足额支付，劳动者可向劳动监察部门投诉或申请劳动仲裁。
- **社保权益**：试用期必须缴纳社会保险，用人单位以试用期为由不缴纳社保的，劳动者可向社保部门投诉。
- **工伤权益**：试用期员工发生工伤，与正式员工享受同等工伤保险待遇，用人单位不得以试用期为由拒绝赔偿。
