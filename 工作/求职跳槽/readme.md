## 通用原则

- **跳槽不是解药**：工作不顺心，先分清是「行业问题、公司问题、岗位问题」还是「自己状态问题」；带着上一份工作没解决的病根跳槽，大概率在下家复发。
- **行情冷时先稳住**：2025–2026 年市场整体偏冷，裸辞风险高；除非有明确 offer 或半年以上现金流缓冲，不建议冲动裸辞。
- **每一次跳槽要有明确目标**：薪资涨幅、技术/业务成长、行业赛道、工作生活平衡——每次跳槽至少满足两个明确目标，否则不如不动。
- **背景调查留好证据**：简历经历、绩效、职位与时间线要能自圆其说；离职前和几位前同事、前上司维护好关系，背调电话可能打给任何一个人。
