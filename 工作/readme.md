## 国内行情一句话

2026 年程序员就业「冰火两重天」：传统 CRUD/前端/测试岗招聘量较 2021 高峰跌 75%–85%、薪资回落约 30%；而 **AI 应用（RAG/Agent/微调）、信创（国产软硬件替代）、鸿蒙开发** 逆势扩招。AI 科学家/负责人平均月薪约 13.3 万（脉脉 2026），「35 岁危机」本质是技能危机——懂业务 + 会用 AI 的资深者正被价值重估。详见 [程序员 · 行业情况](程序员/行业情况.md)。
