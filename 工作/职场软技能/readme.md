## 通用原则

- **软技能可以刻意练习**：与写代码、做运营一样，汇报、谈判、拒绝都是可拆解、可复盘、可迭代的技能，别把它归为「性格问题」。
- **先倾听，再表达**：80% 的沟通冲突源于没听懂对方在问什么；先复述对方的诉求，再给方案，沟通效率立刻提升。
- **功劳要让别人看见**：做得好不如「做得对且被看见」，定期同步、量化成果、让关键人知道你的贡献，是你应得的职业经营。
- **留痕大于口头**：重要结论、变更、承诺一律邮件或 IM 书面确认，既保护自己，也方便追溯——2025 年后越来越多企业用聊天记录与邮件作为绩效、仲裁证据。
